# Computer Programming 1 Resources

## Knowledge

- [CS50: Introduction to Computer Science (Harvard, free via edX/CS50.harvard.edu)](https://cs50.harvard.edu/x/)
  The standard-bearer intro CS course — covers program structure, arrays, algorithms, and more, primarily in C before moving to Python. Use for: pacing and topic ordering, and its C material specifically, since most intro resources skip C++/C entirely.
- [MIT OpenCourseWare — Introductory Programming collection](https://ocw.mit.edu/collections/introductory-programming/)
  Free full course materials (lecture notes, problem sets) across MIT's intro programming offerings, spanning Python, Java, and C. Use for: a second, university-level explanation of any concept that isn't landing.
- [Dev.java (Oracle's official free Java learning site)](https://dev.java/)
  Official, actively maintained beginner-to-intermediate Java material. Use for: Java-specific syntax and idiom, kept current with the language's actual defaults (not a stale third-party tutorial).
- [MDN Web Docs — JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
  The canonical JavaScript reference, maintained by browser vendors and the web standards community. Use for: JavaScript syntax and behavior, especially anywhere it differs from the other three languages (dynamic typing quirks, `this`, prototypes).
- [Google's C++ Education](https://google.github.io/styleguide/cppguide.html) and [cppreference.com](https://en.cppreference.com/)
  cppreference is the definitive, precise C++ language/standard-library reference; Google's guide covers real-world idiom and style. Use for: C++ syntax, and flagging where "technically legal" and "actually a good idea" diverge (memory/pointers especially).
- [W3Schools](https://www.w3schools.com/)
  Not a primary source, but a fast, consistent-format side-by-side syntax lookup across all four languages. Use for: a quick "what's the equivalent line in language X" check while drafting a four-way comparison — always verify against the primary references above before citing.

## Wisdom (Communities)

- [r/learnprogramming](https://www.reddit.com/r/learnprogramming/)
  Large, beginner-friendly, well-moderated community explicitly for people learning to code. Use for: "is this normal to find confusing," debugging help, and sanity-checking whether a lesson's difficulty is well-calibrated for a true beginner.
- [Stack Overflow](https://stackoverflow.com/)
  Not a community to "join" in the traditional sense, but the highest-signal place for a specific, precise error message or syntax question across all four languages. Use for: verifying an exact error message or edge-case behavior before it goes in a lesson.

## Gaps

- No single free resource cleanly covers Python + Java + JavaScript + C++ side by side at the same depth — this course's four-way lessons are synthesized from the language-specific primary sources above, not copied from one existing "polyglot" course. Revisit if a strong dedicated resource surfaces.
