# Mission: Computer Programming 1

## Why
Want real, transferable programming fluency — not "knows Python syntax" but "understands what a variable, a loop, or a function actually *is*," well enough that picking up a fifth language later is a syntax lookup, not a re-learn. Seeing every concept side by side in Python, Java, JavaScript, and C++ from day one is the point: it makes obvious which parts of programming are universal ideas and which parts are just one language's spelling of them.

## Success looks like
- Can write and explain a short program (variables, conditionals, a loop, a function) correctly in all four languages, not just one.
- Explains *why* the same line looks different across languages (static vs dynamic typing, compiled vs interpreted, semicolons and braces vs indentation) rather than just memorizing the differences.
- Reads someone else's short program in any of the four languages and correctly traces what it does by hand, without running it.
- Comfortable with the basic building blocks — strings, arrays/lists, console I/O, and a first class/object — well enough that Computer Programming 2's data structures and OOP depth doesn't require re-teaching the basics.
- Can debug a small program by reading the error message and reasoning about program state, not just guessing and re-running.

## Constraints
- Every core concept is shown in all four languages in parallel (per explicit request) — this is a larger scope per lesson than a single-language course, so lessons stay tightly scoped to one concept at a time to keep the four-way comparison readable.
- Second course in the STEM+ "Computer Programming" strand, right after Computer Programming Ethics — assumes the ethical defaults from that course, doesn't re-teach them.
- No assigned textbook or standards body — self-designed sequence, informed by [CS50](https://cs50.harvard.edu/x/) and [MIT's Introductory Programming OCW collection](https://ocw.mit.edu/collections/introductory-programming/) for pacing and topic ordering. See `NOTES.md` for the unit plan.
- Assumes zero prior programming experience — this is the first from-scratch programming course on STEM+.

## Out of scope
- Data structures beyond arrays/lists, recursion, algorithmic complexity, and deeper OOP (inheritance, interfaces) — all deferred to Computer Programming 2.
- Framework- or platform-specific material (web frameworks, mobile SDKs, build tooling deep-dives) — this course is about the languages themselves, not the ecosystems built on top of them.
