1. What is the key difference between "declaring" a variable and "assigning" it a value?

Some languages combine both steps into one; others separate them, or require the type to be stated explicitly at declaration time.

2. Fill in the blank: Java and C++ require a ___ keyword (like int) the first time a variable is declared, so the compiler knows in advance how much memory to reserve.

Python never needs a type keyword at all; JavaScript needs a declaration keyword (let/const) but no type.

3. Consider this JavaScript code, then answer both parts:

let score = 10;
score = 20;

const limit = 100;
limit = 200;

(a) What happens on the line score = 20;?

(b) What happens on the line limit = 200;?

(a) let allows reassignment later. (b) const locks a variable to its initial value; attempting to reassign it is an error.

4. Why does this Java code fail to compile?

int age = 16;
age = "sixteen"; // compile error

Because age was declared as an int, the compiler rejects any later use inconsistent with that declared type, before execution ever begins.

5. Consider this Python code, then answer both parts:

age = 16
age = "sixteen"

(a) What happens when this code runs?

(b) Why does Python allow this while the equivalent Java code would be rejected?

(a) Python doesn't check whether this is sensible until (or unless) the code actually executes. (b) This is the core static-vs-dynamic distinction: when the type check happens, not whether one exists.

6. Which pairing correctly matches languages in this course to their typing discipline?

Java and C++ check types before the program runs; Python and JavaScript check types while it runs.

7. Consider this Java code, then answer both parts:

int a = 9;
int b = 2;
int result = a / b;

(a) What is the value of result after this runs?

(b) Fill in the blank: 17 % 5 evaluates to ___ in any of the four languages.

(a) 9 / 2 is 4.5, but int-divided-by-int in Java truncates the decimal portion, giving 4. (b) 17 divided by 5 leaves a remainder of 2 — the % operator behaves identically across all four languages.

8. Fill in the blank: Python's dedicated exponent operator, not available in the other three languages, is ___.

7 ** 2 is 49 in Python; Java, JavaScript, and C++ all require a library function instead.

9. Consider this Python line, then answer both parts:

is_open = is_weekday and not is_holiday

(a) What is the Java equivalent of this expression's logic?

(b) Java, JavaScript, and C++ spell logical OR using which symbol?

(a) Java, JavaScript, and C++ spell "and" and "not" as symbols: && and !. (b) This is purely a spelling difference from Python's or — the behavior is identical.

10. Consider the expression 5 > 3 in any of the four languages, then answer both parts:

(a) What type of value does a comparison expression like this always produce?

(b) Which statement about comparison operator symbols across the four languages is correct?

(a) Comparisons always produce a boolean result. (b) These six symbols are identical across Python, Java, JavaScript, and C++.
