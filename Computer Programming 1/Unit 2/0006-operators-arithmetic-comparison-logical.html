Operators — Arithmetic, Comparison, and Logical

The symbols that combine and compare values are almost identical across languages — except in one place Python breaks the pattern.

Lesson 7 → Contents Glossary →

An operator is a symbol that performs an operation on one or more values, called operands. You've already used one without naming it: the = in every variable assignment so far. This lesson covers three families that show up constantly: arithmetic, comparison, and logical operators.

Arithmetic operators

Python 
total = 7 + 3   # 10
diff = 7 - 3    # 4
product = 7 * 3 # 21
quotient = 7 / 3   # 2.333...
remainder = 7 % 3  # 1
power = 7 ** 2     # 49, Python-only spelling
Java 
int total = 7 + 3;   // 10
int diff = 7 - 3;    // 4
int product = 7 * 3; // 21
int quotient = 7 / 3;   // 2 — integer division truncates
int remainder = 7 % 3;  // 1
JavaScript 
let total = 7 + 3;   // 10
let diff = 7 - 3;    // 4
let product = 7 * 3; // 21
let quotient = 7 / 3;   // 2.333...
let remainder = 7 % 3;  // 1
let power = 7 ** 2;     // 49
C++ 
int total = 7 + 3;   // 10
int diff = 7 - 3;    // 4
int product = 7 * 3; // 21
int quotient = 7 / 3;   // 2 — integer division truncates
int remainder = 7 % 3;  // 1

+, -, *, /, and % (remainder, also called modulo) work identically across all four languages. One catch shows up in Java and C++: dividing two int values with / truncates the decimal portion instead of rounding, because the result of an int-divided-by-int is defined to be an int. Python and JavaScript don't have this surprise, since / always produces a precise result. Python also has a dedicated exponent operator, **, that the other three languages don't — they use a library function instead.

Comparison operators

== (equal to), != (not equal to), <, >, <=, and >= work the same way, with the same symbols, in all four languages, and each produces a boolean (true/false, or True/False in Python) result. JavaScript has one extra wrinkle worth knowing about — a stricter === — but that's a JavaScript-specific detail saved for a later lesson, once you've seen more of JavaScript's type coercion behavior.

Logical operators — where Python breaks the pattern

Python 
is_open = is_weekday and not is_holiday
can_enter = has_ticket or is_staff
Java 
boolean isOpen = isWeekday && !isHoliday;
boolean canEnter = hasTicket || isStaff;
JavaScript 
let isOpen = isWeekday && !isHoliday;
let canEnter = hasTicket || isStaff;
C++ 
bool isOpen = isWeekday && !isHoliday;
bool canEnter = hasTicket || isStaff;

Java, JavaScript, and C++ spell "and," "or," and "not" as symbols: &&, ||, !. Python spells them as actual English words: and, or, not. They behave identically — this is purely a spelling difference, not a behavioral one — but it's the single most common source of small syntax errors when switching between Python and the other three languages, so it's worth committing to memory deliberately rather than relying on habit.

Definition An operator is a symbol that performs an operation — arithmetic, comparison, or logical — on one or more operands (the values it acts on). 7 + 3 has the operator + and operands 7 and 3.
Why it matters here Nearly every line of real code you write from here on will contain at least one of these operators. Getting comfortable with where they're identical across languages — and the two places they're not (integer division, logical-operator spelling) — removes a whole class of small, frustrating bugs before they happen.

Check your recall

1. What happens when you divide two int values with / in Java or C++?

7 / 3 produces 2 in Java and C++, not 2.333..., because the result type is fixed to int.

2. How does Python spell the logical AND operator, compared to the other three languages?

This is purely a spelling difference — the behavior is identical across all four languages.

3. What does the % operator compute?

7 % 3 is 1, since 7 divided by 3 leaves a remainder of 1. This works identically in all four languages.

5. Fill in the blank: Python's dedicated exponent operator, not shared by the other three languages, is ___.
