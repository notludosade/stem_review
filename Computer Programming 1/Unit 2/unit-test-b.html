1. In Python, writing count = 5 both introduces the variable's name and gives it a value in one step. What term describes introducing a variable's name (and sometimes its type) for the first time, as distinct from giving it a value?

Declaring introduces a name (and sometimes a type); assigning gives it a value. Python combines both into one step, but the concepts are distinct.

2. Fill in the blank: unlike Python, Java and C++ require you to state a variable's ___ the first time it's declared, since both languages need to know in advance how much memory to reserve.

JavaScript sits in between: it needs a declaration keyword (let/const) but no type, since it figures out the type from the value itself.

3. Consider this JavaScript code, then answer both parts:

const maxPlayers = 4;
let currentPlayers = 4;

currentPlayers = 3;
maxPlayers = 5;

(a) What happens on the line currentPlayers = 3;?

(b) What happens on the line maxPlayers = 5;?

(a) let allows reassignment later. (b) Attempting to reassign a const variable is an error — the JavaScript equivalent of Java's final or C++'s const.

4. Why does this pattern refuse to compile in Java and C++, while running fine in Python?

int age = 16;
age = "sixteen"; // compile error

A statically typed language checks a variable's type before the program ever runs and rejects anything inconsistent with its declared type.

5. Consider this JavaScript code, then answer both parts:

let count = 5;
count = "five";

(a) What happens when this code runs?

(b) What is this behavior called?

(a) count simply now refers to a string instead of a number. (b) A dynamically typed variable's type is just whatever value it currently holds.

6. A classmate says: "JavaScript uses curly braces just like Java, so they must have the same typing discipline." What's wrong with this reasoning?

Java and C++ are statically typed; Python and JavaScript are dynamically typed — that split doesn't track brace-based versus indentation-based syntax at all.

7. Consider this C++ code, then answer both parts:

int x = 14;
int y = 4;
int result = x / y;

(a) Fill in the blank: result equals ___.

(b) If x % y were computed instead, using the same values, what would the result be?

(a) 14 / 4 is 3.5, but int-divided-by-int in C++ truncates to 3. (b) 14 % 4 leaves a remainder of 2, since 4 goes into 14 three times with 2 left over.

8. Fill in the blank: to compute 7 to the power of 2 in Java, JavaScript, or C++, you need a library function, since none of those three languages has a dedicated exponent operator like Python's ___.

7 ** 2 is 49 in Python — a Python-only spelling for exponentiation.

9. Consider this Java line, then answer both parts:

boolean canVote = isCitizen && isOldEnough;

(a) Fill in the blank: the equivalent Python line would spell && as the word ___.

(b) Which statement about this spelling difference is correct?

(a) Python spells logical AND as the word and. (b) This is the single most common source of small syntax errors switching between Python and the other three languages, but the behavior never changes.

10. Consider the expression 10 <= 10 in any of the four languages, then answer both parts:

(a) What value does this expression produce?

(b) Which of the four languages uses a different symbol for "less than or equal to" than the others?

(a) Comparisons always produce a boolean. (b) Comparison operator symbols are identical across all four languages in this course.
