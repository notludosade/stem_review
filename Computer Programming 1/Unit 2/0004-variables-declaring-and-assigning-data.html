Variables — Declaring and Assigning Data

A variable is a name attached to a piece of data — how you attach it differs by language.

Lesson 5 → Contents Glossary →

A variable is a named location that holds a value, which your program can read or change later. Every language in this course has variables — the idea is universal — but how you create one, and how much you have to tell the language up front, varies.

Python 
age = 16
age = 17  # reassigning works with no extra keywords
Java 
int age = 16;
age = 17; // no type keyword needed again — it was fixed at declaration
JavaScript 
let age = 16;
age = 17; // let allows reassignment; const would not
C++ 
int age = 16;
age = 17; // no type keyword needed again — it was fixed at declaration

Python needs nothing but a name and a value — age = 16 both creates the variable and assigns it in one step. Java and C++ require a type keyword (int) the first time a variable is declared, because both languages need to know in advance how much memory to reserve and what operations will be valid on that value. JavaScript sits in between: it needs a declaration keyword (let or const) but no type, since JavaScript figures out the type from the value itself.

let versus const in JavaScript

JavaScript actually offers two ways to declare a variable: let, which allows reassignment later, and const, which locks the variable to its initial value — attempting to reassign a const is an error. Java and C++ have an equivalent idea using the final and const keywords respectively, though those are used less by default than JavaScript's convention of preferring const unless reassignment is actually needed.

Definition Declaring a variable means introducing its name (and in some languages, its type) to the program for the first time. Assigning means giving it a value. Some languages combine both into one step; others separate them, or require the type to be stated explicitly at declaration time.
Why it matters here Whether a language asks you to state a type up front is not a small stylistic detail — it's the surface expression of a much bigger difference between these four languages, which the next lesson covers directly: static versus dynamic typing.
