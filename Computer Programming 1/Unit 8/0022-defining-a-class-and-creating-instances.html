Defining a Class and Creating Instances

Unit 6 grouped many values of the same kind together. A class groups the different pieces of one thing together.

Lesson 23 → Contents Glossary →

A class is a blueprint describing what a kind of thing looks like — its name, its data, eventually its behavior. An instance (or object) is one concrete thing built from that blueprint, with its own copy of the data. Every language runs a special method — a constructor — automatically whenever a new instance is created.

Python 
class Dog:
    def __init__(self, name):
        self.name = name

buddy = Dog("Buddy")
print(buddy.name)  # Buddy
Java 
class Dog {
    String name;
    Dog(String name) {
        this.name = name;
    }
}

Dog buddy = new Dog("Buddy");
System.out.println(buddy.name); // Buddy
JavaScript 
class Dog {
    constructor(name) {
        this.name = name;
    }
}

let buddy = new Dog("Buddy");
console.log(buddy.name); // Buddy
C++ 
class Dog {
public:
    std::string name;
    Dog(std::string name) : name(name) {}
};

Dog buddy("Buddy");
std::cout << buddy.name << std::endl; // Buddy

Python's __init__, Java and C++'s method sharing the class's own name, and JavaScript's constructor are all the same idea: the method that runs the moment Dog("Buddy") or new Dog("Buddy") executes, setting up that instance's own data. Inside it, self (Python) and this (Java, JavaScript) refer back to the specific instance being built — C++ achieves the same thing implicitly, without needing to name it. Notice the C++ example also needed public: before name — C++ class members are private by default, a detail this course returns to in Lesson 24.

Definition A class is a blueprint defining what data and behavior its instances have. An instance (or object) is one concrete realization of a class, with its own independent copy of that data. A constructor is the special method that runs automatically when a new instance is created.
Why it matters here Lesson 16 grouped many values of the same kind — a list of scores. A class groups the different pieces that together describe one real thing — a dog's name, a user's email, a game character's health. Once that shape is defined once as a class, creating a hundred distinct dogs is as easy as calling the constructor a hundred times.
