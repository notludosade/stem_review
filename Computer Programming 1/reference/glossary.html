Every term introduced in this course, defined once and kept consistent everywhere it's used.

Program Anatomy & Setup

Machine code

The raw binary instructions a CPU directly understands. Every language eventually gets translated into this, one way or another — by a compiler, an interpreter, or a JIT compiler.

Bytecode

An intermediate translation of source code — not machine code yet, but not the original source either. Java compiles to bytecode, which then runs on the Java Virtual Machine (JVM).

JIT (just-in-time) compilation

A hybrid execution strategy that compiles the most frequently-used code to real machine code while the program is already running. Used by the JVM and modern JavaScript engines like V8.

Entry point

The specific location in a program where execution begins. Python and JavaScript treat the top of the file as the entry point implicitly; Java and C++ require you to define one explicitly, by name.

Comment

A piece of source text the compiler or interpreter skips entirely, meant only for a human reader. Worth writing when it explains why code does something, not what it does.

Variables, Types & Operators

Variable

A named location that holds a value your program can read or change later. Declaring and assigning one differs across languages, but the concept is universal.

Static typing

A discipline where a variable's type is fixed at declaration and checked before the program runs. Java and C++ are statically typed.

Dynamic typing

A discipline where a variable's type is determined by its current value and checked only while the program is running. Python and JavaScript are dynamically typed.

Operator

A symbol that performs an operation — arithmetic, comparison, or logical — on one or more operands.

Operand

A value that an operator acts on. In 7 + 3, the operands are 7 and 3.

Control Flow

Control flow

The order in which a program's statements execute. If statements, while loops, and for loops are the basic tools for controlling it.

If statement

Branches execution down one of two or more paths based on a boolean condition.

While loop

Repeats a block of code as long as its condition remains true, re-checked before each repetition. Right choice when the repeat count isn't known in advance.

Infinite loop

A while loop whose condition never becomes false, usually because the loop body never updates whatever the condition depends on.

For loop

Repeats a block a set number of times. Java/JavaScript/C++ use a three-part header (initializer, condition, update); Python iterates over a sequence instead.

Functions

Function

A named, reusable block of code. Defined once, then called by name anywhere its logic needs to run.

Parameter

The named placeholder a function declares for its input, written inside its parentheses at definition time.

Argument

The actual value passed in for a parameter when a function is called.

Return value

The result a function hands back to its caller via a return statement. A function with no return statement produces no value.

Scope

The region of a program where a variable's name is valid. Local scope is a single function; global scope is the whole file or class.

Strings

String

A sequence of characters representing text. In Java and C++, implemented as a class rather than a built-in primitive.

Concatenation

Joining two or more strings end to end into one longer string, typically with the + operator.

Index

A character's position within a string, counting from 0.

Substring

A contiguous piece of a string, extracted by specifying a start and end index.

String interpolation

Embedding a variable reference directly inside a string template, as in Python's f-strings or JavaScript's template literals.

String formatting

Using a template with generic placeholders filled in by a separately supplied list of values, as in Java's String.format or C++'s std::format.

Arrays, Lists & Collections

Array

A fixed-size, indexed collection of values. Its size is set when created and can never grow or shrink.

List

A dynamically-sized, indexed collection that can grow or shrink at runtime, such as Python's list, JavaScript's array, or C++'s std::vector.

Iterate

To visit each element of a collection in turn.

For-each loop

Loop syntax that iterates directly over a collection's elements, rather than counting an index up by hand.

Append / push

Adding a new element to the end of a dynamic collection.

Contains / includes

Testing whether a collection holds a particular value.

Basic I/O

Standard output (stdout)

The default destination a program writes printed text to — almost always the terminal.

Standard input (stdin)

The default source a program reads input from — almost always the keyboard.

File handle

An open connection to a file that a program reads from or writes to, similar to a stream connected to the keyboard. Should be closed once you're done with it.

Intro to Objects & Classes

Class

A blueprint defining what data and behavior its instances have.

Instance (object)

One concrete realization of a class, with its own independent copy of that class's data.

Constructor

The special method that runs automatically when a new instance is created.

Method

A function defined inside a class, describing something instances of that class can do.

Encapsulation

Bundling an object's data with the methods that operate on it, and restricting direct outside access to that data.

Private

Accessible only from within the class itself — enforced by the compiler in Java and C++, enforced in modern JavaScript's #fields, and only a naming convention in Python.
