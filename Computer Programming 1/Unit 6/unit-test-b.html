1. A collection's size is set once, when it's created, and can never change afterward. What is this type of collection called, by this unit's terminology?

An array's size can't change after creation; a list (like Python's list, JavaScript's array, or C++'s std::vector) can grow or shrink at runtime instead.

2. Why does this unit use std::vector for C++ examples instead of a raw fixed-size array, even though C++ supports both?

C++ actually offers both a fixed raw array and a dynamic std::vector; std::vector was chosen to match the other three languages' default, resizable collections.

3. Which language declares a dynamic collection of the numbers 10, 20, and 30 as std::vector<int> numbers = {10, 20, 30};?

This is C++'s syntax for a std::vector; Java's fixed-size equivalent uses int[] instead, and Python and JavaScript use no type keyword at all.

4. Fill in the blank: given the shared 0-based indexing model, if letters = ["a", "b", "c", "d"], then letters[2] equals ___ (just the letter, no quotes).

Index 0 is "a", index 1 is "b", index 2 is "c", and index 3 is "d" — the same 0-based counting used everywhere in this unit.

5. A collection has exactly 3 elements, so its only valid indices are 0, 1, and 2. Code attempts to access index 10. Answer both parts:

(a) What happens in Java when this out-of-range access occurs on an array?

(b) Fill in the blank: reading past the end of a C++ std::vector with square brackets is not a guaranteed error at all — it's ___ behavior, which might crash, return garbage, or silently corrupt memory.

(a) Java raises a clear exception immediately, just as Python raises IndexError. (b) C++ is the riskiest of the four here — undefined behavior gives no guarantee at all, which is exactly why bounds-checked accessors like .at() exist.

6. Answer both parts about for-each loop syntax:

(a) Which of these is the correct for-each loop syntax in Python to print every element n of a list called numbers?

(b) Fill in the blank: Java and C++'s for-each loop instead uses a ___ between the element variable and the collection name, written for (int n ___ numbers).

(a) Python's for loop iterates directly over the sequence — no index counting involved. (b) Java and C++ both spell this with a colon; JavaScript uses of instead.

7. In Python, how do you get the number of elements in a list called scores?

Java and C++ use a size() method call, and JavaScript uses a length property — Python's standalone len() function is the odd one out, consistent with how it measures string length too.

8. A Java ArrayList, a Python list, a JavaScript array, and a C++ std::vector each currently hold [1, 2, 3], and each needs a new element, 4, added to the end. Answer both parts:

(a) What method call adds 4 to the end of the JavaScript array?

(b) Fill in the blank: the equivalent method call on the Java ArrayList is numbers.___(4).

(a) JavaScript spells this push; Python spells the same idea append, and C++ spells it push_back. (b) add is Java's ArrayList name for the same action.

9. Checking whether a value already exists inside a collection is called a membership check. Answer both parts:

(a) How do you check whether numbers (a JavaScript array) contains the value 7?

(b) Fill in the blank: on a Java ArrayList, the equivalent membership check is numbers.___(7).

(a) JavaScript uses the includes method. (b) Java's ArrayList spells the same idea contains — C++'s std::vector is the one language with no built-in membership method at all.

10. In Java, int[] scores = {70, 80, 90}; is defined. Answer both parts:

(a) Which of these operations can be performed directly on this int[] without error?

(b) Fill in the blank: to make scores growable instead, this unit switches from int[] to Java's ___ type.

(a) Reading by index works fine on a fixed-size array — it's only growing the array that's unsupported, since int[] has no append, add, or push method at all. (b) ArrayList is the growable counterpart this unit switches to.
