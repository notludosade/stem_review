Arrays, Lists, and Collections — Fixed vs Dynamic

Instead of separate variables for score1, score2, and score3, a collection holds all of them under one name.

Lesson 17 → Contents Glossary →

A collection groups many values together under a single name, each one reachable by its position. All four languages let you write one out as a literal — a comma-separated list of values in brackets or braces.

Python 
numbers = [10, 20, 30]
Java 
int[] numbers = {10, 20, 30};
JavaScript 
let numbers = [10, 20, 30];
C++ 
std::vector<int> numbers = {10, 20, 30};

They don't all behave the same once created, though. Java's int[] is an array: its size is fixed the moment it's created and can never grow or shrink. Python's list and JavaScript's array are lists — they resize automatically as you add or remove values. C++ actually has both: a raw fixed-size array like Java's, and std::vector, a resizable alternative — which is why std::vector was used above instead of a raw array, to match how the other three languages' default collections behave.

Java — arrays cannot grow 
int[] numbers = {10, 20, 30};
numbers.append(40); // compile error: arrays have no append — size is fixed at creation
C++ — std::vector can grow 
std::vector<int> numbers = {10, 20, 30};
numbers.push_back(40); // fine — the vector resizes itself to fit
Definition An array is a fixed-size, indexed collection of values — its size is set when it's created and can't change. A list is a dynamically-sized, indexed collection that can grow or shrink at runtime, such as Python's list, JavaScript's array, or C++'s std::vector.
Why it matters here Almost no real program works with just one value at a time — user records, test scores, inventory items all arrive as collections. Choosing fixed versus dynamic isn't just a syntax detail: a fixed-size array is faster and more memory-predictable when you know the count in advance, while a dynamic list trades a little of that efficiency for the flexibility of not needing to know the count up front.

Check your recall

1. Why does numbers.append(40) fail to compile on a Java int[]?

Growing a Java array requires creating an entirely new, larger array instead.

2. Why does this lesson use std::vector instead of a raw array for C++?

C++ actually offers both a fixed raw array and a dynamic std::vector, unlike Java which only has the fixed version built in.

3. Which of the four languages' default collection types are dynamically resizable by default?

Java's built-in array and C++'s raw array are both fixed-size by default.
