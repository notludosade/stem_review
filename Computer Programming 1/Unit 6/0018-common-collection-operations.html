Common Collection Operations

Three things you'll do with a collection constantly: measure it, grow it, and ask whether it holds something.

Lesson 19 → Contents Glossary →

Lesson 16 showed that Java's int[] array can't grow. To add elements in Java, this lesson switches to ArrayList — Java's built-in dynamic list, the counterpart to Python's list, JavaScript's array, and C++'s std::vector that Lesson 16 already introduced. That gives all four languages a genuinely comparable, growable collection to work with.

Python 
numbers = [10, 20, 30]
len(numbers)          # 3
numbers.append(40)     # [10, 20, 30, 40]
40 in numbers           # True
Java 
ArrayList<Integer> numbers = new ArrayList<>(List.of(10, 20, 30));
numbers.size();          // 3
numbers.add(40);          // [10, 20, 30, 40]
numbers.contains(40);   // true
JavaScript 
let numbers = [10, 20, 30];
numbers.length;             // 3
numbers.push(40);           // [10, 20, 30, 40]
numbers.includes(40);      // true
C++ 
std::vector<int> numbers = {10, 20, 30};
numbers.size();                                                             // 3
numbers.push_back(40);                                                     // [10, 20, 30, 40]
std::find(numbers.begin(), numbers.end(), 40) != numbers.end();  // true

Measuring the count is len() in Python (a standalone function, like Lesson 14's string length), size() in Java and C++, and the length property in JavaScript — the exact same split seen with strings back in Lesson 14. Adding to the end is append, add, push, and push_back respectively — four different names for the same action. Checking membership is where C++ falls behind again: Python, Java, and JavaScript each offer a direct membership check (in, .contains(), .includes()), but std::vector has no built-in membership method at all — it requires std::find from the <algorithm> header, echoing the same one-liner gap Lesson 14 found with C++ string case conversion.

Definition A collection's length (or size) is its element count. To append (or push) is to add a new element to the end of a dynamic collection. A contains (or includes) check tests whether a collection holds a particular value.
Why it matters here These three operations show up constantly in ordinary programs — checking whether a username is already taken, adding a new score to a leaderboard, reporting how many results a search found. Recognizing that C++ keeps needing an extra step for things the other three languages give you in one call is worth internalizing now, since it will keep showing up throughout this course.

Check your recall

1. Why does this lesson use Java's ArrayList instead of the int[] array from Lesson 16?

ArrayList is Java's dynamic list type, comparable to Python's list or C++'s std::vector.

2. Why does checking membership in a C++ std::vector require std::find instead of a single method call?

This mirrors the same one-liner gap Lesson 14 found with C++ string case conversion.

3. What do append, add, push, and push_back all have in common across the four languages?

Four different names, but the same underlying action in every language.

4. Fill in the blank: adding a new element to the end of a Python list is called ___ing it.

JavaScript spells the same idea push; Java spells it add.

5. Fill in the blank: testing whether a collection holds a particular value is called a ___ check.

JavaScript calls this includes; C++ has no direct equivalent method at all.
