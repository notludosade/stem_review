1. What is the key difference between an array and a list, by this unit's definitions?

An array's size can't change after creation; Python's list, JavaScript's array, and C++'s std::vector all resize automatically instead.

2. Unlike Java, which only provides a fixed-size int[] built in, C++ offers two different collection types side by side. What are they?

C++ actually offers both a fixed raw array and a dynamic std::vector, unlike Java which only has the fixed version built in.

3. Which language declares a fixed-size collection of the numbers 1, 2, and 3 as int[] values = {1, 2, 3};?

This is Java's own syntax for a fixed-size array; C++'s raw array puts the brackets after the variable name instead, and Python and JavaScript use no type keyword at all.

4. Fill in the blank: given the shared 0-based indexing model, if numbers = [10, 20, 30], then numbers[1] equals ___.

Index 0 is 10, index 1 is 20, and index 2 is 30 — counting starts at 0 in every one of the four languages.

5. A collection has exactly 3 elements, so its only valid indices are 0, 1, and 2. Code attempts to access index 5. Answer both parts:

(a) What happens in Python when this out-of-range access occurs?

(b) Fill in the blank: the same out-of-range access on a JavaScript array quietly returns ___ instead of raising any error at all.

(a) Python raises IndexError immediately, just as Java raises ArrayIndexOutOfBoundsException. (b) JavaScript is the outlier here — no error, just a silent undefined, which can hide bugs.

6. Answer both parts about for-each loop syntax:

(a) Which of these is the correct for-each loop syntax in Java to print every element n of an array called numbers?

(b) Fill in the blank: JavaScript's for-each loop instead uses the keyword ___, written as for (const n ___ numbers), rather than the colon Java and C++ use.

(a) Java's enhanced for-loop uses type n : collection with a colon. (b) JavaScript spells the same idea for (const n of numbers), using of instead of a colon.

7. In JavaScript, how do you get the number of elements in an array called items?

This is the exact same length-as-property pattern Lesson 14 found with JavaScript string length — Java and C++ use size() instead, and Python uses the standalone len() function.

8. A Python list, a Java ArrayList, a JavaScript array, and a C++ std::vector each currently hold [5, 10, 15], and each needs a new element, 20, added to the end. Answer both parts:

(a) What method call adds 20 to the end of the Python list?

(b) Fill in the blank: the equivalent method call on the C++ std::vector is numbers.___(20).

(a) Python spells this append; JavaScript spells the same idea push, and Java spells it add. (b) push_back is C++'s name for the same action.

9. Checking whether a value already exists inside a collection is called a membership check. Answer both parts:

(a) How do you check whether numbers (a Python list) contains the value 42?

(b) Fill in the blank: unlike the other three languages, C++'s std::vector has no built-in membership method at all — checking membership instead requires the ___ function from the <algorithm> header.

(a) Python uses the in operator directly. (b) C++ requires std::find(numbers.begin(), numbers.end(), 42) != numbers.end() — the same one-liner gap Lesson 14 found with C++ string case conversion.

10. In Java, int[] numbers = {10, 20, 30}; is defined, and code then attempts numbers.append(40);. Answer both parts:

(a) What happens when this exact code attempts to compile?

(b) Fill in the blank: to get a growable collection of integers in Java instead, this unit switches from int[] to Java's ___ type.

(a) Arrays have a fixed size set at creation, with no way to grow them — growing would require creating an entirely new, larger array. (b) ArrayList is Java's dynamic list type, comparable to Python's list, JavaScript's array, or C++'s std::vector.
