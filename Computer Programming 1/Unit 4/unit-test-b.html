1. A C++ function is defined once: void beep() { std::cout << "Beep!" << std::endl; }. It is then called four separate times later in main(). How many times does "Beep!" actually print?

Each of the four calls executes the body once — defining beep() only once doesn't limit how many times it can be called.

2. Fill in the blank: Python and JavaScript need no return-type keyword to define a function that returns nothing, but Java and C++ require the ___ keyword instead.

void is specific to Java and C++; Python and JavaScript don't require anything stated up front for this.

3. A Java method is written as static double average(double a, double b) { ... }. Based on this unit, why is static needed here specifically, in these introductory examples?

Unit 8's coverage of classes explains this fully; for now, static is what lets these introductory examples call a function directly, with no object involved.

4. A Java method is defined as static String repeatName(String name) { return name + name; }, and then called as String twice = repeatName("Sam");. Answer both parts:

(a) What is "Sam" called, in this call?

(b) Fill in the blank: in the definition, name is called the ___.

(a) "Sam" is the actual value supplied at the call site — the argument. (b) name is the placeholder written inside the function's parentheses when it's defined — the parameter.

5. A JavaScript function is written with no return statement anywhere in its body. What does calling it produce?

A function with no return statement (or Java/C++'s void) simply produces no value — JavaScript's version of "no value" is undefined.

6. A C++ function is defined as int addOne(int n) { return n + 1; }. Answer both parts:

(a) What happens when code tries to compile a call like addOne("5")?

(b) Fill in the blank: Python and JavaScript use ___ typing instead, so this kind of mismatch wouldn't be caught until the line actually runs, if at all.

(a) C++ checks an argument's type against the declared parameter type before the program ever runs, so this call is rejected at compile time. (b) Dynamic typing waits until runtime to discover this kind of mismatch, if it's ever caught at all.

7. A Python function is defined as def triple(n): return n * 3, then called as outcome = triple(5). Answer both parts:

(a) Fill in the blank: after this runs, outcome holds ___.

(b) Suppose triple were rewritten in JavaScript but the return keyword was accidentally left out entirely — just n * 3; as a bare statement inside the function body. What would let outcome = triple(5); store in that version?

(a) 5 * 3 is 15, handed back via return and stored in outcome. (b) Evaluating n * 3 without returning it is not the same as returning it — with no return statement, a JavaScript function produces undefined.

8. This JavaScript function computes an area: function area(width, height) { const total = width * height; return total; }. After calling area(3, 5), a later line runs console.log(total). Answer both parts:

(a) What happens when console.log(total) runs?

(b) Fill in the blank: a variable like total, only valid inside the function where it's declared, is called ___ to that function.

(a) total is created fresh each time area runs and disappears the moment it finishes — this behavior is identical in Python, Java, and C++. (b) That's exactly what local scope means.

9. In Python, discount_rate = 0.10 is declared outside any function, and a function def sale_price(price): return price - (price * discount_rate) reads it directly. Answer both parts:

(a) Why can sale_price read discount_rate, even though discount_rate isn't one of its parameters?

(b) Fill in the blank: this kind of variable — declared outside any function and visible to every function in the file — is called a ___ variable.

(a) Declaring discount_rate at the top level, outside any function, makes it global — visible to every function that follows. (b) That's the definition of a global variable, in contrast to a local one scoped to a single function.

10. A programmer wants a function to always use whatever value is currently stored in a variable defined elsewhere in the file, instead of passing that value in as a parameter. What downside does this unit describe for that habit?

Parameters and return values keep a function's behavior self-contained and predictable from its own inputs alone — leaning on globals instead breaks that predictability.
