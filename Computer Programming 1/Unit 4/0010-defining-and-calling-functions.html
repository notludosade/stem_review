Defining and Calling Functions

Every repeated block of logic is a candidate for a name you can call instead of retyping.

Lesson 11 → Contents Glossary →

A function is a named, reusable block of code. You define it once, giving it a name and a body, then call it by name anywhere you need that logic to run — as many times as you want, without retyping the body.

Python 
def greet():
    print("Hello!")

greet()
greet()
Java 
static void greet() {
    System.out.println("Hello!");
}

greet();
greet();
JavaScript 
function greet() {
    console.log("Hello!");
}

greet();
greet();
C++ 
void greet() {
    std::cout << "Hello!" << std::endl;
}

greet();
greet();

All four versions define greet once and call it twice, printing "Hello!" two times. Python's def keyword and JavaScript's function keyword both need nothing else up front. Java and C++ require a return type before the function name — void here means "this function doesn't produce a value to give back," which the next lesson explains in contrast to functions that do. Java also requires static in this context because Java functions normally live inside a class; you'll see why that matters once Unit 8 covers classes directly.

Definition Defining a function means writing its name and body. Calling a function (also called invoking it) means running that body at a specific point in your program by referring to the function's name followed by parentheses.
Why it matters here Functions are the first tool in this course for avoiding repeated code entirely, rather than just making repeated code shorter to write, which is what loops do. A loop repeats the same block in the same place; a function lets you repeat the same block from many different places in your program.
