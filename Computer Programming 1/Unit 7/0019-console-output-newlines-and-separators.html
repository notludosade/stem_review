Console Output — Newlines and Separators

You've been printing since Lesson 2 — now the fine print: does it add a newline for you, or do you have to ask?

Lesson 20 → Contents Glossary →

Every language writes to standard output — the default destination for printed text, almost always the terminal. What differs is whether a trailing newline is added automatically, or whether you have to ask for one.

Python 
print("a", "b", sep=", ")   # a, b            — newline added automatically
print("no newline", end="")  # cursor stays on this line
Java 
System.out.println("a" + ", " + "b"); // a, b — println adds the newline
System.out.print("no newline");        // print does not
JavaScript 
console.log("a", "b");   // a b               — newline added automatically, args joined with spaces
C++ 
std::cout << "a" << ", " << "b" << std::endl; // a, b — std::endl adds the newline
std::cout << "no newline";                       // plain << does not

Python's print() and JavaScript's console.log() both add a trailing newline by default — Python lets you suppress it with end="", while JavaScript has no direct equivalent in a browser at all (Node.js offers process.stdout.write instead, outside this lesson's scope). Java flips the default: print() adds nothing, and you reach for println() specifically when you want the newline. C++ behaves the same way as Java — plain << never adds a newline, so you append std::endl or "\n" yourself whenever you want one.

Definition Standard output (often shortened to stdout) is the default destination a program writes printed text to — almost always the terminal in this course's examples.
Why it matters here Getting the newline behavior wrong is a classic first bug — a progress bar that jumps to a new line every update, or a prompt that appears with no space before the user's typed answer. Knowing which of these four defaults to a newline and which doesn't saves a surprising amount of debugging time later.

Check your recall

1. In Java, which method adds a trailing newline automatically?

print() leaves the cursor on the same line; println() moves to a new one.

2. What does Python's end="" argument to print() do?

sep controls the separator between values; end controls what's printed after the last one.

3. What must you add to a C++ std::cout statement to get a trailing newline?

C++'s default behaves like Java's print() — no automatic newline.

4. Fill in the blank: the default destination a program writes printed text to is called standard output, or ___ for short.

See the definition box above.

5. Fill in the blank: Python's print() and JavaScript's console.log() both automatically add a trailing ___ after their output.

Java and C++ both require you to add this yourself instead.
