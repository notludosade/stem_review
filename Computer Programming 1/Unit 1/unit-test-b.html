1. Why does a C++ program need a compiler step before it can run, while a Python script does not?

Compiling happens once, up front, producing an executable; interpreting happens every time the program runs, with no separate build step.

2. Fill in the blank: every language eventually gets translated into the raw binary instructions a CPU understands directly, called ___ ___.

Compiling, interpreting, and JIT compiling are three different strategies for reaching this same destination.

3. Modern JavaScript engines like V8 use a JIT strategy similar to Java's. Answer both parts:

(a) What does JIT stand for, and when does it compile bytecode into machine code?

(b) Fill in the blank: the intermediate form Java's compiler produces, which is not machine code but runs on the JVM, is called ___.

(a) JIT compiles hot bytecode paths to machine code during execution, getting speed without giving up portability. (b) Bytecode is the intermediate form that runs on the JVM.

4. Why do Java and C++ require you to explicitly define a method or function named main, while Python and JavaScript need no such thing?

An entry point is the specific location where execution begins. Interpreted languages treat the top of the file as the entry point implicitly.

5. Consider this Java program, then answer both parts:

public class Greet {
    public static void main(String[] args) {
        System.out.println("Hi there!");
    }
}

(a) What would happen if the method were renamed to greet instead of main?

(b) Fill in the blank: Java requires every piece of code, including this method, to live inside a ___.

(a) The JVM looks for the exact signature public static void main(String[] args) by name — nothing else will do. (b) There's no such thing as a loose statement floating outside a class in Java.

6. Consider this C++ program, then answer both parts:

#include <iostream>

int main() {
    std::cout << "Hi there!" << std::endl;
    return 0;
}

(a) If the #include <iostream> line were removed, what would happen?

(b) Fill in the blank: a nonzero value returned from main conventionally signals that ___ occurred.

(a) C++ doesn't build console printing into the language core, so the include line explicitly brings in that tooling. (b) return 0; signals success; anything nonzero signals an error.

7. Which of the following correctly prints text to the console in Python, based on this course's examples?

console.log is JavaScript's version, System.out.println is Java's, and std::cout is C++'s — each language spells this differently.

8. Consider comment syntax across the four languages, and answer both parts:

(a) Which languages in this course support the block-comment syntax /* ... */?

(b) Fill in the blank: the single-line comment symbol shared by Java, JavaScript, and C++ is ___.

(a) All three descend from the same C-family syntax tradition; Python has no true block-comment syntax at all. (b) // marks a single-line comment in all three C-family languages.

9. Fill in the blank: unlike Java, JavaScript, and C++, Python has no dedicated syntax for a multi-line block ___.

By convention, Python programmers reuse triple-quoted string literals to serve this purpose instead.

10. Consider this pair of comments placed above the same line of JavaScript code, then answer both parts:

// subtract 1 from lives
lives = lives - 1;

// game ends at 0 -- matches the arcade original's rule
lives = lives - 1;

(a) Which comment is more worth keeping, and why?

(b) Fill in the blank: a comment that merely restates ___ the code does is usually redundant, since well-named code already communicates that.

(a) The first comment adds nothing anyone reading lives = lives - 1 doesn't already know. (b) What is usually visible from well-named code; why often isn't, and that's what's worth writing down.
