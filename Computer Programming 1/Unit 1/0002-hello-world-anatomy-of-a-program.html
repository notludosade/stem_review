Hello, World — Anatomy of a Program in Four Languages

The smallest possible program still reveals a language's whole shape.

Lesson 3 → Contents Glossary →

Every programming tradition starts here: a program that does nothing but print the words "Hello, world!" It's a running joke by now, but it earns its place — the shortest possible program still has to show you how that language organizes code, where execution begins, and how it talks to the outside world.

Python 
print("Hello, world!")
Java 
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, world!");
    }
}
JavaScript 
console.log("Hello, world!");
C++ 
#include <iostream>

int main() {
    std::cout << "Hello, world!" << std::endl;
    return 0;
}

One line does the actual work in every version — printing text — but the amount of surrounding structure varies enormously, and that gap is not random. It tracks directly back to Lesson 1.

Why Python and JavaScript need almost nothing

Python and JavaScript are both interpreted: the interpreter runs your file top to bottom, so a single statement is a complete program — there's no separate "entry point" to declare, because execution just starts at line one. print(...) and console.log(...) are each a call to a built-in function that writes text to the console.

Why Java demands a class and a specific method

Java requires every piece of code to live inside a class — there's no such thing as a loose statement floating outside one. public static void main(String[] args) is a specific method signature the JVM looks for by name to know where to start running your program; get that signature wrong and the JVM has nowhere to begin. This ceremony exists because Java was designed from the start around organizing code into classes, not because printing text is inherently complicated.

Why C++ needs an include and a main function

#include <iostream> pulls in the input/output library — C++ doesn't build console printing into the language core, so you have to explicitly bring in the tools for it. int main() is the required entry point every C++ program must define; the operating system looks for a function with exactly this name to know where execution starts. return 0; tells the operating system the program finished successfully — a nonzero return value conventionally signals an error occurred.

Definition An entry point is the specific location in a program where execution begins. Interpreted languages like Python and JavaScript treat the top of the file as the entry point implicitly; Java and C++ require you to define one explicitly, by name (main) and, in Java's case, a specific method signature.
Why it matters here Every one of these four "extra" pieces — the class wrapper, the specific method signature, the include statement — will show up again and again for the rest of this course. Recognizing them now as structural requirements tied to how each language works, rather than arbitrary boilerplate to memorize, makes every later lesson's code easier to read at a glance.

Check your recall

1. Why can Python's entire program be a single line with no surrounding structure?

Execution just starts at the top of the file — no explicit main function is required.

2. Why does Java require the exact method signature public static void main(String[] args)?

Get the signature wrong and the JVM has no defined entry point to begin execution from.

3. What does #include <iostream> do in the C++ example?

main() is the entry point; std::cout is what actually prints, and it comes from the iostream library this line includes.

4. Fill in the blank: the specific location where a program's execution begins is called its ___ ___.

See the definition box above.

5. Fill in the blank: at the end of the C++ example's main function, ___ tells the operating system the program finished successfully.

A nonzero return value conventionally signals that an error occurred instead.
