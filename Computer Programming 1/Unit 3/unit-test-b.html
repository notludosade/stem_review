1. In Java, JavaScript, and C++, what marks the boundaries of an if statement's block?

Java, JavaScript, and C++ require parentheses around the condition and curly braces around each block; Python uses a colon and indentation instead.

2. Fill in the blank: Java, JavaScript, and C++ all spell "else if" as two separate words, while Python combines them into the single keyword ___.

This single-keyword spelling is unique to Python among the four languages in this course.

3. Consider this Python snippet, then answer both parts:

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")

(a) If score is 85, what prints?

(b) Fill in the blank: the expression score >= 90 must evaluate to a ___ for this to work — true or false.

(a) 85 >= 90 is false, but 85 >= 80 is true, so the elif branch runs. (b) Every if/elif condition must produce a boolean.

4. What is one key difference between how a while loop and a plain if statement handle their condition?

An if statement branches once; a while loop repeats, re-checking its condition before every single pass.

5. Consider this code, then answer both parts:

let tickets = 3;
while (tickets > 0) {
    console.log(tickets);
    // forgot to update tickets here
}

(a) What happens when this runs?

(b) Fill in the blank: every while loop needs something in its body that eventually makes its ___ become false.

(a) Nothing here ever changes tickets, so tickets > 0 never becomes false. (b) This is called an infinite loop — the most common mistake with while loops in every language.

6. Consider this code, then answer both parts:

int count = 5;
while (count > 2) {
    System.out.println(count);
    count = count - 1;
}

(a) What is the last value printed?

(b) Fill in the blank: this loop prints a total of ___ values.

(a) The loop prints 5, 4, 3 — once count drops to 2, count > 2 is false, so it stops. (b) That's three printed values in total: 5, 4, and 3.

7. Consider this C++ for loop, then answer both parts:

for (int i = 1; i <= 3; i++) {
    std::cout << i << std::endl;
}

(a) Fill in the blank: this loop prints ___, 2, 3.

(b) Which part of the header does i <= 3 represent?

(a) Starting at i = 1 and continuing while i <= 3, this loop prints 1, 2, 3. (b) int i = 1 initializes, i <= 3 is the condition, i++ is the update.

8. Fill in the blank: for i in range(6): steps i through the values 0 through ___ (the largest value, not 6 itself).

range(n) produces the sequence 0 through n-1, so range(6) stops at 5.

9. What does this Python code print?

for i in range(3):
    print(i * 2)

range(3) produces 0, 1, 2, and each is doubled before printing: 0 * 2 = 0, 1 * 2 = 2, 2 * 2 = 4.

10. Consider two situations: (1) printing every multiple of 3 from 3 to 30, and (2) rolling a die repeatedly until it lands on a 6. Answer both parts:

(a) Which loop is the natural fit for situation (1)?

(b) Which loop is the natural fit for situation (2)?

(a) The count of multiples from 3 to 30 (ten of them) is known ahead of time. (b) The number of rolls needed depends on chance, not a count you already know.
