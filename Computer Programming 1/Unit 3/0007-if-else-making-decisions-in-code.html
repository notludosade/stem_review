If/Else — Making Decisions in Code

Every program that does more than one thing needs a way to choose which thing to do.

Lesson 8 → Contents Glossary →

An if statement runs a block of code only when a condition is true, and skips it otherwise. Pair it with else to run a different block when the condition is false, or chain else if to check additional conditions in sequence. The condition is any expression that produces a boolean — often built from the comparison and logical operators from Lesson 6.

Python 
if age >= 18:
    print("adult")
elif age >= 13:
    print("teen")
else:
    print("child")
Java 
if (age >= 18) {
    System.out.println("adult");
} else if (age >= 13) {
    System.out.println("teen");
} else {
    System.out.println("child");
}
JavaScript 
if (age >= 18) {
    console.log("adult");
} else if (age >= 13) {
    console.log("teen");
} else {
    console.log("child");
}
C++ 
if (age >= 18) {
    std::cout << "adult" << std::endl;
} else if (age >= 13) {
    std::cout << "teen" << std::endl;
} else {
    std::cout << "child" << std::endl;
}

Java, JavaScript, and C++ require parentheses around the condition and curly braces around each block — this is the same C-family convention that gave those three languages identical comment syntax back in Lesson 3. Python uses a colon and indentation instead of braces; the indentation isn't just a style choice, it's how Python knows where the block ends. Note also the keyword spelling: Python's elif versus the other three languages' two-word else if.

Definition Control flow is the order in which a program's statements execute. An if statement is the most basic control-flow tool: it branches execution down one of two or more paths based on a boolean condition.
Why it matters here Python's indentation-defines-blocks rule is easy to get wrong when switching from a brace-based language, and the reverse — forgetting braces when switching back — is just as common. Both mistakes are among the most frequent bugs beginners hit when working across languages, which is exactly why this course puts all four side by side instead of teaching them separately.
