1. How does Python know where an if block ends, since it has no curly braces?

Inconsistent indentation in Python is actually a syntax error, not just a formatting problem — the indentation is how Python knows where the block ends.

2. Fill in the blank: Python's single keyword for chaining an additional condition onto an if statement, replacing Java/JavaScript/C++'s two-word else if, is ___.

Java, JavaScript, and C++ all spell this as two separate words, else if, instead.

3. Consider this Java snippet, then answer both parts:

if (age >= 18) {
    System.out.println("adult");
} else if (age >= 13) {
    System.out.println("teen");
} else {
    System.out.println("child");
}

(a) If age is 15, what prints?

(b) Fill in the blank: the expression age >= 18 inside the parentheses must evaluate to a ___ for this to work at all.

(a) 15 >= 18 is false, but 15 >= 13 is true, so the second branch runs. (b) Every if condition must produce a boolean — true or false.

4. When does a while loop check its condition?

A while loop repeats a block of code for as long as its condition stays true, re-checking that condition before every single pass.

5. Consider this code, then answer both parts:

count = 10
while count > 0:
    print(count)
    # nothing updates count here

(a) What happens when this runs?

(b) Fill in the blank: a loop like this one, whose condition never becomes false, is called an ___ ___.

(a) Every while loop needs something in its body that eventually makes the condition false — this one has nothing. (b) This is the most common mistake with while loops in every language.

6. Consider this code, then answer both parts:

count = 0
while count < 4:
    print(count)
    count = count + 1

(a) What is the last value printed?

(b) Fill in the blank: this loop prints a total of ___ values.

(a) The loop prints 0, 1, 2, 3 — after the fourth pass count becomes 4, and 4 < 4 is false, so it stops. (b) That's four printed values in total: 0, 1, 2, and 3.

7. Consider this Java for loop, then answer both parts:

for (int i = 0; i < 4; i++) {
    System.out.println(i);
}

(a) What are the three parts of this header, in order?

(b) Fill in the blank: this loop prints the values 0, 1, 2, ___.

(a) int i = 0 initializes, i < 4 is checked before each pass, i++ runs after each pass. (b) The loop runs while i < 4, so it prints 0, 1, 2, 3 and then stops.

8. Fill in the blank: the standard Python function that produces the sequence of numbers a for loop steps through, as in for i in range(5), is ___.

range(n) produces the sequence 0 through n-1, and Python's for loop simply hands you one value at a time from that sequence.

9. What does this Python code print?

for i in range(4):
    print(i)

range(4) produces the sequence 0, 1, 2, 3 — Python's for loop steps through each value in that sequence, one at a time.

10. Consider two situations: (1) printing the numbers 1 through 5, and (2) repeatedly asking a user for input until they type "quit". Answer both parts:

(a) Which loop type is the more natural fit for situation (1), where the exact number of repetitions is known in advance?

(b) Which loop type is the more natural fit for situation (2), where the number of repetitions isn't known in advance?

(a) A for loop bundles a known repeat count into one line. (b) A while loop is the right tool when repetition depends on a condition changing, not a count you already know.
