For Loops — Repeating a Known Number of Times

Three languages count with a three-part header. Python counts by handing you the numbers directly.

Lesson 10 → Contents Glossary →

A for loop is built for repeating a known number of times, bundling the setup, the condition, and the update into one line instead of spreading them across a while loop's declaration, condition, and body. All four languages have one — but Python's works on a genuinely different principle from the other three.

Python 
for i in range(3):
    print(i)
Java 
for (int i = 0; i < 3; i++) {
    System.out.println(i);
}
JavaScript 
for (let i = 0; i < 3; i++) {
    console.log(i);
}
C++ 
for (int i = 0; i < 3; i++) {
    std::cout << i << std::endl;
}

All four print 0, 1, 2 — the same result as Lesson 8's while loop, but in one line of setup instead of three. Java, JavaScript, and C++ use a three-part header: an initializer (int i = 0), a condition checked before each pass (i < 3), and an update run after each pass (i++, meaning "add one to i"). Python's for i in range(3) works completely differently: range(3) produces the sequence of numbers 0, 1, 2, and for i in ... simply hands you one value from that sequence at a time — there's no separate condition or update step to write at all.

Definition A for loop repeats a block a set number of times. Java, JavaScript, and C++ define that count with a three-part header (initializer, condition, update). Python's for loop instead iterates — steps one at a time — over a sequence of values, with range(n) being the standard way to produce the sequence 0 through n-1.
Why it matters here This isn't a small syntax variation like elif versus else if — it's a genuinely different model of what a for loop even is. The three-part-header languages are counting; Python is walking through a sequence. That distinction matters more once this course reaches arrays and lists in Unit 6, where Python's iteration style becomes the natural way to process a collection, while the other three languages can do it either way.

range(n) produces 0 through n-1, which is why for i in range(3) also prints 0, 1, 2 — matching the other three languages' output.
