While Loops — Repeating Until a Condition Changes

A loop that doesn't know in advance how many times it needs to run.

Lesson 9 → Contents Glossary →

A while loop repeats a block of code for as long as a condition stays true, checking that condition again before every repetition. It's the right tool when you don't know ahead of time how many times you'll need to repeat — only what needs to stay true for the repeating to continue.

Python 
count = 0
while count < 3:
    print(count)
    count = count + 1
Java 
int count = 0;
while (count < 3) {
    System.out.println(count);
    count = count + 1;
}
JavaScript 
let count = 0;
while (count < 3) {
    console.log(count);
    count = count + 1;
}
C++ 
int count = 0;
while (count < 3) {
    std::cout << count << std::endl;
    count = count + 1;
}

All four versions print 0, 1, 2, then stop, because after the third pass count becomes 3 and 3 < 3 is false. Notice that count is declared once, before the loop — the loop body only updates it. The syntax pattern is identical to the if statement from Lesson 7: same parentheses-and-braces convention in Java/JavaScript/C++, same colon-and-indentation in Python.

A loop that never ends 
count = 0
while count < 3:
    print(count)
    # forgot to update count — this runs forever

This is called an infinite loop, and it's the most common mistake with while loops in every language: forgetting to update whatever the condition depends on, so the condition never becomes false. Every while loop needs something inside its body that eventually makes the condition stop being true.

Definition A while loop repeats a block of code as long as its condition remains true, re-checking the condition before each repetition. An infinite loop is a while loop whose condition never becomes false, so it never stops on its own.
Why it matters here While loops are the right choice specifically when the number of repetitions depends on something changing during the loop, not on a count you already know. The next lesson covers for loops, which are built for the opposite case — when you already know how many times you want to repeat.
