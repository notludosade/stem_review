1. In C++, what does 'x' (single quotes) represent, as opposed to "x" (double quotes)?

Java and C++ reserve single quotes for a narrower character type; only Python and JavaScript treat single and double quotes as fully interchangeable for strings.

2. Fill in the blank: joining "Hello" and "World" into "HelloWorld" using the same operator normally used for arithmetic addition is called string ___.

All four languages overload + to perform this join, rather than defining a separate operator just for strings.

3. A programmer new to Java notices that String is capitalized like a class name (e.g., MyClass), unlike int or boolean. What's the accurate explanation from this unit?

Unit 8's coverage of objects and classes explains why this class-based implementation matters.

4. In Python, how do you find the length of a string named message?

Java and C++ use a length()/size() method call, and JavaScript uses a length property — Python is the one that uses a standalone function instead.

5. Python calls name.upper(), Java calls name.toUpperCase(), and JavaScript calls name.toUpperCase() — each converting a string to uppercase in a single line. What's different about doing the same thing in C++?

This is a genuine capability gap, not just a spelling difference — Python, Java, and JavaScript all provide a direct one-line method instead.

6. A JavaScript string is defined as let word = "Coral";. Answer both parts:

(a) What does word[2] evaluate to?

(b) Fill in the blank: this same square-bracket indexing also works directly in Python and C++, but not in ___, which instead requires a method call named charAt.

(a) Indexing counts from 0, so C=0, o=1, r=2 — word[2] is "r". (b) Java is the one exception among the four — it has no square-bracket indexing for strings at all.

7. Extracting a piece of a string from a start index up to (but not including) an end index is spelled differently across languages. Answer both parts:

(a) Which of the four languages spells this operation "substr" specifically (not "substring")?

(b) Fill in the blank: Python instead extracts a piece of a string using bracket-based ___ syntax, such as name[0:3].

(a) Java and JavaScript both spell it substring; C++ drops a syllable and spells it substr. (b) Python's approach is called slicing, using start:end inside square brackets rather than a named method at all.

8. A JavaScript program builds a string with let message = `Total: ${total}`;; a C++ program builds an equivalent string with std::string message = std::format("Total: {}", total);. Answer both parts:

(a) Which of these two is "formatting" rather than true "interpolation," by this unit's definition?

(b) Fill in the blank: the JavaScript example is true string ___ instead, since ${total} embeds the actual variable name directly inside the template.

(a) std::format keeps the template and the values separate, matched up by position — that's formatting, not interpolation. (b) The JavaScript template literal embeds the variable reference itself, which is what makes it true interpolation.

9. In Python, count = 3, then message = "Items: " + count. Answer both parts:

(a) What happens when this exact code runs?

(b) Fill in the blank: to fix this, the concatenation would need to convert count to text first, using Python's ___() function.

(a) Python's + can't mix a string operand with a number operand — this raises a TypeError rather than silently converting. (b) str(count) performs that conversion explicitly, which interpolation and formatting both handle automatically instead.

10. Answer both parts about interpolation syntax:

(a) In Python, what character right before the opening quote marks a string literal as an f-string, enabling interpolation?

(b) Fill in the blank: Java's String.format and C++'s std::format each require a separate template with generic placeholders and a value list supplied in order — this style is called string ___.

(a) An f right before the opening quote marks a Python f-string. (b) Java and C++ keep the template and values separate, matched up by position — that's formatting, not interpolation.
