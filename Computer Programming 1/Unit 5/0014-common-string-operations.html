Common String Operations

Finding a string's length, grabbing one character, and pulling out a slice — three operations you'll use constantly.

Lesson 15 → Contents Glossary →

A string can be thought of as a sequence of individual characters, each with a position — its index — starting at 0. That indexing model is shared by all four languages, though how you ask for the length and how you pull out a piece differs.

Python 
name = "Ada"
len(name)     # 3
name[0]       # "A"
name[0:2]     # "Ad"
Java 
String name = "Ada";
name.length();        // 3
name.charAt(0);        // 'A'
name.substring(0, 2); // "Ad"
JavaScript 
let name = "Ada";
name.length;          // 3, a property, not a call
name[0];               // "A"
name.substring(0, 2); // "Ad"
C++ 
std::string name = "Ada";
name.length();        // 3
name[0];               // 'A'
name.substr(0, 2);    // "Ad"

Getting the length is a method call — length() — in Python (as a standalone function, len(name)), Java, and C++, but a plain property with no parentheses in JavaScript (name.length). Getting a single character by index uses square brackets in Python, JavaScript, and C++ (name[0]), but a method call in Java (name.charAt(0)) — Java doesn't support square-bracket indexing on strings directly. Extracting a range of characters is spelled substring in Java and JavaScript, Python-style slicing (name[0:2]) in Python, and substr in C++ — three different names for essentially the same idea, so this is worth memorizing per language rather than assuming a shared pattern.

Case conversion — where C++ genuinely lacks a one-liner

Python, Java, and JavaScript each provide a direct method: name.upper() or name.lower() in Python, name.toUpperCase()/toLowerCase() in Java and JavaScript. C++'s standard string type has no equivalent single method — converting case requires looping over each character and calling std::toupper individually, or using an algorithm from the <algorithm> header. This isn't a small syntax difference like the others in this lesson; it's a real capability gap between C++'s standard string type and the other three languages' built-in convenience.

Definition An index is a character's position within a string, counting from 0. A substring is a contiguous piece of a string, extracted by specifying a start (and often end) index.
Why it matters here These three operations — length, single-character access, and substring extraction — are the building blocks nearly every text-processing task is made of, from validating a password's length to parsing a name into first and last. The exact method names are worth memorizing per language now, since guessing wrong (like trying name[0] in Java) produces an error you'll otherwise have to look up every time.
