1. In Java, what does the value 'A' (single quotes) represent, as opposed to "A" (double quotes)?

Java and C++ reserve single quotes for a narrower character type; only Python and JavaScript treat single and double quotes as fully interchangeable for strings.

2. Fill in the blank: all four languages in this course reuse the same operator, normally used for arithmetic addition, to also mean string concatenation — that operator is ___.

Python, Java, JavaScript, and C++ all overload + to join strings together, instead of adding them numerically.

3. Why are Java's String and C++'s std::string capitalized, unlike int or bool?

Unit 8's coverage of objects and classes explains why this class-based implementation matters.

4. In JavaScript, name.length is written with no parentheses, unlike Java's name.length(). Why?

length is accessed as a plain property in JavaScript, unlike the method calls Python, Java, and C++ all use for this.

5. What makes C++'s approach to converting a string to uppercase different from Python, Java, and JavaScript?

This is a genuine capability gap, not just a spelling difference — Python, Java, and JavaScript all provide a direct one-line method instead.

6. A Python string is defined as name = "Maria". Answer both parts:

(a) What does name[0] evaluate to?

(b) Fill in the blank: this same square-bracket indexing also works directly in JavaScript and C++, but not in ___, which instead requires a method call named charAt.

(a) Indexing counts from 0, so name[0] is the first character, "M". (b) Java is the one exception among the four — it has no square-bracket indexing for strings at all.

7. Extracting a piece of a string from a start index up to (but not including) an end index is spelled differently across languages. Answer both parts:

(a) Fill in the blank: C++'s std::string spells this operation ___ (one word, similar to but not identical to Java's spelling).

(b) Which two languages both spell this exact same operation "substring"?

(a) C++ uses substr, dropping the middle syllable Java and JavaScript keep. (b) Python instead uses slicing syntax like name[0:2] — three different spellings for the same underlying idea.

8. A Python program builds a string with message = f"Score: {points}"; a Java program builds an equivalent string with String message = String.format("Score: %d", points);. Answer both parts:

(a) Which of these two is true "interpolation" rather than "formatting," by this unit's definition?

(b) Fill in the blank: Java's String.format and C++'s std::format instead use a separate template with generic placeholders filled in by a list of values — this style is called string ___.

(a) f-strings embed the variable reference itself inside the template, which is what makes it true interpolation. (b) Java and C++'s approach keeps the template and the values separate, matched up by position — that's formatting, not interpolation.

9. In Python, age = 16, then message = "You are " + age + " years old.". Answer both parts:

(a) What happens when this exact code runs?

(b) Fill in the blank: to fix this, the concatenation would need to explicitly convert age to text first, using Python's ___() function.

(a) Python's + can't mix a string operand with a number operand — this raises a TypeError rather than silently converting. (b) str(age) performs that conversion explicitly, which interpolation and formatting both handle automatically instead.

10. Answer both parts about interpolation syntax:

(a) What punctuation delimits a JavaScript template literal, instead of regular quotes?

(b) Fill in the blank: because ${age} embeds the actual variable name directly inside the string template, JavaScript's template literals are true string ___ — the same term used for Python's f-strings.

(a) Backtick-delimited strings can then contain ${...} placeholders for embedded expressions. (b) Interpolation is defined by the variable name appearing directly inside the template, exactly as it does here.
