Motion in Two Dimensions with Vectors

AP Physics 1's "x-story and y-story, told independently" gets a formal calculus backbone: differentiate a vector by differentiating each component separately.

← Lesson 2 Unit 2, Lesson 4 → Contents Glossary →

Bundle x(t) and y(t) into a single position vector r(t) = x(t) î + y(t) ĵ, where î and ĵ are the fixed unit vectors along the x- and y-axes. Differentiating r(t) is defined component by component — which is exactly why Physics 1's "independence principle" for projectile motion worked in the first place.

Vector Derivatives, Component by Component r(t) = x(t) î + y(t) ĵ
v(t) = dr/dt = (dx/dt) î + (dy/dt) ĵ
a(t) = dv/dt = (d²x/dt²) î + (d²y/dt²) ĵ
Each component differentiates using ordinary single-variable rules from Lesson 1 — î and ĵ are constant vectors (fixed direction, fixed length), so they pass through the derivative untouched.
Why component independence was never a coincidence In AP Physics 1, x- and y-motion were solved separately "because gravity only pulls down." The deeper reason is this lesson's definition: the derivative of a vector sum is the vector sum of the derivatives, term by term. There was never a hidden coupling between x(t) and y(t) to worry about — differentiating r(t) was always going to split cleanly along î and ĵ.
Example: a projectile, done with vectors r(t) = (12t) î + (16t − 4.9t²) ĵ (meters). Then v(t) = (12) î + (16 − 9.8t) ĵ, and a(t) = (0) î + (−9.8) ĵ — constant, pointing straight down, exactly g. At t = 1 s: v(1) = 12î + 6.2ĵ, so speed |v(1)| = √(12² + 6.2²) = √(144 + 38.4) ≈ 13.5 m/s.
Speed vs. Velocity, Restated Velocity v(t) is a vector; speed is its magnitude, |v(t)| = √(vx² + vy²) — always a nonnegative scalar, and generally not the derivative of |r(t)| (distance from the origin), which is a separate, messier quantity. Speed is how fast position is changing along the path, not how fast the object is moving away from the origin.

Check your recall

No peeking back up — answer from memory first, then check.

1. r(t) = (5t) î + (2t²) ĵ. What is v(t)?

Differentiate each component separately: d/dt(5t) = 5, d/dt(2t²) = 4t.

2. For the same r(t) = (5t) î + (2t²) ĵ, what is the acceleration vector a(t)?

Differentiate v(t) = 5î + 4tĵ again, component by component: d/dt(5) = 0, d/dt(4t) = 4. Constant acceleration entirely in the y-direction.

3. At some instant, vx = 3 m/s and vy = 4 m/s. What is the object's speed at that instant?

Speed = |v| = √(v_x² + v_y²) = √(9 + 16) = √25 = 5 m/s — a 3-4-5 triangle.

4. Fill in the blank: at any instant, the velocity vector v(t) points ___ to the path traced by r(t).

Velocity is the derivative of position, and just as in single-variable calculus, a derivative gives the direction of the tangent line — here, tangent to the curved path itself.
