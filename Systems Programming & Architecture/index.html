Systems Programming & Architecture: CS

What actually happens underneath every program you've written — compilation, memory, pointers, the operating system, concurrency, the CPU itself, and the debugging and language tradeoffs that tie it all together, using C to see the machine directly. Assumes you can already program; assumes nothing about C or how a computer works underneath one.
