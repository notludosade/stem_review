1. What is the operating system's core job?

Resource management — CPU, memory, devices — is the OS's foundational role.

2. Fill in the blank: the privileged core of the OS, with full direct hardware access, is called the ___.

The kernel makes the actual resource-allocation decisions with privileged access.

3. What is the difference between a program and a process?

Running an executable twice creates two independent processes from one program file.

4. Fill in the blank: a process blocked on a slow disk read moves to the ___ state, giving up the CPU entirely until the operation finishes.

Freeing the CPU during I/O lets other ready processes use it instead of it sitting idle.

5. Why does a process move from running to waiting instead of just staying running while a disk read completes?

Not wasting CPU time on idle waiting is exactly why the waiting state exists.

6. A user-mode program wants to write bytes directly to a disk device. Answer both parts:

(a) Can user-mode code do this directly, with no further mechanism?

(b) What mechanism lets it accomplish this anyway?

System calls are the controlled bridge from restricted user mode into privileged kernel mode.

7. Fill in the blank: a controlled request that switches the CPU into kernel mode so trusted code can perform a privileged operation is called a ___.

System calls are the sole doorway between user mode and kernel mode.

8. Why does printf ultimately rely on a system call, even though calling it looks like an ordinary user-mode function call?

write(), the system call underneath printf, is what actually performs the privileged output operation.

9. Why does funneling every privileged operation through a small set of system calls help enforce process isolation?

A narrow, checkable doorway is exactly what makes enforcement of isolation guarantees possible.

10. Fill in the blank: the system call in the process-control category used to create a new process is ___.

fork() is the classic process-control system call for spawning a new process.
