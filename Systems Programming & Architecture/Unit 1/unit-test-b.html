1. Why can a compiled C executable run on a machine with no C compiler installed, while a Python script cannot run without Python installed?

Compiling removes the need for the original toolchain at run time; interpreting requires the interpreter every run.

2. Fill in the blank: every programming language, no matter how it's executed, ultimately has to become ___ before a processor can run it.

Machine code is the one format every processor can actually execute.

3. A JavaScript engine like V8 begins running a script by interpreting it, then later compiles a "hot" function into machine code while the script keeps running. What is this strategy called?

JIT compilation mixes interpreting and compiling within a single running program.

4. Fill in the blank: a misspelled filename in an #include directive fails during the ___ stage, since that's the stage that actually opens and pastes in included files.

The preprocessor handles #include expansion before any real compiling happens.

5. A misspelled variable name inside a function body is caught at which stage, and why?

This is a classic compile-time error, caught while the compiler checks syntax and declarations.

6. A program forgets to link against the math library while calling sqrt(), producing "undefined reference to sqrt." Answer both parts:

(a) This error comes from...

(b) The call to sqrt() itself is...

The call itself is fine; the linker just can't find sqrt's implementation without the right library linked in.

7. Fill in the blank: a ___ library stays a separate file on disk, loaded and linked in only when the program actually runs, unlike a static library which is copied directly into the executable.

Dynamic libraries remain external files, loaded at run time rather than baked into the executable.

8. What output does gcc -S hello.c -o hello.s produce, and at which stage does it stop?

-S stops after the compiler stage, producing human-readable assembly rather than an object file or executable.

9. Why doesn't a successful, error-free compile and link guarantee a C program behaves correctly?

A clean build is a structural guarantee, not a logical one — a program can compile cleanly and still be wrong.

10. Fill in the blank: on Linux or macOS, running an executable named hello sitting in the current directory requires typing ___, not just its bare name.

The leading ./ explicitly points the shell at the local file, rather than searching system-wide commands.
