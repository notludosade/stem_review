1. Why can a compiled C executable run on a machine with no C compiler installed, while a Python script requires Python itself to be installed?

Ahead-of-time compiling removes the need for the original toolchain at run time; interpreting requires the interpreter every single time.

2. Fill in the blank: the pipeline stage that takes one or more object files, plus any needed libraries, and resolves every outside reference into one final executable is the ___.

The linker is the final pipeline stage, stitching object files and libraries into one complete executable.

3. What's the difference between a static library and a dynamic library?

Whether the library's code becomes part of the executable at link time, or stays separate until run time, is exactly the distinction.

4. Which region of a process's address space is normally read-only, so a bug can't accidentally overwrite the program's own instructions?

The text segment holds compiled instructions and is normally read-only, protecting the program's own code from accidental overwrite.

5. Fill in the blank: when unbounded recursion pushes more stack frames than the space reserved for the stack can hold, and the OS terminates the program, this is called a ___.

A stack overflow is the OS catching the stack growing into memory it doesn't own, before it can silently corrupt anything.

6. Why does a memory leak get progressively worse the longer a server runs, compared to a short script that exits in a second?

A short-lived script's leaks vanish when it exits; a long-running server's leaks keep compounding for as long as it stays up.

7. What does the dereference operator (*) do when applied to a pointer?

Dereferencing follows a pointer's address to reach the actual value stored there, for reading or writing.

8. Fill in the blank: adding or subtracting an integer from a pointer, where the result automatically moves by whole elements of the pointer's type rather than raw bytes, is called ___.

Pointer arithmetic automatically scales by the pointed-to type's size, moving by whole elements at a time.

9. Why is a dangling pointer dangerous even though it still holds a normal-looking address?

A dangling pointer's outward appearance gives no warning at all that the memory behind it is no longer valid.

10. Why does two's complement let one adder circuit correctly handle both signed and unsigned addition?

One adder, no special-casing for sign — the core engineering payoff of two's complement.

11. Fill in the blank: the part of a floating-point number holding its significant digits, alongside a sign bit and an exponent, is called the ___.

The mantissa (or significand) holds the significant digits, shifted by the exponent to cover a huge range of magnitudes.

12. Why does a compiler insert padding bytes between struct fields?

Padding exists purely to push each field's address to the correct alignment multiple, at the cost of some wasted space.

13. What is the kernel's role, compared to other software commonly thought of as part of "the OS," like a file manager?

The kernel alone holds privileged access; ordinary OS software runs on top of it with the same restricted access as any other program.

14. Fill in the blank: a running instance of a program, with its own address space, open files, and register values, is called a ___.

A process is the running instance; the program is just the static executable file sitting on disk until something runs it.

15. Why does a program have to make a system call to write to a file, instead of writing to the hardware directly?

User mode's restricted access is exactly what makes a controlled switch into kernel mode necessary for privileged operations like file I/O.

16. What do multiple threads within the same process share, that two separate processes do not?

Shared heap and data-segment access is exactly what distinguishes threads from fully isolated separate processes.

17. Fill in the blank: a bug where a program's correctness depends on the precise timing or interleaving of operations across multiple threads is called a ___.

A race condition's outcome depends on execution order that isn't controlled or guaranteed between threads.

18. What happens when a thread tries to lock a mutex that another thread currently holds?

Blocking until the mutex is free is exactly what keeps the critical section running as one uninterrupted unit.

19. What does the "fetch" step of the fetch-decode-execute cycle do?

Fetch reads the instruction the program counter points at; decode and execute happen only afterward.

20. Fill in the blank: the fixed, agreed-upon rule for which registers hold a function's arguments and return value is called the ___.

The calling convention is why compiled functions call each other correctly with no explicit per-call register agreement in the source.

21. Why does requesting a single byte from RAM pull an entire 64-byte cache line into the cache, not just that one byte?

Fetching a whole cache line pays off precisely when nearby memory gets accessed soon after — spatial locality.

22. What triggers a segmentation fault?

The kernel enforces address-space isolation, and a segfault is exactly that enforcement killing an illegal access.

23. Fill in the blank: an operation the C standard places no requirement on at all, which the compiler may assume never happens, is called ___.

Undefined behavior's total absence of requirements is exactly what lets an optimizing compiler assume it never occurs.

24. Why might most production software today be written in a managed language rather than C?

The tradeoff, not a universal ranking, is what decides this — and for most software, safety-by-construction wins over raw speed.
