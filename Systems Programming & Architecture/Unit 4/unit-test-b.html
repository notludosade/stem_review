1. In two's complement, how is a negative value related to its positive counterpart's bit pattern?

Flip every bit and add 1 is exactly how two's complement negation works.

2. Fill in the blank: an 8-bit signed value at its maximum, 127, has 1 added to it and becomes -128 instead of 128. This is an example of integer ___.

The bits wrap around exactly as fixed-width arithmetic dictates once the true result no longer fits.

3. Why is a 32-bit unsigned int decrementing past zero considered a genuinely dangerous bug, not just a cosmetic one?

This wraparound bug class has caused real, exploitable security vulnerabilities in shipped software.

4. Fill in the blank: the part of a floating-point number that determines how far to shift the binary point, giving floating point its large range, is the ___.

The exponent is what lets the same mantissa bits represent both very small and very large magnitudes.

5. Why does 0.5 have an exact binary floating-point representation while 0.1 does not?

Only power-of-two fractions have a finite, exact binary representation.

6. Two different code paths each compute a value that should mathematically equal 1.0, then compare them with ==. Answer both parts:

(a) Can this comparison fail even though both are "supposed to" be 1.0?

(b) What should be used instead of exact == for this kind of comparison?

Rounding along different computational paths can produce tiny discrepancies, which tolerance-based comparison correctly tolerates.

7. Fill in the blank: a struct's actual size can exceed the sum of its fields' sizes because of ___ bytes the compiler inserts to satisfy alignment.

Padding accounts for the gap between "sum of field sizes" and a struct's real, compiled size.

8. Why might a misaligned memory access be slower, or even disallowed, on some processors?

Alignment exists specifically because unaligned access can cost extra memory operations, or fail outright on some architectures.

9. Why does minimizing struct padding matter more for a large array of that struct than for a single instance?

Padding's cost scales linearly with the number of instances, which is exactly why it matters more at scale.

10. Fill in the blank: a 64-bit double and a 32-bit float both follow the same bit-layout standard, called ___, which is why floating-point rounding behaves consistently across virtually every language and platform.

IEEE 754 is the shared standard behind float and double representation almost everywhere.
