1. What is the main engineering payoff of two's complement representation for signed integers?

The same bit pattern and addition circuit works for both interpretations — that's the core reason two's complement won out.

2. Fill in the blank: when an operation's true result needs more bits than a fixed-width type has, causing the value to silently wrap around, this is called integer ___.

Overflow wraps the result around rather than producing the true mathematical answer.

3. An unsigned int loop counter is decremented below zero. What actually happens?

Unsigned wraparound produces a huge positive value, a real source of bugs and vulnerabilities.

4. Fill in the blank: the part of a floating-point number holding its significant digits is the ___.

The mantissa (significand) works together with a sign bit and exponent, mirroring scientific notation.

5. Why does 0.1 + 0.2 not print exactly 0.3 in most programming languages?

Since 1/10 isn't a power of two, its binary representation repeats forever and must be rounded to fit.

6. A program compares two computed double values with ==, expecting them to be mathematically equal. Answer both parts:

(a) Is this comparison guaranteed to behave as expected?

(b) What is the standard, safer alternative?

Tolerance-based comparison sidesteps the exact-equality problem caused by rounding along different calculation paths.

7. Fill in the blank: unused filler bytes a compiler inserts between struct fields purely to satisfy alignment requirements are called ___.

Padding bytes hold no meaningful data — they only push the next field to a properly aligned address.

8. What does memory alignment require of a value's starting address?

An 8-byte value should start at an address divisible by 8, a 4-byte value at one divisible by 4, and so on.

9. Why can reordering a struct's fields reduce its total size, without changing what data it stores?

Ordering fields from largest to smallest alignment requirement tends to minimize padding.

10. Fill in the blank: the standard essentially every modern language and processor uses to define the bit layout of float and double is ___.

IEEE 754 standardizes floating-point representation across virtually every modern platform.
