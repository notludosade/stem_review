1. Fill in the blank: a systematic, unfair difference in how a program's output treats different groups — even when no line of code explicitly references group membership — is called ___ ___.

This can enter through historical data, a seemingly neutral design choice, or a narrow set of testers — not just through deliberate intent.

2. Which of these is NOT one of the three common entry points for bias described in this unit?

The three entry points are training data, rules, and testing — an unused-variable warning has nothing to do with fairness.

3. Fill in the blank: when a seemingly neutral policy produces significantly different outcomes for different groups — regardless of whether anyone intended to discriminate — that's called ___ ___.

No intent to discriminate is required — only a measurable gap in outcomes, which a fairness test is designed to catch before release.

4. Running a fairness test requires demographic data about who's in the evaluation set. How does this square with Lesson 7's data-minimization principle of "collect only what you need"?

The two lessons aren't contradictory — they apply to different datasets serving different purposes.

5. What's the actual way to find out whether a field like zip_code is functioning as a proxy for a protected characteristic?

A proxy relationship isn't visible by reading a field name — it requires measuring correlation against real outcomes.

6. A company builds a fast-shipping eligibility rule using only zip_code, chosen purely for warehouse-proximity reasons. Answer both parts:

(a) Why can this rule still produce a discriminatory outcome even though no one wrote anything referencing race or income?

(b) Fill in the blank: before shipping the rule to production, the team should measure its ___ by zip code against census data, to see whether it favors wealthier areas far more than poorer ones.

(a) Nobody decided to discriminate on purpose — the correlation was baked into the rule through the zip code list. (b) Measuring coverage against real demographic data is what surfaces a correlation that reading the code alone can't reveal.

7. A facial recognition test suite passes 100% of its assertions. Answer both parts:

(a) Why could this system still ship with a serious fairness problem?

(b) Fill in the blank: correctness testing asks "does the function return the right output?" — fairness testing adds a second question about whether accuracy holds evenly across ___.

(a) Correctness and fairness are different questions — a suite built to answer the first says nothing about the second unless it's specifically designed to. (b) Fairness testing checks accuracy across the groups who'll actually use the system.

8. Answer both parts about how to fix a test suite that only checks correctness:

(a) What does a fairness-aware version of the test do differently?

(b) Fill in the blank: the fixed test checks accuracy separately for each ___ group in the evaluation data, not just once overall.

(a) Looping over each group and enforcing a minimum bar is what catches an accuracy gap the original suite couldn't see. (b) A single overall average can hide a group that falls well below the acceptable bar.

9. Answer both parts about what makes a field a "proxy variable":

(a) Fill in the blank: a field that doesn't name a protected characteristic but predicts it closely enough to reproduce its discriminatory effect is called a ___ variable.

(b) Which of these is an example this unit gives of a field that can act as a proxy?

(a) The correlation, not the label, is what makes a field a proxy. (b) Years at current address is named alongside zip code as a field that can reconstruct a protected characteristic's effect.

10. A team removes the "race" field from a credit-scoring dataset and declares the model fixed. Answer both parts:

(a) Why is this insufficient on its own?

(b) Fill in the blank: the responsible next step isn't removing more fields blindly — it's testing the remaining fields for ___ against a demographic evaluation set.

(a) Dropping a protected field is necessary but not sufficient — proxies can reconstruct its effect without ever naming it. (b) Measuring correlation is the only way to actually confirm a field isn't functioning as a proxy.
