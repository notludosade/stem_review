1. Lesson 1 compares two versions of deleteAccount(). What made the first version different from an ordinary bug?

The lesson is explicit that this isn't a bug — it compiles, runs, and can even pass a test checking hidden === true. It's a decision made by whoever wrote it.

2. According to Lesson 2, how many general principles does the 2018 ACM Code of Ethics list?

Contribute to society, avoid harm, be honest and trustworthy, be fair, respect the work behind new ideas, respect privacy, and honor confidentiality — seven in total.

3. Fill in the blank: applying the ACM principle "avoid harm" to a specific pull request requires interpreting it fresh each time, because it's a ___ — not a mechanical rule with one automatic right answer.

Lesson 2 defines a principle as a lens applied to a specific decision, not a rule with one correct mechanical answer.

4. Lesson 3 lists silent exception handling as one of five ethical red flags. What exactly counts as this red flag?

Lesson 3 describes this red flag as "an empty catch/except block that hides a failure instead of surfacing it," the same problem examined closely in Lesson 2.

5. What does Lesson 3 identify the OWASP Top 10 as?

Lesson 3 calls it "the field's own running list of the most critical web application risks," with injection among them.

6. Answer both parts about this course's place in the STEM+ sequence:

(a) Fill in the blank: this course, Computer Programming Ethics, is the ___ course in the four-course STEM+ programming sequence.

(b) What is the goal of putting ethics before the syntax-heavy courses, according to Lesson 1?

(a) The sequence is Computer Programming Ethics → Computer Programming 1 → Computer Programming 2 → AI Developer, in that order. (b) Ethics comes first so secure, honest, fair defaults are already habit by the time the syntax-heavy courses start.

7. Answer both parts about the Software Engineering Code of Ethics (1999):

(a) Fill in the blank: the Software Engineering Code of Ethics was published jointly by ACM and ___.

(b) The Software Engineering Code organizes obligations into eight areas. Which of these is one of them?

(a) It's the ACM/IEEE-CS Software Engineering Code of Ethics and Professional Practice, published in 1999. (b) The eight areas are the public, client and employer, the product, judgment, management, the profession, colleagues, and self.

8. Consider the fixed version of Lesson 2's payment example, which logs the error and re-raises instead of silently passing. Answer both parts:

(a) What does the honest version do that the silent version does not?

(b) Fill in the blank: Lesson 2 calls a bare except: pass with no logging one of the most common ways ordinary code becomes ___ by accident.

(a) The fixed version only prints "Payment successful!" inside the try block, right after a successful charge — never after a failure. (b) Nobody set out to lie to the user, but that's exactly what a silently-swallowed exception makes the program do.

9. Answer both parts about the injection example in Lesson 3:

(a) Fill in the blank: pasting untrusted input directly into a query or command, letting an attacker change what that command does, is called an ___ vulnerability.

(b) What could a username of ' OR '1'='1 do to the vulnerable login query shown in Lesson 3?

(a) This exact term appears throughout OWASP and most security literature. (b) Someone typing ' OR '1'='1 as a username can rewrite what the query does — no password required.

10. Answer both parts about fixing the injection example:

(a) In the fixed Python example, what replaces the username and password directly inside the query string?

(b) Fill in the blank: Java's PreparedStatement and similar tools in other languages all keep user input separate from the query's ___.

(a) The ? placeholders keep the values separate from the query text itself. (b) The shape of the fix is identical across languages: never let user input become part of the query's structure.
