1. A deleteAccount() function sets users[userId].hidden = true and leaves every row in the database untouched. What does Lesson 1 call this kind of code?

The function's real behavior (hide, keep everything) doesn't match what a user reasonably believes "delete" means — exactly the definition of a dark pattern given in Lesson 1.

2. Which of these is one of the seven general principles in the 2018 ACM Code of Ethics?

The seven are: contribute to society, avoid harm, be honest and trustworthy, be fair, respect the work behind new ideas, respect privacy, and honor confidentiality.

3. Fill in the blank: Lesson 2 defines a general ethical commitment like "avoid harm" — one that must be interpreted for each specific decision rather than applied mechanically — as a ___.

A principle is a lens you apply to a decision, not a rule with one automatic right answer.

4. Which of the following is one of the five ethical red flags Lesson 3 lists to scan for in any language?

The five are hardcoded secrets, unsanitized input reaching a query or command, silent exception handling, plaintext sensitive data, and missing authorization checks.

5. According to Lesson 3, how long has injection been on the OWASP Top 10 list of critical web risks?

Injection has been on the OWASP Top 10 for over a decade precisely because it's this common and this language-independent.

6. Answer both parts about why this course is sequenced the way it is:

(a) Why does Lesson 1 say this course teaches ethics before programming syntax?

(b) Fill in the blank: the four-course STEM+ sequence is Computer Programming Ethics → Computer Programming 1 → Computer Programming 2 → ___ Developer.

(a) The plan is for secure, honest, fair defaults to already be habit by the time the syntax-heavy courses start. (b) The full sequence given in Lesson 1 is Computer Programming Ethics → Computer Programming 1 → Computer Programming 2 → AI Developer.

7. Answer both parts about the Software Engineering Code of Ethics:

(a) What is the Software Engineering Code's relationship to the general ACM Code of Ethics?

(b) Fill in the blank: of the Software Engineering Code's eight areas of obligation, the one most about disclosing risk in what you actually ship is called "___."

(a) Published in 1999 by ACM and IEEE-CS jointly, it's a distinct document narrowed to software engineering practice. (b) The "Product" principle calls for high quality and disclosure of significant risks, rather than burying problems to hit a schedule.

8. Consider this snippet from Lesson 2: try: charge_card(amount) / except Exception: pass / print("Payment successful!"). Answer both parts:

(a) What specifically makes this code dishonest?

(b) Fill in the blank: swallowing an error with a bare except and no logging or re-raising is often described as silent ___ handling.

(a) The bare except: pass discards the failure entirely, so the unconditional success message runs regardless of what actually happened. (b) Lesson 3 names this exact red flag "silent exception handling."

9. Four languages in Lesson 3 build the same login query by concatenating username and password directly into SQL text. Answer both parts:

(a) What is the general name for this class of vulnerability?

(b) Fill in the blank: a username of ' OR '1'='1 can rewrite what the query does because the input was never treated as ___ from the query text.

(a) It's been on the OWASP Top 10 for over a decade precisely because it's this common and this language-independent. (b) The fix is to send the input separately from the query and let the database driver keep the two apart.

10. Answer both parts about the fix to Lesson 3's injection example:

(a) What does the fixed, parameterized version of the login query do differently?

(b) Fill in the blank: the ___ query keeps the query's structure fixed while the database driver binds user-supplied values without letting them change what the query means.

(a) The ? placeholders keep the query's structure fixed, so the database driver binds the values without letting them change what the query means. (b) Java's PreparedStatement and its equivalents in other languages all work the same way.
