# Computer Programming Ethics Resources

## Knowledge

- [ACM Code of Ethics and Professional Conduct](https://www.acm.org/code-of-ethics)
  The field's broadest, most widely adopted ethics code — general principles (contribute to society, avoid harm, be honest, respect privacy) that apply to anyone writing software, not just ACM members. Use for: the "why" behind almost every lesson in this course.
- [ACM/IEEE-CS Software Engineering Code of Ethics and Professional Practice](https://www.acm.org/code-of-ethics/software-engineering-code)
  The profession-specific companion code, organized around 8 principles (Public, Client & Employer, Product, Judgment, Management, Profession, Colleagues, Self). Use for: concrete professional obligations — adequate testing, honest documentation, respecting privacy in what software collects.
- [OWASP Top 10:2021](https://owasp.org/Top10/2021/)
  The standard, consensus-built list of the most critical web application security risks (injection, broken access control, cryptographic failures, and more), each with real attack examples. Use for: every lesson on secure-by-default code.
- [Wikipedia — Programming Ethics](https://en.wikipedia.org/wiki/Programming_ethics)
  Accessible overview tying the ACM and IEEE-CS codes together with historical context (Gotterbarn's early-1990s work). Use for: a quick orienting read, cross-checked against the primary codes above before citing anything specific.

## Wisdom (Communities)

- [r/ExperiencedDevs](https://www.reddit.com/r/ExperiencedDevs/)
  Moderated community of working software engineers who regularly discuss real ethical dilemmas (being asked to build a dark pattern, finding a security hole and not knowing who to tell). Use for: grounding a lesson's scenario in something that actually happens on the job.
- [r/netsec](https://www.reddit.com/r/netsec/)
  Security-practitioner community, higher signal than general programming subs for anything OWASP-adjacent. Use for: sanity-checking the secure-by-default units against current practitioner thinking.

## Gaps

- No single community exists specifically for "programming ethics" as its own topic — coverage is split across general security and general software-engineering spaces. Revisit if a dedicated venue (e.g. a responsible-tech Slack/Discord) surfaces later.
