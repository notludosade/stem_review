Unit 6 Test — Version A

Licensing, Attribution & Open Source Trust. 10 points across every lesson in this unit — 5 questions worth 1 point, 5 worth 1 point split across two parts. Score 90% or higher to clear this unit.

1. What is the defining difference between a permissive license (like MIT) and a copyleft license (like GPL)?

MIT/Apache/BSD are permissive; GPL/AGPL are copyleft and can require your own code to be released under the same terms.

2. Fill in the blank: under default copyright law in most countries, a public repository with no LICENSE file means the original author retains ___ ___, and no one else technically has permission to use the code.

Visibility and permission are different things — the code being visible on GitHub doesn't grant anyone the right to use it.

3. Fill in the blank: content posted as a Stack Overflow answer is covered by the ___ license, which requires attribution on reuse and, like the GPL, asks that adaptations carry compatible terms.

Creative Commons Attribution-ShareAlike (CC BY-SA) is the specific variant that applies to Stack Overflow content.

4. An AI coding assistant suggests a long, unusually specific block of code that solves your exact problem perfectly. What's the reasonable practice this unit recommends?

AI-assisted code isn't automatically unusable — but for anything beyond a short, generic pattern, the same verification judgment applies as with any other copy-paste.

5. A developer means to install a package called `reqeusts` but actually installs a malicious package published under that exact misspelled name. What is this attack pattern called?

Typosquatting relies on a developer mistyping a package name and getting the malicious lookalike instead of the real one.

6. A company wants to bundle a GPL-licensed parsing library inside a proprietary, closed-source product it plans to sell. Answer both parts:

(a) What's the actual risk here?

(b) Fill in the blank: a license category, like the GPL, that requires derivative works to carry the same license terms is called ___.

(a) Using a GPL library inside closed-source software you plan to sell can obligate the whole distributed product to be released under the GPL. (b) That obligation to keep derivatives open is exactly what "copyleft" means.

7. A developer adapts a 40-line parsing function from a specific GitHub repository into their own project. Answer both parts:

(a) What should accompany the copied code in the project?

(b) Fill in the blank: crediting the original author or source of reused code, so a license's terms are actually honored, is called ___.

(a) Naming the source and license makes the code traceable and honors the terms attached to it. (b) That credit-giving practice is attribution.

8. A developer says, "It's only twelve lines from a Stack Overflow answer, that's too small to matter legally." Answer both parts:

(a) What does this unit say actually determines whether a licensing question applies?

(b) Fill in the blank: the more substantial, distinctive, or clearly a work of creative ___ a copied block is, the less reasonable it is to treat it as too small to matter.

(a) Very small, generic snippets are often handled pragmatically, but origin and distinctiveness — not size — are what actually matter. (b) A court would weigh whether the block reflects real creative expression, not just its length.

9. An attacker gains access to the publishing credentials of a legitimate, widely-used package and slips malicious code into a routine update. Answer both parts:

(a) Fill in the blank: this attack pattern, which targets software indirectly through a trusted dependency rather than attacking it directly, is called ___ ___ ___.

(b) Why does this kind of attack cause more damage than one aimed directly at a single project?

(a) Compromising a trusted dependency instead of the target directly is a supply chain compromise. (b) One compromised update can propagate to thousands of downstream projects without any of them writing insecure code themselves.

10. Before adding a new dependency, a developer checks that it's actively maintained, has a plausible number of users, and has no open security advisories. Answer both parts:

(a) What should they do about which version to install, and why?

(b) Fill in the blank: locking a dependency to a specific, tested release instead of always tracking the newest one is called version ___.

(a) Pinning prevents an update from silently changing what code is running without your knowledge. (b) This practice is version pinning.
