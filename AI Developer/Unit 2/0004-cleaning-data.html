Cleaning Data

Lesson 3's dataset was tidy on purpose. Real data never is — it has gaps, mistakes, and mismatched scales, all before a model ever sees it.

Lesson 5 → Contents Glossary →

Three problems show up in almost every real dataset: a missing value (a gap where a measurement was never recorded), an outlier (a value so extreme it's likely an error or a genuinely unusual case), and features on wildly different scales, which normalization fixes.

Python — pandas + scikit-learn 
import pandas as pd
from sklearn.preprocessing import StandardScaler

data = pd.DataFrame({
    "square_feet": [1200, 1800, 950, None, 50000],   # None: missing; 50000: likely an error
    "bedrooms":    [2, 3, 1, 2, 3],
    "price":       [250000, 340000, 180000, 210000, 9000000],
})

# 1. Handle missing values
data = data.dropna()                       # remove rows with a gap
# (or: data["square_feet"].fillna(data["square_feet"].mean()) to fill it in instead)

# 2. Handle outliers — a simple, visible threshold here
data = data[data["square_feet"] < 10000]   # drops the 50,000 sq ft "house"

# 3. Normalize — put features on comparable scales
scaler = StandardScaler()
data[["square_feet", "bedrooms"]] = scaler.fit_transform(data[["square_feet", "bedrooms"]])
# square_feet (hundreds to thousands) and bedrooms (single digits) are now
# both centered around 0 with comparable spread

Each step matters for a different reason. A missing value left in place usually crashes the model outright or silently poisons a calculation — dropna() or filling it with a sensible value (often the column's average) are the two basic options. An outlier like a 50,000-square-foot "house" is almost certainly a data-entry mistake, and left in, it can badly distort a model that's sensitive to extreme values — it deserves at least a second look, not automatic trust. And without normalization, a model that measures distance or slope between features — including the KMeans clustering from Lesson 2 and the gradient descent Unit 4 builds — would treat square_feet's much larger numbers as automatically more important than bedrooms, purely because of scale, not real importance.

Definition A missing value is a gap where data was never recorded. An outlier is a value extreme enough to likely be an error or a genuinely unusual case. Normalization rescales features onto comparable ranges so no feature dominates purely due to its raw scale.
Why it matters here "Garbage in, garbage out" applies to every model in this course — Unit 3's classical models and Unit 4's neural networks alike are only as good as the data they're trained on. Cleaning isn't a chore that happens before the real work starts; for most real projects, it is most of the real work.

Check your recall

1. What is a missing value?

The None in the square_feet column above is exactly this — a gap, not a real value of zero or anything else.

2. Why is the 50,000-square-foot entry treated as an outlier worth checking rather than trusted automatically?

It's roughly 25 times larger than any other value in the column — a strong signal something went wrong when it was recorded.

3. Why does normalization matter for a model like KMeans or a neural network using gradient descent?

square_feet's naturally larger numbers would otherwise dominate distance and gradient calculations over bedrooms.
