1. A dataset of restaurant reviews includes columns for wait_time_minutes, party_size, and star_rating, where star_rating is what a model is trying to predict. Which of the following is true?

The inputs the model is given are features; the correct output it's trying to predict, star_rating, is the label.

2. Fill in the blank: by near-universal convention, the input columns a model is given are called ___ (a single capital letter) in almost all machine learning code.

Features are called X and labels are called y — the naming convention used in fit(X_train, y_train) throughout the field.

3. A column of recorded rainfall totals has several blank entries on days when the gauge was never read. Answer both parts:

(a) What is this kind of gap called?

(b) Fill in the blank: instead of dropping these rows, a second option is to ___ the gap in with a sensible value, often the column's average.

(a) An unrecorded measurement is a missing value. (b) fillna() with the column's average is the standard alternative to dropping the row entirely.

4. In a dataset of household monthly grocery spending (in dollars), one row lists a value of $480,000. What is the most reasonable way to treat this value?

$480,000 in monthly groceries is far outside any plausible household spending — a clear candidate for a data-entry error worth checking, not automatic trust.

5. A dataset has one feature measured in square meters (ranging from 40 to 400) and another measured as a count of rooms (1 to 8). Answer both parts:

(a) What happens if these features are used, unscaled, in a model whose training relies on gradient-based distance calculations (like a neural network's gradient descent)?

(b) Fill in the blank: rescaling features onto comparable ranges, often using a tool like StandardScaler, is called ___.

(a) Naturally larger raw numbers dominate distance and gradient calculations unless features are put on comparable scales first. (b) That rescaling step is normalization.

6. Which data split does a model's coefficients, weights, or splits actually come from?

A model learns everything it knows directly from the training set — that's what fitting a model on data means.

7. While building a spam classifier, a developer tries five different max_depth settings for a decision tree and wants to see which setting performs best before finalizing anything. Answer both parts:

(a) Which split should be used to compare these five settings?

(b) Fill in the blank: the ___ set exists specifically for decisions made while a model is still being built, like this one.

(a) Comparing candidate settings during development is precisely what the validation set is for. (b) It's the split meant to be checked repeatedly for exactly this kind of decision.

8. A developer checks the test set's score, doesn't like the result, tweaks a setting, and plans to check the test set again to see if the new setting helped. Answer both parts:

(a) What's wrong with this plan?

(b) Fill in the blank: the test set should be checked exactly ___, at the very end.

(a) Reusing the test set for tuning quietly turns it into a second validation set and destroys the one honest final measurement it was meant to provide. (b) Exactly once, after every other decision has already been made.

9. A model scores 0.35 on its training data and 0.33 on its validation data. What does this indicate?

Poor scores on both training and validation data, with no large gap between them, is underfitting — too simple a model to capture the real pattern anywhere.

10. Another model scores 0.97 on its training data and 0.51 on its validation data. Answer both parts:

(a) What does this pair of scores indicate?

(b) Fill in the blank: memorizing training data instead of the real underlying pattern is called ___.

(a) A much higher training score than validation score is the classic overfitting gap. (b) That failure mode — memorizing instead of learning the real pattern — is called overfitting.
