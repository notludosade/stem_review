1. A dataset of used bicycles includes columns for frame_size, gear_count, and resale_price, where resale_price is what a model is trying to predict. Which of the following is true?

Features are the inputs a model is given; the label is the correct output it's trying to predict — resale_price is what's being predicted here.

2. Fill in the blank: by near-universal convention in machine learning code, the features are called X and the labels are called ___.

fit(X_train, y_train) uses exactly this naming convention throughout the field's tools and documentation.

3. A column of patient ages in a medical dataset has several blank entries where no age was ever recorded. Answer both parts:

(a) What is this gap called?

(b) Fill in the blank: one basic option for handling it is to ___ rows that contain a missing value entirely (a second option is to fill the gap in instead).

(a) A gap where a measurement was never recorded is a missing value. (b) dropna() removes rows with a gap outright — the other basic option is filling the gap in, often with the column's average.

4. In a dataset of adult human heights (in inches), one row lists a height of 780. What is the most reasonable way to treat this value?

780 inches (65 feet) is wildly outside any real adult height — exactly the kind of extreme, likely-erroneous value an outlier check exists to catch.

5. A dataset has one feature measured in dollars (ranging from 10,000 to 500,000) and another measured as a count from 1 to 5. Answer both parts:

(a) Why might this be a problem for a model like KMeans that measures distance between features?

(b) Fill in the blank: rescaling both features onto comparable ranges so neither dominates purely by scale is called ___.

(a) Without rescaling, the feature with naturally larger raw numbers dominates distance calculations, regardless of its real importance. (b) That rescaling step is normalization, e.g. via StandardScaler.

6. What is the training set's job?

Every weight, rule, or split a model produces comes from studying its training set directly — that's what training means.

7. A team trains three candidate models and wants to decide which one to move forward with, trying different settings along the way. Answer both parts:

(a) Which data split should this comparison use?

(b) Fill in the blank: unlike the test set, the ___ set can be checked repeatedly throughout development without losing its purpose.

(a) The validation set exists precisely for repeated tuning and model comparison during development. (b) It's the one split designed to be reused this way — the test set is not.

8. After finishing all tuning using the validation set, a developer is tempted to check the test set twice — once now, and again after making one more small tweak. Answer both parts:

(a) What is the correct rule here?

(b) Fill in the blank: checking the test set early, or more than once, quietly turns it into a second ___ set, and the honest final number disappears.

(a) One honest final check, after all other decisions, is the entire point of holding out a test set. (b) Reusing it for tuning quietly makes it a second validation set, and its honesty is lost.

9. A model scores 0.99 on its training data and 0.40 on its validation data. What does this gap indicate?

A much better training score than validation score is the classic overfitting symptom — memorizing training data, including its noise, instead of the real pattern.

10. A different model scores 0.42 on its training data and 0.39 on its validation data. Answer both parts:

(a) What does this pair of scores indicate?

(b) Fill in the blank: a model that performs well on new, unseen data because it learned the real underlying pattern is said to ___ well.

(a) Poor scores everywhere, training included, is underfitting — too simple a model to capture the real pattern at all. (b) The actual goal, sitting between overfitting and underfitting, is to generalize well.
