1. A model predicts a house's exact resale price in dollars, as a weighted sum of its square footage and bedroom count. What kind of model is this?

A continuous numeric label produced from a weighted sum of features is exactly what linear regression predicts.

2. A trained linear regression model has coef_ = [3.2, 150.0] for features [age_years, mileage_thousands], and an intercept of 20000, predicting a used car's resale price. Answer both parts:

(a) What does the coefficient 150.0 represent?

(b) Fill in the blank: fit() searches for the exact coefficients that make training predictions as close as possible to the true labels, guided by a ___ function measuring that distance.

(a) Each coefficient is the per-unit effect of one feature on the prediction, holding the others fixed. (b) That search is guided by minimizing a loss function, such as mean squared error.

3. Fill in the blank: mean squared ___ is computed by averaging the squared distance between each prediction and its true value, and smaller values indicate a better-fitting model.

Mean squared error is one common loss function — the average of each prediction's squared distance from the true value.

4. Despite its name, what task does logistic regression actually perform?

The name is historical — logistic regression is a classification model that predicts a category, like spam or not spam.

5. A logistic regression model computes a weighted sum of −2.0 for a given email, then passes it through the sigmoid function, producing 0.12. Answer both parts:

(a) What does the sigmoid function guarantee about its output, regardless of the input number?

(b) Fill in the blank: an output of 0.12 means the model estimates roughly a 12% ___ that this email is spam.

(a) Squashing any real number into a value strictly between 0 and 1 is the sigmoid function's entire job. (b) That squashed value is interpreted directly as a probability.

6. A model outputs predict_proba probabilities of 0.62, 0.41, and 0.50 for three emails. Answer both parts:

(a) Using the default threshold, which of these become a positive ("spam") prediction?

(b) Fill in the blank: predict() turns a probability into a final answer using a ___ — 0.5 by default, though it can be moved deliberately.

(a) Anything at or above 0.5 becomes a positive prediction by default. (b) That cutoff point is the threshold, and it isn't fixed by the math — it can be moved.

7. A trained decision tree's first question is num_links > 2. What is this specific feature-and-threshold test called?

A split is the specific feature and threshold a tree node tests — num_links > 2 is one example.

8. Two decision trees are trained on the same spam dataset: one with max_depth=3, and one with no depth limit at all. Answer both parts:

(a) What is the biggest risk with the unlimited-depth tree?

(b) Fill in the blank: limiting max_depth is one direct way to control ___ — the same failure mode covered in Unit 2, here caused by excess model complexity instead of a data problem.

(a) An unlimited tree can grow a branch for nearly every training example, memorizing rather than generalizing. (b) That's overfitting, controlled here by limiting model complexity rather than touching the data.

9. In a dataset where only 4% of transactions are fraudulent, a model that predicts "not fraud" for every single transaction achieves 96% accuracy. What does this reveal about accuracy as a metric here?

A model that never flags fraud can still score high accuracy purely because fraud is rare — recall is what exposes the zero-detection flaw that accuracy alone hides completely.

10. A spam filter's confusion matrix shows 3 false positives (legitimate emails wrongly flagged) and 20 false negatives (real spam that slipped through). Answer both parts:

(a) Which metric is most directly hurt by the 20 false negatives?

(b) Fill in the blank: of everything flagged as spam, the fraction that truly was spam is measured by ___.

(a) False negatives — real spam that slipped through unflagged — directly hurt recall. (b) That "of everything flagged, how much was real" question is exactly what precision measures.
