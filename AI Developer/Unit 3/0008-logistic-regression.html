Logistic Regression

Lesson 1's spam filter used this model already, without explaining how it turns a weighted sum into a yes-or-no answer. Here's the missing piece.

Lesson 9 → Contents Glossary →

Despite the name, logistic regression is a classification model — it predicts a category (spam or not spam), not a continuous number. It computes the same kind of weighted sum as linear regression, then passes that sum through a sigmoid function, which squashes any real number into a value strictly between 0 and 1 — interpretable as a probability.

Python — scikit-learn 
from sklearn.linear_model import LogisticRegression

model = LogisticRegression()
model.fit(X_train, y_train)   # y_train: 0 for "not spam", 1 for "spam"

probabilities = model.predict_proba(X_val)[:, 1]   # P(spam) for each email
predictions = model.predict(X_val)                  # probabilities >= 0.5 become 1

print(probabilities[:3])   # e.g. [0.92, 0.13, 0.55]
print(predictions[:3])     # e.g. [1, 0, 1]

An email with probability = 0.92 is one the model is quite confident is spam; 0.13 is confident it isn't; 0.55 is barely leaning spam at all. predict() turns each of these probabilities into a final 0-or-1 answer using a threshold — 0.5 by default, meaning anything at or above 0.5 becomes a positive prediction. That threshold isn't fixed by the math; it can be moved deliberately, which matters once Lesson 10 gets into exactly what kind of mistake a classifier is making.

Definition Logistic regression is a classification model that produces a probability via a sigmoid function applied to a weighted sum of features. The sigmoid function maps any real number to a value between 0 and 1. Classification is predicting a category rather than a continuous number.
Why it matters here This is the exact model Lesson 1 used for the spam filter, and it's the direct predecessor to the neural network output layer built in Unit 4 — a neural network doing binary classification ends with this same sigmoid step. Lesson 9 tackles the identical spam-or-not problem with a completely different kind of model, decision trees, so the two approaches can be compared directly.

Check your recall

1. Despite its name, what does logistic regression actually do?

The name is historical — the model itself predicts a category, like spam or not spam.

2. What does the sigmoid function do to the weighted sum computed inside the model?

Any real number in, a value between 0 and 1 out — that squashing is the sigmoid's entire job.

3. What threshold does predict() use by default to convert a probability into a final 0-or-1 answer?

Anything at or above 0.5 becomes a positive prediction by default, though this can be moved deliberately.
