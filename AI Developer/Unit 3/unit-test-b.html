1. A model predicts a car's exact fuel efficiency in miles per gallon, as a weighted sum of its weight and engine size. What kind of model is this?

A continuous numeric label, like miles per gallon, produced from a weighted sum of features is exactly what linear regression predicts.

2. A trained linear regression model has coef_ = [-1800.0, 0.05] for features [age_years, mileage_total], and an intercept of 25000, predicting a used car's resale price. Answer both parts:

(a) What does the coefficient −1800.0 represent?

(b) Fill in the blank: fit() searches for coefficients that minimize a ___ function measuring how far predictions are from the true labels.

(a) A negative coefficient means the prediction decreases as that feature increases — here, older cars are predicted to be worth less, all else held fixed. (b) That search minimizes a loss function.

3. Fill in the blank: mean squared ___ is computed by averaging the squared distance between each prediction and its true value, and smaller values indicate a better-fitting model.

Mean squared error is one common loss function — the average of each prediction's squared distance from the true value.

4. A model computes a weighted sum of a patient's symptoms, passes it through a sigmoid function, and outputs a probability of disease presence. What kind of task is this model performing?

Producing a probability via a sigmoid, used to predict a category (disease or not), is logistic regression performing classification.

5. A logistic regression model computes a weighted sum of 3.5 for a given loan applicant, then passes it through the sigmoid function, producing 0.97. Answer both parts:

(a) What can be said about the sigmoid function's output here, and in general?

(b) Fill in the blank: an output of 0.97 means the model estimates roughly a 97% ___ that this applicant belongs to the positive class.

(a) The sigmoid squashes any real number into a value strictly between 0 and 1, never reaching either endpoint exactly. (b) That squashed value is read directly as a probability.

6. A model outputs predict_proba probabilities of 0.30, 0.55, and 0.49 for three loan applicants. Answer both parts:

(a) Using the default threshold, which become a positive prediction?

(b) Fill in the blank: predict() converts a probability into a final answer using a ___, which defaults to 0.5 but can be moved deliberately.

(a) 0.55 is the only value at or above the default 0.5 cutoff. (b) That cutoff is the threshold, and it can be moved deliberately away from its 0.5 default.

7. A trained decision tree's second question, reached only after num_links > 2 is true, is num_exclamations > 5. What is this feature-and-threshold test called?

Every node in a decision tree tests a split — a specific feature and threshold — and num_exclamations > 5 is one example.

8. A decision tree trained with no max_depth limit reaches 100% accuracy on its training data but performs poorly on new data. Answer both parts:

(a) What most likely explains this gap?

(b) Fill in the blank: limiting how many questions deep a tree can grow, via max____, is one direct way to control this kind of overfitting.

(a) Perfect training accuracy alongside poor new-data performance is the classic overfitting signature, caused here by unchecked tree growth. (b) max_depth is exactly the setting that limits this growth.

9. In a medical dataset where only 2% of patients actually have a rare disease, a model that predicts "no disease" for every patient achieves 98% accuracy. What does this reveal?

Because the disease is rare, always predicting "no disease" scores high accuracy while catching zero real cases — exactly the flaw recall exposes and accuracy alone hides.

10. A different spam filter's confusion matrix shows 25 false positives (legitimate emails wrongly flagged) and 2 false negatives (real spam that slipped through). Answer both parts:

(a) Which metric is most directly hurt by the 25 false positives?

(b) Fill in the blank: of everything that truly was spam, the fraction the model actually caught is measured by ___.

(a) False positives — legitimate emails wrongly flagged — directly hurt precision. (b) That "of everything truly positive, how much got caught" question is exactly what recall measures.
