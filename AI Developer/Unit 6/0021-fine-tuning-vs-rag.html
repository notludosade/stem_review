Fine-Tuning vs. RAG

Lesson 20 changed the prompt to change behavior. Sometimes that isn't enough — a model can't answer with facts it never saw, no matter how the prompt is worded. There are two real fixes, not one.

Lesson 22 → Contents Glossary →

Fine-tuning continues training a pretrained model on your own labeled examples, actually updating its weights through the same gradient descent and backpropagation from Unit 4 — just starting from an already-trained model instead of random weights. RAG (Retrieval-Augmented Generation) changes no weight at all: it retrieves relevant text via the embeddings and semantic search from Lesson 19, then inserts that text directly into the prompt as context, exactly as Lesson 20 shaped prompts to steer behavior.

Python — RAG, combining Lessons 18-20 
from openai import OpenAI
import numpy as np

client = OpenAI()

def embed(text):
    return np.array(client.embeddings.create(
        model="text-embedding-3-small", input=text
    ).data[0].embedding)

def cosine_similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

docs = [
    "Refunds are issued within 5 business days of a return request.",
    "The battery lasts approximately 10 hours on a full charge.",
]
doc_vectors = [embed(d) for d in docs]

question = "How long until I get my money back?"
q_vector = embed(question)
best = max(range(len(docs)), key=lambda i: cosine_similarity(q_vector, doc_vectors[i]))

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "system", "content": f"Answer using only this context: {docs[best]}"},
        {"role": "user", "content": question},
    ],
)
print(response.choices[0].message.content)

Nothing about the model's weights changes in that example — the retrieved sentence is just inserted into the system message as context, and the model answers from it. That makes RAG cheap to keep current: add a new document, and the very next query can retrieve it immediately, with no retraining at all. Fine-tuning is the better fit for a different kind of problem entirely — not "the model doesn't know this fact," but "the model needs to consistently respond in a specific style, format, or behavior across every request," which repeated examples in a prompt can only approximate and actual weight updates can lock in directly.

Definition Fine-tuning continues training a pretrained model on new labeled examples, updating its weights. RAG (Retrieval-Augmented Generation) retrieves relevant text via semantic search and inserts it into the prompt as context, with no weight changes at all.
