Embeddings and Semantic Search

Lesson 18's API turns text into text. This lesson turns text into numbers — and those numbers turn out to be searchable by meaning, not just by matching words.

Lesson 20 → Contents Glossary →

An embedding is a list of numbers — a vector — representing a piece of text's meaning, produced by a model trained so that texts with similar meaning end up with similar vectors. Comparing two embeddings with cosine similarity gives a number close to 1 for closely related meanings and close to 0 for unrelated ones, even when the two texts don't share a single word.

Python — OpenAI API 
from openai import OpenAI
import numpy as np

client = OpenAI()

def embed(text):
    response = client.embeddings.create(
        model="text-embedding-3-small",
        input=text,
    )
    return np.array(response.data[0].embedding)

def cosine_similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

query = embed("How do I reset my password?")
doc_a = embed("Steps to change your account password")
doc_b = embed("Our refund policy for annual subscriptions")

print(cosine_similarity(query, doc_a))   # high — related meaning
print(cosine_similarity(query, doc_b))   # low — unrelated meaning

Notice that query and doc_a share almost no words in common, yet their embeddings land close together because the underlying meaning is close. This is semantic search: instead of matching exact keywords like a traditional search engine, embed every document once, embed the incoming query, and rank documents by cosine similarity to find the ones that mean the same thing. In practice, a real system embeds a whole library of documents ahead of time and stores the vectors, so only the query needs embedding at search time.

Definition An embedding is a vector representing a piece of text's meaning, positioned so similar meanings produce similar vectors. Cosine similarity measures how close two vectors point in the same direction. Semantic search ranks results by embedding similarity rather than exact keyword matches.
Why it matters here Lesson 18's chat API only knows what it was trained on — it can't see your private documents. Embeddings are the standard way to bridge that gap: find the most relevant passages from your own data by meaning, then hand just those passages to the chat API as context.
