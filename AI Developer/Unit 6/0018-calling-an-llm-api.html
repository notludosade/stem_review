Calling an LLM API

Nobody trains a model like Lesson 17's from scratch just to use one. Units 6 through 9 are about the far more common path: using models someone else already trained.

Lesson 19 → Contents Glossary →

A large language model API lets a program send text in and get generated text back, without training anything at all — just inference: running an already-trained model forward to produce output.

Python — OpenAI API 
from openai import OpenAI

client = OpenAI()

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain what a for loop does, in one sentence."},
    ],
)

print(response.choices[0].message.content)

model picks which pretrained model — built from Transformer layers exactly like Lesson 17 described, just trained on far more data than any individual could realistically gather — handles the request. messages is a list of turns, each tagged with a role: system sets overall behavior and instructions before the real request arrives, user is the actual question or task, and an assistant role would hold the model's own prior reply if the conversation continues across multiple turns. The response comes back as a structured object, not raw text — the generated text itself sits at response.choices[0].message.content.

Definition Inference is generating output from an already-trained model, with no further training taking place. A role tags each message in an API conversation as system, user, or assistant, shaping how the model interprets it.

From here forward, the far more common real-world task is using one someone else already built and trained — a completely different skill set.
