1. A developer sends a prompt to a pretrained LLM through an API and receives generated text back, without updating any of the model's weights. What is this process called?

Inference is generating output from an already-trained model, with no further training taking place.

2. Using the OpenAI chat completions API exactly as shown in the lesson, where does the model's generated reply text appear in the response object?

The response comes back as a structured object, and the generated text sits at exactly this path.

3. Fill in the blank: a vector of numbers that represents a piece of text's meaning, positioned so that texts with similar meaning produce similar vectors, is called an ___.

An embedding positions similar meanings close together as vectors, even when the underlying words differ.

4. Fill in the blank: the parameter that controls how much randomness a model uses when generating each word — set near 0 for consistent, repeatable output — is called ___.

Temperature controls how much randomness goes into picking each generated word.

5. Fine-tuning continues training a pretrained model on new labeled examples. What actually changes inside the model as a result?

Fine-tuning is real further training, starting from an already pretrained model's weights instead of random ones.

6. An API call's messages list includes {role: system, content: "You are a concise assistant."} followed by {role: user, content: "Summarize this article."}. Answer both parts:

(a) What does the system message set?

(b) Fill in the blank: the role that represents the actual question or task for this turn — as opposed to overall behavior instructions — is the ___ role.

(a) The system role sets overall behavior before the real request arrives. (b) The user role holds the actual question or task for that turn.

7. A query "How do I get a refund?" is embedded and compared against two documents: Doc A, "Steps for returning an item for money back," and Doc B, "Battery life specifications." Answer both parts:

(a) Despite sharing almost no exact words with the query, why would Doc A likely score a high cosine similarity against it?

(b) Fill in the blank: ranking documents by embedding similarity to a query, rather than by exact keyword matches, is called ___ search.

(a) Embeddings capture meaning, so related texts score high similarity even without shared words. (b) Ranking by embedding similarity rather than keyword matches is semantic search.

8. Before asking a model to classify a new review, a prompt includes two already-labeled example reviews with their correct labels. Answer both parts:

(a) What is this technique of including worked examples before the real request called?

(b) Why does this technique tend to work more reliably than just describing the desired pattern in words?

(a) Including worked examples before the real request is few-shot prompting. (b) Showing the exact pattern directly is more reliable than describing it in words alone.

9. A RAG system embeds a question, finds the most similar stored document by cosine similarity, and inserts that document's text into the prompt before asking the model to answer. Answer both parts:

(a) Does this process change any of the model's weights?

(b) Fill in the blank: RAG retrieves relevant text and inserts it into the prompt as ___, letting a new document take effect on the very next query with no retraining.

(a) RAG changes no weight at all — it only inserts retrieved text into the prompt. (b) That retrieved text is inserted as context for the model to answer from.

10. A team needs their assistant to (1) always answer in a specific formal tone across every request, and (2) answer questions about a document added to their library yesterday. Answer both parts:

(a) Which approach better fits requirement (1), consistently locking in a specific tone or style?

(b) Which approach better fits requirement (2), immediately using a document added just yesterday?

(a) Fine-tuning locks in style or behavior directly through weight updates. (b) RAG is cheap to keep current since a new document is retrievable on the very next query.
