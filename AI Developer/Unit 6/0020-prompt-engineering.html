Prompt Engineering

Lesson 18 sent a plain question and got a plain answer. The exact wording, structure, and examples in that request change the output far more than most people expect.

Lesson 21 → Contents Glossary →

Prompt engineering is deliberately designing the text sent to a model to reliably get the output you actually want, without changing the model itself at all. Two techniques do most of the work: giving the model a handful of worked examples first, and controlling how much randomness it uses when generating.

Python — OpenAI API 
from openai import OpenAI

client = OpenAI()

response = client.chat.completions.create(
    model="gpt-4o-mini",
    temperature=0,
    messages=[
        {"role": "system", "content": "Classify each review as positive or negative. Reply with one word only."},
        {"role": "user", "content": "Review: The battery died in an hour.\nLabel:"},
        {"role": "assistant", "content": "negative"},
        {"role": "user", "content": "Review: Setup took thirty seconds and it just worked.\nLabel:"},
        {"role": "assistant", "content": "positive"},
        {"role": "user", "content": "Review: Shipping was fast but the box arrived crushed.\nLabel:"},
    ],
)

print(response.choices[0].message.content)

Giving the model completed examples before the real question — here, two labeled reviews before the unlabeled third one — is called few-shot prompting. It shows the exact input/output pattern expected far more reliably than describing the pattern in words alone. temperature controls how much randomness goes into picking each generated word: a low value like 0 makes output nearly deterministic and consistent, which matters for a task like classification where the same review should always get the same label; a higher value produces more varied, creative output, useful for brainstorming but a liability here.

Definition Prompt engineering is designing the input text sent to a model to reliably shape its output, without changing the model itself. Few-shot prompting includes worked examples in the prompt before the real request. Temperature controls how much randomness the model uses when generating each word.
Why it matters here Every unit before this one changed a model's weights to improve its behavior — through gradient descent, backpropagation, more training data. Prompt engineering gets better output from a model whose weights never change at all.
