1. A team runs their already-trained model forward on new input text to generate a response, without adjusting a single weight in the process. What is this called?

Running an already-trained model forward with no weight updates is exactly inference.

2. In the OpenAI chat completions API, a request is sent with a system message and a user message. What kind of object does the API return the result as?

The API returns a structured response object, not raw text, with the reply at that exact path.

3. Fill in the blank: turning a piece of text into a list of numbers that captures its meaning — so that texts meaning similar things end up with similar vectors — produces an ___.

This vector of numbers representing meaning is an embedding.

4. Fill in the blank: setting this generation parameter to a high value produces more varied, creative output — useful for brainstorming but risky for tasks needing one consistent answer; it is called ___.

Temperature is the parameter that controls this randomness in generation.

5. A company continues training a pretrained model on thousands of their own labeled support tickets. What is this process called, and what does it actually do to the model?

Fine-tuning is real further training that updates weights, starting from an already pretrained model.

6. An API call's messages list includes a system message with formatting instructions, a user message asking a question, then an assistant message holding a previous reply, before a second user message continues the conversation. Answer both parts:

(a) Fill in the blank: the role that holds the model's own prior reply, when a conversation continues across multiple turns, is the ___ role.

(b) What does the very first system message typically establish?

(a) The assistant role holds the model's own prior reply in a multi-turn conversation. (b) The system message sets overall behavior before the real request arrives.

7. A query "What's your cancellation policy?" is embedded and compared by cosine similarity against Doc A, "How to end your subscription and stop billing," and Doc B, "Product color options." Answer both parts:

(a) Fill in the blank: the measure used to compare two embeddings, giving a value near 1 for closely related meanings and near 0 for unrelated ones, is called ___ similarity.

(b) Which document would most likely score the higher cosine similarity against the query, and why?

(a) Cosine similarity is the measure compared here, near 1 for related meaning. (b) Doc A's meaning is much closer to the query's, even without shared words.

8. A prompt for a sentiment-classification task includes three already-labeled example sentences with their correct labels, placed before the real sentence to classify. Answer both parts:

(a) Fill in the blank: providing worked examples in a prompt before the real request, so the model can see the exact pattern expected, is called ___-shot prompting.

(b) What does this technique change about the model itself?

(a) Worked examples placed before the real request is few-shot prompting. (b) It changes the prompt only — no model weight is touched.

9. A support bot embeds an incoming question, retrieves the single most similar stored document, and places its text into the system message before the model answers. Answer both parts:

(a) Fill in the blank: this full technique — retrieving relevant text via semantic search and inserting it into the prompt as context — is called ___ (Retrieval-Augmented Generation).

(b) Why is this approach considered cheap to keep current when new information appears?

(a) This retrieve-then-insert-as-context technique is RAG. (b) Since no weights change, a new document is retrievable immediately on the next query.

10. A team's assistant frequently gives outdated answers about a product catalog that changes weekly, and separately, stakeholders want every response formatted in a strict, consistent structure. Answer both parts:

(a) Which technique better addresses the weekly-changing catalog problem?

(b) Which technique better addresses locking in a strict, consistent response structure across every request?

(a) RAG keeps a weekly-changing catalog current with no retraining. (b) Fine-tuning locks in a consistent structure or behavior more directly than retrieval can.
