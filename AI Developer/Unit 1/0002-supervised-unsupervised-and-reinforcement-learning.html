Supervised, Unsupervised, and Reinforcement Learning

Machine learning means learning from data — but what the data looks like, and what "correct" even means, splits into three very different setups.

Lesson 3 → Contents Glossary →

In supervised learning, every training example comes with the correct answer attached. Lesson 1's spam filter is supervised: each email in X_train had a known label in y_train — spam or not — and the model's whole job was matching that answer as closely as possible.

Unsupervised learning — no labels at all 
from sklearn.cluster import KMeans

# X: customer purchase data — no "correct group" was ever assigned to anyone
model = KMeans(n_clusters=3)
model.fit(X)          # notice: no y argument exists here

labels = model.labels_   # the 3 groups were *discovered*, not looked up

There's no y_train here at all — nobody labeled any customer with their "correct" group in advance. Unsupervised learning finds structure in data that was never labeled to begin with; KMeans above groups similar customers together purely from patterns in the data itself, and it's up to a person afterward to look at each group and decide what it seems to represent.

Reinforcement learning — no labels, but a reward signal 
# A game-playing agent — nobody labeled the "correct" move for any position
for step in range(num_steps):
    action = agent.choose_action(current_state)
    current_state, reward = environment.step(action)
    agent.learn(current_state, action, reward)   # adjusts strategy toward higher reward

Reinforcement learning has no labeled correct answers either, but it isn't structureless like clustering — it has a reward: a number telling the agent how good or bad an action turned out to be (points scored, a game won or lost). The agent learns a strategy purely by trying actions and adjusting toward whatever earned more reward, the same way a person gets better at a game through repeated feedback rather than being told the right move in advance.

Definition Supervised learning learns from labeled input/output pairs. Unsupervised learning finds structure in unlabeled data, with no correct answer given. Reinforcement learning learns a strategy from reward feedback on actions taken in an environment, with no labels at all.
Why it matters here Nearly everything in Unit 3 (classical ML) and Unit 4 (neural networks) is supervised learning — it's the easiest setup to get concrete, checkable results from, which is why it dominates this course's early, foundational units. Recognizing which of these three setups a real problem actually is comes first, though: trying to force a clustering problem into a supervised mold, or vice versa, is a common and avoidable mistake.
