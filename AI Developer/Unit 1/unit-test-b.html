1. A recommendation engine chooses which product to show next using thousands of if/then store rules a merchandising team wrote by hand, with no data-driven learning involved. Which of the following is true?

Hand-written if/then rules, never learned from data, is AI with zero learning involved — the exact same situation as the rule-based spam filter.

2. A translation tool improves its word choices over time by studying millions of human-translated sentence pairs, rather than following grammar rules a person typed in. This is best described as:

Studying data to find its own patterns, rather than following a person's hand-typed rules, is exactly what makes a system machine learning.

3. A speech-to-text system is a many-layered network that turns raw audio directly into text, without a person first extracting hand-picked features like pitch or volume. This makes it:

Many layers plus learning directly from raw input is deep learning — and deep learning is always machine learning too, so the last option's "not machine learning" claim is the trap.

4. A spam filter flags emails using a decision tree trained by fitting on thousands of previously labeled emails (spam or not), rather than a person writing "if contains free money then spam" by hand. Answer both parts:

(a) Is this filter machine learning?

(b) Fill in the blank: if this same filter instead used a many-layered network learning straight from raw email text, it would specifically become an example of ___ learning.

(a) Rules found by fitting on labeled data, not hand-written, is machine learning. (b) Swapping in a many-layered network learning from raw text pushes this one level further, into deep learning.

5. A dataset of past job applicants includes, for each one, whether they were actually hired. Answer both parts:

(a) Training a model to predict hiring outcome on this dataset is:

(b) Fill in the blank: the known hired/not-hired outcome attached to each applicant is this dataset's ___.

(a) A known correct outcome attached to every example is exactly what makes this supervised. (b) That known correct outcome is, by definition, the label.

6. An app groups songs into playlists by similarity using an algorithm that is never told which genre any song belongs to in advance. Answer both parts:

(a) Fill in the blank: because no correct genre is ever assigned in advance, grouping these songs is an example of ___ learning.

(b) What is this algorithm's actual job?

(a) No labels assigned in advance is the definition of unsupervised learning. (b) With no label to match, discovering structure in the data is the only job left.

7. Fill in the blank: A trading bot that receives a numeric gain or loss after every trade, and adjusts its strategy to earn more over time, is guided by a ___ signal.

A reward signal — not a label, not a discovered cluster — is what drives reinforcement learning's improvement over time.

8. A grocery chain both (1) clusters customers into shopper types with no label given, and (2) trains a self-checkout robot that gets a positive score for correctly bagging an item and a negative score for dropping it. Answer both parts:

(a) What key difference separates the robot's learning from the clustering?

(b) Fill in the blank: unlike clustering, the robot learns a ___ through trial and error guided by reward.

(a) Reward feedback tied to actions is the dividing line between reinforcement learning and label-free, reward-free clustering. (b) That reward feedback lets the robot learn a strategy over repeated trials.

9. A thermostat gradually adjusts how early it starts heating a house by earning a better comfort score when residents don't have to manually override the temperature, and a worse score when they do — with no dataset of "correct" heating schedules ever provided. Which learning paradigm is this?

A comfort score that rewards or penalizes outcomes, with no labeled correct schedule anywhere, is reinforcement learning's defining setup.

10. A dataset of used cars lists mileage, age, and engine size for 500 vehicles, with no sale price or any other outcome column recorded. Answer both parts:

(a) Could this dataset be used directly for supervised learning to predict resale value?

(b) Fill in the blank: because no known correct output is recorded for any row, this dataset is currently ___.

(a) No recorded correct output means no target to train against for supervised learning. (b) A dataset missing any attached correct output is, by definition, unlabeled.
