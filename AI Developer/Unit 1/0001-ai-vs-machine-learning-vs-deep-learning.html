AI vs. Machine Learning vs. Deep Learning

Three words used almost interchangeably in headlines, and precisely nested inside each other in practice.

Lesson 2 → Contents Glossary →

A note on format Computer Programming 1 and 2 taught every concept in Python, Java, JavaScript, and C++ side by side. This course doesn't — it's Python-primary throughout, deliberately. Nearly every real-world AI/ML tool (scikit-learn, PyTorch, TensorFlow, Hugging Face, the major LLM APIs) is Python-first, and switching languages for every example would trade real fluency with the field's actual tools for a consistency this particular course doesn't need.

Artificial intelligence (AI) is the broad goal: getting a computer to do something that seems to require intelligence. That goal has been pursued for decades, mostly with hand-written rules — a chess program that follows programmer-written heuristics, a tax form that follows a hard-coded decision tree, are both AI with zero learning involved.

Machine learning (ML) is a specific way of reaching that goal: instead of a person writing the rules, the program learns them from data. Deep learning (DL) is a specific way of doing machine learning: using a neural network with many layers, often learning directly from raw data (pixels, audio, raw text) rather than features a person extracted by hand first. Each term is a subset of the one before it — every deep learning system is machine learning, and every machine learning system is AI, but the reverse isn't true.

The same task, solved two ways, makes the boundary concrete:

Rule-based spam filter — AI, but not machine learning 
def is_spam_rule_based(email_text):
    return "free money" in email_text.lower()

# A person wrote this exact rule. It never changes unless a person edits it.
Learned spam filter — machine learning 
from sklearn.linear_model import LogisticRegression

# X_train: features already extracted from each email (Unit 2 covers this step)
# y_train: 1 if that email was labeled spam, 0 if not
model = LogisticRegression()
model.fit(X_train, y_train)

model.predict(X_new)   # the model decided this itself, from examples

Nobody wrote "free money" into the second version anywhere. The LogisticRegression model found its own rule by looking at thousands of labeled examples — that's what makes it machine learning rather than a rule someone typed in. If X_train were raw email text instead of features someone extracted by hand, and the model were a many-layered neural network instead of logistic regression, that would push this same example one level further in, into deep learning — Unit 4 builds exactly that kind of network from scratch.

Definition AI is any system that performs a task that seems to require intelligence, however it's built. Machine learning is AI built by learning from data instead of hand-written rules. Deep learning is machine learning using many-layered neural networks, often learning directly from raw data.
Why it matters here A huge amount of public confusion — "is ChatGPT the same thing as the AI in my thermostat?" — comes from treating these three words as synonyms. They're not options on the same shelf; they're nested circles, and knowing which circle a given real-world tool actually sits in is the first real skill this course builds.
