1. A CNN's first convolutional layer has 8 filters, each 3×3. As one of these filters slides across an input image, what does it compute at each position it visits?

The same filter weights are reused at every position — the exact perceptron math from Unit 4, applied repeatedly across the image.

2. A feature map is passed through a pooling layer, and its width and height both shrink afterward. What did the pooling layer do to produce this smaller feature map?

Pooling keeps the strongest signal in each small region and discards the rest, shrinking the feature map's size.

3. Partway through processing a long sequence, an RNN's hidden state is inspected. What does it contain at that point?

The hidden state is a running summary updated at every step, not a snapshot of just the latest element.

4. Fill in the blank: unlike a plain RNN, an LSTM adds learned ___ that explicitly control what its state keeps, forgets, and outputs at each step.

Gates are the learned mechanisms that give an LSTM this explicit control over its state.

5. Fill in the blank: in self-attention, the vector a token produces to advertise what it offers to other tokens looking for it is called its ___.

The key is what a token offers to others that are looking, as opposed to the query (what it's looking for) or the value (what it contributes).

6. Two designs are compared for processing a 100×100 image: Design X assigns every pixel-neuron pair its own independent weight; Design Y slides one small filter with shared weights across the whole image. Answer both parts:

(a) What is Design Y's approach — reusing the same filter weights at every position — called?

(b) Which design needs dramatically fewer total weights?

(a) Reusing one filter's weights at every position is weight sharing. (b) Design Y (weight sharing) needs far fewer total weights than assigning an independent weight per pixel.

7. A plain RNN is trained on a 200-step sequence. During backpropagation, the gradient must flow backward through all 200 steps. Answer both parts:

(a) Fill in the blank: a gradient that shrinks toward zero the further back it has to travel through many steps is called a ___ gradient.

(b) What is the practical consequence of this shrinking gradient for the network's training?

(a) A gradient shrinking toward zero over many steps is a vanishing gradient. (b) In practice this means the network effectively forgets context from far earlier in the sequence.

8. In a 50-token sequence, a Transformer's attention layer lets token 2 and token 49 relate to each other directly. Answer both parts:

(a) Fill in the blank: the mechanism that lets a model relate any two sequence positions directly, regardless of distance, is called ___.

(b) Compared to a step-by-step RNN, how does attention relate these two distant tokens?

(a) Attention is the mechanism that relates any two positions directly. (b) It does so in one step, with no sequential dependency between the two tokens.

9. Computing Q @ K.T followed by softmax and weights @ V processes an entire sequence in a small number of matrix multiplications. Answer both parts:

(a) What does this make possible that a step-by-step RNN cannot do?

(b) Fill in the blank: attention where every position in a sequence attends to every other position in that same sequence is called ___-attention.

(a) Being a matrix multiplication over the whole sequence at once is what lets attention run in parallel. (b) That every-position-to-every-position relating is exactly self-attention.

10. Three architectures from this unit each specialize the same underlying training loop for a different kind of data. Answer both parts:

(a) Which architecture is built for sequence data and carries a hidden state forward step by step?

(b) Which architecture solves long-range dependency problems by removing the step-by-step bottleneck entirely, rather than adding gates to manage it?

(a) An RNN carries a hidden state forward one step at a time to process sequences. (b) A Transformer's self-attention removes the sequential bottleneck entirely, unlike an LSTM's gates which only manage it.
