Convolutional Neural Networks

Feeding a raw image into Unit 4's fully-connected MLP would need one weight per pixel per neuron. CNNs exist because that's both wasteful and the wrong shape for the problem.

Lesson 16 → Contents Glossary →

A convolutional neural network (CNN) is built for image-shaped data. Instead of one weight per pixel, it slides a small filter (or kernel) across the image, computing the same small weighted sum at every position — the exact math from Lesson 11's perceptron, just applied repeatedly across a grid instead of once.

Python — PyTorch 
import torch
import torch.nn as nn

class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels=1, out_channels=8, kernel_size=3)
        self.pool = nn.MaxPool2d(kernel_size=2)
        self.fc = nn.Linear(8 * 13 * 13, 10)   # after conv + pool, flatten to a normal layer

    def forward(self, x):
        x = self.pool(torch.relu(self.conv1(x)))   # slide filters, then downsample
        x = x.view(x.size(0), -1)                    # flatten before the final layer
        return self.fc(x)

Each of the 8 filters in conv1 is a small grid of weights, reused at every position across the input image — this weight sharing is what makes a CNN dramatically smaller than a fully-connected layer over raw pixels, and it also means a filter that learns to detect, say, a vertical edge can detect that edge anywhere in the image, not just in one fixed spot. Sliding a filter across the image produces a feature map: a grid that lights up wherever that filter's pattern appears. Pooling then shrinks that feature map, keeping the strongest signal in each small region and discarding the rest, which both reduces the data size and makes the network less sensitive to a feature's exact pixel position.

Definition A convolutional neural network (CNN) processes image-shaped data using filters shared across positions. A filter (kernel) is a small set of weights slid across the input to produce a feature map. Pooling downsamples a feature map, keeping the strongest signal in each region.
Why it matters here This is the first of three specialized architectures in this unit — each one takes the forward pass, loss, and backpropagation from Unit 4 completely unchanged, and simply reshapes what the layers themselves look like to suit a specific kind of data. Check your recall

1. What does a convolutional filter do as it slides across an image?

The filter's weights are reused at every position — that reuse is exactly what weight sharing means.

2. Why do CNNs need far fewer weights than a fully-connected layer over raw pixels?

Weight sharing means one small filter, not one weight per pixel, drives the entire feature map.

3. What does pooling do to a feature map?

MaxPool2d above keeps the maximum value in each small region, shrinking the feature map.
