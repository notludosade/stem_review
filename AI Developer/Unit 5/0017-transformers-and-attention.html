Transformers and Attention

An LSTM's gates help it remember further back — but it still has to process a sequence one step at a time. Attention removes that restriction entirely.

Lesson 18 → Contents Glossary →

Attention lets a model directly relate any two positions in a sequence, regardless of how far apart they are, without passing information step by step through everything in between. A Transformer is a network built almost entirely out of this one mechanism, called self-attention when every position relates to every other position in the same sequence.

Python — NumPy (simplified scaled dot-product attention) 
import numpy as np

def softmax(x):
    e = np.exp(x - np.max(x, axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)

# 3 tokens, each represented by a 4-number vector
Q = np.random.rand(3, 4)   # query: what each token is looking for
K = np.random.rand(3, 4)   # key: what each token offers
V = np.random.rand(3, 4)   # value: what each token actually contributes

scores = Q @ K.T / np.sqrt(4)        # how relevant every token is to every other, all at once
weights = softmax(scores)             # normalized into per-token weights summing to 1
output = weights @ V                  # each token's new representation: a weighted blend of every value

Every token produces three vectors: a query (what it's looking for), a key (what it offers to others looking), and a value (what it actually contributes once matched). Q @ K.T compares every query against every key in one matrix multiplication, producing a relevance score between every pair of tokens simultaneously — token 3 can attend directly to token 1 exactly as easily as to token 2, with no sequential dependency at all. softmax turns each token's raw scores into proper weights, and the final output blends every token's value according to those weights. Because this whole computation is a handful of matrix multiplications over the entire sequence at once, it runs in parallel — the sequential, one-step-at-a-time bottleneck that limits an RNN or LSTM simply isn't there.

Definition Attention lets a model relate any two sequence positions directly, weighted by learned relevance. Self-attention is attention where every position in a sequence attends to every other position in that same sequence. A Transformer is a network built primarily from self-attention layers.
Why it matters here This closes Unit 5. Attention solves the same long-range dependency problem that motivated Lesson 16's LSTM gates, but by removing the sequential bottleneck entirely rather than managing it — that parallelism is a large part of why Transformers scale to the enormous models Unit 6 accesses through APIs rather than training from scratch.
