Backpropagation Intuition

Lesson 13's loop needs a gradient for every weight in every layer. Computing each one independently from scratch would be far too slow — backpropagation is the shortcut.

Lesson 15 → Contents Glossary →

A real network can have thousands of weights spread across many layers. Backpropagation computes the gradient for every one of them efficiently, by walking backward through the network — output layer first, then each earlier layer in turn — reusing work instead of repeating it.

Python — conceptual shape, not a full derivation 
# Forward pass (Lesson 12): compute predictions, left to right
hidden = sigmoid(x @ W1 + b1)
output = sigmoid(hidden @ W2 + b2)
loss_value = loss(output, true_label)

# Backward pass: walk in the opposite direction, right to left
output_gradient = loss_gradient(output, true_label)     # how loss reacts to the output
W2_gradient = hidden.T @ output_gradient                 # how loss reacts to W2

hidden_gradient = output_gradient @ W2.T                 # reuses output_gradient directly
W1_gradient = x.T @ (hidden_gradient * sigmoid_derivative(hidden))

Notice that hidden_gradient is built directly out of output_gradient, which was already computed one step earlier — nothing about the output layer gets recalculated. This chaining is the chain rule from calculus in action: the effect of an early weight on the final loss passes through every layer in between, and each layer's already-computed gradient becomes an ingredient in the previous layer's, rather than something to derive over again. That reuse is precisely why backpropagation scales to networks with millions of weights, where computing each gradient in isolation would be hopelessly slow.

Definition Backpropagation is the algorithm that computes the loss gradient for every weight in a network by walking backward from the output layer, reusing each layer's result in the one before it. The chain rule is the calculus principle that makes this reuse valid.
Why it matters here This closes Unit 4. The full training loop is now complete end to end: forward pass (Lesson 12) produces a prediction, loss (Lesson 13) measures how wrong it was, backpropagation computes every gradient, and gradient descent (Lesson 13) uses them to update every weight. Unit 5's CNNs, RNNs, and Transformers change only the architecture that the forward pass runs through — this exact training loop underneath stays unchanged.

Check your recall

1. What problem does backpropagation solve?

Every weight, in every layer, needs a gradient — backpropagation is how all of them get computed efficiently.

2. What direction does backpropagation move through the network's layers?

output_gradient is computed first, and hidden_gradient is derived from it afterward — output to input, in that order.

3. Why is backpropagation efficient compared to computing each weight's gradient from scratch independently?

hidden_gradient is built directly from output_gradient rather than recomputed from scratch — that reuse is the efficiency gain.
