1. A perceptron has inputs [1, 4], weights [−0.5, 0.25], and bias 0.5, using a step activation (output 1 if the weighted sum is greater than 0, otherwise output 0). What is the perceptron's output?

weighted_sum = (1)(−0.5) + (4)(0.25) + 0.5 = −0.5 + 1 + 0.5 = 1, which is greater than 0, so the step activation outputs 1.

2. Fill in the blank: in a perceptron, the raw weighted sum plus bias is passed through this component to produce the final output — a step function and a sigmoid are two examples of it, called the ___ function.

The activation function is what turns the raw weighted sum into the neuron's actual output.

3. Two perceptrons have identical weights and receive identical inputs, but perceptron X has a bias of 2 and perceptron Y has a bias of −2. Why can they still produce different outputs?

Since bias is added regardless of the inputs, two different bias values shift the weighted sum by different amounts, which can flip whether the step activation fires.

4. Consider a network with two hidden layers between the input and output layer. During the forward pass, whose output is computed immediately before the output layer's?

A forward pass moves layer by layer in sequence, so the last hidden layer's output is exactly what feeds the output layer.

5. A network predicts 0.2 for an example whose true label is 0. Using the squared-error loss (predicted − true)², what is the loss for this example?

(0.2 − 0)² = 0.04.

6. A perceptron using a sigmoid activation computes exactly what logistic regression computes. Answer both parts:

(a) Fill in the blank: replacing a step activation with a ___ activation is precisely what turns a perceptron into logistic regression.

(b) Before that swap, what kind of output does the step-activation perceptron produce?

(a) Swapping the step activation for a sigmoid is what makes the perceptron equivalent to logistic regression. (b) A step activation only ever fires (1) or stays silent (0) — no in-between values.

7. Suppose a hidden layer is added between a network's input and output layers. Answer both parts:

(a) Fill in the blank: this new layer sits between the input and output layers and is called the ___ layer.

(b) What does this layer let the network do that it couldn't do without it?

(a) A layer between input and output that learns a new representation is the hidden layer. (b) That new, learned representation is exactly what lets an MLP separate patterns a lone perceptron cannot.

8. For a loss function loss(w) = (w − 2)², the gradient is gradient(w) = 2(w − 2). At w = 5, answer both parts:

(a) What is the value of the gradient at w = 5?

(b) Fill in the blank: since the gradient at w = 5 is positive, and gradient descent steps opposite the gradient, the next value of w will ___ (increase or decrease).

(a) gradient(5) = 2(5 − 2) = 2(3) = 6. (b) w_new = w − learning_rate × 6, so w decreases — moving toward the minimum at w = 2.

9. Two training runs use the exact same network and data, but different learning rates. Answer both parts:

(a) Run A uses an extremely small learning rate. What is the most likely result?

(b) Run B uses an extremely large learning rate instead. What is the most likely result?

(a) Tiny steps make very slow progress toward the minimum. (b) Oversized steps can jump straight past the minimum and bounce around it instead of settling.

10. A network's backward pass computes output_gradient first, then uses it directly to build hidden_gradient for the layer before it. Answer both parts:

(a) What does reusing output_gradient this way demonstrate?

(b) Fill in the blank: this reuse is mathematically valid because of the ___ rule from calculus, where an early layer's effect on the loss passes through every layer in between.

(a) Reusing an already-computed gradient instead of deriving it from scratch is exactly what makes backpropagation scale. (b) The chain rule is the calculus principle that makes this reuse valid.
