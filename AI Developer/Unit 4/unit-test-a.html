1. A perceptron has inputs [3, −2], weights [0.5, 1.5], and bias −1, using a step activation (output 1 if the weighted sum is greater than 0, otherwise output 0). What is the perceptron's output?

weighted_sum = (3)(0.5) + (−2)(1.5) + (−1) = 1.5 − 3 − 1 = −2.5, which is not greater than 0, so the step activation outputs 0.

2. Fill in the blank: the function applied to a perceptron's weighted sum to produce its final output — a step function or a sigmoid, for example — is called the ___ function.

The activation function converts the raw weighted sum into the neuron's actual output.

3. A perceptron has weights [1, 1] and receives inputs [0, 0], using a step activation. Since the weighted sum here is just the bias, which term is the only one that can make this perceptron fire?

With all inputs at zero, weighted_sum = 0·1 + 0·1 + bias = bias — only the bias term is independent of the (zero) inputs.

4. In a multi-layer perceptron with one hidden layer, what is the correct order of computation during a forward pass?

A forward pass is data flowing through every layer in sequence — input first, then each hidden layer, then the output.

5. A network predicts 0.7 for an example whose true label is 1. Using the squared-error loss (predicted − true)², what is the loss for this example?

(0.7 − 1)² = (−0.3)² = 0.09.

6. A perceptron uses a step activation function. Answer both parts about what changes if that's swapped for a sigmoid:

(a) What does this perceptron become mathematically equivalent to, once the sigmoid replaces the step function?

(b) Fill in the blank: before the swap, this perceptron used a ___ activation function, which only ever outputs 0 or 1.

(a) Swapping the step activation for a sigmoid makes the perceptron compute exactly what logistic regression computes. (b) The original hard 0-or-1 activation was a step function.

7. A network connects its 4 inputs directly to a single output neuron, with no hidden layer in between. Answer both parts:

(a) What capability does this network lack compared to one with a hidden layer?

(b) Fill in the blank: adding a ___ layer between the input and output would let the network learn richer, non-linear representations.

(a) Without a hidden layer, the network can only draw a single straight-line boundary, just like one lone perceptron. (b) A hidden layer transforms the input into a new, learned representation before the output layer sees it.

8. For a loss function loss(w) = (w − 4)², the gradient is gradient(w) = 2(w − 4). At w = 1, answer both parts:

(a) What is the value of the gradient at w = 1?

(b) Fill in the blank: since gradient descent updates w by subtracting the learning rate times the gradient, and the gradient here is negative, the next value of w will ___ (increase or decrease).

(a) gradient(1) = 2(1 − 4) = 2(−3) = −6. (b) w_new = w − learning_rate × (−6) = w + 6·learning_rate, so w increases — moving toward the minimum at w = 4.

9. Gradient descent uses a fixed learning rate for every step. Answer both parts about what can go wrong at the extremes:

(a) What tends to happen if the learning rate is set far too large?

(b) What tends to happen if the learning rate is set far too small?

(a) Too-large steps can jump past the minimum instead of approaching it smoothly. (b) Too-small steps make each update tiny, so training progresses very slowly.

10. A network has an input layer, one hidden layer, and an output layer. During backpropagation, answer both parts:

(a) In what order are the gradients computed?

(b) Fill in the blank: reusing each layer's already-computed gradient as an ingredient in the previous layer's gradient is valid because of the ___ rule from calculus.

(a) Backpropagation walks backward, output layer first, reusing work instead of repeating it. (b) The chain rule from calculus is exactly what makes that reuse mathematically valid.
