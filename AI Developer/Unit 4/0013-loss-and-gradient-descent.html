Loss and Gradient Descent

Lesson 7 said fit() "searches for the coefficients that minimize the loss" without saying how. This is how.

Lesson 14 → Contents Glossary →

After a forward pass produces a prediction, the loss measures how wrong it was compared to the true label. Gradient descent is the algorithm that uses that loss to adjust every weight, a small step at a time, in whichever direction actually reduces it.

Python — a minimal example 
def loss(w):
    return (w - 3) ** 2       # some loss function, minimized when w == 3

def gradient(w):
    return 2 * (w - 3)        # the slope of loss at this w

w = 0.0
learning_rate = 0.1

for step in range(20):
    grad = gradient(w)
    w = w - learning_rate * grad   # step opposite the slope

print(w)   # converges toward 3.0

The gradient is the slope of the loss with respect to a weight — it says which direction increases the loss, and by how much. Gradient descent always steps in the opposite direction, since the goal is to decrease loss, not increase it. The learning rate controls how big each step is: too small, and training crawls; too large, and the weight can overshoot the minimum entirely and bounce around without ever settling. In a real network, this same idea runs for every single weight across every layer simultaneously, using the exact mean-squared-error-style loss from Lesson 7 or a classification-suited loss for a network like Lesson 8's logistic regression — computing all of those gradients at once, efficiently, is exactly what Lesson 14 covers next.

Definition Gradient descent repeatedly adjusts weights in the direction that reduces loss. The gradient is the slope of the loss with respect to a weight. The learning rate controls how large each adjustment step is.
Why it matters here This is the literal mechanism behind "fit() searches for the coefficients that minimize the loss," stated back in Lesson 7 without explanation — every model in this course that learns from data, classical or neural, is running some version of this loop. Lesson 14 covers the one remaining piece: how a network with thousands of weights gets a gradient for every single one of them without thousands of separate calculations.

Check your recall

1. What does the gradient represent?

gradient(w) above computes exactly this slope at the current value of w.

2. Why does gradient descent step opposite the gradient's direction?

w = w - learning_rate * grad subtracts the gradient, moving toward lower loss.

3. What can happen if the learning rate is set too large?

Steps that are too large can jump past the minimum instead of approaching it smoothly.
