The Perceptron

Every neural network in this course, no matter how large, is built entirely out of copies of one small idea.

Lesson 12 → Contents Glossary →

A perceptron is a single artificial neuron. It takes some inputs, multiplies each by its own weight, adds a bias, and passes the result through an activation function to produce one output. That's the entire structure — nothing hidden.

Python — NumPy 
import numpy as np

def perceptron_forward(inputs, weights, bias):
    weighted_sum = np.dot(inputs, weights) + bias
    return 1 if weighted_sum > 0 else 0   # step activation: fire, or don't

inputs = np.array([1.0, 0.5])
weights = np.array([0.8, -0.3])
bias = 0.1

output = perceptron_forward(inputs, weights, bias)
print(output)   # 1 — weighted_sum here is 0.75, above 0

np.dot(inputs, weights) is the weighted sum — exactly the same computation Lesson 7's linear regression and Lesson 8's logistic regression both used, just given a new name and a new picture: an input layer feeding into a single unit. The bias is a number added independent of any input, letting the neuron shift its decision boundary rather than being forced to fire only when the weighted sum is exactly balanced around zero. The activation function is what turns that raw sum into the actual output — here, a simple step: fire (1) if positive, stay silent (0) otherwise. Swap that step for a sigmoid, and this perceptron computes exactly what Lesson 8's logistic regression computes.

Definition A perceptron is a single artificial neuron that computes a weighted sum of inputs plus a bias, then applies an activation function. A weight scales one input's contribution. A bias is an input-independent offset. An activation function converts the weighted sum into the neuron's output.
Why it matters here A perceptron with a sigmoid activation is logistic regression, restated in neural-network vocabulary — nothing new is being learned here mathematically, only the building block that Lesson 12 wires together, by the hundreds or thousands, into an actual neural network.
