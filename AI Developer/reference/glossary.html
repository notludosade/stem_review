What AI/ML Actually Is

Artificial intelligence (AI)

Any system that performs tasks normally requiring human intelligence, including plain rule-based code with no learning involved.

Machine learning (ML)

A subset of AI where a model learns its behavior from data rather than following rules written by hand.

Deep learning (DL)

A subset of ML using neural networks with many layers, capable of learning very complex patterns directly from raw data.

Supervised learning

Learning from labeled input/output pairs, where every training example has a known correct answer attached.

Unsupervised learning

Finding structure in unlabeled data, with no correct answer given for any example.

Reinforcement learning

Learning a strategy from reward feedback on actions taken in an environment, with no labels at all.

Data — The Fuel of AI

Dataset

A collection of examples used to train or evaluate a model, usually one row per example.

Feature

An input column a model is given, conventionally gathered together and called X.

Label

The correct output value paired with an example, conventionally called y — present in supervised learning, absent in unsupervised learning.

Missing value

A gap in a dataset where a measurement was never recorded.

Outlier

A value extreme enough to likely be an error or a genuinely unusual case, worth a second look rather than automatic trust.

Normalization

Rescaling features onto comparable ranges so no single feature dominates purely due to its raw scale.

Training set

The data a model learns from directly — every weight, rule, or split it produces comes from studying these examples.

Validation set

Data checked repeatedly during development, used to tune choices and compare candidate models.

Test set

Data held out and checked exactly once, for a final, honest measure of performance uninfluenced by any development decision.

Overfitting

A large gap between a much better training score and a worse validation score, from memorizing training data instead of the real pattern.

Underfitting

A poor score on both training and validation data, from a model too simple to capture the pattern at all.

Generalization

Performing well on new, unseen data because the real underlying pattern was learned, rather than specific examples memorized.

Classical Machine Learning

Linear regression

A model that predicts a continuous numeric value as a weighted sum of input features.

Coefficient

The weight applied to one feature, showing how much the prediction changes for a one-unit increase in that feature.

Loss function

A measure of how far a model's predictions are from the true values — mean squared error is one common choice.

Logistic regression

A classification model that produces a probability via a sigmoid function applied to a weighted sum of features.

Sigmoid function

A function that maps any real number to a value strictly between 0 and 1.

Classification

Predicting a category rather than a continuous number.

Decision tree

A model that classifies by branching through a sequence of feature-based questions to a final answer.

Node / split

A node is one question in a decision tree; a split is the specific feature and threshold it tests.

Accuracy

The percent of all predictions, across every class, that were correct.

Precision

Of everything predicted positive, the fraction that truly was positive.

Recall

Of everything truly positive, the fraction the model actually caught.

Neural Network Fundamentals

Perceptron

A single artificial neuron that computes a weighted sum of inputs plus a bias, then applies an activation function.

Bias

An input-independent offset added to a neuron's weighted sum.

Activation function

The function that converts a neuron's weighted sum into its output, such as a step function or sigmoid.

Multi-layer perceptron (MLP)

A network of perceptrons arranged in an input layer, one or more hidden layers, and an output layer.

Hidden layer

A layer between the input and output that transforms data into a new, learned representation.

Forward pass

Data flowing through every layer of a network in sequence to produce a final output.

Gradient descent

An algorithm that repeatedly adjusts weights in the direction that reduces loss.

Gradient

The slope of the loss with respect to a weight, indicating which direction increases it and by how much.

Learning rate

A value controlling how large each gradient descent step is.

Backpropagation

The algorithm that computes the loss gradient for every weight in a network by walking backward from the output layer.

Chain rule

The calculus principle that lets each layer's gradient reuse the next layer's already-computed result.

Deep Learning Architectures

Convolutional neural network (CNN)

A network for image-shaped data that slides shared filters across the input instead of using one weight per pixel.

Filter (kernel)

A small set of weights slid across an input to detect a pattern, shared across every position.

Feature map

The grid produced by sliding a filter across an input, lighting up wherever the filter's pattern appears.

Pooling

Downsampling a feature map by keeping the strongest signal in each region.

Recurrent neural network (RNN)

A network that processes a sequence step by step, carrying a hidden state forward.

Hidden state

A running summary an RNN carries forward across the steps of a sequence.

Vanishing gradient

A gradient that shrinks toward zero over many steps, weakening a network's ability to learn long-range dependencies.

LSTM

A recurrent network variant that uses learned gates to control what its state keeps, forgets, or outputs.

Attention

A mechanism letting a model relate any two sequence positions directly, weighted by learned relevance.

Self-attention

Attention where every position in a sequence attends to every other position in that same sequence.

Transformer

A network built primarily from self-attention layers, processed in parallel rather than step by step.

Working with Pretrained Models & APIs

Inference

Generating output from an already-trained model, with no further training taking place.

Role

A tag on each message in an API conversation — system, user, or assistant — shaping how the model interprets it.

Embedding

A vector representing a piece of text's meaning, positioned so texts with similar meaning produce similar vectors.

Cosine similarity

A measure of how closely two vectors point in the same direction, used to compare embeddings.

Semantic search

Ranking results by embedding similarity rather than exact keyword matches.

Prompt engineering

Designing the input text sent to a model to reliably shape its output, without changing the model itself.

Few-shot prompting

Including worked examples in a prompt before the real request, to demonstrate the expected pattern.

Temperature

A parameter controlling how much randomness a model uses when generating each word.

Fine-tuning

Continuing to train a pretrained model on new labeled examples, updating its weights.

RAG (Retrieval-Augmented Generation)

Retrieving relevant text via semantic search and inserting it into the prompt as context, with no weight changes.

Building a Real AI Application

Baseline

The simplest possible working solution to a problem, built first as a benchmark for anything more complex.

Structured output

A model response shaped as data, such as JSON, instead of free-form prose.

Fallback

A safe default behavior used when the primary logic fails or returns something unexpected.

API endpoint

A specific URL a web application listens on to receive a request and return a response.

Input validation

Checking that incoming data matches an expected shape before it's used.

Deploying & Maintaining AI in Production

Latency

The time between sending a request and receiving a response.

Cache

Stored results from a previous request, so an identical future request can be answered instantly.

Monitoring

Continuously logging a deployed system's inputs, outputs, and performance over time.

Drift

A gradual mismatch between what a model learned and the real-world data it currently encounters.

Version pinning

Using an exact, fixed model or prompt version instead of one that can change silently over time.

Rollback

Reverting to a previous known-good version once a new one is found to have regressed.

Responsible AI in the Real World

Algorithmic bias

A model's predictions systematically disadvantaging a group of people, typically from training data reflecting past unfair treatment.

Hallucination

A confident, fluent, but false statement generated by a language model.

Prompt injection

Text hidden in external content, written to hijack a model's instructions rather than answer the user's actual question.

Human-in-the-loop

A system design where a person reviews or confirms a model's output before it takes effect, rather than the system acting fully automatically.
