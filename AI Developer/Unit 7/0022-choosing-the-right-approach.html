Choosing the Right Approach

Six units gave you rule-based code, classical ML, neural networks, and pretrained APIs. A real project starts by picking the cheapest one that actually solves the problem.

Lesson 23 → Contents Glossary →

Lesson 1 opened this course by contrasting rule-based code with machine learning. Now that Unit 6 has added a third option — calling a pretrained API — a real project needs an actual decision, not just awareness that the options exist. The strongest starting habit: build the simplest possible baseline first, even a plain rule-based one, and only reach for something more complex once that baseline demonstrably falls short.

Python — a decision helper, not a formula 
def choose_approach(rules_would_work, have_labeled_data, task_is_common_and_general):
    if rules_would_work:
        return "plain rule-based code — no model needed at all"
    if task_is_common_and_general:
        return "pretrained API (Unit 6) — likely already solves this well"
    if have_labeled_data:
        return "classical ML or a trained neural net (Units 3-5)"
    return "collect labeled data first, or fall back to a rule-based baseline"

print(choose_approach(rules_would_work=True, have_labeled_data=False, task_is_common_and_general=False))
print(choose_approach(rules_would_work=False, have_labeled_data=False, task_is_common_and_general=True))

This isn't a formula to apply blindly — it's a reminder of the order to ask questions in. If a handful of if statements would actually classify the input correctly, Lesson 1's rule-based code is faster to build, cheaper to run, and far easier to debug than any model. If the task is common and general enough — summarizing text, answering general questions, drafting an email — a pretrained API from Unit 6 has almost certainly already learned it, and training your own model would just be re-deriving what already exists. Training something yourself, per Units 3 through 5, only earns its cost when the task is specific to your own data and no existing option already handles it.

Definition A baseline is the simplest possible working solution to a problem, built first so every more complex approach has something concrete to be measured against.
Why it matters here Every technique from Units 1 through 6 is a tool, not a mandate — the skill this unit builds is choosing the right one for a specific problem, not reaching for the most sophisticated one available. Lesson 23 picks one concrete problem and actually builds it, using this exact reasoning to justify the approach chosen.
