The Derivative as a Rigorous Limit

The difference quotient, finally built on Unit 4's epsilon-delta functional limit instead of an intuitive "instantaneous rate of change."

← Unit 4, Lesson 24 Lesson 26 → Contents Glossary →

AP Calc BC defined the derivative as the limit of a difference quotient, using dynamic "h approaches 0" language. This lesson restates that definition using Unit 4, Lesson 19's epsilon-delta functional limit exactly as written — no new machinery, only a precise foundation under a formula already familiar.

Definition — Derivative Let f be defined on an interval containing a. f is differentiable at a if the limit f′(a) = limx→a (f(x) − f(a)) / (x − a) exists (as a functional limit, Unit 4 Lesson 19). If it exists, f′(a) denotes its value.
Why this is the same functional limit from Unit 4, applied to a specific expression Nothing new is being defined here — g(x) = (f(x) − f(a))/(x − a) is simply some function of x (undefined at x = a itself, which is fine, since Lesson 19's functional limit never requires the function be defined at the limit point), and f′(a) is exactly limx→a g(x) in the ordinary sense already built.

Worked example: proving a derivative directly from the definition

Worked Example Prove f(x) = x² is differentiable at a, with f′(a) = 2a. Scratch work: (f(x) − f(a))/(x − a) = (x² − a²)/(x − a) = (x−a)(x+a)/(x−a) = x + a for x ≠ a. So the limit as x → a of this simplified expression is a + a = 2a — an epsilon-delta proof exactly like Lesson 19's worked example, applied to the function x + a. Proof: Let ε > 0, choose δ = ε. For 0 < |x − a| < δ: |(f(x)−f(a))/(x−a) − 2a| = |(x+a) − 2a| = |x − a| < δ = ε. So f′(a) = 2a. ∎

Local linear approximation, restated precisely

Why AP Calc BC's "zoom in and it looks like a line" becomes precise here Differentiability at a is equivalent to the existence of a linear function L(x) = f(a) + f′(a)(x − a) such that limx→a (f(x) − L(x))/(x − a) = 0 — that is, the error in approximating f by its tangent line shrinks faster than (x − a) itself does. This is the exact rigorous content behind "the tangent line is the best linear approximation," a claim AP Calc BC used constantly but never proved.

1. The derivative f′(a) is defined as which kind of limit?

The derivative is defined as an ordinary functional limit (Unit 4), just applied to the specific expression (f(x)−f(a))/(x−a).

2. Why is it acceptable that the difference quotient (f(x) − f(a))/(x − a) is undefined at x = a itself?

Lesson 19's 0 < |x−a| clause is exactly what makes this work — the limit only cares about x near a, never at a.

3. What does it mean for L(x) = f(a) + f′(a)(x−a) to be the "best" linear approximation to f near a?

This limit condition is the rigorous meaning behind "the tangent line is the best linear approximation," a fact AP Calc BC used without proof.
