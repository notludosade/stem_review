Applications of the Mean Value Theorem

The closing lesson of Unit 5: proving, at last, why a positive derivative actually implies an increasing function.

← Lesson 28 Unit 6, Lesson 30 → Contents Glossary →

AP Calc BC used "f′ > 0 implies f increasing" to justify entire curve-sketching and optimization units, always as an appeal to intuition. This closing lesson of Unit 5 proves it directly from the Mean Value Theorem — along with two other facts taken for granted throughout that course.

Sign of the derivative controls monotonicity

Theorem Let f be continuous on [a, b] and differentiable on (a, b). If f′(x) > 0 for all x ∈ (a, b), then f is strictly increasing on [a, b].
Proof Let x₁ < x₂ in [a, b]. By the Mean Value Theorem applied to f on [x₁, x₂] (a valid sub-interval, since f is continuous on [a,b] and differentiable on (a,b)), there exists c ∈ (x₁, x₂) with f′(c) = (f(x₂) − f(x₁))/(x₂ − x₁). Since f′(c) > 0 by hypothesis and x₂ − x₁ > 0, it follows that f(x₂) − f(x₁) > 0, i.e. f(x₁) < f(x₂). So f is strictly increasing. ∎
Why this is the actual justification, not just intuition "Positive slope everywhere means the function climbs" sounds obvious, but the Mean Value Theorem is exactly what turns a purely local, pointwise statement (f′(x) > 0 at each individual x) into a global, comparative one (f(x₁) < f(x₂) for any two points, however far apart). Without MVT, there is no direct route from "the slope is positive at every point" to "the function's values are ordered" — the theorem is doing genuine work, not restating the hypothesis.

Zero derivative everywhere implies constant

Corollary If f is differentiable on an interval and f′(x) = 0 for every x, then f is constant.
Proof For any x₁ < x₂, MVT gives c with f′(c) = (f(x₂)−f(x₁))/(x₂−x₁) = 0, so f(x₂) = f(x₁). Since this holds for any two points, f is constant. ∎
Why this corollary matters for Unit 6 This corollary is exactly what will justify, in Unit 6, that any two antiderivatives of the same function differ by a constant — the fact underlying "+C" in every indefinite integral computed throughout AP Calc BC, and a fact that requires MVT specifically, not just the definition of the derivative.

Worked example

Worked Example Prove sin(x) ≤ x for all x ≥ 0. Let f(x) = x − sin(x); f(0) = 0, and f′(x) = 1 − cos(x) ≥ 0 for all x (since cos(x) ≤ 1 always). By the theorem's non-strict version (f′ ≥ 0 implies non-decreasing, proved identically with ≥ replacing >), f is non-decreasing on [0, ∞), so f(x) ≥ f(0) = 0 for all x ≥ 0, i.e. x ≥ sin(x).

1. What does the Mean Value Theorem contribute to the proof that f′ > 0 implies f is increasing?

MVT is the bridge from a local, pointwise derivative condition to a global, comparative statement about function values.

2. Why does f′(x) = 0 everywhere imply f is constant?

MVT forces every pair of function values to be equal once the derivative vanishes everywhere between them.

The non-negative derivative, via the non-strict monotonicity theorem, is exactly what forces f to stay at or above its starting value of 0.
