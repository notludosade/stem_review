Closed Sets, Closure, Interior, and Boundary

The rest of Real Analysis A's Unit 3 vocabulary — now defined for any topological space, with no sequences and no distance required.

← Lesson 2 Unit 2, Lesson 4 → Contents Glossary →

This closing lesson of Unit 1 rebuilds closed sets, closure, interior, and boundary — all four defined in Real Analysis A using sequences and limit points (Unit 3, Lessons 14–15) — using nothing but the open sets from Lessons 1–2. The definitions land in exactly the same place on ℝ, but now apply to any topological space, sequences or no sequences.

Closed sets

Definition — Closed Set A subset F of a topological space (X, τ) is closed if its complement X \ F is open (X \ F ∈ τ). This is verbatim Real Analysis A's Unit 3, Lesson 14 definition — now stated for any (X, τ), not only ℝ.
Theorem — Closure Properties of Closed Sets In any topological space: (i) ∅ and X are both closed; (ii) an arbitrary intersection of closed sets is closed; (iii) a finite union of closed sets is closed.
Proof (i) Complements of ∅ and X are X and ∅, both open by (T1). (ii) Let {Fα} be closed sets. By De Morgan, X \ ⋂Fα = ⋃(X \ Fα), a union of open sets, hence open by (T2) — so ⋂Fα is closed. (iii) For finitely many closed F₁, …, Fₙ, X \ ⋃Fᵢ = ⋂(X \ Fᵢ), a finite intersection of open sets, hence open by (T3) — so ⋃Fᵢ is closed. ∎
Why the quantifiers flip This is exactly De Morgan's Law converting the open-set axioms (T2: arbitrary unions, T3: finite intersections) into their closed-set mirror image (arbitrary intersections, finite unions) — the same flip Real Analysis A noted for ℝ specifically at the end of Unit 3, Lesson 14, now proved once and for all for every topological space.

Closure

Definition — Closure The closure of A ⊆ X, written Ā (or cl(A)), is the intersection of all closed sets containing A: Ā = ⋂{F : F closed, A ⊆ F}. By the theorem above, an arbitrary intersection of closed sets is closed, so Ā is itself closed — the smallest closed set containing A.
Example In (ℝ, τstd), the closure of (0, 1) is [0, 1]: every closed set containing (0, 1) must contain 0 and 1 too (any open set around 0 or 1 intersects (0, 1), so removing either point would leave a set whose complement fails to be open), and [0, 1] itself is closed with (0, 1) ⊆ [0, 1]. This matches Real Analysis A's sequential closure from Unit 3, Lesson 15 exactly — for subsets of ℝ, "smallest closed set containing A" and "A together with all its sequential limit points" always agree, since ℝ's ε-ball topology lets a shrinking sequence of balls around any boundary point produce a genuine convergent sequence.

Interior and boundary

Definition — Interior and Boundary The interior of A, written int(A) (or A°), is the union of all open sets contained in A — the largest open set inside A. The boundary of A, written ∂A, is ∂A = Ā \ int(A).
Example In (ℝ, τstd): int([0, 1]) = (0, 1) (the largest open set fitting inside [0, 1] excludes the two endpoints, which have no ε-ball around them staying inside [0, 1]). Since [0, 1] is already closed, cl([0, 1]) = [0, 1]. So ∂[0, 1] = [0, 1] \ (0, 1) = {0, 1} — the boundary is exactly the two endpoints, matching geometric intuition precisely.
Why closure and interior are dual constructions Closure is the smallest closed superset; interior is the largest open subset. In fact X \ cl(A) = int(X \ A) — taking the complement of the closure of A gives exactly the interior of A's complement, a direct consequence of De Morgan applied to the intersection/union definitions above. Closure and interior are the same idea, run in opposite directions.

Check your recall

No peeking back up — answer from memory first, then check.

1. How is a closed set F defined in a topological space (X, τ)?

Closed is defined entirely in terms of the complement being open — identical in spirit to Real Analysis A's definition, now stated for any topological space.

2. Why does De Morgan's Law flip "arbitrary unions, finite intersections" (the open-set axioms) into "arbitrary intersections, finite unions" for closed sets?

De Morgan's Law is the mechanical engine behind the flip — X \ ⋂F_α = ⋃(X \ F_α) and X \ ⋃F_i = ⋂(X \ F_i) directly convert one closure property into the other.

3. What is int([0, 1]) in (ℝ, τstd), and why?

Interior is the largest open set fitting inside [0, 1] — and any ε-ball around 0 or 1 spills outside [0, 1], so those two points can't belong to the interior.

4. Fill in the blank: the closure of A is the ___ closed set containing A — the intersection of every closed set that contains A.

Smallest is exactly right — intersecting more closed supersets can only shrink or keep the same result, never grow it.

5. Fill in the blank: for A = [0, 1] in (ℝ, τstd), the boundary ∂A = Ā \ int(A) equals ___.

Ā = [0,1] and int(A) = (0,1), so the boundary is exactly the two endpoints {0, 1}.
