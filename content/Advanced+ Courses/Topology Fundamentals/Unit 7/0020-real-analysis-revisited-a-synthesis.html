Real Analysis Revisited — A Synthesis

Four specific results from Real Analysis A, walked through one more time — each now visibly a single special case of a theorem this course proved in full generality.

← Lesson 19 Lesson 21 → Contents Glossary →

This course opened (Lesson 1) by promising that Real Analysis A's ε-ball open sets were a special case of something more general. Eighteen lessons later, that promise has been kept four separate times. This lesson doesn't introduce anything new — it lines the four correspondences up side by side, with a fresh example for each, so the generalization is visible all at once.

1. Open sets: from ε-balls to axioms

Fresh Example Let X = {red, green, blue} with τ = {∅, {red}, {red, green}, X}. Checking (T1)–(T3) directly (unions and intersections of these four sets never produce anything outside the list) confirms τ is a genuine topology — despite X having no numbers, no distance, and no possible ε-ball. Real Analysis A's Lesson 14 could never have stated this example; its definition of "open" was written in terms of a quantity, |x−y|, that doesn't exist here. This course's Lesson 1 definition applies without modification.

2. Continuity: from ε-δ to preimages

Fresh Example Let f(x) = 3x − 5. Real Analysis A would check continuity at, say, x = 4 by choosing δ = ε/3 (since |f(x) − f(4)| = 3|x − 4|). This course's Lesson 4 instead checks that f⁻¹((a,b)) = ((a+5)/3, (b+5)/3) is open for every open interval (a,b) — an open interval maps back to an open interval under this particular f, for every choice of (a,b), confirming continuity with no ε or δ named anywhere. Lesson 4's equivalence theorem guarantees both checks certify the exact same fact.

3. Connectedness and IVT: from intervals of ℝ to any connected space

Fresh Example Let g(x) = 2x³ − 5x − 1 on [1, 2]. g(1) = 2 − 5 − 1 = −4, g(2) = 16 − 10 − 1 = 5. Real Analysis A's Unit 4, Lesson 22 would locate a root of g in (1,2) via c = sup{x ∈ [1,2] : g(x) < 0}, then rule out g(c) > 0 and g(c) < 0 by hand using ε-δ continuity. This course's Lesson 9 instead observes [1,2] is connected (it's an interval), so g([1,2]) is connected (continuous image of connected), hence an interval (connected subsets of ℝ are intervals) — and since 0 lies between g(1) = −4 and g(2) = 5, it must lie in g([1,2]) too. Same root, same interval, a three-line proof built from general theorems instead of a bespoke supremum argument.

4. Compactness and EVT: from sequences to open covers

Fresh Example Let K = [−1, 3] and h(x) = −(x−1)² + 8. Real Analysis A's Unit 3, Lessons 16–17 would show K is compact by proving every sequence in K has a subsequence converging within K, then Unit 4, Lesson 23 would build a maximizing sequence xₙ with h(xₙ) → sup h(K) and extract a convergent subsequence. This course's Lesson 11 instead shows K compact directly from being closed and bounded (Heine-Borel via bisection), and Lesson 12 shows h(K) is compact (continuous image of compact), hence closed and bounded (Heine-Borel again), hence contains its own supremum (closed sets contain their limit points) — attained at x = 1, where h(1) = 8, with no sequence constructed at any point.
Why the pattern is always the same In every one of the four rows, Real Analysis A's proof depended on some structure specific to ℝ — a distance |x−y|, a supremum, a convergent subsequence. This course's version of each result instead depends only on open sets, preimages, and covers — structure that ℝ happens to have, but that plenty of other spaces (finite sets, quotient spaces, function spaces never discussed in this course) have too, without ever having a distance defined on them at all.

Check your recall

No peeking back up — answer from memory first, then check.

1. What made the topology example on X = {red, green, blue} impossible to state using Real Analysis A's original definition of open?

Without a distance function, "ε-ball" is meaningless — exactly the gap this course's axiomatic definition of topology closes.

2. In the g(x) = 2x³ − 5x − 1 example, which two facts combine to place 0 inside g([1,2])?

Connectedness of the image, combined with the interval characterization of connected subsets of ℝ, is exactly what forces 0 into g([1,2]).

3. In the h(x) = −(x−1)² + 8 example, what replaces the maximizing sequence Real Analysis A would have constructed?

Compactness-preservation plus Heine-Borel plus "closed sets contain their limit points" together replace the entire sequence-extraction argument.

4. Fill in the blank: in every one of the four correspondences, Real Analysis A's version of the proof depended on some structure specific to ℝ, most often ___, that this course's version never needs.

Distance-based structure — ε-balls, suprema tied to a metric, convergent subsequences — is exactly what each topological proof avoids relying on.

5. Fill in the blank: this course's four theorems replace ℝ-specific structure with reasoning about ___ instead, which is why each one applies far beyond ℝ.

Open sets, preimages, and covers are the common thread running through every one of this course's generalized theorems.
