1. Which of the following best states vector space axiom (6), (a + b)v = av + bv?

Axiom (6) distributes over the sum of two field scalars (a + b). Axiom (5) is the similar-looking rule for vector addition, a(u+v) = au+av — a common mix-up.

2. Fill in the blank: the proof that (−1)v = −v uses axiom (6) to rewrite 1v + (−1)v as (1 + (−1))v = ___v.

1 + (−1) = 0 in the field, so (1+(−1))v = 0v — which Lesson 1 already proved equals the zero vector.

3. Is Skew₂ = {A ∈ M₂(ℝ) : Aᵀ = −A} (the skew-symmetric matrices) a subspace of M₂(ℝ)?

0ᵀ = 0 = −0, so the zero matrix qualifies; (A+B)ᵀ = Aᵀ+Bᵀ = −A−B = −(A+B), and (cA)ᵀ = cAᵀ = −cA — all three subspace-test conditions hold.

4. Let D = {A ∈ M₂(ℝ) : det(A) = 0}. Taking A = [[1,0],[0,0]] and B = [[0,0],[0,1]] (both in D, since both determinants are 0), A + B = [[1,0],[0,1]] has determinant 1 ≠ 0. This shows D fails the subspace test's condition on closure under ___.

D does contain the zero matrix and is even closed under scalar multiplication, but the example shows two matrices in D can sum to a matrix outside D — closure under addition fails.

5. In the proof of the Uniqueness of Basis Representation Theorem, why does subtracting two hypothetical representations of v produce a combination equal to 0?

Both sums equal the same vector v, so subtracting one representation from the other gives v − v = 0, expressed as a combination of the basis vectors with coefficients (cᵢ − dᵢ).

6. Suppose w and w′ are both additive inverses of a vector v — that is, v + w = 0 and v + w′ = 0. Answer both parts about proving w = w′:

(a) Which chain of equalities correctly proves w = w′?

(b) Fill in the blank: the step (w + v) + w′ regroups w + (v + w′) using vector space axiom ___.

(a) Rewriting w using the identity, substituting v+w′=0, then regrouping and using v+w=0 again is exactly the mirror of the zero-vector uniqueness proof, applied to inverses instead. (b) Regrouping w + (v + w′) into (w + v) + w′ is precisely axiom (2), associativity.

7. Let Tr₀ = {A ∈ M₂(ℝ) : tr(A) = 0} (matrices whose diagonal entries sum to zero). Answer both parts:

(a) Which subspace-test condition does Tr₀ satisfy first, and why?

(b) For A = [[1,2],[3,−1]] and B = [[−1,0],[4,1]], both in Tr₀ (tr(A) = 1 + (−1) = 0, tr(B) = −1 + 1 = 0), A + B = [[0,2],[7,0]]. Fill in the blank: tr(A + B) = ___.

(a) The zero matrix trivially has trace 0, satisfying condition (i) directly. (b) A+B = [[0,2],[7,0]], whose diagonal entries sum to 0 + 0 = 0, confirming closure under addition.

8. Let S = {1+x, x, 3+4x} ⊂ P₁(ℝ). Answer both parts about applying the Reduction Theorem:

(a) Which nontrivial relation shows S is linearly dependent?

(b) Removing the redundant vector 3+4x leaves {1+x, x}, which is independent and still spans P₁(ℝ). Fill in the blank: {1+x, x} is therefore a ___ for P₁(ℝ).

(a) Expanding 3(1+x) + x − (3+4x) = (3+3x) + x − (3+4x) = 0 + 0x = 0, a nontrivial relation. (b) An independent spanning set is exactly the definition of a basis.

9. Given that B = {1, 1+x, x²} is a basis for P₂(ℝ), answer both parts about writing p(x) = 2 + 3x + 4x² as c₁(1) + c₂(1+x) + c₃(x²):

(a) What is c₂?

(b) Fill in the blank: since B is linearly independent, this representation is the ___ one possible for p(x), by the Uniqueness of Basis Representation Theorem.

(a) Matching coefficients: c₁(1)+c₂(1+x)+c₃x² = (c₁+c₂) + c₂x + c₃x². Comparing to 2+3x+4x² gives c₂ = 3, then c₁ = 2−3 = −1, and c₃ = 4. (b) Independence of B is exactly what forces this to be the only representation.

10. Consider the Reduction Theorem's proof mechanics on a spanning set S = {v₁, v₂, v₃} of a space V, where the dependency 2v₁ − v₂ + 0v₃ = 0 holds (v₃'s coefficient is 0). Answer both parts:

(a) Which vector can validly be removed from S by the theorem's argument, and why?

(b) Fill in the blank: solving 2v₁ − v₂ = 0 for v₁ gives v₁ = (1/2)___.

(a) The proof requires solving for a vector with a nonzero coefficient in the dependency; a coefficient of 0 gives no way to isolate v₃. (b) 2v₁ = v₂, so v₁ = (1/2)v₂.
