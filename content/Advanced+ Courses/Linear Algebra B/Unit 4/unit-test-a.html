1. For an n×n matrix A, det(A−λI) is a polynomial in λ of what degree, with what leading term?

The cofactor-expansion induction proves degree exactly n with leading coefficient (−1)ⁿ, coming from the all-diagonal term (a₁₁−λ)(a₂₂−λ)⋯(aₙₙ−λ).

2. Fill in the blank: A′=P⁻¹AP and A share the same characteristic polynomial because det(A′−λI)=det(P⁻¹)det(A−λI)det(P), and det(P⁻¹)det(P) = ___ (since P⁻¹P=I).

det(P⁻¹)det(P) = det(P⁻¹P) = det(I) = 1, leaving det(A′−λI) = det(A−λI) exactly.

3. For any eigenvalue λ, which relationship between geometric and algebraic multiplicity always holds?

The block-triangular determinant argument proves geometric multiplicity is squeezed between 1 and algebraic multiplicity, but equality is not guaranteed (as the defective example shows).

4. For A=[[3,1],[0,3]], what is dim(E₃)?

(A−3I)=[[0,1],[0,0]]; solving (A−3I)v=0 forces v₂=0, leaving v₁ free — a 1-dimensional eigenspace, less than the algebraic multiplicity 2.

5. Which of the following is always true?

Eλ's closure under scalar multiplication directly guarantees invariance; the other statements reverse implications that don't hold, or claim an equality (Kλ=Eλ) that fails exactly in the defective case.

6. For distinct eigenvalues λ₁=1, λ₂=4 with eigenvectors v₁, v₂, suppose c₁v₁+c₂v₂=0. Applying T gives c₁v₁+4c₂v₂=0. Answer both parts:

(a) Subtracting the original equation from this gives which relation?

(b) Since v₂ ≠ 0, 3c₂v₂ = 0 forces c₂ = ___.

(a) (c₁v₁+4c₂v₂)−(c₁v₁+c₂v₂) = 3c₂v₂ = 0. (b) A nonzero vector times a scalar equals 0 only if the scalar is 0.

7. For A=[[4,0,0],[0,4,1],[0,0,4]], λ=4 has algebraic multiplicity 3. Answer both parts:

(a) What is dim(E₄)?

(b) Fill in the blank: since 2 ≠ 3, A is ___ diagonalizable.

(a) (A−4I)=[[0,0,0],[0,0,1],[0,0,0]]; solving forces v₃=0, leaving v₁,v₂ free — dim 2. (b) 2 falls short of the algebraic multiplicity 3, so the criterion fails.

8. For B=[[5,1,0],[0,5,1],[0,0,5]], answer both parts:

(a) What is dim(ker(B−5I))?

(b) dim(ker((B−5I)²)) = ___.

(a) (B−5I)=[[0,1,0],[0,0,1],[0,0,0]] forces v₂=v₃=0, leaving only v₁ free. (b) (B−5I)² = [[0,0,1],[0,0,0],[0,0,0]], forcing only v₃=0 — a 2-dimensional kernel, growing toward the full algebraic multiplicity 3.

9. For A = [[1,2],[2,1]], answer both parts:

(a) What is the characteristic polynomial?

(b) Factoring gives (λ−3)(λ+1). Name the negative eigenvalue: ___.

(a) det(A−λI) = (1−λ)²−4 = λ²−2λ+1−4 = λ²−2λ−3. (b) Factoring λ²−2λ−3 = (λ−3)(λ+1) gives eigenvalues 3 and −1.

10. In the (⟹) direction of the Diagonalizability Criterion's proof, |B∩Eλᵢ| ≤ dim(Eλᵢ) ≤ aᵢ for each i, and both outer sums equal n. Answer both parts:

(a) What forces every inequality to be an equality?

(b) Fill in the blank: a sum of nonnegative slack terms (aᵢ − dim(Eλᵢ)) that must total exactly ___ forces every individual slack term to vanish.

(a) Matching totals with nonnegative individual gaps forces every gap to be exactly 0. (b) The slack terms are all ≥ 0 and sum to 0, so each one individually must be 0.
