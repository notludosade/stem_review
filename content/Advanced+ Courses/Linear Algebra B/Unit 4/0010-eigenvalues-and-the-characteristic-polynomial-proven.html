Eigenvalues and the Characteristic Polynomial, Proven Properly

Linear Algebra A computed eigenvalues by solving det(A−λI)=0 without ever proving that expression is a polynomial, or that eigenvalues survive a change of basis. Both get proved here — plus the independence fact Unit 6 depends on.

← Lesson 9 Lesson 11 → Contents Glossary →

Linear Algebra A's Lesson 16 defined eigenvalue and eigenvector exactly as they'll be used here: Av = λv for some nonzero v. What it never justified is why det(A−λI) is even a polynomial (rather than some other function of λ), why eigenvalues don't secretly depend on which basis A happens to be written in, or why eigenvectors for different eigenvalues never collide. This lesson proves all three.

1. Eigenspaces are subspaces

Definition — Eigenvalue, Eigenvector, Eigenspace For a linear operator T: V → V, a scalar λ is an eigenvalue if T(v) = λv for some nonzero v ∈ V, and any such v is an eigenvector. The eigenspace Eλ = {v ∈ V : T(v) = λv} = ker(T − λI) is the set of all eigenvectors for λ, together with 0.

Eλ = ker(T − λI) is a kernel of the linear map T − λI (itself linear, since T is and λI is), so Lesson 7's theorem already proves Eλ is a subspace of V — no new argument needed.

2. The characteristic polynomial really is a polynomial

Theorem — Degree and Leading Term For an n×n matrix A, det(A − λI) is a polynomial in λ of degree exactly n, with leading term (−1)ⁿλⁿ.
Proof Sketch (induction on n, via cofactor expansion) n=1: det(A−λI) = a₁₁−λ, degree 1 with leading term −λ = (−1)¹λ¹. ✓

Inductive step: expand det(A−λI) along row 1: det(A−λI) = Σⱼ (−1)^{1+j}(A−λI)1j M1j, where M1j is the (n−1)×(n−1) minor from deleting row 1 and column j. The j=1 term is (a₁₁−λ)·M₁₁, and M₁₁ is exactly det(A′−λI′) for the (n−1)×(n−1) submatrix A′ — by the inductive hypothesis, degree n−1 with leading term (−1)^{n−1}λ^{n−1}. So (a₁₁−λ)M₁₁ contributes degree n, leading term (−λ)(−1)^{n−1}λ^{n−1} = (−1)ⁿλⁿ. Every other term (j≠1) deletes column j≠1, which removes one of the diagonal (aᵢᵢ−λ) entries without replacing it — so that minor has at most n−2 diagonal λ-terms, giving degree ≤ n−2, too low to affect the λⁿ coefficient. So det(A−λI) has degree n, leading term (−1)ⁿλⁿ. ∎
Fact — Eigenvalues Are Exactly the Roots λ is an eigenvalue of A if and only if det(A−λI) = 0. (A−λI has a nonzero kernel exactly when it's singular, i.e. non-invertible — precisely when its determinant is 0, by Linear Algebra A's determinant-invertibility connection.)

3. Similar matrices share the same characteristic polynomial

Theorem If A′ = P⁻¹AP for some invertible P, then det(A′−λI) = det(A−λI) for every λ. So similar matrices — in particular, [T]B and [T]B′ for any two bases (Lesson 9) — always have the same characteristic polynomial.
Proof A′ − λI = P⁻¹AP − λI = P⁻¹AP − λP⁻¹P = P⁻¹(A − λI)P, using P⁻¹P = I. Taking determinants and using multiplicativity (det(XY) = det(X)det(Y), from Linear Algebra A): det(A′−λI) = det(P⁻¹)·det(A−λI)·det(P) = det(P⁻¹)det(P)·det(A−λI) = det(P⁻¹P)·det(A−λI) = det(I)·det(A−λI) = det(A−λI). ∎
Why this settles a real gap Without this theorem, "the eigenvalues of T" wouldn't even be well-defined — computing det([T]B − λI) in one basis could, in principle, give a different answer than computing it in another. This theorem proves that never happens: eigenvalues belong to the operator T itself, not to whatever basis was used to compute them.

4. Eigenvectors for distinct eigenvalues are independent

Theorem If λ₁,…,λk are distinct eigenvalues of T with eigenvectors v₁,…,vk, then {v₁,…,vk} is linearly independent.
Proof (induction on k) k=1: v₁ ≠ 0 is automatically independent (Linear Algebra A). Inductive step: assume {v₁,…,vk−1} is independent, and suppose c₁v₁+⋯+ckvk = 0 (∗). Apply T, using T(vᵢ)=λᵢvᵢ: c₁λ₁v₁+⋯+ckλkvk = 0 (∗∗). Multiply (∗) by λk: c₁λkv₁+⋯+ckλkvk = 0 (∗∗∗). Subtract (∗∗)−(∗∗∗): c₁(λ₁−λk)v₁+⋯+ck−1(λk−1−λk)vk−1 = 0 (the vk terms cancel exactly). By the inductive hypothesis, {v₁,…,vk−1} is independent, so every coefficient is 0: cᵢ(λᵢ−λk) = 0 for i < k. Since the eigenvalues are distinct, λᵢ ≠ λk, forcing cᵢ = 0 for i = 1,…,k−1. Substituting back into (∗): ckvk = 0, and vk ≠ 0 forces ck = 0 too. Every coefficient is 0. ∎

1. Why is Eλ automatically a subspace, with no new proof needed in this lesson?

T − λI is itself a linear map, so its kernel is a subspace by the general kernel theorem from Unit 3 — no eigenvalue-specific argument is required.

2. In the proof that det(A−λI) has degree n, why do the j≠1 terms in the cofactor expansion not affect the λⁿ leading coefficient?

Every λ in the expansion comes from a diagonal entry; skipping column j≠1 while keeping row 1 loses one guaranteed diagonal λ-term, capping the degree contribution below n.

3. Fill in the blank: the proof that similar matrices share a characteristic polynomial relies on the ___ of the determinant, det(XY)=det(X)det(Y).

Splitting det(P⁻¹(A−λI)P) into det(P⁻¹)det(A−λI)det(P), then regrouping det(P⁻¹)det(P)=det(I)=1, is exactly the multiplicativity property doing the work.

4. In the proof that eigenvectors of distinct eigenvalues are independent, what is the purpose of computing (∗∗) − (∗∗∗)?

Both (∗∗) and (∗∗∗) have identical cₖλₖvₖ terms, so subtracting eliminates vₖ entirely, leaving a dependency only among the first k−1 vectors — exactly what the inductive hypothesis can handle.

5. Fill in the blank: in the same proof, once every cᵢ for i<k is shown to be 0, substituting back into (∗) leaves cₖvₖ = 0, and since vₖ ≠ 0, this forces cₖ = ___.

A nonzero vector times a scalar can only equal 0 if the scalar itself is 0 — the same single-nonzero-vector fact from the base case.
