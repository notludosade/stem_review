Orthogonality and the Gram-Schmidt Process

Any independent set can be reshaped into an orthogonal one spanning exactly the same subspaces along the way — one projection-and-subtract step at a time. This lesson derives the formula and runs it on a concrete example.

1. Orthogonality

Definition — Orthogonal, Orthonormal Vectors u, v are orthogonal if ⟨u,v⟩ = 0. A set is orthogonal if every pair of its vectors is orthogonal, and orthonormal if it's orthogonal and every vector also has norm 1.
Fact — Orthogonal Nonzero Vectors Are Independent If u₁,…,uk are nonzero and pairwise orthogonal, they are linearly independent.
Proof Suppose c₁u₁+⋯+ckuk = 0. Take the inner product of both sides with uj (for any fixed j): ⟨c₁u₁+⋯+ckuk, uj⟩ = 0. By bilinearity, this expands to c₁⟨u₁,uj⟩+⋯+ck⟨uk,uj⟩ = 0. Every term with a different index vanishes by orthogonality, leaving only cj⟨uj,uj⟩ = 0. Since uj ≠ 0, ⟨uj,uj⟩ ≠ 0 (positive-definiteness), so cj = 0. This holds for every j, so every coefficient is 0. ∎

2. The Gram-Schmidt process, derived

Theorem — Gram-Schmidt Given a linearly independent set {v₁,…,vk}, define u₁ = v₁ and, for i = 2,…,k: ui = vi − Σj<i (⟨vi,uj⟩/⟨uj,uj⟩) uj. Then {u₁,…,uk} is orthogonal, every ui ≠ 0, and span{u₁,…,ui} = span{v₁,…,vi} for every i.
Proof (induction on i) i=1: u₁=v₁≠0 (independent sets contain no zero vector), and span{u₁}=span{v₁} trivially.

Inductive step: assume the claim holds through i−1. For any j < i, compute ⟨ui,uj⟩ = ⟨vi,uj⟩ − Σl<i(⟨vi,ul⟩/⟨ul,ul⟩)⟨ul,uj⟩. By the inductive orthogonality of u₁,…,ui−1, every term with l≠j vanishes, leaving only the l=j term: (⟨vi,uj⟩/⟨uj,uj⟩)⟨uj,uj⟩ = ⟨vi,uj⟩. So ⟨ui,uj⟩ = ⟨vi,uj⟩ − ⟨vi,uj⟩ = 0 — orthogonal to every earlier u.

ui ≠ 0: ui is vi minus a combination of u₁,…,ui−1 ∈ span{v₁,…,vi−1} (by the inductive spanning claim). If ui were 0, vi would lie in span{v₁,…,vi−1}, contradicting the independence of {v₁,…,vi}.

Spanning: ui is vi minus a combination of earlier u's (themselves combinations of v₁,…,vi−1), so ui ∈ span{v₁,…,vi}, giving span{u₁,…,ui} ⊆ span{v₁,…,vi}. Conversely, vi = ui + (that same combination of earlier u's), so vi ∈ span{u₁,…,ui}; together with v₁,…,vi−1 ∈ span{u₁,…,ui−1} ⊆ span{u₁,…,ui} (inductive hypothesis), this gives span{v₁,…,vi} ⊆ span{u₁,…,ui}. Both inclusions together give equality. ∎

Dividing each ui by its own norm produces an orthonormal basis ei = ui/‖ui‖ spanning the same subspaces at every stage.

Worked Example — Gram-Schmidt on Three Vectors in ℝ³ v₁=(1,1,0), v₂=(1,0,1), v₃=(0,1,1). u₁ = v₁ = (1,1,0), with ⟨u₁,u₁⟩ = 2.
u₂ = v₂ − (⟨v₂,u₁⟩/⟨u₁,u₁⟩)u₁ = (1,0,1) − (1/2)(1,1,0) = (1/2, −1/2, 1). Check: ⟨u₂,u₁⟩ = 1/2 − 1/2 + 0 = 0. ✓ ⟨u₂,u₂⟩ = 1/4+1/4+1 = 3/2.
u₃ = v₃ − (⟨v₃,u₁⟩/⟨u₁,u₁⟩)u₁ − (⟨v₃,u₂⟩/⟨u₂,u₂⟩)u₂. ⟨v₃,u₁⟩ = 0+1+0 = 1, so the first projection is (1/2)(1,1,0) = (1/2,1/2,0). ⟨v₃,u₂⟩ = 0(1/2)+1(−1/2)+1(1) = 1/2, so the second projection is (1/3)(1/2,−1/2,1) = (1/6,−1/6,1/3). Subtracting both from v₃: u₃ = (0,1,1) − (1/2,1/2,0) − (1/6,−1/6,1/3) = (−2/3, 2/3, 2/3). Check: ⟨u₃,u₁⟩ = −2/3+2/3+0 = 0 ✓, and ⟨u₃,u₂⟩ = (−2/3)(1/2)+(2/3)(−1/2)+(2/3)(1) = −1/3−1/3+2/3 = 0 ✓.

1. In the proof that orthogonal nonzero vectors are independent, what happens after taking the inner product of c₁u₁+⋯+cₖuₖ=0 with a fixed uⱼ?

Orthogonality kills every cross term ⟨uᵢ,uⱼ⟩ for i≠j, isolating cⱼ⟨uⱼ,uⱼ⟩=0 — and positive-definiteness (uⱼ≠0 ⟹ ⟨uⱼ,uⱼ⟩≠0) forces cⱼ=0.

2. In the Gram-Schmidt proof, why does ⟨uᵢ,uⱼ⟩ reduce to just ⟨vᵢ,uⱼ⟩ − ⟨vᵢ,uⱼ⟩ for j < i?

Only the l=j term in the projection sum survives orthogonality, and it's constructed to exactly equal ⟨vᵢ,uⱼ⟩ — canceling the leading term and leaving 0.

3. Fill in the blank: the proof that uᵢ≠0 relies on the ___ of {v₁,…,vᵢ} — if uᵢ were 0, vᵢ would be a combination of v₁,…,vᵢ₋₁.

uᵢ=0 would mean vᵢ equals exactly the subtracted combination of earlier u's (themselves combinations of earlier v's) — contradicting independence of the original set.

4. In the worked example, what is ⟨u₁,u₁⟩ for u₁=(1,1,0)?

⟨u₁,u₁⟩ = 1²+1²+0² = 2.

5. In the worked example, u₃ = (___, 2/3, 2/3). Fill in the first coordinate (as a fraction like -2/3).

Subtracting both projections from v₃ gives u₃ = (0,1,1) − (1/2,1/2,0) − (1/6,−1/6,1/3) = (−2/3, 2/3, 2/3).
