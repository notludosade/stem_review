1. Which set, with the operations shown, is a vector space over ℝ?

Upper triangular matrices contain the zero matrix and are closed under addition and scalar multiplication. The others fail: no zero vector, no zero matrix (det 0≠1), and f(0)=5≠0 respectively.

2. Fill in the blank: for W to be a subspace, in addition to closure under addition and scalar multiplication, W must contain the ___ vector.

Condition (i) of the subspace test — containing 0 — is independent of the two closure conditions.

3. A spanning set of 5 vectors for a 3-dimensional space must be:

Any set larger than the space's dimension is automatically dependent — a direct consequence of the Exchange Lemma.

4. If {v₁,…,v₄} is independent in a vector space that also has a spanning set of only 3 vectors, this situation is:

The Exchange Lemma's inequality m≤n (independent size ≤ spanning size) holds over any field and rules this out entirely.

5. If dim(U)=6, dim(W)=4, and dim(U∩W)=3, what is dim(U+W)?

dim(U+W) = dim(U)+dim(W)−dim(U∩W) = 6+4−3 = 7.

6. The change-of-basis matrix PB←B′ is built by:

Each column records where a B′ basis vector lands in B's coordinates — the reverse assignment would build PB′←B instead.

7. For a linear map T: V → W, ker(T) is a subspace of:

ker(T) = {v ∈ V : T(v)=0} lives entirely inside the domain V, not the codomain W.

8. If dim(V)=9 and nullity(T)=5, what is rank(T)?

rank(T) = dim(V) − nullity(T) = 9 − 5 = 4.

9. Matrices representing the same linear operator relative to two different bases are always:

The Change of Basis Theorem proves this exact relationship, for any two bases of the same operator's domain.

10. For A=[[0,1],[1,0]], name the negative eigenvalue.

det(A−λI) = λ²−1 = (λ−1)(λ+1), giving eigenvalues 1 and −1.

11. T is diagonalizable exactly when, for every eigenvalue λ:

The Diagonalizability Criterion requires equality of the two multiplicities for every eigenvalue, not just one of them, and geometric multiplicity is always ≥1 for a genuine eigenvalue.

12. Which subspace is always T-invariant?

Since Eλ is closed under scalar multiplication and T(v)=λv for v∈Eλ, T never sends Eλ outside itself — true for every operator, not just special ones.

13. Cauchy-Schwarz's equality case, |⟨u,v⟩|=‖u‖‖v‖, holds exactly when:

A zero discriminant in the proof corresponds exactly to u being a scalar multiple of v — linear dependence, not orthogonality.

14. For v₁=(1,0,0), v₂=(1,0,1), Gram-Schmidt gives u₂=(0,0,___).

u₁=(1,0,0); ⟨v₂,u₁⟩=1, ⟨u₁,u₁⟩=1, so u₂ = (1,0,1) − 1·(1,0,0) = (0,0,1).

15. For a subspace W of finite-dimensional V, dim(W)+dim(W⊥) equals:

The direct sum V=W⊕W⊥ forces dimensions to add up to dim(V) exactly.

16. Every eigenvalue of a self-adjoint operator is:

The proof (λ‖v‖²=conj(λ)‖v‖², forcing λ=conj(λ)) guarantees only realness, not any sign or irrationality property.

17. For A=[[1,4],[4,1]], name the negative eigenvalue.

det(A−λI) = (1−λ)²−16 = λ²−2λ−15 = (λ−5)(λ+3), giving eigenvalues 5 and −3.

18. The singular values of A are:

σᵢ=√λᵢ, where λᵢ are AᵀA's (always nonnegative) eigenvalues — this works even when A itself has no eigenvalues of its own (non-square A).

19. If N³=0 but N²≠0 for some operator N, N's index of nilpotency is:

The index of nilpotency is the smallest k with N^k=0 — here that's 3, since N²≠0 rules out a smaller index.

20. If a repeated eigenvalue has algebraic multiplicity 6, covered by Jordan blocks of sizes 3, 2, and 1, how many blocks are there in total?

3+2+1=6 matches the algebraic multiplicity, using 3 separate blocks.

21. A quadratic form Q(x)=xᵀAx is negative definite exactly when:

In principal-axis coordinates, Q=Σλᵢyᵢ² is negative for every nonzero y exactly when every λᵢ is negative.
