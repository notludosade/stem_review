The No-Cloning Theorem

Lesson 12 showed measurement destroys a state. This lesson closes off the obvious workaround — "just copy the qubit first" — with a short, clean proof straight from unitarity.

← Lesson 14 Unit 4, Lesson 16 → Contents Glossary →

If a single measurement destroys a qubit's superposition, the natural fix seems obvious: make several identical copies of the unknown state first, then measure each one to statistically reconstruct α and β, as Lesson 12's example did. That fix has a fatal flaw — you can't make those copies in the first place, for an unknown state. This is the no-cloning theorem, and unlike the Born rule and collapse, it isn't a postulate — it's a theorem, provable directly from unitarity.

1. One tool borrowed early from Unit 4

Preview — Joint States of Two Qubits Unit 4 develops this fully, but this proof needs one fact now: the joint state of two independent qubits, one in state |ψ⟩ and one in state |φ⟩, is written |ψ⟩⊗|φ⟩ (or |ψφ⟩ for short). Inner products of joint states multiply piece by piece: ⟨ψ⊗φ|χ⊗ω⟩ = ⟨ψ|χ⟩⟨φ|ω⟩. That's the only tensor-product fact this lesson relies on.

2. The theorem

Theorem — No-Cloning There is no unitary operation U on two qubits such that U(|ψ⟩⊗|0⟩) = |ψ⟩⊗|ψ⟩ for every single-qubit state |ψ⟩. In words: no fixed quantum machine can take an arbitrary unknown state and a blank qubit, and output two copies of that state, for every possible input state.
Proof Suppose, toward contradiction, that such a U exists, and suppose it successfully clones two particular states |ψ⟩ and |φ⟩: U(|ψ⟩⊗|0⟩) = |ψ⟩⊗|ψ⟩ and U(|φ⟩⊗|0⟩) = |φ⟩⊗|φ⟩. Because U is unitary, it preserves inner products (Lesson 6 established this same fact for a single qubit; it holds identically here). So:
⟨ψ⊗0|φ⊗0⟩ = ⟨U(ψ⊗0)|U(φ⊗0)⟩ = ⟨ψ⊗ψ|φ⊗φ⟩
The left side is ⟨ψ|φ⟩⟨0|0⟩ = ⟨ψ|φ⟩. The right side is ⟨ψ|φ⟩⟨ψ|φ⟩ = ⟨ψ|φ⟩². So ⟨ψ|φ⟩ = ⟨ψ|φ⟩², which means ⟨ψ|φ⟩(1 − ⟨ψ|φ⟩) = 0, forcing ⟨ψ|φ⟩ to be either 0 or 1. Since both states are normalized, ⟨ψ|φ⟩ = 1 only when |φ⟩ equals |ψ⟩ up to global phase (the same physical state), and ⟨ψ|φ⟩ = 0 means the states are orthogonal. So a single fixed U can only clone states that are either identical or orthogonal to each other — never a generic pair of distinct, non-orthogonal states. Since |ψ⟩ was required to be arbitrary, no single U works for every possible input. ∎
Why classical bit-copying doesn't contradict this Notice the proof's loophole precisely: orthogonal states (⟨ψ|φ⟩ = 0) can be cloned together by a single fixed device. |0⟩ and |1⟩ are orthogonal — and indeed, a CNOT-based circuit (Unit 5, Lesson 22 previews this exact construction) can clone |0⟩ and |1⟩ specifically. This is exactly why classical bit-copying (which only ever needs to handle the two orthogonal values 0 and 1) never runs into a no-cloning obstruction — the theorem only bites once superposition, and the possibility of non-orthogonal unknown states, enters the picture.

3. Why this matters going forward

No-cloning closes off Lesson 12's obvious workaround for good: given a single copy of an unknown quantum state, there is no way to duplicate it first and then measure the copies. It also has real practical teeth beyond this course's proofs — it's the reason an eavesdropper cannot silently copy a qubit in transit to inspect later without disturbing it, which is exactly the security guarantee underlying quantum key distribution protocols like BB84. And it will resurface directly in Unit 8: any scheme for protecting quantum information from noise (quantum error correction) has to work around the fact that it cannot simply make backup copies the way a classical repetition code does.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does the no-cloning theorem state?

No-cloning is specifically about copying an unknown state for every possible input — it says nothing about measurement counts or multi-qubit gates in general, and classical bits are copyable (they're a special, orthogonal-states-only case).

2. Which property of unitary operations is the key step the no-cloning proof relies on?

Preserving ⟨ψ⊗0|φ⊗0⟩ = ⟨U(ψ⊗0)|U(φ⊗0)⟩ is exactly what forces ⟨ψ|φ⟩ = ⟨ψ|φ⟩², the equation the whole contradiction is built on.

3. Which pair of states CAN, in principle, be cloned by the same fixed device, according to the proof's own conclusion?

The proof shows ⟨ψ|φ⟩ must be 0 or 1 for cloning to be consistent — orthogonal states (⟨ψ|φ⟩ = 0), like |0⟩ and |1⟩, pass this test, which is exactly why classical bit-copying is possible.

4. Fill in the blank: the theorem proving that no unitary can copy an arbitrary unknown quantum state is called the ___ theorem.

The no-cloning theorem is the standard name for exactly this result.

5. Fill in the blank: because an eavesdropper cannot make a perfect undetected copy of an unknown qubit, no-cloning underlies the security of quantum ___ distribution protocols like BB84.

Quantum key distribution's security guarantee rests directly on no-cloning — an eavesdropper intercepting qubits in transit cannot copy them without a detectable disturbance.
