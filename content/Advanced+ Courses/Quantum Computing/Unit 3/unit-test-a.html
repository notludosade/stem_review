1. For |ψ⟩ = (1/2)|0⟩ + (√3/2)|1⟩, what is P(1), the probability of measuring outcome 1?

P(1) = |√3/2|² = 3/4 — square the amplitude's magnitude, never use the amplitude itself.

2. Which formula correctly gives the probability of outcome i when measuring |ψ⟩ in an orthonormal basis {|e₀⟩, |e₁⟩}?

The Born rule requires squaring the magnitude of the inner product ⟨eᵢ|ψ⟩ — this works for any orthonormal basis, not just the computational one.

3. A qubit in state (3/5)|0⟩ + (4/5)|1⟩ is measured and the outcome is 1. Answer both parts:

(a) What is the qubit's state immediately afterward?

(b) Fill in the blank: measuring the same qubit again immediately (same basis) gives outcome 1 with probability ___.

(a) The state collapses exactly to |1⟩. (b) Since the qubit is now exactly |1⟩, a second measurement returns 1 with certainty.

4. Why can't repeated measurement of one single qubit be used to determine its original superposition amplitudes?

Once collapsed, a qubit stays in its collapsed basis state — re-measuring it in the same basis just reproduces the same outcome, since the original superposition is already gone.

5. Fill in the blank: to measure a qubit in the X basis using only a computational-basis measurement device, first apply the ___ gate.

H maps |+⟩ to |0⟩ and |−⟩ to |1⟩, so applying H before an ordinary measurement exactly reproduces X-basis statistics.

6. A qubit in state |1⟩ is measured in the X basis. What is P(+)?

⟨+|1⟩ = 1/√2, so P(+) = |1/√2|² = 1/2 — like |0⟩, the state |1⟩ splits evenly when measured in the X basis.

7. Which property must an operator have to represent a measurable physical observable?

Hermitian operators are exactly the ones with real eigenvalues, which is what allows those eigenvalues to represent physically measurable outcomes.

8. For |ψ⟩ = (1/2)|0⟩ + (√3/2)|1⟩, answer both parts:

(a) What is ⟨Z⟩?

(b) Fill in the blank: since ⟨Z⟩ is negative, measuring this state is more likely to give outcome ___.

(a) ⟨Z⟩ = |1/2|² − |√3/2|² = 1/4 − 3/4 = −1/2. (b) A negative ⟨Z⟩ means outcome 1 (eigenvalue −1) carries more weight — consistent with P(1) = 3/4 from Question 1.

9. In the no-cloning proof, assuming a single U clones both |ψ⟩ and |φ⟩ leads to which equation?

Unitarity's inner-product preservation forces ⟨ψ|φ⟩ = ⟨ψ|φ⟩², which only has solutions 0 or 1 — not an identity that holds for every pair automatically.

10. Fill in the blank: a single fixed cloning device CAN copy two states if their inner product ⟨ψ|φ⟩ equals 0 or ___.

⟨ψ|φ⟩ = 1 means the two states are actually the same physical state (up to global phase), and ⟨ψ|φ⟩ = 0 means orthogonal — the only two cases the proof leaves open.
