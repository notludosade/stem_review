Expectation Values

One real number that summarizes an entire measurement's statistics at once — computed directly from the state vector, with no explicit probability list required.

← Lesson 13 Lesson 15 → Contents Glossary →

An observable is a physical quantity that can be measured — for a qubit, the Pauli matrices X, Y, and Z are the standard observables, each corresponding to measurement in its own basis (Z in the computational basis, X in Lesson 13's X basis, Y in a similar Y basis). Every observable in quantum mechanics is represented by a Hermitian operator, and its expectation value packages an entire probability distribution into a single number.

1. Hermitian operators and eigenvalues as outcomes

Definition — Hermitian Operator A matrix A is Hermitian if A† = A — it equals its own conjugate transpose. You can check directly that X, Y, and Z are all Hermitian (each is real and symmetric, or in Y's case, conjugating and transposing return the original matrix).

Hermitian operators have a special property from Linear Algebra B worth recalling here: their eigenvalues are always real numbers, and eigenvectors for distinct eigenvalues are orthogonal. For Z, the eigenvectors are exactly |0⟩ (eigenvalue +1: Z|0⟩ = |0⟩) and |1⟩ (eigenvalue −1: Z|1⟩ = −|1⟩). The measurement postulates generalize cleanly: measuring the observable Z returns one of its eigenvalues (+1 or −1) with the Born-rule probability for the corresponding eigenvector — this is just outcomes 0 and 1 relabeled as +1 and −1.

2. The expectation value formula

Definition — Expectation Value For an observable A and a state |ψ⟩, the expectation value is ⟨A⟩ = ⟨ψ|A|ψ⟩ — the average outcome you'd get, weighted by probability, over many repeated measurements on identically prepared copies of |ψ⟩.

For Z specifically, writing out ⟨ψ|Z|ψ⟩ for |ψ⟩ = α|0⟩ + β|1⟩ = (α, β)ᵀ: Z|ψ⟩ = (α, −β)ᵀ, so ⟨ψ|Z|ψ⟩ = α*α + β*(−β) = |α|² − |β|². This is exactly P(0)·(+1) + P(1)·(−1), the probability-weighted average of the two eigenvalues — confirming ⟨A⟩ = ⟨ψ|A|ψ⟩ computes precisely the weighted-average outcome, directly from the state vector, with no need to list P(0) and P(1) separately first.

Example |ψ⟩ = (4/5)|0⟩ + (3/5)|1⟩ (both amplitudes real for simplicity). ⟨Z⟩ = |4/5|² − |3/5|² = 16/25 − 9/25 = 7/25 = 0.28. Interpretation: measuring Z on many copies of this state, you'd see +1 (outcome 0) more often than −1 (outcome 1), and the long-run average would settle near 0.28 — closer to +1 than to −1, matching the fact that P(0) = 16/25 > P(1) = 9/25.
Why ⟨Z⟩ = 0 doesn't necessarily mean "50/50 in every basis" ⟨Z⟩ = 0 exactly when |α|² = |β|² — a 50/50 split for Z-measurement. But this says nothing at all about X or Y measurement statistics for that same state. |+⟩ has ⟨Z⟩ = 0 (a coin flip in the Z basis) but ⟨X⟩ = 1 (completely deterministic in the X basis, by Lesson 13). A single expectation value only ever summarizes statistics for its own observable — never confuse "this observable's expectation is 0 (or extreme)" with "the state is maximally uncertain (or certain) about everything."

Check your recall

No peeking back up — answer from memory first, then check.

1. What is ⟨Z⟩ for the state |0⟩?

|0⟩ gives outcome 0 (eigenvalue +1) with certainty, so ⟨Z⟩ = 1·(+1) + 0·(−1) = +1.

2. What is ⟨Z⟩ for the state |+⟩?

|+⟩ splits 50/50 between Z-basis outcomes, so ⟨Z⟩ = (1/2)(+1) + (1/2)(−1) = 0 — the two contributions cancel exactly.

3. For |ψ⟩ = (√3/2)|0⟩ + (1/2)|1⟩ (real amplitudes), what is ⟨Z⟩?

⟨Z⟩ = |√3/2|² − |1/2|² = 3/4 − 1/4 = 1/2.

4. Fill in the blank: the eigenvalues of Z are +1 (for eigenvector |0⟩) and ___ (for eigenvector |1⟩).

Z|1⟩ = −|1⟩, so −1 is the eigenvalue paired with the |1⟩ eigenvector — matching measurement outcome 1.

5. Fill in the blank: every observable in quantum mechanics is represented by a ___ operator, satisfying A† = A.

Hermitian operators guarantee real eigenvalues, which is exactly what's needed for eigenvalues to represent physically measurable outcomes.
