Building Bell States with H and CNOT

Two gates, applied to an ordinary two-bit input, produce all four Bell states on demand — the standard circuit every entanglement-based protocol in quantum computing starts with.

← Lesson 21 Lesson 23 → Contents Glossary →

Lesson 21 showed CNOT entangles a superposed control with its target. Combine that with H, which creates the superposition in the first place, and you get the standard two-gate recipe for manufacturing any of Unit 4's four Bell states from an ordinary classical-looking input.

1. The main case: |00⟩ → |Φ⁺⟩

Trace — |00⟩ Through the Circuit Start: |00⟩. Apply H to qubit 1: (H|0⟩) ⊗ |0⟩ = |+⟩ ⊗ |0⟩ = (|00⟩ + |10⟩)/√2. Apply CNOT (qubit 1 control, qubit 2 target): CNOT|00⟩ = |00⟩ stays, CNOT|10⟩ = |11⟩. Result: (|00⟩ + |11⟩)/√2 = |Φ⁺⟩.

2. The other three: flip the input bits

The same two-gate circuit, fed a different two-bit classical input, produces a different Bell state. Trace |10⟩: H on qubit 1 gives H|1⟩ ⊗ |0⟩ = |−⟩ ⊗ |0⟩ = (|00⟩ − |10⟩)/√2; CNOT then gives (|00⟩ − |11⟩)/√2 = |Φ⁻⟩. Trace |01⟩: H|0⟩ ⊗ |1⟩ = |+⟩ ⊗ |1⟩ = (|01⟩ + |11⟩)/√2; CNOT swaps the second term's target bit, giving (|01⟩ + |10⟩)/√2 = |Ψ⁺⟩. Trace |11⟩: H|1⟩ ⊗ |1⟩ = |−⟩ ⊗ |1⟩ = (|01⟩ − |11⟩)/√2; CNOT gives (|01⟩ − |10⟩)/√2 = |Ψ⁻⟩.

Summary Table Input |00⟩ → |Φ⁺⟩. Input |10⟩ → |Φ⁻⟩. Input |01⟩ → |Ψ⁺⟩. Input |11⟩ → |Ψ⁻⟩. This is a clean one-to-one correspondence: this exact circuit maps each of the four computational basis states to a distinct Bell state.
Why this circuit is worth memorizing outright This two-gate pattern — H on the qubit that will act as control, then CNOT into the target — is the standard building block behind quantum teleportation, superdense coding, and quantum key distribution protocols built on entanglement, none of which this course derives in full, but all of which start from exactly this circuit. Recognizing "H then CNOT on two fresh qubits" as "we're about to build a Bell pair" is a genuinely useful pattern-matching skill going forward, including in Unit 6 and Unit 7's algorithms, which reuse the same H-then-entangle logic in a more elaborate form.

Check your recall

No peeking back up — answer from memory first, then check.

1. Tracing |00⟩ through H (on qubit 1) then CNOT, what state results?

H|0⟩⊗|0⟩ = (|00⟩+|10⟩)/√2, then CNOT gives (|00⟩+|11⟩)/√2 = |Φ⁺⟩.

2. Tracing |01⟩ through H (on qubit 1) then CNOT, what state results?

H|0⟩⊗|1⟩ = (|01⟩+|11⟩)/√2, then CNOT flips the second term's target: (|01⟩+|10⟩)/√2 = |Ψ⁺⟩.

3. Which classical two-bit input produces |Φ⁻⟩ through this circuit?

H|1⟩⊗|0⟩ = (|00⟩−|10⟩)/√2, then CNOT gives (|00⟩−|11⟩)/√2 = |Φ⁻⟩.

4. Fill in the blank: this circuit maps each of the ___ computational basis inputs to a distinct Bell state, a one-to-one correspondence.

|00⟩, |01⟩, |10⟩, |11⟩ map respectively to |Φ⁺⟩, |Ψ⁺⟩, |Φ⁻⟩, |Ψ⁻⟩ — four inputs, four distinct outputs.

5. Fill in the blank: the Bell-state preparation circuit applies ___ to the control qubit first, before applying CNOT.

H creates the superposition on the control qubit that CNOT then spreads onto the target, producing entanglement.
