1. What is CNOT|01⟩ (control = 0, target = 1)?

With control = 0, CNOT does nothing — the target only flips when the control is |1⟩.

2. What does CNOT give when applied to [(5/13)|0⟩ + (12/13)|1⟩] ⊗ |0⟩?

CNOT flips the target only on the |1⟩ branch of the control: (5/13)CNOT|00⟩ + (12/13)CNOT|10⟩ = (5/13)|00⟩ + (12/13)|11⟩, an entangled state.

3. Tracing |10⟩ through H (on qubit 1) then CNOT, what state results?

H|1⟩⊗|0⟩ = (|00⟩−|10⟩)/√2, then CNOT gives (|00⟩−|11⟩)/√2 = |Φ⁻⟩.

4. Answer both parts about CZ:

(a) What is CZ|01⟩?

(b) Fill in the blank: CZ|00⟩ = (___)|00⟩.

(a) CZ only ever touches |11⟩, so |01⟩ is left completely unchanged. (b) Every basis state other than |11⟩ is multiplied by 1 (unchanged) under CZ.

5. What is SWAP|01⟩?

SWAP exchanges the two qubits' values, turning |01⟩ into |10⟩.

6. Fill in the blank: building SWAP out of CNOT gates alone requires exactly ___ of them, alternating control and target.

Three alternating CNOTs — CNOT(1→2), then CNOT(2→1), then CNOT(1→2) — exactly reproduce SWAP.

7. What is Toffoli|1, 0, 1⟩ (controls 1 and 0, target 1)?

Toffoli only flips the target when BOTH controls are 1. Here one control is 0, so nothing changes.

8. Trace |00⟩ through: X applied to qubit 1, then H applied to qubit 2, then CNOT with qubit 1 as control and qubit 2 as target. What is the final state?

X gives |10⟩; H on qubit 2 gives (|10⟩+|11⟩)/√2. Since qubit 1 (the control) is definitely |1⟩ in both terms, CNOT simply flips qubit 2 in each term, mapping the state to itself: (|11⟩+|10⟩)/√2 = (|10⟩+|11⟩)/√2, still |1⟩⊗|+⟩ — no entanglement results, since the control was never in superposition.

9. Why must a universal quantum gate set be described in terms of "approximation," unlike a classical universal gate set like {NAND}?

Since there are uncountably many possible unitary operations, a finite gate set can only ever get arbitrarily close to any one of them — exact construction the way NAND achieves classically isn't possible.

10. Fill in the blank: in the universal set {H, T, CNOT}, the gate specifically responsible for supplying the ability to create entanglement is ___.

CNOT is the only gate in the set that acts on more than one qubit, making it the source of all entangling power — H and T alone, however combined, can never entangle anything.
