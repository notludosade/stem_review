Other Multi-Qubit Gates: CZ, SWAP, and Toffoli

CNOT isn't the only multi-qubit gate worth knowing by name — one of these three finally answers Lesson 6's open question about whether classical AND has any quantum equivalent at all.

← Lesson 22 Lesson 24 → Contents Glossary →

1. CZ — controlled-Z

Definition — CZ Gate CZ applies a Z gate to the target qubit if and only if the control qubit is |1⟩. As a matrix: CZ = diag(1, 1, 1, −1) — every basis state is left alone except |11⟩, which picks up a −1.
Why CZ doesn't actually need a "control" and "target" label Because CZ's matrix is diagonal and only touches |11⟩, it doesn't matter which qubit you call the control and which the target — the gate is exactly symmetric between the two qubits (relabeling qubit 1 and qubit 2 leaves the matrix unchanged). This is unlike CNOT, where swapping control and target genuinely changes the gate. CZ is a pure relative-phase gate on the two-qubit level, exactly analogous to Unit 2's single-qubit Z gate.

2. SWAP

Definition — SWAP Gate SWAP exchanges the two qubits' states entirely: SWAP|00⟩ = |00⟩, SWAP|01⟩ = |10⟩, SWAP|10⟩ = |01⟩, SWAP|11⟩ = |11⟩. Like CNOT, it's a permutation matrix, so unitarity is automatic.
Fact — SWAP from Three CNOTs SWAP can be built entirely from three CNOT gates, alternating which qubit is the control: CNOT(1→2), then CNOT(2→1), then CNOT(1→2) again, reproduces SWAP exactly. Trace |10⟩ through it: CNOT(1→2) gives |11⟩ (control qubit 1 = 1, flip target); CNOT(2→1) gives |01⟩ (control qubit 2 = 1, flip qubit 1); CNOT(1→2) gives |01⟩ (control qubit 1 = 0 now, no change) — matching SWAP|10⟩ = |01⟩ exactly.

3. Toffoli — the reversible AND

Definition — Toffoli Gate (CCNOT) The Toffoli gate acts on three qubits: two controls and one target. It flips the target if and only if both controls are |1⟩: Toffoli|c₁, c₂, t⟩ = |c₁, c₂, t ⊕ (c₁ AND c₂)⟩.
Why Toffoli finally answers Lesson 6's open question Lesson 6 pointed out that classical AND destroys information and has no direct single-qubit or simple two-qubit unitary equivalent. Toffoli is the resolution: initialize the target qubit to |0⟩, and Toffoli|c₁, c₂, 0⟩ = |c₁, c₂, c₁ AND c₂⟩ — the target now holds exactly the AND of the two control bits, and the whole operation is perfectly reversible (Toffoli is its own inverse, since flipping the same target twice under the same controls undoes itself). This is the standard trick for embedding any classical, even logically irreversible, computation into a reversible quantum circuit: keep every input bit around unchanged, and write outputs to freshly initialized ancilla qubits instead of overwriting inputs. In fact, {Toffoli, X} together (or even Toffoli alone, in the right configuration) is universal for classical reversible computation — any classical circuit can be built from Toffoli gates plus ancilla qubits, without ever losing information the way ordinary AND does.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does CZ do to the state |11⟩?

CZ = diag(1,1,1,−1) leaves every basis state alone except |11⟩, which gets multiplied by −1.

2. Why doesn't it matter which qubit is labeled "control" for CZ, unlike for CNOT?

Because CZ's matrix is diagonal and touches only |11⟩ (the one basis state where both qubits agree), swapping which qubit is called "control" changes nothing about the matrix.

3. What is SWAP|01⟩?

SWAP exchanges the two qubits' values entirely: 0 and 1 trade places, turning |01⟩ into |10⟩.

4. Fill in the blank: SWAP can be built from three ___ gates in a row, alternating which qubit serves as the control each time.

Three alternating CNOTs — CNOT(1→2), then CNOT(2→1), then CNOT(1→2) — exactly reproduce SWAP.

5. Fill in the blank: the Toffoli gate flips its target qubit if and only if both control qubits are ___.

Toffoli flips the target exactly when both controls are 1 — implementing a reversible version of classical AND when the target starts at |0⟩.
