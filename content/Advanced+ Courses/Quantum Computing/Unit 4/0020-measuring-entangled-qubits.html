Measuring Entangled Qubits

The precise mechanics of measuring just one qubit out of a multi-qubit state — and a side-by-side computation showing exactly what entanglement adds that a product state never has.

← Lesson 19 Unit 5, Lesson 21 → Contents Glossary →

Lesson 19 used partial measurement informally. This closing lesson of Unit 4 states the rule precisely, for any two-qubit state, and then runs the exact same rule on a product state and an entangled state side by side — making the difference impossible to miss.

1. The partial-measurement rule

Rule — Measuring One Qubit of a Two-Qubit State For |Ψ⟩ = c₀₀|00⟩ + c₀₁|01⟩ + c₁₀|10⟩ + c₁₁|11⟩, measuring only the first qubit gives outcome 0 with probability P(0) = |c₀₀|² + |c₀₁|², and outcome 1 with probability P(1) = |c₁₀|² + |c₁₁|² (Lesson 11's Born rule, summed over the second qubit's two possibilities). If the outcome is 0, the post-measurement state is the surviving terms, renormalized: (c₀₀|00⟩ + c₀₁|01⟩) / √(|c₀₀|² + |c₀₁|²). If the outcome is 1: (c₁₀|10⟩ + c₁₁|11⟩) / √(|c₁₀|² + |c₁₁|²).

In words: measuring one qubit discards every term inconsistent with the outcome observed, then rescales what's left so the remaining state is properly normalized again — the multi-qubit generalization of Lesson 12's collapse.

2. Case 1: measuring one qubit of a product state

Example — Product State |Ψ⟩ = |+⟩ ⊗ |0⟩ = (|00⟩ + |10⟩)/√2, so c₀₀ = 1/√2, c₀₁ = 0, c₁₀ = 1/√2, c₁₁ = 0. Measure qubit 1: P(0) = |1/√2|² + 0 = 1/2. If outcome 0: post-state = (1/√2)|00⟩ / (1/√2) = |00⟩ — qubit 2 is |0⟩. If outcome 1: P(1) = |1/√2|² + 0 = 1/2, post-state = (1/√2)|10⟩ / (1/√2) = |10⟩ — qubit 2 is still |0⟩. Either way, qubit 2 ends up in exactly the same state, |0⟩, completely unaffected by which outcome qubit 1 gave.

3. Case 2: measuring one qubit of an entangled state

Example — Entangled State |Ψ⟩ = |Φ⁺⟩ = (|00⟩ + |11⟩)/√2, so c₀₀ = 1/√2, c₀₁ = 0, c₁₀ = 0, c₁₁ = 1/√2. Measure qubit 1: P(0) = 1/2, and if outcome 0: post-state = (1/√2)|00⟩ / (1/√2) = |00⟩ — qubit 2 collapses to |0⟩. P(1) = 1/2, and if outcome 1: post-state = (1/√2)|11⟩ / (1/√2) = |11⟩ — qubit 2 collapses to |1⟩ this time. Now qubit 2's resulting state genuinely depends on which outcome qubit 1 gave — 0 forces qubit 2 to |0⟩, 1 forces it to |1⟩.
Why this comparison is the cleanest definition of entanglement in practice That dependence is precisely what "entangled" buys you and a product state never does: for a product state, measuring one qubit never changes what the other qubit's own state is (Lesson 19's no-signaling theorem, seen concretely at the level of a single-shot calculation rather than as an abstract statistical statement). For an entangled state, measuring one qubit instantly determines what state the other collapses to — even though (as Lesson 19 already proved) this can never be exploited to send Bob a signal, since from Bob's side alone, without knowing Alice's result, his own qubit still just looks maximally random.

Check your recall

No peeking back up — answer from memory first, then check.

1. When measuring one qubit of a two-qubit state and obtaining a specific outcome, what happens to the terms inconsistent with that outcome?

Partial measurement discards every basis term inconsistent with the observed outcome, then rescales the surviving terms so the resulting state is properly normalized.

2. For |Ψ⁺⟩ = (|01⟩ + |10⟩)/√2, if qubit 1 is measured and gives outcome 0, what is qubit 2's resulting state?

Only the |01⟩ term survives outcome 0, so the post-measurement state is |01⟩ = |0⟩ ⊗ |1⟩ — qubit 2 collapses to |1⟩.

3. For a product state |ψ⟩ ⊗ |φ⟩, what happens to qubit 2's state when qubit 1 is measured?

For a product state, the two qubits were never entangled to begin with, so measuring one has zero effect on the other's state — this is exactly the contrast with the entangled-state example above.

4. Fill in the blank: after discarding the terms inconsistent with a measurement outcome, the surviving terms must be ___ so the resulting state is a valid, normalized state again.

Renormalizing (dividing by the square root of the surviving probability) restores the normalization condition, since simply discarding terms leaves less than unit total probability.

5. Fill in the blank: for an entangled state, the resulting state of the unmeasured qubit ___ on which outcome was observed for the measured qubit — unlike for a product state, where it never does.

This outcome-dependence of the other qubit's resulting state is the sharpest concrete signature of entanglement, contrasted directly against the product-state case in this lesson.
