1. What is |1⟩ ⊗ |1⟩ as a column vector?

(0,1)ᵀ ⊗ (0,1)ᵀ = (0·0, 0·1, 1·0, 1·1)ᵀ = (0,0,0,1)ᵀ = |11⟩.

2. Fill in the blank: the state space of 5 qubits has dimension ___.

2⁵ = 32 — each additional qubit doubles the dimension.

3. Which set of coefficients (c₀₀, c₀₁, c₁₀, c₁₁) is validly normalized?

4 × |1/2|² = 4 × 1/4 = 1. The others fail: 3 × 1/4 = 3/4; 1² + 1² = 2; 2 × 1/4 = 1/2 — none equal 1.

4. Which of these is a product state (factorable into two single-qubit states)?

(|00⟩+|01⟩+|10⟩+|11⟩)/2 = |+⟩ ⊗ |+⟩, a clean tensor product. The other three are the entangled Bell states |Φ⁺⟩, |Ψ⁺⟩, and |Ψ⁻⟩.

5. Which Bell state is (|01⟩ − |10⟩)/√2?

|Ψ⁻⟩ = (|01⟩ − |10⟩)/√2 — the minus-sign version built from |01⟩ and |10⟩, as opposed to |00⟩ and |11⟩.

6. Attempting to factor |Ψ⁺⟩ = (|01⟩ + |10⟩)/√2 as (a|0⟩+b|1⟩) ⊗ (c|0⟩+d|1⟩) gives the equations ac = 0, ad = 1/√2, bc = 1/√2, bd = 0. Answer both parts:

(a) What does ad = 1/√2 tell you about a and d?

(b) Fill in the blank: since a ≠ 0, the equation ac = 0 forces c = ___, which then contradicts bc = 1/√2.

(a) A nonzero product requires both factors nonzero. (b) With a ≠ 0, ac = 0 forces c = 0, but then bc = 0 can never equal 1/√2 — no factorization exists, confirming |Ψ⁺⟩ is entangled.

7. For |Ψ⁻⟩ = (|01⟩ − |10⟩)/√2, if qubit 1 is measured and gives outcome 0, what does qubit 2 give with certainty?

Only the |01⟩ term survives outcome 0 for qubit 1, collapsing the state to |01⟩ — qubit 2 is guaranteed to be 1, the opposite of qubit 1's outcome.

8. Bob applies a Z gate to his half of |Φ⁺⟩ before Alice measures her qubit. What is Alice's probability of measuring 0 afterward?

(I⊗Z)|Φ⁺⟩ = (|00⟩−|11⟩)/√2 = |Φ⁻⟩, and Alice's marginal P(0) = |1/√2|² = 1/2 either way — no local operation Bob performs changes Alice's own measurement statistics.

9. For |Ψ⟩ = |+⟩ ⊗ |1⟩ = (|01⟩ + |11⟩)/√2, what is qubit 2's resulting state, regardless of qubit 1's measurement outcome?

Since qubit 2 was never entangled with qubit 1, measuring qubit 1 (either outcome) leaves qubit 2 exactly as it started: |1⟩.

10. For |Φ⁻⟩ = (|00⟩ − |11⟩)/√2, if qubit 1 is measured and gives outcome 1, what is qubit 2's resulting state?

Only the −|11⟩ term survives outcome 1; renormalizing gives −|11⟩/|−1| = −|11⟩, physically the same as |11⟩ (a global phase of −1) — qubit 2 is |1⟩.
