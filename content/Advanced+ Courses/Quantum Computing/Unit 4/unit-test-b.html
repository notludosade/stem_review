1. For |ψ⟩ = (3/5)|0⟩ + (4/5)|1⟩ and |φ⟩ = |0⟩, what is |ψ⟩ ⊗ |φ⟩ as a column vector?

(3/5, 4/5)ᵀ ⊗ (1, 0)ᵀ = (3/5·1, 3/5·0, 4/5·1, 4/5·0)ᵀ = (3/5, 0, 4/5, 0)ᵀ.

2. Fill in the blank: the state space of 6 qubits has dimension ___.

2⁶ = 64.

3. Which set of coefficients (c₀₀, c₀₁, c₁₀, c₁₁) is validly normalized?

3 × |1/√3|² = 3 × 1/3 = 1. The others fail: 3/4 + 1/16 = 13/16; 3 × 1/2 = 3/2; 1² + 1² = 2 — none equal 1.

4. Which of these is a product state (factorable into two single-qubit states)?

(|00⟩+|01⟩)/√2 = |0⟩ ⊗ |+⟩, a clean tensor product. The other three are the entangled Bell states |Ψ⁻⟩, |Φ⁺⟩, and |Φ⁻⟩.

5. Which Bell state is (|00⟩ − |11⟩)/√2?

|Φ⁻⟩ = (|00⟩ − |11⟩)/√2 — the minus-sign version built from |00⟩ and |11⟩, as opposed to |01⟩ and |10⟩.

6. Attempting to factor |Φ⁻⟩ = (|00⟩ − |11⟩)/√2 as (a|0⟩+b|1⟩) ⊗ (c|0⟩+d|1⟩) gives the equations ac = 1/√2, ad = 0, bc = 0, bd = −1/√2. Answer both parts:

(a) What does ac = 1/√2 tell you about a and c?

(b) Fill in the blank: since a ≠ 0, the equation ad = 0 forces d = ___, which then contradicts bd = −1/√2.

(a) A nonzero product requires both factors nonzero. (b) With a ≠ 0, ad = 0 forces d = 0, but then bd = 0 can never equal −1/√2 — no factorization exists, confirming |Φ⁻⟩ is entangled.

7. For |Φ⁻⟩ = (|00⟩ − |11⟩)/√2, if qubit 1 is measured and gives outcome 1, what does qubit 2 give with certainty?

Only the −|11⟩ term survives outcome 1 for qubit 1, collapsing the state to (a global phase times) |11⟩ — qubit 2 is guaranteed to be 1, matching qubit 1's outcome.

8. Bob applies an H gate to his half of |Φ⁺⟩ before Alice measures her qubit. What is Alice's probability of measuring 0 afterward?

(I⊗H)|Φ⁺⟩ = (|00⟩+|01⟩+|10⟩−|11⟩)/2, and Alice's marginal P(0) = |1/2|²+|1/2|² = 1/2 either way — no local operation Bob performs, regardless of which gate, ever changes Alice's own measurement statistics.

9. For |Ψ⟩ = |−⟩ ⊗ |1⟩ = (|01⟩ − |11⟩)/√2, what is qubit 2's resulting state, regardless of qubit 1's measurement outcome?

Since qubit 2 was never entangled with qubit 1, measuring qubit 1 (either outcome) leaves qubit 2 exactly as it started: |1⟩.

10. For |Ψ⁺⟩ = (|01⟩ + |10⟩)/√2, if qubit 1 is measured and gives outcome 1, what is qubit 2's resulting state?

Only the |10⟩ term survives outcome 1 for qubit 1; renormalizing gives |10⟩ — qubit 2 is |0⟩, the opposite of qubit 1's outcome.
