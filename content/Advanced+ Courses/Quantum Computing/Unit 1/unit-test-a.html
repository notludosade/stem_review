1. A register of 4 classical bits has 2⁴ = 16 possible configurations. How does this compare to a system of 4 qubits?

n qubits span a 2ⁿ-dimensional vector space in which the state can carry amplitude along many basis directions simultaneously — unlike n classical bits, which are always in exactly one of 2ⁿ configurations.

2. Fill in the blank: as a column vector, |0⟩ = ___.

|0⟩ is defined as the first standard basis vector of ℂ², (1, 0)ᵀ.

3. For |ψ⟩ = 2i|0⟩ + 3|1⟩, answer both parts:

(a) What is the bra ⟨ψ|?

(b) Fill in the blank: ⟨ψ|ψ⟩ = ___.

(a) Conjugate transpose: conjugating 2i gives −2i, and 3 stays 3, giving the row vector (−2i, 3). (b) ⟨ψ|ψ⟩ = (−2i)(2i) + (3)(3) = −4i² + 9 = 4 + 9 = 13.

4. Which of these is a validly normalized qubit state?

|1/√5|² + |2/√5|² = 1/5 + 4/5 = 1. The others fail: 1/4 + 1/4 = 1/2; 9/25 + 9/25 = 18/25; 1² + 1² = 2 — none equal 1.

5. For |ψ⟩ = α|0⟩ + β|1⟩, under what condition is |ψ⟩ NOT a superposition of |0⟩ and |1⟩?

A superposition requires both amplitudes to be nonzero. If either is exactly 0, the state reduces to just |0⟩ or just |1⟩ — no combination at all.

6. Which pair of states give identical 50/50 measurement probabilities in the computational basis, yet are physically different states?

Both |+⟩ = (|0⟩+|1⟩)/√2 and |−⟩ = (|0⟩−|1⟩)/√2 give |1/√2|² = 1/2 for each outcome, but they differ by a relative phase (the sign on |1⟩) that a different measurement basis can detect.

7. Answer both parts about the Bloch parametrization |ψ⟩ = cos(θ/2)|0⟩ + e^(iφ)sin(θ/2)|1⟩:

(a) What is the allowed range of θ?

(b) Fill in the blank: for θ = 2π/3, cos(θ/2) = ___.

(a) θ ranges over [0, π] (a half-turn), while φ takes the full [0, 2π). (b) θ/2 = π/3, and cos(π/3) = 1/2.

8. |+i⟩ = (|0⟩ + i|1⟩)/√2 and |−i⟩ = (|0⟩ − i|1⟩)/√2 both have equal-weight amplitudes. Where do they sit on the Bloch sphere?

Both are equal-weight superpositions, so both lie on the equator (θ = π/2); the phase factors i = e^(iπ/2) and −i = e^(i3π/2) place them at φ = π/2 and φ = 3π/2, on opposite sides of the equator from each other.

9. Answer both parts:

(a) Are (1/√2)|0⟩ + (1/√2)|1⟩ and −(1/√2)|0⟩ − (1/√2)|1⟩ the same physical state?

(b) Fill in the blank: for any real γ, the magnitude of the global phase factor e^(iγ) is always ___.

(a) Multiplying every term by −1 is a global phase, physically invisible. (b) |e^(iγ)| = 1 always, which is exactly why global phase cancels out of every Born-rule probability.

10. Fill in the blank: a phase factor that multiplies only one component of a state (not the whole vector uniformly) is called a ___ phase, and — unlike global phase — it is physically detectable in the right measurement basis.

Relative phase multiplies different basis components unevenly, so unlike global phase it survives the Born rule's |·|² and can show up in a well-chosen measurement.
