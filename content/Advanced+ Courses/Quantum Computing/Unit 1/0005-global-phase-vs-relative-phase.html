Global Phase vs. Relative Phase

Two different-looking state vectors can be the exact same physical state — and the distinction between the phase that never matters and the phase that always matters closes out this unit's dimension count.

← Lesson 4 Unit 2, Lesson 6 → Contents Glossary →

Lesson 3 counted the valid qubit states as a 3-dimensional surface inside ℂ² ≅ ℝ⁴ (one real normalization constraint cutting a 4-real-dimensional space down by one dimension). Lesson 4's Bloch sphere, however, is only 2-dimensional — a sphere's surface takes just two angles, θ and φ, to specify a point. Something ate one more dimension between Lesson 3 and Lesson 4. This lesson names exactly what.

1. Global phase

Definition — Global Phase Two states |ψ⟩ and eiγ|ψ⟩, for any real number γ, are said to differ by a global phase. eiγ is a complex number of magnitude 1 multiplying the entire state vector, not just one component.
Fact — Global Phase Is Physically Unobservable |ψ⟩ and eiγ|ψ⟩ represent the exact same physical state — no measurement, in any basis, can ever tell them apart.

Here's why. The Born rule (Lesson 11 states this fully; for now, take it as given) says the probability of any measurement outcome associated with basis state |e⟩ is |⟨e|ψ⟩|². Replacing |ψ⟩ with eiγ|ψ⟩ gives ⟨e|(eiγ|ψ⟩) = eiγ⟨e|ψ⟩, and then

|eiγ⟨e|ψ⟩|² = |eiγ|² |⟨e|ψ⟩|² = 1 · |⟨e|ψ⟩|² = |⟨e|ψ⟩|²

— exactly the same probability, for every basis you could choose to measure in, since |eiγ| = 1 always. Global phase is, in a precise sense, information the mathematics carries around that no experiment can ever extract. This is the missing dimension: the 3-dimensional surface of Lesson 3 minus one more dimension for the physically-irrelevant global phase leaves exactly the 2-dimensional Bloch sphere of Lesson 4.

2. Relative phase

Contrast this with the φ that appears inside the Bloch parametrization itself, cos(θ/2)|0⟩ + eiφsin(θ/2)|1⟩. This eiφ multiplies only the |1⟩ component, not the whole vector — it's a relative phase between the two amplitudes, and Lesson 3 already showed it matters:

Fact — Relative Phase Is Physically Meaningful |+⟩ = (|0⟩ + |1⟩)/√2 and |−⟩ = (|0⟩ − |1⟩)/√2 give identical measurement probabilities in the computational (Z) basis — both split 50/50 between outcomes 0 and 1. But they are physically different states: Lesson 13 shows that measuring in a different basis (the X basis, built from |+⟩ and |−⟩ themselves) tells them apart with certainty. A relative phase, unlike a global one, is not swept away by taking |·|² — it survives, and shows up the moment you measure in the right basis or apply the right gate.
Why this distinction is the whole reason interference is possible Global phase drops out of every probability calculation because it multiplies an entire ket uniformly — there's nothing for it to interfere with, since every term picks up the identical factor. Relative phase survives specifically because it multiplies different basis components by different amounts, so when a later gate recombines those components (Unit 2 onward), the relative phases can make terms add constructively or cancel destructively. Every interference effect this course studies — including Unit 6's speedup for Deutsch-Jozsa and Unit 7's Grover's algorithm — is built entirely out of relative phase, never global phase. This is worth remembering as a rule of thumb going forward: if a calculation changes only a global phase, nothing physical happened.
Example |0⟩ and i|0⟩ = eiπ/2|0⟩ are the same physical state (i is a global phase factor here, since it multiplies the state's only nonzero term). But (|0⟩ + i|1⟩)/√2 and (|0⟩ + |1⟩)/√2 are different physical states — the i multiplies only the |1⟩ term, making it a relative phase between the two components, not a global one.

Check your recall

No peeking back up — answer from memory first, then check.

1. Are |1⟩ and −|1⟩ the same physical state?

−1 has magnitude 1 (it's e^(iπ)), and it multiplies the entire state uniformly, so it's a global phase — physically unobservable. −|1⟩ is still normalized: |−1|² = 1.

2. Why can no measurement ever distinguish |ψ⟩ from e^(iγ)|ψ⟩?

Since |e^(iγ)| = 1 for any real γ, multiplying an amplitude by e^(iγ) before squaring its magnitude changes nothing — this holds for every basis, so no measurement in any basis can detect a pure global phase.

3. Which of these is an example of a physically meaningful relative phase, not an unobservable global one?

Only the |+⟩-versus-|−⟩ sign flips the phase of one component (|1⟩) relative to the other (|0⟩) — a relative phase, which changes the physical state. The other options each multiply every term in their state by the same overall factor, which is a global phase and physically invisible.

4. Fill in the blank: an overall factor e^(iγ) multiplying an entire qubit state is called a ___, and it is never physically observable.

Global phase is unobservable precisely because it multiplies every amplitude by the same magnitude-1 factor, which cancels out of every Born-rule probability.

5. Fill in the blank: Lesson 3's 3-dimensional surface of valid states, minus one further dimension for the physically irrelevant global phase, leaves the Bloch sphere's ___-dimensional surface.

Removing the global-phase freedom takes the 3-dimensional normalized-state surface down to the Bloch sphere's 2-dimensional surface, parametrized by θ and φ alone.
