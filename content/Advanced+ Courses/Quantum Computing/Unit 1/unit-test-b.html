1. A register of 3 classical bits has 2³ = 8 possible configurations. How does this compare to a system of 3 qubits?

n qubits span a 2ⁿ-dimensional vector space, letting the state carry amplitude along many basis directions simultaneously — unlike n classical bits, always in exactly one of 2ⁿ configurations.

2. Fill in the blank: as a column vector, |1⟩ = ___.

|1⟩ is defined as the second standard basis vector of ℂ², (0, 1)ᵀ.

3. For |φ⟩ = 3|0⟩ − 4i|1⟩, answer both parts:

(a) What is the bra ⟨φ|?

(b) Fill in the blank: ⟨φ|φ⟩ = ___.

(a) Conjugate transpose: 3 stays 3, and conjugating −4i gives 4i, so ⟨φ| = (3, 4i). (b) ⟨φ|φ⟩ = (3)(3) + (4i)(−4i) = 9 − 16i² = 9 + 16 = 25.

4. Which of these is a validly normalized qubit state?

|4/5|² + |3/5|² = 16/25 + 9/25 = 1. The others fail: 4/9 + 4/9 = 8/9; 1² + 1² = 2; 0.36 + 0.81 = 1.17 — none equal 1.

5. For |ψ⟩ = α|0⟩ + β|1⟩ with α = 0 and β = 1, what is |ψ⟩?

A superposition requires both amplitudes nonzero. With α = 0, the state collapses to exactly |1⟩, which is properly normalized (|0|² + |1|² = 1) but not a combination of both basis states.

6. In the Bloch parametrization at θ = π/2, which value of φ gives |−⟩ = (|0⟩ − |1⟩)/√2?

e^(iπ) = −1, so φ = π gives cos(π/4)|0⟩ + (−1)sin(π/4)|1⟩ = (|0⟩ − |1⟩)/√2 = |−⟩. φ = 0 instead gives |+⟩.

7. Answer both parts about the Bloch parametrization |ψ⟩ = cos(θ/2)|0⟩ + e^(iφ)sin(θ/2)|1⟩:

(a) What is the allowed range of φ?

(b) Fill in the blank: for θ = π/3, sin(θ/2) = ___.

(a) φ ranges over the full [0, 2π), while θ ranges over [0, π]. (b) θ/2 = π/6, and sin(π/6) = 1/2.

8. Which points on the Bloch sphere correspond to the state |0⟩?

At θ = 0, sin(θ/2) = 0, so the e^(iφ) factor multiplies a zero coefficient and never matters — every φ gives the same point, the north pole, representing |0⟩.

9. Answer both parts:

(a) Are |1⟩ and i|1⟩ the same physical state?

(b) Fill in the blank: because global phase never changes any measurement probability, two states differing only by a global phase are considered the ___ physical state.

(a) i has magnitude 1 and multiplies the entire state uniformly, so it's a global phase — physically unobservable. (b) They count as the "same" physical state, since no experiment can ever tell them apart.

10. Fill in the blank: unlike a global phase, a ___ phase multiplies different amplitudes of a state by different amounts, so it survives the Born rule and can be detected by measuring in the right basis.

Relative phase is exactly the phase difference between components that a global phase factor does not produce, since a global phase multiplies every component equally.
