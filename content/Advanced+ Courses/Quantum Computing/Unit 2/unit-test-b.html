1. Is M = [[1, 0], [1, 0]] a valid quantum gate?

M is real, so M† = Mᵀ = [[1,1],[0,0]]. Computing MᵀM gives [[2,0],[0,0]], not the identity — M fails the unitarity test.

2. A classical AND gate cannot be undone from its output alone. Why doesn't this problem affect quantum gates?

Every unitary matrix has an inverse (its own conjugate transpose), so unlike classical AND, a quantum gate can never destroy information — the input state can always be recovered by applying the inverse gate.

3. What is X|0⟩?

X = [[0,1],[1,0]] swaps the two basis states, so X|0⟩ = |1⟩.

4. For |ψ⟩ = (5/13)|0⟩ + (12/13)|1⟩, answer both parts about Z|ψ⟩:

(a) What does Z do to the |1⟩ component?

(b) Fill in the blank: Z|ψ⟩ = (5/13)|0⟩ + (___)|1⟩.

(a) Z multiplies the |1⟩ amplitude by −1. (b) So the new |1⟩ coefficient is −12/13, while |0⟩'s coefficient (5/13) is untouched.

5. What is Y|1⟩?

Y = [[0,−i],[i,0]] applied to (0,1)ᵀ gives (−i, 0)ᵀ = −i|0⟩.

6. Fill in the blank: applying any single Pauli gate (X, Y, or Z) to a state twice in a row always returns the original state — the smallest positive number of applications that guarantees this, for every Pauli gate, is ___.

Every Pauli gate satisfies P² = I, so exactly 2 applications always return the original state.

7. Answer both parts about the Hadamard gate:

(a) What is H|0⟩?

(b) Fill in the blank: measuring H|0⟩ in the computational basis gives outcome 1 with probability ___.

(a) H|0⟩ = |+⟩. (b) |+⟩ = (|0⟩ + |1⟩)/√2 gives |1/√2|² = 1/2 probability for each outcome.

8. For any valid single-qubit state |ψ⟩, what is H(H|ψ⟩)?

H² = I for every input, so applying H twice to any state returns exactly that state, unchanged.

9. Answer both parts:

(a) What is S², the S gate applied twice?

(b) Fill in the blank: T² = ___.

(a) S = R_(π/2), so S² = R_π = Z. (b) T = R_(π/4), so T² = R_(π/2) = S.

10. What is the final physical state of the circuit |0⟩ → X → S → measure?

X|0⟩ = |1⟩, then S|1⟩ = i|1⟩. Since i multiplies the entire (single-term) state, it's a global phase — i|1⟩ and |1⟩ are the same physical state, exactly Unit 1's global-phase lesson applied here.
