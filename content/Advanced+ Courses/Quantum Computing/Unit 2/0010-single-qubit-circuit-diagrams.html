Single-Qubit Circuit Diagrams

A quantum circuit reads left to right like a sentence, but computes right to left like a matrix product — mixing up that order is the single most common bug in reading a diagram correctly.

← Lesson 9 Unit 3, Lesson 11 → Contents Glossary →

Units 5 through 7 will draw and reason about circuits constantly. This closing lesson of Unit 2 gets the notation and the one crucial reading rule in place, using only the single-qubit gates already in hand.

1. Reading a circuit diagram

Convention — Circuit Diagrams A horizontal line is a wire, representing one qubit as time moves left to right. A labeled box on the wire is a gate, applied to the qubit's current state at that point in time. Time flows strictly left to right — a gate drawn earlier on the wire is applied before one drawn later.

2. The order-reversal rule

Why circuit order and matrix order run opposite directions If a circuit applies gate A, then gate B, then gate C, reading left to right, the resulting state is C(B(A|ψ⟩)) — which, written as a single matrix product, is CBA|ψ⟩, not ABC|ψ⟩. The gate applied first (leftmost in the diagram) ends up rightmost in the matrix product, right next to |ψ⟩, because matrix-vector multiplication is evaluated by acting on the vector first with the matrix closest to it. This reversal trips up almost everyone the first few times — it's worth deliberately double-checking on every new circuit until reading it becomes automatic.
Example — Tracing the Circuit Above The circuit shown applies H first, then S, to |0⟩. Step by step: H|0⟩ = |+⟩ = (1/√2)(|0⟩ + |1⟩). Then S|+⟩ = (1/√2)(S|0⟩ + S|1⟩) = (1/√2)(|0⟩ + i|1⟩) = |+i⟩, Unit 1's fourth named Bloch-sphere landmark. As a single matrix expression, this whole circuit computes S·H·|0⟩ — S written first (leftmost) even though H is applied first (drawn leftmost in the diagram), exactly the reversal the box above describes.

3. A second worked trace

Circuit: |0⟩ → X → H → measure. Trace it gate by gate, left to right, exactly as time flows: X|0⟩ = |1⟩ (Lesson 7's bit flip). Then H|1⟩ = |−⟩ (Lesson 8). The final state is |−⟩ — measuring it in the computational basis gives 0 or 1 with equal probability, same as measuring |+⟩ would, but Lesson 13 will show these two states are still distinguishable with the right choice of measurement basis.

Check your recall

No peeking back up — answer from memory first, then check.

1. A circuit applies gate A, then gate B, then gate C, in that left-to-right order. What single matrix expression gives the final state?

The gate applied first ends up closest to |ψ⟩ in the matrix product, so left-to-right circuit order becomes right-to-left matrix order: CBA|ψ⟩.

2. What is the final state of the circuit |0⟩ → X → H → measure?

X|0⟩ = |1⟩ first, then H|1⟩ = |−⟩ — trace the gates in the order they're applied (left to right in the diagram), not in matrix-product order.

3. What is the final state of the circuit |0⟩ → H → S → measure?

H|0⟩ = |+⟩, then S|+⟩ = (1/√2)(|0⟩ + i|1⟩) = |+i⟩ — the worked example traced through this exact circuit.

4. Fill in the blank: time flows ___ across a circuit diagram, even though the matrix product representing the whole circuit is written in the opposite order.

Circuit diagrams are always read left to right for time order — it's only the corresponding matrix product that reverses this order.

5. Fill in the blank: after applying H then S to |0⟩, the probability of measuring outcome 1 is ___.

The resulting state is |+i⟩ = (|0⟩ + i|1⟩)/√2, and |i/√2|² = 1/2 — S only changes phase, never the measurement probabilities set by H.
