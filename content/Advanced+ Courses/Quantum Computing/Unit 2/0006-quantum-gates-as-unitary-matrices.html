Quantum Gates as Unitary Matrices

A quantum gate is just a matrix-vector product — but not every matrix is allowed to be one, and the restriction that qualifies a matrix is exactly the property Linear Algebra B called unitary.

← Lesson 5 Lesson 7 → Contents Glossary →

Unit 1 built up the space of single-qubit states. This unit starts moving through that space: a quantum gate transforms one qubit state into another. Unlike classical logic gates, which are built from truth tables, a quantum gate is defined the same way any linear map was defined in Linear Algebra A — as a matrix acting on a vector.

1. Gates as matrices

Definition — Single-Qubit Gate A single-qubit gate is a 2 × 2 matrix U acting on a state vector by left multiplication: |ψ'⟩ = U|ψ⟩. Applying a gate to a state produces a new state.

Not every 2 × 2 matrix is allowed to be a gate, though. Whatever U is, it has to send every valid (normalized) input state to another valid (normalized) output state — a gate can't be allowed to produce a state that violates Lesson 1.3's normalization condition. That single requirement turns out to force a very specific structure on U.

2. The unitary requirement

Definition — Unitary Matrix A matrix U is unitary if U†U = I, where U† is the conjugate transpose (Lesson 1.2's bra construction, applied to a whole matrix instead of a vector) and I is the identity matrix. Equivalently, U's inverse exists and equals its conjugate transpose: U⁻¹ = U†.
Fact — Every Quantum Gate Is Unitary U preserves normalization for every input state if and only if U is unitary. Proof: for any normalized |ψ⟩, the output |ψ'⟩ = U|ψ⟩ is normalized exactly when ⟨ψ'|ψ'⟩ = 1. Compute ⟨ψ'|ψ'⟩ = (U|ψ⟩)†(U|ψ⟩) = ⟨ψ|U†U|ψ⟩. If U†U = I, this is ⟨ψ|ψ⟩ = 1, as required. (The converse — that this working for every |ψ⟩ forces U†U = I exactly — is a short additional argument this course won't belabor, but it's the reason "unitary" is exactly the right condition, not just a sufficient one.)
Example — Checking Unitarity Is U = [[0, 1], [1, 0]] unitary? Since U is real, U† is just its transpose, which is U itself here (it's symmetric). Compute U†U = U·U = [[0,1],[1,0]]·[[0,1],[1,0]] = [[1,0],[0,1]] = I. Yes, unitary — this particular matrix will get its own name next lesson.

3. Reversibility: the payoff of unitarity

Why quantum gates are always reversible, unlike classical logic gates Because U⁻¹ = U† always exists for a unitary U, every quantum gate can be undone — apply U†, and you're back exactly where you started, with no information lost. Compare this to a classical AND gate: knowing the output bit 0 doesn't tell you whether the inputs were (0,0), (0,1), or (1,0) — information was destroyed, and AND has no inverse function. A classical gate that is reversible, like NOT (flip the bit, and flipping again undoes it), has a natural quantum analogue — Lesson 7's X gate is exactly the quantum NOT. But a gate like AND, which loses information, cannot be directly realized as a single-qubit (or even simple multi-qubit) unitary gate at all — building reversible versions of classical logic takes real work, which Unit 5's Toffoli gate addresses.

The identity gate I = [[1, 0], [0, 1]] is the trivial case: I|ψ⟩ = |ψ⟩, doing nothing at all. It's unitary (I†I = I·I = I) and it's its own inverse — the "do nothing" gate every circuit implicitly starts from.

Check your recall

No peeking back up — answer from memory first, then check.

1. What property must a 2 × 2 matrix U have to be a valid single-qubit quantum gate?

Unitarity, U†U = I, is exactly the condition that guarantees U sends every normalized input state to a normalized output state.

2. Why does every quantum gate have to be reversible?

Unitarity directly supplies an inverse, U† — applying it after U restores the original state exactly, with no information lost along the way.

3. Is U = [[1, 1], [0, 1]] unitary?

U's transpose (it's real, so U† = Uᵀ) is [[1,0],[1,1]]. Multiplying U†U gives [[1,1],[1,2]], which is not the identity matrix — U is not unitary, and could not be a valid quantum gate (it would fail to preserve normalization on some input state).

4. Fill in the blank: a matrix U is unitary exactly when U†U = ___.

Unitarity is defined by U†U equaling the identity matrix I — equivalently, U's inverse is its own conjugate transpose.

5. Fill in the blank: for a unitary matrix U, the inverse U⁻¹ is always equal to ___.

U⁻¹ = U† is exactly what unitarity guarantees — the inverse is always just the conjugate transpose, with no separate computation needed.
