The Basic Idea of Quantum Error Correction

Classical error correction copies a bit and takes a majority vote. Lesson 15's no-cloning theorem forbids the quantum version of that trick outright — and yet quantum error correction exists, and works. This lesson shows how.

← Lesson 36 Lesson 38 → Contents Glossary →

A classical repetition code protects 1 bit by storing 3 copies and taking a majority vote if noise flips one of them. Two facts from earlier in this course seem to rule out the direct quantum analogue: Lesson 15's no-cloning theorem (you can't copy an unknown state), and Lesson 12's collapse (measuring a qubit to "check" it destroys its superposition). Quantum error correction works around both, and the way it does is worth understanding precisely.

1. The 3-qubit bit-flip code

Encoding Encode a single logical qubit α|0⟩ + β|1⟩ into 3 physical qubits: |0⟩L = |000⟩, |1⟩L = |111⟩, so α|0⟩ + β|1⟩ becomes α|000⟩ + β|111⟩. This is built with two CNOT gates (Lesson 21) from the original qubit as control, copying its classical basis label — not the unknown amplitudes α, β themselves — onto two fresh |0⟩ qubits. No-cloning is not violated: the state α|000⟩+β|111⟩ is entangled across three qubits, not three independent copies of α|0⟩+β|1⟩.

2. Detecting an error without learning α or β

Fact — Syndrome Measurement Suppose noise flips exactly one physical qubit (say qubit 2), turning α|000⟩+β|111⟩ into α|010⟩+β|101⟩. Using two extra ancilla qubits, measure only the parities q₁⊕q₂ and q₂⊕q₃ (via CNOTs from the data qubits into the ancillas, then measuring only the ancillas) — never measuring q₁, q₂, or q₃ directly.
Why This Doesn't Collapse α or β Check both branches of the superposition against the parity q₁⊕q₂: for |010⟩, it's 0⊕1 = 1; for |101⟩, it's 1⊕0 = 1. Both branches give the same parity value, regardless of α and β. The same holds for q₂⊕q₃: 1⊕0 = 1 for |010⟩, and 0⊕1 = 1 for |101⟩ — again identical across both branches. Because every branch of the logical superposition agrees on the syndrome, measuring it reveals only which qubit flipped (here: syndrome (1,1) means qubit 2), with zero effect on the relative amplitudes α and β. The encoded information survives completely untouched.

Once the syndrome identifies qubit 2 as the flipped one, applying X to qubit 2 restores α|000⟩+β|111⟩ exactly — the original logical state, fully recovered, with α and β never once revealed or disturbed. The full syndrome table for this code: (0,0) means no error, (1,0) means qubit 1 flipped, (1,1) means qubit 2 flipped, (0,1) means qubit 3 flipped — each single-qubit flip produces its own unique, unambiguous syndrome.

3. Scaling up: real codes

Vocabulary — Logical vs. Physical Qubits A physical qubit is an actual hardware qubit, subject to Lesson 36's noise. A logical qubit is the error-protected qubit encoded across several physical qubits, behaving (as long as errors stay below the code's correction capacity) like an ideal, noiseless qubit for the purposes of running an algorithm.

The 3-qubit code above only protects against bit-flip (X) errors, not phase-flip (Z) errors. Peter Shor's 9-qubit code nests the bit-flip code together with an analogous phase-flip code to protect against both simultaneously — the first quantum error-correcting code ever discovered. Modern hardware mostly uses surface codes instead: a 2D grid arrangement of physical qubits whose connectivity requirements match real chip layouts far better than the abstract 9-qubit construction, currently the leading practical approach for large-scale error correction.

Why error correction can, in principle, make arbitrarily long computation possible The fault-tolerance threshold theorem states, roughly: if the physical error rate per gate is below some fixed threshold, then encoding a computation with enough error-correction overhead (larger codes, more physical qubits per logical qubit) can suppress the logical error rate as low as desired, making arbitrarily long, reliable quantum computation possible in principle. This is the theoretical basis for believing Shor's algorithm at real cryptographic scale is eventually achievable — not a hope, but a proven result, conditional on physical error rates being pushed below the threshold. Lesson 39 looks at how close today's hardware actually is to that threshold.

Check your recall

No peeking back up — answer from memory first, then check.

1. Why can't quantum error correction simply make several independent copies of a qubit, the way a classical repetition code does?

Lesson 15's no-cloning theorem directly rules out producing independent copies of an unknown state — the encoding above works around this by entangling, not copying.

2. Why can't quantum error correction just directly measure each physical qubit to check for errors?

Directly measuring q₁, q₂, or q₃ would collapse them to definite values, destroying the superposition that encodes α and β — syndrome measurement via ancillas avoids exactly this.

3. In the 3-qubit bit-flip code, a syndrome measurement returns (1, 0). Which physical qubit needs correcting?

The syndrome table gives (0,0) for no error, (1,0) for qubit 1, (1,1) for qubit 2, and (0,1) for qubit 3 — (1,0) uniquely identifies qubit 1 as the flipped one.

4. Fill in the blank: a single error-protected qubit, encoded across several physical qubits, is called a ___ qubit.

A logical qubit behaves like an ideal, noiseless qubit as long as errors stay within the code's correction capacity, built from multiple underlying physical qubits.

5. Fill in the blank: the modern, hardware-practical family of quantum error-correcting codes currently leading real large-scale efforts (used by IBM, Google, and others) is called ___.

Surface codes arrange physical qubits in a 2D grid whose connectivity matches real chip layouts far better than earlier, more abstract constructions like the 9-qubit code.
