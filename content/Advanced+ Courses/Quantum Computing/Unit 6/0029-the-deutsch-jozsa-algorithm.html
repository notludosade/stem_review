The Deutsch-Jozsa Algorithm

Lesson 28's exact circuit, scaled up to n input bits — and the "2 versus 1" query gap turns into "exponential versus 1."

← Lesson 28 Lesson 30 → Contents Glossary →

The Deutsch-Jozsa algorithm, developed by David Deutsch and Richard Jozsa, generalizes Lesson 28's circuit to any number of input bits, with essentially no new ideas — the same H, oracle, H structure, just wider.

1. The generalized problem

Problem — Deutsch-Jozsa Given oracle access to f: {0,1}ⁿ → {0,1}, promised to be either constant (same output on all 2ⁿ inputs) or balanced (output 0 on exactly half the inputs, output 1 on the other half), determine which.

Classically, in the worst case, a deterministic algorithm needs to query more than half the inputs — 2ⁿ⁻¹ + 1 queries — to be certain: after seeing 2ⁿ⁻¹ identical outputs, the function could still turn out either constant (if the rest match too) or balanced (if the rest are all the other value), so one more query is unavoidable.

2. The circuit, generalized

Circuit Start with |0⟩⊗n ⊗ |1⟩. Apply H to every qubit (H⊗n on the first register, H on the second). Apply Uf. Apply H⊗n to the first register again. Measure the first register.

After H⊗n and Uf, phase kickback (Lesson 27, applied term by term across the whole superposition) gives (1/√2ⁿ) Σx (−1)f(x)|x⟩ ⊗ |−⟩, dropping the now-irrelevant |−⟩. The key fact needed for the final H⊗n is that it transforms |x⟩ into (1/√2ⁿ) Σz (−1)x·z|z⟩, where x·z is the bitwise dot product of x and z mod 2 — the direct n-qubit generalization of single-qubit H's action.

3. The amplitude on the all-zero string

Fact — What Determines the Outcome After the final H⊗n, the amplitude on the all-zero string |00...0⟩ works out to (1/2ⁿ) Σx (−1)f(x) (since x·0 = 0 for every x). If f is constant (value c on every input): this sum is (1/2ⁿ)(2ⁿ)(−1)c = (−1)c, magnitude 1 — the all-zero string is measured with certainty. If f is balanced: exactly half the terms contribute +1 and half contribute −1, so the sum is (1/2ⁿ)[2ⁿ⁻¹ − 2ⁿ⁻¹] = 0 — the all-zero string is measured with probability exactly 0.
Result Measure all n qubits of the first register after the circuit. All-zero result: f is constant, with certainty. Any other result (any nonzero string): f is balanced, with certainty. Either way, one query to Uf — regardless of how large n is — settles the question completely.
Why this is an exponential, not just constant, speedup The classical worst case, 2ⁿ⁻¹ + 1 queries, grows exponentially with n. The quantum algorithm's query count — exactly 1 — never grows at all. For n = 20 input bits, a classical deterministic algorithm might need over half a million queries in the worst case; Deutsch-Jozsa still needs exactly one. This is a genuinely exponential separation between quantum and classical query complexity, not merely the "cut in half" flavor of Lesson 28's n = 1 warm-up — the gap widens without bound as the problem grows.

Check your recall

1. What does measuring the all-zero string at the end of the Deutsch-Jozsa circuit indicate?

Measuring all zeros occurs with certainty exactly when f is constant — the amplitude on that outcome is 0 whenever f is balanced.

2. What does measuring any nonzero string at the end of the circuit indicate?

Since the all-zero outcome has probability exactly 1 when f is constant, seeing any other outcome guarantees f must be balanced instead.

3. Why does the classical worst-case query count grow exponentially with n, while the quantum count stays at 1?

The classical lower bound genuinely scales as 2ⁿ⁻¹ + 1, while the quantum circuit's single query and interference-based measurement give a certain answer regardless of n — a real, provable exponential gap.

4. Fill in the blank: regardless of how large n is, the Deutsch-Jozsa algorithm always needs exactly ___ oracle query.

One query to U_f, combined with the surrounding Hadamard layers, is always sufficient, no matter how many input bits f takes.

5. Fill in the blank: when f is balanced, the probability of measuring the all-zero string is exactly ___.

The +1 and −1 contributions from a balanced f's inputs cancel exactly, leaving zero amplitude — and hence zero probability — on the all-zero outcome.
