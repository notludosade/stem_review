1. If f(x) = 1, what does Uf|x⟩|0⟩ equal?

U_f|x⟩|y⟩ = |x⟩|y⊕f(x)⟩; with y = 0 and f(x) = 1, y⊕f(x) = 0⊕1 = 1, giving |x⟩|1⟩.

2. Applying H⊗n to n zero qubits, then Uf, produces which state (up to the normalization factor)?

A single oracle query, applied to the full 2ⁿ-term superposition created by H^⊗n, evaluates f at every one of the 2ⁿ inputs simultaneously.

3. Answer both parts about phase kickback:

(a) Which single-qubit gate, applied to |1⟩, produces the target state needed for phase kickback?

(b) Fill in the blank: for f(x) = 1, Uf|x⟩|−⟩ = (___)|x⟩|−⟩.

(a) H|1⟩ = |−⟩, exactly the state phase kickback requires. (b) (−1)^f(x) with f(x) = 1 gives (−1)¹ = −1.

4. What role does interference play that quantum parallelism alone does not provide?

Interference is what lets amplitudes from different branches reinforce or cancel before measurement, turning otherwise-inaccessible parallel information into a usable measurement outcome.

5. What is the classical deterministic worst-case query count for the n-bit Deutsch-Jozsa problem, as a function of n?

After seeing 2ⁿ⁻¹ identical outputs, f could still be either constant or balanced, so one more query — 2ⁿ⁻¹ + 1 total — is always required for certainty.

6. In Deutsch's algorithm, measuring the first qubit and obtaining outcome 1 indicates that f is:

Outcome 1 occurs with certainty exactly when f is balanced, complementing outcome 0's certain occurrence when f is constant.

7. Fill in the blank: f outputting the exact same value on every one of its 2ⁿ inputs is called ___.

Constant is the other half of the Deutsch-Jozsa promise, contrasted with balanced.

8. When f is constant, what is the probability of measuring the all-zero string at the end of the Deutsch-Jozsa circuit?

When f is constant, every term in the sum contributes the same sign, giving an amplitude of magnitude 1 on the all-zero string — probability 1, regardless of n.

9. Two algorithms solve the same problem, one using 3 oracle queries plus a large amount of other computation, the other using 100 oracle queries plus very little other computation. Which has lower query complexity?

Query complexity is defined purely by oracle call count — 3 is lower than 100, regardless of how much other computation either algorithm performs.

10. Which statement accurately describes the status of the Deutsch-Jozsa exponential query-complexity separation?

Unlike many famous complexity-theory claims, the Deutsch-Jozsa separation is a fully proven mathematical result within the oracle model, independent of any unresolved conjecture.
