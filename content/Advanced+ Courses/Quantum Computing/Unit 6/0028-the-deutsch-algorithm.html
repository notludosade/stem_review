The Deutsch Algorithm: A One-Qubit Warm-Up

The smallest possible quantum algorithm that provably beats every classical approach — three gates, one query, and a guaranteed correct answer every single time.

← Lesson 27 Lesson 29 → Contents Glossary →

Lesson 26 built the state; Lesson 27 gave it phase kickback. This lesson closes the loop with one more Hadamard, producing Deutsch's algorithm — historically the first quantum algorithm ever shown to provably outperform any classical algorithm, on a task simple enough to trace completely by hand.

1. The problem

Problem — Constant or Balanced? Given oracle access to f: {0,1} → {0,1}, determine whether f is constant (f(0) = f(1)) or balanced (f(0) ≠ f(1)).
Why this needs 2 queries classically Knowing only f(0) tells you nothing about whether f is constant or balanced — f(1) could still be either value. The same goes for knowing only f(1). Any classical algorithm that always gives the correct answer, no matter what f turns out to be, must query both f(0) and f(1): 2 queries, no way around it.

2. The circuit

Circuit — Deutsch's Algorithm Start with |0⟩ ⊗ |1⟩. Apply H to both qubits. Apply Uf (phase kickback, since the second qubit is now |−⟩). Apply H to the first qubit. Measure the first qubit.

3. The full trace

Trace Start: |0⟩|1⟩. After H⊗H: |+⟩|−⟩. After Uf (Lesson 27's result): [(−1)f(0)|0⟩ + (−1)f(1)|1⟩]/√2 ⊗ |−⟩. Now split into cases for the first qubit's state (dropping the |−⟩, which plays no further role):

If f is constant (f(0) = f(1) = c): the first qubit's state is (−1)c[|0⟩+|1⟩]/√2 = (−1)c|+⟩. Applying H: (−1)cH|+⟩ = (−1)c|0⟩ — physically just |0⟩ (a global phase). Measuring gives 0, with certainty.

If f is balanced (f(0) ≠ f(1)): the first qubit's state is ±[|0⟩−|1⟩]/√2 = ±|−⟩ (the sign depends on which of f(0), f(1) is 0). Applying H: ±H|−⟩ = ±|1⟩ — physically just |1⟩. Measuring gives 1, with certainty.

Result Measuring outcome 0 means f is constant. Measuring outcome 1 means f is balanced. The answer is certain, not probabilistic — and it took exactly one query to Uf, half of the two queries any classical algorithm needs.
Why this small example matters more than its size suggests The speedup here — 2 classical queries down to 1 quantum query — looks modest. Its real significance is that it's a clean, fully worked, provable example that quantum interference (not randomness, not luck) can extract a global property of a function using strictly fewer oracle queries than any classical strategy ever could, guaranteed. Lesson 29 generalizes this exact circuit — same three ingredients, H then oracle then H — to n input bits, where the classical-versus-quantum query gap becomes exponential instead of just "2 versus 1."

Check your recall

No peeking back up — answer from memory first, then check.

1. What does Deutsch's algorithm determine about f?

The algorithm answers a global question about f — constant versus balanced — without ever revealing the individual values f(0) or f(1) themselves.

2. How many oracle queries does any classical algorithm need to determine constant-versus-balanced with certainty?

Knowing only one of f(0) or f(1) leaves the other value — and hence constant-versus-balanced — completely undetermined, so both must be checked classically.

3. How many oracle queries does Deutsch's algorithm need?

A single application of U_f, combined with the surrounding Hadamard gates, is enough to determine constant-versus-balanced with certainty.

4. Fill in the blank: measuring the first qubit and getting outcome 0 at the end of Deutsch's circuit means f is ___.

Outcome 0 corresponds to (−1)^c|0⟩ in the trace — occurring exactly when f is constant.

5. Fill in the blank: measuring the first qubit and getting outcome 1 at the end of Deutsch's circuit means f is ___.

Outcome 1 corresponds to ±|1⟩ in the trace — occurring exactly when f is balanced.
