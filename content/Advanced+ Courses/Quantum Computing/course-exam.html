1. Which of these is a validly normalized qubit state?

|5/13|² + |12/13|² = 25/169 + 144/169 = 169/169 = 1. The others fail: 1/4+1/4=1/2; 1²+1²=2; 4/9+4/9=8/9.

2. Fill in the blank: at the north pole of the Bloch sphere (θ = 0), the state |0⟩ is measured in the computational basis with probability ___.

θ = 0 gives |ψ⟩ = |0⟩ exactly, so measuring in the computational basis returns 0 with certainty.

3. Are −(|0⟩ + |1⟩)/√2 and (|0⟩ + |1⟩)/√2 the same physical state?

−1 = e^(iπ) multiplies the entire state uniformly, making it a global phase — physically unobservable, unlike a relative phase between individual amplitudes.

4. What is H|1⟩?

H(0,1)ᵀ = (1/√2)(1,−1)ᵀ = |−⟩.

5. Fill in the blank: for any Pauli gate P (X, Y, or Z), P² = ___.

Every Pauli gate is its own inverse — applying it twice always returns the identity matrix.

6. A circuit applies gate A, then B, then C, left to right. Which matrix expression gives the final state?

Circuit order (left to right, chronological) reverses into matrix order (right to left) — the gate applied first sits closest to |ψ⟩.

7. For |ψ⟩ = (1/2)|0⟩ + (√3/2)|1⟩, what is P(1)?

P(1) = |√3/2|² = 3/4.

8. Fill in the blank: after a qubit is measured and gives outcome 1, measuring it again immediately (same basis) gives outcome 1 with probability ___.

The qubit has already collapsed to |1⟩, so a second same-basis measurement returns 1 with certainty.

9. What does the no-cloning theorem prove?

The theorem specifically rules out a universal cloning device for arbitrary unknown states — orthogonal states (like classical bit values) remain copyable.

10. Why can |Φ⁺⟩ = (|00⟩ + |11⟩)/√2 not be written as (a|0⟩+b|1⟩) ⊗ (c|0⟩+d|1⟩)?

The coefficient-matching contradiction is exactly the proof that |Φ⁺⟩ is entangled — no product-state factorization exists.

11. Fill in the blank: the state space of 4 qubits has dimension ___.

2⁴ = 16 — each additional qubit doubles the dimension.

12. Why can't entanglement be used to send information faster than light?

The no-signaling theorem guarantees local operations never change the other party's own marginal statistics — correlations only become visible after comparing results via ordinary classical communication.

13. What is CNOT|10⟩ (control = 1, target = 0)?

With control = 1, CNOT flips the target from 0 to 1, giving |11⟩.

14. Fill in the blank: the standard three-gate universal set for quantum computing is {H, ___, CNOT}.

T, combined with H, densely approximates any single-qubit rotation, while CNOT supplies the necessary entangling power.

15. Applying CNOT to a superposed control, (α|0⟩+β|1⟩) ⊗ |0⟩, produces which state?

The target flips exactly on the |1⟩ branch, correlating it with the control and producing an entangled state.

16. In the Deutsch-Jozsa circuit, measuring any nonzero string in the first register indicates:

The all-zero string has probability exactly 1 when f is constant and exactly 0 when f is balanced — so any nonzero outcome guarantees balanced.

17. Fill in the blank: regardless of how large n is, the Deutsch-Jozsa algorithm always needs exactly ___ oracle query.

One query, combined with the surrounding Hadamard layers and interference, is always sufficient.

18. What is the purpose of preparing the oracle's target qubit in state |−⟩ before applying Uf?

This is phase kickback — the key trick that makes f's output available to later interference instead of being lost to measurement collapse.

19. Grover's algorithm achieves what kind of speedup over classical unstructured search?

Grover's O(√N) queries versus the classical O(N) is a quadratic gap, provably optimal by the BBBT lower bound.

20. Fill in the blank: Shor's algorithm efficiently solves the problem of integer ___.

Shor's algorithm factors large composite integers exponentially faster than any known classical algorithm.

21. What assumption does RSA's security rest on that Shor's algorithm directly threatens?

RSA's public key includes a large composite N, and its security rests entirely on factoring N being classically infeasible.

22. What is decoherence?

Decoherence is specifically unwanted environmental interaction degrading quantum information over time — not an intentional operation, and distinct from a deliberate measurement.

23. Fill in the blank: NISQ stands for ___.

Noisy Intermediate-Scale Quantum, coined by John Preskill, describes the current era of quantum hardware.

24. In the 3-qubit bit-flip code, why does syndrome measurement (via parity-checking ancillas) not collapse the encoded logical amplitudes α and β?

Because both branches of α|000⟩+β|111⟩ (and their error-shifted versions) always agree on the parity outcome for a given error location, the ancilla measurement extracts only error-location information, leaving α and β completely undisturbed.
