Unit 1 — Qubits & Superposition

Qubit

A two-level quantum system whose state is a vector in a two-dimensional complex vector space, capable of superposition — unlike a classical bit, which is always definitely 0 or definitely 1.

Ket

Dirac notation for a column vector representing a quantum state, written |ψ⟩ — |0⟩ and |1⟩ are the computational basis kets.

Bra

The conjugate transpose of a ket, written ⟨ψ|, a row vector used to compute inner products ⟨φ|ψ⟩.

Superposition

A qubit state α|0⟩ + β|1⟩ with both α and β nonzero — a genuine combination of both basis states, not classical uncertainty about a pre-existing value.

Normalization

The requirement |α|² + |β|² = 1 on a qubit state's amplitudes, matching the requirement that measurement probabilities sum to 1.

Bloch Sphere

A geometric picture of every single-qubit pure state as a point on the surface of a unit sphere, parametrized by angles θ and φ, once global phase is set aside.

Global Phase

An overall factor e^(iγ) multiplying an entire state vector — physically unobservable, since it cancels out of every Born-rule probability.

Relative Phase

A phase factor that multiplies only one component of a state, not the whole vector — unlike global phase, it is physically detectable in the right measurement basis.

Unit 2 — Quantum Gates I

Quantum Gate

A unitary matrix that transforms one qubit state into another; always reversible, since U⁻¹ = U† exists for every unitary U.

Unitary Matrix

A matrix U satisfying U†U = I — exactly the condition that guarantees a gate preserves normalization on every input state.

Pauli Gates (X, Y, Z)

The three single-qubit gates X (bit flip), Y (bit and phase flip combined), and Z (phase flip) — each its own inverse, and each a 180° Bloch-sphere rotation about its own axis.

Hadamard Gate

H = (1/√2)[[1,1],[1,−1]], the standard gate for turning a basis state into an equal-weight superposition; H|0⟩ = |+⟩ and H|1⟩ = |−⟩.

Phase Gate

A gate Rφ that leaves |0⟩ unchanged and multiplies |1⟩'s amplitude by e^(iφ); S and T are the specific cases φ = π/2 and φ = π/4.

Circuit Diagram

A left-to-right depiction of gates applied to qubit wires over time — read chronologically left to right, but written as a matrix product in the reverse order.

Unit 3 — Measurement & Probability

Born Rule

The postulate that measuring |ψ⟩ in basis {|eᵢ⟩} gives outcome i with probability |⟨eᵢ|ψ⟩|².

Measurement Collapse

The postulate that a qubit's state instantaneously becomes the corresponding basis state |i⟩ the moment a measurement returns outcome i, discarding all other amplitude information.

Expectation Value

⟨A⟩ = ⟨ψ|A|ψ⟩ for a Hermitian observable A — the probability-weighted average measurement outcome, computed directly from the state vector.

Hermitian Operator

A matrix A satisfying A† = A; its eigenvalues are always real, letting them represent physically measurable outcomes.

No-Cloning Theorem

No unitary operation can copy an arbitrary, unknown quantum state onto a blank qubit for every possible input state — proved directly from unitarity's inner-product preservation.

Unit 4 — Multi-Qubit Systems & Entanglement

Tensor Product

The operation ⊗ combining two qubit states into one joint state in a larger vector space; n qubits together span a 2ⁿ-dimensional space.

Product State

A multi-qubit state that can be written as |ψ⟩ ⊗ |φ⟩ for some single-qubit states — the non-entangled special case.

Entangled State

A multi-qubit state that cannot be written as a tensor product of individual single-qubit states.

Bell State

One of the four maximally entangled two-qubit states |Φ⁺⟩, |Φ⁻⟩, |Ψ⁺⟩, |Ψ⁻⟩, forming an alternative orthonormal basis to the computational basis.

No-Signaling Theorem

No local operation performed on one half of an entangled pair ever changes the other party's own measurement statistics — why entanglement cannot transmit information faster than light.

Hidden Variables

A hypothetical fixed, pre-agreed classical explanation for entangled correlations, ruled out by Bell's theorem — entangled correlations are provably stronger than any such classical model could produce.

Unit 5 — Quantum Gates II

CNOT Gate

A two-qubit gate that flips its target qubit if and only if its control qubit is |1⟩ — the standard gate for turning superposition into entanglement.

CZ Gate

A two-qubit gate that multiplies |11⟩'s amplitude by −1 and leaves every other basis state unchanged; symmetric between its two qubits.

SWAP Gate

A two-qubit gate that exchanges the states of its two qubits entirely; buildable from three alternating CNOT gates.

Toffoli Gate

A three-qubit gate (CCNOT) that flips its target iff both of its control qubits are |1⟩ — a reversible quantum implementation of classical AND.

Universal Gate Set

A set of gates, like {H, T, CNOT}, from which any unitary operation on any number of qubits can be approximated to arbitrary accuracy with a finite circuit.

Unit 6 — Quantum Algorithms I

Oracle

A black-box unitary gate Uf|x⟩|y⟩ = |x⟩|y⊕f(x)⟩ representing a function f, queried without regard to how f is internally computed.

Quantum Parallelism

Evaluating a function on every input simultaneously via one oracle query applied to a superposition — useless on its own without interference to extract a global answer.

Phase Kickback

The technique of preparing an oracle's target qubit in |−⟩ so that Uf|x⟩|−⟩ = (−1)^f(x)|x⟩|−⟩, encoding f's output as a relative phase instead of a value that would collapse upon measurement.

Query Complexity

The number of times an algorithm calls an oracle, counted independently of any other computation it performs — the standard basis for comparing classical and quantum algorithms in the oracle model.

Unit 7 — Quantum Algorithms II

Grover's Algorithm

A quantum algorithm solving unstructured search among N items in O(√N) queries, a provably optimal quadratic speedup over the classical O(N).

Diffusion Operator

D = 2|s⟩⟨s| − I, the "inversion about the mean" operator that, alternated with Grover's oracle, amplifies the marked item's amplitude each round.

Shor's Algorithm

A quantum algorithm factoring large integers in time polynomial in their digit count, by efficiently finding the period of aˣ mod N via the Quantum Fourier Transform.

Post-Quantum Cryptography

Cryptographic schemes designed to remain secure even against a large-scale quantum computer, built on problems with no known efficient quantum attack.

Unit 8 — Real Hardware & Error

Decoherence

The loss of a qubit's superposition and phase information due to unwanted interaction with its environment.

T1 / T2 (Coherence Times)

T1 measures how long a qubit's energy-level information survives before decaying; T2 measures how long its relative phase survives, always T2 ≤ 2×T1.

Quantum Error Correction

Encoding a logical qubit across several physical qubits and using ancilla-based syndrome measurement to detect and correct errors without ever measuring (and so without collapsing) the encoded amplitudes.

Logical Qubit

An error-protected qubit built from several physical qubits, behaving like an ideal, noiseless qubit as long as errors stay within the code's correction capacity.

NISQ

Noisy Intermediate-Scale Quantum — John Preskill's term for the current era of quantum hardware, with a meaningful but modest qubit count still too error-prone for large fault-tolerant algorithms.
