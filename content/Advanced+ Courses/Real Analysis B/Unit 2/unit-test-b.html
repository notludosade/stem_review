1. For Σ xⁿ/n!, what is the radius of convergence, and why?

The Ratio Test ratio |xⁿ⁺¹/(n+1)!|/|xⁿ/n!| = |x|/(n+1) → 0 for any fixed x, so the series converges absolutely for every real x — radius of convergence ∞.

2. Which theorem/tool from Unit 1 is directly used to prove a power series converges uniformly on [c−r, c+r] for r < R?

The proof bounds each term by an x-independent Mₙ = M·ρⁿ forming a convergent geometric series, then applies the Weierstrass M-Test directly.

3. Let f(x) = Σxⁿ/n! (radius of convergence R = ∞). Fill in the blank: the term-by-term derivative Σn·xⁿ⁻¹/n! must also have radius of convergence ___.

The differentiation lemma guarantees the differentiated series has exactly the same radius of convergence as the original — here, infinite.

4. Which of the following is required for a function's Taylor series centered at c to even be written down?

Only infinite differentiability at c is needed to write down the coefficients f(k)(c)/k! — nothing about the series' behavior needs to be known first.

5. Which pair of functions from this unit are both shown to be analytic on all of ℝ?

Both eˣ and sin(x) have remainder bounds that shrink to 0 for every x, making them analytic on all of ℝ; e−1/x² is the counterexample that is C^∞ but not analytic at 0.

6. Σ xⁿ/n² has radius of convergence R = 1. Answer both parts about its endpoint behavior.

(a) What happens at x = 1 and x = −1?

(b) Fill in the blank: so the interval of convergence of Σxⁿ/n² is the closed interval [−1, ___].

(a) |xⁿ/n²| ≤ 1/n² at both endpoints, and Σ1/n² (p=2>1) converges, giving absolute convergence at both. (b) The interval of convergence is the closed interval [−1, 1].

7. For Σxⁿ/n! (R = ∞), answer both parts about where uniform convergence holds.

(a) For any x₀ ∈ ℝ, how can uniform convergence on a set containing x₀ be guaranteed?

(b) Fill in the blank: since x₀ was arbitrary, this shows the sum function of Σxⁿ/n! is continuous at every point of ℝ, built one closed ___ at a time.

(a) Any r < R = ∞ works, so picking r = |x₀|+1 always gives a valid closed interval containing x₀. (b) Continuity at every point of ℝ is built up one closed subinterval at a time, even though the theorem never gives uniform convergence on all of ℝ at once.

8. Consider f(x) = Σaₙxⁿ with a₀ = 3, a₁ = 5, a₂ = 7, centered at c = 0. Answer both parts.

(a) What is f(0)?

(b) Fill in the blank: since a₁ = f′(0)/1! = f′(0), we get f′(0) = ___.

(a) At x=0, every term aₙxⁿ with n≥1 vanishes, leaving f(0) = a₀ = 3. (b) Since aₖ = f(k)(c)/k!, a₁ = f′(0), so f′(0) = 5.

9. For f(x) = eˣ centered at c = 0, the Lagrange remainder is Rₙ(x) = eξ/(n+1)!·xⁿ⁺¹ for some ξ between 0 and x. Answer both parts.

(a) What bound on |eξ| makes Rₙ(x) → 0 as n → ∞, for fixed x?

(b) Fill in the blank: since |x|ⁿ⁺¹/(n+1)! → 0 (factorial growth beats any fixed exponential), Rₙ(x) → 0, showing eˣ is ___ on all of ℝ.

(a) Since ξ is between 0 and x, |eξ| never exceeds e|x|, a bound depending only on x, not n. (b) The remainder shrinks to 0 for every x, so eˣ equals its own Taylor series everywhere — analytic on all of ℝ.

10. f(x) = e−1/x² for x ≠ 0, f(0) = 0, has Taylor series identically 0 at c = 0. Answer both parts.

(a) Why does this not contradict Taylor's Theorem with Lagrange Remainder?

(b) Fill in the blank: for x ≠ 0, Rₙ(x) = f(x) − 0 = f(x) ≠ 0 for every n, so the Taylor series converges everywhere but equals f(x) only at the single point x = ___.

(a) Taylor's Theorem always supplies an exact remainder formula, but whether that remainder vanishes as n grows is a separate question — here it provably does not for x≠0. (b) The series matches f(x) only at x = 0, the single point of agreement.
