Taylor Series and Analytic Functions

Lesson 8 showed a power series's coefficients are forced to be its Taylor coefficients. This lesson runs the construction the other way — starting from an infinitely differentiable function, and asking honestly whether its Taylor series converges back to it.

← Lesson 8 Lesson 10 → Contents Glossary →

If f is a power series around c, Lesson 8 proved its coefficients must be aₖ = f(k)(c)/k!. Nothing in that argument required f to have started as a power series — it only used that f was infinitely differentiable at c. So the following construction makes sense for any C^∞ function, whether or not we know yet that it equals a power series.

Definition — Taylor Series If f is infinitely differentiable at c, its Taylor series centered at c is Σk=0∞ [f(k)(c)/k!]·(x − c)ᵏ. The Taylor series can always be written down from f's derivatives at c alone — it says nothing yet about whether the series converges, or whether it converges to f(x).
Why "always exists" is weaker than it sounds Being C^∞ at a single point c is a strong hypothesis, but it only pins down the coefficients — it doesn't force the resulting series to have positive radius of convergence, and even if it does converge on some interval, nothing so far says the sum equals f(x) rather than something else entirely. Both failures are genuinely possible; Lesson 10 exhibits one of them. This lesson isolates the condition under which neither failure happens.
Definition — Analytic f is analytic at c if there is some r > 0 such that f(x) equals its Taylor series centered at c for every x ∈ (c − r, c + r). f is analytic on an interval if it is analytic at every point of that interval.

To test whether f actually equals its Taylor series, compare f to the series' partial sums — the degree-n Taylor polynomials Pₙ(x) = Σk=0n [f(k)(c)/k!]·(x−c)ᵏ — and track the gap Rₙ(x) = f(x) − Pₙ(x).

Theorem — Taylor's Theorem with Lagrange Remainder Suppose f is (n+1)-times differentiable on an interval containing c and x. Then Rₙ(x) = f(x) − Pₙ(x) = f(n+1)(ξ)/(n+1)!·(x − c)ⁿ⁺¹ for some ξ strictly between c and x.
Proof sketch Fix x ≠ c and define g(t) = f(x) − Σk=0n [f(k)(t)/k!]·(x−t)ᵏ − M·(x−t)ⁿ⁺¹, choosing the constant M so that g(c) = 0 (possible since the bracketed sum is a fixed number once M is chosen). By construction g(x) = 0 as well (every term in the sum vanishes at t = x, since (x−t)ᵏ = 0 for k ≥ 1, leaving f(x) − f(x) = 0, and the M-term also vanishes). Since g(c) = g(x) = 0, Rolle's Theorem (Real Analysis A) gives some ξ between c and x with g′(ξ) = 0. Differentiating g(t) in t, every term in the sum telescopes except the last, leaving g′(t) = −f(n+1)(t)/n!·(x−t)ⁿ + M·(n+1)·(x−t)ⁿ. Setting g′(ξ) = 0 and solving gives M = f(n+1)(ξ)/(n+1)!. Since M was defined so that g(c) = 0 forces f(x) − Pₙ(x) = M·(x−c)ⁿ⁺¹, substituting M gives exactly Rₙ(x) = f(n+1)(ξ)/(n+1)!·(x−c)ⁿ⁺¹. ∎
Why this is the right tool for testing analyticity f(x) equals its Taylor series at x precisely when Rₙ(x) → 0 as n → ∞ — that's just the definition of the partial sums Pₙ(x) converging to f(x). Taylor's Theorem hands us a formula for Rₙ(x) built entirely from a single higher derivative at some (unknown, but existing) point ξ — turning "does the series converge to f?" into "can the derivatives of f be bounded well enough to force this one term to 0?".
Example: eˣ is analytic on all of ℝ Every derivative of eˣ is eˣ itself. Fix any x and let c = 0. On the interval between 0 and x, |eᵗ| ≤ e|x| =: B, a bound independent of n. So |Rₙ(x)| = |eᵗ/(n+1)!·xⁿ⁺¹| ≤ B·|x|ⁿ⁺¹/(n+1)! for the relevant ξ. Since |x|ⁿ⁺¹/(n+1)! → 0 as n → ∞ (factorial growth eventually beats any fixed exponential — the same fact that gave Σxⁿ/n! radius R = ∞ in Lesson 6), Rₙ(x) → 0. So eˣ equals its own Taylor series Σxⁿ/n! everywhere: eˣ is analytic on all of ℝ, and Lesson 6's mystery series is now fully identified.
Example: sin(x) is analytic on all of ℝ Every derivative of sin(x) is ± sin(x) or ± cos(x), so |f(n+1)(ξ)| ≤ 1 for every n and every ξ. So |Rₙ(x)| ≤ |x|ⁿ⁺¹/(n+1)! → 0 exactly as above, with an even simpler bound (B = 1, valid for every x at once). sin(x) equals its Taylor series Σ(−1)ᵏx²ᵏ⁺¹/(2k+1)! everywhere.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does it mean for f to be analytic at c?

Analyticity is the stronger condition: the Taylor series must actually converge back to f itself on some interval, not merely exist.

2. What does Taylor's Theorem with Lagrange Remainder give a formula for?

The Lagrange remainder formula expresses the error between f and its degree-n Taylor polynomial using a single unknown intermediate point ξ.

3. Why does the bound on Rₙ(x) for eˣ and sin(x) force Rₙ(x) → 0?

The same factorial-beats-exponential fact from Lesson 6's R = ∞ example forces the remainder bound to 0 for any fixed x.

4. Fill in the blank: the proof of Taylor's Theorem constructs an auxiliary function g with g(c) = g(x) = 0, then applies ___'s Theorem from Real Analysis A.

Rolle's Theorem supplies the point ξ where g′(ξ) = 0, which the proof then solves for the remainder formula.

5. Fill in the blank: f is analytic at c exactly when the ___ term Rₙ(x) = f(x) − Pₙ(x) goes to 0 as n → ∞.

Rₙ(x) → 0 is precisely the statement that the Taylor polynomials converge to f(x), i.e. that f equals its Taylor series there.
