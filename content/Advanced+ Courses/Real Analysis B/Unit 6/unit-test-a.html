1. Let φ = 3χ_{[0,2]} + 5χ_{(2,4]} be in canonical form. What is ∫_{[0,4]} φ dm?

∫φdm = Σᵢaᵢm(Eᵢ∩E) = 3·m([0,2]) + 5·m((2,4]) = 3·2 + 5·2 = 6 + 10 = 16.

2. Dirichlet's function f = 1·χ_ℚ + 0·χ_{[0,1]\ℚ} is simple. Answer both parts:

(a) What is ∫₀¹ f dm?

(b) Fill in the blank: this works because m(ℚ) = ___, making the value-1 piece of f invisible to Lebesgue measure.

(a) ∫₀¹fdm = 1·m(ℚ∩[0,1]) + 0·m([0,1]\ℚ) = 1·0 + 0·1 = 0. (b) m(ℚ) = 0 is exactly what makes the set where f = 1 contribute nothing to the integral — the gap Lesson 22 opened is now fully closed.

3. Let f(x) = x on [−3,3], and f⁺ = max(f,0), f⁻ = max(−f,0). Answer both parts:

(a) What are f⁺ and f⁻ here?

(b) Fill in the blank: since ∫₋₃³f⁺dm and ∫₋₃³f⁻dm are both finite (f is bounded on a finite-measure set), f is Lebesgue ___ on [−3,3].

(a) f⁺ keeps only the nonnegative part of f and zeroes out the rest; f⁻ keeps the size of the negative part and zeroes out the rest — together f = f⁺ − f⁻. (b) A measurable function bounded on a set of finite measure is automatically Lebesgue integrable.

4. If f is Riemann integrable on [a,b], what does the Riemann–Lebesgue comparison theorem guarantee?

Riemann integrability makes f bounded on a finite-measure set (hence Lebesgue integrable), and sandwiching f between step functions built from refining partitions — using the Monotone Convergence Theorem to pass to the limit — shows the two integral values agree exactly.

5. The Monotone Convergence Theorem concludes lim_n ∫fₙ dm = ∫f dm under which hypothesis?

MCT requires the sequence to be increasing and nonnegative, converging pointwise — it needs no uniformity and no domination, unlike the Dominated Convergence Theorem.

6. Let fₙ = (1 − 1/n)·χ_{[0,1]}. This sequence increases, with fₙ → χ_{[0,1]} pointwise. Answer both parts:

(a) What is ∫fₙ dm?

(b) Fill in the blank: by MCT, lim_n ∫fₙ dm = ∫(lim_n fₙ)dm = m([0,1]) = ___.

(a) ∫fₙdm = (1−1/n)·m([0,1]) = (1−1/n)·1 = 1−1/n. (b) As n → ∞, 1 − 1/n → 1, matching ∫χ_{[0,1]}dm = m([0,1]) = 1 exactly, as MCT guarantees.

7. Let fₙ = n·χ_{(0,1/n)}. Answer both parts:

(a) What is ∫fₙ dm, for every n?

(b) Fill in the blank: fₙ → 0 pointwise, yet ∫fₙdm stays fixed at 1, so no dominating integrable function can exist for this sequence, because sup_n fₙ(x) is ___ as x → 0⁺.

(a) ∫fₙdm = n·m((0,1/n)) = n·(1/n) = 1 for every n. (b) sup_nfₙ(x) grows without bound as x → 0⁺, since some fₙ hits height n arbitrarily close to 0 — no single integrable function can dominate peaks that grow as their supports shrink to a point.

8. What does Fatou's Lemma state, for nonnegative measurable f₁,f₂,f₃,…?

Fatou's Lemma is a one-directional inequality: mass can vanish in the limit (as in the moving bump, where equality fails), but the integral of the liminf can never exceed the liminf of the integrals.

9. Fill in the blank: the capstone identifies the deepest failure of Riemann integration as this — a ___ of Riemann integrable functions can fail to be Riemann integrable at all, which is exactly what motivates rebuilding the integral around measure in Units 5–6.

Dirichlet's function is the pointwise limit of the integrable fₙ sequence from Lesson 22, yet it is not Riemann integrable — this exact failure mode is what Lebesgue measure and integration are built to repair.

10. Answer both parts, reflecting on the whole course's dependency chain:

(a) According to the capstone, what do MCT and DCT do to the hypothesis needed for swapping a limit with an integral, compared to Unit 1's uniform convergence requirement?

(b) Fill in the blank: the Dominated Convergence Theorem finally constructs, in full, the counterexample that Unit 1 Lesson 4 called "beyond this course's scope" — commonly known as the moving ___.

(a) The Lebesgue integral supports interchange theorems under conditions far weaker than the uniform convergence Riemann integration needed. (b) The moving bump, fₙ = n·χ_{(0,1/n)}, is a two-line computation once Lebesgue measure is available, finally realizing what Lesson 4 could only describe.
