Convergence and Completeness

Sequences and Cauchy sequences carry over to any metric space unchanged. Whether every Cauchy sequence actually converges, though, depends entirely on the space — and the answer for C[a,b] turns out to already be sitting in Unit 1.

← Lesson 12 Lesson 14 → Contents Glossary →

Definition — Convergence A sequence (xₙ) in (X, d) converges to x ∈ X if d(xₙ, x) → 0 as n → ∞, i.e. for every ε > 0 there is N such that n ≥ N implies d(xₙ, x) < ε.
Definition — Cauchy Sequence A sequence (xₙ) in (X, d) is Cauchy if for every ε > 0 there is N such that m, n ≥ N implies d(xₘ, xₙ) < ε.
Theorem — Convergent Implies Cauchy Every convergent sequence in a metric space is Cauchy.
Proof Suppose xₙ → x. Given ε > 0, choose N so that n ≥ N implies d(xₙ, x) < ε/2. Then for m, n ≥ N, the triangle inequality gives d(xₘ, xₙ) ≤ d(xₘ, x) + d(x, xₙ) < ε/2 + ε/2 = ε. ∎
Definition — Complete Metric Space A metric space (X, d) is complete if every Cauchy sequence in X converges to some point of X.
Why the converse of the theorem is the interesting question Every convergent sequence is Cauchy, in any metric space — that direction is free. Whether every Cauchy sequence converges is not free at all; it's a genuine property some spaces have and others lack, and it's exactly what "complete" names.
Example: ℝ is complete, ℚ is not ℝ with d(x,y) = |x−y| is complete — this is precisely the Cauchy Criterion for sequences from Real Analysis A. But ℚ with the same formula for d is a perfectly good metric space that is not complete: let xₙ be the truncation of √2's decimal expansion to n digits. Each xₙ ∈ ℚ, and (xₙ) is Cauchy (consecutive truncations get arbitrarily close), but the sequence converges to √2 in ℝ — a number not in ℚ at all. There is no rational number the sequence converges to, so (xₙ) is a Cauchy sequence in ℚ with no limit in ℚ.
Why this matters Completeness is not automatic just because a space "looks like" ℝ — ℚ sits inside ℝ with the identical distance formula, yet fails to be complete. Completeness depends on the space having no such "missing points" for its own Cauchy sequences to converge to.
Theorem — (C[a,b], dsup) Is Complete The metric space C[a,b] with d(f,g) = supx∈[a,b]|f(x) − g(x)| (Lesson 11) is complete: every Cauchy sequence of continuous functions converges, in this metric, to a continuous function.
Proof Let (fₙ) be Cauchy in (C[a,b], d). For each fixed x ∈ [a,b], |fₙ(x) − fₘ(x)| ≤ d(fₙ, fₘ) → 0 as m,n → ∞, so (fₙ(x)) is a Cauchy sequence of real numbers — hence converges, since ℝ is complete. Define f(x) to be this limit, for each x.

The convergence fₙ → f is uniform. Given ε > 0, choose N so that d(fₙ, fₘ) < ε/2 for all m, n ≥ N — meaning |fₙ(x) − fₘ(x)| < ε/2 for every x ∈ [a,b] simultaneously. Fix n ≥ N and x, and let m → ∞: |fₙ(x) − fₘ(x)| → |fₙ(x) − f(x)|, so |fₙ(x) − f(x)| ≤ ε/2 < ε. Since N did not depend on x, this bound holds for every x ∈ [a,b] at once: supx|fₙ(x) − f(x)| ≤ ε/2 for all n ≥ N. That is exactly fₙ → f uniformly.

Since each fₙ is continuous and fₙ → f uniformly, f is continuous (Unit 1, Lesson 3) — so f ∈ C[a,b]. And d(fₙ, f) → 0 is precisely uniform convergence, so fₙ → f in this metric space. Every Cauchy sequence converges: (C[a,b], d) is complete. ∎
Why this theorem is Unit 1 in disguise Strip away the metric-space language and this proof is doing exactly two things Unit 1 already established: completeness of ℝ turns a Cauchy sequence of numbers fₙ(x) into a pointwise limit, and the Uniform Limit of Continuous Functions theorem (Unit 1, Lesson 3) turns that pointwise limit into a continuous function once the convergence is shown to be uniform. Completeness of a function space and continuity surviving a uniform limit are, at bottom, the same fact viewed from two different vantage points.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does the Theorem "Convergent Implies Cauchy" require of the metric space?

The proof only uses the triangle inequality and the definition of convergence, so it holds in any metric space, complete or not.

2. Why is ℚ (with the usual absolute-value metric) not complete?

The √2-truncation sequence is Cauchy in ℚ but converges only to an irrational number, which lies outside ℚ.

3. What two facts does the proof that (C[a,b], d_sup) is complete combine?

Completeness of ℝ produces the pointwise limit f, and Unit 1's continuity theorem upgrades that (once uniformity is shown) to f being continuous.

4. Fill in the blank: a sequence where d(xₘ,xₙ) can be made arbitrarily small for all sufficiently large m,n is called a ___ sequence.

This is the definition of a Cauchy sequence, generalized verbatim from Real Analysis A to any metric space.

5. Fill in the blank: a metric space where every Cauchy sequence converges to a point of the space is called ___.

Completeness is exactly the property that Cauchy sequences never "fall through a gap" in the space.
