1. Why does checking whether nums[left] ≤ nums[mid] at each step of the rotated-array search actually work to identify a sorted half?

This comparison is only meaningful because that sorted-half guarantee always holds, regardless of where the rotation point falls.

2. Fill in the blank: [4, 5, 6, 7, 0, 1, 2] was sorted once, then had a prefix moved to the end — this kind of array is called ___ sorted.

The array is no longer sorted overall, but retains this specific, exploitable structure.

3. Suppose canFinish(5) is true for some eating speed 5 in the Koko problem. What does monotonicity guarantee about canFinish(8)?

Monotonicity in this problem means "true past a threshold" — once a speed works, every faster speed also works.

4. Fill in the blank: binary search over an answer space (rather than a sorted array) requires the condition being tested to be ___ — true on one side of a threshold, false on the other.

This is the actual property binary search depends on — sortedness is just one common way to get it.

5. A target value appears in roughly half of a large sorted array. Why would finding its first and last index by scanning outward from one match, rather than running two binary searches, be a poor choice?

Whenever a target is repeated across a large fraction of the array, scanning outward from one match is effectively a linear pass.

6. Trace the rotated-array binary search on nums = [6, 7, 0, 1, 2, 4, 5] with target = 4. Answer both parts:

(a) At the first step, left=0, right=6, mid=3 (nums[mid]=1). Since nums[left]=6 is NOT ≤ nums[mid]=1, which half is sorted, and where does the search go next?

(b) Fill in the blank: this trace ultimately finds target 4 at index ___.

(a) Since nums[left] > nums[mid], the right half [1,2,4,5] must be the sorted one, and 4 falls within [1,5], so the search moves right (left=mid+1=4). (b) The next step checks left=4, right=6, mid=5 (value 4) — an exact match at index 5.

7. Trace the binary-search-on-the-answer algorithm for Koko Eating Bananas on piles = [30, 11, 23, 4, 20], h = 5. Answer both parts:

(a) The search starts with left=1, right=30 (the largest pile). At the first midpoint, speed=15, how many hours does Koko need, and what does the algorithm do next?

(b) Fill in the blank: continuing this binary search finds the minimum working eating speed to be ___.

(a) At speed 15, the five piles need 2+1+2+1+2 = 8 hours, over the 5-hour budget, so the search must try faster speeds. (b) Continuing the search converges on 30 — at any slower speed, such as 29, at least one pile pushes the total to 6 hours or more, exceeding the 5-hour limit; only speed 30 keeps every single-pile hour to exactly 1, for a total of 5.

8. Trace the last-occurrence binary search on nums = [2, 2, 3, 3, 3, 3, 5] with target = 3. Answer both parts:

(a) At the first step, left=0, right=6, mid=3 (nums[mid]=3, a match) while searching for the LAST occurrence. What does the algorithm do next?

(b) Fill in the blank: this trace ultimately finds the last occurrence of 3 at index ___.

(a) For a last-occurrence search, finding a match doesn't stop the search — it records the index and narrows toward the right half, since a later match might still exist. (b) Searching right of index 3 (new left=4) finds another match at mid=5 (value 3), records it, and narrows further right (left=6); at left=6, right=6, mid=6 holds value 5 (greater than target), so right retreats below left and the loop ends, leaving index 5 as the last occurrence.

9. A problem gives an array with no particular order, but a function isPossible(x) is provided that's guaranteed false for small x and true for large x, with a single crossover point. Answer both parts:

(a) Can binary search be used to find that crossover point?

(b) Fill in the blank: this works because binary search's real requirement is the ability to ___ half of the remaining candidates at each step, using any decidable rule available.

(a) A monotonic predicate is enough on its own — Lesson 9 makes exactly this case with Koko's eating speed, where no array of speeds ever existed. (b) "Eliminate" names the one operation every variant in this unit actually depends on.

10. A problem requires: (1) searching a rotated array of size n, (2) binary-searching an answer space of range r, and (3) finding both boundaries of a duplicated target in a sorted array of size n. Answer both parts:

(a) What do all three approaches have in common?

(b) Fill in the blank: since each approach halves its own search space every step, none needs more than O(___ n) time (or O(log r) for the answer-space version).

(a) Sorted-half checks, monotonic conditions, and boundary narrowing all still throw away half the remaining candidates each step. (b) Halving a search space every step is exactly what produces a logarithmic bound, regardless of which decidable rule does the halving.
