1. What two properties make a problem suitable for dynamic programming?

Overlapping subproblems means caching pays off; optimal substructure means the full answer can be built directly from smaller ones.

2. What is the key difference between memoization and tabulation?

Both compute the same answers, just in opposite order — one keeps recursion and adds a cache, the other builds an array from the base cases upward with no recursion at all.

3. Trace the tabulated climb_stairs_tab(5). Answer both parts:

(a) What is dp[5], the number of ways to climb 5 stairs taking 1 or 2 steps at a time?

(b) Fill in the blank: since dp[i] only ever depends on the previous two values, the tabulated array can be compressed down to O(___) space instead of O(n).

(a) dp[1]=1, dp[2]=2, dp[3]=3, dp[4]=5, dp[5]=8 — each value is the sum of the two before it, exactly like Fibonacci. (b) Only the last two dp values are ever read, so two variables replace the whole array, dropping space to O(1).

4. What is the recurrence relation behind House Robber?

Robbing house i forces skipping house i - 1, so the comparison is against the best result two houses back, not one.

5. Trace Kadane's algorithm on nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]. Answer both parts:

(a) What is the maximum subarray sum?

(b) Fill in the blank: the subarray achieving this maximum sum is [4, -1, 2, ___].

(a) Running the current = max(nums[i], current + nums[i]) update across the array, the running best climbs to 6 at the subarray [4, -1, 2, 1] and never exceeds it afterward. (b) 4 + (-1) + 2 + 1 = 6.

6. Why are the entire top row and left column of the Unique Paths table set to 1?

An edge cell can only be reached by moving entirely in one direction, since moving the other way would immediately leave the grid.

7. Find the edit distance between word1 = "cat" and word2 = "cut". Answer both parts:

(a) What is the edit distance between "cat" and "cut"?

(b) Which single edit transforms "cat" into "cut"?

(a) Filling the dp table by the recurrence gives dp[3][3] = 1. (b) "cat" and "cut" differ in exactly one position — the middle letter — so a single substitution suffices, matching dp[i][j] = dp[i-1][j-1] everywhere the two words already agree.

8. Trace can_partition([1, 5, 11, 5]). Answer both parts:

(a) What is the target subset sum dp must reach, and is it reachable?

(b) Fill in the blank: the inner loop iterates sums from target down to num, which enforces the 0/1 rule — iterating the other direction would let a number be ___ within the same subset.

(a) Total = 22, target = 11; {11} alone is a subset summing exactly to 11, so dp[11] ends up True. (b) Iterating forward would let a lower value already updated by the current number get read again by a higher one, effectively reusing that number twice in one subset.

9. Fill in the blank: choosing whether to include each item at most once toward a capacity is the classic 0/1 ___ problem.

The 0 and 1 refer to excluding or including each item exactly zero or one times — Partition Equal Subset Sum is this exact problem in disguise.

10. Trace length_of_lis([10, 9, 2, 5, 3, 7, 101, 18]). Answer both parts:

(a) What is the length of the longest increasing subsequence?

(b) Fill in the blank: a faster approach to this problem replaces the nested loop with ___ search over tracked subsequence tails, cutting the inner scan to O(log n).

(a) One longest chain is 2, 3, 7, 101 (or 2, 3, 7, 18), giving dp values that peak at 4. (b) Unit 3's binary search finds where each new number belongs among tracked tail values in O(log n) instead of scanning every earlier index.
