1D DP: House Robber & Maximum Subarray

Two of the most common interview DP problems, both solved by tracking just one or two running values instead of a whole array.

← Lesson 26 Lesson 28 → Contents Glossary →

Problem: given an array of houses with money in each, rob them to maximize total money stolen — without ever robbing two adjacent houses. At each house, there's a real choice: rob it (and skip the previous one) or skip it (and keep whatever the best was up to the previous house). That's a recurrence: rob(i) = max(rob(i - 1), rob(i - 2) + nums[i]) — skip this house, or take it plus the best from two houses back.

The idea Since rob(i) only ever depends on the two previous values, there's no need for a full array — Lesson 26's O(1)-space optimization applies directly. Track two running values, prev2 (best through i − 2) and prev1 (best through i − 1), and slide them forward one house at a time.
Python 
def rob(nums):
    prev2, prev1 = 0, 0     # best through i - 2, best through i - 1
    for num in nums:
        current = max(prev1, prev2 + num)   # skip this house, or take it
        prev2, prev1 = prev1, current
    return prev1
Java 
int rob(int[] nums) {
    int prev2 = 0, prev1 = 0;   // best through i - 2, best through i - 1
    for (int num : nums) {
        int current = Math.max(prev1, prev2 + num);   // skip this house, or take it
        prev2 = prev1;
        prev1 = current;
    }
    return prev1;
}
JavaScript 
function rob(nums) {
  let prev2 = 0, prev1 = 0;   // best through i - 2, best through i - 1
  for (const num of nums) {
    const current = Math.max(prev1, prev2 + num);   // skip this house, or take it
    prev2 = prev1;
    prev1 = current;
  }
  return prev1;
}
C++ 
int rob(std::vector<int>& nums) {
    int prev2 = 0, prev1 = 0;   // best through i - 2, best through i - 1
    for (int num : nums) {
        int current = std::max(prev1, prev2 + num);   // skip this house, or take it
        prev2 = prev1;
        prev1 = current;
    }
    return prev1;
}

This runs in O(n) time and O(1) space — the two variables replace what would otherwise be an n-length dp array, since only the two most recent entries are ever read. A closely related problem, Maximum Subarray (LeetCode #53), asks for the largest sum of any contiguous subarray, and is solved by Kadane's algorithm: track the best sum ending exactly at the current position, current = max(nums[i], current + nums[i]) — either the current element starts a fresh subarray, or it extends the best one ending just before it — updating a running maximum as it goes. Same shape as House Robber: one running value (or two), one O(n) pass, one decision per element between "start fresh" and "extend what came before."

Why it matters here Both problems share the same 1D DP skeleton: a decision at each position that depends only on a small, fixed number of previous results, collapsed from an array into a handful of variables. This is Lesson 26's Climbing Stairs recurrence generalized — instead of always adding the previous two values, each problem now has its own rule for combining them (a max instead of a sum, or comparing "skip" against "take"). Spotting "the answer at position i depends only on the last one or two positions" is the signal for this entire lesson's pattern.

Check your recall

1. What is the recurrence relation behind House Robber?

Robbing house i forces skipping house i - 1, so the comparison is against the best result two houses back.

2. Why can House Robber be solved with two variables instead of a full array?

Once older results are no longer needed, keeping the full array around is unnecessary.

3. In Kadane's algorithm, what does the current variable represent at each step?

Deciding whether to extend this running sum or restart it at the current element is the core of the algorithm.

4. Fill in the blank: the algorithm that tracks the best subarray sum ending at each position is known as ___'s algorithm.

Named after the algorithm's discoverer, Jay Kadane.

5. Fill in the blank: House Robber's core constraint is that no two ___ houses can both be robbed.

This constraint is exactly what makes robbing house i force skipping house i - 1.
