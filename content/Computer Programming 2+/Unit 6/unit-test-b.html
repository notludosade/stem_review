1. Why is a tree considered a special case of a graph, rather than something entirely separate?

Dropping those two guarantees is exactly what turns a tree into a general graph.

2. Fill in the blank: {0: [1, 2], 1: [0, 3], 2: [0], 3: [1]} is an example of an ___ list, the most common way to represent a graph in code.

Each key maps to the list of nodes it directly connects to.

3. A grid-spreading problem seeds its BFS queue with every initially-infected cell at once, instead of starting from just one cell. Why does this still work correctly with the standard levelSize trick from level-order traversal?

Seeding the queue with multiple starting points is the only change; the round-by-round levelSize logic is otherwise unchanged from Lesson 12.

4. Fill in the blank: once a graph's edges have different costs, plain BFS no longer guarantees correct shortest paths — it only works when the graph is ___, meaning every edge costs the same.

Dijkstra's algorithm is what's needed once this assumption no longer holds.

5. What does a course's in-degree represent in Kahn's algorithm?

A course with in-degree zero has nothing left blocking it and can start the queue.

6. Given the grid [['1','0','1'],['1','0','1'],['0','0','1']], the DFS scan starts at (0,0). Answer both parts:

(a) Which cells get marked visited as part of that first DFS call?

(b) Fill in the blank: after DFS also runs starting from (0,2), covering (0,2), (1,2), and (2,2), the total number of islands found is ___.

(a) From (0,0), DFS can move down to (1,0); moving right from either cell hits column 1, which is entirely water ('0'), so the search stops there. (b) The outer loop later finds (0,2) still unvisited and starts a second DFS, which sinks the entire right-column group — two separate DFS calls means two islands total.

7. For grid [[2,1,0],[1,1,0],[0,1,1]] (rotten orange at (0,0), fresh oranges elsewhere, 0 = empty), answer both parts:

(a) How many fresh oranges remain after minute 1 of the multi-source BFS?

(b) Fill in the blank: continuing this simulation minute by minute, every fresh orange eventually rots, and the total number of minutes elapsed is ___.

(a) (0,0)'s two orthogonal neighbors, (1,0) and (0,1), are fresh and both rot during minute 1, leaving 3 of the original 5 fresh oranges (at (1,1), (2,1), (2,2)). (b) The rot keeps spreading one ring outward each minute — (1,1) rots in minute 2, (2,1) in minute 3, and (2,2) last in minute 4 — for a total of 4 minutes.

8. For numCourses=5 with prerequisites [[1,0],[2,0],[3,1],[4,2],[4,3]] (course4 needs both 2 and 3), answer both parts:

(a) What is course4's initial in-degree, and which courses start in the queue?

(b) Fill in the blank: processing the queue in order eventually visits all 5 courses with no cycle, so canFinish returns ___.

(a) Course4 lists two prerequisites (2 and 3), giving it in-degree 2; only course0 starts with in-degree 0, since every other course depends on something. (b) Processing unlocks courses one dependency at a time — 1 and 2 after course0, then 3 after course1, then finally 4 once both 2 and 3 are done — all 5 courses get visited, so canFinish returns true.

9. For edges = [[1,2],[2,3],[1,3]] processed in order, answer both parts:

(a) What happens when the algorithm reaches edge [1,3]?

(b) Fill in the blank: by the time edge [1,3] is processed, nodes 1, 2, and 3 already share a root because of the earlier edges [1,2] and [2,___].

(a) After processing [1,2] and [2,3], nodes 1, 2, and 3 have all been merged into one group under root 3; when [1,3] is checked, find(1) and find(3) both resolve to root 3, so union returns false and [1,3] is the redundant edge. (b) The earlier edges [1,2] and [2,3] already chained all three nodes together through node 2, before edge [1,3] is ever processed.

10. For times=[[2,1,1],[2,3,4],[1,3,2]], n=3, k=2, trace Dijkstra's algorithm. Answer both parts:

(a) After processing node 2 (distance 0) and node 1 (distance 1), what entries are in the heap, and what happens when (4,3) is eventually popped?

(b) Fill in the blank: since every node is reached, the final signal delay time (the maximum distance across all nodes) is ___.

(a) Processing node 1 relaxes the edge to node 3, pushing (3,3) — a shorter candidate than the (4,3) pushed directly from node 2; node 3 gets finalized at distance 3 first, so the stale (4,3) entry is correctly skipped when it's later popped. (b) With dist = {2:0, 1:1, 3:3} covering all 3 nodes, the answer is the maximum of these, 3.
