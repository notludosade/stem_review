1. What does "black-box observation" mean when applied to a compiled game?

A black box is understood only through observable inputs and outputs, since source code isn't available.

2. Fill in the blank: a tool that watches a running program's memory for values that change in correlation with an observed action is called a ___ ___.

Cheat Engine is the best-known general-purpose memory scanner.

3. Why are log files a useful debugging resource even with no reverse-engineering tools?

Log files are typically plain, human-readable text — no special tools required.

4. Fill in the blank: a collaboratively edited modding reference maintained by a game's player community is called a ___.

A community wiki often surpasses official documentation for modding-specific problems.

5. What does DMCA Section 1201 generally prohibit?

Section 1201's key trigger is defeating a technical protection, not the underlying purpose of doing so.

6. Ghidra and IDA, and a memory scanner like Cheat Engine, serve different purposes. Answer both parts:

(a) What does Ghidra or IDA work on?

(b) What does a memory scanner work on instead?

Decompilers/disassemblers analyze the static executable; memory scanners observe a running program's live state.

7. Reverse-engineering compiled behavior is described as building working hypotheses. Answer both parts:

(a) Does a memory scanner ever produce proof of exactly why a value changed?

(b) Why is a decompiler's reconstructed logic only an approximation?

Both techniques are inherently indirect — correlation and approximation, never the original source recovered exactly.

8. Most everyday modding problems are solved without deep reverse-engineering tools. Answer both parts:

(a) What is trial-and-error debugging?

(b) What should typically be checked before reaching for a decompiler or memory scanner?

Checking community knowledge first is the highest-value debugging step, before any deeper reverse-engineering tool.

9. Section 1201 includes an interoperability exception. Answer both parts:

(a) What does this exception narrowly cover?

(b) Is this exception a blanket shield for any reverse-engineering a modder considers reasonable?

The interoperability exception is real but narrow — it does not cover every reverse-engineering scenario.

10. The exact same reverse-engineering tools can be used for different purposes. Answer both parts:

(a) Which purpose sits on safer legal ground?

(b) What is the key factor that determines legal risk here, more than the tools used?

Legal risk in reverse-engineering hinges on whether a protection was circumvented and why, not on the sophistication of the technique.
