Sorting Algorithms

The simplest way to sort is also the slowest. Understanding why points straight at a faster one.

Lesson 16 → Contents Glossary →

Bubble sort repeatedly steps through the list, swapping adjacent elements that are out of order, until a full pass makes no swaps. It's easy to write and easy to trace by hand — and it's O(n²): for every one of the n elements, it may scan almost the whole list again.

Python 
def bubble_sort(items):
    n = len(items)
    for i in range(n):
        for j in range(0, n - i - 1):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
    return items
Java 
static void bubbleSort(int[] items) {
    int n = items.length;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (items[j] > items[j + 1]) {
                int temp = items[j];
                items[j] = items[j + 1];
                items[j + 1] = temp;
            }
        }
    }
}
JavaScript 
function bubbleSort(items) {
    const n = items.length;
    for (let i = 0; i < n; i++) {
        for (let j = 0; j < n - i - 1; j++) {
            if (items[j] > items[j + 1]) {
                [items[j], items[j + 1]] = [items[j + 1], items[j]];
            }
        }
    }
    return items;
}
C++ 
void bubbleSort(std::vector<int>& items) {
    int n = static_cast<int>(items.size());
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (items[j] > items[j + 1]) {
                std::swap(items[j], items[j + 1]);
            }
        }
    }
}

Bubble sort's nested loop is the same shape as Lesson 13's O(n²) example — no surprise, since it's a loop inside a loop. Merge sort takes a fundamentally different approach: split the list in half, recursively sort each half, then merge the two sorted halves back together in order. Recursively halving the problem — the same move that made binary search O(log n) — combined with an O(n) merge step at each level gives merge sort O(n log n), a real, practical improvement over O(n²) for anything but the smallest lists.

Python 
def merge_sort(items):
    if len(items) <= 1:                 # base case
        return items
    mid = len(items) // 2
    left = merge_sort(items[:mid])      # recursive case
    right = merge_sort(items[mid:])     # recursive case
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i]); i += 1
        else:
            result.append(right[j]); j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result

Every language's standard library already ships a fast, well-tested O(n log n) sort — Python's sorted(), Java's Collections.sort(), JavaScript's Array.prototype.sort(), C++'s std::sort() — so real code almost never hand-writes bubble sort or merge sort. Quicksort is the other classic O(n log n) approach many of those built-ins draw on: pick a "pivot" element, partition everything smaller to one side and everything larger to the other, then recursively sort each side. The value of learning bubble sort and merge sort isn't to replace the built-in — it's to understand, concretely, what "the built-in sort is O(n log n)" actually means and why that's worth caring about.

Definition Bubble sort repeatedly swaps adjacent out-of-order pairs — O(n²). Merge sort recursively splits and merges sorted halves — O(n log n). Quicksort recursively partitions around a pivot — also O(n log n) on average.
Why it matters here This closes the loop on the entire unit.
