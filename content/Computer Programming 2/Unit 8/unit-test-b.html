Unit 8 Test — Version B

Capstone — Putting It Together. 10 points across every lesson in this unit — 5 questions worth 1 point, 5 worth 1 point split across two parts. Score 90% or higher to clear this unit.

1. Lesson 23 splits a Circle class into shapes.py and main.py (or shapes.js and main.js). What best defines the word "module" as used here?

shapes.py and shapes.js each hold the Circle class so it can be imported into main — exactly what makes a file a module.

2. Circle.java needs no extra file beyond Circle.java and Main.java, but C++'s Circle needs shapes.h in addition to shapes.cpp and main.cpp. Answer both parts:

(a) What role does shapes.h play that Circle.java doesn't need an equivalent of?

(b) Fill in the blank: main.cpp includes shapes.h to learn Circle's declared shape without ever seeing shapes.cpp — the conventional file extension for this kind of file is .___.

(a) Because C++ compiles files independently, shapes.h is how main.cpp learns Circle's shape without needing shapes.cpp's implementation. (b) .h is the standard C++ header file extension.

3. Suppose TaskManager.get_task returned -1 instead of raising TaskNotFoundError for a missing id. What capstone concept from Unit 2 would be lost?

Returning -1 instead of raising TaskNotFoundError would be exactly the meaningless-return-value problem custom exceptions exist to avoid.

4. Suppose TaskManager stored its tasks in a plain list of (id, description, priority) entries instead of a dict, HashMap, Map, or unordered_map. What would get_task lose?

A list requires scanning entry by entry to find a matching id; the hash map's whole advantage is skipping that scan.

5. tasksByPriority() calls each language's built-in sort — sorted(), List.sort(), Array.sort(), std::sort() — instead of a hand-written sorting algorithm. Why, per the earlier sorting unit?

Reaching for a proven built-in sort, rather than writing one from scratch, is exactly the earlier lesson TaskManager reuses here.

6. Only the C++ version of the capstone wraps its TaskManager in std::make_unique. Answer both parts:

(a) Why is this step specific to the C++ version, unlike the other three languages?

(b) Fill in the blank: unique_ptr ties an object's heap lifetime to its owner's ___ lifetime, freeing the object automatically once that owner goes out of scope.

(a) The other three languages garbage-collect automatically; C++ needs unique_ptr to get an equivalent automatic cleanup. (b) Tying heap cleanup to the stack's automatic lifetime is exactly the RAII idea unique_ptr applies.

7. A task can have subtasks, which can themselves have subtasks. The suggested totalEstimatedHours extension needs to add up hours across all of them, at any depth. Answer both parts:

(a) What technique does walking an arbitrarily deep chain of subtasks like this call for?

(b) Fill in the blank: totalEstimatedHours calling itself on each subtask, which may in turn call itself on further subtasks, is an example of ___.

(a) Arbitrary nesting depth is exactly the situation recursion handles cleanly, without knowing the depth in advance. (b) A function calling itself on smaller versions of the same problem is the definition of recursion.

8. Following the unit-testing lesson's pattern, a student writes a test named getTaskMissingIdThrows() for TaskManager. Answer both parts:

(a) What should this test actually call and check?

(b) Fill in the blank: the specific exception a correct get_task must raise when the id was never added is named ___.

(a) A test that checks a missing id, one small known input, and asserts the correct outcome is exactly a unit test applied to TaskManager. (b) TaskNotFoundError is the exact custom exception get_task should raise.

9. Java represents one task with a small Task class holding description and priority fields; Python instead uses a plain (description, priority) tuple. Answer both parts:

(a) What does Java's dedicated Task class provide that Python's tuple representation doesn't?

(b) Fill in the blank: C++'s equivalent of Java's small Task class is declared using the keyword ___, whose fields are public by default.

(a) Java's Task class gives named, declared fields; Python's tuple accesses description and priority only by position. (b) struct Task { std::string description; int priority; }; is C++'s equivalent representation.

10. Fill in the blank: TaskManager is described as a ___ project — one deliberately built to combine ideas from many earlier units at once, rather than isolating just one.

A capstone project is the test of whether separate topics — OOP, error handling, data structures, sorting, ownership — were actually one connected skill all along.
