Linear Regression

The simplest real model in this course — and the clearest place to see what "training" actually means underneath everything fancier.

Lesson 8 → Contents Glossary →

Lesson 3's housing dataset had a continuous numeric label — price — rather than a category. Linear regression predicts exactly that kind of label: a number produced from a weighted sum of the input features.

Python — scikit-learn 
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

model = LinearRegression()
model.fit(X_train, y_train)

print(model.coef_)         # one weight per feature, e.g. [142.5, 8900.0]
print(model.intercept_)    # baseline value when every feature is 0

# predicted_price = intercept + coef[0]*square_feet + coef[1]*bedrooms

predictions = model.predict(X_val)
error = mean_squared_error(y_val, predictions)
print(error)

Each entry in model.coef_ is a coefficient (or weight) — how much the prediction changes for a one-unit increase in that feature, holding the others fixed. fit() doesn't guess these numbers; it searches for the exact coefficients that make predictions on the training set as close as possible to the true labels, where "as close as possible" is measured by a loss function — here, mean squared error: the average of each prediction's squared distance from the true value. Smaller loss means better-fitting coefficients.

Definition Linear regression predicts a continuous numeric value as a weighted sum of input features. A coefficient is the weight applied to one feature. A loss function measures how far a model's predictions are from the true values — mean squared error is one common choice.
Why it matters here "Search for the coefficients that minimize the loss" is exactly what every model in this course does, including the neural networks in Unit 4 — linear regression is just the simplest case, small enough to reason about by hand. Lesson 8's logistic regression reuses this same weighted-sum idea for a completely different kind of label.
