Datasets, Features, and Labels

Every model in this course learns from a table. Knowing what each column in that table is called is the first real vocabulary this unit builds.

Lesson 4 → Contents Glossary →

A dataset is the collection of examples a model learns from — usually one row per example. Each column is either a feature (an input the model is given) or, for supervised learning, the label (the correct output it's trying to predict). A small housing dataset makes this concrete:

Python — pandas 
import pandas as pd

data = pd.DataFrame({
    "square_feet": [1200, 1800, 950],
    "bedrooms":    [2, 3, 1],
    "price":       [250000, 340000, 180000],
})

features = data[["square_feet", "bedrooms"]]   # X: what the model sees
labels = data["price"]                          # y: what the model predicts

print(features)
#    square_feet  bedrooms
# 0         1200         2
# 1         1800         3
# 2          950         1

Each row is one house — one example. square_feet and bedrooms are features: information available before the sale, which the model is allowed to look at. price is the label: the actual number the model is trying to learn to predict, known for every house in this training set but not known for a new house the model will see later. By convention, features are called X and labels are called y in almost all machine learning code — the exact names fit(X_train, y_train) used back in Lesson 1.

Definition A dataset is a collection of examples used to train or evaluate a model. A feature is an input column the model is given. A label is the correct output value paired with an example, present in supervised learning and absent in unsupervised learning.
Why it matters here Every classical ML model in Unit 3 and every neural network in Unit 4 is, underneath, just a function that turns a row of features into a prediction — trained by comparing that prediction to the real label, over and over, across every row in the dataset. Nothing else in this course makes sense without this vocabulary in place first.
