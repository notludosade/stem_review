1. A home security camera flags "motion detected" whenever pixel brightness changes by more than a fixed amount a technician typed into its configuration file. Which is true?

A fixed, hand-typed threshold is a hand-written rule, never learned from data — AI with zero learning involved.

2. Fill in the blank: a supervised model is trained using labeled correct answers, while a reinforcement learning agent is trained using a ___ signal reflecting how good or bad its actions were.

Supervised learning matches against a known label; reinforcement learning has no label at all, only a reward signal shaping future behavior.

3. A developer trains a model, checks its score on the test set, doesn't like the number, adjusts a hyperparameter, and checks the test set's score again to see if it improved. What mistake is being made?

Checking the test set to guide a decision is exactly what the validation set is for — doing this with the test set erases its one honest final check.

4. Fill in the blank: a model that scores far higher on its training data than on its validation data is showing a classic symptom of ___.

A large training-vs-validation gap means the model memorized training data rather than learning the real pattern — overfitting.

5. A hospital's diagnostic classifier raises its decision threshold from 0.5 to 0.8, so it only flags a patient as "high risk" when very confident. Which is the most likely consequence?

Raising the threshold makes the model stricter about flagging positive — fewer false positives (higher precision) but more missed real cases (lower recall).

6. Fill in the blank: predicting a continuous dollar amount calls for linear regression, while predicting one of a fixed set of categories calls for a model built for ___ instead, such as logistic regression or a decision tree.

The label type — continuous number vs. category — is what determines whether a regression or classification model is the right tool.

7. In what order does one full training step of a neural network occur?

Each step depends on the one before it: you need a prediction before a loss, a loss before gradients, and gradients before an update.

8. A network's weights are updated once per training step. Which step directly produces the loss value used to guide that update?

Loss is always a comparison between what the model predicted and what the label actually says — no comparison, no loss.

9. A developer needs to classify photos of handwritten digits. Which architecture is the most natural fit, and why?

CNNs' shared filters are specifically built to detect local spatial patterns, making them the natural fit for image data.

10. A developer wants to process very long documents while relating distant words to each other without a step-by-step bottleneck. Which architecture is the best fit, and why?

Self-attention lets any two positions interact directly regardless of distance, and unlike an RNN's step-by-step recurrence, it's computed in parallel.

11. A support assistant confidently invents plausible but false details about a product it was never trained on. Which technique most directly addresses this?

Grounding the model in retrieved, real documents is what directly prevents it from inventing facts about things it never actually saw.

12. A team wants source-cited answers pulled from their own internal documents. Which technique fits best?

RAG's whole mechanism is retrieving real source documents at answer time, which is exactly what citation requires.

13. A startup wants to build a tool that extracts key dates from legal contracts. Before writing a single line of AI code, what should be checked first?

The strongest starting habit is building the simplest possible baseline first, so anything fancier has something concrete to beat.

14. Fill in the blank: a function that calls an LLM API wrapped in a try/except returning a safe empty result on failure is using a ___.

A safe default returned when the primary path fails is a fallback.

15. A chatbot answers thousands of nearly identical FAQ questions per day, paying full latency and per-token cost every time, even for exact repeats. What is the most direct fix?

A cache stores a previous result so an identical future request skips repeating the full cost and latency.

16. Three months after deploying a new prompt version, monitoring logs show accuracy dropping while a human reviewer overrides the model far more often than before. What should the team consider?

Falling accuracy plus rising human overrides together are exactly the kind of regression monitoring exists to catch, and a rollback is the direct fix.

17. A medical-intake chatbot's underlying model is found, during internal testing, to confidently describe a drug interaction that does not actually exist. What is the most important reason a human should stay in the loop before any such guidance reaches a patient?

A model can fail silently, sounding just as confident when it's wrong as when it's right — exactly why human oversight matters most for consequential decisions.

18. Fill in the blank: a hiring tool shows a wide recall gap between two applicant groups during testing, but the company ships it anyway without adding any review step. Its predictions systematically disadvantaging one group like this is called algorithmic ___.

A demonstrable, systematic fairness gap like this is algorithmic bias — and judging that it needed a human in the loop before shipping was the developer's call to make.
