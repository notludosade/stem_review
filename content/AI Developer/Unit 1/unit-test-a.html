1. A voice assistant's wake-word detector is a many-layered neural network trained directly on raw audio waveforms. Which statement about this system is correct?

Every deep learning system is machine learning, and every machine learning system is AI — never the reverse. A many-layered network learning from raw audio fits deep learning specifically, which drags the other two labels along with it.

2. Which of the following best distinguishes a machine-learned system from a purely rule-based one?

The rule-based spam filter checked a phrase a person typed in by hand; the learned version found its own rule by fitting on labeled examples. That's the entire distinction.

3. An image classifier is built as a many-layered neural network that learns directly from raw pixel values, with no features extracted by hand beforehand. What does this description make the system?

Many layers, learning directly from raw data instead of hand-picked features, is exactly what makes a system deep learning.

4. A photo app sorts pictures into "cat" or "dog" using a many-layered neural network that learns directly from raw pixel data, with no hand-written rules involved. Answer both parts:

(a) Is this system machine learning?

(b) Fill in the blank: because it uses a many-layered network learning directly from raw pixels, this system is more specifically an example of ___ learning.

(a) Its rules were found by studying data, not written by a person — that's machine learning. (b) Many layers learning straight from raw pixels is specifically deep learning, a further-nested subset.

5. A model is trained on thousands of x-ray images, each one tagged by a radiologist as either "pneumonia" or "no pneumonia." Answer both parts:

(a) What kind of learning is this?

(b) Fill in the blank: because every image already has a known, correct tag attached, training on this dataset is an example of ___ learning.

(a) The radiologist's tag is a known correct answer attached to every example — the defining feature of supervised learning. (b) Same reasoning, in the vocabulary word itself.

6. A retailer runs a clustering algorithm on customer purchase histories with no prior category ever assigned to any customer. Answer both parts:

(a) What is the algorithm's job in this setup, since there's no known correct group for any customer?

(b) Fill in the blank: because nobody assigned a correct group to any customer in advance, this is called ___ learning.

(a) With no label to match, the only job left is finding structure in the data itself. (b) No labels at all, discovered structure instead — that's unsupervised learning by definition.

7. Fill in the blank: A robot arm learning to stack blocks receives a positive score when a block lands correctly and a negative score when it topples the stack. This score is called the ___ signal.

A reward signal tells an agent how good or bad an action turned out to be, with no labeled "correct move" ever given.

8. Both a clustering algorithm and a game-playing agent train on data with no labels attached. Answer both parts:

(a) What is the key difference between the two?

(b) Fill in the blank: unlike clustering, reinforcement learning learns a ___ through trial and error guided by reward.

(a) Reward feedback on actions taken is exactly what separates reinforcement learning from unlabeled, reward-free clustering. (b) That reward feedback is what lets the agent learn a strategy over time.

9. A ride-sharing app's dispatch algorithm improves its pickup-time decisions over weeks by receiving a positive signal when a rider rates the ride highly and a negative signal when they rate it poorly, with no dataset of "correct dispatch actions" ever provided. Which learning paradigm is this?

No labels, but a clear reward-like feedback signal that shapes future decisions — that combination is reinforcement learning specifically.

10. A weather dataset includes daily temperature, humidity, and wind speed for the past five years, with no "correct forecast" column of any kind attached. Answer both parts:

(a) Could this dataset be used directly for supervised learning to predict tomorrow's temperature?

(b) Fill in the blank: because no known correct output is attached to any row, this dataset is currently ___.

(a) Supervised learning needs a known correct output to train against — this dataset has none. (b) A dataset with no attached correct output is, by definition, unlabeled.
