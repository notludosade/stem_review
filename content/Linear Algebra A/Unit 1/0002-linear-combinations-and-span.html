Linear Combinations and Span

Scale a handful of vectors, add them up, and ask: which points can you actually reach?

← Lesson 1 Lesson 3 → Contents Glossary →

Lesson 1 gave you two operations: add vectors, scale vectors. This lesson asks what happens when you use both, freely and repeatedly, starting from a fixed handful of vectors. The answer to "which points can I reach?" turns out to be one of the most useful questions in the entire subject.

1. Linear combinations

Definition — Linear Combination A linear combination of vectors v₁, v₂, …, vₖ is any vector of the form c₁v₁ + c₂v₂ + ⋯ + cₖvₖ, where c₁, …, cₖ are scalars (real numbers). Every one of Lesson 1's operations is already a special case: v + w is a linear combination with both coefficients equal to 1, and cv is a linear combination of a single vector.

2. Span: every combination, all at once

Definition — Span The span of a set of vectors {v₁, …, vₖ}, written span{v₁, …, vₖ}, is the set of all linear combinations of those vectors — every point reachable by choosing some c₁, …, cₖ. Span isn't one vector; it's an entire set, usually infinite.

Why span collapses to a line With v1 = (2, 1) and v2 = (−1, 2) — two vectors pointing in genuinely different directions — sweeping c1 and c2 reaches every point in the plane: span{v1, v2} = ℝ². Click the button above to make v2 a scalar multiple of v1 instead. Now every combination c1v1 + c2v2 is really just (c1 + 2c2)v1 — one direction, scaled — so the span collapses down to a single line through the origin. A second vector only adds new reachable territory if it points somewhere the first one couldn't already scale into.
Edge case worth stating precisely The zero vector is always in the span of any set of vectors — set every coefficient to 0. This includes the empty set: span(∅) = {0} by definition (an "empty sum" of coefficients is 0). Span is never actually empty, even when you start with nothing to combine.

Check your recall

1. Which expression is a linear combination of v₁ and v₂?

A linear combination is strictly scale-then-add: c₁v₁ + c₂v₂. 3v₁ − 2v₂ is exactly that form with c₁ = 3, c₂ = −2.

2. For v1 = (1, 0) and v2 = (0, 1), what is span{v1, v2}?

c1(1,0) + c2(0,1) = (c1, c2), and c1, c2 can be any real numbers — that reaches every point in ℝ².

3. Fill in the blank: for v = (3, −1), the linear combination 2v = ___.

2v scales every component by 2: (2·3, 2·−1) = (6, −2).

4. If v2 = 3v1 (and v1 is nonzero), what is span{v1, v2}?

c1v1 + c2v2 = c1v1 + c2(3v1) = (c1 + 3c2)v1 — every combination is just some scalar times v1, so nothing outside v1's line is ever reached.

5. What is the span of the empty set of vectors?

With no vectors to combine, the only linear combination available is the empty sum, which is defined to be 0 — so span(∅) = {0}, never empty itself.
