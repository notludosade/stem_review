1. For u = (−3, 2) and w = (5, 1), what is u + w?

Add component-wise: (−3 + 5, 2 + 1) = (2, 3).

2. Fill in the blank: for v = (4, −3), the scalar multiple 3v = ___.

Scale every component by 3: (3·4, 3·−3) = (12, −9).

3. For v = (5, 12), answer both parts:

(a) What is ‖v‖?

(b) Fill in the blank: if w = −v, then ‖w‖ = ___.

(a) ‖v‖ = √(5² + 12²) = √169 = 13. (b) Magnitude scales by |c|, and |−1| = 1, so ‖−v‖ = ‖v‖ = 13 — flipping direction doesn't change length.

4. For v1 = (3, 0) and v2 = (0, −2), answer both parts:

(a) What is span{v1, v2}?

(b) Fill in the blank: the span of the empty set of vectors (no vectors at all) is ___.

(a) v1 and v2 point along different axes, so every (x, y) is reachable as (x/3)v1 + (y/−2)v2. (b) With no vectors to combine, only the empty sum is available, which is defined to equal 0 — so span(∅) = {0}, never empty itself.

5. A nonempty subset W of ℝ² that contains the origin and is closed under addition, but NOT closed under scalar multiplication, is:

All three conditions of the subspace test must hold; failing even one (here, scalar multiplication) disqualifies W, no matter how many others pass.

6. Answer both parts:

(a) For W = {(x, y) : x − y = 0}, is W a subspace of ℝ²?

(b) Fill in the blank (yes/no): for W' = {(x, y) : x² + y² = 1}, the unit circle, is W' closed under scalar multiplication?

(a) Every point (x, x) passes both closure checks, and (0, 0) satisfies the rule. (b) No — scaling (1, 0) on the circle by 2 gives (2, 0), which is off the circle (2² + 0² = 4 ≠ 1). The unit circle also doesn't contain the origin, so it fails the subspace test twice over.

7. Fill in the blank: for any vector v, v + (−v) = ___.

Every vector has an additive inverse, and adding it always produces the zero vector — the defining property of −v.

8. For v1 = (0, 4) and v2 = (−2, 1), answer both parts:

(a) What is 3v2 − v1?

(b) Fill in the blank: v1 + v2 = ___.

(a) 3v2 = (−6, 3), minus v1 = (0, 4) gives (−6, −1). (b) (0, 4) + (−2, 1) = (−2, 5).

9. If v1 = (0, 0) (the zero vector) and v2 = (3, −1), what is span{v1, v2}?

c1v1 + c2v2 = c1(0,0) + c2v2 = c2v2 — the zero vector contributes nothing to a span, so the result is exactly v2's own line.

10. Answer both parts:

(a) Are (7, −2) and (7, −2) equal vectors?

(b) Fill in the blank: for (2a, 6) to equal (10, 2b), a = ___.

(a) Identical components in identical positions — this is exactly vector equality. (b) Matching first components requires 2a = 10, so a = 5.
