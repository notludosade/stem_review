1. For A = [[1, −2], [3, 0]] and B = [[−4, 5], [2, 1]], what is A + B?

Add entry-by-entry: (1 + −4, −2 + 5; 3 + 2, 0 + 1) = (−3, 3; 5, 1).

2. Fill in the blank: for M = [[5, −2], [0, 3]], the scalar multiple −2M = ___.

Scale every entry by −2: (−2·5, −2·−2; −2·0, −2·3) = (−10, 4; 0, −6).

3. For A = [[1, 4, −2], [3, 0, 5]] (a 2×3 matrix), answer both parts:

(a) What are the dimensions of Aᵀ?

(b) Fill in the blank: the entry in row 1, column 2 of Aᵀ equals ___.

(a) Transposing swaps rows and columns: 2×3 becomes 3×2. (b) Entry (1,2) of Aᵀ is entry (2,1) of A, which is 3.

4. For A = [[1, 2], [0, −1]] and B = [[3, 1], [2, 4]], answer both parts:

(a) What is entry (1,1) of AB?

(b) Fill in the blank: entry (2,2) of AB = ___.

(a) Row 1 of A, (1,2), dotted with column 1 of B, (3,2): (1)(3)+(2)(2) = 7. (b) Row 2 of A, (0,−1), dotted with column 2 of B, (1,4): (0)(1)+(−1)(4) = −4.

5. If A is 2×3 and B is 3×2, how do AB and BA compare?

Both inner dimensions (3) match, so both products exist — but AB takes A's rows and B's columns (2×2), while BA takes B's rows and A's columns (3×3). Different sizes can't be equal.

6. Answer both parts:

(a) For any compatible matrix A, what is IA?

(b) Fill in the blank: I₃, the 3×3 identity matrix, has ___ ones along its main diagonal.

(a) I is the multiplicative identity for matrices, so IA = A. (b) An n×n identity matrix always has exactly n ones on its diagonal — here, 3.

7. Fill in the blank: a square matrix with no inverse is called ___.

"Singular" is the standard term — it's the opposite of "invertible" (or "nonsingular").

8. For A = [[2, 1], [1, 1]], answer both parts:

(a) What is det(A) = ad − bc?

(b) Fill in the blank: A⁻¹ = ___.

(a) ad − bc = (2)(1) − (1)(1) = 1. (b) A⁻¹ = (1/1)·[[1, −1], [−1, 2]] = [[1, −1], [−1, 2]].

9. Which of these matrices is singular (has no inverse)?

ad − bc = (2)(6) − (4)(3) = 12 − 12 = 0 — row 2 is exactly 1.5 times row 1, which is exactly the kind of redundancy that produces a zero determinant and no inverse.

10. For A = [[1, 0], [2, −1]] and B = [[0, 3], [1, 1]], answer both parts:

(a) What is A + B?

(b) Fill in the blank: AB = ___.

(a) Add entry-by-entry: (1+0, 0+3; 2+1, −1+1) = (1, 3; 3, 0). (b) Row 1 of A, (1,0), dotted with each column of B gives (0, 3). Row 2 of A, (2,−1), dotted with each column gives (2·0−1·1, 2·3−1·1) = (−1, 5). AB = [[0, 3], [−1, 5]].
