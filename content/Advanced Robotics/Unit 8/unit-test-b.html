Unit 8 Test — Version B

Full-System Integration. 10 questions covering every lesson in this unit. Score 80% or higher to clear this unit.

1. In the autonomy stack, what role does Unit 6's decision-making layer play relative to the other layers?

Decision-making sits above the other layers, coordinating which capability governs behavior rather than replacing any single layer.

2. If localization (Unit 3) in an autonomy stack produces a faulty pose estimate, what generally happens to that fault?

Each layer depends on the layers below it, so an early fault propagates downstream through the whole stack.

3. Answer both parts about warehouse robot fleets:

(a) In the two-robots-approaching-one-aisle example, why does a deadlock occur even though each robot's individual plan is correct?

(b) Fill in the blank: many warehouse robots carry an entire shelving ___ to a human picker rather than picking individual items.

(a) The deadlock comes from the interaction between two individually correct plans, not either plan being wrong. (b) Carrying whole shelving pods is a common real design choice.

4. Fill in the blank: the choice between LIDAR-based and camera-based (vSLAM) sensing in consumer robot vacuums is largely driven by ___ constraints, not which sensor is objectively better.

A consumer product's tight budget, not raw sensor superiority, drives the common choice of cheaper camera-based vSLAM over LIDAR.

5. Why do self-driving perception stacks typically fuse multiple sensor types rather than relying on just one?

Complementary sensors cover each other's specific weaknesses, which matters enormously when missed detections carry high stakes.

6. Fill in the blank: identifying that a sensed region is a specific type of object, like a pedestrian or a cyclist, is called object ___.

Object detection classifies what a sensed region actually is, going beyond a plain occupancy grid's free/occupied distinction.

7. Answer both parts about seam failures:

(a) In the localization-delay-versus-controller example, why does the mismatch only appear once the components are connected?

(b) Fill in the blank: catching seam failures requires testing the ___ system under realistic conditions, not just its parts.

(a) Both components behave correctly individually — the mismatch is about how their outputs interact once connected. (b) Only testing the full integrated system reveals seam failures.

8. What kind of seam failure could occur between a behavior tree's navigation branch and manipulation branch if not designed carefully?

Each branch's individually correct logic could independently assume exclusive arm control, a seam failure neither branch's own testing would catch alone.

9. Fill in the blank: the capstone's real lesson is that solving a genuine autonomous robot task requires ___ across every unit of this course at once.

Integration across every unit, not mastery of any single algorithm in isolation, was the real skill this course built toward.

10. Why does the capstone's behavior tree include a high-priority reactive branch for battery level, able to interrupt any other step?

Root-level re-evaluation every cycle is what lets a high-priority reactive branch interrupt a slower deliberative action at any point.
