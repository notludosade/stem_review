Unit 6 Test — Version B

Autonomy & Decision-Making. 10 questions covering every lesson in this unit. Score 80% or higher to clear this unit.

1. Why is purely deliberative control, by itself, too slow to dodge a sudden obstacle?

Reasoning over a full model before acting takes time that a sudden, immediate hazard doesn't allow for.

2. Fill in the blank: Unit 4's local obstacle avoidance is an example of ___ control, responding immediately with no lookahead beyond current surroundings.

Local obstacle avoidance reacts to immediate sensor data, the defining trait of reactive control, as opposed to global A* planning's deliberative reasoning.

3. Answer both parts about finite state machines:

(a) In a robot vacuum FSM with states Cleaning, Returning, and Charging, what determines the robot's current behavior?

(b) Fill in the blank: a named behavioral mode like 'Charging' is called a ___.

(a) An FSM's robot behavior is fully determined by its single current state. (b) States are the fixed set of named modes an FSM can occupy.

4. What happens to an FSM with no defined transition for a real failure case it actually encounters?

A missing transition for a real situation leaves the FSM with no defined behavior for it — unacceptable for hardware in a shared space.

5. What happened to the state count in the Lesson 32 worked example once realistic failure handling (ItemMissing, retries) was added?

Adding realistic failure handling grew the state count meaningfully — exactly the scaling problem that motivates behavior trees as an alternative.

6. Fill in the blank: the behavior tree status returned by a long-running action, like navigation, on every tick until it finishes, is called ___.

Running indicates an action is still in progress; the tree re-evaluates from the root each cycle while it's active.

7. Answer both parts about behavior tree composites:

(a) In a Selector over [Sequence(Attempt Grasp, Verify Grasp), Report Failure], if Attempt Grasp fails, what happens?

(b) Fill in the blank: if the Sequence succeeds instead, the Selector succeeds too and never evaluates ___.

(a) A Sequence fails immediately on its first failing child, prompting the Selector to try its next option. (b) A Selector stops trying children as soon as one succeeds.

8. Fill in the blank: in a behavior tree, adding one more failure case generally means adding one more ___, not rewiring the whole structure.

Behavior trees let new failure handling be added as an additional branch, unlike an FSM's need to wire new states and transitions throughout.

9. Why can a high-priority battery-check branch interrupt a long-running navigation action in a behavior tree?

Root-level re-evaluation every cycle is what lets a fast, high-priority branch preempt a slower, ongoing action without a separate interrupt mechanism.

10. Why is layering (combining reactive and deliberative control) the actual solution, rather than choosing and improving just one architecture?

Slow/brittle deliberation and goalless reaction are complementary flaws — combining both architectures, with a way for the fast layer to interrupt the slow one, addresses both.
