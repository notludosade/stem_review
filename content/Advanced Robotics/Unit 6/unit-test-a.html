1. What is the defining feature of reactive control?

Reactive control responds immediately to sensed conditions without building or reasoning over a broader model.

2. Fill in the blank: control that builds and reasons over a model of the situation before acting, like full route planning, is called ___ control.

Deliberative control is goal-directed and reasons ahead, at the cost of being slower than a pure reflex.

3. Answer both parts about finite state machines:

(a) At any given moment, how many states is a robot's FSM in?

(b) Fill in the blank: the rule that moves an FSM from one state to another, triggered by a condition, is called a ___.

(a) An FSM's robot is always in exactly one named state at a time. (b) Transitions are triggered by conditions like sensor thresholds or completed sub-tasks.

4. Why is handling plausible failure cases described as the real design work in building a robot FSM, more than the happy-path transitions?

An FSM without an explicit transition for a real failure either crashes, hangs, or silently misbehaves — handling failure well is where the real design effort goes.

5. Fill in the blank: as real robot behavior grows more complex with more failure cases, FSMs tend to need an unwieldy growth in the number of ___ and transitions needed.

Covering every situation with a manageable number of states and transitions gets unwieldy fast, which behavior trees address structurally.

6. Answer both parts about behavior tree node statuses:

(a) What are the three possible statuses a behavior tree node can return?

(b) Fill in the blank: a node that succeeds only if all its children succeed, in order, is called a ___ node.

(a) Success, Failure, and Running are the three statuses every BT node returns. (b) A Sequence node requires all children to succeed, in order, failing immediately on the first failure.

7. What does a Selector (Fallback) node do?

A Selector tries options in order until one succeeds, modeling 'try this, and if it fails, try that instead.'

8. How do behavior trees handle a new failure case differently than FSMs, according to this unit?

Behavior trees let new failure handling be added as an additional branch, unlike an FSM's need to wire new states and transitions throughout.

9. How does the Running status make behavior trees naturally reactive?

Re-evaluating from the root every tick means a high-priority reactive branch (like a battery check) can preempt a long-running deliberative action.

10. Fill in the blank: a control architecture combining fast reactive layers and slower deliberative layers, with the fast layer able to override when needed, is called a ___ architecture.

Layered (hybrid) architectures combine reactive and deliberative control rather than choosing only one.
