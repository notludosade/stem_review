Configuration Space

A robot isn't a point — but planning gets dramatically simpler once you shrink it into one, by growing the obstacles instead.

← Lesson 19 Lesson 21 → Contents Glossary →

The last lesson quietly treated the robot as a single point moving between graph nodes. Real robots have actual physical size and shape, and a path that looks clear for a point can be genuinely blocked for the robot's real body. Configuration space is the trick that resolves this without complicating every downstream calculation.

Definition A robot's configuration is a complete description of its state relevant to planning — for a simple mobile robot, its (x, y, θ) pose; for the arms in Unit 1, its joint values. Configuration space (or C-space) is the space of all possible configurations. Crucially, an obstacle in the real, physical world corresponds to a larger, "inflated" forbidden region in configuration space — not just the physical obstacle itself, but every configuration that would cause the robot's real body to collide with it.
Why inflating obstacles turns the robot back into a point If a circular mobile robot has radius r, "the robot's body doesn't hit this wall" is exactly equivalent to "the robot's center point stays at least r away from the wall." Growing every obstacle outward by r, then planning for the robot's center point alone against these grown obstacles, gives exactly the same valid paths as reasoning about the robot's true physical extent directly — at a fraction of the computational cost, because Lesson 19's graph-search machinery, built for point-like nodes, now applies without modification.
Example A circular robot with a 0.3 m radius approaches a doorway 0.7 m wide. In the real, physical world, the robot's body fits with 0.2 m to spare on each side. In configuration space, the doorway's two door-frame obstacles have each grown by 0.3 m, narrowing the gap between them to 0.7 − 2(0.3) = 0.1 m — still open, correctly reflecting that the robot's center can pass through with 0.05 m of margin on either side of that narrowed gap, matching the real-world clearance exactly.

For a non-circular robot, or a robot arm with several joints, configuration space gets more elaborate — a robot arm's C-space has as many dimensions as its degrees of freedom (Lesson 2), and "growing" an obstacle isn't as simple as a uniform radius. The core idea survives unchanged, though: however complex the robot's real shape and motion constraints are, they get absorbed once, up front, into how obstacles are represented in C-space — and every planning algorithm downstream gets to treat the robot as a simple point again.

With the graph built and the robot's real size accounted for, the next lesson covers the actual searching: the family of algorithms — starting simple, then building to A* — that find a route through this graph.

Check your recall

No peeking back up — answer from memory first, then check.

1. What is a robot's configuration space?

Configuration space is the space of all possible robot states — poses for a mobile robot, joint values for an arm — not a physical location.

2. Why does an obstacle in configuration space typically appear larger than the same obstacle in the physical world?

Inflating the obstacle by the robot's own size lets planning treat the robot as a single point while still correctly accounting for its real physical extent.

3. What is the main benefit of planning in configuration space rather than reasoning about the robot's true physical extent directly?

By inflating obstacles once up front, downstream planning algorithms can treat the robot as a point, avoiding repeated shape-collision checks during search.

4. Fill in the blank: a complete description of a robot's state relevant to planning — pose for a mobile robot, joint values for an arm — is called its ___.

Configuration is the state description; configuration space is the space of all such states.

5. For a circular robot with radius 0.25 m approaching a gap between two obstacles 1.0 m apart, fill in the blank: in configuration space, the effective gap between the inflated obstacles is ___ m.

Each obstacle grows by the robot's radius (0.25 m) on the side facing the gap, narrowing it by 2 × 0.25 m = 0.5 m: 1.0 − 0.5 = 0.5 m.
