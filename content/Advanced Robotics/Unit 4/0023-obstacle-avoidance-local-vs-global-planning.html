Obstacle Avoidance — Local vs. Global Planning

A* finds a path through the map the robot had. Obstacle avoidance is about the obstacles the map didn't have — the ones the robot only discovers by driving.

← Lesson 22 Lesson 24 → Contents Glossary →

A* (Lesson 22) is a global planner: given the whole map, it finds a complete route from start to goal before the robot moves at all. That route is only as good as the map it was computed from — and Unit 3 already established that maps are built from noisy sensors and can be incomplete, especially in previously unmapped or changed areas. Local planning, this lesson's subject, handles what the global plan couldn't have known about.

Definition Global planning computes a full path using the complete (already-known) map, typically before the robot starts moving. Local planning (or local obstacle avoidance) continuously adjusts the robot's immediate motion using only current, nearby sensor data — reacting to obstacles the global map didn't include, whether because they weren't there when the map was built or because that area was never mapped at all.
Why both layers are necessary, not redundant Global planning alone is blind to anything not already in the map — a person walking into the aisle, a dropped box, a door that's now closed. Local planning alone, with no global plan at all, can make locally sensible decisions that add up to a bad overall route, or get stuck in a dead end a global view would have avoided entirely. Running both together — global planning sets the intended route, local planning keeps execution safe and responsive along the way — is standard practice, not a matter of picking one.
Example A warehouse robot's global A* plan routes it straight down aisle 3 toward the goal. Partway down, its LIDAR detects a pallet left in the aisle since the map was last built — invisible to the global plan, real to the robot's current sensors. Local obstacle avoidance steers the robot around the pallet using only this immediate LIDAR data, without re-running full A* search over the entire warehouse — and once clear, the robot resumes following the original global route.

A common, simple local-avoidance idea is treating obstacles as generating a "push" and the goal as generating a "pull" — the robot's immediate motion follows the combined effect, moving toward the goal while steering away from anything sensed nearby. This kind of approach is fast to compute (essential, since it has to run continuously while driving) but genuinely local: it reasons about immediate surroundings only, with no memory of the map's overall structure, which is exactly why it needs a global plan alongside it rather than instead of it.

Local avoidance handles obstacles the map missed. It doesn't yet handle obstacles that are actively moving, or a mismatch serious enough that the whole global route needs reconsidering — both the subject of this unit's final lesson.

Check your recall

No peeking back up — answer from memory first, then check.

1. What is the key limitation of a global planner like A* that local obstacle avoidance addresses?

A global plan is fixed to the map's knowledge at planning time; local planning uses fresh sensor data to react to whatever the map missed.

2. Why is running both global and local planning together standard practice, rather than choosing just one?

Global planning sets an informed overall route; local planning keeps execution safe against what the map didn't capture — each covers the other's blind spot.

3. In the warehouse pallet example, what does local obstacle avoidance do once the robot has steered around the newly detected pallet?

Local avoidance handles the immediate obstacle without discarding the global plan — once clear, the robot simply continues along its original intended route.

4. Fill in the blank: computing a full path using the complete, already-known map, typically before the robot starts moving, is called ___ planning.

Global planning (like A*) uses the whole map at once, ahead of execution.

5. Fill in the blank: continuously adjusting a robot's immediate motion using only current, nearby sensor data is called ___ planning (or obstacle avoidance).

Local planning reacts to what's immediately sensed, handling what the global map couldn't have known about.
