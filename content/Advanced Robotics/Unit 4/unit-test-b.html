1. What connects two nodes in a planning graph, and what does it usually represent?

Edges represent valid transitions between nodes, typically weighted by cost such as distance.

2. What happens if a planning grid's resolution is made extremely fine ('for extra safety')?

Finer resolution is more faithful to the map but produces a much larger graph, trading search speed for precision the robot's own size may not require.

3. Answer both parts about configuration space:

(a) What is a robot's 'configuration'?

(b) A circular robot has radius 0.3 m. Fill in the blank: for a gap 1.2 m wide between two obstacles, the effective gap in configuration space is ___ m.

(a) Configuration is the state description — pose for a mobile robot, joint values for an arm. (b) 1.2 − 2(0.3) = 0.6 m.

4. What guarantee does breadth-first search (BFS) provide, and under what assumption?

BFS explores ring by ring, guaranteeing fewest edges traversed — which only equals shortest distance when all edges cost the same.

5. What specific inefficiency in Dijkstra's algorithm does adding a heuristic address?

Without any sense of direction toward the goal, Dijkstra explores wastefully; a heuristic lets a search prioritize promising nodes.

6. Answer both parts about A* search:

(a) A node has g(n) = 7 and h(n) = 2. What is f(n)?

(b) Fill in the blank: A* always expands the unvisited node with the lowest ___(n) value.

(a) f(n) = g(n) + h(n) = 7 + 2 = 9. (b) A* prioritizes nodes by f(n), the sum of cost-so-far and heuristic estimate.

7. Fill in the blank: a heuristic that never overestimates the true remaining cost to the goal is called ___.

An admissible heuristic never overestimates, which is what guarantees A* finds the true lowest-cost path.

8. Why is running both global and local planning together standard practice?

Global planning provides an informed overall route; local planning reacts to what the map couldn't have known — each covers the other's weakness.

9. Why can't local obstacle avoidance alone handle a doorway that is now completely blocked?

A completely blocked route isn't a small deviation to steer around — it requires the global plan itself to be recomputed via replanning.

10. Why does a moving obstacle violate a core assumption behind standard A* search?

A* searches a fixed, static graph; a moving obstacle changes the situation over time, which standard A* doesn't account for on its own.
