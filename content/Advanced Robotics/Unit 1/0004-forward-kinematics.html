Forward Kinematics

Given every joint angle, computing exactly where the end-effector ends up — a straightforward calculation, once you see it as chaining frames.

← Lesson 3 Lesson 5 → Contents Glossary →

Every joint on a robot arm has a sensor (an encoder — Unit 2 covers these properly) that reports its current angle or extension. Forward kinematics is the calculation that turns that whole list of joint values into a single answer: the pose of the end-effector.

Definition Forward kinematics is the function that maps a robot's joint values (angles for revolute joints, extensions for prismatic joints) to the position and orientation of its end-effector, expressed in the world frame. It is called "forward" because it goes in the natural direction of the chain: from the base, where you control the joints, out to the tip, where you care about the result.

The last lesson's frame-chaining idea is exactly the mechanism: knowing joint 1's angle fixes frame {1} relative to frame {0}; knowing joint 2's angle then fixes frame {2} relative to frame {1}; and so on. Forward kinematics is nothing more than combining all of these link-by-link relationships into one overall answer. The genuinely good news about forward kinematics, compared to almost everything else in this unit, is that it is always well-defined and computationally simple: plug in the joint values, and there is exactly one answer, computed directly with no searching or guessing required.

A worked example: the 2-link planar arm

The simplest non-trivial case is a robot arm confined to a flat plane, with two revolute joints and two links of length L1 and L2. Joint 1 (at the fixed base) has angle θ1, measured from the x-axis. Joint 2 has angle θ2, measured relative to link 1's own direction. The end-effector's (x, y) position works out to:

x = L1cos(θ1) + L2cos(θ1 + θ2)  y = L1sin(θ1) + L2sin(θ1 + θ2)

Each term is just "how far this link reaches in x (or y), given the total angle it's rotated to by the time you reach it." Link 1 reaches L1 at angle θ1; link 2 reaches L2 further, but at the combined angle θ1 + θ2, because link 2's own rotation is measured relative to link 1, which is itself already rotated by θ1. This is frame-chaining in formula form.

Worked example Let L1 = 0.5 m, L2 = 0.3 m, θ1 = 30°, θ2 = 45°. Then θ1 + θ2 = 75°. x = 0.5 cos(30°) + 0.3 cos(75°) = 0.5(0.866) + 0.3(0.259) ≈ 0.433 + 0.078 = 0.511 m. y = 0.5 sin(30°) + 0.3 sin(75°) = 0.5(0.5) + 0.3(0.966) ≈ 0.250 + 0.290 = 0.540 m. Given those two joint angles, the end-effector is at (0.511, 0.540) m — one answer, computed directly, no ambiguity.
Why this scales to real arms A 6-DOF arm in 3D uses the exact same idea — chain a frame transformation through each joint — just with rotation in three dimensions instead of a single plane angle, handled with the rotation-matrix machinery Lesson 3 deliberately set aside. The formula gets more involved, but the computation is still direct: plug in six joint values, get exactly one end-effector pose out. This is also precisely the calculation a robot's controller runs, continuously, just to know where its own end-effector currently is.

Forward kinematics answers "given these joint values, where does the arm end up?" The next lesson asks what range of end-effector positions are even reachable in the first place — before flipping the question around entirely in Lesson 6.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does forward kinematics compute?

Forward kinematics goes from joint values (known, controllable) to end-effector pose (the result) — the 'forward' direction along the chain.

2. For a 2-link planar arm, why does link 2's contribution use the angle (θ1 + θ2) rather than θ2 alone?

θ2 is defined relative to link 1's own direction, so link 2's true angle in the world frame is the sum θ1 + θ2 — exactly the frame-chaining idea from the previous lesson.

3. Why is forward kinematics described as 'always well-defined,' unlike inverse kinematics (next lesson)?

Given specific joint values, there is exactly one resulting end-effector pose — a direct calculation, not a search. Inverse kinematics, run the other direction, does not share this guarantee.

4. Fill in the blank: the calculation that maps a robot's joint values to its end-effector's pose is called ___ kinematics.

Forward kinematics runs in the natural base-to-tip direction of the chain.

5. For L1 = 0.4 m, L2 = 0.4 m, θ1 = 0°, θ2 = 90°, fill in the blank: the end-effector's y-coordinate is ___ m. (Round to 1 decimal place.)

y = L1 sin(θ1) + L2 sin(θ1+θ2) = 0.4 sin(0°) + 0.4 sin(90°) = 0 + 0.4(1) = 0.4 m.
