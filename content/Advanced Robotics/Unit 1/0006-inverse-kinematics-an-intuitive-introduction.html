Inverse Kinematics — An Intuitive Introduction

Forward kinematics has exactly one answer. Its reverse can have many, one, or none — and that difference is the whole difficulty.

← Lesson 5 Unit 2, Lesson 7 → Contents Glossary →

Every lesson so far has gone from joint values to end-effector pose. In practice, a task usually hands you the goal backward: "put the end-effector at this specific position," full stop, with no joint values given at all. Finding the joint values that achieve a target end-effector pose is inverse kinematics (IK), and it is a fundamentally harder problem than forward kinematics.

Definition Inverse kinematics is the problem of finding joint values that place the end-effector at a specified target pose. Unlike forward kinematics, a target pose can have zero solutions (the target is outside the workspace from Lesson 5), exactly one solution, or many solutions (multiple joint configurations reach the identical pose).
Why the reverse direction is harder Forward kinematics is a straightforward plug-in-and-compute formula, because you're moving in the natural direction the chain equations were written for. Running that same relationship backward means solving a system of nonlinear equations (the sines and cosines from Lesson 4's formula don't invert cleanly), and nonlinear systems don't come with a guarantee of exactly one clean answer the way linear ones often do. This many-to-one-or-none-or-many mismatch is the entire reason IK gets treated as a separate, harder problem rather than "just run forward kinematics in reverse."

A worked example: 2-link IK by geometry

For the 2-link planar arm, there's a clean geometric route to IK that avoids inverting the trig equations directly. Given a target point (x, y) and link lengths L1, L2, the triangle formed by the base, the elbow, and the target has known side lengths L1, L2, and r = √(x² + y²) (the straight-line distance from base to target). The law of cosines gives the elbow angle θ2 directly:

cos(θ2) = (r² − L1² − L2²) / (2·L1·L2)
Worked example Let L1 = 0.5 m, L2 = 0.3 m, and the target be (x, y) = (0.6, 0.2) m. Then r² = 0.6² + 0.2² = 0.36 + 0.04 = 0.40. cos(θ2) = (0.40 − 0.25 − 0.09) / (2 · 0.5 · 0.3) = 0.06 / 0.3 = 0.2, so θ2 = cos−1(0.2) ≈ 78.5°. From there, a short bit of geometry (not shown) recovers θ1 too. Notice the ± ambiguity already visible: cos−1(0.2) is satisfied by both +78.5° and −78.5°, corresponding to the elbow bending "up" or "down" — two different, equally valid joint configurations that place the end-effector at the exact same target.

That "elbow up or elbow down" ambiguity is the multiple-solutions case from the definition above, made concrete. If r had come out larger than L1 + L2, the target would be outside the workspace entirely — the zero-solutions case, and the formula would have no valid answer (cos(θ2) computing to something outside [−1, 1] is exactly how that shows up numerically).

For a 6-DOF arm in 3D, this kind of closed-form geometric approach usually isn't available — instead, IK is often solved numerically, by an iterative algorithm that starts from a guess and repeatedly adjusts the joint values to reduce the error between the current and target end-effector pose, converging toward a solution (or, if the target is unreachable, failing to converge at all). The details of those iterative solvers are beyond this course's scope, but the shape of the problem — search, don't just compute — is the key takeaway distinguishing IK from forward kinematics for the rest of this course.

Check your recall

No peeking back up — answer from memory first, then check.

1. Why can inverse kinematics have zero, one, or many solutions, while forward kinematics always has exactly one?

Forward kinematics is a direct plug-in computation. Running it backward means solving nonlinear trigonometric equations, which don't guarantee a single clean solution.

2. In the 2-link IK worked example, what does the ± ambiguity in θ2 = cos⁻¹(0.2) correspond to physically?

Both +78.5° and −78.5° are mathematically valid elbow angles, corresponding to the arm bending its elbow in two different but equally valid directions to reach the same point.

3. If a target point's distance r from the base exceeds L1 + L2, what does this mean for inverse kinematics?

r > L1 + L2 places the target beyond the arm's maximum reach (the outer radius of its workspace from Lesson 5) — geometrically unreachable, so IK has zero solutions.

4. Fill in the blank: the problem of finding joint values that place the end-effector at a specified target pose is called ___ kinematics.

Inverse kinematics runs the forward-kinematics relationship in reverse: pose to joint values, instead of joint values to pose.

5. Fill in the blank: unlike inverse kinematics, forward kinematics always has exactly ___ solution(s) for a given set of joint values.

Forward kinematics is a direct computation with no ambiguity — one set of joint values always produces exactly one end-effector pose.
