Glossary

Definitions in the exact form used across lessons.

← Lesson 1 Contents

Kinematics

Degree of Freedom (DOF)

The minimum number of independent numbers needed to fully specify a system's configuration.

Kinematic Chain

A series of rigid links connected by movable joints, from a robot's base to its end-effector.

End-Effector

The working tip of a robot's kinematic chain, such as a gripper, torch, or nozzle.

Pose

A rigid body's position together with its orientation.

Forward Kinematics

The calculation that maps a robot's joint values to its end-effector's pose.

Inverse Kinematics

The problem of finding joint values that place the end-effector at a specified target pose.

Workspace

The complete set of end-effector positions reachable by some combination of valid joint values.

Sensing and Perception

Proprioception

Sensing that measures a robot's own internal state, such as joint angles or wheel rotation.

Exteroception

Sensing that measures the external world, such as distance to obstacles or camera images.

LIDAR

A sensor that measures distance using time-of-flight: timing how long a laser pulse takes to reflect back.

Point Cloud

A set of individual (x, y, z) points built from many laser returns, describing surrounding surfaces in 3D.

Wheel Encoder

A sensor attached to a wheel's axle that counts discrete ticks as the wheel rotates.

Bias

A consistent, repeatable offset between a sensor's reading and the true value.

Noise

Unpredictable, scattered variation in a sensor's readings around the true value.

Sensor Fusion

Combining measurements from multiple sensors into a single, more reliable estimate.

Localization and Mapping

Localization

The problem of estimating a robot's own pose within an environment using noisy sensor data.

Dead Reckoning

Estimating current position by accumulating a sequence of small measured motions from a known starting pose.

Odometry

Dead reckoning built specifically from a wheeled robot's own encoder readings.

Drift

The growth of position error in a dead-reckoning estimate over time, caused by small per-step errors accumulating.

Occupancy Grid

A representation of the environment as a grid of cells, each estimating the probability of being occupied.

SLAM

Simultaneous Localization and Mapping — building a map while tracking the robot's own pose within it, at the same time.

Loop Closure

A detected match between a current sensor reading and a previously recorded observation, indicating a revisited location.

Path Planning

Configuration Space

The space of all possible configurations (states) a robot could be in, with obstacles inflated by the robot's own size.

A* Search

A graph search algorithm that expands the node with the lowest f(n) = g(n) + h(n), combining real cost-so-far with a heuristic.

Heuristic

A cheap estimate of remaining cost from a node to the goal, used to prioritize promising nodes during search.

Admissible Heuristic

A heuristic that never overestimates the true remaining cost to the goal.

Global Planning

Computing a full path using the complete, already-known map, typically before the robot starts moving.

Local Planning

Continuously adjusting a robot's immediate motion using only current, nearby sensor data.

Replanning

Recomputing a new global path after detecting the current one is no longer valid or safe.

Motion Control

Trajectory

A path together with specified timing — a function of intended position (and often velocity) over time.

Trajectory Generation

The process of computing a trajectory's timing, typically respecting velocity and acceleration limits.

Pure Pursuit

A steering strategy that continuously aims toward a point on the path a fixed lookahead distance ahead.

Lookahead Distance

In pure pursuit, the fixed distance ahead of the robot used to select the steering target.

Cross-Track Error

The perpendicular deviation between a robot's actual position and its intended position on the trajectory.

Trajectory Smoothing

Modifying a planned path to reduce sharp corners and abrupt direction changes, while still respecting obstacles.

Autonomy and Decision-Making

Reactive Control

Control that maps sensed conditions directly to actions, with little or no internal state or lookahead.

Deliberative Control

Control that builds and reasons over a model of the situation before acting.

Finite State Machine (FSM)

A fixed set of named states, with transitions between them triggered by specific conditions.

Behavior Tree

A tree of nodes, evaluated top-down and repeatedly, where each node returns Success, Failure, or Running.

Sequence Node

A behavior tree node that runs its children in order, succeeding only if all of them succeed.

Selector Node

A behavior tree node that tries its children in order, succeeding as soon as any one succeeds.

Layered Architecture

A control architecture combining fast reactive layers and slower deliberative layers, with the fast layer able to override when needed.

Manipulation

Manipulation

The deliberate use of a robot's end-effector to change the position, orientation, or state of an object.

Gripper

An end-effector with movable fingers or jaws that close around an object to hold it.

Grasp

A specific contact configuration and approach pose expected to hold an object securely.

Grasp Planning

The problem of selecting a grasp that is both physically reachable and mechanically sound.

Coefficient of Friction (μ)

A material-dependent constant relating grip (normal) force to the maximum friction force available before slipping.

Suction Gripper

An end-effector that holds an object using a pressure difference created by a vacuum pump.

Soft Gripper

A gripper built from flexible materials that passively deform to match an object's shape on contact.

Manipulation Pipeline

The ordered sequence Perceive, Plan, Grasp, and Place that a robot runs to complete a pick-and-place task.

Systems and Integration

Autonomy Stack

The full software architecture connecting a robot's perception, state estimation, planning, and control into one running system.

Seam Failure

A failure occurring because two correctly-functioning components made incompatible assumptions about each other.

Object Detection

Identifying that a sensed region is a specific type of object, like a pedestrian or a cyclist.

Object Tracking

Following a detected object's motion over time to predict where it's likely to go next.
