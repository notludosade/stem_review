Loss Functions: Measuring How Wrong a Prediction Is

AI Developer's Lesson 13 used loss(w) = (w − 3) ** 2 as a stand-in and moved on. Before gradient descent can do anything real, that stand-in needs to become an actual, deliberately chosen function — and the choice depends entirely on what kind of answer the network is producing.

← Lesson 1 Lesson 3 → Contents Glossary →

A loss function takes a prediction and the true answer and returns one number: how bad that prediction was. Every training loop in this course minimizes some loss function — the only question, lesson to lesson, is which one, and that answer depends on what the output layer is actually predicting.

Python — the two workhorse losses 
import numpy as np

def mse(prediction, true_value):
    return (prediction - true_value) ** 2

def cross_entropy(predicted_prob, true_label):
    # true_label is 0 or 1; predicted_prob is the model's P(class = 1)
    p = np.clip(predicted_prob, 1e-9, 1 - 1e-9)   # avoid log(0)
    return -(true_label * np.log(p) + (1 - true_label) * np.log(1 - p))

print(mse(0.9, 1.0))              # 0.01  — small, close prediction
print(cross_entropy(0.9, 1))      # 0.105 — small, close prediction
print(cross_entropy(0.01, 1))     # 4.605 — confidently wrong, punished hard

Mean Squared Error (MSE) — squared difference between prediction and truth — is the standard loss for regression, predicting a continuous number, exactly as it was for AI Developer's linear regression. Cross-entropy loss is the standard for classification instead, and it is not just MSE with a different name: look at the last two lines above. A prediction of 0.9 versus a true label of 1 scores fine under either loss. But a confidently wrong prediction — 0.01 when the answer was 1 — gets a mild MSE penalty of about 0.98, while cross-entropy explodes toward infinity as a wrong prediction's confidence approaches 0 or 1. That's deliberate: cross-entropy is built from log-probability, so it punishes overconfident mistakes far more severely than a middling one.

Definition A loss function scores how wrong a single prediction was against the true value. Mean Squared Error (MSE), (prediction − true)², is the standard loss for regression. Cross-entropy loss, built from negative log-probability, is the standard loss for classification, and grows sharply as a confident prediction turns out to be wrong.
Why cross-entropy pairs with sigmoid and softmax specifically Lesson 1's sigmoid and softmax both squash their output toward 0 or 1 for large inputs — recall that near-flat region. Pairing a squashed output with MSE can leave gradient descent almost nothing to follow: MSE's own slope also flattens out exactly where the prediction is most confidently wrong, compounding the saturation problem instead of cutting through it. Cross-entropy's log term does the opposite — it stays steep exactly where a confident prediction is wrong, which is precisely where a network most needs a strong training signal. This is why virtually no real classifier pairs sigmoid or softmax with MSE.
