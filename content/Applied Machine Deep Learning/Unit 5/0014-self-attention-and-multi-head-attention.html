Self-Attention and Multi-Head Attention

AI Developer's Lesson 17 computed one attention pass and asked what "multi-head" meant without answering. This lesson answers it — and shows why one attention computation per layer usually isn't enough.

← Lesson 13 Lesson 15 → Contents Glossary →

Recall the shape: every token produces a query, a key, and a value; softmax(Q @ K.T / sqrt(d)) @ V blends every token's value according to how relevant each one is to each query. That single computation is one attention head. The problem: a sentence has more than one kind of relationship happening between its words at once — grammatical agreement, which word modifies which, which pronoun refers to which noun — and a single attention head has to average all of those into one weighted blend per token. Some of that gets lost in the average.

Python — NumPy, splitting into multiple heads 
import numpy as np

def softmax(x):
    e = np.exp(x - np.max(x, axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)

def attention(Q, K, V):
    scores = Q @ K.T / np.sqrt(Q.shape[-1])
    return softmax(scores) @ V

seq_len, d_model, num_heads = 4, 8, 2
d_head = d_model // num_heads   # each head works in a smaller subspace

x = np.random.rand(seq_len, d_model)

head_outputs = []
for h in range(num_heads):
    Wq, Wk, Wv = (np.random.randn(d_model, d_head) * 0.1 for _ in range(3))
    Q, K, V = x @ Wq, x @ Wk, x @ Wv     # each head gets its own learned projection
    head_outputs.append(attention(Q, K, V))

multi_head_output = np.concatenate(head_outputs, axis=-1)   # back to shape (seq_len, d_model)

Multi-head attention runs several smaller attention computations in parallel instead of one large one — here, 2 heads, each working in a 4-dimensional subspace instead of one head working in the full 8-dimensional space. Each head has its own learned Wq, Wk, Wv projections, so nothing forces two heads to learn the same kind of relevance; in practice, different heads in a trained Transformer often specialize — one attending mostly to a word's immediate neighbor, another tracking a pronoun back to the noun it refers to, several places away. The heads' outputs get concatenated back together at the end, landing back at the model's original dimension, so the rest of the network never has to know how many heads were involved.

Definition An attention head is one full query/key/value attention computation. Multi-head attention runs several attention heads in parallel, each with its own learned projections working in a smaller subspace, then concatenates their outputs back together.
Why splitting into smaller heads isn't just "more capacity" Splitting one 8-dimensional head into two 4-dimensional heads doesn't meaningfully increase the total parameter count or computation — it's roughly the same total budget, spent differently. The actual gain is representational diversity: one head's softmax necessarily produces one weighting per token, forcing every kind of relevance into a single blend, while several smaller, independently-learned heads can each specialize in a different relationship without competing with each other for the same weights.

1. What is one "attention head," concretely?

softmax(Q @ K.T / sqrt(d)) @ V computed once, with one set of Q/K/V, is one attention head.

2. Why might a single attention head struggle to capture more than one kind of relationship between words?

One softmax output per token means one combined weighting, not several independent ones.

3. What happens to multiple attention heads' outputs at the end of a multi-head attention layer?

np.concatenate(head_outputs, axis=-1) restores the model's original dimensionality after the heads run in parallel.
