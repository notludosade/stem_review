The Transformer Architecture End to End

Lesson 14 built multi-head attention. That's the centerpiece, but a real Transformer block needs three more pieces around it before it's an architecture you could actually stack and train — this lesson assembles all of it.

← Lesson 14 Unit 6, Lesson 16 → Contents Glossary →

Attention has one blind spot: Q @ K.T is completely symmetric with respect to position — shuffle the input tokens, and the same relevance scores come out shuffled right along with them, with nothing in the math itself encoding "this token came third." Positional encoding fixes this directly: a fixed pattern of values, one per position, added elementwise to each token's embedding before attention ever runs, giving the model something position-dependent to work with despite attention itself having no built-in sense of order.

Python — one full Transformer block 
import torch.nn as nn

class TransformerBlock(nn.Module):
    def __init__(self, d_model, num_heads, d_ff):
        super().__init__()
        self.attn = nn.MultiheadAttention(d_model, num_heads, batch_first=True)
        self.norm1 = nn.LayerNorm(d_model)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff), nn.ReLU(), nn.Linear(d_ff, d_model)
        )
        self.norm2 = nn.LayerNorm(d_model)

    def forward(self, x):
        attn_out, _ = self.attn(x, x, x)          # self-attention: x attends to itself
        x = self.norm1(x + attn_out)               # residual connection, then normalize
        ffn_out = self.ffn(x)                       # same small MLP, applied per token
        x = self.norm2(x + ffn_out)                 # residual connection again
        return x

Two x + … lines are residual connections — the exact same additive shortcut Lesson 12's LSTM cell state used to keep gradients from vanishing, applied here across depth instead of across time. Each one is immediately followed by layer normalization, which rescales each token's vector to have a stable mean and variance before the next sub-layer sees it — keeping values in a well-behaved range so a stack of dozens of these blocks doesn't drift toward instability as depth increases. The feed-forward network is an ordinary two-layer MLP, exactly Unit 1's shape, applied independently to every token's vector — it's where each token gets to process what attention just gathered, on its own, without looking at any other token. Stack this whole block N times (real models commonly use dozens), and the model's final output is one context-aware vector per input token, ready for whatever the task needs — Lesson 1's softmax for next-token prediction, a classification head, or anything else.

Definition Positional encoding injects position information into token embeddings, since attention itself is order-agnostic. A residual connection adds a sub-layer's input back onto its output. Layer normalization rescales each token's vector to a stable range after each residual addition. The feed-forward network is a small MLP applied independently, per token, after attention.
Why residual connections matter more as Transformers get deeper A 96-layer Transformer stacks the block above 96 times. Without residual connections, that's a 96-layer-deep chain a gradient would have to backpropagate through using nothing but Unit 2's ordinary chain rule — exactly the setup that produces vanishing gradients, just across depth instead of across an RNN's time steps. The x + attn_out and x + ffn_out lines give the gradient a direct, unobstructed path backward through every block, parallel to whatever the attention and feed-forward sub-layers are doing — the same additive trick Lesson 12's cell state used, reapplied to make depth itself survivable.

Shuffling input tokens shuffles Q @ K.T's output right along with them — order has to be injected separately.
