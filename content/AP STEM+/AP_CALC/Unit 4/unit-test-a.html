1. P(t) is a plant's height in centimeters, t weeks after planting. The units of P′(t) are:

A derivative's units are always (units of output)/(units of input): centimeters per week. Flipping the ratio, multiplying instead of dividing, and squaring the input's units (that's acceleration's unit, one derivative further) are the three distractors.

2. N(t) is the number of bacteria in a colony, t hours after t = 0. Suppose N′(5) = −300. Answer both parts:

(a) At t = 5, the population is:

(b) Fill in the blank: the population is shrinking by about ___ bacteria per hour at t = 5.

(a) A negative derivative always means the quantity is decreasing at that instant, regardless of context. (b) N′(5) = −300 bacteria/hour is the instantaneous rate at t = 5 — over one more hour, the population is predicted to shrink by approximately that same 300 bacteria, treating the rate as roughly constant over such a short step.

3. An object has v(t) = 7 and a(t) = −3 at some instant. The object is:

Velocity is positive and acceleration is negative — opposite signs — so the object is slowing down. It's still moving forward right now (v(t) ≠ 0), just decelerating, which rules out "at rest."

4. A particle's position is s(t) = t³ − 9t² + 24t (meters). Answer both parts:

(a) v(t) equals:

(b) Fill in the blank: the object is first momentarily at rest (the smaller of two such times) at t = ___.

(a) Differentiating term by term: d/dt[t³] = 3t², d/dt[−9t²] = −18t, d/dt[24t] = 24, giving v(t) = 3t² − 18t + 24. (b) Setting v(t) = 0: 3t² − 18t + 24 = 0 → t² − 6t + 8 = 0 → (t − 2)(t − 4) = 0, so t = 2 or t = 4 — the smaller value is 2.

5. In the related-rates strategy, numeric values for the changing quantities should be substituted:

Plugging in a specific numeric value before differentiating "freezes" that variable into a constant, whose derivative is 0 — destroying the very relationship you need. Numbers go in only after the derivative is taken.

6. A circle's area is A = πr². At the instant r = 5 cm and dr/dt = 3 cm/s, answer both parts:

(a) Differentiating A = πr² with respect to t gives dA/dt equals:

(b) Fill in the blank: dA/dt = ___ cm²/s (leave your answer in terms of π).

(a) The Power Rule and Chain Rule together give d/dt[πr²] = π·2r·(dr/dt) = 2πr·(dr/dt), since r is itself a function of t. (b) Substituting r = 5, dr/dt = 3 only after differentiating: dA/dt = 2π(5)(3) = 30π ≈ 94.2 cm²/s.

7. For a function that is concave down on an interval, the linearization L(x) at a point a in that interval:

A concave-down curve lies below its own tangent lines everywhere except the point of tangency — so the tangent line's height, L(x), sits above the true curve, overestimating f(x).

8. Let f(x) = ∛x (the cube root of x) and a = 8, so f(8) = 2. Answer both parts:

(a) f′(8) equals:

(b) Fill in the blank: using L(x) = f(8) + f′(8)(x − 8), the linearization estimate for ∛8.6 is L(8.6) = ___.

(a) f′(x) = (1/3)x^(−2/3). At x = 8: 8^(2/3) = (∛8)² = 2² = 4, so x^(−2/3) = 1/4, and f′(8) = (1/3)(1/4) = 1/12. (b) L(8.6) = 2 + (1/12)(8.6 − 8) = 2 + (1/12)(0.6) = 2 + 0.05 = 2.05.

9. Direct substitution into lim f(x)/g(x) yields 0/0. Fill in the blank: this is called an ___ form, one of exactly two forms (along with ∞/∞) that license L'Hôpital's Rule.

0/0 has no defined value on its own — it could resolve to anything depending on how fast numerator and denominator approach zero. That's exactly what "indeterminate" means, and it's the signal that licenses L'Hôpital's Rule.

10. Consider limx→0 (1 − cos(2x))/x², which plugs in to 0/0. Answer both parts:

(a) After one application of L'Hôpital's Rule, this limit becomes:

(b) Fill in the blank: the limit's exact value is ___.

(a) Differentiating top and bottom: d/dx[1 − cos(2x)] = 2sin(2x), d/dx[x²] = 2x, giving lim (2sin(2x))/(2x). (b) Plugging in x = 0 still gives 0/0 — indeterminate again — so a second application is needed: d/dx[2sin(2x)] = 4cos(2x), d/dx[2x] = 2, giving lim (4cos(2x))/2 = 4(1)/2 = 2.
