L'Hôpital's Rule

Some limits plug in to 0/0 and refuse to simplify by any algebra trick you know. Derivatives — the tool this whole unit has been applying — turn out to crack them open too.

← Lesson 4 Unit 5, Lesson 1 → Contents Glossary →

This unit has spent four lessons using derivatives to describe the world — rates, motion, related rates, approximation. This last lesson turns the derivative back on a purely computational problem: limits that older factoring and rationalizing tricks can't touch.

1. Indeterminate forms

Formula A limit limx→a f(x)/g(x) is an indeterminate form if plugging in x = a gives 0/0 or ∞/∞ — an expression with no defined value on its own, since it could resolve to anything depending on how fast the numerator and denominator each approach their limit.
Formula — L'Hôpital's Rule If limx→a f(x)/g(x) is 0/0 or ∞/∞, then limx→a f(x)/g(x) = limx→a f′(x)/g′(x), provided that second limit exists. Take the derivative of the top and the derivative of the bottom separately — this is not the quotient rule, and nothing here differentiates f(x)/g(x) as a single fraction.
Worked Example limx→0 (sin x)/x plugs in to 0/0 — indeterminate. Differentiating top and bottom separately: limx→0 (cos x)/1 = cos(0) = 1, matching the well-known result from Unit 1's limit work, now reached by a completely different route.

2. Checking the form before every application

The single most common mistake with this rule is applying it to a limit that was never indeterminate in the first place. The check is mandatory and comes before anything else.

Try It — Spot the Indeterminate Form

Plug in x = 3: (9 − 9)/(3 − 3) = 0/0. Indeterminate — L'Hôpital's Rule applies. Differentiating: lim (2x)/(1) = 2(3) = 6.

Plug in x = 3: (3 + 1)/(3 − 3) = 4/0. Not indeterminate — this is a nonzero number over zero, which signals a vertical asymptote (the limit diverges to ±∞ or fails to exist), not a 0/0 or ∞/∞ form. L'Hôpital's Rule does not apply here.

Plug in x = 0: (e⁰ − 1)/0 = 0/0. Indeterminate — L'Hôpital's Rule applies. Differentiating: lim (eˣ)/(1) = e⁰ = 1.

3. Repeated application

Worked Example limx→0 (1 − cos x)/x² plugs in to 0/0. Differentiating once: lim (sin x)/(2x), which plugs in to 0/0 again. Differentiating a second time: lim (cos x)/2 = cos(0)/2 = 1/2. The rule can be reapplied as many times as needed, as long as each new limit is still indeterminate before you differentiate again.

Check your recall

1. L'Hôpital's Rule may be applied to lim f(x)/g(x) only when direct substitution gives:

Only the two indeterminate forms, 0/0 and ∞/∞, license L'Hôpital's Rule. A nonzero number over zero signals a diverging limit (often ±∞), and zero over a nonzero number already has a perfectly good value — zero — without any further work.

2. L'Hôpital's Rule replaces lim f(x)/g(x) with lim ___, provided the original limit was 0/0 or ∞/∞.

The rule differentiates numerator and denominator independently — f′(x)/g′(x) — never the quotient rule applied to f(x)/g(x) as one expression.

3. limx→0 (1 − cos x)/x² requires how many applications of L'Hôpital's Rule before it stops being indeterminate?

The first application gives (sin x)/(2x), which is still 0/0 at x = 0 — indeterminate a second time. Only the second application, giving (cos x)/2, resolves to a definite value, 1/2.
