1. For f(x) = x on [0, 6] with n = 3 subintervals (Δx = 2), the left Riemann sum equals:

Left endpoints are x = 0, 2, 4, with heights 0, 2, 4. Summing (0 + 2 + 4)·2 = 12. (The right sum, using x = 2, 4, 6, would give 24; the midpoint sum, using x = 1, 3, 5, would give 18.)

2. Fill in the blank: since a Riemann sum's rectangle heights are negative wherever f(x) < 0, a definite integral measures ___ area, not plain area.

Regions above the x-axis contribute positively and regions below subtract — that's exactly what "signed" (or "net signed") area means, distinct from the plain, always-positive area enclosed by a curve.

3. Let g(x) = ∫3x (2t + 1) dt. Answer both parts:

(a) By FTC Part 1, g′(x) equals:

(b) Fill in the blank: d/dx ∫0x³ cos(t) dt = cos(x³) · ___

(a) FTC Part 1 hands back the integrand evaluated at the upper bound x, directly: g′(x) = 2x + 1 — the lower bound 3 never even enters. (b) The upper bound here is x³, not x, so the Chain Rule contributes a factor of d/dx[x³] = 3x².

4. If ∫27 f dx = 10 and ∫27 g dx = 4, then ∫27 (3f(x) − g(x)) dx equals:

The constant-multiple and difference properties split this apart: 3∫f dx − ∫g dx = 3(10) − 4 = 30 − 4 = 26.

5. ∫25 3x² dx equals:

An antiderivative of 3x² is F(x) = x³. By FTC Part 2: F(5) − F(2) = 125 − 8 = 117.

6. A particle's velocity is v(t) = t − 4 (m/s) on [0, 8]. Answer both parts:

(a) The net displacement over [0, 8] is:

(b) Fill in the blank: the total distance traveled over [0, 8] is ___ meters.

(a) An antiderivative is F(t) = t²/2 − 4t. Net displacement = F(8) − F(0) = 0 − 0 = 0. (b) v(t) = 0 at t = 4, splitting the interval: |F(4) − F(0)| + |F(8) − F(4)| = |−8 − 0| + |0 − (−8)| = 8 + 8 = 16 meters, even though the particle ends up back where it started.

7. Let f(x) = 4x³ − 6x. Answer both parts:

(a) The general antiderivative of f is:

(b) Fill in the blank: if F′(x) = 4x³ − 6x and F(1) = 5, then C = ___.

(a) Reversing the Power Rule term by term: ∫4x³ dx = x⁴, ∫−6x dx = −3x², plus a constant of integration: F(x) = x⁴ − 3x² + C. (b) F(1) = 1 − 3 + C = −2 + C = 5, so C = 7.

8. For ∫ 5x⁴(x⁵ + 2)³ dx, answer both parts:

(a) The correct substitution is:

(b) Fill in the blank: with that substitution, du = ___ dx.

(a) u = x⁵ + 2 is the "inside" piece being raised to a power, and its derivative is exactly the leftover factor outside the parentheses. (b) Differentiating u = x⁵ + 2 gives du = 5x⁴ dx.

9. For ∫ 1/(x² − 4x + 13) dx, answer both parts:

(a) Completing the square, x² − 4x + 13 equals:

(b) Fill in the blank: so ∫ 1/(x² − 4x + 13) dx = (1/3)·arctan((x − 2)/___) + C.

(a) (x − 2)² = x² − 4x + 4, so matching x² − 4x + 13 requires adding back 9 more: (x − 2)² + 9. (b) This matches the standard form ∫ du/(u² + a²) = (1/a)·arctan(u/a) + C with u = x − 2 and a² = 9, so a = 3.

10. ∫ x·cos(x) dx, using integration by parts with u = x and dv = cos(x) dx, equals:

With u = x (du = dx) and dv = cos(x) dx (v = sin(x)): ∫u dv = uv − ∫v du = x·sin(x) − ∫sin(x) dx = x·sin(x) − (−cos(x)) + C = x·sin(x) + cos(x) + C.
