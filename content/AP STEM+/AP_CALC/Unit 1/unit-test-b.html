1. Which best describes what limx→c f(x) = L means?

The formal meaning is about the approach, not an exact requirement at c itself — f(c) might be undefined, might equal L, or might equal something else, and none of that changes whether the limit itself is L.

2. Let k(x) = 3 − x for x < 1, and k(x) = x² for x ≥ 1. Answer both parts about the behavior at x = 1:

(a) What is limx→1⁺ k(x)?

(b) Fill in the blank: Since limx→1⁻ k(x) = 2 and limx→1⁺ k(x) = 1 disagree, limx→1 k(x) = ___.

(a) For x ≥ 1, k(x) = x², so as x → 1⁺, k(x) → 1² = 1. (b) The left-hand limit is 3 − 1 = 2 ≠ 1, so the two-sided limit does not exist (DNE), even though k(1) = 1 itself is a perfectly ordinary number.

3. limx→−1 (2x² + 4x − 3) equals:

Since 2x² + 4x − 3 is a polynomial, it's continuous everywhere, so direct substitution applies with no algebra first: 2(−1)² + 4(−1) − 3 = 2 − 4 − 3 = −5.

4. A function m(x) satisfies 2 − x² ≤ m(x) ≤ 2 + x² for all x near 0. By the Squeeze Theorem, limx→0 m(x) equals:

Both bounding functions approach 2 as x → 0 (2 − 0² = 2 and 2 + 0² = 2), so m is squeezed to that same value regardless of its exact behavior in between.

5. Answer both parts about evaluating limits algebraically:

(a) limx→−2 (x² − 4)/(x + 2) equals:

(b) Fill in the blank: Rationalizing the numerator, limx→0 (√(x + 16) − 4)/x = ___ (as a fraction).

(a) Factoring gives (x − 2)(x + 2)/(x + 2) = x − 2 for x ≠ −2, and substituting x = −2 gives −2 − 2 = −4. (b) Multiplying by the conjugate √(x + 16) + 4 turns the numerator into (x + 16) − 16 = x, cancelling the x in the denominator and leaving 1/(√(x + 16) + 4); substituting x = 0 gives 1/(4 + 4) = 1/8.

6. Let f(x) = 2x − 1 for x ≠ 4, and f(4) = 3. Answer both parts:

(a) Which continuity condition fails for f at x = 4?

(b) Fill in the blank: To repair this discontinuity, f(4) should be redefined to equal ___.

limx→4 f(x) = 2(4) − 1 = 7, but f(4) = 3 — both the limit and f(4) exist individually, they just disagree, so redefining f(4) = 7 would remove the (removable) discontinuity entirely.

7. A function q(x) jumps abruptly from approaching 2 on the left to starting at 6 on the right, right at x = 3 — with no vertical asymptote and no redefinable point that could fix it. What type of discontinuity does q have at x = 3?

A jump discontinuity occurs when the left-hand and right-hand limits both exist individually but disagree with each other — unlike a removable discontinuity, no single redefined value at x = 3 could make the two-sided limit exist.

8. Let h(x) = 1 / ((x + 2)(x − 6)). Answer both parts:

(a) The vertical asymptotes of h occur at:

(b) Fill in the blank: If the numerator of a rational function also equals zero at the same point where the denominator is zero, that point is a ___ instead of a vertical asymptote.

(a) The denominator (x + 2)(x − 6) is zero at x = −2 and x = 6, and the numerator (1) is never zero, so both are genuine vertical asymptotes. (b) A shared zero in numerator and denominator cancels algebraically before any division by zero happens, producing a hole (a removable discontinuity) rather than an asymptote.

9. Fill in the blank: For f(x) = (2x − 7)/(4x + 1), since the numerator and denominator have equal degree, the horizontal asymptote is y = ___ (as a decimal or fraction).

With equal degrees in numerator and denominator, the horizontal asymptote is the ratio of the leading coefficients: 2/4 = 1/2.

10. Let f(x) = x³ − 4x − 1, continuous everywhere, with f(2) = −1 and f(3) = 14. Answer both parts:

(a) Which fact justifies using the IVT to guarantee a root of f in (2, 3)?

(b) Fill in the blank: The IVT guarantees at least ___ value(s) of c in (2, 3) with f(c) = 0.

(a) The IVT needs only continuity on [2, 3] and the target value 0 lying between f(2) and f(3) — whether f is increasing or decreasing, and its endpoint signs beyond "0 is between them," are irrelevant. (b) The theorem guarantees existence, never uniqueness — there might be exactly one root or several, and the IVT holds regardless.
