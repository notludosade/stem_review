1. By definition, f′(a) equals:

The derivative is the limit of the difference quotient as h → 0 — not a fixed-h approximation, and not with the wrong sign or denominator.

2. For g(x) = x³, use the symmetric difference quotient [g(a + h) − g(a − h)] / (2h) to estimate g′(3) with h = 0.1. Answer both parts:

(a) g(3.1) − g(2.9) is closest to:

(b) Fill in the blank: [g(3.1) − g(2.9)] / 0.2 rounds to ___ (to two decimal places).

(a) g(3.1) = 3.1³ = 29.791 and g(2.9) = 2.9³ = 24.389, so their difference is 29.791 − 24.389 = 5.402. (b) Dividing by 2h = 0.2 gives 5.402 / 0.2 = 27.01, very close to the exact derivative g′(3) = 3(3)² = 27.

3. Which of the following is NOT alternate notation for the derivative of y = f(x) with respect to x?

∫f(x)dx denotes an antiderivative (integral), an entirely different operation — the other three are all standard ways of writing the same derivative.

4. Which statement correctly describes the relationship between differentiability and continuity at a point?

If f′(a) exists, f must be continuous at a — but the converse fails, as with f(x) = |x| at x = 0, which is continuous yet has no derivative there (a corner).

5. For h(x) = 2x⁵ − 4x³ + 6x − 9, answer both parts:

(a) h′(x) equals:

(b) Fill in the blank: h″(x) = 40x³ − 24x + ___.

(a) Differentiating term by term: d/dx[2x⁵] = 10x⁴, d/dx[−4x³] = −12x², d/dx[6x] = 6, d/dx[−9] = 0 — giving 10x⁴ − 12x² + 6. (b) Differentiating again: 10x⁴ → 40x³, −12x² → −24x, and the constant 6 → 0, so h″(x) = 40x³ − 24x + 0.

6. For f(x) = 3sin(x) − 2cos(x), answer both parts:

(a) f′(x) equals:

(b) Fill in the blank: f′(0) = ___.

(a) d/dx[3sin x] = 3cos x, and d/dx[−2cos x] = −2·(−sin x) = 2sin x, so f′(x) = 3cos x + 2sin x. (b) At x = 0: f′(0) = 3cos(0) + 2sin(0) = 3(1) + 2(0) = 3.

7. Fill in the blank: d/dx[5eˣ] = ___.

eˣ is its own derivative, so the Constant Multiple Rule just carries the 5 along unchanged: d/dx[5eˣ] = 5eˣ.

8. d/dx[csc x] equals:

Cosecant's derivative carries a minus sign (like its "co" partner cotangent) and pairs csc x with cot x — not with tan x, which belongs to secant's derivative instead.

9. For p(x) = x²·cos(x), answer both parts:

(a) p′(x) equals:

(b) Fill in the blank: p′(0) = ___.

(a) With f(x) = x² (f′ = 2x) and g(x) = cos x (g′ = −sin x), the Product Rule gives p′(x) = 2x·cos x + x²·(−sin x) = 2x cos x − x² sin x. (b) At x = 0: p′(0) = 2(0)cos(0) − 0²sin(0) = 0.

10. For q(x) = cos(x) / (x + 1), answer both parts:

(a) q′(x) equals:

(b) Fill in the blank: q′(0) = ___.

(a) With f(x) = cos x (f′ = −sin x) and g(x) = x + 1 (g′ = 1), the Quotient Rule gives q′(x) = [f′g − fg′]/g² = [−sin(x)(x+1) − cos(x)] / (x+1)². (b) At x = 0: q′(0) = [−sin(0)(1) − cos(0)]/1² = [0 − 1]/1 = −1.
