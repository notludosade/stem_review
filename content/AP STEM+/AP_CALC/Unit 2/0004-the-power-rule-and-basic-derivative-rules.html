The Power Rule and Basic Derivative Rules

The limit definition, done once and for all — so you never have to run it again for a polynomial.

← Lesson 3 Lesson 5 → Contents Glossary →

Lessons 1–3 built the derivative from the limit definition, term by careful term. That's the last time this course computes a derivative that way. From here on, a handful of shortcut rules — all provably equivalent to the limit definition — do the work instantly.

1. The Power Rule

Rule Power Rule: for any real number n, d/dx[xⁿ] = n·xn−1.

This holds for positive integers (x², x³, ...), negative integers (x⁻¹ = 1/x), and fractional exponents (x^(1/2) = √x) alike — the exponent drops down as a coefficient, and the new exponent is one less than before.

2. Constant, sum, difference, and constant multiple

Rules Constant Rule: d/dx[c] = 0. Constant Multiple Rule: d/dx[c·f(x)] = c·f′(x). Sum/Difference Rule: d/dx[f(x) ± g(x)] = f′(x) ± g′(x).

Together with the Power Rule, these four facts are enough to differentiate any polynomial term by term — no limit required for any of it.

Worked Example For h(x) = 3x⁴ − 2x³ + 5x − 7: differentiate each term separately. d/dx[3x⁴] = 12x³ (Power Rule + constant multiple). d/dx[−2x³] = −6x² . d/dx[5x] = 5 (since x¹ has derivative 1·x⁰ = 1). d/dx[−7] = 0 (Constant Rule). Add them up: h′(x) = 12x³ − 6x² + 5.
