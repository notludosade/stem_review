Expected Value

Unit 4 closes by turning a random outcome into a single number: not what will happen on any one trial, but what the long-run average settles toward if you repeated the experiment forever. It's the concept behind "the house always wins" and every insurance premium ever set.

← Lesson 11 Lesson 13 → Contents Glossary →

1. Random variables

Definition — Random Variable A random variable X is a function from the sample space S to the real numbers: X: S → ℝ. It assigns a number to every outcome — "number of heads in 3 coin flips," "sum of two dice," "dollars won" — turning an abstract outcome into something you can average and compare.

2. Expected value

Definition — Expected Value The expected value of a discrete random variable X is E[X] = Σ x · P(X = x), summed over every value x that X can take. It is a probability-weighted average — each possible value contributes in proportion to how likely it is.
Worked example — a fair game Roll a fair die: if it lands on 6, you win $5; otherwise, you lose $1. Let X = your winnings. X = 5 with probability 1/6, and X = −1 with probability 5/6. E[X] = 5·(1/6) + (−1)·(5/6) = 5/6 − 5/6 = 0. On any single roll you either win $5 or lose $1 — you never actually see "$0" happen — but averaged over many, many rolls, your winnings per roll converge toward exactly $0. This is what makes it a mathematically fair game: E[X] = 0 means neither side has an edge in the long run.
Why "expected" doesn't mean "most likely" or "guaranteed" E[X] = 0 in the example above is not one of X's two possible values (5 and −1) at all — it's the long-run average, not a prediction about any single trial. This is the single most common misreading of expected value: E[X] = 3.5 for a fair die roll doesn't mean you should expect to roll a 3.5 (impossible) — it means if you rolled the die a huge number of times and averaged the results, that average would converge to 3.5. Casinos and insurers rely on exactly this gap between "any one outcome" and "the long-run average" to run profitable businesses on games and policies where nearly every individual event is unpredictable.
Linearity of Expectation For any random variables X and Y (independent or not), E[X + Y] = E[X] + E[Y]. This holds unconditionally, which makes it one of the most useful shortcuts in probability — it lets you compute the expected value of a complicated sum by breaking it into simpler pieces and adding their expectations, without ever needing to know how the pieces interact.

1. A random variable is best described as:

A random variable is formally a function X: S → ℝ — it converts each outcome of the sample space into a number, which is what makes averaging ("expected value") possible.

2. A game costs $2 to play. You win $10 with probability 0.1, and win nothing otherwise. What is the expected net profit per play?

Expected winnings = 10(0.1) + 0(0.9) = 1. Net profit subtracts the $2 cost: 1 − 2 = −$1, so the game loses money for the player on average.

3. E[X] = 3.5 for rolling one fair six-sided die. What does this actually mean?

Expected value is a long-run average, not a prediction about any individual trial or the "most likely" outcome — no single roll can ever equal 3.5.

4. Fill in the blank: for the $5-on-a-6, otherwise-lose-$1 game, E[X] = 5(1/6) + (−1)(5/6) = ___.

5/6 − 5/6 = 0 — a mathematically fair game, with no long-run edge to either side.

5. Fill in the blank: the rule E[X + Y] = E[X] + E[Y], which holds even when X and Y aren't independent, is called ___.

Linearity of expectation holds unconditionally, regardless of dependence between X and Y, which is what makes it such a powerful computational shortcut.
