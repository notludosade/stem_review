Modular Arithmetic

This closing lesson of Unit 6 turns the Division Algorithm's remainder into arithmetic that wraps around — exactly like a clock, where 9 plus 5 hours lands back on 2, not 14. It's the same wraparound logic behind cryptography, hash tables, and every calendar calculation.

1. Congruence modulo n

Definition — Congruence Modulo n For a fixed positive integer n (the modulus), integers a and b are congruent modulo n, written a ≡ b (mod n), if n | (a − b) — equivalently, a and b leave the same remainder when divided by n via Lesson 16's Division Algorithm.
Worked example 17 ≡ 5 (mod 12), since 12 | (17 − 5 = 12). Both 17 and 5 leave remainder 5 when divided by 12 (17 = 12·1 + 5; 5 = 12·0 + 5). This is exactly clock arithmetic: 17:00 and 5:00 point to the same spot on a 12-hour clock face.
Definition — a mod n a mod n denotes the unique remainder r from the Division Algorithm applied to a and n — the single representative of a's congruence class in the range 0 ≤ r < n. So 17 mod 12 = 5, and (−1) mod 12 = 11 (since −1 = 12(−1) + 11).

2. Arithmetic respects congruence

Property — Modular Addition and Multiplication If a ≡ b (mod n) and c ≡ d (mod n), then a + c ≡ b + d (mod n), and a · c ≡ b · d (mod n). In practice, this means you can reduce mod n at any point in a calculation — before, during, or after — without changing the final answer mod n, which is what makes modular arithmetic tractable for huge numbers.
Worked example What is 9 + 5 on a 12-hour clock? 9 + 5 = 14, and 14 mod 12 = 2 — so the clock reads 2. Or reduce first: 9 ≡ 9, 5 ≡ 5 (mod 12), so 9 + 5 ≡ 2 (mod 12) directly, without ever computing 14.
Why this matters beyond clocks Cryptographic systems like RSA perform modular exponentiation on numbers hundreds of digits long — computing the full result first and reducing afterward would be computationally infeasible, but reducing mod n at every intermediate step keeps every number in the calculation small throughout. Hash tables use "key mod (table size)" to assign entries to a fixed number of slots. Both rely on exactly this fact: you never need the "real" value, only its residue mod n.

1. Is 23 ≡ 8 (mod 5) true?

23 − 8 = 15, and 5 | 15, so 23 ≡ 8 (mod 5) — congruence doesn't require equality, only equal remainders (both are 3).

2. What is (−1) mod 12?

−1 = 12(−1) + 11, and the remainder must satisfy 0 ≤ r < 12, so (−1) mod 12 = 11.

3. Why can modular arithmetic reduce values mod n at any point during a calculation, without affecting the final answer mod n?

Since a≡b and c≡d (mod n) guarantees a+c≡b+d and a·c≡b·d (mod n), swapping any number for a congruent one at any step never changes the final result's residue mod n.

4. Fill in the blank: on a 12-hour clock, 9 + 5 wraps around to ___.

9 + 5 = 14, and 14 mod 12 = 2.

5. Fill in the blank: in a ≡ b (mod n), the fixed number n is called the ___.

n is the modulus — the number that determines how the wraparound works and defines each congruence class.
