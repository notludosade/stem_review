Set Notation and Operations

Unit 1 kept writing "x ∈ D" without ever defining D formally. This lesson defines it: what a set is, the standard number sets you'll use for the rest of the course, and the operations — union, intersection, difference, complement — that combine sets the way Lesson 2's connectives combined statements.

1. Sets, membership, and notation

Definition — Set A set is an unordered collection of distinct objects, called its elements. x ∈ A means "x is an element of A"; x ∉ A means it isn't. A set can be written by roster notation — listing elements, like A = {2, 4, 6, 8} — or by set-builder notation — a predicate describing membership, like A = {x ∈ ℤ : x is even and 0 < x < 10}, read "the set of x in ℤ such that x is even and between 0 and 10." Order and repetition don't matter: {1, 2, 3} and {3, 1, 2, 1} name the exact same set.
Convention — The Natural Numbers, in This Course Different textbooks disagree about whether 0 counts as a natural number. This course fixes a convention and uses it everywhere from here on: ℕ = {0, 1, 2, 3, …} — 0 is included. When a later lesson needs the positive integers only, it says so explicitly (usually written ℤ⁺ or "n ≥ 1"), rather than relying on ℕ to exclude 0. The other standard number sets: ℤ = {…, −2, −1, 0, 1, 2, …} (integers), ℚ (rationals, ratios of integers), ℝ (reals). ℕ ⊆ ℤ ⊆ ℚ ⊆ ℝ.

2. The empty set and subsets

Definition — Empty Set (∅) and Subset (⊆) The empty set, written ∅ or {}, is the unique set with no elements. A is a subset of B, written A ⊆ B, if every element of A is also an element of B — formally, ∀x, x ∈ A → x ∈ B. A is a proper subset of B, written A ⊂ B, if A ⊆ B and A ≠ B (B has at least one element A doesn't).
Why ∅ is a subset of every set — including itself ∅ ⊆ B for every set B, including B = ∅ itself. This follows directly from Lesson 3's vacuous truth: the subset definition is ∀x, x ∈ ∅ → x ∈ B, a universally-quantified statement over the empty domain — vacuously true no matter what B is, since there is no x ∈ ∅ that could ever violate it. This is one of the most commonly-doubted facts in this unit precisely because it feels like it should require ∅ to "have something in common" with B; it doesn't need to, because the implication is never even tested.

3. Set operations

Definitions — Union, Intersection, Difference, Complement Union: A ∪ B = {x : x ∈ A ∨ x ∈ B} — everything in A, B, or both. Intersection: A ∩ B = {x : x ∈ A ∧ x ∈ B} — only what's in both. Difference: A − B = {x : x ∈ A ∧ x ∉ B} — in A but not B. Complement (relative to a fixed universal set U): Aᶜ = U − A — everything in U that's not in A. Notice the pattern: union mirrors ∨, intersection mirrors ∧, and complement mirrors ¬ — set operations are Lesson 2's connectives wearing different notation.
Worked example Let U = {1,...,10}, A = {2,4,6,8,10} (evens), B = {3,6,9} (multiples of 3). A ∪ B = {2,3,4,6,8,9,10}. A ∩ B = {6} (the one number in both). A − B = {2,4,8,10} (evens that aren't multiples of 3). Aᶜ = {1,3,5,7,9} (the odds).
De Morgan's Laws for Sets (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ, and (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ. These are exactly the quantifier-negation rules from Lesson 3, and the connective-level De Morgan's laws, restated in set language — the same underlying idea appears at three levels of this course's vocabulary so far: statements, quantifiers, and now sets.

1. In this course's convention, is 0 a natural number?

This course explicitly fixes the convention ℕ = {0, 1, 2, 3, …}, including 0, and uses it consistently in every later lesson.

2. Is ∅ a subset of itself?

∅ ⊆ B is vacuously true for every B whatsoever, including B = ∅ — there's no element of ∅ that could ever fail to be in B.

3. Let U = {1,...,10}, A = {2,4,6,8,10}, B = {3,6,9}. What is A ∩ B?

The only element in both A and B is 6, so A ∩ B = {6}.

4. Fill in the blank (use "A^c" for complement of A and "intersect" for ∩): by De Morgan's law, (A ∪ B)ᶜ = ___.

De Morgan's law for sets: the complement of a union equals the intersection of the complements, (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ.

5. Fill in the blank: A ⊂ B (with A ⊆ B and A ≠ B) means A is a ___ of B.

⊂ specifically marks a subset that is not equal to the larger set — B must contain at least one element A doesn't, which is exactly the definition of a proper subset.
