1. What is a process's address space?

Each process gets its own private, isolated address space, laid out by the operating system into the text, data, heap, and stack regions.

2. Fill in the blank: the region holding a program's compiled machine instructions, normally marked read-only, is called the ___.

The text (or code) segment holds instructions and is protected from being overwritten by a running bug.

3. What does a stack frame hold?

A frame is per-call bookkeeping, popped in one step when its function returns.

4. Fill in the blank: the stack removes frames in ___ order — the most recently added frame is always removed first.

Last-in-first-out (LIFO) is exactly how nested function calls unwind correctly.

5. Why is it dangerous for a function to return a pointer to one of its own local variables?

The frame is gone the moment the function returns, making that address unsafe to use afterward.

6. A program declares int x = 5; inside a function, and separately calls malloc(sizeof(int)) to get a pointer p. Answer both parts:

(a) x's memory is automatically freed...

(b) The block p points to is automatically freed...

Stack locals are freed automatically on return; heap allocations stay reserved until explicitly freed.

7. Fill in the blank: the standard C function that releases a heap block back, given a pointer previously returned by malloc, is ___.

free() is the counterpart to malloc(), releasing the block back for reuse.

8. What exactly is a memory leak?

A leak is a reserved-but-unreachable block — the OS won't reclaim it while the process is still running.

9. What tradeoff does garbage collection in Python or Java make, compared to C's manual malloc/free?

Garbage collection buys safety from leaked/forgotten frees at a real, measurable performance cost.

10. Fill in the blank: unbounded recursion that pushes frames past the space reserved for the stack causes a ___, which the OS detects and terminates the program for.

A stack overflow is the OS stopping a runaway stack before it corrupts adjacent memory.
