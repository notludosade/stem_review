1. A direct proof of "if x is a multiple of 6, then x is a multiple of 3" should begin by assuming what?

A direct proof of P → Q assumes only the hypothesis P — here, "x is a multiple of 6" — and reasons forward toward the conclusion.

2. A student "proves" if n is even then n² is even by writing: "Since n² is even, n² = 2m for some integer m, so n = √(2m), which is even." What is the flaw?

A direct proof of P → Q may only assume P. Starting from Q and reasoning toward P does not establish P → Q, regardless of whether the conclusion happens to be true.

3. Fill in the blank: by definition, an integer n is even exactly when n = ___ for some integer k.

n = 2k is the definition of even, used throughout every parity proof in this unit.

4. Which integer k witnesses 9 ∣ 117 (that is, 117 = 9k)?

9 × 13 = 117, so k = 13 is the required witness.

5. Fill in the blank: A ⊆ B means every element of A is also an element of ___.

Subset is the claim ∀x, x ∈ A → x ∈ B — every element of A lands in B.

6. Consider proving: if a and b are even, then a − b is even. Let a = 2j and b = 2k. Answer both parts:

(a) What is a − b in a form matching the definition of even?

(b) Fill in the blank: since j − k is an integer, a − b = 2m where m = ___.

a − b = 2j − 2k = 2(j − k), matching the definition of even with witness m = j − k.

7. Suppose a ∣ b with b = 7a, and b ∣ c with c = 5b. Answer both parts:

(a) Which integer witnesses a ∣ c?

(b) Fill in the blank: c = a × ___.

c = 5b = 5(7a) = 35a, so a ∣ c with witness 35.

8. When proving A ⊆ C from A ⊆ B and B ⊆ C, answer both parts:

(a) Why must x be an arbitrary element of A, rather than one specific chosen element?

(b) Fill in the blank: x must be an ___ element of A — fixed for the argument, but with no special property assumed beyond membership in A.

(a) A universal claim needs an argument valid for every element, which is exactly what an arbitrary, property-free element provides. (b) "Arbitrary" is the precise term.

9. Let X = {n ∈ ℤ : n is a multiple of 4} and Y = {n ∈ ℤ : n is a multiple of 2}. Answer both parts:

(a) Which inclusion holds?

(b) Fill in the blank: X ≠ Y, witnessed by the smallest positive element of Y \ X, which is ___.

(a) Every multiple of 4 is a multiple of 2 (X ⊆ Y), but 2 ∈ Y is not a multiple of 4, so Y ⊄ X. (b) 2 is the smallest positive witness that Y ⊄ X.

10. Claim: "if a and b are odd integers, then a + b is even." A student writes: "a = 2k + 1, b = 2k + 1, so a + b = 4k + 2 = 2(2k + 1), which is even." Answer both parts:

(a) What is the actual gap in this proof?

(b) Fill in the blank: reusing k for both witnesses silently assumes a and b are ___.

The conclusion is true, but this argument doesn't establish it for arbitrary odd a and b — only for a = b. A valid proof needs two independent witnesses, a = 2j + 1 and b = 2k + 1.
