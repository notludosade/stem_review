1. A direct proof of "if x is a multiple of 10, then x is a multiple of 5" should begin by assuming what?

A direct proof of P → Q assumes only the hypothesis P — here, "x is a multiple of 10" — and reasons forward toward the conclusion.

2. A student "proves" if n is odd then n² is odd by writing: "Since n² is odd, n² = 2m + 1 for some integer m, so n = √(2m + 1), which is odd." What is the flaw?

A direct proof of P → Q may only assume P. Starting from Q and reasoning toward P does not establish P → Q, regardless of whether the conclusion happens to be true.

3. Fill in the blank: by definition, an integer n is odd exactly when n = ___ for some integer k.

n = 2k + 1 is the definition of odd, used throughout every parity proof in this unit.

4. Which integer k witnesses 11 ∣ 143 (that is, 143 = 11k)?

11 × 13 = 143, so k = 13 is the required witness.

5. Fill in the blank: A = B means A ⊆ B and B ⊆ ___.

Set equality by double inclusion requires both A ⊆ B and B ⊆ A.

6. Consider proving: if a and b are even, then ab is a multiple of 4. Let a = 2j and b = 2k. Answer both parts:

(a) What is ab in a form matching "multiple of 4"?

(b) Fill in the blank: ab = 4 × ___.

ab = (2j)(2k) = 4jk, matching the definition of "multiple of 4" with witness jk.

7. Suppose a ∣ b with b = 3a, and b ∣ c with c = 8b. Answer both parts:

(a) Which integer witnesses a ∣ c?

(b) Fill in the blank: c = a × ___.

c = 8b = 8(3a) = 24a, so a ∣ c with witness 24.

8. When proving A ⊆ C from A ⊆ B and B ⊆ C, answer both parts:

(a) What must be true of the element x used in the argument?

(b) Fill in the blank: this works because A ⊆ C is a ___ quantified claim — the argument must hold for every element, so it can use nothing specific to one chosen element.

(a) An arbitrary element with no special properties is what lets the argument generalize. (b) A ⊆ C unpacks to a universally quantified statement over all of A.

9. Let X = {n ∈ ℤ : n is a multiple of 6} and Y = {n ∈ ℤ : n is a multiple of 3}. Answer both parts:

(a) Which inclusion holds?

(b) Fill in the blank: X ≠ Y, witnessed by the smallest positive element of Y \ X, which is ___.

(a) Every multiple of 6 is a multiple of 3 (X ⊆ Y), but 3 ∈ Y is not a multiple of 6, so Y ⊄ X. (b) 3 is the smallest positive witness that Y ⊄ X.

10. Claim: "if a and b are even integers, then ab is a multiple of 4." A student writes: "a = 2k, b = 2k, so ab = 4k², which is a multiple of 4." Answer both parts:

(a) What is the actual gap in this proof?

(b) Fill in the blank: reusing k for both witnesses silently assumes a and b are ___.

The conclusion is true, but this argument doesn't establish it for arbitrary even a and b — only for a = b. A valid proof needs two independent witnesses, a = 2j and b = 2k.
