Reading a Broken CI Pipeline

Lesson 5 covered the easy case: green means safe, red means look. This lesson is about actually looking — reading a build log to tell a real bug apart from a test that was never trustworthy in the first place.

← Lesson 5 Unit 3, Lesson 7 → Contents Glossary →

A red build tells you something failed. It doesn't tell you why, and "why" determines what happens next: a real bug needs a code fix, a broken test needs a test fix, and a flaky test needs something else entirely — usually just clicking retry and moving on, which is a far less satisfying answer than it sounds.

Reading the build log

Definition A build log is the recorded output of every stage the CI server ran, in order, including exactly where it stopped and why. Reading one well means starting at the first failure, not the last line of output — later stages often never ran at all (Lesson 5's fail-fast ordering), and later error messages are frequently just noise caused by the first real failure.
Definition A flaky test is a test that sometimes passes and sometimes fails against the exact same code, with nothing about the code actually changing between runs — usually caused by timing assumptions, shared state between tests, or a dependency on something outside the test's control (like the current time or network latency). A flaky test is worse than a test that's simply wrong: a wrong test is at least consistently wrong, while a flaky one slowly teaches everyone on the team to distrust red builds and start ignoring them.

    Why "root cause, not symptom" matters most on a broken pipeline
    It's tempting to fix whatever the last error message says, but the last message is frequently a symptom of an earlier one — a database connection failure three stages in might just be fallout from a config change that broke at build time, long before any test ran. Diagnosing from the first failure backward, instead of the last failure forward, is usually the difference between a five-minute fix and an hour spent chasing an effect instead of its cause.
