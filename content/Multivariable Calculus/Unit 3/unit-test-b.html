1. For a unit vector u, Duf(x,y) is computed as:

The directional derivative is the gradient dotted with the chosen unit direction vector.

2. Fill in the blank: at a point where ∇f = ⟨6, 8⟩, the maximum possible directional derivative in any direction is ___

The maximum of D_u f is |∇f| = √(36+64) = √100 = 10.

3. The tangent plane to z = f(x,y) at (a,b) is given by:

The tangent plane is the surface's best flat approximation — the base value plus one linear correction term per partial derivative.

4. At a critical point, D = fxxfyy − (fxy)² > 0 and fxx < 0. The point is:

D > 0 means consistent curvature in every direction; the sign of f_xx then decides max (negative) versus min (positive).

5. Every local maximum or minimum of a differentiable f(x,y) must occur at:

A critical point (∇f = 0, or undefined) is a necessary condition for a local extremum, though not every critical point is actually an extremum.

6. For f(x,y) = x² + y² at (5, 12), in the direction u = ⟨0, 1⟩, answer both parts:

(a) Fill in the blank: ∇f(5,12) = ___ (format: <a,b>)

(b) Fill in the blank: Duf(5,12) = ___

(a) ∇f = ⟨2x,2y⟩, so ∇f(5,12) = ⟨10,24⟩. (b) D_u f = ⟨10,24⟩ · ⟨0,1⟩ = 24 — exactly f_y(5,12), since u is the y-direction.

7. For f(x,y) = xy² at (a,b) = (1, 2), answer both parts:

(a) The linearization L(x,y) at (1,2) is:

(b) Fill in the blank: L(1.2, 1.9) = ___

(a) f(1,2)=4, f_x=y²=4, f_y=2xy=4, so L(x,y) = 4 + 4(x−1) + 4(y−2). (b) L(1.2,1.9) = 4 + 4(0.2) + 4(−0.1) = 4 + 0.8 − 0.4 = 4.4.

8. For f(x,y) = y² − x² at the critical point (0,0), answer both parts:

(a) Fill in the blank: D = fxxfyy − (fxy)² = ___

(b) The point (0,0) is:

(a) f_xx = -2, f_yy = 2, f_xy = 0, so D = (-2)(2) - 0 = -4. (b) D < 0 means a saddle point — f increases along the y-axis and decreases along the x-axis through the origin.

9. For f(x,y) = x² + y² at (0, 3), answer both parts:

(a) Fill in the blank: ∇f(0,3) = ___ (format: <a,b>)

(b) The directional derivative Duf(0,3) is exactly 0 for u equal to:

(a) ∇f = ⟨2x,2y⟩, so ∇f(0,3) = ⟨0,6⟩. (b) D_u f = 0 exactly when u ⊥ ∇f; ⟨1,0⟩ · ⟨0,6⟩ = 0, the horizontal direction along the level curve there.

10. For f(x,y) = x² + y² at (2,1), answer both parts:

(a) A normal vector to the tangent plane at (2,1) is:

(b) Fill in the blank: f(2,1) = ___

(a) The normal is ⟨f_x, f_y, -1⟩ = ⟨4,2,-1⟩ at (2,1). (b) f(2,1) = 4 + 1 = 5.
