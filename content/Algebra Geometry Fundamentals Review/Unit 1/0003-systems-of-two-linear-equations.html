Systems of Two Linear Equations

Two lines, one shared point — and two clean algebraic ways to find it without graphing anything.

← Lesson 2 Lesson 4 → Contents Glossary →

A system of equations is a set of equations considered together, where a solution must satisfy every equation at once. For two linear equations in x and y, that solution is the single point where their two lines cross — assuming they aren't parallel or the exact same line.

Why sliding m₁ to equal m₂ breaks it Set both sliders to the same slope: the lines become parallel and the point vanishes — no solution, because parallel lines with different intercepts never cross. Now also match both intercepts: the lines lie exactly on top of each other, and every point is a solution. These are the three possible outcomes for any linear system: exactly one solution, no solution, or infinitely many.

Solving without a graph: substitution

Solve: y = 2x − 1 and y = −x + 5 Step 1 — Both equations already equal y, so set them equal to each other: 2x − 1 = −x + 5.
Step 2 — Solve for x: 3x = 6, so x = 2.
Step 3 — Substitute back into either original equation: y = 2(2) − 1 = 3.
Solution: (2, 3).

Solving without a graph: elimination

Solve: 3x + 2y = 12 and x − 2y = 4 Step 1 — The y-terms are already opposites (+2y and −2y), so add the equations directly: 4x = 16.
Step 2 — Solve: x = 4.
Step 3 — Substitute into either original equation: 4 − 2y = 4, so y = 0.
Solution: (4, 0).
Definition Substitution solves one equation for one variable and plugs that expression into the other equation. Elimination adds or subtracts multiples of the two equations so one variable's terms cancel out entirely. Both always produce the same solution — pick whichever is less work for the specific system in front of you.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does the solution to a system of two linear equations represent graphically?

A solution must satisfy both equations at once, which is exactly the (x, y) pair where both lines pass through the same point.

2. A system's two lines are parallel with different y-intercepts. How many solutions does the system have?

Parallel lines with different intercepts never cross, so no (x, y) pair satisfies both equations.

3. Solve by substitution: y = x + 1 and y = 3x − 5. What is x?

x + 1 = 3x − 5 → 6 = 2x → x = 3.

4. Fill in the blank: adding 2x + y = 7 to x − y = 2 cancels the y-terms directly — this technique is called ___.

Elimination adds or subtracts the equations (or scaled versions of them) so that one variable's terms cancel out.

5. Fill in the blank: if a system's two equations describe the exact same line, the system has ___ solutions.

Every point on an identical line satisfies both equations, so there are infinitely many solutions rather than one or zero.
