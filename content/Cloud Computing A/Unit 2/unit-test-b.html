1. What role does a hypervisor play with respect to a virtual machine?

The hypervisor is the layer that carves physical hardware into isolated virtual machines.

2. Fill in the blank: a software-based emulation of a complete computer — its own virtual CPU, memory, and disk — running on top of a physical machine alongside others, is called a ___.

This is the definition of a virtual machine, created and isolated by the hypervisor.

3. A team needs a VM with enough vCPU and memory for a busy production database, but doesn't want to negotiate a custom hardware carve-up. What should they do?

Instance sizes exist precisely so a customer can pick a fitting slice without custom negotiation.

4. Four containers run on one host machine. How many operating system kernels are running underneath them?

Containers share one host OS kernel, unlike VMs, which each run their own guest OS.

5. Why does booting a VM take much longer than starting a container?

The full OS boot process is what makes VM startup inherently slower than container startup.

6. Comparing isolation strength between VMs and containers. Answer both parts:

(a) At what level is a VM's isolation enforced?

(b) At what level is a container's isolation enforced?

VM isolation is a hardware-level hypervisor boundary; container isolation is a lighter-weight, process-level boundary enforced by the shared kernel.

7. Fill in the blank: computing where the provider runs uploaded function code only when a triggering event occurs, without the developer provisioning any server themselves, is called ___ computing.

This describes serverless (FaaS) computing exactly.

8. A serverless thumbnail-generation function sits with no uploads for hours. What happens to its cost during that time?

Scale-to-zero is exactly this: no traffic means no held capacity and no cost.

9. Fill in the blank: a serverless function invoked frequently enough to keep its execution environment ready, avoiding the extra startup delay, is described as staying ___.

A "warm" function skips the cold start delay because its environment is already spun up from a recent invocation.

10. A workload is spiky and mostly idle, with occasional bursts of activity. Why is serverless often the cheaper choice for it compared to an always-on VM?

Serverless's cost advantage is specific to idle, spiky workloads, where an always-on VM would otherwise bill for unused time.
