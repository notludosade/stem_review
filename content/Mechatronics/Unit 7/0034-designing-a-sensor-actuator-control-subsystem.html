Designing a Sensor + Actuator + Control Subsystem

Six units of individual pieces. This lesson is the recipe for combining them into one working system.

← Unit 6, Lesson 33 Lesson 35 → Contents Glossary →

Units 1 through 6 each covered one piece: a sensor, an actuator, a microcontroller, a signal-processing technique, a control strategy. Real mechatronic systems need all of them working together. This lesson lays out the general recipe every remaining lesson in this unit follows.

The recipe, in order 1. Identify the physical quantity to control, and pick a sensor that measures it (Unit 1). 2. Identify the actuator that can actually affect that quantity (Unit 2). 3. Decide on a control strategy matched to the actuator's nature — bang-bang for a strictly on/off actuator, PID for a continuously variable one (Units 5–6). 4. Add filtering if the sensor is noisy enough to need it, especially before any derivative term (Unit 4). 5. Write the setup/loop program tying read → decide → write together (Unit 3), running that decision fresh every single pass through loop().

Matching control strategy to actuator, specifically

Why this matching step can’t be skipped A relay-driven heater (a strictly on/off actuator) physically cannot produce a smooth, in-between output — commanding it with a PID controller's continuously variable number doesn't make it act proportionally, since the relay only has fully on and fully off to work with. Bang-bang control is often the correct choice for such an actuator, not a lesser one. Conversely, a PWM-driven DC fan (a continuously variable actuator) can genuinely use PID's smooth output — restricting it to bang-bang wastes real capability, exactly the point Unit 5, Lesson 27 raised.
A middle ground worth knowing Some on/off actuators can still get proportional-like behavior by combining bang-bang switching with PWM — a solid-state relay (SSR) with phase control, for instance, can approximate a variable output on an otherwise strictly on/off load. This is beyond this course's scope in detail, but it's worth knowing the on/off-vs-proportional line isn't always as hard as "relay means bang-bang, full stop."

The next two lessons walk through this recipe on two concrete, worked systems — a temperature-controlled fan, and a line-following robot's steering logic — showing exactly how the five steps above turn into a real, working program.
