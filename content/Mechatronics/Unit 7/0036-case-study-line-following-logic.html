Case Study: Line-Following Logic

A classic beginner robotics problem — and a second, very different application of the exact same error-driven correction idea.

← Lesson 35 Lesson 37 → Contents Glossary →

A line-following robot steers itself along a marked path using nothing but two simple light sensors and a differential steering correction — no camera, no map, just the same feedback idea from Unit 5 applied to steering instead of temperature.

The sensor setup Two reflectance sensors (photoresistors or phototransistors from Unit 1, Lessons 1 and 3) are mounted on the front of the robot, spaced a little wider than the line is thick — one just left of center, one just right. A dark line reflects less light than the surrounding floor, so each sensor's reading indicates whether it's currently over the line or over open floor.

Simple decision logic — a bang-bang-like approach

Pseudocode: differential steering correction 
loop():
    leftOnLine = readLeftSensor() < THRESHOLD
    rightOnLine = readRightSensor() < THRESHOLD

    if leftOnLine AND NOT rightOnLine:
        // line drifting left of center - steer left
        setMotors(leftSpeed = SLOW, rightSpeed = FAST)
    elif rightOnLine AND NOT leftOnLine:
        // line drifting right of center - steer right
        setMotors(leftSpeed = FAST, rightSpeed = SLOW)
    else:
        // both on the line, or both off it - go straight
        setMotors(leftSpeed = FAST, rightSpeed = FAST)

This is genuinely bang-bang-like control (Unit 5, Lesson 25): each sensor only ever reports on-line or off-line, and the response is one of a small handful of fixed motor-speed combinations — no smooth, proportional steering here, just discrete correction based on which sensor triggered.

A more advanced version: proportional steering

The same PID ideas, applied to a different physical quantity A more capable version replaces the two simple on/off sensors with an array of several sensors (or one continuous-output analog sensor) that estimates how far off-center the line currently is — a numeric error, exactly like Unit 6's error signal, just measuring lateral position instead of temperature. A proportional (or full PID) controller then computes a steering correction proportional to that error, producing smooth, continuous steering instead of the discrete left/right/straight snapping shown above. The controller math doesn't change at all between temperature and steering — only what's being measured does.

This is worth sitting with: PID isn't a temperature-control technique, or a motor-control technique — it's a completely general strategy for turning any measurable error into a corrective actuator output, whether that error is degrees off target, millimeters off a line, or miles per hour off a cruise-control setpoint (Unit 8, Lesson 41 covers exactly that last one).

Check your recall

No peeking back up — answer from memory first, then check.

1. What information does each of the two line-following sensors provide in the basic version of this system?

The basic two-sensor version only reports a simple on-line/off-line state per sensor, based on how much light is reflected back.

2. Why is the basic version of this line-following logic described as "bang-bang-like"?

On/off sensor readings driving a fixed handful of discrete motor-speed responses is exactly bang-bang-style control, applied to steering instead of temperature.

3. What does the "more advanced version" of line-following change, compared to the basic two-sensor version?

Turning the sensing into a numeric lateral-position error is what allows the same proportional/PID machinery from Unit 6 to apply here, producing smoother output than the basic on/off version.

4. Fill in the blank: the general control strategy that turns any measurable error — whether temperature, steering position, or speed — into a corrective actuator output is called ___ control.

PID is a general-purpose strategy, not tied to any one physical quantity — the same formula applies whether the error is measured in degrees, millimeters, or miles per hour.

5. Fill in the blank: mounting light sensors so they detect a dark line against a lighter floor relies on the line reflecting ___ light than the surrounding floor.

A dark line reflects less light back to the sensor than the lighter floor around it, which is exactly what lets the sensor distinguish line from floor.
