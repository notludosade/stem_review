Feedback: The Core Idea Behind Closed-Loop Systems

One quantity — the gap between where you want to be and where you actually are — drives every closed-loop system in this course.

← Lesson 23 Lesson 25 → Contents Glossary →

Lesson 23 defined closed-loop control loosely as "measuring the result and adjusting." This lesson makes that precise, introducing the single quantity every closed-loop controller is actually built around.

Definition Feedback is the act of measuring a system's actual output and routing that measurement back into the controller's decision-making. The quantity a controller actually reacts to is the error: the difference between the desired value (the setpoint) and the measured actual value.
error = setpoint − measured value
Example A thermostat set to 70°F, currently reading 65°F, computes error = 70 − 65 = 5°F. That single number — how far off, and in which direction — is everything the controller needs to decide what to do next. Every control strategy for the rest of this course, from the simplest to the most sophisticated, is really just a different way of turning this one number into an actuator command.

Negative feedback vs. positive feedback

Definition Negative feedback acts to reduce the error — the correction pushes the system back toward the setpoint, which is what "feedback" means in essentially every control system in this course. Positive feedback does the opposite: it amplifies the error, pushing the system further away from any stable point.
A callback worth making explicitly Engineering 1's Tacoma Narrows Bridge case study described exactly this positive-feedback pattern: the bridge's twisting changed how it caught the wind, which increased the twisting further, feeding back into more twisting still, with nothing acting to reduce the error. That's positive feedback in an uncontrolled physical system — destabilizing, growing without bound. Every control system in this course is deliberately built around negative feedback instead, specifically because it's stabilizing.

From here on, "feedback" in this course always means negative feedback unless stated otherwise — the corrective kind, driving error toward zero rather than away from it.

Check your recall

No peeking back up — answer from memory first, then check.

1. A cruise control system is set to 60 mph and the car is currently traveling 55 mph. What is the error?

error = setpoint − measured value = 60 − 55 = 5 mph.

2. What is the key difference between negative and positive feedback?

Negative feedback corrects toward the setpoint (stabilizing); positive feedback amplifies deviation (destabilizing) — opposite effects despite the similar-sounding names.

3. Why did the Tacoma Narrows Bridge’s twisting motion grow into a catastrophic oscillation instead of settling down?

This is positive feedback in an uncontrolled physical system: each cycle of twisting amplified the next, with no negative feedback present to counteract it.

4. Fill in the blank: the difference between a controller’s desired setpoint and its actual measured value is called the ___.

Error is the single quantity nearly every control strategy in this course is built to drive toward zero.

5. Fill in the blank: feedback that acts to reduce error and stabilize a system, the kind used throughout this course, is called ___ feedback.

Negative feedback is the corrective, stabilizing kind — in contrast to positive feedback, which amplifies error instead.
