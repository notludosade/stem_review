1. What is the key structural difference between a microcontroller and a general-purpose computer?

A microcontroller favors predictable, dedicated real-time control over the flexibility of an OS-managed general-purpose computer.

2. Fill in the blank: an operating system pausing a program unpredictably to handle unrelated tasks would break a control loop’s reliance on predictable ___.

Real-time control depends on predictable timing, which an OS juggling many processes can disrupt.

3. What is the key difference between a microcontroller’s flash memory and its RAM?

Flash retains the program between power cycles; RAM loses its contents the instant power is cut.

4. Fill in the blank: dedicated hardware blocks on a microcontroller for specific jobs, like timing or analog conversion, so the CPU doesn’t handle everything in software, are called ___.

Peripherals — GPIO, ADC, timers — offload specific jobs from the CPU into dedicated hardware.

5. What determines whether a GPIO pin acts as a digital input or a digital output?

GPIO’s flexibility comes from being configurable in code as either an input or an output.

6. In the pseudocode pattern using INPUT_PULLUP, why does a pressed button read LOW rather than HIGH?

With a pull-up enabled, the pin idles HIGH; pressing the button pulls it to ground, reading LOW.

7. Fill in the blank: a GPIO output pin can only source a small amount of current, typically tens of ___, far too little to directly drive a motor.

GPIO current limits are why a driver circuit (like an H-bridge) must sit between a control pin and a real motor load.

8. On a 10-bit ADC, what range of raw values does analogRead() return?

A 10-bit ADC has 2^10 = 1024 levels, giving raw readings from 0 to 1023.

9. Fill in the blank: a resistor placed in series with an LED to keep its current within a safe range is called a ___ resistor.

Without this resistor, an LED’s low forward resistance would let current spike dangerously high.

10. Why does pin configuration belong in setup() rather than loop()?

Setup runs exactly once for a reason — configuration is a one-time task, unlike the ongoing work in loop().
