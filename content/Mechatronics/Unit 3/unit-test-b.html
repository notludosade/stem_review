1. Which of these is a real example of a microcontroller?

The ATmega328P is a real, widely used microcontroller — small, cheap, and built to run one dedicated program.

2. Fill in the blank: microcontrollers are favored in mechatronics because they offer low cost, low power, and predictable, ___-time response.

Real-time, predictable response is the core requirement most control loops depend on.

3. Which type of memory keeps a microcontroller’s program stored even when power is removed?

Flash memory is non-volatile, retaining the program between power cycles, unlike volatile RAM.

4. Fill in the blank: generating a precise PWM signal purely in software would tie up the CPU almost completely, which is why a dedicated ___ peripheral handles it in hardware instead.

A dedicated timer peripheral frees the CPU to do other work while still generating precise, repeating PWM timing.

5. A GPIO pin has been configured with pinMode(PIN, OUTPUT). What can it now do?

Configuring a pin as OUTPUT lets code drive it HIGH or LOW to control external hardware.

6. What problem does a pull-up (or pull-down) resistor solve for a digital input pin?

Without a pull-up or pull-down, an unconnected input pin floats and can read noise instead of a defined state.

7. Fill in the blank: because GPIO pins can’t supply enough current for a motor, a small control signal from the pin instead switches a separate, higher-current power source through a driver or ___.

A transistor or relay lets a small GPIO signal control a much larger current without the GPIO pin carrying that current itself.

8. Why does analogRead() typically take measurably longer to execute than digitalRead()?

Analog-to-digital conversion isn’t instantaneous — the ADC needs time to sample and convert, unlike a simple digital HIGH/LOW read.

9. Fill in the blank: without a current-limiting resistor, an LED’s low forward resistance would let current spike according to ___’s law.

Ohm’s law (V = IR) predicts the dangerous current spike a bare LED connection would allow.

10. What runs during a microcontroller program’s loop() phase?

Loop is the repeating phase, running continuously in contrast to setup’s one-time execution.
