Sensors and Signals

Analog Signal

A voltage that varies continuously over a range, where any value between minimum and maximum is meaningful.

Digital Signal

A signal that takes on only a small set of discrete states, almost always just two: HIGH and LOW.

ADC (Analog-to-Digital Converter)

Microcontroller hardware that samples a continuous voltage and returns a raw digital number scaled across its resolution.

DAC (Digital-to-Analog Converter)

Hardware that converts a digital number directly into a corresponding continuous analog voltage.

Resolution

The number of bits an ADC uses to represent a voltage reading; an n-bit ADC has 2^n discrete levels.

Quantization Error

The small, unavoidable rounding difference between a true continuous voltage and an ADC’s nearest reported discrete level.

Voltage Divider

A circuit of two resistors in series between supply voltage and ground, tapped at the midpoint, used to read a resistive sensor as a voltage.

Thermistor

A resistor whose resistance changes predictably with temperature; the common NTC type decreases resistance as temperature rises.

Thermocouple

A junction of two dissimilar metals that generates a small voltage proportional to temperature difference, via the Seebeck effect.

Photoresistor (LDR)

A light-dependent resistor whose resistance decreases as light hitting it increases; cheap but slow and imprecise.

Phototransistor

A transistor whose base current is triggered by light, producing a fast, precise, and roughly linear light-dependent current.

Ultrasonic Distance Sensor

A sensor that measures distance by timing how long a high-frequency sound pulse takes to bounce back from an object.

Limit Switch

A mechanical switch that reports a single digital state — triggered or not triggered — based on physical contact.

Pull-up Resistor

A resistor connecting an input pin to supply voltage so it reads HIGH by default, preventing an undefined, floating reading.

Calibration

The process of relating a sensor’s raw electrical output to the physical quantity it measures, using known reference readings.

Noise

Random, unwanted variation in a sensor reading that doesn’t reflect an actual change in the physical quantity being measured.

Moving Average Filter

A filter that keeps a rolling buffer of the last N readings and outputs their average, trading responsiveness for smoothness.

Exponential Moving Average (EMA)

A smoothing filter that updates one running value each cycle using a weight alpha, needing no buffer of past readings.

Actuators

Actuator

A component that converts an electrical signal into physical motion or force.

DC Motor

A motor that converts direct-current electrical energy into continuous rotational motion, with no built-in sense of position.

Stall Torque

The maximum torque a motor produces right before it stops turning entirely under too much load.

H-Bridge

A circuit of four switches that lets a DC motor be driven in either direction using low-power control signals.

Back-EMF

The voltage spike a motor generates when its magnetic field collapses as it is switched off.

Servo Motor

A motor combined with a gearbox, a position sensor, and a control circuit, driving its shaft to and holding a commanded angle.

Stepper Motor

A motor that rotates in discrete, fixed-angle steps by energizing its coils in sequence, trackable without a feedback sensor.

Microstepping

Energizing a stepper motor’s coils at intermediate current levels to divide each full step into smaller sub-steps.

PWM (Pulse-Width Modulation)

Rapidly switching a digital pin fully on and off so a connected device responds to the time-averaged effect, approximating an analog output.

Duty Cycle

The percentage of each PWM cycle spent HIGH rather than LOW; average voltage is approximately duty cycle times supply voltage.

Microcontrollers and Programming

Microcontroller (MCU)

A single chip combining a processor, memory, and I/O circuitry, designed to run one dedicated program controlling hardware in real time.

GPIO (General-Purpose Input/Output)

A pin whose role as digital input or digital output is configured in software rather than fixed in hardware.

Peripheral

Dedicated hardware on a microcontroller for a specific job, such as GPIO, an ADC, or a timer, offloading work from the CPU.

Flash Memory

Non-volatile memory that stores a microcontroller’s program code and retains it even with power removed.

RAM

Volatile memory that holds a microcontroller’s working data, losing its contents the instant power is removed.

Setup Phase

The part of a microcontroller program that runs exactly once, used for pin configuration and initialization.

Loop Phase

The part of a microcontroller program that repeats indefinitely for as long as the chip has power.

Encoder

A position sensor that reports rotation, often as a stream of digital pulses (incremental) or a directly readable angle (absolute).

Control Systems

Open-Loop Control

A control strategy that issues a command from a predetermined plan, with no sensor checking whether the actual result matches it.

Closed-Loop Control

A control strategy that measures the actual result with a sensor and continuously adjusts the command based on that measurement.

Feedback

Measuring a system’s actual output and routing that measurement back into the controller’s decision-making.

Error

The difference between a controller’s desired setpoint and its measured actual value.

Negative Feedback

Feedback that acts to reduce error, stabilizing a system by pushing it back toward the setpoint.

Positive Feedback

Feedback that amplifies error, destabilizing a system by pushing it further from any stable point.

Bang-Bang (On/Off) Control

A control strategy that drives an actuator to only fully on or fully off, based on whether the measured value is above or below setpoint.

Hysteresis (Deadband)

Using two separated thresholds instead of one, so a value must cross the opposite threshold before an actuator switches back.

Chattering

The rapid, repeated on/off switching a bang-bang controller produces when noise causes readings to cross a single threshold.

PID Control

A control strategy combining proportional, integral, and derivative terms into one continuously variable actuator output.

Proportional Term (P)

The PID term that scales corrective output directly with the current error.

Integral Term (I)

The PID term that accumulates error over time, eliminating the steady-state error that pure proportional control often leaves behind.

Derivative Term (D)

The PID term that reacts to how fast the error is changing, damping oscillation and anticipating overshoot.

Steady-State Error

The small, persistent gap between setpoint and actual value that remains even after a system has settled.

Integral Windup

Unbounded growth of a PID controller’s integral term while the actuator is saturated, causing a large overshoot once it can respond again.

Gain (Kp, Ki, Kd)

A tunable constant controlling how strongly a PID term contributes to the total controller output.

Tuning

The process of adjusting a PID controller’s gains so a system responds quickly, without excessive oscillation, and settles at setpoint.

Integration and Real-World Systems

Sensor Fusion

Combining readings from multiple sensors measuring the same or related quantities into a single, more reliable estimate.

Safety Override

Structuring control logic so a safety condition, once detected, fully bypasses the normal control calculation rather than being blended into it.

IMU (Inertial Measurement Unit)

A sensor combining an accelerometer and a gyroscope, used to measure an object’s tilt and rotation rate.

ESC (Electronic Speed Controller)

A specialized motor driver that converts a control signal into the precise current a brushless motor needs.

ABS (Anti-Lock Braking System)

A bang-bang control system that rapidly pulses brake pressure to keep a wheel just short of skidding under hard braking.

PLC (Programmable Logic Controller)

An industrial-grade, ruggedized cousin of the microcontroller, built for high reliability in harsh factory environments.

Ladder Logic

A visual PLC programming notation, originally designed to resemble relay wiring diagrams, solving the same read-decide-write loop as text-based code.

Kinematics

The mathematics relating a robotic arm’s joint angles to its end-effector’s actual position in space.
