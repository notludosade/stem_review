1. In the apartment building analogy for ports, what does the port number represent?

IP address = street address (device); port number = apartment number (program).

2. Fill in the blank: by convention, a browser connects to port ___ by default for plain (unencrypted) HTTP traffic.

Port 80 is the well-known port for HTTP; port 443 is the well-known port for HTTPS.

3. Why do well-known ports matter for interoperability?

A pre-agreed convention (like port 80 for HTTP) removes the need to discover the correct port before connecting.

4. What does a TCP acknowledgment (ACK) confirm?

An ACK confirms receipt; a missing ACK within the expected window is what triggers retransmission.

5. Fill in the blank: a protocol like TCP that requires a setup process (a handshake) before exchanging any data is described as ___.

Connection-oriented protocols set up shared state before data flows — the opposite of UDP's connectionless design.

6. During the TCP handshake. Answer both parts:

(a) What is the final message, sent by the client?

(b) After this final message is sent, what is true of the connection?

The handshake completes with the client's final ACK, after which both sides may exchange data freely.

7. In the postcard analogy for UDP, what does dropping a postcard in a mailbox with no confirmation of arrival represent?

Like a postcard, a UDP datagram is sent with no built-in confirmation of arrival.

8. Fill in the blank: besides live video and gaming, one other common UDP-based use case mentioned in this unit is a ___ lookup, where retrying at the application level is simpler than TCP's full connection overhead.

DNS lookups are typically small, fast, single-exchange requests, a good fit for UDP's lower overhead.

9. A multiplayer game sends a player's position 60 times per second over the network. Answer both parts:

(a) Which protocol is the better fit?

(b) Why?

For fast-changing real-time data, a dropped-and-superseded update is preferable to waiting on a guaranteed but outdated retransmission.

10. Fill in the blank: the protocol with higher overhead and added latency, due to its handshake, sequence numbers, and retransmission machinery, is ___.

TCP's reliability guarantees come at the cost of more overhead than UDP's minimal, connectionless approach.
