1. A packet travels from a laptop through three routers to reach a server. What happens to the destination MAC address at each hop along the way?

MAC addresses are rewritten at every hop, unlike the IP addresses inside, which stay the same for the whole journey.

2. Fill in the blank: a 48-bit identifier, permanently burned into a device's NIC by the manufacturer, is called a ___.

A MAC address identifies hardware for the immediate next hop, distinct from an IP address's end-to-end role.

3. What does each of the four numbers in a dotted-decimal IPv4 address represent?

Four 8-bit octets, separated by dots, make up the complete 32-bit IPv4 address.

4. Fill in the blank: an address like 10.0.0.5 or 192.168.1.1, only meaningful inside one local network and reused across countless separate networks, is called a ___ address.

Private addresses only need to be unique within their own local network, unlike globally unique public addresses.

5. Why does CIDR's configurable prefix length matter, compared to forcing every subnet to be the same fixed size?

Configurable prefix length is exactly what "classless" addressing was built to enable — right-sized subnets instead of one-size-fits-all.

6. Why are a subnet's network address and broadcast address never assigned to an individual device? Answer both parts:

(a) What does the network address (all host bits 0) represent?

(b) What does the broadcast address (all host bits 1) do?

Neither address identifies a single device, which is why they're excluded from the usable host count.

7. A /26 subnet has 6 host bits. How many usable host addresses does it have?

2^6 − 2 = 62, subtracting the network and broadcast addresses from the total.

8. Fill in the blank: one major technique that let many private devices share a single public IPv4 address, extending IPv4's usable lifespan despite exhaustion, is ___ (covered fully in Unit 4).

NAT is a workaround that delayed the practical impact of address exhaustion, not a permanent substitute for more address space.

9. Roughly how many addresses does IPv6's 128-bit space provide, compared to IPv4? Answer both parts:

(a) IPv6's address space is approximately:

(b) This is achieved by using how many bits per address, versus IPv4's 32?

IPv6's 128-bit addresses provide a vastly larger space than IPv4's 32-bit addresses, intended to avoid ever repeating exhaustion.

10. Fill in the blank: because IPv4 and IPv6 devices can't natively talk to each other, most modern networks run both protocols side by side, an arrangement called ___.

Dual-stack lets networks support both protocols during the long, gradual transition instead of a single hard cutover.
