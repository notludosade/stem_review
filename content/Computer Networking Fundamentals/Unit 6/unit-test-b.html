1. What four parts make up every HTTP message, in order?

The start line, headers, blank line, and optional body are consistent across every HTTP request and response.

2. Fill in the blank: the HTTP method used to retrieve data with no side effects and no request body is ___.

GET retrieves a resource without modifying anything, unlike POST, PUT, or DELETE.

3. A response arrives with status code 301. What category does this fall into, and what does it mean?

301 (Moved Permanently) is a 3xx redirection code.

4. A program receives a response in the 4xx range. What's the sensible response?

4xx codes indicate a client-side problem with the request itself, distinct from 5xx server-side failures.

5. Fill in the blank: the property of HTTP where the server does not automatically remember anything about a client's previous requests is called being ___.

Each request is handled as a completely independent event under stateless HTTP.

6. After logging into a website, every later request automatically includes a Cookie header with a session value. Answer both parts:

(a) Does this mean HTTP is not actually stateless after all?

(b) What deletes this "logged in" behavior instantly?

Cookies are a client-side workaround layered on top of stateless HTTP, not a violation of statelessness.

7. In what order do the TCP and TLS handshakes happen for an HTTPS connection?

TLS sits on top of an already-established TCP connection, adding its own handshake before any HTTP data flows.

8. Fill in the blank: HTTPS defaults to port ___, distinct from plain HTTP's default port 80.

Port 443 is the well-known port for HTTPS traffic.

9. A weather app sends a GET request to a server and receives back JSON data instead of an HTML page. Answer both parts:

(a) Is this a valid use of HTTP?

(b) What term describes this kind of HTTP-based interface between two programs?

A REST API uses the same HTTP request-response pattern as a browser, just consumed by another program instead of a human.

10. Fill in the blank: in REST terminology, the piece of data a specific URL represents — like "a specific user" — is called a ___.

Each endpoint in a REST API corresponds to a specific resource that HTTP methods act upon.
