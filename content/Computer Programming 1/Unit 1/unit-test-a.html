1. Which statement correctly describes why C++ requires a separate build step before running, while Python does not?

A compiler translates C++'s entire source file into machine code before it ever runs; an interpreter translates and runs Python line by line, with no separate build step.

2. Fill in the blank: the raw binary instructions specific to a CPU's hardware, which every language eventually gets translated into one way or another, are called ___ ___.

Compiling, interpreting, and JIT compiling are three different strategies for reaching this same destination.

3. Consider how Java runs a program, and answer both parts:

(a) What does Java's compiler produce before the JVM ever runs the program?

(b) Fill in the blank: the JVM compiles frequently-used bytecode into real machine code while the program is already running — this hybrid strategy is called ___ compilation.

(a) Bytecode runs on the JVM rather than directly on the CPU. (b) JIT (just-in-time) compilation gets much of compiled code's speed without giving up the JVM's portability.

4. In Python and JavaScript, where does program execution begin?

Interpreted languages like Python and JavaScript treat the top of the file as the entry point implicitly; Java and C++ require one to be defined explicitly.

5. Consider this Java program, then answer both parts:

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, world!");
    }
}

(a) Why must this exact method signature, public static void main(String[] args), appear?

(b) Fill in the blank: in Java, every piece of code must live inside a ___, unlike Python, where a loose statement is perfectly fine.

(a) Get the signature wrong and the JVM has nowhere to begin execution. (b) Java was designed from the start around organizing code into classes.

6. Consider this C++ program, then answer both parts:

#include <iostream>

int main() {
    std::cout << "Hello, world!" << std::endl;
    return 0;
}

(a) What does the #include <iostream> line do?

(b) Fill in the blank: the line ___ tells the operating system the program finished successfully.

(a) main() is the entry point; std::cout is what actually prints, and it comes from the iostream library this line includes. (b) A nonzero return value conventionally signals an error instead.

7. Which pair correctly matches a language to its console-printing call?

Each language spells "print to the console" differently: print() in Python, System.out.println() in Java, console.log() in JavaScript, and std::cout in C++.

8. Consider comment syntax across the four languages, and answer both parts:

(a) Which single-line comment syntax do Java, JavaScript, and C++ all share?

(b) Fill in the blank: Python's single-line comment symbol, the odd one out among the four languages, is ___.

(a) Java, JavaScript, and C++ descend from the same C-family syntax tradition. (b) Python uses # instead, and has no dedicated block-comment syntax at all.

9. Fill in the blank: Python has no dedicated block-comment syntax — by convention, multi-line notes reuse triple-quoted ___ instead.

A triple-quoted block is technically a string literal — Python just repurposes it by convention when it isn't assigned to anything.

10. Consider this pair of comments placed above the same line of Python code, then answer both parts:

# increment count by 1
count = count + 1

# retries max out at 3 -- the payment API rate-limits after that
count = count + 1

(a) What's the problem with the first comment?

(b) Fill in the blank: a comment worth keeping usually explains ___ code does something, not what it does.

(a) Anyone who can read count = count + 1 already knows it increments count. (b) The second comment answers a question the code alone can't: why does this cap exist?
