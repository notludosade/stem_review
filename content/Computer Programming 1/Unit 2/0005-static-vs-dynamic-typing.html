Static vs Dynamic Typing

The question isn't whether a language has types — every language here does. It's when it checks them.

Lesson 6 → Contents Glossary →

Every value in every language has a type — a number, a piece of text, a true/false, and so on. What differs is when the language checks that a variable's type is being used correctly: before the program ever runs, or while it's running.

Reassigning a variable to a different type 
# Python
age = 16
age = "sixteen"  # runs fine — Python doesn't stop you

In Python, that second line runs without complaint. age simply now refers to a string instead of a number — Python doesn't check whether that's a sensible thing to do until the moment the code actually executes, if ever. JavaScript behaves the same way.

Java 
int age = 16;
age = "sixteen"; // compile error: incompatible types
C++ 
int age = 16;
age = "sixteen"; // compile error: cannot convert string to int

Java and C++ refuse to even compile that code. Because age was declared as an int, the compiler checks every later use of age against that declared type before the program ever runs, and rejects anything inconsistent. This is static typing. Python and JavaScript check types while the program runs instead, which is dynamic typing — the code above is valid Python syntax, so it runs, and only fails later (or not at all) if something actually tries to use age as a number.

Definition In a statically typed language (Java, C++), a variable's type is fixed at declaration and checked before the program runs. In a dynamically typed language (Python, JavaScript), a variable's type is determined by whatever value it currently holds, and checked only while the program is running.
Why it matters here Static typing catches a whole category of mistakes — passing the wrong kind of value somewhere — before you ever run the program. Dynamic typing trades that safety net for flexibility and less upfront ceremony. Neither is strictly better; they're different tradeoffs, and you'll feel both throughout the rest of this course, since every future lesson's code runs differently in Java/C++ versus Python/JavaScript when a type mistake sneaks in.

This is static typing: the check happens at compile time, before execution.

This is dynamic typing — a variable's type is just whatever value it currently holds.
