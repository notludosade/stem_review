Series and Parallel Circuits

Two ways to wire components together — and why one string of holiday lights going dark takes down the rest.

← Lesson 17 Lesson 19 → Contents Glossary →

Real circuits rarely have just one resistor. This lesson covers the two fundamental ways to connect multiple components, and why the difference matters far beyond the math.

Series circuits: one path, one current

Definition In a series circuit, components are connected end-to-end in a single loop, so the same current flows through every component in sequence. Total resistance is simply the sum: R_total = R₁ + R₂ + R₃ + ...
Example Three 4-ohm resistors in series: R_total = 4 + 4 + 4 = 12 ohms. With a 12-volt battery, current = V / R = 12 / 12 = 1 amp flows through all three resistors equally, since there's only one path for it to take.
Why one failure breaks the whole series loop Because a series circuit has only one path, breaking that path anywhere — one burnt-out bulb, one loose connection — breaks it everywhere downstream, dropping current to zero for the entire loop. This is exactly why an old-style string of holiday lights, wired in series, goes completely dark when a single bulb burns out.

Parallel circuits: multiple paths, shared voltage

Definition In a parallel circuit, components are connected across the same two points, so each one gets the full source voltage independently, and current can take multiple separate paths. Total resistance follows: 1/R_total = 1/R₁ + 1/R₂ + 1/R₃ + ...
Example Three 4-ohm resistors in parallel: 1/R_total = 1/4 + 1/4 + 1/4 = 3/4, so R_total = 4/3 ≈ 1.33 ohms. Notice this is less than any single resistor's own resistance — adding more parallel paths always makes it easier for current to flow overall, the opposite effect of adding resistors in series.
Why one failure doesn't break a parallel circuit Because each component has its own independent path back to the source, a single component failing (going open) only removes that one path — current simply continues to flow through the remaining paths. This is exactly why modern household wiring is parallel: one blown lightbulb or one appliance switched off doesn't take down every other outlet in the house.

Why the choice matters beyond the math

The formulas above are mechanical, but the real engineering insight is the reliability trade-off: series wiring means every component depends on every other component in the loop; parallel wiring means components fail independently of each other. Real electrical design deliberately chooses parallel wiring almost everywhere reliability matters — household circuits, computer components — specifically to avoid a single point of failure taking down the whole system.

Check your recall

No peeking back up — answer from memory first, then check.

1. Three 4-ohm resistors are connected in series. What is the total resistance?

Series resistances simply add: 4 + 4 + 4 = 12 ohms.

2. Why does adding more resistors in parallel always decrease the circuit's total resistance?

More parallel paths means more ways for current to get through, so total resistance drops below even the smallest individual resistor's value.

3. Why is household wiring built as parallel circuits rather than series?

Independent paths mean one component failing doesn't remove the path for every other component — exactly the reliability property series wiring lacks.

4. Fill in the blank: in a ___ circuit, components share a single path, so the same current flows through all of them and a single break stops current everywhere.

Series wiring has exactly one loop, so every component's current is identical and every component depends on the whole loop staying closed.

5. Fill in the blank: in a ___ circuit, each component gets the same source voltage independently, and current can take multiple separate paths.

Parallel components each connect across the same two points, giving them shared voltage and independent current paths.
