The Laplace Transform and Its Basic Properties

Units 3–4 solved equations by guessing a form and matching coefficients. This unit trades the differential equation for an algebra problem entirely — by transforming the whole thing into a new variable, s.

← Unit 4, Lesson 12 Lesson 14 → Contents Glossary →

1. Turning a function of t into a function of s

Definition — Laplace Transform For a function f(t) defined on t ≥ 0, the Laplace transform is L{f(t)}(s) = F(s) = ∫₀∞ e−stf(t) dt — an improper integral that turns a function of t into a new function of s, for every s large enough that the integral converges.
Fact — Linearity L{af(t) + bg(t)} = a·L{f(t)} + b·L{g(t)} for constants a, b — the transform of a sum is the sum of the transforms, which is what makes it possible to build up complicated transforms from a short table of basic ones.
Fact — A Basic Transform Table L{1} = 1/s. L{t} = 1/s². L{tn} = n!/sn+1. L{eat} = 1/(s−a). L{cos(bt)} = s/(s²+b²). L{sin(bt)} = b/(s²+b²). Every entry comes from directly evaluating ∫₀∞e−stf(t)dt — Lesson 14 needs one more entry (for derivatives) to actually solve equations.
Worked Example Find L{3 + 5t}. By linearity: L{3 + 5t} = 3·L{1} + 5·L{t} = 3(1/s) + 5(1/s²) = 3/s + 5/s². No integral needs to be evaluated by hand — the table and linearity do all the work.

Check your recall

1. The Laplace transform of f(t) is defined as:

The defining integral uses e^(−st), a decaying factor for s large enough to make the improper integral converge.

2. Fill in the blank: L{1} = ___

∫₀^∞ e^(−st)(1) dt = [−e^(−st)/s]₀^∞ = 0 − (−1/s) = 1/s.

3. L{e^(at)} equals:

∫₀^∞ e^(−st)e^(at) dt = ∫₀^∞ e^(−(s−a)t) dt = 1/(s−a), convergent for s > a.

4. Fill in the blank: by linearity, L{4t + 7} = 4/s² + ___

L{4t + 7} = 4·L{t} + 7·L{1} = 4/s² + 7/s.

5. L{cos(bt)} equals:

L{cos(bt)} = s/(s²+b²), while L{sin(bt)} = b/(s²+b²) — easy to mix up, since they share the same denominator.
