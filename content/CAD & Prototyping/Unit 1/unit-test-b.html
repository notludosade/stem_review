1. A single unconstrained circle in a 2D sketch has 3 DOF (2 for its center point, 1 for its radius). A coincident constraint pins its center to the origin (−2 DOF). How many degrees of freedom remain?

3 − 2 = 1 DOF remains — the radius is still free, since no radius or diameter dimension has been applied yet.

2. Fill in the blank: a constraint that fixes a relationship between entities, like parallel or tangent, without specifying any number, is called a ___ constraint.

Geometric constraints fix relationships (parallel, tangent, coincident); dimensional constraints fix actual measurements (length, angle, radius).

3. A plate has width = 90mm, margin = 9mm, and 4 evenly spaced holes. Using spacing = (width − 2×margin) / (holes − 1), what is the hole spacing?

spacing = (90 − 2×9) / (4 − 1) = (90 − 18) / 3 = 72 / 3 = 24mm.

4. Fill in the blank: instead of typing a fixed number, a parametric dimension can be defined as a ___ referencing other named parameters.

A formula/expression is what lets a dimension recompute automatically whenever the parameters it references change.

5. A designer needs to model a flat gasket with constant thickness and an irregular outline. Which basic 3D feature is the natural choice?

Extrude pushes any 2D profile — regular or irregular — a fixed distance, which is exactly what a constant-thickness flat gasket needs.

6. A model has Sketch1 → Extrude1 (a base) → Fillet1 (rounds Extrude1's edges) → Sketch2 (drawn on one of Fillet1's rounded faces). Answer both parts:

(a) What happens to Sketch2 if Fillet1's radius is later changed enough to eliminate the face Sketch2 was drawn on?

(b) Fill in the blank: the sequential, ordered record of Sketch1, Extrude1, Fillet1, and Sketch2 that determines this dependency is called the ___.

(a) Sketch2 depended on Fillet1's specific rounded face — if that geometry changes shape enough, the reference breaks. (b) This ordered record is the feature tree (history tree).

7. A designer adds a constraint that directly contradicts one already applied to the sketch. Answer both parts:

(a) What does the CAD software do?

(b) Fill in the blank: a sketch with contradictory or conflicting constraints is described as ___.

(a) CAD software flags a conflict as an error to be resolved by the designer, rather than guessing which constraint was intended. (b) This state is called overdefined (or over-constrained).

8. A hole count parameter is set to drive both the number of mounting holes and a formula for their spacing. Answer both parts:

(a) If the hole count is changed from 5 to 7, what happens to the hole spacing formula's result?

(b) Fill in the blank: a named variable like hole count, that a formula can reference, is called a ___.

(a) Because the spacing dimension is a formula referencing the hole count, changing the count recomputes the spacing automatically. (b) This named, formula-referenceable variable is a parameter.

9. A part is a small knob, fully symmetric around a central shaft axis. Answer both parts:

(a) Which basic 3D feature is the natural way to create this part from a single 2D profile?

(b) Fill in the blank: to generate the entire knob from one profile, the revolve angle must be ___ degrees.

(a) A fully rotationally symmetric part is exactly what revolve is built for. (b) A full 360° revolve is needed to generate the complete solid from a single half-profile.

10. Model C builds a chamfer first, then adds a mounting-hole sketch that references the chamfered edge. Model D builds the same flat base, adds its mounting-hole sketch referencing the original flat face, and applies the chamfer last. Both models currently look identical. Answer both parts:

(a) Which model's mounting-hole sketch is more likely to fail to rebuild if the chamfer size is later changed?

(b) Fill in the blank: because every feature depends on what came before it, the ___ features appear in the tree is part of the design itself, not just bookkeeping.

(a) Two models can look identical yet behave completely differently under edits, purely based on what each feature chose to reference. (b) Feature order is itself a real design decision, not incidental bookkeeping.
