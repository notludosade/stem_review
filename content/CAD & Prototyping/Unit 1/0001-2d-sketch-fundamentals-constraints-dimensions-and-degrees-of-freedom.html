2D Sketch Fundamentals — Constraints, Dimensions, and Degrees of Freedom

Every 3D feature in a CAD model starts life as a flat, 2D sketch — and how tightly that sketch is pinned down decides whether the model behaves or falls apart later.

Lesson 2 → Contents Glossary →

Almost every solid a CAD program can build — a bracket, a housing, a gear — starts from a flat 2D sketch that later gets extruded, revolved, or otherwise turned into 3D geometry. Before any of that, the sketch itself has to be under control. This lesson is about what "under control" actually means, precisely enough to check it.

Sketch entities and two kinds of constraints

A sketch is built from simple entities — lines, arcs, circles, points — and controlled two different ways:

Definition Geometric constraints fix the relationship between entities without specifying a number: coincident (two points touch), horizontal, vertical, parallel, perpendicular, tangent, equal (two lengths or radii match), symmetric. Dimensional constraints fix an actual measurement: a distance, a length, a radius or diameter, an angle.

Both kinds do the same underlying job — removing ambiguity about where the geometry sits — but a sketch built only from dimensions with no geometric constraints is usually fragile (nothing stops two lines that are supposed to be parallel from drifting apart if a length changes), so real sketches combine both.

Degrees of freedom

Definition A 2D point has two degrees of freedom (DOF): it can move in x and in y. A sketch's total DOF is the sum of every unconstrained way its entities are still free to move. Each constraint removes some number of DOF. A sketch is fully constrained when 0 DOF remain — no entity can move at all without violating a constraint.

Most CAD programs color sketch geometry to show this at a glance: underdefined entities (DOF remaining) are usually blue and can be dragged around; fully constrained entities are usually black or a different fixed color and won't move no matter where you click and drag.

Worked Example — Constraining a Single Line A line has two endpoints, so it starts with 4 DOF (2 per endpoint). Add a coincident constraint pinning one endpoint to the sketch origin: that endpoint's 2 DOF are removed, leaving 2 (the other endpoint can still be anywhere on a circle around the first). Add a length dimension: that removes 1 more DOF, leaving 1 — the free endpoint can now only slide around a fixed-radius arc. Add an angle dimension from the x-axis: the last DOF is removed. 4 − 2 − 1 − 1 = 0. The line is fully constrained.

Underdefined, fully defined, and overdefined

A sketch can end up in one of three states, and CAD software tracks the difference automatically:

Underdefined DOF > 0. Some geometry can still move. Not an error — early in sketching, most geometry is underdefined on purpose — but a sketch that's still underdefined when a feature is built from it can shift unpredictably if anything upstream changes.
Fully defined DOF = 0. Every entity's position is pinned down by some combination of geometric and dimensional constraints, with no conflicts. This is the target state before building a feature from the sketch.
Overdefined / conflicting A constraint is added that contradicts another already in place — for example, constraining a line horizontal and then also giving it a nonzero vertical-distance dimension between its endpoints. CAD software flags this as an error rather than silently choosing one; it has to be resolved by deleting the conflicting constraint, not worked around.
Why fully constraining a sketch matters An underdefined sketch isn't just untidy — it's a hidden risk. If a teammate (or you, six months later) accidentally drags an underdefined entity while editing something else, the geometry can shift with no warning, and every feature built from that sketch shifts with it. Fully constraining a sketch before building on it is what makes a model's behavior predictable — which becomes essential the moment dimensions are driven by parameters instead of typed-in numbers, the subject of the next lesson.

Check your recall

No peeking back up — answer from memory first, then check.

1. What removes degrees of freedom from a 2D sketch?

Both kinds of constraint remove ambiguity about position — geometric constraints fix relationships, dimensional constraints fix measurements, and a well-built sketch normally uses both.

2. How many degrees of freedom does a single, completely unconstrained 2D point have?

A 2D point can move in x and in y — 2 DOF. (A 2D line has 4, since it's two points.)

3. What happens when a new constraint directly contradicts one already applied to the sketch?

A conflict is flagged as an error the designer has to resolve — CAD software won't guess which constraint you actually meant.

4. Fill in the blank: a sketch with DOF greater than 0, where some geometry can still be dragged, is called ___.

Underdefined geometry still has freedom to move — it isn't wrong, but it isn't finished either.

5. Fill in the blank: a sketch is fully constrained when exactly ___ degrees of freedom remain.

Zero DOF means no entity in the sketch can move without breaking a constraint — the geometry is completely pinned down.
