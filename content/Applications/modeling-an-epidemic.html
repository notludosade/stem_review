Modeling an Epidemic

Case counts grow, peak, and fall because people move between interacting populations—and a small system of differential equations can reveal why.

← Applications STEM+ Home →

The Concept, From Differential EquationsThe SIR model partitions a fixed population N into susceptible S, infectious I, and recovered R. It uses dS/dt = −βSI/N, dI/dt = βSI/N − γI, and dR/dt = γI. The local effective reproduction number is Rₑ = (β/γ)(S/N).

The threshold is dynamic

Early in an outbreak S/N is near 1, so Rₑ is close to the basic model value β/γ. Infections grow when Rₑ > 1, peak near Rₑ = 1, and decline below it. Reducing contact or transmission lowers β; faster removal from the infectious state raises γ; immunity lowers S/N. Different mechanisms can therefore cross the same threshold.

A model is a lens, not a forecast machineThe basic SIR equations assume homogeneous mixing, fixed parameters, and immediate transitions between compartments. Age, geography, behavior, delayed reporting, reinfection, and random effects can matter. Useful modeling states assumptions, tests sensitivity, and updates parameters instead of treating one curve as destiny.

Check your understanding

1. With β = 0.30/day, γ = 0.10/day, and S/N = 1/3, what is Rₑ?

Rₑ = (0.30/0.10)(1/3) = 3/3 = 1, the local peak threshold in the basic model.

2. Which change directly lowers β in this model?

β compresses contact frequency and transmission probability into an effective transmission rate.
