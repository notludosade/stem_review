Unit 6 Test — Version A

Building & Sharing a Mod. 10 questions covering every lesson in this unit. Score 80% or higher to clear this unit.

1. What does a mod manifest let a mod loader do?

The manifest is metadata the loader reads programmatically to manage the mod.

2. Fill in the blank: the MAJOR.MINOR.PATCH version-numbering convention is called ___.

Semantic versioning gives dependency declarations something concrete to check against.

3. What is a mod conflict?

A conflict specifically requires two mods touching the same underlying thing.

4. Fill in the blank: a running record documenting what changed in each released version of a mod is a ___.

A changelog pairs naturally with semantic versioning — each bump gets an entry explaining why.

5. Why does attribution matter even when borrowed content came from another modder rather than the original game developer?

Crediting other modders' work matters both ethically and as a real license term in many cases.

6. A modder is preparing a package for distribution. Answer both parts:

(a) What should the package generally never include?

(b) What should the readme cover, at minimum?

Only changed files belong in a package, and a readme should cover exactly what a new user needs to install and use it.

7. A mod passes every test when installed completely alone. Answer both parts:

(a) Is this sufficient testing before a wide release?

(b) What should testing also check for?

Realistic testing checks compatibility with mods a real player is likely to already have installed.

8. A mod is technically well-packaged and thoroughly tested for compatibility. Answer both parts:

(a) Is this alone enough to call it "ready to publish responsibly"?

(b) What should a published mod state about its own reuse or redistribution terms?

Publishing responsibly requires both technical readiness and passing the legal/ethical check, plus clearly stated terms.

9. Nexus Mods and Steam Workshop are both mod hosting platforms. Answer both parts:

(a) What is a mod hosting platform, generally?

(b) What other kind of general-purpose sites can also host mods that don't fit a dedicated platform?

Dedicated platforms and general-purpose sites both serve as real mod hosting options.

10. Modding communities run on norms beyond what's written in any EULA. Answer both parts:

(a) Which of these is a community norm this lesson described?

(b) Are legal and ethical concerns treated as separate questions in this final lesson?

The capstone explicitly ties technical quality and legal/ethical responsibility together as one combined standard.
