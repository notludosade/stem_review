1. Besides performance, what is the second reason studios bundle assets into a custom archive format?

Light obfuscation is the second reason — not real security, just a mild barrier to casual tampering.

2. Fill in the blank: extractor tools exist specifically to unpack a studio-specific container file known as an ___ ___.

Extensions like .pak, .vpk, .wad, and .bsa are all examples of archive formats extractors are built for.

3. What is the purpose of a model interchange format like .fbx or .obj?

Interchange formats bridge a game's proprietary in-game model format and common modeling tools.

4. Fill in the blank: the internal bone structure a mesh deforms around during animation is called a ___.

A rig (or skeleton) is separate from the mesh's raw geometry — it's what lets the mesh move.

5. What does an audio bank system like FMOD or Wwise actually manage?

A bank routes and manages sound playback logic, not just storing raw files.

6. A modder encounters an unfamiliar, undocumented archive format. Answer both parts:

(a) Should this be treated as real cryptographic security?

(b) What has modding communities historically done about undocumented formats like this?

Community reverse-engineering, not developer documentation, is how most popular archive formats got understood.

7. Two model files both define shape and movement differently. Answer both parts:

(a) A static rock model with no animation would need which of these?

(b) An animated character model needs a mesh plus what additional structure?

Every model needs a mesh for shape; only animated models additionally need a rig to move that shape.

8. A studio's own designers benefit from config files before any modder gets involved. Answer both parts:

(a) Why do studios build games with data-driven values in the first place?

(b) What kind of modding does this same design choice enable as a side effect?

The same convenience that helps a studio's own designers is what makes config-only modding possible for players too.

9. PNG and OBJ are open formats; many in-game formats are proprietary instead. Answer both parts:

(a) What defines an open format like PNG?

(b) Why might a studio still choose a proprietary in-game format over an open one?

Proprietary formats are often optimized for a specific engine's performance needs, at the cost of needing community tools to read outside it.

10. An unpacked archive contains footstep.ogg, player_rig.fbx, and settings.json. Answer both parts:

(a) Which of these is most likely audio?

(b) Which of these is most likely a human-readable config file?

.ogg is an audio format, .fbx is a model format, and .json is a common human-readable config format.
