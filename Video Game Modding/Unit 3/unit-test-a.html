1. Why is Lua so commonly used as a game's embedded scripting language?

Lua's small footprint and embeddability are exactly why it's the industry's most common modding language.

2. Fill in the blank: a restricted execution environment that only exposes a limited, deliberate set of functions to a mod script is called a ___.

A sandbox is what lets a studio safely run untrusted, community-written scripts inside its game.

3. What is an event hook?

Event hooks let mods respond to game events without modifying the original logic at all.

4. Fill in the blank: a function registered to automatically run when a specific event fires is called a ___.

A callback is the actual code that runs once its registered event fires.

5. What does a modding framework like Forge or BepInEx add on top of a game's raw scripting API?

A framework sits on top of the API, providing shared infrastructure so individual mods don't reinvent it.

6. Config edits (Unit 2) and scripted mods (Unit 3) differ in what they can do. Answer both parts:

(a) What can a scripted mod add that a config edit cannot?

(b) What does a scripted mod require that a config edit does not?

Scripted mods trade the simplicity of a config edit for the ability to add genuinely new logic, at the cost of needing real programming skill.

7. A game's scripting API deliberately limits what a mod script can do. Answer both parts:

(a) What does API stand for?

(b) What does the API specifically define for a mod script?

The API is the deliberate boundary a studio draws around what a script is permitted to touch.

8. Three separate mods all register a callback for the same onPlayerDamage event. Answer both parts:

(a) What determines which callback runs first?

(b) Why can the order these callbacks run in actually matter?

Since multiple callbacks can modify the same value, their run order can produce genuinely different results.

9. A framework's mod loader manages more than one mod at once. Answer both parts:

(a) What does a mod's declared dependency require?

(b) What does load order determine when two mods try to change the same thing?

Dependencies let mods build on each other safely; load order extends hook priority up to whole mods competing over the same change.

10. Event hooks are one example of a broader programming pattern. Answer both parts:

(a) What is this broader pattern called?

(b) Is this pattern unique to game modding?

Event-driven programming is a general pattern that shows up throughout software, not something unique to games.
