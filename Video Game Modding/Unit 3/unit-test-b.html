1. What does it mean for a scripting language to be "embedded" in a game?

An embedded scripting language means the interpreter itself is part of the engine, letting scripts run without recompiling anything.

2. Fill in the blank: the specific set of functions a sandboxed script is allowed to call is defined by the game's ___.

The API is the boundary the sandbox actually enforces.

3. Why doesn't the original game code that fires an event need to know a mod exists?

Firing code and mod callbacks are decoupled — the game announces, and mods choose whether to listen.

4. Fill in the blank: code that runs in response to something happening, rather than in a fixed sequence, follows the ___ ___ pattern.

Event-driven programming underlies event hooks, and isn't unique to modding.

5. What is a mod loader, specifically?

The mod loader is the concrete framework component responsible for bringing mods into the running game.

6. A modder wants to add a brand-new ability that doesn't exist in the base game at all. Answer both parts:

(a) Is a config-only edit (Unit 2) enough to do this?

(b) What kind of mod is actually needed instead?

Genuinely new behavior requires scripting, since config edits can only change values that already exist.

7. A sandboxed mod script tries to make a network request, but is blocked. Answer both parts:

(a) Why would the sandbox block this?

(b) What is this restriction meant to protect?

Sandboxing exists precisely to make it safe to run scripts from untrusted, third-party sources.

8. An ArmorMod reduces damage, and a separate CriticalHitMod applies bonus damage, both hooking onPlayerDamage. Answer both parts:

(a) Could running these two hooks in a different order change the final damage number?

(b) What mechanism decides which of these two callbacks runs first?

Hook priority is exactly the mechanism that resolves this kind of order-dependent conflict between callbacks.

9. RebalanceMod declares a dependency on BaseTexturePack. Answer both parts:

(a) What does this dependency declaration mean?

(b) What can a modern framework's mod loader do with a declared dependency like this?

Declared dependencies let a mod loader catch missing requirements automatically, rather than leaving a player to discover a broken game.

10. Minecraft's Forge lets many independently-written mods coexist in one game. Answer both parts:

(a) Does Forge replace Minecraft's own underlying scripting/programming layer?

(b) What problem would many mods face without a framework like Forge managing them?

A framework exists specifically to solve, once, the problems individual mods would otherwise each reinvent.
