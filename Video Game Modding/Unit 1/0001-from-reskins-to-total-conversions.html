From Reskins to Total Conversions — the Spectrum of Modding

"Modding" isn't one thing. It's a spectrum from swapping a color to building an entirely new game inside someone else's engine — and where a mod sits on that spectrum changes everything about how hard it is to make.

Lesson 2 → Contents Glossary →

A mod — short for "modification" — is any change a player makes to a game that the original developer didn't ship by default. That definition covers an enormous range. Recoloring a character's outfit is a mod. So is adding a single new weapon. So is replacing the entire game with a new one that just happens to reuse the original's engine and assets. This course spends six units on that whole range, but before touching a single file format or scripting API, it's worth seeing the spectrum laid out end to end — because the position on it predicts almost everything else: how much skill it takes, what tools are involved, and how likely the developer is to allow it.

The spectrum, low effort to high effort

Roughly, from smallest change to largest:

Cosmetic reskins swap a texture or color palette without touching any logic — a re-painted car, a re-colored sword. Config tweaks edit settings the game already exposes in a plain-text file — damage numbers, spawn rates, difficulty curves — using nothing but a text editor (Unit 2 covers this in depth). Asset additions introduce genuinely new content — a new 3D model, a new sound, a new level — built in the game's existing format and dropped in alongside the originals (Unit 4). Scripted mods use an exposed scripting API to add new behavior — a new game mode, a new ability, an entirely scripted questline — without recompiling anything (Unit 3). At the far end, total conversions replace nearly everything: story, assets, and rules, keeping only the underlying engine. Counter-Strike began as a total-conversion mod of Half-Life; Dota began as a total-conversion mod of Warcraft III's map editor. Both eventually became standalone commercial games.

Definition A total conversion is a mod that replaces nearly all of a game's original content — assets, rules, story — while still running on the original game's engine.
