# Resources

## Primary sources

- **Git** — the [Pro Git book](https://git-scm.com/book/en/v2), free and official, is the authoritative reference for version control concepts and commands used throughout Unit 2.
- **Design Patterns: Elements of Reusable Object-Oriented Software** (Gamma, Helm, Johnson, Vlissides — the "Gang of Four") — the original source for the design pattern vocabulary used in Unit 4.
- **Martin Fowler's website** ([martinfowler.com](https://martinfowler.com/)) — widely regarded as one of the most trusted practitioner sources on software architecture, refactoring, and technical debt, referenced throughout Unit 5.
- **The Scrum Guide** ([scrumguides.org](https://scrumguides.org/)) — the official, current definition of Scrum, maintained by its original co-creators, used throughout Unit 7.
- **The Agile Manifesto** ([agilemanifesto.org](https://agilemanifesto.org/)) — already introduced in Career Applied Engineering; referenced again here for the process-specific detail Unit 7 covers.

## Wisdom communities

- [r/ExperiencedDevs](https://www.reddit.com/r/ExperiencedDevs/) — practitioner discussion on code review norms, architecture trade-offs, and real team workflows, from working engineers rather than students.
- [r/programming](https://www.reddit.com/r/programming/) — broader software engineering discussion, useful for seeing how these practices play out across different companies and stacks.
- [Stack Overflow](https://stackoverflow.com/) — while not a community for open-ended discussion, its accepted-answer format is a valuable way to see real testing and design-pattern trade-offs debated in context.

## Note on scope

Unlike Computer Programming 1/2, there is no single canonical textbook this entire course is built from — software engineering practice is documented across many practitioner sources rather than one unified reference. The sources above are the most consistently cited across the industry for each specific unit's topic.
