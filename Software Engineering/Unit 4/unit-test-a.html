1. A teammate says "I used an Observer pattern here" instead of walking through the whole class structure line by line. What does naming the pattern actually provide?

A pattern names a general shape of solution, adapted to the specific situation — the value is communication and recognition, not exact reusable code.

2. Where did the Gang of Four's cataloged design patterns actually come from?

Patterns are discovered, not invented — the Gang of Four named recurring shapes engineers kept independently rediscovering.

3. A codebase has the same if payment_type == "credit_card": ... elif payment_type == "paypal": ... block copy-pasted in five different files. What problem does a Factory solve here?

A Factory's whole purpose is centralizing "which object to create" decision logic in one maintainable place.

4. Fill in the blank: a Singleton guarantees a class has exactly ___ instance across the entire program, with one global point of access to it.

Exactly one instance, globally accessible, is the specific guarantee Singleton provides.

5. Fill in the blank: a class called LoggerAdapter wraps an old LegacyLogger so new code can call .log(message) even though the old class only has .write_log(msg). This is an example of the ___ pattern.

Adapter translates an existing class's interface into one that different calling code expects, without modifying the original class.

6. A global Logger Singleton makes it hard to test what got logged during one specific function call, since every test in the process shares the exact same instance. Answer both parts:

(a) Why does Singleton create this specific testing problem?

(b) Fill in the blank: many engineers prefer passing a single shared instance explicitly as a parameter, called dependency ___, specifically to avoid this hidden global.

Singleton's global, shared access point hides coupling and makes substituting fakes in a test hard — dependency injection avoids that by making the shared instance explicit.

7. A StockPrice object changes value, and three unrelated observers — a chart, a push notification, and a logging service — are all notified automatically. Answer both parts:

(a) What does StockPrice need to know about what each observer does in response?

(b) Fill in the blank: this is an example of the ___ pattern, where a subject maintains a list of dependents and notifies them all automatically when its state changes.

Observer decouples the subject entirely from what each observer actually does in response to a notification.

8. A shipping calculator uses a growing if method == "standard": ... elif method == "express": ... chain, versus a version where each method is its own small class implementing a shared calculate() method. Answer both parts:

(a) What is the advantage of the class-based version when a new shipping method is added?

(b) Fill in the blank: this class-based approach is the ___ pattern — a family of interchangeable algorithms behind one shared interface.

Strategy isolates each algorithm into its own class, so the calling code and other algorithms stay untouched when a new one is added.

9. A product has exactly one shipping method, with no plan to add more, but an engineer builds a full Strategy pattern with an interface and a class for it anyway, reasoning "we might need more methods later." Answer both parts:

(a) What does this lesson call this kind of decision?

(b) Fill in the blank: the principle against this — "you aren't gonna need it" — is abbreviated ___.

YAGNI recommends building the simplest thing that satisfies today's actual requirement, adding the pattern later only if a real second case appears.

10. This unit grouped Factory and Singleton in one category, and Adapter, Observer, and Strategy across two others. Answer both parts:

(a) What category do Factory and Singleton belong to?

(b) Fill in the blank: Observer and Strategy are ___ patterns, about how objects communicate and share responsibility, while Adapter is structural.

Creational patterns control object creation (Factory, Singleton); structural patterns compose objects together (Adapter); behavioral patterns govern communication (Observer, Strategy).
