1. In a fixed-context encoder-decoder architecture, what does the decoder use as its summary of the entire input?

The context vector is the encoder's only handoff to the decoder in this architecture.

2. Fill in the blank: replacing reliance on one fixed context vector with direct, weighted access to every encoder hidden state is called ___.

Attention removes the fixed-size information bottleneck rather than just shrinking it.

3. Why does multi-head attention split computation into several smaller heads instead of one large head?

Independently-learned heads can specialize without competing for the same weights within one softmax.

4. Fill in the blank: one full query/key/value attention computation, before any splitting into parallel versions, is an ___.

Multi-head attention runs several of these in parallel, each with its own learned projections.

5. Why does a Transformer need positional encoding?

Attention alone has no built-in sense of token order — positional encoding supplies it.

6. Sentence length and the fixed-context bottleneck. Answer both parts:

(a) As input sentences get longer, a fixed-size context vector's contents become...

(b) This compression is best described as a...

A fixed-size vector holding more and more information as sentences grow is a genuine information bottleneck.

7. Comparing decoder access to the input. Answer both parts:

(a) Without attention, the decoder can access...

(b) With attention, the decoder can access...

Attention's whole point is removing the single fixed-vector restriction on what the decoder can see.

8. Multi-head attention mechanics. Answer both parts:

(a) Each head in multi-head attention typically has...

(b) After all heads compute their output, the results are...

Separate projections let heads specialize; concatenation restores the shape the rest of the model expects.

9. Interpreting a trained attention head. Answer both parts:

(a) In a real trained Transformer, different attention heads within the same layer often...

(b) A row in an attention weight matrix represents...

Each row sums the relevance of every key token to that row's specific query token.

10. Residual connections and depth. Answer both parts:

(a) The "x + attn_out" line in a Transformer block is an example of...

(b) This is the same additive idea, applied across depth, as...

Both give a gradient a direct additive path, avoiding the compounding-shrinkage failure mode from earlier units.
