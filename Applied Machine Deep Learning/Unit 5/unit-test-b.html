1. Why does a fixed-context encoder-decoder architecture tend to translate long sentences worse than short ones?

A fixed-size bottleneck holding increasingly compressed information is the direct cause of the quality drop.

2. Fill in the blank: what attention specifically replaces reliance on is the fixed-size ___.

Instead of one fixed summary, attention gives direct access to every encoder hidden state.

3. In multi-head attention, why does giving each head its own separate Wq, Wk, Wv projections matter?

Independent projections are exactly what allow heads to specialize rather than duplicate each other.

4. Fill in the blank: running several attention heads in parallel and concatenating their outputs back together is called ___.

Each head works in a smaller subspace; concatenation restores the original model dimension.

5. What does layer normalization do inside a Transformer block?

Layer normalization keeps values well-behaved so deep stacks of blocks train more stably.

6. Encoder and decoder roles. Answer both parts:

(a) The encoder's job is to...

(b) Without attention, the decoder's only handoff from the encoder is...

The encoder summarizes; without attention, only one fixed-size summary reaches the decoder.

7. What attention changes, precisely. Answer both parts:

(a) Attention gives the decoder access to...

(b) This removes the specific problem of...

Attention's core fix is direct access, removing the single fixed-size summary as the only channel of information.

8. Splitting one attention computation into several. Answer both parts:

(a) Splitting one 8-dimensional head into two 4-dimensional heads mainly changes...

(b) The actual gain from doing this is...

Multi-head attention is about diversity of representation, not primarily raw added capacity.

9. Reading an attention weight matrix. Answer both parts:

(a) One row of the matrix represents...

(b) A cell with a very low value indicates...

Each cell's value is the relevance weight between one specific query and one specific key.

10. Stacking Transformer blocks. Answer both parts:

(a) A very deep stack of Transformer blocks, without residual connections, would risk...

(b) Fill in the blank: the sub-layer that processes each token's vector independently, after attention has already gathered context, is the ___.

Residual connections address the depth-wise version of the same vanishing-gradient risk; the FFN handles per-token processing after attention.
