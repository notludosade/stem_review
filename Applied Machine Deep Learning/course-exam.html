1. Why does a weight matrix let a layer compute every neuron's weighted sum in one matrix multiply?

One row per neuron is exactly what makes a single matrix multiply equivalent to every neuron's weighted sum at once.

2. Fill in the blank: the standard loss function for classification, built from negative log-probability, is ___ loss.

Its log term punishes confidently wrong predictions far more severely than MSE does.

3. What can happen if gradient descent's learning rate is set too large?

Overshooting the minimum by more than the starting distance makes each subsequent step worse, not better.

4. Why does backpropagation compute gradients starting from the output layer and moving backward?

Each layer's local gradient is reused by the layer before it, which only works walking backward from where loss is known.

5. Fill in the blank: one full pass through the entire training set is called one ___.

An epoch is made up of many iterations, one per mini-batch processed.

6. What does dropout actually do during training?

Dropout is active only during training and changes which activations are zeroed on every single step.

7. Why does a fully-connected layer over a raw image need vastly more parameters than a convolutional layer covering that same image?

A convolutional filter's weights are shared across every position; a fully-connected layer's are all independent.

8. Fill in the blank: how many positions a filter moves between each computation is called its ___.

A stride of 2 skips every other position compared to a stride of 1.

9. Why does a 3×3 filter in a network's second conv+pool block effectively cover more of the original image than one in the first block?

Receptive field grows with depth even though each individual filter stays the same small size.

10. Why do "the dog bit the mail carrier" and "the mail carrier bit the dog" produce the same bag-of-words representation?

Order carries the meaning here, and order is exactly what bag-of-words throws away.

11. Fill in the blank: unrolling a recurrence across time steps and backpropagating through the result like an ordinary deep network is called ___.

This is what makes an RNN's vanishing gradient possible to explain using the same chain rule from Unit 2.

12. Why does an LSTM's cell state update, c_new = f × c_prev + i × c_candidate, help avoid a vanishing gradient?

The additive update is the same shortcut-connection idea behind residual connections in very deep networks.

13. In a fixed-context encoder-decoder architecture, why does translation quality tend to degrade on longer sentences?

A fixed-size vector holding increasingly compressed information is a genuine information bottleneck.

14. Fill in the blank: running several smaller attention computations in parallel, each with its own learned projections, is called ___.

Different heads can specialize in different kinds of relationships, instead of averaging every signal into one blend.

15. Why does a Transformer need positional encoding?

Attention itself has no built-in sense of token order — positional encoding supplies it.

16. Why is a matrix multiply well suited to GPU hardware specifically?

Independent multiply-add operations match exactly the many-simple-cores design a GPU was built around.

17. Fill in the blank: freezing every pretrained weight and training only a newly added head is called ___.

Fine-tuning goes further, unfreezing some pretrained layers as well.

18. Why can random search outperform grid search on the same trial budget?

Grid search's exhaustive but shallow coverage wastes trials on hyperparameters that don't matter much.

19. Why can a model that always predicts the majority class score very high accuracy on an imbalanced dataset, despite being useless?

A dataset that's mostly one class rewards always guessing that class with high accuracy, regardless of actual skill.

20. Fill in the blank: a change in the true relationship between input and correct output, often invisible until new labels arrive, is called ___.

This is distinct from data drift, which is detectable from input statistics alone, without any labels.
