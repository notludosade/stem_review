1. Why do "the dog bit the mail carrier" and "the mail carrier bit the dog" have identical bag-of-words representations?

Order carries the meaning here, and order is exactly what bag-of-words throws away.

2. Fill in the blank: input where different examples can have different numbers of elements is called ___ input.

A sequence model needs to handle this natively, without relying only on padding to a fixed size.

3. What does backpropagation through time (BPTT) actually do?

Unrolling turns the recurrence into a chain that ordinary backpropagation can walk through.

4. Fill in the blank: capping a gradient's magnitude before it's used to update weights, directly addressing exploding gradients, is called ___.

Clipping puts a ceiling on an oversized gradient before it's applied.

5. What does an LSTM's output gate control?

h_new = o * tanh(c_new) — the output gate filters how much of memory is surfaced right now.

6. Comparing representations of text. Answer both parts:

(a) A representation that discards word order entirely is a...

(b) A model that processes elements one at a time, in order, is a...

One representation throws order away by design; the other is built specifically to track it.

7. Padding sentences to a fixed length before a fully-connected layer. Answer both parts:

(a) This padding directly solves...

(b) It leaves unsolved...

Padding fixes shape, not the position-independent weight sharing a genuine sequence model provides.

8. Gradient compounding across time steps. Answer both parts:

(a) Multiplying many per-step factors under 1 together, across many time steps, causes...

(b) tanh's derivative is capped at a maximum of...

Because tanh's derivative rarely reaches its own maximum of 1, plain RNNs lean toward vanishing rather than exploding.

9. Vanishing versus exploding gradients. Answer both parts:

(a) Gradient clipping is a complete, direct fix for...

(b) Vanishing gradients instead require...

Clipping caps an oversized gradient but can't inject signal back into one that's already collapsed toward zero.

10. Comparing LSTMs and GRUs. Answer both parts:

(a) An LSTM's cell state update, c_new = f * c_prev + i * c_candidate, helps avoid vanishing gradients because it is...

(b) Fill in the blank: the simplified architecture with two gates and no separate cell state is the ___.

The additive cell state update is the key mechanism; the GRU is the simplified two-gate alternative.
