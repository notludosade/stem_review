1. A model treats "cat chases dog" and "dog chases cat" identically. What kind of representation is it most likely using?

Identical treatment of reordered sentences with the same words is the signature of an order-blind, bag-of-words representation.

2. Fill in the blank: an architecture built to process elements in order, one at a time, regardless of how many there are, is called a ___.

This is what fixes both the order problem and the variable-length problem together, natively.

3. Why is BPTT described as treating each time step "like a layer" in an ordinary deep network?

The unrolled recurrence is structurally similar enough to a deep feedforward chain that the same backward-pass logic applies.

4. Fill in the blank: when per-step gradient factors exceed 1, compounding across many time steps produces an ___.

This is the mirror image of a vanishing gradient — growth instead of shrinkage.

5. What does an LSTM's input gate control?

c_new = f * c_prev + i * c_candidate — the input gate i scales how much new information is added.

6. Order-sensitivity in language. Answer both parts:

(a) "The mail carrier bit the dog" versus "the dog bit the mail carrier" differ in meaning because of...

(b) A representation built to capture this difference must track...

Both sentences share a vocabulary; only their order differs, and that's exactly what changes the meaning.

7. Fixed-size versus sequence architectures. Answer both parts:

(a) A CNN's filters and a fully-connected layer's weight matrix both assume...

(b) A genuine sequence model instead needs to handle...

Fixed-shape architectures need padding as a workaround; sequence models are built to handle variable length directly.

8. Why plain RNNs lean toward vanishing rather than exploding gradients. Answer both parts:

(a) tanh's derivative is capped at a maximum value of...

(b) This makes a typical per-step factor land...

A capped, usually-smaller-than-1 derivative pushes plain RNNs toward vanishing far more often than exploding.

9. Comparing fixes. Answer both parts:

(a) Fill in the blank: capping a gradient's magnitude before applying a weight update is ___.

(b) This technique specifically targets...

Clipping puts a ceiling in place, which is exactly the fix an exploding — not vanishing — gradient needs.

10. Comparing gate counts. Answer both parts:

(a) An LSTM uses how many gates?

(b) Fill in the blank: name one of the two gates a GRU uses instead (update gate or reset gate).

LSTMs use three gates and a separate cell state; GRUs simplify to two gates with no separate cell state.
