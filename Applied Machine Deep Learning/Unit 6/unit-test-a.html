1. Why is a matrix multiply well suited to a GPU's architecture specifically?

Independent multiply-add operations are exactly the shape of problem thousands of simple GPU cores were built for.

2. Fill in the blank: total work completed per unit time, rather than the speed of any single operation, is called ___.

Many parallel cores boost this metric even without any individual core being especially fast.

3. What does feature extraction do with a pretrained network's weights?

Feature extraction keeps the pretrained network fixed and trains only the new layer added on top.

4. Fill in the blank: losing previously learned, useful weights by updating them too aggressively on new data is called ___.

A small learning rate on unfrozen pretrained layers is meant to guard against exactly this.

5. What is a hyperparameter, as distinguished from a parameter?

Learning rate, batch size, and dropout rate are hyperparameters; weights and biases are parameters.

6. Comparing what a GPU speeds up. Answer both parts:

(a) A GPU dramatically speeds up...

(b) It does little to speed up...

Parallel hardware helps within-iteration work; it can't remove the genuine sequential dependency between iterations.

7. Serial versus parallel time. Answer both parts:

(a) Serial computation's total time scales mainly with...

(b) Parallel computation's total time depends far more on...

Serial cost tracks operation count directly; parallel cost tracks available core count for independent work.

8. Choosing a transfer strategy. Answer both parts:

(a) A small new dataset, similar to the original training data, favors...

(b) A larger dataset from a meaningfully different domain can better afford...

Dataset size and domain similarity, not a fixed rule, guide how deep to unfreeze.

9. Guarding against catastrophic forgetting. Answer both parts:

(a) Catastrophic forgetting happens when new training...

(b) A common safeguard against it is...

Small, gentle updates to pretrained layers help preserve what they already learned.

10. Grid search versus random search. Answer both parts:

(a) With a 3x3 grid over two hyperparameters, grid search tests how many distinct values of each hyperparameter?

(b) Random search with the same 9-trial budget instead tests...

Random sampling avoids repeating values, giving broader per-dimension coverage for the same total trial count.
