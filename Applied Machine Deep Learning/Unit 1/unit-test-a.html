1. What does a layer's weight matrix let you compute in a single matrix multiply?

W @ x computes every neuron's weighted sum at once because each row of W belongs to one neuron.

2. Fill in the blank: the activation function computed as max(0, z), and the default choice for hidden layers in most modern networks, is ___.

ReLU stays linear for positive inputs instead of saturating the way sigmoid and tanh do.

3. Why does cross-entropy loss punish a confidently wrong prediction far more severely than Mean Squared Error does?

The log term is what makes cross-entropy explode for confidently wrong predictions, unlike MSE's comparatively mild penalty.

4. Fill in the blank: for a network with many weights, the collection of one partial derivative per weight is called the ___.

Each entry of the gradient vector describes how one specific weight alone would change the loss.

5. What problem does momentum fix in plain gradient descent?

Momentum's running average of recent gradients smooths out the zig-zag and speeds up consistent progress.

6. A network has an input layer, one hidden layer, and an output layer. Answer both parts:

(a) The hidden layer's values are...

(b) Fill in the blank: the layer shaped to produce the network's final answer is the ___.

Hidden layers pass values only to later layers within the network; the output layer is what the rest of the world actually sees.

7. Comparing output-layer activations. Answer both parts:

(a) For a single yes/no prediction, the output layer typically uses...

(b) For choosing one class out of several, the output layer typically uses...

Sigmoid handles a single probability; softmax coordinates a whole distribution across multiple classes at once.

8. Pairing losses with tasks. Answer both parts:

(a) Predicting a house's price in dollars is best paired with...

(b) Fill in the blank: pairing a saturating output activation with MSE works poorly because MSE's own slope also tends to ___ where the prediction is most confidently wrong.

A continuous dollar amount calls for MSE; a saturated activation paired with MSE compounds, rather than fixes, the flat-gradient problem.

9. Points on a loss surface. Answer both parts:

(a) A point where loss is lower than every nearby point, but not necessarily the lowest possible overall, is a...

(b) A point that curves downward in some directions and upward in others, where the gradient is zero without it being a minimum, is a...

Both are points with zero gradient, but only one is actually a minimum in every direction.

10. Optimizer behavior. Answer both parts:

(a) Fill in the blank: the optimizer used in most real training scripts, giving every weight its own effectively adapted learning rate, is ___.

(b) An excessively large learning rate is most likely to cause...

Adam builds on momentum with per-weight adaptive rates; an oversized rate still risks overshoot regardless of optimizer.
