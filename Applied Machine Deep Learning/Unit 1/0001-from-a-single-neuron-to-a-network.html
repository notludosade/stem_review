From a Single Neuron to a Network

AI Developer's Unit 4 built one perceptron and stacked a few into a layer. This course starts exactly there and goes further: real weight matrices, every activation function you'll actually meet in practice, and why the choice among them is never cosmetic.

Lesson 2 → Contents Glossary →

Recall the shape: a perceptron takes inputs, multiplies each by a weight, adds a bias, sums it all, and passes that sum through an activation function. A real network is nothing more than many of these computed at once, arranged in layers, each layer's output feeding the next layer's input. The part AI Developer left as a loop over individual neurons is, in practice, a handful of matrix operations — and the specific activation function attached to each layer isn't a footnote, it's one of the first real design decisions in building a network by hand.

Python — NumPy, a full layer at once 
import numpy as np

# One layer of 3 neurons, each taking 4 inputs.
# W has shape (3, 4): one row of weights per neuron.
W1 = np.random.randn(3, 4) * 0.1
b1 = np.zeros(3)

x = np.array([0.5, -1.2, 0.3, 0.8])   # 4 input features

def relu(z):
    return np.maximum(0, z)

hidden = relu(W1 @ x + b1)   # all 3 neurons' weighted sums, in one matrix multiply

# A second layer turns those 3 hidden values into 1 output.
W2 = np.random.randn(1, 3) * 0.1
b2 = np.zeros(1)

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

output = sigmoid(W2 @ hidden + b2)
print(output)   # a single number between 0 and 1

W1 @ x + b1 computes every neuron's weighted sum in hidden's layer in one operation — W1 is a weight matrix, with one row of weights per neuron in that layer, so a matrix-vector multiply is exactly "every neuron computes its own weighted sum," done all at once instead of neuron by neuron. hidden here is a hidden layer: it sits between the raw input and the network's final answer, and nothing outside the network ever looks at its values directly. output is the output layer — whatever shape the task actually needs, one number for a yes/no prediction here, more for anything else.

Notice the two layers above use two different activation functions on purpose. ReLU (max(0, z)) is the default choice for hidden layers in almost every modern network: it's cheap to compute, and unlike sigmoid or tanh, it doesn't squash large positive inputs into a narrow range — a neuron firing strongly stays informative instead of getting flattened toward 1.0. Sigmoid and tanh both saturate at their extremes (their curves go nearly flat for large |z|), which — as Unit 2 shows once gradients enter the picture — becomes a real problem for training deep networks, not just an aesthetic one. Sigmoid still earns its place at an output layer for yes/no predictions, since squashing to (0, 1) is exactly what a probability needs. For predicting one class out of several, the output layer instead uses softmax, which turns a whole vector of raw scores into a probability distribution — every value between 0 and 1, all of them summing to exactly 1 — rather than squashing each score independently the way sigmoid does.

Definition A weight matrix holds one row of weights per neuron in a layer, so W @ x computes every neuron's weighted sum in one matrix multiply. A hidden layer sits between input and output and is never read directly; the output layer produces the network's final answer, shaped to the task. ReLU is max(0, z); sigmoid squashes to (0, 1); tanh squashes to (−1, 1); softmax turns a vector of scores into a probability distribution that sums to 1.
Why the activation choice isn't cosmetic Swapping ReLU for sigmoid in every hidden layer of a real network doesn't just change the numbers slightly — it can change whether the network trains at all. Unit 2 shows exactly why: gradient descent needs a real, non-flat slope to follow backward through every layer, and a saturated sigmoid's near-zero slope is precisely where that signal starts to disappear. Filing that away now makes Lesson 4's backpropagation land as an explanation, not a surprise.

1. What does a weight matrix's shape represent for a layer of neurons?

W1 @ x above computes all 3 neurons' weighted sums in one operation because W1 has one row per neuron.

2. Why is ReLU the default choice for hidden layers in most modern networks, instead of sigmoid?

Sigmoid flattens toward 1.0 for large inputs; ReLU stays linear (and informative) for any positive input.

3. Why does a multi-class output layer use softmax instead of applying sigmoid to each output independently?

Independent sigmoids wouldn't necessarily sum to 1; softmax is built specifically to produce one coherent distribution over classes.
