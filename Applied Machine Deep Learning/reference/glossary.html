Unit 1 — The Perceptron and Gradient Descent

Weight matrix

Holds one row of weights per neuron in a layer, so W @ x computes every neuron's weighted sum in one matrix multiply, instead of neuron by neuron.

Hidden layer / output layer

A hidden layer sits between input and output and is never read directly from outside the network; the output layer produces the network's final answer, shaped to whatever the task needs.

ReLU / sigmoid / tanh / softmax

ReLU is max(0, z), the default for hidden layers since it doesn't saturate for positive inputs; sigmoid squashes to (0, 1); tanh squashes to (−1, 1); softmax turns a vector of scores into a probability distribution across classes that sums to 1.

Loss function

Takes a prediction and the true value and returns one number describing how bad that prediction was — the thing every training loop in this course minimizes.

Mean Squared Error (MSE)

The squared difference between prediction and true value, (prediction − true)² — the standard loss for regression.

Cross-entropy loss

Built from negative log-probability, the standard loss for classification — grows sharply as a confident prediction turns out to be wrong, unlike MSE's comparatively mild penalty.

Gradient vector

For a network with many weights, one partial derivative per weight — how much that weight alone would change the loss, holding every other weight fixed.

Local minimum / saddle point

A local minimum is a point where loss is lower than every nearby point, but not necessarily the lowest possible overall; a saddle point curves downward in some directions and upward in others, so the gradient is zero there without it being a minimum.

Momentum

Accumulates a running average of recent gradients, smoothing out zig-zagging across narrow valleys and speeding up consistent downhill progress compared to plain gradient descent.

Adam

The optimizer used in most real training scripts, building on momentum by giving every individual weight its own effectively adapted learning rate.

Unit 2 — Training a Neural Network

Backpropagation

Computes the loss gradient for every weight by walking backward through a network, layer by layer, from the output.

Chain rule

The calculus rule that makes each layer's already-computed local gradient a valid, reusable ingredient for the gradient of the layer before it.

Local gradient

A small derivative computed at a single point in the network, using only values already available there, rather than borrowed from elsewhere.

Batch / stochastic / mini-batch gradient descent

Batch gradient descent computes a gradient from the entire training set before every update; stochastic gradient descent (SGD) updates from just one example at a time; mini-batch gradient descent, the practical default, updates from a small chunk of examples at a time.

Batch size

How many examples are in one mini-batch — small batches give noisier but more frequent updates, large batches give smoother but more expensive ones.

Iteration (step)

One single weight update, using one mini-batch's gradient.

Epoch

One full pass through the entire training set — made up of many iterations, one per mini-batch processed.

Regularization

Any technique that trades away a little training accuracy on purpose, in exchange for a network that generalizes better to data it hasn't seen.

Dropout

Randomly zeroes out a different fraction of a layer's activations on every training step; active only during training, forcing the network to spread a pattern redundantly instead of relying on one neuron.

Weight decay

Adds a penalty proportional to squared weight size directly into the loss (L2 regularization), pulling weights toward smaller values alongside minimizing prediction error.

Early stopping

Halts training once validation loss stops improving, even if training loss is still falling.

Unit 3 — Convolutional Neural Networks

Fully-connected layer

Connects every input to every neuron independently, with no assumption about structure — the direct but parameter-heavy alternative to a convolutional layer over image data.

Spatial locality

The assumption that nearby pixels are more related to each other than to distant pixels — what a small local filter matches.

Translation invariance

The assumption that a pattern like an edge means the same thing regardless of where in the image it appears — what licenses reusing the same filter weights at every position.

Stride

How many positions a convolutional filter moves between each computed value.

Padding

Adds a border of zeros around an input before convolving, most often to keep the output the same size as the input ("same" padding) instead of shrinking it ("valid" padding).

Max pooling / average pooling

Max pooling keeps the largest value in each small region of a feature map; average pooling keeps the mean — either way shrinking the map with no new weights to learn.

Receptive field

How much of the original input a single value in a layer's output is actually influenced by — grows with every convolutional or pooling layer stacked before it.

Unit 4 — Recurrent and Sequence Models

Bag-of-words

A representation that treats input as an unordered collection, discarding sequence order entirely — two sentences with the same words but different order look identical to it.

Variable-length input

Input where different examples can have different numbers of elements, unlike a fixed-size image or feature vector.

Sequence model

An architecture built to process elements in order, one at a time, regardless of how many there are — fixing both the order problem and the variable-length problem natively.

Backpropagation through time (BPTT)

Unrolls a recurrence across time steps and backpropagates through the result like an ordinary deep network, one layer per time step.

Vanishing gradient / exploding gradient

A vanishing gradient results from multiplying many per-step factors under 1 together across many time steps; an exploding gradient is the same compounding effect with factors over 1.

Gradient clipping

Caps a gradient's magnitude before it's used to update weights — a direct fix for exploding gradients specifically.

Cell state

An LSTM's separate long-term memory, distinct from its hidden state, updated additively rather than through repeated multiplication.

Forget gate / input gate / output gate

An LSTM's three gates: the forget gate controls how much of the old cell state survives, the input gate controls how much new candidate information is written in, and the output gate controls how much of the cell state is exposed as the hidden state.

GRU (Gated Recurrent Unit) / update gate / reset gate

A simplified gated architecture using two gates — an update gate (merging forget and input) and a reset gate — with no separate cell state, and fewer parameters than an LSTM.

Unit 5 — Attention and Transformers

Encoder-decoder architecture

Uses one network to read an input sequence and a separate network to generate an output sequence from it.

Context vector

A fixed-size summary the encoder compresses its entire input into — the information bottleneck attention was built to remove.

Attention

Replaces reliance on a single fixed context vector with direct, weighted access to every encoder hidden state.

Attention head

One full query/key/value attention computation, producing one relevance weighting per token.

Multi-head attention

Runs several attention heads in parallel, each with its own learned projections working in a smaller subspace, then concatenates their outputs back together.

Positional encoding

A fixed, position-dependent pattern added to token embeddings before attention runs, since attention's own math has no built-in sense of order.

Residual connection

Adds a sub-layer's input back onto its output, giving the gradient a direct path backward through a deep stack of blocks.

Layer normalization

Rescales each token's vector to a stable mean and variance after a residual addition, keeping values well-behaved across many stacked blocks.

Feed-forward network

A small two-layer MLP applied independently to each token's vector, after attention has already gathered context across tokens.

Unit 6 — Training at Scale

Serial computation

Processes operations one at a time, in sequence — total time scales directly with the number of operations.

Parallel computation

Processes many independent operations simultaneously across multiple cores — total time depends far more on available cores than operation count.

Throughput

Total work completed per unit time, not the speed of any single operation — the metric parallel hardware like a GPU is built to maximize.

Transfer learning

Starts from a network already trained on a different, usually larger dataset, instead of training from scratch.

Feature extraction

Freezes all pretrained weights and trains only a newly added head on top.

Fine-tuning

Also unfreezes some pretrained layers, typically with a small learning rate, in addition to training a new head.

Catastrophic forgetting

Losing previously learned, useful weights by updating them too aggressively on new data.

Hyperparameter

A setting fixed before training and chosen by the practitioner — learning rate, batch size, dropout rate — rather than learned automatically by gradient descent.

Grid search

Exhaustively tries every combination from fixed value sets — thorough, but the trial count grows multiplicatively with every added hyperparameter.

Random search

Samples each hyperparameter's value independently at random, using the same total trial budget — often outperforms grid search by covering each dimension more broadly.

Unit 7 — Evaluating and Deploying Models

Confusion matrix

A table counting true positives, false positives, false negatives, and true negatives — every metric in this unit is computed from just these four counts.

Precision

Of everything the model predicted as positive, how much actually was — a low precision means a lot of false alarms.

Recall

Of everything that actually was positive, how much the model caught — a low recall means a lot of real cases slipping through undetected.

F1 score

The harmonic mean of precision and recall — stays closer to whichever is lower, so a model can't score well by excelling at one while neglecting the other.

Data drift

A change in the distribution of input features compared to training time, detectable by comparing input statistics alone, without new labels.

Concept drift

A change in the true relationship between input and correct output, often invisible until new labels eventually arrive, even when inputs still look statistically familiar.

Retraining trigger

A defined threshold — a metric crossing a set value, or a fixed time interval — that starts a new training run automatically, rather than leaving the decision to whenever someone happens to notice.
