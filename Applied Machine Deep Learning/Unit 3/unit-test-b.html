1. A convolutional layer's parameter count stays fixed no matter how large the input image gets. Why?

Parameter sharing across positions is exactly why filter size, not image size, determines the parameter count.

2. Fill in the blank: the assumption that nearby pixels are more related to each other than to distant pixels is called ___.

A small local filter matches this exact assumption about image structure.

3. In conv_at(img, f, row, col) from this unit's lessons, what does np.sum(patch * f) actually compute?

patch * f multiplies elementwise; np.sum collapses that into the single feature map value at that position.

4. Fill in the blank: how many positions a filter moves between each computed value is its ___.

A stride of 2 skips every other position compared to a stride of 1.

5. What distinguishes average pooling from max pooling?

Both shrink the map by region; only the statistic kept per region differs.

6. A fully-connected layer versus a convolutional layer over a 256×256 image. Answer both parts:

(a) Doubling the image's width and height would most affect the parameter count of...

(b) The convolutional layer's parameter count would instead...

Only the fully-connected layer's parameter count is tied to the raw pixel count of the image.

7. CNN assumptions applied. Answer both parts:

(a) A filter trained to detect a vertical edge in the top-left of an image can also detect it in the bottom-right because of...

(b) A 3×3 filter only looking at a small local neighborhood, rather than the whole image at once, reflects...

Translation invariance is about reused meaning across position; spatial locality is about how much of the image one filter looks at.

8. With a 6×6 input, a 2×2 filter, and stride 1. Answer both parts:

(a) Fill in the blank: the output feature map is ___×___ (enter just one side's length).

(b) If "same" padding were used instead of no padding, the output would be...

⌊(6 − 2) / 1⌋ + 1 = 5 with no padding; same padding is specifically calibrated to preserve the 6×6 size.

9. Choosing stride and padding for a network's early layers. Answer both parts:

(a) Early layers, still building up basic features, typically favor...

(b) Later layers can more easily afford to...

Detail preservation matters more early; compactness becomes more affordable once basic features are already extracted.

10. Depth and coverage in a CNN. Answer both parts:

(a) A layer's receptive field is best described as...

(b) Fill in the blank: stacking more conv+pool blocks before a layer, even with small fixed filter sizes, ___ its receptive field.

Deeper layers see an increasingly large effective patch of the original image, one reason deep CNNs detect increasingly abstract patterns.
