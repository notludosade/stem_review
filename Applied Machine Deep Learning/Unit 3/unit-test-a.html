1. Why does a fully-connected layer over a raw image need vastly more parameters than a convolutional layer covering the same image?

A fully-connected layer's weights are all independent; a convolutional filter's weights are shared across every position.

2. Fill in the blank: the assumption that a pattern means the same thing no matter where in the image it appears is called ___.

This is exactly what licenses reusing the same filter weights at every position.

3. What single value does a convolution compute at one position over an input patch?

Multiply filter and patch elementwise, then sum — that sum is the feature map's value at that position.

4. Fill in the blank: adding a border of zeros around an input before convolving, often to keep output size equal to input size, is called ___.

"Same" padding is calibrated specifically to preserve spatial size between input and output.

5. What does max pooling do to a feature map?

Max pooling shrinks a feature map by keeping only each region's largest value, with no new weights involved.

6. Comparing a fully-connected layer and a convolutional layer over the same 100×100 grayscale image. Answer both parts:

(a) The fully-connected layer's parameter count depends on...

(b) The convolutional layer's parameter count depends on...

A convolutional filter's weight count is fixed and reused everywhere; a fully-connected layer's grows with the image.

7. Two assumptions behind CNNs. Answer both parts:

(a) The assumption that nearby pixels are more related than distant ones is...

(b) These two assumptions generally do not transfer well to...

Tabular columns lack the spatial relationships that make locality and translation invariance meaningful assumptions.

8. With a 9×9 input, a 3×3 filter, and stride 2. Answer both parts:

(a) Fill in the blank: the output feature map is ___×___ (enter just one side's length).

(b) This uses the formula...

⌊(9 − 3) / 2⌋ + 1 = 4, giving a 4×4 output.

9. Stride and padding compared. Answer both parts:

(a) Increasing stride from 1 to 2 mainly...

(b) Padding, by contrast, mainly...

Stride controls how much the filter skips; padding controls whether spatial size is preserved.

10. Deep CNN stacking. Answer both parts:

(a) Fill in the blank: how much of the original input a layer's output value is actually influenced by is its ___.

(b) This quantity, for a fixed 3×3 filter size, tends to...

Even with a fixed filter size, stacking blocks on already-pooled data grows the effective coverage over the original image.
