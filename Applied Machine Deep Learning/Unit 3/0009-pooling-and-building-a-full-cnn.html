Pooling and Building a Full CNN

Lesson 8 computed one feature map. A real CNN stacks many convolutional layers with something shrinking the data between them — this lesson covers that shrinking step, and assembles the whole architecture end to end.

← Lesson 8 Unit 4, Lesson 10 → Contents Glossary →

AI Developer's Lesson 15 named pooling as something that "keeps the strongest signal in each region." Concretely: max pooling divides a feature map into small non-overlapping regions (2×2 is standard) and keeps only the largest value in each one, discarding the rest. Average pooling does the same division but keeps the mean of each region instead of its maximum. Either way, a 4×4 feature map pooled with 2×2 regions comes out as a 2×2 map — a factor-of-4 reduction in data, with no new weights to learn at all.

Python — PyTorch, both pooling types 
import torch.nn as nn

max_pool = nn.MaxPool2d(kernel_size=2)   # keeps the largest value per 2x2 region
avg_pool = nn.AvgPool2d(kernel_size=2)   # keeps the mean value per 2x2 region

# A minimal full CNN: two conv+pool blocks, then a classifier head
model = nn.Sequential(
    nn.Conv2d(3, 16, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),   # 32x32x3 -> 16x16x16
    nn.Conv2d(16, 32, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),  # 16x16x16 -> 8x8x32
    nn.Flatten(),                                                             # 8x8x32 -> 2048
    nn.Linear(8 * 8 * 32, 128), nn.ReLU(),
    nn.Linear(128, 10)                                                        # 10-class output
)

Notice the pattern repeating: convolution extracts local features, ReLU keeps only the useful signal, pooling shrinks the map. Each conv+pool block after the first is working on an already-pooled, already-abstracted version of the image, so a small 3×3 filter in the second block effectively "sees" a much larger patch of the original image than a 3×3 filter in the first block does. That effective coverage is a layer's receptive field, and it grows with every conv+pool block stacked — which is exactly why deeper layers in a real CNN tend to respond to increasingly large, increasingly abstract patterns (edges, then textures, then shapes, then whole objects), while the earliest layers stay focused on small local detail.

Definition Max pooling keeps the largest value in each small region of a feature map; average pooling keeps the mean. A layer's receptive field is how much of the original input a single value in that layer's output is actually influenced by — it grows with every convolutional or pooling layer stacked before it.
Why pooling adds a little tolerance for exact pixel position If a recognizable feature shifts by a pixel or two between two images of the same object, the raw feature map values shift too — but max pooling over a small region often keeps returning the same maximum regardless of exactly which pixel within that region held it. That small amount of positional slack is separate from, and stacks on top of, the translation invariance Lesson 7 covered from weight sharing itself — one comes from reusing the same filter everywhere, the other from tolerating small shifts within each pooled region.

1. What does max pooling do to a feature map?

MaxPool2d(kernel_size=2) keeps the largest of each 2x2 region, shrinking the map with no new weights.

2. Why does a 3×3 filter in a network's second conv+pool block effectively cover more of the original image than one in the first block?

Receptive field grows with depth even though each individual filter stays the same small size.

3. In the example model above, what does nn.Flatten() do right before the classifier head?

nn.Linear expects a flat vector, so Flatten reshapes the 3D feature maps into one dimension first.
