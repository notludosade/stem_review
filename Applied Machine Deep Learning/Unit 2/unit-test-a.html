1. What direction does backpropagation move through a network's layers, and why?

Working backward lets dL_dzo, for example, be reused directly by the hidden layer's gradient computation.

2. Fill in the blank: a small derivative computed at a single point in the network, from values already available there, is a ___.

dao_dzo = a_o * (1 - a_o) is a local gradient — needing nothing but a_o itself.

3. What distinguishes mini-batch gradient descent from stochastic gradient descent (SGD)?

SGD is the batch-size-1 extreme; mini-batch sits between SGD and full batch gradient descent.

4. Fill in the blank: one full pass through the entire training set is called one ___.

Training typically runs for many epochs, not just one.

5. What problem is regularization meant to address?

Regularization trades a little training accuracy for better generalization to unseen data.

6. In the tiny two-neuron network from this unit, dL_dzo is computed once. Answer both parts:

(a) dL_dzo is used to compute...

(b) This reuse is the direct result of applying...

The chain rule is exactly what licenses reusing one already-computed factor across multiple downstream gradients.

7. Comparing the forward and backward pass. Answer both parts:

(a) The forward pass computes...

(b) The backward pass computes...

Forward produces the prediction and loss; backward turns that loss into gradients for every weight.

8. Batch size tradeoffs. Answer both parts:

(a) A small batch size tends to produce a gradient estimate that is...

(b) A large batch size tends to produce a gradient estimate that is...

Batch size trades noise and memory cost against how smooth and reliable each individual gradient estimate is.

9. With 20,000 training examples and a batch size of 100. Answer both parts:

(a) Fill in the blank: one epoch takes ___ iterations.

(b) One "iteration" (or step) refers to...

20,000 divided by 100 is 200 iterations per epoch; each iteration is one update, not one full pass.

10. Comparing two regularization techniques. Answer both parts:

(a) Randomly zeroing a different subset of activations on every training step describes...

(b) Fill in the blank: adding a penalty proportional to squared weight size directly into the loss is called ___.

Dropout removes activations at random; weight decay penalizes large weight values directly in the loss.
