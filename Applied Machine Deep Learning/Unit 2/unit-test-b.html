1. Why does backpropagation compute gradients starting from the output layer instead of the input layer?

Loss is computed at the output, so that is where the chain of derivatives has to begin.

2. Fill in the blank: dao_dzo = a_o * (1 − a_o), computed using only a value already sitting at that one neuron, is an example of a ___.

It needs nothing borrowed from any other part of the network — the definition of a local gradient.

3. What is the defining feature of stochastic gradient descent (SGD)?

SGD is the batch-size-1 extreme, fast per update but noisy per gradient.

4. Fill in the blank: a single weight update, using one mini-batch's gradient, is called one ___ (or step).

An epoch is made up of many iterations, one per batch processed.

5. What tradeoff does regularization make, in general?

Regularization deliberately gives up some training-set fit for better generalization.

6. In the tiny network worked through this unit, dL_dah is computed from dL_dzo and w_o. Answer both parts:

(a) dL_dah represents...

(b) Reusing dL_dzo instead of recomputing it from scratch is an example of...

dL_dah = dL_dzo * w_o reuses a value already computed for the output neuron's own gradient.

7. Forward pass versus backward pass. Answer both parts:

(a) Values like z_h and a_h, computed during the forward pass, are later used to...

(b) This is why frameworks generally keep forward-pass values in memory until...

Local gradients during backpropagation are built directly from forward-pass values like a_h.

8. Full batch versus mini-batch. Answer both parts:

(a) Full batch gradient descent's main drawback on a large dataset is...

(b) Mini-batch gradient descent addresses this by...

Mini-batches sit between the slow, accurate full batch and the fast, noisy single-example SGD.

9. With 5,000 training examples and a batch size of 25. Answer both parts:

(a) Fill in the blank: one epoch takes ___ iterations.

(b) An "epoch," by definition, is...

5,000 divided by 25 is 200 iterations per epoch; the epoch itself is the full pass, not one update.

10. Comparing two regularization techniques. Answer both parts:

(a) Fill in the blank: randomly zeroing a different subset of activations on every training step, active only during training, is ___.

(b) Adding a penalty proportional to squared weight size directly into the loss describes...

Dropout zeroes activations at random; weight decay penalizes large weight values directly.
