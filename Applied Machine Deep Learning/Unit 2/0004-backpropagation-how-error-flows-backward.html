Backpropagation: How Error Flows Backward

AI Developer's Lesson 14 showed backpropagation's shape in code, output layer to input, reusing each layer's gradient in the one before it. This lesson runs that exact process by hand, with real numbers, on a network small enough to compute every single value yourself.

Take the smallest network that still has something to backpropagate through: two inputs, one hidden neuron, one output neuron, both using sigmoid. A forward pass produces a prediction and a loss, exactly as Unit 1 covered. Backpropagation is what happens next — walking back through that same network, computing how much each individual weight contributed to the final loss, using the chain rule to reuse work instead of repeating it.

Python — the same tiny network, forward and backward 
import numpy as np

def sigmoid(z): return 1 / (1 + np.exp(-z))

x1, x2, y = 1.0, 0.0, 1.0
w1, w2, b_h = 0.5, -0.6, 0.1     # weights/bias into the hidden neuron
w_o, b_o = 0.8, -0.2             # weight/bias from hidden to output

# Forward pass
z_h = w1 * x1 + w2 * x2 + b_h
a_h = sigmoid(z_h)
z_o = w_o * a_h + b_o
a_o = sigmoid(z_o)
loss = (a_o - y) ** 2

# Backward pass — the chain rule, one factor at a time
dL_dao = 2 * (a_o - y)               # d(loss)/d(output)
dao_dzo = a_o * (1 - a_o)            # sigmoid's own local derivative
dL_dzo = dL_dao * dao_dzo            # reused below, twice

dL_dwo = dL_dzo * a_h                # gradient for w_o
dL_dah = dL_dzo * w_o                # error passed back to the hidden neuron

dah_dzh = a_h * (1 - a_h)
dL_dzh = dL_dah * dah_dzh
dL_dw1 = dL_dzh * x1                 # gradient for w1
dL_dw2 = dL_dzh * x2                 # gradient for w2

Every line under "Backward pass" is one local gradient — a small, self-contained derivative computed using only values already sitting in memory from the forward pass — multiplied by whatever arrived from the layer just processed. Notice dL_dzo gets used twice: once to compute dL_dwo directly, and once more, unmodified, as the starting point for everything the hidden layer needs. That reuse is the entire efficiency argument for backpropagation over computing each weight's gradient from scratch — with two weights it barely matters, but the same pattern is what makes a network with fifty million weights trainable at all.

Definition Backpropagation computes the loss gradient for every weight by walking backward through a network, layer by layer, from the output. The chain rule is the calculus rule that makes each layer's gradient a valid ingredient for the one before it. A local gradient is one small derivative computed at a single point in the network, using only values already available there.
Why dL_dzo appears in two different gradients dL_dzo answers one specific question: "if the output neuron's pre-activation sum changed slightly, how much would loss change?" That answer doesn't depend on which weight you're about to compute a gradient for — it's a property of the output neuron alone. Both dL_dwo (this neuron's own weight) and dL_dah (the error signal handed to the previous layer) are legitimately built from it. Backpropagation is, at its core, computing exactly one local gradient per neuron and reusing it everywhere that neuron's output was used.

1. In the worked example, what is dL_dzo used for besides computing dL_dwo?

dL_dah = dL_dzo * w_o reuses dL_dzo directly, exactly the reuse backpropagation is built around.

2. What is a "local gradient," as used in this lesson?

dao_dzo = a_o * (1 - a_o) is exactly this — computable from a_o alone, with nothing borrowed from elsewhere.

3. Why does dL_dwo need a_h as one of its factors, and not just dL_dzo alone?

The chain rule multiplies dL_dzo by dzo_dwo, and dzo_dwo is exactly a_h given how z_o is defined.
