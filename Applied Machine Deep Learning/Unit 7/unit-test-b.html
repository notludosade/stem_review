1. Why does F1 score use the harmonic mean of precision and recall instead of a plain average?

The harmonic mean specifically punishes a large gap between precision and recall.

2. Fill in the blank: tp / (tp + fp) computes ___.

This is precision — of everything predicted positive, how much actually was.

3. What does "beyond accuracy" mean in the context of this unit?

Accuracy remains one useful number, just not a complete picture on its own — especially with class imbalance.

4. Fill in the blank: a change in the true relationship between input and correct output, often invisible until new labels arrive, is ___.

Inputs can look statistically ordinary while this kind of drift is already underway.

5. What does a retraining trigger do?

A defined trigger removes the decision from "whenever someone happens to notice" to a set, automatic threshold.

6. The precision/recall tradeoff. Answer both parts:

(a) A model that predicts "positive" more freely tends to see...

(b) This tradeoff means "beyond accuracy" does NOT imply...

Predicting positive more often catches more real cases but also raises more false alarms — there's no universally "correct" metric.

7. Confusion matrix vocabulary. Answer both parts:

(a) A true positive means the model predicted positive and...

(b) A true negative means the model predicted negative and...

"True" outcomes mean the prediction matched reality; "false" outcomes mean it didn't.

8. Detecting a lazy classifier. Answer both parts:

(a) A model that always predicts the majority class on a heavily imbalanced dataset will show...

(b) Its recall for the minority class will be approximately...

High accuracy paired with near-zero recall for the class that matters is the tell-tale sign of this failure.

9. Detecting drift without labels. Answer both parts:

(a) Data drift can be detected by...

(b) A shifting prediction distribution, even with familiar-looking inputs, can be an early proxy signal for...

Input statistics alone reveal data drift; a shifting output distribution can hint at concept drift before labels confirm it.

10. Why monitoring is described as the discipline this course closes on. Answer both parts:

(a) A trained model's weights represent...

(b) Monitoring exists specifically to address...

Deployment isn't the finish line — it's where a static model meets a moving target, and monitoring is built around exactly that gap.
