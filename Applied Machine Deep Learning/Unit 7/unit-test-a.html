1. What question does recall answer?

recall = tp / (tp + fn) — it measures how much of the real positive class got caught.

2. Fill in the blank: a table counting true positives, false positives, false negatives, and true negatives is a ___.

Every metric in this unit is derived from these four counts.

3. Why can a model that always predicts the majority class score very high accuracy on an imbalanced dataset, despite being useless?

A dataset that's 99% one class rewards always guessing that class with 99% accuracy, regardless of actual skill.

4. Fill in the blank: a change in the distribution of input features, detectable without new labels, is called ___.

Comparing live input statistics against training-time statistics is enough to detect this, with no labels needed.

5. Why can't Lesson 19's evaluation metrics simply be recomputed continuously once a model is deployed?

The absence of continuously arriving ground truth is exactly why monitoring relies on proxies instead.

6. Choosing which metric to optimize for a task. Answer both parts:

(a) A spam filter, where a false positive (real email marked spam) is especially costly, is usually tuned to favor...

(b) A cancer-screening model, where a false negative (a missed real case) is especially costly, is usually tuned to favor...

The relative cost of a false positive versus a false negative should drive which metric a task prioritizes.

7. Reading confusion matrix counts. Answer both parts:

(a) A false negative means the model predicted...

(b) A false positive means the model predicted...

The two "false" outcomes are mirror images of each other, differing in which direction the model got it wrong.

8. A rare-disease model always predicts "healthy." Answer both parts:

(a) Its accuracy on a dataset that's 99% healthy patients would be approximately...

(b) Its recall for the actual disease cases would be approximately...

High accuracy and near-zero recall together are the classic signature of a lazy model on an imbalanced dataset.

9. Comparing the two kinds of drift. Answer both parts:

(a) A change in the true relationship between input and correct output, even when inputs look familiar, is...

(b) This kind of drift is harder to detect because...

Concept drift can hide behind statistically ordinary-looking inputs, unlike data drift.

10. Retraining triggers. Answer both parts:

(a) A retraining trigger is best described as...

(b) Choosing where to set that threshold generally involves weighing...

Retraining triggers formalize when "good enough" evidence of drift outweighs the cost of doing nothing.
