BFS & Shortest Paths in Unweighted Graphs

Lesson 12's level-order traversal generalizes directly — and starting a BFS from more than one node at once unlocks an entire class of "spreading" problems.

← Lesson 18 Lesson 20 → Contents Glossary →

Problem: a grid contains fresh oranges (1), rotten oranges (2), and empty cells (0). Every minute, every rotten orange rots any fresh orange directly adjacent to it. Return the number of minutes until no fresh orange remains, or -1 if some fresh orange can never be reached. This is exactly Lesson 12's level-order BFS, except the traversal starts from every rotten orange simultaneously, not from a single root.

The idea Push every initially rotten orange into the queue at once — this is a multi-source BFS. Then run the same level-by-level pattern from Lesson 12: process everything currently in the queue as "this minute," pushing newly-rotted neighbors as the next minute's work. The number of rounds run is exactly the number of minutes elapsed.
Python 
from collections import deque

def oranges_rotting(grid):
    rows, cols = len(grid), len(grid[0])
    queue = deque()
    fresh = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == 2:
                queue.append((r, c))       # every rotten orange starts in the queue
            elif grid[r][c] == 1:
                fresh += 1

    minutes = 0
    directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]
    while queue and fresh > 0:
        minutes += 1
        for _ in range(len(queue)):        # exactly one minute's worth of spreading
            r, c = queue.popleft()
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                    grid[nr][nc] = 2
                    fresh -= 1
                    queue.append((nr, nc))
    return minutes if fresh == 0 else -1
Java 
int orangesRotting(int[][] grid) {
    int rows = grid.length, cols = grid[0].length;
    Queue<int[]> queue = new LinkedList<>();
    int fresh = 0;
    for (int r = 0; r < rows; r++) {
        for (int c = 0; c < cols; c++) {
            if (grid[r][c] == 2) queue.add(new int[] { r, c });   // every rotten orange starts in the queue
            else if (grid[r][c] == 1) fresh++;
        }
    }

    int minutes = 0;
    int[][] directions = { {1, 0}, {-1, 0}, {0, 1}, {0, -1} };
    while (!queue.isEmpty() && fresh > 0) {
        minutes++;
        int levelSize = queue.size();
        for (int i = 0; i < levelSize; i++) {   // exactly one minute's worth of spreading
            int[] cell = queue.poll();
            for (int[] d : directions) {
                int nr = cell[0] + d[0], nc = cell[1] + d[1];
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && grid[nr][nc] == 1) {
                    grid[nr][nc] = 2;
                    fresh--;
                    queue.add(new int[] { nr, nc });
                }
            }
        }
    }
    return fresh == 0 ? minutes : -1;
}
JavaScript 
function orangesRotting(grid) {
  const rows = grid.length, cols = grid[0].length;
  const queue = [];
  let fresh = 0;
  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      if (grid[r][c] === 2) queue.push([r, c]);   // every rotten orange starts in the queue
      else if (grid[r][c] === 1) fresh++;
    }
  }

  let minutes = 0;
  const directions = [[1, 0], [-1, 0], [0, 1], [0, -1]];
  while (queue.length > 0 && fresh > 0) {
    minutes++;
    const levelSize = queue.length;
    for (let i = 0; i < levelSize; i++) {   // exactly one minute's worth of spreading
      const [r, c] = queue.shift();
      for (const [dr, dc] of directions) {
        const nr = r + dr, nc = c + dc;
        if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && grid[nr][nc] === 1) {
          grid[nr][nc] = 2;
          fresh--;
          queue.push([nr, nc]);
        }
      }
    }
  }
  return fresh === 0 ? minutes : -1;
}
C++ 
int orangesRotting(std::vector<std::vector<int>>& grid) {
    int rows = grid.size(), cols = grid[0].size();
    std::queue<std::pair<int,int>> q;
    int fresh = 0;
    for (int r = 0; r < rows; r++)
        for (int c = 0; c < cols; c++) {
            if (grid[r][c] == 2) q.push({r, c});   // every rotten orange starts in the queue
            else if (grid[r][c] == 1) fresh++;
        }

    int minutes = 0;
    std::vector<std::pair<int,int>> directions = {{1,0},{-1,0},{0,1},{0,-1}};
    while (!q.empty() && fresh > 0) {
        minutes++;
        int levelSize = q.size();
        for (int i = 0; i < levelSize; i++) {   // exactly one minute's worth of spreading
            auto [r, c] = q.front(); q.pop();
            for (auto [dr, dc] : directions) {
                int nr = r + dr, nc = c + dc;
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && grid[nr][nc] == 1) {
                    grid[nr][nc] = 2;
                    fresh--;
                    q.push({nr, nc});
                }
            }
        }
    }
    return fresh == 0 ? minutes : -1;
}

Every cell is enqueued and processed at most once, so this is O(rows · cols) time and space, same as Lesson 18's DFS. The one new idea is seeding the queue with many starting points instead of one — everything else, including the levelSize trick that separates one round from the next, is identical to Lesson 12.

Why it matters here Because BFS explores in strict order of distance from its source (or sources), it's the standard algorithm for shortest paths whenever every edge costs the same — one step, one minute, one move. Multi-source BFS is the trick specifically worth remembering: any "starting from all of these points, how long until X spreads everywhere" problem is a queue seeded with more than one node, not a fundamentally different algorithm.

Seeding the queue with multiple starting nodes at once is the entire idea — everything else is standard BFS.

2. Why is BFS the right choice here instead of DFS?

DFS would plunge down one path first, losing the round-by-round structure that "minutes" requires.
