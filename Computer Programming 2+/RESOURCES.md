# Computer Programming 2+ Resources

## Knowledge

- [NeetCode Roadmap](https://neetcode.io/roadmap)
  A curated, pattern-first sequence of interview problems (the basis for the "Blind 75" and "NeetCode 150" lists), organized by topic in almost exactly the order this course follows: arrays/hashing, two pointers, sliding window, stacks, binary search, linked lists, trees, heaps, backtracking, graphs, dynamic programming, greedy, intervals, math, bit manipulation. Use for: confirming this course's unit order matches the pattern frequency real interviews test, and for extra practice problems per pattern beyond the ones cited in each lesson.
- [Algorithms for Competitive Programming (cp-algorithms.com)](https://cp-algorithms.com/index.html)
  A community-maintained, competitive-programming-focused reference with rigorous, concise writeups (many contributed by top competitive programmers) and clean C++ implementations. Use for: the competitive-programming framing of topics this course covers (graphs, DSU/union-find, dynamic programming) — cited directly in units where the "contest" motivation is strongest.
- [USACO Guide — Introduction to Competitive Programming](https://usaco.guide/general/intro-cp)
  A free, curated competitive-programming curriculum aimed at contest prep, with a companion resources page. Use for: the "constraints tell you the required complexity" reflex (Unit 1) and as a signposted next step for topics this course deliberately places out of scope (segment trees, advanced graph algorithms) — see its [Resources: Competitive Programming](https://usaco.guide/general/resources-cp) page.
- [VisuAlgo](https://visualgo.net/en)
  Interactive visualizations of data structures and algorithms (trees, heaps, graph traversal, sorting) built for teaching. Use for: any lesson where seeing the structure animate — a heap sift-down, a BFS frontier expanding, a DFS backtracking — would make the mechanism click faster than static code alone.
- [Big-O Cheat Sheet](https://www.bigocheatsheet.com/)
  A single-page reference of time/space complexity for common data structure operations and sorting algorithms. Use for: Unit 1's complexity-in-practice lesson, and as a running cross-check whenever a lesson claims a specific Big-O bound.
- [LeetCode Explore — Patterns](https://leetcode.com/explore/)
  LeetCode's own official pattern-based learning tracks, directly on the platform this course is preparing students for. Use for: the exact problems cited in each lesson's "Practice on LeetCode" section — always confirm current problem numbers/names against the live site rather than memory, since LeetCode occasionally renumbers or retires problems.

## Wisdom (Communities)

- [r/leetcode](https://www.reddit.com/r/leetcode/)
  Very active subreddit for LeetCode-specific problem discussion, interview debriefs, and pattern explanations. Use for: getting unstuck on a specific cited problem, or reading real interview experience reports tied to a pattern just learned.
- [Codeforces](https://codeforces.com/)
  The largest active competitive-programming contest platform and community, with frequent rated contests at every skill level and a very active discussion forum. Use for: the "competitive programming / contests" half of this course's dual motivation — a natural next step once a unit's pattern is solid, to test it under real time pressure.
- [r/cscareerquestions](https://www.reddit.com/r/cscareerquestions/)
  Large community focused on technical interview experiences and career prep. Use for: the "technical interview" half of this course's dual motivation — real accounts of what interviews at specific companies actually test.

## Gaps
- No community resource specific to *this course's* exact four-language format (Python/Java/JavaScript/C++ in parallel) exists externally — LeetCode itself supports all four languages per-problem, which is what makes the citation convention workable, but pattern write-ups elsewhere are usually single-language (often Python or Java). Lessons should keep translating patterns into all four rather than relying on an external multi-language source.
