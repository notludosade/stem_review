Backtracking on Grids: Word Search

Closing this unit where it started: backtracking is still DFS with a visited check, now searching for one specific path instead of counting every region.

← Lesson 24 Contents Glossary →

Problem: given a grid of letters and a target word, determine whether the word can be traced by moving to horizontally or vertically adjacent cells, using each cell at most once. This is Lesson 18's island-counting DFS again, but instead of exploring everywhere reachable, the recursion follows one specific target — the next required letter — and gives up the instant a cell doesn't match.

The idea Try starting the search from every cell. At each step, check that the current cell matches the next required letter and hasn't been used yet in this attempt; if not, that branch fails immediately. If it matches, mark the cell visited (choose), recurse into all four neighbors looking for the next letter (explore), then unmark it (unchoose) — because a cell used on one attempted path might be needed again on a different one, unlike the sunk land cells in Lesson 18 that never needed to be restored.
Python 
def exist(board, word):
    rows, cols = len(board), len(board[0])

    def backtrack(r, c, i):
        if i == len(word):
            return True                 # every letter matched
        if (r < 0 or r >= rows or c < 0 or c >= cols
                or board[r][c] != word[i]):
            return False                 # out of bounds or wrong letter: fail this branch

        temp = board[r][c]
        board[r][c] = '#'                # choose: mark visited for this attempt
        found = (backtrack(r + 1, c, i + 1) or backtrack(r - 1, c, i + 1) or
                 backtrack(r, c + 1, i + 1) or backtrack(r, c - 1, i + 1))
        board[r][c] = temp               # unchoose: restore for other attempts
        return found

    for r in range(rows):
        for c in range(cols):
            if backtrack(r, c, 0):
                return True
    return False

boolean exist(char[][] board, String word) {
    int rows = board.length, cols = board[0].length;
    for (int r = 0; r < rows; r++) {
        for (int c = 0; c < cols; c++) {
            if (backtrack(board, word, r, c, 0)) return true;
        }
    }
    return false;
}

boolean backtrack(char[][] board, String word, int r, int c, int i) {
    if (i == word.length()) return true;             // every letter matched
    if (r < 0 || r >= board.length || c < 0 || c >= board[0].length
            || board[r][c] != word.charAt(i)) return false;   // out of bounds or wrong letter: fail

    char temp = board[r][c];
    board[r][c] = '#';                 // choose: mark visited for this attempt
    boolean found = backtrack(board, word, r + 1, c, i + 1)
                 || backtrack(board, word, r - 1, c, i + 1)
                 || backtrack(board, word, r, c + 1, i + 1)
                 || backtrack(board, word, r, c - 1, i + 1);
    board[r][c] = temp;                // unchoose: restore for other attempts
    return found;
}

function exist(board, word) {
  const rows = board.length, cols = board[0].length;

  function backtrack(r, c, i) {
    if (i === word.length) return true;               // every letter matched
    if (r < 0 || r >= rows || c < 0 || c >= cols || board[r][c] !== word[i]) {
      return false;                                     // out of bounds or wrong letter: fail
    }

    const temp = board[r][c];
    board[r][c] = '#';                 // choose: mark visited for this attempt
    const found = backtrack(r + 1, c, i + 1) || backtrack(r - 1, c, i + 1) ||
                  backtrack(r, c + 1, i + 1) || backtrack(r, c - 1, i + 1);
    board[r][c] = temp;                // unchoose: restore for other attempts
    return found;
  }

  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      if (backtrack(r, c, 0)) return true;
    }
  }
  return false;
}

bool backtrack(std::vector<std::vector<char>>& board, const std::string& word, int r, int c, int i) {
    if (i == (int)word.size()) return true;             // every letter matched
    int rows = board.size(), cols = board[0].size();
    if (r < 0 || r >= rows || c < 0 || c >= cols || board[r][c] != word[i]) {
        return false;                                     // out of bounds or wrong letter: fail
    }

    char temp = board[r][c];
    board[r][c] = '#';                 // choose: mark visited for this attempt
    bool found = backtrack(board, word, r + 1, c, i + 1) ||
                 backtrack(board, word, r - 1, c, i + 1) ||
                 backtrack(board, word, r, c + 1, i + 1) ||
                 backtrack(board, word, r, c - 1, i + 1);
    board[r][c] = temp;                // unchoose: restore for other attempts
    return found;
}

bool exist(std::vector<std::vector<char>>& board, std::string word) {
    for (int r = 0; r < (int)board.size(); r++) {
        for (int c = 0; c < (int)board[0].size(); c++) {

    }
    return false;
}

Worst case, this explores up to 4^L paths from each of the grid's rows·cols starting cells, where L is the word's length — exponential, but bounded tightly by L in practice since a wrong letter prunes a branch immediately. The temporary '#' marker plays the same role as Lesson 18's sunk land cells, except it must be restored afterward, since a cell ruled out on one starting attempt may still be perfectly valid on the next.

Why it matters here This closes the unit on the same note it opened with in Lesson 18: backtracking is DFS with a visited marker, plus the choose-explore-unchoose discipline from Lesson 23 to make that marker temporary rather than permanent. Grid backtracking (word search, N-Queens, Sudoku solvers) always follows this shape — mark a cell as used, recurse into its neighbors, then release it, so the same board can be reused across every attempted path.

Check your recall

1. Why must a visited cell be un-marked after backtracking, unlike Lesson 18's sunk land cells?

Lesson 18 counted every reachable region once; Word Search searches for one specific path per attempt, so failed attempts must not affect later ones.

2. What causes a branch of this search to fail immediately?

Any one of these conditions means this path cannot possibly complete the word, so recursion stops there.

3. What does the index i track during the recursion?

Reaching i equal to the word's length means every letter has already been matched in order.

4. Fill in the blank: restoring a cell's original letter after exploring its neighbors is the ___ step from Lesson 23's template.

Without this step, a cell ruled out early would stay unusable for every later attempt too.

5. Fill in the blank: in the worst case, this search's runtime is ___ in the word's length, though pruning keeps it fast in practice.

Up to 4 directions are tried at each of the word's L letters, giving roughly 4^L work per starting cell.
