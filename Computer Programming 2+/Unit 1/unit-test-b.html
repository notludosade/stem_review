1. With n = 100,000 numbers, a brute-force Two Sum solution using two nested loops needs roughly how many comparisons in the worst case?

n² comparisons at n = 100,000 is on the order of 10 billion — exactly the scale the lesson uses to motivate optimizing away the nested loop.

2. Which statement best describes the trade-off the hash-map Two Sum solution makes compared to brute force?

The same trade as brute force, viewed from the other direction: memory spent to buy back time.

3. Fill in the blank: naming this precisely — the specific repeated work a slow solution does that a faster one removes — is what points toward the right structure to fix it. This repeated, avoidable work is called the ___.

Identifying the bottleneck is what points toward which optimization pattern actually applies.

4. A function contains one loop of n iterations nested inside another loop of n iterations. What is the resulting time complexity?

A loop inside another loop, each of size n, costs O(n) × O(n) = O(n²) — the "nested loops multiply" half of the rule.

5. Fill in the blank: a dynamic array occasionally pays O(n) to resize and copy, but this cost is rare enough that averaged over many appends, each append still works out to O(1). This averaging technique is called ___ analysis.

Amortized analysis is why dynamic arrays are treated as constant-time in practice, despite occasional expensive resizes.

6. Trace the hash-map Two Sum algorithm on nums = [5, 1, 4] with target = 5, walking left to right. Answer both parts:

(a) By the time the algorithm processes index 2 (the number 4), what does the seen map contain, and does a match occur at that step?

(b) Fill in the blank: the value looked up at each step — target minus the current number — is called the ___.

(a) After indices 0 and 1, seen holds {5: 0, 1: 1}; at index 2, complement = 5 − 4 = 1, which is already stored, so the match [1, 2] is returned. (b) "Complement" is the general term for that lookup value.

7. Consider a recursive function that computes n! by calling itself with n − 1 until it reaches 0, doing O(1) extra work per call besides the recursive call. Answer both parts:

(a) What is this function's space complexity, and why?

(b) Fill in the blank: converting this recursive function into an equivalent loop keeps its time complexity at O(n) but drops its space complexity to O(___).

(a) Exactly like sum_to(n), each pending call occupies stack space until its return, giving O(n) regardless of how little work each call does besides recursing. (b) A loop needs only a running total, not a growing call stack, so space drops to O(1).

8. Two contest problems each state a different constraint on n. Answer both parts:

(a) Problem X states n ≤ 18. What does this most strongly suggest about the intended solution?

(b) Problem Y instead states n ≤ 10⁵. What does this most strongly suggest?

(a) n this small is a common deliberate signal that an exponential brute force is fine. (b) n up to 10⁵ typically rules out anything quadratic, pointing toward linear or linearithmic solutions instead.

9. Answer both parts about the five-step framework's order (Clarify, Brute force, Find the bottleneck, Pattern-match, Verify):

(a) Which step comes immediately before "Verify"?

(b) Fill in the blank: the third step — naming the specific repeated or wasted work the brute force does — is called finding the ___.

(a) The order runs Clarify → Brute force → Find the bottleneck → Pattern-match → Verify, so pattern-match directly precedes verify. (b) This is the same "bottleneck" concept introduced in Lesson 1, now named explicitly as framework step 3.

10. Answer both parts about why steps 2 and 5 matter even outside an interview:

(a) In a timed contest, where only the final submission is graded, what is the purpose of step 5 (verify)?

(b) Fill in the blank: stating the naive, obviously-too-slow approach out loud in step 2 is still valuable because it proves the problem is understood and gives a correctness ___ to optimize from.

(a) Without an interviewer present, tracing against edge cases is the only safety net before submitting. (b) "Baseline" is what the brute force establishes before anything is optimized against it.
