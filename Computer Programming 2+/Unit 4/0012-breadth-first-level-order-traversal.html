Breadth-First / Level-Order Traversal

Depth-first plunges down one branch at a time. Breadth-first sweeps across each depth before going deeper — and that needs a queue, not recursion.

← Lesson 11 Lesson 13 → Contents Glossary →

Problem: given a binary tree, return its node values grouped level by level — all values at depth 0, then all at depth 1, and so on. Depth-first recursion naturally tracks a path from root to one deep node; it has no built-in notion of "everyone at the same depth." Breadth-first search (BFS) does, by processing nodes in the exact order they were discovered — which is what a queue (FIFO, from CP2's Unit 3) is for.

The idea Push the root into a queue. Repeatedly: record how many nodes are currently in the queue (that's exactly one level's worth), pop and process each of them, and push their children as you go — those children become the next level.
Python 
from collections import deque

def level_order(root):
    if root is None:
        return []
    result = []
    queue = deque([root])
    while queue:
        level_size = len(queue)
        level = []
        for _ in range(level_size):
            node = queue.popleft()
            level.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        result.append(level)
    return result
Java 
List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.add(root);
    while (!queue.isEmpty()) {
        int levelSize = queue.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < levelSize; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.add(node.left);
            if (node.right != null) queue.add(node.right);
        }
        result.add(level);
    }
    return result;
}
JavaScript 
function levelOrder(root) {
  if (root === null) return [];
  const result = [];
  const queue = [root];
  while (queue.length > 0) {
    const levelSize = queue.length;
    const level = [];
    for (let i = 0; i < levelSize; i++) {
      const node = queue.shift();
      level.push(node.val);
      if (node.left) queue.push(node.left);
      if (node.right) queue.push(node.right);
    }
    result.push(level);
  }
  return result;
}
C++ 
std::vector<std::vector<int>> levelOrder(TreeNode* root) {
    std::vector<std::vector<int>> result;
    if (root == nullptr) return result;
    std::queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        int levelSize = q.size();
        std::vector<int> level;
        for (int i = 0; i < levelSize; i++) {
            TreeNode* node = q.front();
            q.pop();
            level.push_back(node->val);
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        result.push_back(level);
    }
    return result;
}

Every node is enqueued once and dequeued once, so this is O(n) time and, in the worst case, O(n) space too — a very wide tree's last level can hold close to half its nodes in the queue at once. Capturing level_size before the inner loop starts is the entire trick: it draws a hard line between "this level" and "the next level" even though both live in the same queue.

Why it matters here BFS is the natural choice whenever a problem cares about depth, distance, or "shortest path" in an unweighted structure — level order gives you depth for free, since every node popped in round k is exactly k steps from the root. Unit 6 reuses this exact queue-based shape for graphs, where it becomes the standard algorithm for shortest paths when every edge costs the same.

Check your recall

1. What data structure does breadth-first traversal rely on that depth-first recursion doesn't need?

Processing nodes in discovery order, level by level, is exactly what a FIFO queue provides.

2. Why does the algorithm record the queue's size before starting the inner loop each round?

Without capturing that count first, newly-pushed children would get processed as part of the current level by mistake.

3. What is the worst-case space complexity of level-order traversal, and when does it occur?

A tree's widest level can approach n/2 nodes, all sitting in the queue simultaneously.

4. Fill in the blank: level-order traversal processes nodes in the order they were discovered, which is exactly what a ___ provides.

First in, first out is exactly the order breadth-first traversal needs.

5. Fill in the blank: every node popped during round k of level-order traversal is exactly k steps of ___ from the root.

This is exactly why BFS gives distance/depth information for free.
