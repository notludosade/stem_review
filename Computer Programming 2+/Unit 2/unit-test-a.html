1. Fill in the blank: when a linked list's tail points back into an earlier node instead of ending in null, causing a naive traversal to never terminate, the list contains a ___.

A cycle is exactly what makes a naive traversal loop forever, since it never reaches null.

2. Compared to storing every visited node in a hash set to detect a cycle, what does Floyd's tortoise-and-hare algorithm achieve?

Two pointer variables cost O(1) space, versus storing every visited node in a hash set, which costs O(n).

3. Given an array of n elements and a fixed window size k, brute-force recomputing the sum of every window from scratch costs how much?

n possible starting positions, each requiring k additions, multiply to O(n·k).

4. In the longest-substring-without-repeats problem, what specifically triggers the window to shrink from the left?

A repeated character is exactly what violates the "no repeats" rule the window is maintaining.

5. What is the general recipe behind variable-size sliding window problems, regardless of the exact condition being enforced?

This expand/shrink/track shape generalizes across many different specific window conditions.

6. Answer both parts about opposite-direction two pointers:

(a) What single fact about an array must be true for the opposite-direction two-pointer Two Sum approach to work correctly?

(b) Fill in the blank: a string that reads the same forwards and backwards, checkable by walking two pointers inward from both ends, is a ___.

(a) Sortedness is what guarantees which direction to move a pointer when the current sum is too high or too low. (b) "Palindrome" — the other classic use of this same pointer shape.

7. Trace opposite-direction two pointers on the sorted array [1, 3, 5, 8, 11] with target = 13. Answer both parts:

(a) After the first comparison (1 + 11 = 12), which pointer moves, and in which direction?

(b) Fill in the blank: once the correct pair (5 and 8, at indices 2 and 3) is found, the algorithm has used only O(___) extra space beyond the input array itself.

(a) 12 is less than the target 13, and on sorted data the only way to increase the sum is moving left rightward. (b) Just two pointer variables are used as extra memory — O(1) space, unlike the hash map's O(n).

8. Answer both parts about why Floyd's algorithm terminates:

(a) Once both the slow and fast pointers are inside a cycle, why must they eventually meet?

(b) Fill in the blank: Floyd's algorithm is nicknamed the "___ and hare" algorithm, after its slow and fast pointers.

(a) A gap that shrinks by exactly one integer step each iteration must eventually reach zero. (b) The slow pointer is the "tortoise," moving one step at a time.

9. Answer both parts about sliding a fixed-size window forward by one position:

(a) What two operations does sliding the window forward by one position require?

(b) Fill in the blank: this incremental update drops the total cost of scanning every window from O(n·k) down to O(___).

(a) Only the outgoing and incoming elements actually change between adjacent windows — everything else is shared. (b) Each element is added exactly once and subtracted exactly once overall, giving O(n) total regardless of k.

10. Answer both parts about the true complexity of the variable-size sliding window from Lesson 7:

(a) The code has a while loop nested inside a for loop, which looks like O(n²). What is the actual time complexity, and why?

(b) Fill in the blank: because its length isn't fixed and adjusts based on a rule, this lesson's window is called a ___-size sliding window.

(a) left makes at most n total moves across the whole run, not per outer-loop iteration — the key exception to "nested loops multiply." (b) "Variable," in contrast with Lesson 6's fixed-size window.
