1. Fill in the blank: a naive traversal of a linked list never terminates when the list contains a ___ — its tail pointing back into an earlier node instead of ending in null.

Without a cycle, every traversal eventually reaches null and terminates normally.

2. The brute-force way to detect a cycle stores every visited node in a hash set. What does this cost that Floyd's algorithm avoids?

Storing every visited node costs O(n) space; Floyd's algorithm needs only two pointer variables, O(1).

3. Why is brute-force recomputing every window's sum from scratch considered wasteful, once you look for the bottleneck?

Sliding by one position changes only which single element enters and leaves — everything else is repeated, wasted work in the brute-force version.

4. Which of these correctly describes when the window shrinks in the longest-substring-without-repeats algorithm?

Shrinking only happens in response to a repeated character breaking the "no repeats" rule.

5. A new problem asks for the shortest substring containing at least one vowel and one consonant. Which recipe from this unit applies directly?

This is the same expand/shrink/track shape from the variable-size window lesson, applied to a different specific condition.

6. Answer both parts about what opposite-direction two pointers require and where else the shape appears:

(a) Why can't opposite-direction two pointers safely be used on an array that is not sorted?

(b) Fill in the blank: checking whether a string reads the same forwards and backwards by walking pointers inward from both ends is checking whether it's a ___.

(a) Without a guaranteed order, there's no way to know which pointer to move to fix a sum that's too high or too low. (b) "Palindrome" — the symmetric-structure use of this same pattern.

7. Trace opposite-direction two pointers on the sorted array [2, 4, 6, 9, 12] with target = 15. Answer both parts:

(a) After the second comparison (4 + 12 = 16), which pointer moves, and in which direction?

(b) Fill in the blank: the pair that finally matches is 6 and 9, at indices 2 and 3 — found using no hash map and only O(___) extra space.

(a) 16 exceeds the target of 15, and on sorted data the only way to reduce the sum is moving right leftward. (b) Just two pointer variables — O(1) space, unlike the hash map's O(n).

8. Answer both parts about what happens when there is no cycle at all:

(a) If a linked list has no cycle, what happens to the fast pointer as Floyd's algorithm runs?

(b) Fill in the blank: the pointer that moves one node at a time in Floyd's algorithm is nicknamed the "___," while the pointer moving two nodes at a time is the hare.

(a) Moving twice as fast, the fast pointer simply runs out of list first when there's no cycle to trap it in. (b) "Tortoise" is the slow pointer's nickname.

9. Answer both parts about why the fixed-size sliding window technique is fast:

(a) Why do adjacent windows of size k share most of their elements?

(b) Fill in the blank: subtracting the outgoing element and adding the incoming element, instead of recomputing the sum from scratch, is called an ___ update.

(a) k − 1 elements are shared between any two windows one position apart. (b) "Incremental" is the term for updating a running total by adjusting only for what changed.

10. Answer both parts about why the nested-loop appearance of variable-size sliding window is misleading:

(a) An interviewer says this code "looks O(n²) because of the nested loops." What is the correct rebuttal?

(b) Fill in the blank: unlike a fixed-size window, this one grows and shrinks based on a rule — making it a ___-size sliding window.

(a) Both pointers make at most n total moves combined across the entire run — the key exception to "nested loops multiply." (b) "Variable," since there's no fixed k here.
