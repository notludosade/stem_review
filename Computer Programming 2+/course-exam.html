1. A brute-force solution to a pairfinding problem checks every pair with two nested loops over n elements. What is its worst-case time complexity?

Two nested loops over n elements gives n × n comparisons in the worst case — O(n²).

2. Fill in the blank: the single slowest step that dominates an algorithm's overall running time is called its ___.

Finding the bottleneck — the step that costs the most — is the second step of the five-step framework, right after brute force.

3. Why does the opposite-direction two-pointer pattern work on a sorted array to find a target sum, without needing nested loops?

Sortedness is what makes each pointer move meaningful — the sum only moves in one predictable direction as either pointer shifts.

4. Fill in the blank: when a linked list's tail points back into an earlier node instead of ending in null, the list contains a ___.

A cycle is exactly what makes a naive traversal loop forever, since it never reaches null.

5. In a rotated sorted array like [4, 5, 6, 7, 0, 1, 2], what guarantee makes binary search still applicable even though the whole array isn't sorted?

No matter where the midpoint falls, one of the two halves it creates is guaranteed to be fully sorted, which is enough to decide which side to search next.

6. Fill in the blank: a condition that is false for all values below some threshold and true at or above it (or vice versa) is called ___.

Monotonicity is exactly what lets binary search be applied over an abstract answer space, not just a sorted array.

7. Pre-order, in-order, and post-order traversal all visit the exact same set of nodes in a binary tree. What actually distinguishes them from one another?

All three visit the same nodes — the only difference is where the "visit the current node" step falls relative to the recursive left/right calls.

8. Fill in the blank: level-order traversal processes nodes using a ___, since that structure preserves the order in which nodes were discovered.

A queue's first-in-first-out order is exactly what going level by level requires — recursion alone can't produce that order.

9. What is the one ordering rule a min-heap actually enforces?

A heap only guarantees the parent-child ordering locally — it is not fully sorted the way a BST's in-order traversal is.

10. Fill in the blank: a complete binary tree where every parent is smaller (min-heap) or larger (max-heap) than both of its children is called a ___.

A heap is defined entirely by that parent-child ordering rule, stored compactly as an array.

11. What is the key structural difference between a tree and a general graph?

A tree is really just a special case of a graph — one with no cycles and exactly one path between any two nodes.

12. Fill in the blank: mapping each node to the list of nodes it directly connects to is called an ___ list.

An adjacency list is the standard way to represent a graph's connections without wasting space on an n×n matrix.

13. What are the three steps of the backtracking template introduced for generating subsets and permutations?

The choose/explore/unchoose cycle is what lets backtracking try a path and then cleanly undo it to try the next one.

14. Fill in the blank: cutting off a branch of the search early, once it's known it cannot lead to a valid answer, is called ___.

Pruning is what keeps backtracking practical — without it, the search would explore every branch to its full depth regardless of whether it could possibly succeed.

15. What is the key difference between memoization and tabulation?

Both avoid recomputation of the same subproblem — memoization does it lazily on top of recursion, tabulation does it by filling a table in order.

16. Fill in the blank: a problem where the same smaller subproblem gets solved repeatedly across different branches of recursion has ___ subproblems, one of the two properties dynamic programming requires.

Overlapping subproblems (alongside optimal substructure) is exactly what makes caching results worthwhile in the first place.

17. Why does the interval-scheduling greedy algorithm sort intervals by end time rather than start time?

Ending earliest is what maximizes the room left over for future choices — the core exchange argument behind this greedy strategy.

18. Fill in the blank: the bitwise operator satisfying a ^ a = 0 and a ^ 0 = a, which lets paired values cancel out, is ___.

XOR's self-cancelling property is exactly what the Single Number trick relies on — every paired value cancels, leaving only the unpaired one.
