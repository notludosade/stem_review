1. What ordering rule does a max-heap enforce?

A max-heap is a min-heap with the comparison flipped: every parent dominates its children by being larger, not smaller.

2. Fill in the blank: unlike a BST, a ___ enforces an ordering rule only between a node and its direct children — not across an entire subtree.

This looser rule is exactly what makes a heap's insert and remove-min/max operations cheap.

3. Why is heapify (building a heap from an existing unsorted collection) O(n) rather than O(n log n) like a full sort?

Since most nodes are near the bottom of the tree, the total work across all of them sums to O(n), not O(n log n).

4. A heap capped at size k=3 is used to find the 3rd largest value in an array. After processing every element, what does the heap's minimum represent?

Once the heap holds exactly the k largest values seen, its minimum is precisely the kth largest overall.

5. Fill in the blank: unlike the heap approach, ___ cannot process the array as a stream and has a worse worst case, though it averages O(n) time.

This partitioning approach trades stream-friendliness and worst-case guarantees for a better average case.

6. Trace the bounded min-heap (capped at size k=3) for nums = [7, 10, 4, 3, 20, 15] as each element is pushed left to right. Answer both parts:

(a) After pushing 3 (the fourth element), the heap exceeds size 3 and must pop. What gets popped, and what does the heap contain afterward?

(b) Fill in the blank: continuing this process through the rest of the array, the final heap holds {10, 15, 20}, so the 3rd largest element is ___.

(a) Pushing 3 grows the heap to {3,4,7,10}, past the cap of 3, so the smallest value (3) is popped, leaving {4,7,10}. (b) Continuing to push 20 and 15 (each time popping the current smallest once the cap is exceeded) leaves the heap holding exactly the three largest values seen, {10,15,20}; its minimum, 10, is the 3rd largest element overall.

7. A problem has n total elements but only u unique values, and asks for the k most frequent. Answer both parts:

(a) Why is the combined hash map + bounded heap approach never worse than O(n log k)?

(b) Fill in the blank: a completely different approach reaches O(n) overall by exploiting the fact that frequency can never exceed the array's length, using ___ sort.

(a) Since the number of unique values u is at most n, the heap term u log k can never push the total past O(n log k). (b) Bucket sort groups values into buckets indexed by frequency, avoiding the heap entirely for an O(n) total.

8. For nums = [4,4,4,5,5,6,6,6,6] with k=2, frequencies are 4→3, 5→2, 6→4. Pairs are pushed in that order into a heap capped at size 2, ordered by frequency. Answer both parts:

(a) What happens when the pair (frequency=4, value=6) is pushed?

(b) Fill in the blank: after processing every value, the heap holds the pairs for values 4 and 6, so the top 2 frequent elements are 4 and ___.

(a) Pushing (4,6) brings the heap to three entries, past the cap of 2, so the pair with the lowest frequency — (2,5) — is popped, correctly discarding the least frequent value. (b) What remains, (3,4) and (4,6), are exactly the two most frequent values, 4 and 6.

9. A heap is stored as a plain array, not linked nodes. Answer both parts:

(a) For a node at index i (i > 0), what index holds its parent?

(b) Fill in the blank: because a heap's structure is entirely encoded in array indices, no explicit ___ are needed to link a node to its children.

(a) Solving 2·parent+1=i (or 2·parent+2=i) for parent gives parent = floor((i−1)/2), the standard formula for a node's parent in this array representation. (b) No linked structure is needed — the tree relationships are fully implied by array position, avoiding the extra memory pointers would cost.

10. Answer both parts about heap defaults across this course's four languages:

(a) Which of these heap-related defaults is correctly matched to its language?

(b) Fill in the blank: implementing a small MinHeap class by hand in JavaScript, rather than relying on a language built-in, is considered the ___ practice in that language, not a workaround.

(a) Python's heapq only ever behaves as a min-heap, and C++'s priority_queue defaults to max-heap unless std::greater is supplied — opposite defaults that are easy to mix up. (b) Because JavaScript has no built-in heap at all, hand-writing one, as shown across Lessons 15–17, is the expected, standard approach — not an improvised workaround.
