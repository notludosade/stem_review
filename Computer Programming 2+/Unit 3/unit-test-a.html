1. In a rotated sorted array like [4, 5, 6, 7, 0, 1, 2], what guarantee makes binary search still applicable even though the whole array isn't sorted?

That guaranteed sorted half is exactly what lets the algorithm decide which side to search next.

2. Fill in the blank: an array that was sorted once and then had some prefix cut off and moved to the end is called a ___ sorted array.

This is the exact structure Lesson 8 is built around.

3. In the Koko Eating Bananas problem, why can binary search be applied directly over candidate eating speeds even though there's no array of speeds to search?

Monotonicity, not sortedness, is the actual property binary search depends on here.

4. Fill in the blank: a condition that is false for all values below some threshold and true at or above it (or vice versa) is called ___.

This is the real requirement binary search runs on, whether or not the search space is an array.

5. Why is running two binary searches to find the first and last index of a target better than one binary search plus scanning outward linearly?

If a target fills half the array, scanning outward from one match is effectively a full linear pass.

6. Trace the rotated-array binary search on nums = [4, 5, 6, 7, 0, 1, 2] with target = 0. Answer both parts:

(a) At the first step, left=0, right=6, mid=3 (nums[mid]=7). Which half is sorted, and which half does the search continue into?

(b) Fill in the blank: this trace ultimately finds target 0 at index ___.

(a) nums[left]=4 ≤ nums[mid]=7, so the left half [4,5,6,7] is the sorted one; since target 0 falls outside [4,7), the search moves right (left = mid+1 = 4). (b) The next step checks left=4, right=6, mid=5 (value 1): nums[4]=0 ≤ nums[5]=1, so [0,1] is sorted, and 0 falls inside that range, moving right=4; now left=right=4, mid=4 (value 0) — an exact match at index 4.

7. Trace the binary-search-on-the-answer algorithm for Koko Eating Bananas on piles = [3, 6, 7, 11], h = 8. Answer both parts:

(a) The search starts with left=1, right=11 (the largest pile). At the first midpoint, speed=6, how many hours does Koko need, and what does the algorithm do next?

(b) Fill in the blank: continuing this binary search finds the minimum working eating speed to be ___.

(a) At speed 6, the four piles need 1+1+2+2 = 6 hours total, within the 8-hour budget, so the search narrows toward slower speeds. (b) Continuing the search (narrowing between speeds 3, 5, and 4) converges on 4 as the minimum working speed — at speed 4 she needs exactly 1+2+2+3 = 8 hours, right at the limit; any slower speed exceeds it.

8. Trace the first-occurrence binary search on nums = [5, 7, 7, 7, 8, 8, 10] with target = 7. Answer both parts:

(a) At the first step, left=0, right=6, mid=3 (nums[mid]=7, a match). What does the algorithm do next?

(b) Fill in the blank: this trace ultimately finds the first occurrence of 7 at index ___.

(a) Finding a match doesn't stop a first-occurrence search — it records the index and narrows toward the left half, since an earlier match might still exist. (b) Searching left of index 3 (new right=2) finds another match at mid=1 (value 7), which is recorded and narrows further left (right=0); at left=0, right=0, mid=0 holds value 5 (less than target), so left advances past right and the loop ends, leaving index 1 as the first occurrence.

9. Across rotated arrays, answer-space search, and boundary search, answer both parts about what binary search actually depends on:

(a) What single property must hold about a search space — whether it's an array or an abstract range — for binary search to safely eliminate half the candidates at each step?

(b) Fill in the blank: this is why Unit 3 frames binary search as needing the ability to ___ half of the remaining possibilities at every step, not necessarily a sorted array specifically.

(a) Sortedness is just one common way to guarantee that a decidable elimination rule exists — rotated-array structure and monotonic conditions are two others covered this unit. (b) "Eliminate" is the exact verb Lesson 8 uses to generalize binary search beyond sorted arrays.

10. Answer both parts about the time complexity shared across this unit's binary search variants:

(a) Rotated-array search, binary search on the answer space, and first/last boundary search all share what complexity relative to the size of their search space (n, or the range of possible answers)?

(b) Fill in the blank: finding both the first and last occurrence of a target costs O(___ n) total — the same order as a single ordinary binary search.

(a) Every variation in this unit — sorted-half checks, monotonic conditions, or boundary narrowing — still throws away half the remaining candidates each step, keeping all three logarithmic. (b) Two independent O(log n) searches run one after another still total O(log n), not O(n).
