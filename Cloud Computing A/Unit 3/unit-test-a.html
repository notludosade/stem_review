1. Which storage model stores data as discrete files-plus-metadata in a flat namespace, accessed as whole units via an API?

Object storage's flat namespace and API-based whole-object access defines it against block and file storage.

2. Fill in the blank: storage presented as fixed-size blocks and attached as a virtual hard disk to a single VM at a time is called ___ storage.

Block storage's single-VM attachment and low-latency small reads/writes fit database workloads.

3. What distinguishes file storage from block storage?

Concurrent multi-machine access is file storage's defining advantage over single-attachment block storage.

4. A production database needs frequent, small, random, low-latency reads and writes. Which storage model fits best?

Block storage's low-latency small random I/O is exactly what a database's data files need.

5. What does "durability" measure?

Durability is about long-term data survival, not real-time reachability, speed, or price.

6. A service is available 99.9% of the time over a year. Answer both parts:

(a) Roughly how much downtime does this allow across the year?

(b) Does this availability figure say anything about whether the data could be permanently lost?

99.9% availability allows roughly 8.77 hours of downtime a year, and it says nothing about durability — the two are independent guarantees.

7. Fill in the blank: going from 99.99% to 99.999% availability typically demands much more ___ than going from 99% to 99.9%, for a much smaller absolute reduction in downtime.

Each additional 9 costs disproportionately more effort for a shrinking absolute benefit — a diminishing-returns curve.

8. What does moving data from a "hot" storage tier to a "cold" or "archive" tier change?

Tiers trade retrieval speed for cost without changing the underlying storage model or deleting anything.

9. Fill in the blank: an automated rule like "move any object untouched for 90 days to the archive tier" is called a ___ policy.

A lifecycle policy automates tier transitions instead of requiring manual tracking of every file's access pattern.

10. A team is deciding how to store a dataset. According to this unit's three-question framework, what should they determine first?

Access pattern narrows the storage model first; durability/availability needs and access frequency (tier) come after.
