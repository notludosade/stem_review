1. Even though a VPC's underlying physical network hardware is shared across many customers, what does the VPC make it behave like from the inside?

A VPC creates the experience of a private, isolated network on top of shared underlying hardware.

2. Fill in the blank: a subnet with a route to the internet through an internet gateway, meant to hold resources reachable from outside, is called a ___ subnet.

A public subnet's internet route is what makes resources in it reachable from outside the VPC.

3. In a typical three-tier web app, which subnet do the public-facing web servers sit in, and why?

Web servers need to be reachable from the internet, which is exactly what a public subnet's route provides.

4. Why do clients only ever talk to a load balancer's address, never directly to a specific backend server?

The load balancer's address abstracts away which specific server ends up handling any given request.

5. What are load balancer health checks?

Health checks run continuously and automatically, letting the load balancer react to failures in real time.

6. Comparing round robin and least connections routing when all servers are equally healthy and fast. Answer both parts:

(a) How does round robin choose the next server?

(b) How does least connections choose the next server?

Round robin rotates evenly regardless of load; least connections actively checks current load before routing each request.

7. Fill in the blank: a CDN's globally distributed caching servers, positioned physically close to users, are called ___.

Edge locations are what let a CDN serve users from nearby rather than from one distant origin server.

8. What is a cache hit?

A cache hit is served instantly from the edge, without needing to reach the origin server at all.

9. How does a CDN reduce load on the origin server, not just speed up requests for distant users?

Edge caching absorbs the bulk of requests, sparing the origin server from handling every single one.

10. Which type of content is generally the best fit for CDN edge caching?

Static, shared, infrequently-changing content is exactly what edge caching is built to serve well.
