1. What is a Virtual Private Cloud (VPC)?

A VPC is a software-defined isolated network, not a physical cable or a VM type.

2. Fill in the blank: a subnet with no route to the internet, meant to hold resources like a database that should only be reachable from inside the VPC, is called a ___ subnet.

A private subnet lacks an internet route, blocking outside access at the network level.

3. In a typical three-tier web app, why does the database sit in a private subnet instead of the same public subnet as the web servers?

Removing the internet route entirely blocks outside access at the network level, before any credential check even happens.

4. What is the core job of a load balancer?

Spreading requests across a fleet of servers is the load balancer's defining function.

5. What happens when a load balancer's health check detects that a server has failed?

Health checks let a load balancer route around a failed server automatically, keeping the rest of the fleet serving traffic.

6. A fleet has one server running noticeably slower than the other two. Answer both parts:

(a) How does round robin routing treat the slow server?

(b) How does least connections routing treat the slow server?

Round robin ignores current load and treats every server equally; least connections adapts, avoiding a server that's already backed up.

7. Fill in the blank: a globally distributed network of caching servers that store copies of content close to users is called a ___.

A CDN's whole purpose is caching content geographically close to the people requesting it.

8. What happens on a cache miss at a CDN edge location?

A cache miss triggers one fetch from the origin, after which the content is cached for fast future hits.

9. Besides making requests faster for distant users, what other benefit does a CDN provide to the origin server itself?

Cached content absorbs most requests at the edge, reducing the load that ever reaches the origin.

10. Why is a logged-in user's personalized dashboard a poor fit for CDN edge caching, unlike a static logo image?

Content that varies per user or must always be fresh generally has to route to the origin instead of being cached at the edge.
