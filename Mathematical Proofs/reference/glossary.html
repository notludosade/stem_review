Unit 1 — Logical Foundations

Statement (Proposition)

A sentence that is either true or false, but not both and not neither — the basic unit every proof technique in this course manipulates.

Conditional Statement (P → Q)

"If P, then Q" — true in every case except when P is true and Q is false. P is the hypothesis; Q is the conclusion.

Vacuous Truth

The case where P → Q is true purely because P is false, regardless of Q — a conditional with a false hypothesis is automatically true.

Biconditional (P ↔ Q)

True exactly when P and Q share the same truth value — usually proved as two separate conditionals, P → Q and Q → P.

Universal Quantifier (∀)

∀x ∈ D, P(x) is true exactly when P(x) holds for every single x in the domain D.

Existential Quantifier (∃)

∃x ∈ D, P(x) is true exactly when P(x) holds for at least one x in the domain D — one witness is enough.

Counterexample

A single element of the domain for which a universally quantified claim fails — enough on its own to disprove a ∀ statement.

Unit 2 — Direct Proof

Direct Proof

Assume the hypothesis P, reason forward through a chain of justified steps, and arrive at the conclusion Q — the default first strategy for any conditional claim.

Divides (a ∣ b)

a divides b if there exists an integer k such that b = ak — an existential definition, proved by exhibiting the witness k.

Witness

The specific object produced and checked to prove an existential claim — for example, the k in a ∣ b, or the pair (a, b) in a rational number.

Subset (A ⊆ B)

Every element of A is also an element of B — a universally quantified claim over the elements of A.

Set Equality by Double Inclusion

A = B means A ⊆ B and B ⊆ A — proved as two separate arbitrary-element arguments, one in each direction.

Arbitrary Element (Element-Chasing) Proof

To prove ∀x ∈ A, P(x), let x be a fixed but unspecified element of A, and prove P(x) using nothing about x beyond x ∈ A.

Unit 3 — Contradiction & Contrapositive

Contrapositive

¬Q → ¬P, the rearrangement of P → Q that is always logically equivalent to it — unlike the converse or inverse, which are not guaranteed equivalent.

Converse / Inverse

The converse of P → Q is Q → P; the inverse is ¬P → ¬Q. Neither is guaranteed equivalent to the original conditional.

Proof by Contrapositive

A direct proof of ¬Q → ¬P, using the single assumption ¬Q — proves P → Q by logical equivalence, without ever assuming P.

Proof by Contradiction

Assume the claim is false (for P → Q, assume P and ¬Q together), reason forward, and derive a statement together with its own negation.

Contradiction

A statement R reached alongside its negation ¬R — since no true set of assumptions can produce this, reaching one proves the original assumption false.

Unit 4 — Mathematical Induction

Principle of Mathematical Induction

If P(n₀) holds (base case) and P(k) → P(k+1) for every relevant k (inductive step), then P(n) holds for every n ≥ n₀.

Base Case

The confirmed-true starting instance, P(n₀), that the inductive step's chain of implications needs in order to begin firing — n₀ need not be 1.

Inductive Hypothesis

The assumption "P(k) is true," used inside the inductive step solely to prove P(k) → P(k+1) — never independently established on its own.

Strong Induction

Like ordinary induction, except the inductive step may assume every case P(n₀), …, P(k) — not just P(k) alone — before proving P(k+1).

Unit 5 — Proof Strategies in Practice

Proof by Cases

Partition the domain into exhaustive cases, and prove the claim separately within each one — the cases need not be mutually exclusive.

Exhaustive (Case Split)

A set of cases that covers every element of the domain, with none left out — the one requirement a valid case split must satisfy.

Existence Proof

Proves ∃x, P(x) by exhibiting one witness satisfying P and verifying it.

Uniqueness Proof

Proves at most one object satisfies P by assuming two objects, b and c, both satisfy P, then deriving b = c.

∃! (Exists Uniquely)

Asserts both existence and uniqueness together — proved as two separate arguments, not one combined argument.
