1. Why does a proof by cases require the cases to be exhaustive?

If some element fits no case, the proof has said nothing about it — exhaustiveness is what closes that gap.

2. A student splits a proof about integers n into "Case 1: n ≤ 0" and "Case 2: n ≥ 0." What, if anything, is wrong with this split?

n = 0 satisfies both n ≤ 0 and n ≥ 0 — covered twice, not zero times. Exhaustiveness, not mutual exclusivity, is what's actually required.

3. Fill in the blank: a case split that leaves no element of the domain out is called ___.

Exhaustive — the single property a case split needs for the resulting proof to be valid.

4. Which claim asserts existence but makes no uniqueness claim at all?

A plain existence claim like this one produces a witness (x = 2) and makes no claim, one way or the other, about whether other solutions exist.

5. Fill in the blank: before choosing a proof technique, the decision framework's first step is always to ___ the claim's quantifiers and exact condition.

You cannot choose a strategy for a claim you haven't fully parsed — unpacking always comes first.

6. Consider proving: for every integer n, n² + 3n is even. Answer both parts:

(a) In the case n is even (n = 2k), what does n² + 3n simplify to?

(b) Fill in the blank: in the case n is odd (n = 2k+1), n² + 3n = 4k² + 8k + 4 = 2(2k² + 4k + ___).

(a) (2k)² + 3(2k) = 4k² + 6k = 2k(2k+3), even. (b) (2k+1)² + 3(2k+1) = 4k² + 4k + 1 + 6k + 3 = 4k² + 10k + 4 — expanding carefully and factoring out 2 confirms evenness either way.

7. Consider proving: the equation 2x + 6 = 0 has a unique real solution. Answer both parts:

(a) What witness establishes existence?

(b) Fill in the blank: for uniqueness, assume 2b + 6 = 0 and 2c + 6 = 0. Subtracting gives 2b = 2c, so dividing by 2 gives b = ___.

(a) −3 is the standard witness. (b) 2b = 2c forces b = c, exactly the uniqueness argument's structure.

8. Claim: "There is no integer solution to 6x = 9." Answer both parts:

(a) Which technique fits best?

(b) Fill in the blank: this claim denies the existence of a solution, matching the framework's question: does it assert something is ___?

(a) 6x is always divisible by 3, but 9's role forces x = 3/2, not an integer — assuming an integer solution exists and reaching this impossibility is contradiction's job. (b) "Impossible" / "does not exist" claims route directly to contradiction.

9. Claim: "For every integer n ≥ 1, 1 + 2 + 4 + ⋯ + 2ⁿ⁻¹ = 2ⁿ − 1." Answer both parts:

(a) Which technique fits best?

(b) Fill in the blank: specifically weak induction, since the case for k+1 terms only ever needs the case for ___ terms.

(a) Adding one more power of 2 to the sum relates directly to the previous total, exactly what induction is built for. (b) Only the immediately preceding case, k, is ever needed — weak induction suffices.

10. Claim: "for every integer n, if n² is divisible by 5, then n is divisible by 5." Answer both parts:

(a) Which two techniques combine naturally to prove this?

(b) Fill in the blank: the contrapositive's hypothesis, "n not divisible by 5," splits into exactly ___ cases (remainders 1, 2, 3, or 4 when n is divided by 5).

(a) The awkward hypothesis "n² divisible by 5" is easier to handle via the contrapositive, and the contrapositive itself naturally splits by remainder. (b) Exactly four nonzero remainders mod 5 exist: 1, 2, 3, and 4.
