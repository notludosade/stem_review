Proof by Cases

When a single argument can't cover every possibility at once, split the domain into pieces small enough to handle separately — as long as no possibility is left out.

← Lesson 12 Lesson 14 → Contents Glossary →

Some claims resist a single uniform argument not because they're false, but because the reasoning genuinely differs depending on which kind of object you're looking at. Proof by cases handles this directly: split the possibilities into pieces, prove the claim separately within each piece, and cover every piece.

Definition — Proof by Cases To prove a statement holds for every x in a domain D, partition D into cases D₁, D₂, …, Dₙ such that every x in D falls into at least one Dᵢ (the cases are exhaustive). Prove the statement holds for x in each Dᵢ separately, using whatever argument fits that case. Since every x falls into some case, and the statement is proved in every case, the statement holds for all of D.
Why exhaustiveness is the one requirement that can't slip Proof by cases is only as strong as its weakest link — the argument that the cases actually cover everything. "x > 0" and "x < 0" looks exhaustive at a glance, but silently drops x = 0 entirely; a claim proved in both of those cases has said nothing whatsoever about zero. Before writing a single case's argument, state explicitly why every possible x lands in at least one case — usually because of a trichotomy (x > 0, x = 0, or x < 0) or a fact like "every integer is even or odd," never left implicit.
Worked example Claim: For every integer n, n² + n is even.
Proof. Every integer is either even or odd (this covers all cases — no integer is neither).
Case 1: n is even. Then n = 2k for some integer k. n² + n = 4k² + 2k = 2(2k² + k), which is even.
Case 2: n is odd. Then n = 2k + 1 for some integer k. n² + n = (2k+1)² + (2k+1) = (2k+1)(2k+2) = 2(2k+1)(k+1), which is even.
Both cases give an even result, and every integer is even or odd, so n² + n is even for every integer n. ∎
Second worked example Claim: For every real number x, |x|² = x².
Proof. Every real x satisfies x ≥ 0 or x < 0 (this covers all cases).
Case 1: x ≥ 0. Then |x| = x by definition of absolute value, so |x|² = x².
Case 2: x < 0. Then |x| = −x, so |x|² = (−x)² = x².
Both cases give |x|² = x², so the claim holds for every real x. ∎

Check your recall

No peeking back up — answer from memory first, then check.

1. What property must a set of cases have for a proof by cases to be valid?

If some element of the domain fits no case, the proof says nothing about that element — exhaustiveness is what makes the case split cover the whole claim.

2. A student splits a proof about real numbers x into "Case 1: x > 0" and "Case 2: x < 0." What is wrong with this split?

x > 0 and x < 0 together miss x = 0 entirely — a genuine gap, exactly the kind exhaustiveness is meant to rule out.

3. Fill in the blank: a set of cases that covers every element of the domain, with none left out, is called ___.

Exhaustive — the one property a case split must have for the resulting proof to cover the whole domain.

4. In the proof that n² + n is even, what does Case 1 (n even) conclude, and how?

Substituting n = 2k gives n² + n = 4k² + 2k = 2(2k² + k), matching the definition of even — and Case 2 (n odd) is still required, since Case 1 alone doesn't cover odd integers.

5. Fill in the blank: to make the case split "x > 0" and "x < 0" exhaustive over the reals, a third case is needed: x = ___.

Adding the missing case x = 0 is exactly what restores exhaustiveness to the split.
