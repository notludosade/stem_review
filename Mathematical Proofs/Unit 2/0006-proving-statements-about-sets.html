Proving Statements About Sets

Closing out Unit 2 by pointing direct proof at sets instead of integers — same structure, one new trick: picking an arbitrary element and arguing about it.

← Lesson 5 Lesson 7 → Contents Glossary →

A claim about sets — "A is a subset of B," "A equals B," "A is a subset of A ∪ B" — is, underneath the notation, always a quantified claim about elements. This lesson shows how to unpack that quantified claim (Lesson 2) and prove it directly (Lesson 4), with one new move: reasoning about a single, arbitrary, unspecified element.

Definition — Subset A ⊆ B means: ∀x, x ∈ A → x ∈ B. In words, every element of A is also an element of B. Note this is a universally quantified conditional — Lesson 2 and Lesson 4's machinery apply directly.
Definition — Set Equality by Double Inclusion A = B means: A ⊆ B and B ⊆ A. Two sets are equal exactly when each is a subset of the other — an element-level biconditional, matching Lesson 1's note that proving P ↔ Q usually means proving two conditionals separately.
Technique — The Arbitrary Element (Element-Chasing) Proof To prove ∀x ∈ A, P(x) — in particular, to prove A ⊆ B — let x be an arbitrary element of A: fixed for the duration of the argument, but with no property assumed beyond "x ∈ A." Prove P(x) (here, x ∈ B) using only that assumption. Because x was never assumed to have any special property, the argument works for every element of A at once, which is exactly what the universal claim requires.
Theorem — Transitivity of Subset If A ⊆ B and B ⊆ C, then A ⊆ C.
Proof Assume A ⊆ B and B ⊆ C. To show A ⊆ C, let x be an arbitrary element of A. Since A ⊆ B, x ∈ B. Since B ⊆ C and x ∈ B, x ∈ C. Since x was an arbitrary element of A and we showed x ∈ C, every element of A is in C. Therefore A ⊆ C. ∎
Theorem — A ⊆ B if and only if A ∩ B = A For any sets A and B: A ⊆ B ⟺ A ∩ B = A.
Proof (⇒) Assume A ⊆ B. We show A ∩ B = A by double inclusion. First, A ∩ B ⊆ A always holds (any element of an intersection belongs to each set intersected). For the reverse, let x be an arbitrary element of A; since A ⊆ B, x ∈ B too, so x ∈ A ∩ B — giving A ⊆ A ∩ B. Both inclusions hold, so A ∩ B = A.
(⇐) Assume A ∩ B = A. To show A ⊆ B, let x be an arbitrary element of A. Since A = A ∩ B, x ∈ A ∩ B, so in particular x ∈ B. Since x was arbitrary, A ⊆ B. ∎
Why the proof splits into two completely separate halves Because the claim is a biconditional, each direction gets its own hypothesis and its own arbitrary-element argument — nothing proved in (⇒) may be reused as a fact in (⇐), since (⇐) starts from a different assumption entirely. This is the same "prove two conditionals" discipline from Lesson 1, now visible as two distinct element-chasing arguments stacked back to back.
Try It — Follow the Arbitrary Element

Claim: if A ⊆ B and B ⊆ C, then A ⊆ C. Click "Reveal next" to trace where the arbitrary element x travels.

  1. Fix x. Let x be an arbitrary element of A — some fixed but otherwise unspecified element. Nothing else about x is assumed.
  2. Move x into B. Since A ⊆ B and x ∈ A, it follows that x ∈ B.
  3. Move x into C. Since B ⊆ C and x ∈ B, it follows that x ∈ C.
  4. Generalize. x was an arbitrary element of A, and it ended up in C. Since this argument used nothing specific to x, it holds for every element of A.
  5. Conclude. Every element of A is in C, so A ⊆ C by definition. ∎ One arbitrary element, chased through two subset relations, proves the claim for all of A at once.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does A ⊆ B mean, precisely?

Subset is a statement about every element of A landing in B — ∀x, x ∈ A → x ∈ B — not about size, overlap, or A itself being a member of B.

2. To prove A = B using double inclusion, what must be shown?

Set equality is defined as mutual subset — both directions must be proved, typically with two separate arbitrary-element arguments.

3. In an arbitrary-element proof that A ⊆ B, why is it invalid to instead pick one specific known element of A and check only that one?

This is exactly Lesson 2's ∀ logic: proving a universal claim requires an argument that works for every case, which is why x must be arbitrary — using no property beyond "x ∈ A" — rather than one specific chosen element.

4. Fill in the blank: to prove A ⊆ B, you let x be an ___ element of A — fixed for the argument, but with no special property assumed.

Arbitrary — using no property of x beyond membership in A is exactly what makes the argument generalize to every element.

5. Fill in the blank: A ∩ B is always a subset of ___ (using the single-letter set name from this lesson's biconditional theorem, the smaller side of the general inclusion that holds no matter what B is).

A ∩ B ⊆ A always holds, regardless of B — it's the fact used, without proof, as the easy half of the (⇒) direction above.
