1. What is the truth value of "If 4 is odd, then 10 is even," and why?

P → Q is false only when P is true and Q is false. Here P ("4 is odd") is false, so the conditional is vacuously true.

2. Let P be false and Q be true. What is the truth value of ¬P ∧ Q?

¬P is true (since P is false), and Q is true, so ¬P ∧ Q requires both — and both hold.

3. Fill in the blank: the connective that is true whenever at least one of its parts is true is called ___.

Disjunction (P ∨ Q) only needs one side true — unlike conjunction, which needs both.

4. What is the negation of ∀x ∈ ℤ, x + 1 > x?

Negating ∀ flips it to ∃ and negates the predicate: ¬(x + 1 > x) is x + 1 ≤ x.

5. Fill in the blank: proving ∀x ∈ D, P(x) is false requires exhibiting only ___ counterexample.

A single failing case is enough to disprove a universal claim, no matter how large the domain.

6. Consider two statements about integers: (I) ∃x ∀y, x ≤ y. (II) ∀y ∃x, x ≤ y. Answer both parts:

(a) Which statement, if either, is true?

(b) Fill in the blank: statement (I) fails because no single integer can be ≤ ___ integer simultaneously — there is no smallest integer.

(a) In (II), x is chosen after y and is allowed to depend on it, so x = y always works. (b) In (I), one fixed x would have to be below every integer at once, which is impossible since ℤ has no minimum.

7. Answer both parts about definitions versus theorems:

(a) When an ordinary theorem (not a definition) states "if P then Q," what does "if" mean?

(b) Fill in the blank: proving a general object satisfies an existential definition still requires describing how to construct a ___, even if expressed in terms of other given variables.

(a) Only definitions carry the biconditional convention; ordinary theorems mean exactly what P → Q says. (b) Even a general proof must show how to build the witness the definition demands.

8. Consider the claim 8 ∣ 96. Answer both parts:

(a) Which integer k correctly witnesses this claim (96 = 8k)?

(b) Fill in the blank: since 96 = 8 × 12, k = ___.

8 × 12 = 96, so k = 12 is the required witness.

9. Let P = "the sky is green" (false) and Q = "9 is a perfect square" (true). Answer both parts:

(a) What is the truth value of P → Q?

(b) Fill in the blank: the truth value of Q → P is ___.

(a) P false makes P → Q vacuously true. (b) Q → P has a true hypothesis and false conclusion — the one case that makes a conditional false.

10. Consider: "For every real number x, there exists a real number y with y² = x," symbolically ∀x ∈ ℝ, ∃y ∈ ℝ, y² = x. Answer both parts:

(a) Which is the correct negation?

(b) Fill in the blank: the negation says some real number x has ___ real square root.

(a) Both quantifiers flip and the predicate negates: ∀→∃, ∃→∀, y²=x → y²≠x. (b) This correctly reads "some x has no real y with y²=x" — true in fact, witnessed by any negative x.
