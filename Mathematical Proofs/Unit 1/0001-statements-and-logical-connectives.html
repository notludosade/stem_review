Statements and Logical Connectives

A proof is an argument built entirely out of statements. Before you can build one, you need to know exactly what a statement is, and exactly what happens when you glue two of them together.

Lesson 2 → Contents Glossary →

Precalculus and AP Calculus BC asked you to compute: solve for x, find the derivative, evaluate the limit. This course asks something different — to argue, in a way precise enough that another person has no honest way to disagree once they've followed every step. That kind of argument is built out of a specific kind of sentence, combined by a small, fixed set of operations. This lesson names both.

Definition — Statement A statement (or proposition) is a sentence that is either true or false, but not both, and not neither. "7 is prime" is a statement (true). "12 is prime" is a statement (false). "x + 2 = 5" is not a statement on its own — its truth depends on a value of x that hasn't been fixed. "Is 7 prime?" and "Solve for x" are not statements at all; they aren't the kind of sentence that has a truth value.
Why this definition earns its keep Every proof technique in this course — direct proof, contradiction, contrapositive, induction — is really just a recipe for legally getting from statements you already know are true to a new statement you want to show is true. None of that machinery makes sense applied to a question or a command. Nailing down "statement" first is what makes every later definition in this course actually stand on solid ground, instead of secretly depending on a fuzzy sense of "the kind of thing that could be true."

Combining statements: the logical connectives

Statements P and Q can be combined into new, compound statements using a small fixed set of connectives. Each one is defined by exactly how its truth value depends on the truth values of its parts — nothing about meaning or subject matter, only truth value in, truth value out.

Definition — Negation, Conjunction, Disjunction The negation of P, written ¬P ("not P"), is true exactly when P is false. The conjunction of P and Q, written P ∧ Q ("P and Q"), is true exactly when both P and Q are true. The disjunction of P and Q, written P ∨ Q ("P or Q"), is true when at least one of P, Q is true — this is the inclusive "or": P ∨ Q is still true if both happen to be true.
Example Let P = "6 is even" (true) and Q = "6 is prime" (false). Then ¬Q = "6 is not prime" is true. P ∧ Q = "6 is even and 6 is prime" is false, since Q fails. P ∨ Q = "6 is even or 6 is prime" is true, since P alone already succeeds.

The conditional: if P, then Q

The connective that does almost all the work in this course is the conditional, because "if this, then that" is the shape of nearly every theorem you'll ever prove.

Definition — Conditional Statement The conditional P → Q ("if P, then Q") is true in every case except when P is true and Q is false. P is called the hypothesis (or antecedent); Q is called the conclusion (or consequent). Equivalently: P → Q asserts that truth of P is enough to guarantee truth of Q — it makes no claim at all about what happens when P is false.
Why P → Q counts as true when P is false This is the single most common stumbling block in this lesson, so sit with it directly. "If it rains, the game is cancelled" is a promise about what happens when it rains. If it doesn't rain, the promise was never tested — nothing you observe on a dry day can break it, whether or not the game happens to run. Mathematicians formalize "the promise wasn't broken" as true, not "unknown" or "not applicable" — a statement needs some truth value, and "not false" is the only defensible one available. This case is called vacuous truth: P → Q is automatically true whenever P is false, regardless of Q. It will matter directly in Unit 3, where proof by contrapositive and proof by contradiction both lean on exactly this fact.
Definition — Biconditional The biconditional P ↔ Q ("P if and only if Q") is true exactly when P and Q have the same truth value — both true, or both false. Proving a biconditional almost always means proving two conditionals: P → Q and Q → P, one in each direction.

Check your recall

No peeking back up — answer from memory first, then check.

1. Which of the following is a statement in the sense this lesson defines?

"17 is a prime number" has a definite truth value (true) with no free variable. "x² = 9" depends on an unfixed x, and a question or command has no truth value at all.

2. What is the truth value of "If 2 + 2 = 5, then Paris is the capital of France," and why?

P → Q is false in exactly one case: P true and Q false. Here P ("2+2=5") is false, so the conditional is automatically — vacuously — true, no matter what the conclusion says.

3. Let P be true and Q be false. What is the truth value of P ∨ Q?

Disjunction only needs one side true. P is true, so P ∨ Q is true regardless of Q.

4. Fill in the blank: a conditional statement P → Q that is true only because its hypothesis P is false is said to be true ___.

This case — true purely because the hypothesis fails — is called vacuous truth, and it comes up constantly in Unit 3.

5. Fill in the blank: P ↔ Q, true exactly when P and Q share the same truth value, is called a ___.

Biconditional — usually proved as two separate conditionals, P → Q and Q → P.
