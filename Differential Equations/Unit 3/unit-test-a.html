1. For y″ + 7y′ + 10y = 0, the characteristic equation is:

Substituting y = e^(rx) and dividing out e^(rx) directly carries the coefficients over: r² + 7r + 10 = 0.

2. For a repeated root r, the general solution is:

The second independent solution needed alongside e^(rx) is xe^(rx), not another copy of e^(rx) or a different exponent.

3. Fill in the blank: for roots r = ±3i, the general solution is y = C₁cos(___x) + C₂sin(___x)

Here α = 0 (no exponential envelope) and β = 3, giving pure oscillation y = C₁cos(3x) + C₂sin(3x).

4. Solve y″ − y′ − 6y = 0, y(0) = 5, y′(0) = 0. Answer both parts:

(a) The general solution (before applying initial conditions) is:

(b) Fill in the blank: applying both initial conditions gives C₁ = ___

(a) r² − r − 6 = (r−3)(r+2) = 0 gives r = 3, −2. (b) y(0) = C₁ + C₂ = 5 and y′(0) = 3C₁ − 2C₂ = 0 solve to C₁ = 2, C₂ = 3.

5. Solve y″ − 4y′ + 4y = 0, y(0) = 3. Answer both parts:

(a) The general solution (before applying the initial condition) is:

(b) Fill in the blank: applying y(0) = 3 gives C₁ = ___

(a) r² − 4r + 4 = (r−2)² = 0 gives a repeated root r = 2, so y = (C₁ + C₂x)e^(2x). (b) y(0) = (C₁ + 0)e⁰ = C₁ = 3.

6. Solve y″ + 2y′ + 5y = 0. Answer both parts:

(a) The general solution is:

(b) Fill in the blank: the exponential envelope is e^(___x)

(a) r² + 2r + 5 = 0 has discriminant 4 − 20 = −16 < 0, giving r = (−2 ± 4i)/2 = −1 ± 2i, so α = −1, β = 2. (b) The envelope is e^(αx) = e^(−1x).

7. For a nonhomogeneous equation ay″ + by′ + cy = g(x), the general solution is built as:

The complementary solution y_h (both arbitrary constants) plus one particular solution y_p (no free constants) together form the complete general solution.

8. Fill in the blank: if the naive trial form for y_p already solves the homogeneous equation, multiply the guess by ___ before solving for its coefficients.

Multiplying by x keeps the trial form independent of the matching term already in y_h.

9. For y″ − y′ − 6y = 14e^(5x) (r = 5 is not a root of r² − r − 6 = 0). Answer both parts:

(a) The correct trial form for y_p is:

(b) Fill in the blank: solving for the coefficient gives A = ___

(a) r = 5 is not a root (roots are 3, −2), so no resonance — trial form Ae^(5x). (b) Substituting: 25A − 5A − 6A = 14A = 14, so A = 1.

10. For y″ − y′ − 6y = e^(3x) (note: r = 3 is already a root of r² − r − 6 = 0). Answer both parts:

(a) The correct trial form for y_p is:

(b) Fill in the blank: solving for the coefficient gives A = ___

(a) Since r = 3 is a simple root, the plain guess Ae^(3x) would collapse to 0 — multiply by x to get Axe^(3x). (b) Substituting and simplifying (the xe^(3x) terms cancel, as they always do for a correctly chosen resonance guess) leaves 5Ae^(3x) = e^(3x), so A = 1/5.
