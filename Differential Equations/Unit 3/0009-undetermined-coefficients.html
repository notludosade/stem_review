Nonhomogeneous Equations and the Method of Undetermined Coefficients

Lessons 7–8 handled a right side of zero. A real forcing term needs one more piece added to the solution — found by guessing its shape from the forcing term itself.

← Lesson 8 Unit 4, Lesson 10 → Contents Glossary →

1. Splitting the solution in two

Definition — Nonhomogeneous Equation A nonhomogeneous second-order linear equation has the form ay″ + by′ + cy = g(x), with g(x) ≠ 0 — a forcing term with no y in it.
Fact — General Solution Structure The general solution is y = yh + yp: yh is the complementary solution — the general solution of the matching homogeneous equation ay″ + by′ + cy = 0 from Lessons 7–8, carrying both arbitrary constants — and yp is any single particular solution of the full nonhomogeneous equation. Only yh supplies C₁ and C₂; yp is one fixed function with no free constants at all.
Method — Undetermined Coefficients Guess the form of yp from g(x)'s type, with unknown coefficients: a degree-n polynomial g(x) → guess a degree-n polynomial; g(x) = aekx → guess Aekx; g(x) = a·cos(kx) or a·sin(kx) → guess A·cos(kx) + B·sin(kx) (always both, even if g has only one). Substitute the guess into the full equation and solve for the unknown coefficients. Resonance case: if the guessed form already solves the homogeneous equation, multiply it by x (or x² for a repeated root) before solving.
Worked Example Solve y″ − 3y′ + 2y = e4x. Characteristic equation r² − 3r + 2 = (r−1)(r−2) = 0 gives yh = C₁ex + C₂e2x. Since r = 4 is not a root, guess yp = Ae4x: yp′ = 4Ae4x, yp″ = 16Ae4x. Substituting: 16Ae4x − 12Ae4x + 2Ae4x = e4x → 6A = 1 → A = 1/6. General solution: y = C₁ex + C₂e2x + (1/6)e4x.
Worked Example — Resonance Solve y″ − 3y′ + 2y = ex — same left side as above, but now the forcing term matches root r = 1 already in yh. The naive guess Aex would make the left side collapse to 0 (since ex solves the homogeneous equation), never matching ex. Guess instead yp = Axex. Substituting and simplifying gives −Aex = ex, so A = −1: yp = −xex.

2. Matching the guess to the forcing term

Pick a type of forcing term below to see the correct trial form for yp — including what changes in the resonance case.

Try It — Choosing a Trial Solution
g(x) = 3x² + 1, and 0 is not a root of the characteristic equation → trial y_p = Ax² + Bx + C (match the degree of g exactly, include every lower power).
g(x) = 5e^(4x), and r = 4 is not a root of the characteristic equation → trial y_p = Ae^(4x) (one unknown coefficient, same exponent as g).
g(x) = 5e^(x), but r = 1 already solves y″ − 3y′ + 2y = 0 → the plain guess Ae^(x) collapses to 0 and can't match. Multiply by x: trial y_p = Axe^(x). (If r = 1 were a repeated root of the characteristic equation, multiply by x² instead.)
g(x) = 4cos(3x) → trial y_p = A·cos(3x) + B·sin(3x). Both terms are required even though g has no sine — differentiating cos(3x) twice always reintroduces a sine term.

Check your recall

1. The general solution of ay″ + by′ + cy = g(x) is built as:

The complementary solution y_h (carrying both arbitrary constants) and one particular solution y_p (with no free constants) add together to form the complete general solution.

2. For y″ + y′ − 6y = 6x (and 0 is not a root of the characteristic equation), the correct trial form for y_p is:

g(x) = 6x is a degree-1 polynomial, so the trial form should be a general degree-1 polynomial, Ax + B — including the constant term B even though g(x) doesn't have one.

3. Fill in the blank: if the naive trial form for y_p already solves the homogeneous equation, multiply the guess by ___ (or by its square, for a repeated root) before solving.

Multiplying the resonating guess by x keeps it independent of y_h's matching term, the same fix Lesson 8 used for a repeated root's second solution.

4. Fill in the blank: for y″ − 3y′ + 2y = e^(4x), solving y_p = Ae^(4x) gives A = ___

Substituting y_p = Ae^(4x) gives 16Ae^(4x) − 12Ae^(4x) + 2Ae^(4x) = 6Ae^(4x), set equal to e^(4x): 6A = 1, so A = 1/6.

5. Fill in the blank: the correct trial form for g(x) = cos(3x) is y_p = A·cos(3x) + B·___(3x)

Differentiating cos(3x) always produces a sine term, so both cos(3x) and sin(3x) must appear in the trial form, regardless of which one g(x) itself contains.
