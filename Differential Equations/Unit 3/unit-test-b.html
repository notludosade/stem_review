1. For y″ + 9y′ + 14y = 0, the characteristic equation is:

Substituting y = e^(rx) and dividing out e^(rx) carries the coefficients over directly: r² + 9r + 14 = 0.

2. The second independent solution for a repeated root r, alongside e^(rx), is:

xe^(rx) is the second independent solution found by reduction of order — an extra factor of x, not a different exponent or a rescaled copy.

3. Fill in the blank: for roots r = ±5i, the general solution is y = C₁cos(___x) + C₂sin(___x)

Here α = 0 (no exponential envelope) and β = 5, giving pure oscillation y = C₁cos(5x) + C₂sin(5x).

4. Solve y″ − 2y′ − 8y = 0, y(0) = 6, y′(0) = 6. Answer both parts:

(a) The general solution (before applying initial conditions) is:

(b) Fill in the blank: applying both initial conditions gives C₁ = ___

(a) r² − 2r − 8 = (r−4)(r+2) = 0 gives r = 4, −2. (b) y(0) = C₁ + C₂ = 6 and y′(0) = 4C₁ − 2C₂ = 6 solve to C₁ = 3, C₂ = 3.

5. Solve y″ − 6y′ + 9y = 0, y(0) = 4. Answer both parts:

(a) The general solution (before applying the initial condition) is:

(b) Fill in the blank: applying y(0) = 4 gives C₁ = ___

(a) r² − 6r + 9 = (r−3)² = 0 gives a repeated root r = 3, so y = (C₁ + C₂x)e^(3x). (b) y(0) = (C₁ + 0)e⁰ = C₁ = 4.

6. Solve y″ + 4y′ + 13y = 0. Answer both parts:

(a) The general solution is:

(b) Fill in the blank: the exponential envelope is e^(___x)

(a) r² + 4r + 13 = 0 has discriminant 16 − 52 = −36 < 0, giving r = (−4 ± 6i)/2 = −2 ± 3i, so α = −2, β = 3. (b) The envelope is e^(αx) = e^(−2x).

7. In a nonhomogeneous equation's general solution y = y_h + y_p, the particular solution y_p:

y_p is one fixed function that satisfies the full equation — only y_h supplies the two arbitrary constants C₁ and C₂.

8. Fill in the blank: if a trial y_p form for undetermined coefficients duplicates a term already in y_h, the fix is to multiply the guess by ___

Multiplying by x keeps the trial form independent of the matching term already present in y_h.

9. For y″ − 2y′ − 8y = −5e^(3x) (r = 3 is not a root of r² − 2r − 8 = 0). Answer both parts:

(a) The correct trial form for y_p is:

(b) Fill in the blank: solving for the coefficient gives A = ___

(a) r = 3 is not a root (roots are 4, −2), so no resonance — trial form Ae^(3x). (b) Substituting: 9A − 6A − 8A = −5A = −5, so A = 1.

10. For y″ − 2y′ − 8y = e^(4x) (note: r = 4 is already a root of r² − 2r − 8 = 0). Answer both parts:

(a) The correct trial form for y_p is:

(b) Fill in the blank: solving for the coefficient gives A = ___

(a) Since r = 4 is a simple root, the plain guess Ae^(4x) would collapse to 0 — multiply by x to get Axe^(4x). (b) Substituting and simplifying leaves 6Ae^(4x) = e^(4x), so A = 1/6.
