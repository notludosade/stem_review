1. An undamped spring-mass system's equation of motion is:

Newton's second law with Hooke's restoring force gives x″ + ω²x = 0, ω = √(k/m) — a plus sign, giving oscillation rather than runaway growth.

2. Fill in the blank: for m = 5 kg and k = 45 N/m, ω = √(k/m) = ___ rad/s

ω = √(45/5) = √9 = 3.

3. Underdamped motion (oscillation inside a decaying envelope) occurs when:

β < ω₀ gives a negative discriminant in the characteristic equation — complex roots, hence oscillation with a decaying envelope.

4. Critically damped motion occurs when:

β = ω₀ gives a repeated root — the boundary between oscillating (underdamped) and not oscillating (overdamped).

5. Fill in the blank: pure resonance in the undamped forced case occurs when the driving frequency ω equals ___

When ω matches the natural frequency ω₀, the forcing term matches the homogeneous solution, triggering unbounded resonant growth.

6. A 4 kg mass on a spring with k = 16 N/m starts at x(0) = 5, released from rest. Answer both parts:

(a) ω equals:

(b) Fill in the blank: the period T = 2π/ω = ___

(a) ω = √(16/4) = √4 = 2. (b) T = 2π/2 = π.

7. A damped spring has β = 3, ω₀ = 5. Answer both parts:

(a) This system is:

(b) Fill in the blank: the damped frequency ω_d = √(ω₀² − β²) = ___

(a) β = 3 < ω₀ = 5, so underdamped. (b) ω_d = √(25 − 9) = √16 = 4.

8. A critically damped system has β = ω₀ = 3, x(0) = 4, x′(0) = 0. Answer both parts:

(a) The general solution form is:

(b) Fill in the blank: applying the initial conditions gives C₂ = ___

(a) A repeated root r = −3 gives x(t) = (C₁ + C₂t)e^(−3t). (b) x(0) = C₁ = 4. x′(t) = C₂e^(−3t) − 3(C₁+C₂t)e^(−3t), so x′(0) = C₂ − 3C₁ = 0, giving C₂ = 3(4) = 12.

9. For x″ + 25x = 20cos(3t) (so ω₀ = 5, ω = 3). Answer both parts:

(a) Since ω ≠ ω₀, this is:

(b) Fill in the blank: the steady-state response is x_p(t) = ___·cos(3t)

(a) ω = 3 differs from ω₀ = 5, so the response stays bounded. (b) x_p(t) = [f₀/(ω₀²−ω²)]cos(ωt) = [20/(25−9)]cos(3t) = 1.25cos(3t).

10. A damped forced system has ω₀ = 4, β = 1, f₀ = 8, driven exactly at ω = 4. Answer both parts:

(a) Fill in the blank: M(4) = f₀/√[(ω₀²−ω²)² + (2βω)²] = ___

(b) Since damping is present, the amplitude at this driving frequency is:

(a) At ω = ω₀ = 4, the first term (ω₀²−ω²) vanishes, leaving M(4) = 8/√(0 + (2·1·4)²) = 8/8 = 1. (b) Any positive damping keeps the denominator away from zero, so the amplitude stays finite even exactly at resonance — unlike the undamped case.
