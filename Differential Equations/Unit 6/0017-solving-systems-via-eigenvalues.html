Solving Systems via Eigenvalues

Unit 3 guessed y = e^(rx) and found a characteristic equation in r. The matrix version guesses X = ve^(λt) — and finds the exact same kind of characteristic equation, now in λ.

1. The matrix version of the exponential guess

Method — The Eigenvalue Guess For X′ = AX, try X = veλt, where v is a constant vector. Substituting: λveλt = Aveλt, so Av = λv — v must be an eigenvector of A with eigenvalue λ. A nontrivial solution exists only when det(A − λI) = 0, the matrix's characteristic equation — the direct matrix analogue of Unit 3's ar² + br + c = 0.
Fact — General Solution, Real Distinct Eigenvalues For a 2×2 system with distinct real eigenvalues λ₁ ≠ λ₂ and matching eigenvectors v₁, v₂, the general solution is X(t) = C₁v₁eλ₁t + C₂v₂eλ₂t — structurally identical to Unit 3's y = C₁er₁x + C₂er₂x, with a vector attached to each exponential.
Fact — The 2×2 Characteristic Equation, in Trace and Determinant For A = [[a, b], [c, d]], det(A − λI) expands to λ² − Tλ + D = 0, where T = a + d (the trace) and D = ad − bc (the determinant). Exactly like Unit 3's discriminant, T² − 4D > 0, = 0, or < 0 sorts the eigenvalues into real distinct, repeated, or complex conjugate pairs — the classification Lesson 18 turns into a picture.
Worked Example Solve X′ = AX for A = [[1, 1], [4, 1]]. Characteristic equation: (1−λ)² − 4 = 0 → λ = 1 ± 2 → λ₁ = 3, λ₂ = −1. For λ₁ = 3: (A − 3I)v = 0 gives −2v₁ + v₂ = 0, so v₁ = (1, 2). For λ₂ = −1: (A + I)v = 0 gives 2v₁ + v₂ = 0, so v₂ = (1, −2). General solution: X(t) = C₁(1, 2)e3t + C₂(1, −2)e−t.

1. Substituting X = ve^(λt) into X′ = AX leads to the condition:

λve^(λt) = Ave^(λt) simplifies (dividing out e^(λt), never zero) to Av = λv — the defining equation of an eigenvalue/eigenvector pair.

2. Fill in the blank: a nontrivial eigenvector v exists only when det(A − λI) = ___

(A − λI)v = 0 has a nonzero solution v only when A − λI is singular, i.e. det(A − λI) = 0 — the matrix characteristic equation.

3. For A = [[1, 1], [4, 1]], the eigenvalues are:

(1−λ)² − (1)(4) = 0 → (1−λ)² = 4 → 1−λ = ±2 → λ = 3 or λ = −1.

4. Fill in the blank: for A = [[1, 1], [4, 1]], the general solution X(t) = C₁(1,2)e^(3t) + C₂(1,−2)e^(___t)

The second eigenvalue found in the worked example was λ₂ = −1, matching eigenvector (1, −2).

5. For a 2×2 matrix, the characteristic equation in terms of trace T and determinant D is:

Expanding det(A − λI) for a 2×2 matrix always produces λ² − Tλ + D = 0 — the trace and determinant are all that's needed, without writing out a, b, c, d individually.
