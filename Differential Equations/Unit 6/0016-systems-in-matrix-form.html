Writing a System in Matrix Form

Every equation so far has tracked one unknown function. Real systems often couple several together — and packaging them as a single matrix equation is what lets linear algebra take over from here.

← Unit 5, Lesson 15 Lesson 17 → Contents Glossary →

1. Packaging two equations into one

Definition — System of First-Order Linear Equations A pair of coupled equations x′ = ax + by, y′ = cx + dy can be written as a single matrix equation X′ = AX, where X = [x, y]T and A = [[a, b], [c, d]]. Each entry of A is exactly the coefficient sitting in front of the matching variable in the original pair.
Fact — Any Higher-Order Equation Is a System in Disguise Unit 3's y″ + by′ + cy = 0 converts to a first-order system by introducing x₁ = y and x₂ = y′: then x₁′ = x₂ (by definition), and x₂′ = y″ = −cy − by′ = −cx₁ − bx₂. Every nth-order linear equation becomes a system of n first-order equations this same way — which is exactly why the matrix methods in Lessons 17–18 end up solving Unit 3's equations too, from a completely different angle.
Worked Example — Converting a Second-Order Equation Convert y″ − 5y′ + 6y = 0. Let x₁ = y, x₂ = y′. Then x₁′ = x₂, and x₂′ = y″ = 5y′ − 6y = 5x₂ − 6x₁. In matrix form: X′ = [[0, 1], [−6, 5]]X.
Worked Example — A System Given Directly x′ = 3x − 2y, y′ = 4x − y converts directly, reading coefficients straight into the matrix: A = [[3, −2], [4, −1]].

1. The system x′ = ax + by, y′ = cx + dy has matrix form X′ = AX with A equal to:

Row 1 holds x′'s coefficients (a, b) in order, and row 2 holds y′'s coefficients (c, d) in order — matching the equations top to bottom.

2. Fill in the blank: converting y″ − 5y′ + 6y = 0 with x₁ = y, x₂ = y′ gives x₂′ = 5x₂ + ___x₁

x₂′ = y″ = 5y′ − 6y = 5x₂ − 6x₁, so the coefficient of x₁ is −6.

3. For x′ = 3x − 2y, y′ = 4x − y, the matrix A is:

Reading each equation's coefficients into its own row, in order, gives [[3, −2], [4, −1]].

4. Fill in the blank: in A = [[3, −2], [4, −1]], the entry in row 2, column 1 is ___

Row 2 is [4, −1], so its first entry (column 1) is 4 — the coefficient of x in the y′ equation.

5. Rewriting a second-order equation as a first-order system is useful because:

The conversion doesn't change what the equation says — it just repackages it so that eigenvalue methods, built for systems of any size, can solve it too.
