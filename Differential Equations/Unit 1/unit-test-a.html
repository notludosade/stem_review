1. Which function solves dy/dx = 4y?

y = e^(4x) differentiates to y′ = 4e^(4x) = 4y, matching for every x. y = 4e^x gives y′ = 4e^x = y, not 4y.

2. Fill in the blank: the order of d²y/dx² − 3(dy/dx) + y = 0 is ___.

The highest derivative appearing is d²y/dx², so the order is 2.

3. Consider y = e^(−2x) as a candidate solution of y′ + 2y = 0. Answer both parts:

(a) Does it solve the equation?

(b) Fill in the blank: for this y, y′(0) = ___

(a) y′ = −2e^(−2x), so y′ + 2y = −2e^(−2x) + 2e^(−2x) = 0 for every x — a valid solution. (b) y′(0) = −2e⁰ = −2.

4. Which equation is separable?

e^(x+y) = e^x·e^y is already a product of a pure function of x and a pure function of y. The other three add x and y together before any operation that could split them apart.

5. Solve dy/dx = 2xy, y(0) = 4. Answer both parts:

(a) The general solution (before applying the initial condition) is:

(b) Fill in the blank: applying y(0) = 4 gives C = ___

(a) Separating gives dy/y = 2x dx; integrating gives ln|y| = x² + C₁, so y = Ce^(x²). (b) y(0) = Ce⁰ = C = 4.

6. Solve dy/dx = y·cos(x), y(0) = 1. Answer both parts:

(a) The general solution (before applying the initial condition) is:

(b) Fill in the blank: applying y(0) = 1 gives C = ___

(a) Separating gives dy/y = cos(x) dx; integrating gives ln|y| = sin(x) + C₁, so y = Ce^(sin x). (b) y(0) = Ce⁰ = C = 1.

7. Fill in the blank: a solution family such as y = Ce^(−3x), written with an arbitrary constant before any initial condition is applied, is called the ___ solution.

The general solution is the entire family of curves indexed by C; an initial condition selects one member of that family, the particular solution.

8. For dy/dx + (1/x)y = 3 (x > 0), the integrating factor μ(x) is:

μ(x) = e^(∫(1/x)dx) = e^(ln x) = x.

9. Solve dy/dx + 2y = 6, y(0) = 1. Answer both parts:

(a) The integrating factor μ(x) is:

(b) Fill in the blank: with y = 3 + Ce^(−2x), applying y(0) = 1 gives C = ___

(a) μ(x) = e^(∫2 dx) = e^(2x). (b) 1 = 3 + Ce⁰ = 3 + C, so C = −2.

10. Solve dy/dx + y = 5, y(0) = 2. Answer both parts:

(a) The general solution (before applying the initial condition) is:

(b) Fill in the blank: applying y(0) = 2 gives C = ___

(a) μ(x) = e^x gives d/dx[e^x y] = 5e^x, so e^x y = 5e^x + C and y = 5 + Ce^(−x). (b) 2 = 5 + Ce⁰ = 5 + C, so C = −3.
