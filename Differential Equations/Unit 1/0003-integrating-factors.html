First-Order Linear Equations and Integrating Factors

Not every first-order equation separates. This lesson handles a much broader family — any equation linear in y — with a single multiplying trick that turns the left side into one derivative.

← Lesson 2 Unit 2, Lesson 4 → Contents Glossary →

1. Standard form

Definition — First-Order Linear Equation, Standard Form A first-order equation is linear if it can be written dy/dx + P(x)y = Q(x) — y and y′ appear only to the first power, never multiplied together or stuffed inside another function. The coefficient on dy/dx must be exactly 1; if it isn't, divide the whole equation by it first.
Method — Integrating Factor Multiply both sides by the integrating factor μ(x) = e∫P(x) dx. This is constructed so the left side collapses into a single derivative: d/dx[μ(x)y] = μ(x)Q(x). Integrate both sides with respect to x, then divide by μ(x) to solve for y.
Worked Example Solve dy/dx + (2/x)y = x², for x > 0. Here P(x) = 2/x, so μ(x) = e∫(2/x)dx = e2ln x = x². Multiplying through: d/dx[x²y] = x²·x² = x⁴. Integrate: x²y = x⁵/5 + C. Solve for y: y = x³/5 + C/x².

3. Why the left side collapses

Why This Matters μ(x) is built specifically so that μ′(x) = P(x)μ(x) — the Product Rule then gives d/dx[μy] = μy′ + μ′y = μy′ + P(x)μy = μ(y′ + P(x)y), exactly the left side of the original equation multiplied by μ. That's not a coincidence; it's the entire reason e∫P dx was chosen as the multiplier.

Standard form requires the coefficient on y′ to be exactly 1. Dividing every term by 3 gives y′ + 2y = 3x, ready for P(x) = 2 to be read off directly.

2. Fill in the blank: for dy/dx + 5y = Q(x), the integrating factor is μ(x) = ___

μ(x) = e^(∫P(x)dx) with P(x) = 5 gives μ(x) = e^(∫5 dx) = e^(5x).

3. Multiplying dy/dx + P(x)y = Q(x) by its integrating factor μ(x) turns the left side into:

μ(x) is constructed precisely so the Product Rule collapses μ(x)y′ + P(x)μ(x)y back into the single derivative d/dx[μ(x)y] — the entire point of the method.

4. Fill in the blank: solving dy/dx + 2y = 4, y(0) = 5 gives y = 2 + Ce^(−2x) with C = ___

Substituting y(0) = 5 gives 5 = 2 + Ce⁰ = 2 + C, so C = 3.
