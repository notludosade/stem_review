What a Differential Equation Actually Is

Every equation you've solved so far asks for a number. A differential equation asks for a whole function — one whose own rate of change is part of the question.

Lesson 2 → Contents Glossary →

1. An equation about a function and its derivative

Definition — Differential Equation A differential equation is an equation relating an unknown function to one or more of its derivatives, such as dy/dx = 2y or y″ + 4y = 0. A solution is an entire function y(x) that makes the equation true for every x in its domain — not a single number, the way x² − 4 = 0 asks for numbers.
Definition — Order The order of a differential equation is the highest derivative that appears. dy/dx = 2y is first-order (only y′ appears); y″ + 4y = 0 is second-order (y″ appears). Units 1–2 of this course work with first-order equations; Units 3–4 move to second-order.
Worked Example — Verifying a Solution Does y = e2x solve dy/dx = 2y? Differentiate the proposed function: y′ = 2e2x. Compare to 2y = 2e2x. They match for every x, so yes — y = e2x is a solution. Does y = x² solve the same equation? y′ = 2x, but 2y = 2x². These agree only at x = 0, not for every x, so y = x² is not a solution.

3. Where these equations come from

Why This Matters Physical laws are almost always stated as relationships between a rate of change and the current state — not as a formula for the state itself. Population growth, radioactive decay, spring motion, cooling coffee, and current in a circuit are all first phrased as differential equations. This course builds the toolkit to turn each of those into an explicit formula.

Check your recall

1. A differential equation's solution is:

Unlike x² − 4 = 0, which asks for numbers, a differential equation asks for a whole function y(x) whose derivative(s) make the equation hold everywhere.

2. Fill in the blank: the equation y″ − 3y′ + 2y = 0 has order ___.

The highest derivative appearing is y″, so the order is 2 — a second-order differential equation.

3. Which function solves dy/dx = −y?

y = e^(−x) differentiates to y′ = −e^(−x) = −y, matching the equation for every x. y = e^x gives y′ = y (the wrong sign), and neither of the other two candidates matches at all.

4. Fill in the blank: verifying y = 4 (a constant function) as a solution of dy/dx = y − 4 requires checking that y′ = ___ matches the right side, 4 − 4 = 0.

A constant function has derivative 0 everywhere, and the right side y − 4 = 4 − 4 = 0 too — both sides match, so y = 4 is a valid (constant, "equilibrium") solution.
