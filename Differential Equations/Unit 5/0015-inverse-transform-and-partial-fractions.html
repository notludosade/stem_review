1. Undoing the transform

Definition — Inverse Laplace Transform L−1{F(s)} = f(t) means f is the function whose Laplace transform is F — undoing Lesson 13's table lookup in the other direction. Like the transform itself, L−1 is linear: L−1{aF(s) + bG(s)} = a·L−1{F(s)} + b·L−1{G(s)}.
Fact — First Shifting Theorem L{eatf(t)} = F(s − a), so in reverse, L−1{F(s − a)} = eatf(t). This handles any denominator built by completing the square, like (s−a)² + b² — it's the shifted version of L{sin(bt)} or L{cos(bt)}, multiplied by eat.
Method — Partial Fractions Before Inverting When Y(s) is a rational function that doesn't match the table directly, decompose it into simpler pieces first — distinct linear factors A/(s−a) + B/(s−b), exactly as in ordinary partial-fractions integration — then invert each piece separately using the table and linearity.
Worked Example — Distinct Linear Factors Invert Y(s) = 1/[(s−1)(s+2)]. Write 1/[(s−1)(s+2)] = A/(s−1) + B/(s+2), so 1 = A(s+2) + B(s−1). At s = 1: 1 = 3A → A = 1/3. At s = −2: 1 = −3B → B = −1/3. So Y(s) = (1/3)/(s−1) − (1/3)/(s+2), and y(t) = (1/3)et − (1/3)e−2t.
Worked Example — Completing the Square Invert Y(s) = 1/(s² + 2s + 5). Completing the square: s² + 2s + 5 = (s+1)² + 4. Since L{sin(2t)} = 2/(s²+4), the First Shifting Theorem gives L{e−tsin(2t)} = 2/[(s+1)²+4]. Matching Y(s) = 1/[(s+1)²+4] = (1/2)·2/[(s+1)²+4] gives y(t) = (1/2)e−tsin(2t).

Check your recall

1. L−1{F(s)} = f(t) means:

The inverse transform undoes the forward transform exactly: if L{f(t)} = F(s), then L^(−1){F(s)} = f(t).

2. The correct partial-fraction setup for 1/[(s−1)(s+2)] is:

Two distinct linear factors split into two separate fractions, added together, each with its own unknown constant numerator.

3. Fill in the blank: for 1/[(s−3)(s+1)] = A/(s−3) + B/(s+1), solving gives A = ___

1 = A(s+1) + B(s−3). At s = 3: 1 = 4A, so A = 1/4.

4. The First Shifting Theorem states:

Multiplying f(t) by e^(at) shifts the transform's variable by a, replacing every s with (s − a) — the exact tool needed for a completed-square denominator.

5. Fill in the blank: inverting Y(s) = 1/(s² + 2s + 5) = 1/[(s+1)² + 4] gives y(t) = ___·e^(−t)sin(2t)

L{sin(2t)} = 2/(s²+4), so by the shift theorem L{e^(−t)sin(2t)} = 2/[(s+1)²+4]. Matching the coefficient 1 (not 2) in Y(s) requires scaling by 1/2.
