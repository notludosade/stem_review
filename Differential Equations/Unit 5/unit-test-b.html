1. L{e^(at)} equals:

∫₀^∞ e^(−st)e^(at) dt = 1/(s−a), convergent for s > a.

2. Fill in the blank: L{tⁿ} = ___

L{tⁿ} = n!/s^(n+1), the general power-function entry (L{t} = 1/s² is the n=1 case).

3. The derivative property for a first derivative states L{y′(t)} =

The derivative property multiplies the transform by s and subtracts the function's initial value.

4. The correct partial-fraction setup for 1/[(s−4)(s+1)] is:

Two distinct linear factors split into two separate fractions added together, each with its own unknown numerator.

5. Fill in the blank: the First Shifting Theorem, read in reverse, states L^(−1){F(s − a)} = ___

Shifting F's argument by a corresponds to multiplying f(t) by e^(at) — the two operations are inverses of each other.

6. Find L{7 + 2t³}. Answer both parts:

(a) Fill in the blank: L{t³} = ___

(b) Fill in the blank: by linearity, L{7 + 2t³} = 7/s + ___

(a) L{t³} = 3!/s⁴ = 6/s⁴. (b) L{7 + 2t³} = 7·L{1} + 2·L{t³} = 7/s + 2(6/s⁴) = 7/s + 12/s⁴.

7. Solve y′ − 3y = 0, y(0) = 5 with Laplace transforms. Answer both parts:

(a) The transformed equation is:

(b) Fill in the blank: y(t) = ___e^(3t)

(a) sY(s) − y(0) − 3Y(s) = 0 → sY(s) − 5 − 3Y(s) = 0 → (s−3)Y(s) = 5. (b) Y(s) = 5/(s−3) matches L{5e^(3t)}, so y(t) = 5e^(3t).

8. Solve y″ + 25y = 0, y(0) = 0, y′(0) = 5. Answer both parts:

(a) Y(s) equals:

(b) Fill in the blank: y(t) = sin(___t)

(a) s²Y(s) − s(0) − 5 + 25Y(s) = 0 → (s²+25)Y(s) = 5 → Y(s) = 5/(s²+25). (b) This matches L{sin(5t)} = 5/(s²+25) exactly, so y(t) = sin(5t).

9. Invert Y(s) = 1/[(s−4)(s+1)]. Answer both parts:

(a) Fill in the blank: with 1/[(s−4)(s+1)] = A/(s−4) + B/(s+1), A = ___

(b) y(t) equals:

(a) 1 = A(s+1) + B(s−4). At s = 4: 1 = 5A, so A = 1/5. (b) By symmetry B = −1/5, giving y(t) = (1/5)e^(4t) − (1/5)e^(−t).

10. Invert Y(s) = 1/(s² + 6s + 13). Answer both parts:

(a) Completing the square, s² + 6s + 13 equals:

(b) Fill in the blank: y(t) = ___·e^(−3t)sin(2t)

(a) (s+3)² = s²+6s+9, so matching s²+6s+13 needs +4 more: (s+3)²+4. (b) L{sin(2t)} = 2/(s²+4), so by the shift theorem L{e^(−3t)sin(2t)} = 2/[(s+3)²+4]. Matching Y(s) = 1/[(s+3)²+4] requires scaling by 1/2.
