1. L{tⁿ} equals:

L{tⁿ} = n!/s^(n+1), the general power-function entry in the transform table (L{t} = 1/s² is the n = 1 case).

2. Fill in the blank: L{e^(at)} = ___

∫₀^∞ e^(−st)e^(at) dt = 1/(s−a), convergent for s > a.

3. L{y′(t)} equals:

The derivative property multiplies the transform by s and subtracts the initial value.

4. The correct partial-fraction setup for 1/[(s−2)(s+5)] is:

Two distinct linear factors split into two separate fractions added together, each with its own unknown numerator.

5. Fill in the blank: the First Shifting Theorem states L{e^(at)f(t)} = F(___)

Multiplying f(t) by e^(at) shifts the transform's argument: every s becomes (s − a).

6. Find L{5 + 3t²}. Answer both parts:

(a) Fill in the blank: L{t²} = ___

(b) Fill in the blank: by linearity, L{5 + 3t²} = 5/s + ___

(a) L{t²} = 2!/s³ = 2/s³. (b) L{5 + 3t²} = 5·L{1} + 3·L{t²} = 5/s + 3(2/s³) = 5/s + 6/s³.

7. Solve y′ − 2y = 0, y(0) = 4 with Laplace transforms. Answer both parts:

(a) The transformed equation is:

(b) Fill in the blank: y(t) = ___e^(2t)

(a) sY(s) − y(0) − 2Y(s) = 0 → sY(s) − 4 − 2Y(s) = 0 → (s−2)Y(s) = 4. (b) Y(s) = 4/(s−2) matches L{4e^(2t)}, so y(t) = 4e^(2t).

8. Solve y″ + 16y = 0, y(0) = 0, y′(0) = 4. Answer both parts:

(a) Y(s) equals:

(b) Fill in the blank: y(t) = sin(___t)

(a) s²Y(s) − s(0) − 4 + 16Y(s) = 0 → (s²+16)Y(s) = 4 → Y(s) = 4/(s²+16). (b) This matches L{sin(4t)} = 4/(s²+16) exactly, so y(t) = sin(4t).

9. Invert Y(s) = 1/[(s−2)(s+3)]. Answer both parts:

(a) Fill in the blank: with 1/[(s−2)(s+3)] = A/(s−2) + B/(s+3), A = ___

(b) y(t) equals:

(a) 1 = A(s+3) + B(s−2). At s = 2: 1 = 5A, so A = 1/5. (b) By symmetry B = −1/5, giving y(t) = (1/5)e^(2t) − (1/5)e^(−3t).

10. Invert Y(s) = 1/(s² + 4s + 13). Answer both parts:

(a) Completing the square, s² + 4s + 13 equals:

(b) Fill in the blank: y(t) = ___·e^(−2t)sin(3t)

(a) (s+2)² = s²+4s+4, so matching s²+4s+13 needs +9 more: (s+2)²+9. (b) L{sin(3t)} = 3/(s²+9), so by the shift theorem L{e^(−2t)sin(3t)} = 3/[(s+2)²+9]. Matching Y(s) = 1/[(s+2)²+9] requires scaling by 1/3.
