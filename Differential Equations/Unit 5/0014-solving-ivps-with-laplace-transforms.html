1. Transforming a derivative

Fact — The Derivative Property L{f′(t)} = sF(s) − f(0), and applying it twice gives L{f″(t)} = s²F(s) − sf(0) − f′(0). This is the key entry the rest of the table lacked: it folds the initial conditions directly into the transformed equation, turning a differential equation in t into an ordinary algebraic equation in s.
Method — Solving an IVP with Laplace Transforms (1) Take the Laplace transform of both sides of the equation, writing Y(s) = L{y(t)} and applying the derivative property with the given initial conditions plugged in immediately. (2) Solve the resulting algebraic equation for Y(s). (3) Recognize (or, in Lesson 15, decompose) Y(s) as a transform from the table, and read off y(t).
Worked Example Solve y″ + 4y = 0, y(0) = 1, y′(0) = 0 — Unit 4's undamped spring equation. Transforming: [s²Y(s) − s(1) − 0] + 4Y(s) = 0 → (s² + 4)Y(s) = s → Y(s) = s/(s² + 4). This matches Lesson 13's table entry L{cos(2t)} = s/(s²+4) exactly, so y(t) = cos(2t) — the same simple harmonic motion solution Unit 4 found with the characteristic equation, reached by an entirely different route.

1. L{y′(t)} equals:

The derivative property multiplies the transform by s and subtracts the initial value — dropping the −y(0) term is one of the most common errors in this method.

2. L{y″(t)} equals:

Applying the derivative property twice brings in both initial conditions, in this exact order: s²Y(s) minus s times y(0) minus y′(0) — swapping which condition gets multiplied by s is a common slip.

3. Fill in the blank: solving y′ − 5y = 0, y(0) = 3 with Laplace transforms gives (s−5)Y(s) = 3, so y(t) = ___e^(5t)

Y(s) = 3/(s−5) matches L{e^(at)} = 1/(s−a) scaled by 3, with a = 5 — so y(t) = 3e^(5t).

4. The three steps of the Laplace method, in order, are:

The whole point of the method is to avoid guessing: transform first (turning derivatives into algebra), solve the resulting algebraic equation for Y(s), then transform back at the very end.

5. Fill in the blank: solving y″ + 9y = 0, y(0) = 0, y′(0) = 3 gives (s²+9)Y(s) = 3, so Y(s) = 3/(s²+9), and y(t) = ___

Y(s) = 3/(s²+9) matches L{sin(bt)} = b/(s²+b²) exactly with b = 3, so y(t) = sin(3t).
