1. Which of these is an example of unstructured data?

Unstructured data has no fixed set of fields — free text has no such structure, unlike the fixed fields of the other three.

2. Fill in the blank: data describing a quality or category (e.g. color, country) rather than a numeric amount is called ___ data.

Qualitative (categorical) data describes a quality or category, unlike quantitative data, which measures an amount.

3. A satisfaction survey records responses as Low, Medium, or High. Which level of measurement is this?

Ordinal data has a meaningful order but no guaranteed equal gap between categories, unlike interval or ratio data.

4. Fill in the blank: data collected by someone else, for a different original purpose, and reused for a new question, is called ___ data.

Secondary data was collected by someone else for their own purpose; primary data is collected directly for the question at hand.

5. Which tool is generally the better fit for a million-row dataset edited simultaneously by many people across an organization?

Databases enforce rules and support many simultaneous readers and writers safely at that scale, which spreadsheets aren't designed for.

6. A national survey wants to make sure small subgroups (like rural voters) aren't accidentally missed, so it divides the population into subgroups first and samples within each. Answer both parts:

(a) What is this sampling method called?

(b) A separate researcher instead just surveys whoever answers their phone in the first hour of calling, using whatever numbers were easiest to reach. What is this second method called?

(a) Stratified sampling deliberately samples within subgroups to guarantee they aren't missed. (b) Convenience sampling just takes whoever is easiest to reach — the cheapest but least reliable method.

7. A company wants to know what its customers think, so it emails a satisfaction survey only to customers with an active account and analyzes the 40% who reply. Answer both parts:

(a) What does this collection method risk introducing?

(b) Why can't simply emailing more customers using the exact same method fix this problem?

Sampling bias is a systematic mismatch between a sample and the population, caused by the collection method itself — it does not shrink no matter how much more data is collected the same way.

8. A dataset lists a customer's country as "USA" in one row and "United States" in another for the same real customer, and elsewhere has a delivery-date field containing a phone number by mistake. Answer both parts:

(a) The USA / United States mismatch is an example of which data quality dimension?

(b) The phone number appearing in a delivery-date field is an example of which data quality dimension?

(a) Both spellings are factually accurate — the same fact just isn't represented the same way, which is a consistency problem. (b) A value that doesn't conform to its field's expected format or rules is a validity problem, regardless of whether it happens to be accurate elsewhere.

9. A web analytics service exports visit data as a text file where each visit looks like {"page": "/home", "duration": 42, "tags": ["new-user"]}. A second export is a plain-text file where each line is one row with commas separating page, duration, and tag. Answer both parts:

(a) Which format is the first export?

(b) Which format is the second export?

JSON's nested key-value structure suits the first export; CSV's strict comma-separated rows-and-columns shape suits the second.

10. A spreadsheet, a database table, and a CSV file all share the same basic shape. Answer both parts:

(a) Fill in the blank: an individual record — one customer, one order — is called a ___.

(b) Fill in the blank: an attribute recorded consistently for every record, like "email" or "order date," is called a ___.

Rows are individual records; columns are the fields recorded the same way across every one of those records — the one structural idea shared by spreadsheets, databases, and CSV files.
