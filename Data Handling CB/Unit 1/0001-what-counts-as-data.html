What Counts as Data

Before touching a spreadsheet or a database, you need a vocabulary for describing what kind of data you're even looking at — because that classification determines which operations and statistics are valid to use on it.

Lesson 2 → Contents Glossary →

"Data" covers everything from a column of sales totals to a folder of customer support call recordings. Those two things need completely different tools and completely different kinds of analysis. This lesson builds the classification system this whole course leans on: structured vs. unstructured, qualitative vs. quantitative, and — the one that trips people up most — the four levels of measurement.

Structured vs. unstructured data

Definitions Structured data fits neatly into rows and columns — a fixed set of fields, consistently present, like a spreadsheet of orders (order ID, date, customer, amount). Unstructured data has no fixed fields — free text, images, audio, video. A support ticket's "category" field is structured; the paragraph the customer typed describing their problem is unstructured. Most of this course works with structured data, because it's what spreadsheets and databases are built for — but real organizations hold enormous amounts of unstructured data too, and knowing the difference is the first step in deciding what tool even applies.
Semi-structured data A middle category exists: semi-structured data has some organizing structure (tags, key-value pairs) without fitting a strict table — a JSON file like {"name": "Ada", "orders": [12, 15]} or an email (structured headers: From, To, Date; unstructured body). You'll meet this again when working with data exported from web services and APIs.

Qualitative vs. quantitative

Definitions Quantitative data is numeric and measures an amount — height, price, count of items sold. Qualitative data (also called categorical) describes a quality or category — color, country, yes/no. The distinction matters immediately: it doesn't make sense to compute an "average" country, but it does make sense to compute an average price.

The four levels of measurement

Definitions Quantitative and qualitative are a coarse split. A finer classification, the levels of measurement, has four levels:
  • Nominal — categories with no inherent order (country, color, product type).
  • Ordinal — categories with a meaningful order, but no consistent numeric gap between them (star ratings 1–5, education level, satisfaction: low/medium/high).
  • Interval — numeric, ordered, with meaningful equal gaps, but no true zero (temperature in Celsius: 0° isn't "no temperature," and 20° isn't "twice as hot" as 10°).
  • Ratio — numeric, ordered, equal gaps, and a true zero, so ratios are meaningful (price, weight, count: $20 really is twice $10).
Why this classification matters more than it looks like it should Each level of measurement restricts which operations produce a meaningful answer. Averaging a nominal variable (the "average" favorite color of a survey's respondents) is meaningless — there's no numeric value underneath it to average. Averaging an ordinal variable (the "average" star rating) is extremely common in practice but is a real approximation: it silently assumes the gap between 1 and 2 stars is the same size as the gap between 4 and 5, which the ordinal level doesn't actually guarantee. Interval data can be averaged and subtracted meaningfully, but not divided into ratios. Only ratio data supports every arithmetic operation without caveats. Every later unit's statistics content — means, correlations, regressions — is quietly built on ratio (or, with some caution, interval) data; recognizing when you're actually working with ordinal or nominal data is what keeps an analysis honest.
Classifying a few examples Customer's country (nominal) · Movie rating out of 5 stars (ordinal) · Temperature in Fahrenheit (interval) · Number of units sold (ratio) · Order ID number (nominal — even though it's written as a number, "average order ID" is meaningless, since the number is just a label).

Check your recall

No peeking back up — answer from memory first, then check.

1. What is the key difference between structured and unstructured data?

The defining trait is a fixed, consistent field structure — not the storage tool or the data type of any single field.

2. Why is averaging an ordinal variable (like a 1-5 star rating) treated as an approximation rather than a fully justified calculation?

Ordinal data's order is guaranteed but its gap sizes are not, which is exactly the assumption an average quietly makes.

3. Why is an order ID number classified as nominal data rather than ratio data?

Being written as digits doesn't make a value ratio-level — what matters is whether the number measures an amount or just labels a category.

4. Fill in the blank: the level of measurement that has meaningful order, equal gaps, and a true zero — making ratios between values meaningful — is called ___.

Ratio data is the only level where a value like $20 can correctly be described as "twice" a value like $10.

5. Fill in the blank: data with some organizing structure (like tags or key-value pairs) that doesn't fit a strict table, such as a JSON file or an email, is called ___ data.

Semi-structured data sits between rigid tables and fully free-form text, common in exports from web services and APIs.
