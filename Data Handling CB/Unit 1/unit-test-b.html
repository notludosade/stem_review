1. Which of these is an example of structured data?

Structured data fits a fixed, consistently present set of fields; the other three have no fixed fields at all.

2. Fill in the blank: a variable measuring a numeric amount, such as price or weight, is called ___ data (the opposite of qualitative).

Quantitative data is numeric and measures an amount; qualitative (categorical) data describes a quality instead.

3. Temperature recorded in Celsius has meaningful equal gaps between degrees, but 0°C doesn't mean "no temperature." Which level of measurement is this?

Interval data has meaningful order and equal gaps, but no true zero — unlike ratio data, where a true zero makes ratios meaningful.

4. Fill in the blank: data collected directly for the exact question at hand — like a survey you designed and ran yourself — is called ___ data.

Primary data is collected directly for the question at hand; secondary data was collected by someone else for a different purpose.

5. Which tool is generally the better fit for a one-time analysis of 200 rows done by a single analyst?

A spreadsheet is fast to start and sufficient for small, single-analyst, interactive work; a full database here would be needless overhead.

6. A pollster gives every registered voter in the state an equal chance of being selected by drawing names from the complete voter roll. Answer both parts:

(a) What is this sampling method called?

(b) A different pollster instead only interviews voters standing outside one particular polling place because it's easiest to reach. What is this method called?

(a) Random sampling gives every population member an equal chance of selection. (b) Convenience sampling just takes whoever's easiest to reach — the cheapest but least reliable method.

7. A fitness app only has usage data from people who downloaded and kept the app, and wants to conclude something about "the average adult's" exercise habits from that data alone. Answer both parts:

(a) What is this an example of?

(b) Why doesn't collecting data from many more app users fix the problem?

Sampling bias is a systematic mismatch baked into the collection method itself, and it doesn't shrink no matter how much more data is collected the same way.

8. A monthly sales report shows a store's revenue as $0 for a month it was actually open and trading normally, and a separate "last updated" timestamp on the whole report is a year old even though sales happen daily. Answer both parts:

(a) The impossible $0 revenue for a month the store was open points to a problem with which dimension?

(b) The stale, year-old "last updated" timestamp on daily sales data is a problem with which dimension?

(a) A value that doesn't correctly reflect reality is an accuracy problem. (b) Data that isn't current enough for the question being asked is a timeliness problem, independent of whether it was accurate when recorded.

9. Two exports of the same product catalog exist: one is plain text where every line is one product with values separated by commas; the other nests each product's attributes and a list of its tags inside curly braces and key-value pairs. Answer both parts:

(a) Fill in the blank: the comma-separated, strictly row-and-column export is a ___ file.

(b) Fill in the blank: the nested, key-value export common in API and web-service exports is a ___ file.

CSV is the simplest, universal rows-and-columns text format; JSON's nested key-value structure is more flexible, common in API exports.

10. Spreadsheets, database tables, and CSV files all organize data the same basic way. Answer both parts:

(a) What does an individual row represent?

(b) What does a column represent?

Rows are individual records; columns are the fields recorded the same way across every record — the shared shape across spreadsheets, databases, and CSV files.
