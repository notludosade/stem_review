1. Which data role most directly builds and maintains the pipelines and databases that get raw data into a queryable, analysis-ready state?

Data Engineers build the infrastructure that Analysts, Data Scientists, and BI Analysts then query and analyze.

2. Which data role does this course's curriculum map to most directly?

The Data Analyst role's core day-to-day work overlaps most directly with this course's units.

3. A job posting titled "Data Analyst" lists Python, statistical modeling, A/B testing, and machine learning as its requirements. What role does this actually describe, regardless of its title?

Job titles aren't standardized across companies — the actual listed skills, not the title, are the reliable signal of what a role really is.

4. What should a strong data portfolio project show, beyond just the final chart or dashboard?

The visible reasoning across every stage of the pipeline is what distinguishes a strong portfolio piece from a merely polished chart.

5. Fill in the blank: an interview format that presents a realistic business scenario and dataset and asks a candidate to reason through it live is called a ___.

This is the standard term for the format used across data roles to evaluate reasoning process rather than one "correct" number.

6. A portfolio piece shows only a polished final chart, with no visible process behind it. Answer both parts:

(a) Why is this actually a weaker portfolio piece than one showing the full process?

(b) What specifically should the project include to address this gap?

Showing the raw data and the specific judgment calls made to clean it, recorded in a cleaning log, is what lets a reviewer trust the conclusion rather than just admire the picture.

7. A candidate is choosing a topic for a portfolio project. Answer both parts:

(a) Why might a project built around a question the candidate personally cares about produce a more coherent final story?

(b) Which of these is a reasonable place to find raw material for such a project?

A genuinely motivating question supplies context for free, but the raw material itself can reasonably come from public sources like open-data portals, as long as the project goes through the full pipeline.

8. A case-study prompt asks: "Weekly signups dropped 20% last month — what would you look into?" Answer both parts:

(a) Why is "I'd check for a confounding variable before concluding a cause" a stronger answer than immediately naming a specific root cause?

(b) What should a strong candidate check before assuming a product-side cause for the drop?

What's being tested is whether the candidate's instinct is to reach for a plausible driver immediately or to first rule out measurement issues and confounders — the discipline this course built across several units.

9. The capstone walks a churn-analysis dataset through every unit of this course, in order. Answer both parts:

(a) Why must Unit 5's cleaning happen before Unit 4's statistics can be trusted?

(b) Which unit's relational structure organizes the churn dataset before SQL querying begins?

Cleaning (Unit 5) is what makes the input to Unit 4's statistics trustworthy, and Unit 3's relational structure — separate tables linked by keys — is what SQL then queries.

10. The capstone closes with an argument about a single discipline running through all eight units. Answer both parts:

(a) According to this argument, what single discipline underlies every unit in this course?

(b) Which lesson's argument is the clearest direct example of this discipline?

Deliberate, disclosed judgment calls — not any single technique — is the thread tying every unit together, and the cleaning log is the clearest concrete example of it.
