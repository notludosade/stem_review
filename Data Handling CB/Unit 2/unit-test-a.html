1. Which function counts only cells containing numeric values, ignoring blanks and text?

COUNT is restricted to numeric cells; COUNTA counts any non-empty cell regardless of type.

2. Fill in the blank: =___(range, criteria) counts only cells in range matching criteria.

COUNTIF counts only cells matching a condition, unlike plain COUNT, which counts every numeric cell.

3. A formula =C2/C10 is copied from row 2 down to row 3, without any dollar signs. What happens?

Relative references shift silently when a formula is copied — no error is raised, which is exactly why this bug is so easy to miss.

4. Fill in the blank: restricting a cell's entries to a fixed list of allowed values (so a user picks rather than types) is usually implemented with a ___ list.

A dropdown list restricts entry to a known set of valid values, making an inconsistent variant impossible to type in.

5. In a pivot table, which area do you use to choose a numeric column and how it should be aggregated (sum, average, count)?

Values is where the actual numeric column and its aggregation method are chosen, distinct from Rows and Columns, which only choose groupings.

6. An Orders sheet has Customer ID in column A. A Customers sheet has Customer ID in column A, Name in column B, Region in column C. Answer both parts about =VLOOKUP(A2, Customers!A:C, 3, FALSE) entered in the Orders sheet:

(a) What does this formula return?

(b) What is VLOOKUP's key structural limitation shown by this kind of lookup?

(a) col_index 3 counts three columns into A:C, which is Region. (b) VLOOKUP only searches the leftmost column of its range and looks rightward — it fails if the search key isn't leftmost.

7. Using the same two sheets, a formula reads =INDEX(Customers!B:B, MATCH(A2, Customers!A:A, 0)). Answer both parts:

(a) What does MATCH(A2, Customers!A:A, 0) return?

(b) What does the full INDEX-MATCH formula return overall?

MATCH finds the position of a match; INDEX then retrieves the value at that position from a different range — here, column B.

8. Answer both parts about =XLOOKUP(A2, Customers!A:A, Customers!C:C):

(a) What does this formula return?

(b) What is XLOOKUP's main advantage over VLOOKUP?

XLOOKUP does what INDEX-MATCH does in one call, searching either direction and matching exactly by default — removing VLOOKUP's directionality limit.

9. A pivot table is built from an orders sheet, dragging Region into Rows and Sum of Order Total into Values. Answer both parts:

(a) What happens to the original orders sheet when the pivot table is built?

(b) The analyst then drags Product Category into Rows instead of Region, to see the totals sliced differently. Why is this safe to try?

A pivot table reads from the source data to build a summary view without modifying it, so experimenting with different groupings costs nothing.

10. A shared order sheet uses conditional formatting to highlight any "Order Total" cell that is negative in red. Answer both parts:

(a) What does this conditional formatting rule actually do?

(b) Fill in the blank: unlike conditional formatting, a ___ rule set on the column could actually reject or warn against a disallowed value at the moment of entry.

Conditional formatting only flags existing values visually; data validation is what can actually prevent bad values from being entered in the first place.
