1. Which function counts every non-empty cell in a range, regardless of whether it holds a number or text?

COUNTA counts any non-blank cell of any type; COUNT is restricted to numeric cells only.

2. Fill in the blank: =___(B2:B100, "West", C2:C100) sums column C only for rows where column B equals "West".

SUMIF sums a different column, but only for rows matching a given criteria in a condition range.

3. A formula in cell C2 reads =B2/$D$1, correctly dividing each month's sales by a fixed annual target in D1. What happens when this formula is copied down to C3?

The dollar signs lock D1 in place under copying, while the relative reference B2 shifts normally to B3 — exactly what absolute references are for.

4. Fill in the blank: beyond fixed dropdown lists, a validation ___ can require a cell to be a number within a range, a date, or text matching a specific pattern, rejecting or warning on anything else.

A validation rule can restrict entries beyond a fixed list, such as requiring a number in range or a specific date format.

5. In a pivot table, which area restricts the whole table to a subset of the data, such as only "Completed" orders?

Filters narrows the entire pivot table's scope without changing how Rows, Columns, or Values are configured.

6. A Products sheet has Product ID in column A, Product Name in column B, Price in column C. An analyst writes =VLOOKUP(A2, Products!A:C, 2, FALSE) in a different sheet. Answer both parts:

(a) What does this formula return?

(b) The analyst later needs to look up a Product ID using a table where Product ID sits in the rightmost column instead of the leftmost. Why does VLOOKUP fail here?

(a) col_index 2 is the second column of A:C, which is Product Name. (b) VLOOKUP's leftmost-column, rightward-only search is exactly what fails when the lookup key isn't leftmost.

7. A lookup table has Region in column C and the Region Manager's name in column A, to the left of Region. Answer both parts:

(a) Why would INDEX-MATCH work here when VLOOKUP would not?

(b) In the combined formula, what specific job does the INDEX function do?

MATCH finds a position by searching either direction; INDEX retrieves the value at that position from any range, which is what fixes VLOOKUP's directionality limit.

8. An analyst has two versions of the same lookup: one written as =INDEX(Customers!B:B, MATCH(A2, Customers!A:A, 0)), the other as =XLOOKUP(A2, Customers!A:A, Customers!B:B). Answer both parts:

(a) How do these two formulas compare in what they return?

(b) What is the practical benefit of XLOOKUP over writing INDEX and MATCH separately?

XLOOKUP and INDEX-MATCH often produce the identical result; XLOOKUP's benefit is doing it in a single, simpler function call.

9. A pivot table shows Sum of Order Total broken down by Region in Rows and Month in Columns. Answer both parts:

(a) What does one individual cell in this grid represent?

(b) The underlying orders sheet gets three new rows added. What must happen for the pivot table to reflect them?

Each cell aggregates exactly the rows matching its row and column labels; a pivot table can be rebuilt from scratch whenever the underlying data changes.

10. A spreadsheet highlights any date more than a year old in orange using conditional formatting, but has no validation rule on the date column. Answer both parts:

(a) Can a user still type an invalid or extremely old date into the column?

(b) Fill in the blank: adding a data ___ rule restricting the column to dates within the last year, rather than only highlighting old ones, would actually prevent the bad entries going forward.

Conditional formatting only flags existing values after the fact; a validation rule is what could actually prevent the bad entry from being typed in the first place.
