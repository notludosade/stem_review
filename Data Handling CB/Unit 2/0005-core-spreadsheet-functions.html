Core Spreadsheet Functions

A handful of functions, used well, cover most day-to-day spreadsheet work. This lesson builds the core set — and the one habit (absolute vs. relative references) that determines whether they survive being copied across a sheet.

← Lesson 4 Lesson 6 → Contents Glossary →

Lesson 4 placed spreadsheets as the right tool for small, interactive, single-analyst work. This lesson starts actually using one — the functions that turn a spreadsheet from a grid of typed numbers into something that computes.

The core aggregate functions

Functions =SUM(range) adds every number in a range. =AVERAGE(range) computes the arithmetic mean. =COUNT(range) counts numeric cells in a range; =COUNTA(range) counts non-empty cells of any type. =MAX(range) / =MIN(range) return the largest/smallest value. Every one of these ignores blank cells rather than treating them as zero — a detail that matters once Unit 5 discusses missing data.

Conditional versions: COUNTIF, SUMIF, and their multi-condition forms

Functions =COUNTIF(range, criteria) counts only cells matching a condition, e.g. =COUNTIF(A2:A100, "Completed"). =SUMIF(range, criteria, sum_range) sums a different column, but only for rows where range matches criteria, e.g. =SUMIF(B2:B100, "West", C2:C100) sums column C only for rows where column B is "West". =COUNTIFS and =SUMIFS extend this to multiple conditions at once — e.g. sum revenue where region is "West" and month is "January".

IF and nested logic

Function =IF(condition, value_if_true, value_if_false) — e.g. =IF(B2>100, "High", "Low"). IF statements can be nested, but more than one or two levels of nesting usually signals it's time for a lookup table instead (Lesson 6) — a long chain of nested IFs is hard to read and easy to break with one misplaced parenthesis.

Absolute vs. relative references

The distinction A relative reference (e.g. A2) shifts automatically when a formula is copied to a new cell — copying =A2*2 from row 2 to row 3 becomes =A3*2. An absolute reference (e.g. $A$2, with dollar signs locking the row and/or column) stays fixed no matter where the formula is copied. A mixed reference locks only the row or only the column (A$2 or $A2).
Why this is the single most common source of spreadsheet bugs A formula like =C2/$C$10 (each row's value divided by a fixed total in cell C10) works perfectly in row 2 — but if the dollar signs are missing (=C2/C10) and the formula is copied down to row 3, the denominator silently shifts to C11, an empty or wrong cell, and every row below the first quietly computes a wrong answer with no error message. Because spreadsheets don't raise an error for this — the formula still "runs," it just references the wrong cell — this bug is invisible unless you specifically check. The habit worth building: before copying any formula across multiple cells, ask which parts of each reference should move with it and which parts should stay fixed, and lock the fixed ones with $.
Worked example A sheet has monthly sales in B2:B13 and a fixed annual target in D1. To compute each month's percent of the annual target: =B2/$D$1 in C2, then copy down to C13. Without the $ signs, C3 would compute =B3/D2 — dividing by an empty cell instead of the target.

Check your recall

No peeking back up — answer from memory first, then check.

1. What is the difference between COUNT and COUNTA?

COUNT is restricted to numeric values; COUNTA counts any cell holding something, numeric or not.

2. What happens if a formula like =C2/C10 (no dollar signs) is copied from row 2 down to row 3?

Relative references shift with the copy silently — no error is raised, which is exactly why this bug is so easy to miss.

3. When should nested IF statements typically be replaced with a lookup table instead?

Deep IF nesting is a readability and fragility signal, not a hard technical limit — which is exactly why Lesson 6 introduces lookups as the more maintainable alternative.

4. Fill in the blank: the function that sums values in one column only for rows where a different column matches a given condition is ___.

SUMIF takes a condition range, a criteria, and a separate range to actually sum — letting you filter and aggregate in one step.

5. Fill in the blank: a reference like $A$2, which stays fixed no matter where the formula containing it is copied, is called an ___ reference.

The dollar signs lock the row and/or column, keeping the reference fixed under copying — the opposite of a relative reference's automatic shift.
