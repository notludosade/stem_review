# Mission: Data Handling: CB

## Why
Nearly every career now involves working with data in some form — pulling numbers into a spreadsheet, querying a database, reading a chart in a meeting, or deciding whether a claimed trend is real. Most people pick up these skills unevenly and informally, and end up unable to tell a solid analysis from a misleading one, or unable to go from a messy export to a clear takeaway. This course teaches data handling as a practical, career-facing skill: how to find and question data, work with it in the tools professionals actually use (spreadsheets, SQL), clean it, analyze it with real statistical grounding, visualize and present it honestly, and understand the ethics and career paths built around it.

## Success looks like
- Can look at any dataset and correctly identify its structure, its likely sources of bias, and whether it's fit for the question being asked
- Comfortable manipulating and summarizing data in spreadsheets (functions, lookups, pivot tables) and in SQL (SELECT, joins, aggregation, subqueries)
- Understands core statistics well enough to compute and correctly interpret descriptive statistics, distributions, correlation, confidence intervals, and simple regression — and to recognize when a claim is overreaching what the data supports
- Can take a raw, messy dataset through cleaning and preparation to an analysis-ready state, explaining each decision made along the way
- Can choose an honest chart for a given question, spot a misleading one, and structure an analysis into a clear narrative for a specific audience
- Understands the ethical and regulatory basics around data (privacy, bias, governance) well enough to flag concerns before they become problems
- Knows the landscape of data-related roles, can build a portfolio that demonstrates real data-handling skill, and has a working approach to data-focused case-study interviews

## Constraints
- No formal prerequisite — built to be broadly accessible. Basic algebra (comfort with variables and simple formulas, e.g. from Precalculus) is helpful for Unit 4's statistics content but not required.
- Practical and tool-grounded throughout: every statistical or conceptual idea is paired with how to actually do it in a spreadsheet or SQL, not left abstract
- SQL is taught using standard, portable syntax (no vendor-specific dialect features) since the goal is transferable understanding, not one product's quirks
- Statistics content goes deep enough to use correctly and avoid common misinterpretations, but this is not a substitute for a full statistics or Real Analysis course — proofs are not the focus here, correct practical use is

## Out of scope
- Programming-language-based data analysis (pandas, R, etc.) — covered by the Computer Programming courses and AI Developer if the learner wants to go further; this course stays at the spreadsheet/SQL/conceptual level deliberately, to stay accessible without a coding prerequisite
- Machine learning and predictive modeling beyond simple linear regression — that is AI Developer's territory
- Deep database administration (indexing internals, transactions, scaling) — this course teaches SQL as a query language for analysis, not database engineering
- Rigorous mathematical statistics (formal proofs of estimator properties, measure-theoretic probability) — covered, if ever added, by a dedicated statistics/probability course; this course is applied
