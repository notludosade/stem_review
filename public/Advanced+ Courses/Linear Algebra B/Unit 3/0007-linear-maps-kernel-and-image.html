Linear Maps, Kernel, and Image

Linear Algebra A only ever saw T: ℝⁿ → ℝᵐ, T(v) = Av. The same definition, unchanged, describes maps between any two vector spaces — derivatives, traces, evaluations — and every one of them carries two built-in subspaces worth naming.

← Lesson 6 Lesson 8 → Contents Glossary →

Linear Algebra A's Lesson 12 defined a linear transformation as T(u+v) = T(u)+T(v) and T(cv) = cT(v), then only ever tested it on matrix-vector products T(v) = Av. Nothing in that definition actually requires V and W to be ℝⁿ and ℝᵐ — and once that restriction is dropped, derivatives and traces turn out to be linear maps too.

1. Linear maps between any two vector spaces

Definition — Linear Map For vector spaces V, W over the same field F, a function T: V → W is a linear map if T(u+v) = T(u)+T(v) and T(cv) = cT(v) for all u, v ∈ V and c ∈ F.
Two Linear Maps That Are Not Matrix-Vector Products (a) T: P₂(ℝ) → P₁(ℝ), T(p) = p′ (the derivative). Linearity is exactly the sum rule and constant-multiple rule from calculus: (p+q)′ = p′+q′ and (cp)′ = cp′.
(b) T: M₂(ℝ) → ℝ, T(A) = tr(A) (the trace, sum of diagonal entries). tr(A+B) = tr(A)+tr(B) and tr(cA) = c·tr(A) both hold entry-by-entry.

2. Kernel and image are subspaces

Definition — Kernel and Image For a linear map T: V → W, the kernel is ker(T) = {v ∈ V : T(v) = 0}, and the image is im(T) = {T(v) : v ∈ V} ⊆ W.
Theorem — Kernel and Image Are Subspaces ker(T) is a subspace of V, and im(T) is a subspace of W.
Proof ker(T): T(0) = T(0·0) = 0·T(0) = 0, so 0 ∈ ker(T). If T(u)=0 and T(v)=0, then T(u+v) = T(u)+T(v) = 0+0 = 0, so u+v ∈ ker(T). If T(u)=0, then T(cu) = cT(u) = c·0 = 0, so cu ∈ ker(T). All three subspace-test conditions hold.

im(T): 0 = T(0) ∈ im(T). If w₁ = T(v₁) and w₂ = T(v₂) are both in im(T), then w₁+w₂ = T(v₁)+T(v₂) = T(v₁+v₂) ∈ im(T) (it's the image of v₁+v₂). If w = T(v) ∈ im(T), then cw = cT(v) = T(cv) ∈ im(T). All three conditions hold. ∎

3. Injectivity is exactly a trivial kernel

Theorem — T Is Injective ⟺ ker(T) = {0} A linear map T: V → W is injective (one-to-one) if and only if ker(T) = {0}.
Proof (⟹) Suppose T is injective. If v ∈ ker(T), then T(v) = 0 = T(0). Injectivity forces v = 0. So ker(T) ⊆ {0}, and since 0 ∈ ker(T) always, ker(T) = {0}.

(⟸) Suppose ker(T) = {0}. If T(u) = T(v) for some u, v ∈ V, then T(u−v) = T(u)−T(v) = 0 (using linearity: T(u−v) = T(u) + T(−v) = T(u) − T(v)), so u−v ∈ ker(T) = {0}, meaning u−v = 0, i.e. u = v. So T is injective. ∎
Why this shortcut is worth having Checking injectivity directly means checking "T(u)=T(v) ⟹ u=v" for every pair of vectors — infinitely many pairs. This theorem reduces the entire check to a single question: does T(v)=0 have any solution besides v=0? For a matrix map T(v)=Av, that's exactly Linear Algebra A's homogeneous-system test, now proved to be the right test rather than just asserted.
Worked Example — Kernel and Image of the Derivative Map For T: P₂(ℝ) → P₁(ℝ), T(p) = p′: ker(T) = {p ∈ P₂(ℝ) : p′ = 0} = the constant polynomials, span{1} — a 1-dimensional subspace. Since ker(T) ≠ {0}, T is not injective (e.g. T(x² ) = T(x²+1) = 2x). For the image: any q(x) = ax+b ∈ P₁(ℝ) is T(½ax² + bx) = ax+b, so every element of P₁(ℝ) is reached — im(T) = P₁(ℝ), all of it.

Check your recall

No peeking back up — answer from memory first, then check.

1. Which of the following is a linear map?

Trace satisfies both linearity conditions directly. T(p)=p+1 fails T(0)=1≠0; T(x,y)=xy and T(x)=x² are both nonlinear (quadratic) — none of the others preserve addition and scalar multiplication.

2. In the proof that ker(T) is a subspace, how is T(0) = 0 established?

Writing 0 = 0·0 and applying T's scalar-multiplication rule directly proves T(0)=0 for every linear map, without any extra assumption.

3. Fill in the blank: a linear map T is injective if and only if ker(T) = ___.

ker(T) = {0} (only the zero vector maps to zero) is exactly equivalent to injectivity, proved in both directions in this lesson.

4. For T: P₂(ℝ) → P₁(ℝ), T(p) = p′, what is ker(T)?

p′ = 0 exactly when p is constant, since any nonzero-degree term in p contributes a nonzero derivative term.

5. Fill in the blank: the (⟸) direction of the injectivity theorem shows T(u)=T(v) implies T(___) = 0, then uses ker(T)={0} to conclude u=v.

T(u−v) = T(u)−T(v) = 0 by linearity, and this is exactly what puts u−v into the kernel, forcing u−v=0.
