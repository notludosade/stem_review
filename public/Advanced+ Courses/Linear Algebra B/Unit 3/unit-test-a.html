1. Which of the following is a linear map?

Evaluation at a fixed point is always linear: (p+q)(2)=p(2)+q(2) and (cp)(2)=c·p(2). The others fail — the first two are quadratic in their input, and the last fails T(0)=1≠0.

2. Fill in the blank: T(0) = T(0·0) = 0·T(0) = 0 for any linear map T, invoking the ___ property of linearity.

T(cv) = cT(v), the scalar multiplication (homogeneity) rule, is what turns T(0·0) into 0·T(0).

3. According to the Rank-Nullity Theorem, for T: V → W with V finite-dimensional, which equation always holds?

The identity is stated in terms of dim(V), the domain — not dim(W), and the two terms need not be equal to each other.

4. If dim(V) = 7 and rank(T) = 4, what is nullity(T)?

nullity(T) = dim(V) − rank(T) = 7 − 4 = 3.

5. Two matrices representing the same linear operator T: V → V relative to two different bases are always what?

The Change of Basis Theorem proves exactly this relationship — the two matrices are similar, not generally equal, inverse, or transpose to each other.

6. For T: P₂(ℝ) → ℝ, T(p) = p(1) − p(0). Answer both parts:

(a) Which polynomial is in ker(T)?

(b) ker(T) = span{x²−x, 1}. Fill in the blank: nullity(T) = ___.

(a) For p(x)=x²−x: p(1)=0, p(0)=0, so T(p)=0. (b) {x²−x, 1} is a linearly independent set of 2 vectors, so nullity(T) = 2.

7. Let T: ℝ⁴ → ℝ², T(x,y,z,w) = (x+z, y+w). Answer both parts:

(a) What is dim(ker(T))?

(b) By Rank-Nullity, rank(T) = 4 − 2 = ___.

(a) x+z=0 and y+w=0 leave x,y free (z=−x, w=−y), a 2-dimensional kernel. (b) rank(T) = 4 − 2 = 2, matching dim(ℝ²), so T is surjective.

8. Let T(x,y) = (3x, x+y) and B′ = {(1,0), (1,1)}. Answer both parts:

(a) T(1,0) = (3,1). What is column 1 of [T]B′?

(b) T(1,1) = (3,2). Column 2 of [T]B′ is (1, ___).

(a) (3,1) = a(1,0)+b(1,1) gives b=1, a=2. (b) (3,2) = a(1,0)+b(1,1) gives b=2, a=1.

9. For P = [[1,1],[0,1]] (the change-of-basis matrix for B′={(1,0),(1,1)}), answer both parts:

(a) What is P⁻¹?

(b) Computing P⁻¹[T]BP confirms [T]B′ = [[2,1],[1,___]].

(a) For [[a,b],[c,d]], the inverse is (1/det)[[d,−b],[−c,a]]; here det=1, giving [[1,−1],[0,1]]. (b) The full computation reproduces [T]B′ = [[2,1],[1,2]] from Question 8.

10. Let T: ℝ³ → ℝ², T(x,y,z) = (x−y, y−z). Answer both parts:

(a) Is T injective?

(b) Fill in the blank: since T(1,1,1) = T(0,0,0) yet (1,1,1) ≠ ___, T fails to be injective.

(a) x=y and y=z forces x=y=z, giving the 1-dimensional kernel span{(1,1,1)}. (b) Two distinct inputs mapping to the same output is a direct witness against injectivity.
