Matrix Representation and Change of Basis

Every linear map becomes an actual matrix once bases are chosen on both sides — and changing the basis changes the matrix in an exactly predictable way: by conjugating with the change-of-basis matrix.

← Lesson 8 Lesson 10 → Contents Glossary →

Linear Algebra A only ever wrote a linear map as a matrix relative to the standard basis. This lesson builds the matrix relative to any chosen bases, then proves exactly how that matrix changes when the bases do — the fact behind "similar matrices," used constantly starting in Unit 4.

1. The matrix of a linear map, relative to chosen bases

Definition — Matrix Representation For a linear map T: V → W, a basis B = {v₁,…,vn} of V, and a basis C of W, the matrix of T relative to B and C, written [T]C←B, is the matrix whose j-th column is [T(vj)]C — the coordinates, relative to C, of where T sends the j-th basis vector of B.
Theorem — What [T]C←B Does For every v ∈ V: [T(v)]C = [T]C←B [v]B.
Proof Write v = c₁v₁+⋯+cnvn, so [v]B = (c₁,…,cn). By linearity of T, T(v) = c₁T(v₁)+⋯+cnT(vn). Apply the (linear, Lesson 6) coordinate map relative to C: [T(v)]C = c₁[T(v₁)]C+⋯+cn[T(vn)]C — exactly c₁ times column 1 of [T]C←B plus ⋯ plus cn times column n, which is the matrix-vector product [T]C←B(c₁,…,cn) = [T]C←B[v]B. ∎

2. Changing the basis: similar matrices

For an operator T: V → V (same space on both sides), comparing its matrix relative to two different bases B and B′ of the same V produces the single most useful relationship in the rest of this course.

Theorem — Change of Basis for an Operator Let T: V → V, let B, B′ be bases of V, and let P = PB←B′ (Lesson 6's change-of-basis matrix). Then [T]B′ = P⁻¹ [T]B P.
Proof For any v ∈ V, apply Lesson 6's formula and the previous theorem: [T(v)]B = [T]B[v]B = [T]B P [v]B′ (using [v]B = P[v]B′). On the other hand, converting T(v)'s own coordinates from B back to B′ uses P⁻¹ (Lesson 6's change-of-basis matrices are always invertible, since PB′←B = P⁻¹ undoes the conversion): [T(v)]B′ = P⁻¹[T(v)]B = P⁻¹[T]BP[v]B′. But by definition, [T(v)]B′ = [T]B′[v]B′ too. Since this holds for every v — in particular for each basis vector of B′, which pins down every column — [T]B′ = P⁻¹[T]BP. ∎
Why this is worth naming: similarity Two matrices A and A′ related by A′ = P⁻¹AP for some invertible P are called similar. This theorem says exactly this: the matrices representing the same linear operator relative to two different bases are always similar. Unit 4's entire point — that eigenvalues don't depend on which basis you happened to compute in — is a direct consequence, proved formally in Lesson 10.
Worked Example — T(x,y) = (x+2y, 3y), Standard Basis vs. B′ = {(1,1), (0,1)} Relative to the standard basis, [T]B = [[1,2],[0,3]] (columns are T(1,0)=(1,0) and T(0,1)=(2,3), written in standard coordinates). Now compute [T]B′ directly: T(1,1) = (1+2, 3) = (3,3); writing (3,3) = a(1,1)+b(0,1) gives a=3, b=0, so column 1 is (3,0). T(0,1) = (2,3); writing (2,3) = a(1,1)+b(0,1) gives a=2, b=1, so column 2 is (2,1). So [T]B′ = [[3,2],[0,1]].

Check against the theorem: P = PB←B′ = [[1,0],[1,1]] (columns are B′'s vectors, already in standard coordinates), and P⁻¹ = [[1,0],[−1,1]]. Computing P⁻¹[T]BP: first [T]BP = [[1,2],[0,3]][[1,0],[1,1]] = [[3,2],[3,3]]; then P⁻¹(that) = [[1,0],[−1,1]][[3,2],[3,3]] = [[3,2],[0,1]]. Matches [T]B′ exactly. ✓

Check your recall

No peeking back up — answer from memory first, then check.

1. What goes in column j of [T]C←B?

Each column tracks where one of B's basis vectors is sent by T, expressed in C's coordinate system — exactly what's needed for matrix-vector multiplication to reproduce [T(v)]C.

2. In the proof of [T]B′ = P⁻¹[T]BP, why is P invertible in the first place?

Since converting B′-coordinates to B-coordinates and back is the identity operation, PB←B′ and PB′←B are genuine two-sided inverses of each other.

3. Fill in the blank: matrices A and A′ with A′ = P⁻¹AP for some invertible P are called ___ matrices.

Similarity is exactly the relationship this lesson's theorem proves holds between any two matrix representations of the same operator.

4. In the worked example, what is column 1 of [T]B′ for B′ = {(1,1),(0,1)}?

T(1,1) = (3,3), and expressing (3,3) in B′-coordinates (solving a(1,1)+b(0,1)=(3,3)) gives a=3, b=0.

5. In the worked example, [T]B′ = [[3,2],[0,___]]. Fill in the blank.

Column 2 comes from T(0,1) = (2,3) = 2(1,1) + 1(0,1), giving (2,1) — so the bottom-right entry is 1.
