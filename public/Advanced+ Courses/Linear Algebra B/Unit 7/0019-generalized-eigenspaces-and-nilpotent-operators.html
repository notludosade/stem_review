Generalized Eigenspaces and Nilpotent Operators

Lesson 12 defined generalized eigenspaces and left their inner structure unexamined. This lesson opens them up: every generalized eigenspace is exactly an eigenvalue plus a nilpotent operator, and a nilpotent operator's own structure is a chain.

← Lesson 18 Lesson 20 → Contents Glossary →

1. Nilpotent operators

Definition — Nilpotent An operator N: V → V is nilpotent if Nk = 0 for some positive integer k. The smallest such k is N's index of nilpotency.
Theorem — A Nilpotent Operator's Only Eigenvalue Is 0 If N is nilpotent (Nk=0) and Nv=λv for some v≠0, then λ=0.
Proof Applying N repeatedly, Nkv = λkv (each application of N multiplies by λ again, since v stays an eigenvector of N throughout — Nʲv=λʲv by induction on j). But Nk=0, so Nkv=0, giving λkv=0. Since v≠0, λk=0, forcing λ=0. ∎

2. Every generalized eigenspace is "eigenvalue plus nilpotent"

Theorem — Structure of T Restricted to Kλ Kλ is T-invariant, and T restricted to Kλ equals λI + N, where N = (T−λI)|Kλ is nilpotent on Kλ.
Proof First, Kλ is (T−λI)-invariant: if v ∈ Kλ, then (T−λI)kv=0 for some k (Lesson 12), so (T−λI)k[(T−λI)v] = (T−λI)k+1v = (T−λI)[(T−λI)kv] = (T−λI)(0) = 0 — so (T−λI)v ∈ Kλ too. Since T = (T−λI) + λI and both pieces keep Kλ inside itself, Kλ is T-invariant.

Let N = (T−λI)|Kλ. By Lesson 12, the kernel chain for T−λI stabilizes by exponent n=dim(V) at the latest, and Kλ = ker((T−λI)n) — meaning every v ∈ Kλ satisfies (T−λI)nv = 0, i.e. Nn = 0 on Kλ. So N is nilpotent. And T|Kλ = (T−λI)|Kλ + λI|Kλ = N + λI. ∎
Why this is the fix Lesson 12 promised Within Kλ, T doesn't act like a single scalar λ (that would just be Eλ again) — it acts like λ plus a nilpotent "leftover" N. Lesson 20's Jordan form is exactly the choice of basis that makes this leftover N as simple as possible: a chain of 1's just off the diagonal.

3. Nilpotent chains

Theorem — A Nilpotent Chain Is Independent If Nk−1v ≠ 0 for some vector v (with Nk=0), then {v, Nv, N²v, …, Nk−1v} is linearly independent.
Proof Suppose c₀v + c₁Nv + ⋯ + ck−1Nk−1v = 0. Apply Nk−1 to both sides: every term cᵢNk−1(Nⁱv) = cᵢNk−1+iv vanishes for i≥1 (since k−1+i ≥ k, and Nk=0 already kills it), leaving only c₀Nk−1v = 0. Since Nk−1v ≠ 0, c₀=0. The relation becomes c₁Nv+⋯+ck−1Nk−1v=0; apply Nk−2 the same way to force c₁=0, and continue. Each step isolates and zeroes one more coefficient, until every cᵢ=0. ∎
Worked Example — The Chain Inside a Defective Matrix Revisiting Lesson 11's A=[[2,1,0],[0,2,0],[0,0,3]]: K₂ = ker((A−2I)²) = {(v₁,v₂,0)} (Lesson 12), a 2-dimensional space. N = (A−2I)|K₂ sends (v₁,v₂,0) ↦ (v₂,0,0) — reading off row 1 of A−2I=[[0,1,0],[0,0,0],[0,0,1]] restricted to v₃=0. Take v=(0,1,0): Nv=(1,0,0)≠0, and N²v = N(1,0,0) = (0,0,0). So {v,Nv} = {(0,1,0),(1,0,0)} is a nilpotent chain of length 2 — and it's independent, matching dim(K₂)=2 exactly. This chain, reordered {Nv,v} = {(1,0,0),(0,1,0)}, is precisely the basis that will produce a Jordan block in Lesson 20.

Check your recall

No peeking back up — answer from memory first, then check.

1. Why does Nkv=0 combined with Nv=λv force λ=0?

Repeatedly applying N to an eigenvector just repeatedly multiplies by λ, so Nkv=λkv — combined with Nk=0 and v≠0, this pins λk=0, hence λ=0.

2. In the proof that Kλ is T-invariant, what is shown first?

Showing (T−λI)-invariance first is what makes the rest of the argument work — combined with λI trivially keeping Kλ inside itself, T=(T−λI)+λI is then automatically T-invariant too.

3. Fill in the blank: in the nilpotent chain independence proof, applying N^(k−1) to the dependency relation isolates c₀N^(k−1)v = ___, since every other term already vanishes.

Every term with i≥1 gets hit by an exponent ≥ k after applying N^(k−1), vanishing since N^k=0 — leaving only the c₀ term equal to 0.

4. For A=[[2,1,0],[0,2,0],[0,0,3]] and N=(A−2I)|K₂, what is N²v for v=(0,1,0)?

Nv=(1,0,0), and N(1,0,0)=(0,0,0) — the chain terminates after one more step, confirming N²=0 on K₂.

5. Fill in the blank: the chain {v,Nv} from the worked example has length ___, exactly matching dim(K₂).

The chain has 2 vectors, v and Nv, matching the 2-dimensional K₂ exactly — a single chain spans the whole generalized eigenspace here.
