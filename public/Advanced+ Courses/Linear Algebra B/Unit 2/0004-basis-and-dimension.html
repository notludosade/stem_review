Basis and Dimension

Linear Algebra A stated, without proof, that every basis of a space has the same size. This lesson proves it — the single fact that makes "the dimension of V" a well-defined number at all.

← Lesson 3 Lesson 5 → Contents Glossary →

Linear Algebra A's Lesson 11 asserted that "every basis of a given vector space has exactly the same number of vectors" and moved on. But nothing said so far rules out V having a basis of 3 vectors and a basis of 5 vectors — until the theorem below closes that gap for good.

1. The Exchange Lemma

Theorem — Steinitz Exchange Lemma Let V be a vector space. If {v₁, …, vn} spans V and {w₁, …, wm} ⊆ V is linearly independent, then m ≤ n.
Proof Build up the w's one at a time, each time swapping one out for one of the v's, and track that the result still spans V.

Step 0: {v₁, …, vn} spans V (given).

Inductive step (k → k+1, assuming k < m): suppose after k swaps, some relabeling gives a spanning set {w₁, …, wk, vk+1, …, vn} (k of the original v's replaced by w₁,…,wk). If k = n already, no v's remain — the spanning set is exactly {w₁,…,wn}, so wn+1 would have to be a linear combination of w₁,…,wn, contradicting the independence of {w₁,…,wm} (which contains w₁,…,wn+1 since k+1 = n+1 ≤ m). So this case forces the process to already have used up all m of the w's, meaning m ≤ n and the theorem holds.

Otherwise k < n, so some v's remain. Since {w₁,…,wk,vk+1,…,vn} spans V, wk+1 is some combination c₁w₁+⋯+ckwk+dk+1vk+1+⋯+dnvn. Not every dj can be 0 — otherwise wk+1 would be a combination of w₁,…,wk alone, giving a nontrivial dependency among w₁,…,wk+1 (coefficient −1 on wk+1), contradicting independence of the w's. So some dj ≠ 0; solve for vj in terms of the rest and swap it out for wk+1. The new set {w₁,…,wk+1, remaining v's} still spans V, by the same substitution argument as the Reduction Theorem's proof (Lesson 3).

Repeating this for k = 0, 1, …, m−1 either runs out of v's first (forcing m ≤ n, as shown above) or successfully reaches k = m with m ≤ n throughout. Either way, m ≤ n. ∎
Why "exchange," not just "count" The proof doesn't just compare sizes — it actively trades a vᵢ for a wⱼ at every step, and the argument for why a trade is always possible (some dⱼ ≠ 0) is exactly where independence of the w's gets used. Counting alone would say nothing about whether the exchange is even legal; the mechanism is the proof.
A Small Case, Traced by Hand In ℝ², let {v₁, v₂, v₃} = {e₁, e₂, e₁+e₂} (spans ℝ², since e₁, e₂ alone already do) and {w₁} = {e₁ − e₂} (independent, being nonzero). Write w₁ = 1·e₁ + (−1)·e₂ + 0·(e₁+e₂) — the coefficient on e₁ is nonzero, so e₁ can be swapped out: {e₁−e₂, e₂, e₁+e₂} spans ℝ² too (e₂ is present directly, and e₁ = (e₁−e₂) + e₂ is recoverable). The lemma's conclusion, m ≤ n, reads 1 ≤ 3 here — true, and with room to spare since the original spanning set was redundant.

2. Dimension is well-defined

Corollary — Every Basis Has the Same Size If B₁ = {v₁,…,vn} and B₂ = {w₁,…,wm} are both bases of a finite-dimensional vector space V, then n = m.
Proof B₁ spans V and B₂ is independent (both basis properties) — the Exchange Lemma gives m ≤ n. Symmetrically, B₂ spans V and B₁ is independent — the Exchange Lemma gives n ≤ m. So n = m. ∎

With this proved, dimension is legitimate: dim(V) is defined as the common size of every basis of V, and the Exchange Lemma is exactly what guarantees "the common size" is a single well-defined number rather than a range of possibilities.

Check your recall

No peeking back up — answer from memory first, then check.

1. In the Exchange Lemma's proof, what goes wrong if every coefficient dⱼ on the remaining v's is 0 when expressing wk+1?

If wₖ₊₁ were expressible using only w₁,…,wₖ, that combination minus wₖ₊₁ itself would be a nontrivial relation among w₁,…,wₖ₊₁ — but those are assumed independent, so this is exactly the contradiction that forces some dⱼ ≠ 0.

2. In the Corollary's proof, why does applying the Exchange Lemma twice (once each direction) prove n = m?

Since both B₁ and B₂ are simultaneously spanning sets and independent sets, the lemma applies in both directions — and two inequalities pointing opposite ways force equality.

3. Fill in the blank: the Exchange Lemma requires {v₁,…,vₙ} to span V, and {w₁,…,wₘ} to be ___.

The roles are not symmetric — one set must span, the other must be independent — and the conclusion m ≤ n only follows with that specific pairing.

4. In the worked ℝ² example, why is it legal to swap e₁ out of {e₁, e₂, e₁+e₂} for w₁ = e₁ − e₂?

The nonzero coefficient on e₁ (specifically, 1) is exactly what the proof requires to solve for e₁ and legally substitute it out while preserving the span.

5. Fill in the blank: because every basis of V has the same size, that common size can be called the ___ of V without ambiguity.

Dimension is defined as this common size — a definition that only makes sense once the Corollary guarantees the size really is common to every basis.
