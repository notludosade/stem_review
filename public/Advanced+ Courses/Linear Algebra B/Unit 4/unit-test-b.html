1. Which statement about det(A−λI) is correct, for an n×n matrix A?

The all-diagonal term (a₁₁−λ)⋯(aₙₙ−λ) is the unique source of the λⁿ term, contributing exactly (−1)ⁿλⁿ — and the result holds for any square matrix, not just symmetric ones.

2. Fill in the blank: for A′=P⁻¹AP, det(A′−λI) = det(P⁻¹)·det(A−λI)·det(P). Regrouping det(P⁻¹)det(P) uses the fact that P⁻¹P = ___.

P⁻¹P = I by definition of matrix inverse, and det(I) = 1, leaving det(A′−λI) = det(A−λI).

3. Which example is consistent with the Geometric ≤ Algebraic theorem?

Geometric multiplicity can fall short of algebraic multiplicity (2 ≤ 3 here), but it can never exceed it, and algebraic multiplicity is always at least 1 for an actual eigenvalue.

4. For A=[[5,2],[0,5]], what is dim(E₅)?

(A−5I)=[[0,2],[0,0]]; solving forces v₂=0, leaving v₁ free — a 1-dimensional eigenspace, less than the algebraic multiplicity 2.

5. Which statement about invariant subspaces and generalized eigenspaces is correct?

Since T and (T−λI) commute, T(v) satisfies the same kernel condition as v whenever v is a generalized eigenvector — so Kλ is T-invariant too, not just Eλ.

6. For distinct eigenvalues λ₁=1, λ₂=6 with eigenvectors v₁, v₂, suppose c₁v₁+c₂v₂=0. Applying T gives c₁v₁+6c₂v₂=0. Answer both parts:

(a) Subtracting the original equation from this gives which relation?

(b) Since v₂ ≠ 0, 5c₂v₂ = 0 forces c₂ = ___.

(a) (c₁v₁+6c₂v₂)−(c₁v₁+c₂v₂) = 5c₂v₂ = 0. (b) A nonzero vector times a scalar equals 0 only if the scalar is 0.

7. For A=[[6,1,0],[0,6,0],[0,0,1]], λ=6 has algebraic multiplicity 2. Answer both parts:

(a) What is dim(E₆)?

(b) Fill in the blank: since 1 ≠ 2, A is ___ diagonalizable.

(a) (A−6I)=[[0,1,0],[0,0,0],[0,0,−5]]; solving forces v₂=0 and v₃=0, leaving only v₁ free — dim 1. (b) 1 falls short of the algebraic multiplicity 2.

8. For C=[[3,1,0],[0,3,1],[0,0,3]], answer both parts:

(a) What is dim(ker(C−3I))?

(b) dim(ker((C−3I)²)) = ___.

(a) (C−3I)=[[0,1,0],[0,0,1],[0,0,0]] forces v₂=v₃=0, leaving only v₁ free. (b) (C−3I)² has only its top-right entry nonzero, forcing just v₃=0 — a 2-dimensional kernel.

9. For A = [[4,1],[1,4]], answer both parts:

(a) What is the characteristic polynomial?

(b) Factoring gives (λ−5)(λ−3). Name the smaller eigenvalue: ___.

(a) det(A−λI) = (4−λ)²−1 = λ²−8λ+16−1 = λ²−8λ+15. (b) Factoring λ²−8λ+15 = (λ−5)(λ−3) gives eigenvalues 5 and 3.

10. Suppose |B∩Eλᵢ| ≤ dim(Eλᵢ) ≤ aᵢ holds for every i, and Σ|B∩Eλᵢ| = Σaᵢ = n. Answer both parts:

(a) What conclusion follows?

(b) Fill in the blank: this is the same logical pattern as Unit 2's dimension formula proof — nonnegative terms with a fixed total force every ___ term to vanish.

(a) Matching totals with nonnegative individual gaps forces every gap to 0. (b) A sum of nonnegative slack terms equal to 0 forces each individual slack term to be 0.
