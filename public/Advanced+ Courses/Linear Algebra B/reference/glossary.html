Unit 1 — Vector Spaces, Abstractly

Field

A set with + and · satisfying commutativity, associativity, distributivity, and inverses — ℝ and ℂ are the two fields this course uses.

Vector Space

A set V with addition and scalar multiplication over a field F, satisfying eight axioms — generalizes ℝⁿ to polynomials, matrices, and functions.

Subspace

A subset W of V that is itself a vector space under V's own operations, verified by the three-condition Subspace Test.

Span

Set of every linear combination of given vectors — proved to be the smallest subspace containing them.

Reduction Theorem

Every finite spanning set contains a basis, found by discarding vectors expressible in terms of the rest.

Unit 2 — Dimension Theory

Steinitz Exchange Lemma

If one set spans V and a second is independent, the independent set can never outnumber the spanning set — the fact that makes dimension well-defined.

Dimension

dim(V), the common size of every basis of V — a single well-defined number, guaranteed by the Exchange Lemma's corollary.

Coordinate Vector

[v]B — the tuple of scalars representing v uniquely relative to basis B.

Change-of-Basis Matrix

PB←B′ — converts B′-coordinates directly into B-coordinates via matrix multiplication.

Unit 3 — Linear Transformations

Kernel

ker(T) = {v : T(v)=0} — always a subspace of the domain.

Image

im(T) = {T(v) : v∈V} — always a subspace of the codomain.

Rank-Nullity Theorem

dim(V) = rank(T) + nullity(T) — kernel and image dimensions always add up to the domain's dimension.

Similar Matrices

A′ = P⁻¹AP for some invertible P — the relationship between any two matrix representations of the same operator.

Unit 4 — Eigentheory Revisited Rigorously

Algebraic Multiplicity

An eigenvalue's multiplicity as a root of the characteristic polynomial.

Geometric Multiplicity

dim(Eλ) — always between 1 and the algebraic multiplicity, never more.

Diagonalizability Criterion

T is diagonalizable exactly when geometric multiplicity equals algebraic multiplicity for every eigenvalue.

Generalized Eigenspace

Kλ = ⋃ₖker((T−λI)ᵏ) — recovers exactly the dimension an ordinary eigenspace can fall short of.

Unit 5 — Inner Product Spaces

Inner Product

A function ⟨·,·⟩ satisfying symmetry, bilinearity, and positive-definiteness — generalizes the dot product.

Cauchy-Schwarz Inequality

|⟨u,v⟩| ≤ ‖u‖‖v‖, with equality exactly when u,v are linearly dependent.

Gram-Schmidt Process

Converts any independent set into an orthogonal one, spanning the same subspaces at every stage.

Orthogonal Complement

W⊥ = {v : ⟨v,w⟩=0 for all w∈W} — together with W, splits V exactly: V = W ⊕ W⊥.

Projection Theorem

The closest point to v inside a subspace W is exactly v's own component in W, from the W⊕W⊥ decomposition.

Unit 6 — Spectral Theory

Adjoint

T* — the operator satisfying ⟨T(v),w⟩=⟨v,T*(w)⟩ for all v,w.

Self-Adjoint (Hermitian)

T* = T — guarantees real eigenvalues, and orthogonal eigenvectors for distinct eigenvalues.

Spectral Theorem

Every self-adjoint operator has a full orthonormal eigenbasis — diagonalization is never blocked.

Singular Value Decomposition (SVD)

A = UΣVᵀ for any matrix A, built from the Spectral Theorem applied to AᵀA.

Unit 7 — Jordan Form and Capstone

Nilpotent Operator

N with Nᵏ=0 for some k — its only possible eigenvalue is 0.

Nilpotent Chain

{v,Nv,…,N^(k−1)v} with N^(k−1)v≠0 — always linearly independent, and the seed of one Jordan block.

Jordan Block

Jk(λ) — λ on the diagonal, 1 on the superdiagonal, 0 elsewhere.

Jordan Canonical Form

The block-diagonal matrix of Jordan blocks every operator (with a splitting characteristic polynomial) is similar to.

Quadratic Form

Q(x)=xᵀAx for symmetric A — diagonalizes into Σλᵢyᵢ² via the Principal Axis Theorem.
