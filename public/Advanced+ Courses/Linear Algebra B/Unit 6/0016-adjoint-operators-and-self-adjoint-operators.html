Adjoint Operators and Self-Adjoint Operators

Symmetric matrices behave better than generic ones under an inner product — real eigenvalues, orthogonal eigenvectors, guaranteed. This lesson names the reason: they equal their own adjoint.

← Lesson 15 Lesson 17 → Contents Glossary →

Linear Algebra A never singled out symmetric matrices as special for eigenvalues. This lesson proves exactly why they are: a symmetric matrix is its own adjoint, and that single algebraic fact forces both real eigenvalues and orthogonal eigenvectors.

1. The adjoint operator

Definition — Adjoint For an operator T: V → V on a finite-dimensional inner product space, the adjoint T* is the operator satisfying ⟨T(v),w⟩ = ⟨v,T*(w)⟩ for all v, w ∈ V.
Theorem — T* Exists, Is Unique, and Is [T]ᵀ in an Orthonormal Basis T* exists and is unique. Relative to any orthonormal basis, [T*] = [T]ᵀ (real case) — the matrix transpose.
Proof Existence: fix an orthonormal basis; in it, ⟨v,w⟩ is just the dot product of coordinate vectors (orthonormal bases make this identification exact). Define S by [S] = [T]ᵀ. Then ⟨T(v),w⟩ = ([T]v)·w = v·([T]ᵀw) = ⟨v,S(w)⟩, using the standard matrix identity (Ax)·y = x·(Aᵀy). So S satisfies the defining property — T* exists, with matrix [T]ᵀ.

Uniqueness: suppose S₁, S₂ both satisfy ⟨v,Sᵢ(w)⟩=⟨T(v),w⟩ for all v. Subtracting: ⟨v, S₁(w)−S₂(w)⟩ = 0 for every v. Taking v = S₁(w)−S₂(w) gives ‖S₁(w)−S₂(w)‖² = 0, so S₁(w)=S₂(w) by positive-definiteness. This holds for every w, so S₁=S₂. ∎

2. Self-adjoint (symmetric / Hermitian) operators

Definition — Self-Adjoint T is self-adjoint if T* = T, i.e. ⟨T(v),w⟩ = ⟨v,T(w)⟩ for all v, w. Relative to an orthonormal basis, this means A = Aᵀ over ℝ (symmetric) or A = A* (conjugate transpose) over ℂ (Hermitian).

3. Two guaranteed facts about self-adjoint operators

Theorem — Eigenvalues Are Real Every eigenvalue of a self-adjoint operator is real, even when eigenvectors are sought over ℂ.
Proof Using the Hermitian inner product ⟨u,w⟩ = u·w (linear in the first slot, conjugate-linear in the second — the standard convention that makes ⟨v,v⟩ real and positive), suppose T(v)=λv with v≠0. On one hand, ⟨T(v),v⟩ = ⟨λv,v⟩ = λ⟨v,v⟩ = λ‖v‖² (linearity in the first slot). On the other, self-adjointness gives ⟨T(v),v⟩ = ⟨v,T(v)⟩ = ⟨v,λv⟩ = λ⟨v,v⟩ = λ‖v‖² (conjugate-linearity in the second slot). Equating: λ‖v‖² = λ‖v‖². Since v≠0, ‖v‖²>0, so λ = λ — meaning λ is real. ∎
Theorem — Eigenvectors for Distinct Eigenvalues Are Orthogonal If T is self-adjoint with T(v₁)=λ₁v₁, T(v₂)=λ₂v₂, and λ₁≠λ₂, then ⟨v₁,v₂⟩=0.
Proof λ₁⟨v₁,v₂⟩ = ⟨T(v₁),v₂⟩ = ⟨v₁,T(v₂)⟩ (self-adjointness) = ⟨v₁,λ₂v₂⟩ = λ₂⟨v₁,v₂⟩ = λ₂⟨v₁,v₂⟩ (λ₂ is real, by the previous theorem). So (λ₁−λ₂)⟨v₁,v₂⟩ = 0. Since λ₁≠λ₂, ⟨v₁,v₂⟩ = 0. ∎
Why this is stronger than Lesson 10's independence theorem Lesson 10 proved eigenvectors of distinct eigenvalues are independent, for any operator. This theorem proves something strictly stronger for self-adjoint operators specifically: not merely independent, but exactly orthogonal — no Gram-Schmidt step required to make them so. This is the fact Lesson 17's Spectral Theorem builds an entire orthonormal eigenbasis from.
Worked Example — Real Eigenvalues and Orthogonal Eigenvectors A = [[5,2],[2,5]] is symmetric. Characteristic polynomial: (5−λ)²−4 = λ²−10λ+21 = (λ−7)(λ−3) — both real roots, as guaranteed. For λ=7: (A−7I) = [[−2,2],[2,−2]], giving eigenvector (1,1). For λ=3: (A−3I) = [[2,2],[2,2]], giving eigenvector (1,−1). Check orthogonality: ⟨(1,1),(1,−1)⟩ = 1−1 = 0. ✓ — exactly as the theorem guarantees, with no extra work needed.

1. In the proof that T* exists, what identity is used to show [T]ᵀ satisfies the defining adjoint property?

This dot-product identity is exactly what translates ⟨T(v),w⟩ into ⟨v,S(w)⟩ for S with matrix [T]ᵀ — no assumption that A is invertible or symmetric is used.

2. In the proof that eigenvalues of a self-adjoint operator are real, what does equating ⟨T(v),v⟩ computed two ways actually show?

Computing ⟨T(v),v⟩ via linearity in the first slot gives λ‖v‖²; via self-adjointness and conjugate-linearity in the second slot gives conj(λ)‖v‖² — equating and dividing by the positive ‖v‖² forces λ real.

3. Fill in the blank: the orthogonality proof concludes (λ₁−λ₂)⟨v₁,v₂⟩ = 0; since λ₁≠λ₂, this forces ⟨v₁,v₂⟩ = ___.

Since λ₁−λ₂≠0, the only way the product can be 0 is if ⟨v₁,v₂⟩ itself is 0 — exactly orthogonality.

4. For A=[[5,2],[2,5]], what are the eigenvalues?

det(A−λI) = (5−λ)²−4 = λ²−10λ+21 = (λ−7)(λ−3), giving eigenvalues 7 and 3.

5. For the eigenvectors (1,1) and (1,−1) of A=[[5,2],[2,5]], ⟨(1,1),(1,−1)⟩ = ___.

1(1) + 1(−1) = 0 — the two eigenvectors are orthogonal, exactly as guaranteed for a symmetric matrix's distinct eigenvalues.
