Span, Independence, and the Existence of a Basis

Linear Algebra A asserted that a basis gives every vector exactly one representation, and never proved that a basis exists at all. Both get proved here.

← Lesson 2 Lesson 4 → Contents Glossary →

Two facts from Linear Algebra A were used constantly but never proved: that a basis represents every vector uniquely, and that a basis exists in the first place — you were only ever handed one (usually the standard basis) rather than shown one could always be found. This lesson proves both, for any finite-dimensional vector space over any field.

1. Span is the smallest subspace containing a set

Definition — Span For a subset S = {v₁, …, vk} of a vector space V, span(S) is the set of every linear combination c₁v₁ + ⋯ + ckvk, with c₁, …, ck ∈ F.
Theorem — span(S) Is the Smallest Subspace Containing S span(S) is a subspace of V, and if W is any subspace with S ⊆ W, then span(S) ⊆ W.
Proof span(S) is a subspace: it contains 0 (take every cᵢ = 0), and it's closed under addition and scalar multiplication, since a sum of two linear combinations of S is again a linear combination of S, and scaling a linear combination of S by a is again one (distribute a across each cᵢvᵢ term). By the Subspace Test, span(S) is a subspace.

Minimality: suppose W is a subspace with S ⊆ W. Since W is closed under addition and scalar multiplication, any linear combination c₁v₁ + ⋯ + ckvk of vectors already in W must itself be in W. So every element of span(S) is in W — span(S) ⊆ W. ∎

2. A basis gives unique coordinates

Linear independence keeps its Linear Algebra A definition unchanged: v₁, …, vk are linearly independent if the only solution to c₁v₁ + ⋯ + ckvk = 0 is c₁ = ⋯ = ck = 0. A basis is still an independent spanning set. What Linear Algebra A never proved is why that combination is exactly what makes representations unique.

Theorem — Uniqueness of Basis Representation If B = {v₁, …, vn} is a basis for V, every vector v ∈ V can be written as v = c₁v₁ + ⋯ + cnvn for exactly one choice of scalars c₁, …, cn.
Proof Existence: B spans V, so some choice of scalars works — that's the definition of span.

Uniqueness: suppose v = c₁v₁ + ⋯ + cnvn and also v = d₁v₁ + ⋯ + dnvn. Subtracting, 0 = (c₁ − d₁)v₁ + ⋯ + (cn − dn)vn. Since B is linearly independent, the only solution to this is the trivial one: cᵢ − dᵢ = 0 for every i, i.e. cᵢ = dᵢ for every i. So the two representations were identical all along. ∎
Why independence, specifically, is what forces uniqueness Spanning alone guarantees a representation exists; it says nothing about how many. It's independence — applied to the difference of two hypothetical representations — that collapses "a representation" into "the one and only representation." This is exactly why a basis needs both properties together, and why coordinates relative to a basis (Lesson 6) are well-defined at all.

3. Existence: every finite spanning set contains a basis

A vector space is finite-dimensional if it has a finite spanning set. (Pn(ℝ) and Mm×n(ℝ) both qualify; C[a, b] does not — no finite set of continuous functions spans all of it.) The theorem below is what guarantees a basis exists at all, for any finite-dimensional space.

Theorem — The Reduction Theorem If S = {v₁, …, vm} spans V, then some subset of S is a basis for V.
Proof If S is already linearly independent, S itself is a basis (independent and spanning) — done. Otherwise, S is dependent, so some nontrivial combination c₁v₁ + ⋯ + cmvm = 0 exists with some cⱼ ≠ 0. Solve for vⱼ: vⱼ = −(1/cⱼ)(sum of the other terms), so vⱼ is a linear combination of the remaining vectors. Remove vⱼ from S to form S′ — the span is unchanged, since anywhere vⱼ was used in a combination, its own expression in terms of the rest of S′ can be substituted in instead. S′ still spans V, with one fewer vector.

Repeat: if S′ is independent, stop — it's a basis. Otherwise remove another redundant vector the same way. Since S is finite, this process must terminate after at most m − 1 removals (it cannot remove every vector, since a spanning set for a nonzero space can't shrink to ∅ and still span; if V = {0}, the process correctly terminates at the empty set, which is the basis for the zero space by convention). Whatever set remains when the process stops is independent and still spans V — a basis. ∎
Why this settles existence for good Every finite-dimensional space has, by definition, at least one finite spanning set. The Reduction Theorem turns that single spanning set into an actual basis by construction — deleting exactly the redundant vectors span already flagged. Combined with Lesson 4's proof that every basis has the same size, "the dimension of V" is now a fully justified, well-defined number for any finite-dimensional space, not just ℝⁿ.
Worked Example — Reducing a Spanning Set of P₂(ℝ) Let S = {1, x, 2 + x, x²} — does it span P₂(ℝ), and if so, find a basis inside it. S spans P₂(ℝ) since 1, x, x² alone already reach every polynomial a + bx + cx². Is S independent? Check: 2 + x is itself a combination of the other two: 2 + x = 2(1) + 1(x). So c₁(1) + c₂(x) + c₃(2+x) + c₄(x²) = 0 has the nontrivial solution c₁ = 2, c₂ = 1, c₃ = −1, c₄ = 0 — S is dependent. Removing 2 + x (the vector solved for) leaves {1, x, x²}, which is independent and still spans P₂(ℝ) — a basis, recovered from a redundant spanning set exactly as the Reduction Theorem's proof describes.

Check your recall

No peeking back up — answer from memory first, then check.

1. In the proof that span(S) is the smallest subspace containing S, what does the minimality half of the proof actually show?

Since W is closed under the vector space operations and contains S, it's forced to contain every linear combination of S's vectors — which is exactly span(S) — regardless of whether S is independent or W is finite-dimensional.

2. In the proof of uniqueness of basis representation, what step is taken after assuming v has two representations, c₁v₁+⋯+cₙvₙ and d₁v₁+⋯+dₙvₙ?

Subtracting the two representations produces a combination of the basis vectors equal to 0; linear independence then forces every coefficient (cᵢ − dᵢ) to be 0, proving the two representations were identical.

3. Fill in the blank: spanning alone guarantees a representation exists; it is ___ that forces there to be only one.

Applying independence to the difference of two hypothetical representations is exactly what collapses them into a single, unique representation.

4. In the Reduction Theorem's proof, once a dependent relation c₁v₁+⋯+cₘvₘ = 0 is found with some cⱼ ≠ 0, why is it safe to remove vⱼ from S without shrinking the span?

Because vⱼ is redundant — expressible using the rest of S — every combination that used vⱼ can be rewritten without it, so the span is exactly preserved by the removal.

5. Fill in the blank: the Reduction Theorem guarantees a basis exists for every ___ vector space — one with at least one finite spanning set.

Finite-dimensional is defined exactly as "has a finite spanning set" — precisely the hypothesis the Reduction Theorem needs to construct a basis.
