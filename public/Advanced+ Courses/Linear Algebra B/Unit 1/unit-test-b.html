1. Which of the following best states vector space axiom (5), a(u + v) = au + av?

Axiom (5) distributes a single scalar across a sum of two vectors. Axiom (6) is the similar-looking rule for a sum of two scalars, (a+b)v = av+bv — a common mix-up.

2. Fill in the blank: the proof that the zero vector is unique considers two additive identities 0 and 0′, and evaluates the single expression 0 + 0′ in ___ different ways.

Treating 0′ as the identity gives 0 + 0′ = 0; treating 0 as the identity gives 0 + 0′ = 0′ — the same expression evaluated two different ways forces 0 = 0′.

3. Is Diag₂ = {A ∈ M₂(ℝ) : A is diagonal} a subspace of M₂(ℝ)?

The zero matrix has every entry 0, including off-diagonal ones, so it's diagonal; sums and scalar multiples of diagonal matrices stay diagonal. (Matrix products aren't relevant — the subspace test only checks addition and scalar multiplication.)

4. Let W = {p ∈ P₂(ℝ) : p(1) = 1}. Since the zero polynomial satisfies 0(1) = 0 ≠ 1, W fails the subspace test because it does not contain the ___.

Condition (i) requires 0 ∈ W; since the zero polynomial isn't in W, the subspace test already fails, regardless of the other two conditions.

5. Why does the proof that span(S) is the smallest subspace containing S need both halves — "span(S) is a subspace" and "any subspace containing S contains span(S)"?

"Smallest" is a two-part claim — being a subspace at all, and being contained in every other subspace that contains S — so both directions of the proof are genuinely necessary.

6. Prove that −(−v) = v for any vector v, using the definition of additive inverse and the uniqueness result from Question 6 of Version A's logic. Answer both parts:

(a) Which fact establishes that v itself acts as an additive inverse of −v?

(b) Fill in the blank: because v satisfies the defining equation for an inverse of −v, and additive inverses are ___, it follows that −(−v) = v.

(a) v + (−v) = 0 combined with commutativity shows v also satisfies (−v) + v = 0, the defining property of an inverse of −v. (b) Since inverses are unique, v must be exactly −(−v).

7. Let U = {p ∈ P₂(ℝ) : p(1) = 0}. Answer both parts:

(a) Which subspace-test condition does U satisfy first, and why?

(b) For p(x) = x² − 1 and q(x) = 2x − 2 (both in U, since p(1) = 0 and q(1) = 0), (p+q)(x) = x² + 2x − 3. Fill in the blank: (p+q)(1) = ___.

(a) The zero polynomial vanishes everywhere, including at 1, satisfying condition (i) immediately. (b) (p+q)(1) = 1 + 2 − 3 = 0, confirming U is closed under addition here.

8. Let S = {2, x−1, x+3} ⊂ P₁(ℝ). Answer both parts about applying the Reduction Theorem:

(a) Which nontrivial relation shows S is linearly dependent?

(b) Removing the redundant vector x+3 leaves {2, x−1}, which is independent and still spans P₁(ℝ). Fill in the blank: {2, x−1} is therefore a ___ for P₁(ℝ).

(a) Expanding 2(2) + (x−1) − (x+3) = 4 + x − 1 − x − 3 = 0, a nontrivial relation. (b) An independent spanning set is exactly the definition of a basis.

9. Given that B = {1, x, 1+x+x²} is a basis for P₂(ℝ), answer both parts about writing p(x) = 5 + 2x + 3x² as c₁(1) + c₂(x) + c₃(1+x+x²):

(a) What is c₁?

(b) Fill in the blank: since B is linearly independent, this is the ___ representation of p(x) possible.

(a) Matching coefficients: c₁(1)+c₂(x)+c₃(1+x+x²) = (c₁+c₃) + (c₂+c₃)x + c₃x². Comparing to 5+2x+3x² gives c₃ = 3, then c₂ = 2−3 = −1, and c₁ = 5−3 = 2. (b) Independence of B is exactly what forces this to be the only representation.

10. Consider the Reduction Theorem's proof mechanics on a spanning set S = {v₁, v₂, v₃} of a space V, where the dependency 0v₁ + 3v₂ − v₃ = 0 holds (v₁'s coefficient is 0). Answer both parts:

(a) Which vector can validly be removed from S by the theorem's argument, and why?

(b) Fill in the blank: solving 3v₂ − v₃ = 0 for v₃ gives v₃ = ___v₂.

(a) A coefficient of 0 gives no way to isolate v₁ in the relation, so only v₂ or v₃ can be solved for. (b) 3v₂ = v₃, so v₃ = 3v₂.
