Subspaces and the Abstract Subspace Test

Linear Algebra A's subspace test worked because ℝⁿ's axioms are "free" for any subset. This lesson proves that's true of any vector space, not just ℝⁿ — the three-condition test transfers unchanged.

← Lesson 1 Lesson 3 → Contents Glossary →

Linear Algebra A's Lesson 3 gave the subspace test for subsets of ℝⁿ, with a "why" box hand-waving that the other seven axioms "come along for free." This lesson proves that claim as an actual theorem, for a subset of any vector space V over any field F — not just ℝⁿ.

1. The definition, restated for general V

Definition — Subspace A subset W of a vector space V is a subspace of V if W is itself a vector space under V's addition and scalar multiplication, restricted to W.

2. The subspace test, proved

Theorem — The Subspace Test A nonempty subset W of a vector space V (over a field F) is a subspace of V if and only if: (i) 0 ∈ W, (ii) u, w ∈ W ⟹ u + w ∈ W (closed under addition), and (iii) u ∈ W, a ∈ F ⟹ au ∈ W (closed under scalar multiplication).
Proof (⟹) If W is a subspace, it's a vector space, so it has its own zero vector 0W and is closed under its own addition and scalar multiplication — that's exactly (i)–(iii), once 0W = 0 is confirmed. (It is: 0W + 0W = 0W inside W, and adding −0W, computed in V, to both sides gives 0W = 0.)

(⟸) Suppose W satisfies (i)–(iii); check all eight vector space axioms hold for W. Axioms (1), (2), (5), (6), (7), (8) are equalities that hold for every vector in V — since every element of W is in particular an element of V, they hold automatically for elements of W too. That leaves only (3) and (4): (3) holds because (i) puts 0 in W directly, and it still acts as an identity since it does so in all of V. (4): for any v ∈ W, (iii) with a = −1 gives (−1)v ∈ W, and Lesson 1 proved (−1)v = −v — so −v ∈ W, giving W its additive inverses. Together with closure (ii)–(iii) making + and · well-defined operations on W itself, all eight axioms hold, so W is a vector space, hence a subspace of V. ∎
Why only two axioms needed real work Six of the eight axioms are universally-quantified equalities ("for all u, v, w…") — true throughout V, so automatically true on any subset. Only "does W actually contain 0" and "can + and · even be performed inside W without leaving it" can fail for a subset. That's the entire content of the theorem, and it's exactly as true for Pn(ℝ) or Mm×n(ℝ) as it was for ℝⁿ — nothing in the proof above referenced coordinates.

3. Worked examples in non-ℝⁿ spaces

Example — Symmetric Matrices Let Symn = {A ∈ Mn(ℝ) : Aᵀ = A} (matrices equal to their own transpose). Check the test: (i) the zero matrix satisfies 0ᵀ = 0. (ii) If Aᵀ = A and Bᵀ = B, then (A + B)ᵀ = Aᵀ + Bᵀ = A + B, so A + B ∈ Symn. (iii) (cA)ᵀ = cAᵀ = cA, so cA ∈ Symn. All three hold — Symn is a subspace of Mn(ℝ).
Example — Functions Vanishing at a Point Let W = {f ∈ C[0, 1] : f(0) = 0}. (i) The zero function satisfies 0(0) = 0. (ii) If f(0) = 0 and g(0) = 0, then (f + g)(0) = f(0) + g(0) = 0. (iii) (cf)(0) = c·f(0) = 0. W is a subspace of C[0, 1]. Contrast this with {f ∈ C[0, 1] : f(0) = 1} — that set fails (i) immediately (the zero function has 0(0) = 0 ≠ 1), so it's not a subspace, even though it looks similar.
Non-Example — Invertible Matrices GLn(ℝ), the invertible n×n matrices, is not a subspace of Mn(ℝ): condition (i) already fails, since the 0 matrix is never invertible. (It also fails closure under addition — I and −I are both invertible, but I + (−I) = 0 is not.)

Check your recall

No peeking back up — answer from memory first, then check.

1. In the proof that conditions (i)–(iii) imply W is a subspace, why do axioms like commutativity (u + v = v + u) need no separate check for W?

Six of the eight vector space axioms hold for every vector in V, unconditionally — so they hold for any subset's vectors automatically. Only containing 0 and staying closed under the two operations can actually fail.

2. Is Sym₂ = {A ∈ M₂(ℝ) : Aᵀ = A} a subspace of M₂(ℝ)?

(A+B)ᵀ = Aᵀ + Bᵀ = A + B whenever A and B are symmetric, so the sum stays symmetric — and the zero matrix is trivially symmetric, so all three conditions hold.

3. Fill in the blank: the set of ___ n×n matrices fails to be a subspace of Mₙ(ℝ) because the zero matrix is never one of them.

GLₙ(ℝ), the invertible matrices, fails condition (i) of the subspace test immediately — the zero matrix has determinant 0, so it's never invertible.

4. Is W = {f ∈ C[0, 1] : f(0) = 1} a subspace of C[0, 1]?

Condition (i) of the subspace test fails outright: the zero function isn't in W, since it sends 0 to 0, not 1. (It also fails closure — adding two functions with f(0) = g(0) = 1 gives (f+g)(0) = 2 ≠ 1.)

5. Fill in the blank: in the proof that subspace conditions (i)–(iii) are sufficient, axiom (4) — every vector has an additive inverse — follows from condition (iii) applied with scalar a = −1, combined with Lesson 1's proof that (−1)v = −v, together with condition (i) supplying ___ to start from.

Axiom (3) — that 0 itself is in W and acts as the identity — is what condition (i) directly supplies; axiom (4) then follows from closure under scalar multiplication by −1.
