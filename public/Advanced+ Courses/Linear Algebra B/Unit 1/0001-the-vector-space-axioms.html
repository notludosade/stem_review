The Vector Space Axioms

Linear Algebra A worked entirely inside ℝⁿ. This course starts by naming exactly what ℝⁿ's addition and scalar multiplication rules have in common with polynomials, matrices, and functions — as axioms, stated once and used everywhere after.

Lesson 2 → Contents Glossary →

Linear Algebra A's Lesson 3 defined a vector space in one loose sentence — "a set closed under addition and scalar multiplication, obeying the algebra rules you already rely on" — and then never left ℝⁿ again. That was a deliberate shortcut: every fact that course proved was really a fact about ℝⁿ specifically, verified by direct computation on components. This course drops the shortcut. The axioms below are the actual rules, stated in full, and every later theorem in this course is proved from them alone — which means every proof works identically whether the vectors are tuples of numbers, polynomials, matrices, or functions.

1. Working over a field

Definition — Field A field F is a set with two operations, + and ·, such that both are commutative and associative, · distributes over +, F has an additive identity 0 and multiplicative identity 1 (0 ≠ 1), every element has an additive inverse, and every nonzero element has a multiplicative inverse.

ℝ and ℂ are the two fields this course uses; ℚ works too, though it rarely comes up. "Scalar" always means "element of the field F currently in use." Nothing below cares which field F actually is — only that it satisfies these rules — so every proof transfers to ℝ, ℂ, or any other field without changes.

2. The vector space axioms, in full

Definition — Vector Space A vector space over a field F is a set V with an addition + : V × V → V and a scalar multiplication · : F × V → V satisfying, for all u, v, w ∈ V and a, b ∈ F:
(1) u + v = v + u (commutativity)
(2) (u + v) + w = u + (v + w) (associativity)
(3) there is a vector 0 ∈ V with v + 0 = v for every v (additive identity)
(4) for every v there is a vector −v with v + (−v) = 0 (additive inverse)
(5) a(u + v) = au + av (scalar multiplication distributes over vector addition)
(6) (a + b)v = av + bv (scalar multiplication distributes over field addition)
(7) (ab)v = a(bv) (scalar multiplication is compatible with field multiplication)
(8) 1v = v, where 1 is F's multiplicative identity
Vector spaces beyond ℝⁿ Each of these satisfies all eight axioms, checked the same way ℝⁿ was: (a) Mm×n(ℝ), all m×n real matrices, under matrix addition and scalar multiplication; (b) Pn(ℝ), all real polynomials of degree ≤ n, under ordinary addition and scalar multiplication of polynomials; (c) C[a, b], all continuous real-valued functions on [a, b], under pointwise addition (f + g)(x) = f(x) + g(x); (d) ℂⁿ over the field ℂ itself. None of these look like tuples of numbers, yet every proof that only uses axioms (1)–(8) applies to all four without modification.

3. Two consequences, proved directly from the axioms

The axioms don't mention "0 is unique" or "0v = 0" — those get proved, not assumed. Doing so once here, from nothing but (1)–(8), is the whole discipline this course runs on.

Claim — The Zero Vector Is Unique A vector space has only one additive identity.
Proof Suppose 0 and 0′ are both additive identities. Since 0′ is an identity, 0 + 0′ = 0. Since 0 is an identity, 0 + 0′ = 0′. The left-hand sides are literally the same expression, so 0 = 0 + 0′ = 0′. ∎
Claim — 0v = 0 and (−1)v = −v For any vector v: the scalar 0 times v equals the zero vector, and the scalar −1 times v equals v's additive inverse.
Proof Since 0 + 0 = 0 in F, axiom (6) gives 0v = (0 + 0)v = 0v + 0v. Add −(0v) (which exists by axiom (4)) to both sides: 0v + (−(0v)) = 0v + 0v + (−(0v)), so 0 = 0v. That proves the first claim. For the second, axiom (6) and the first claim give v + (−1)v = 1v + (−1)v = (1 + (−1))v = 0v = 0 — so (−1)v is an additive inverse of v. By axiom (4) v already has an additive inverse −v, and the same uniqueness argument as above (applied to inverses instead of identities) shows an inverse is unique, so (−1)v = −v. ∎
Why bother proving something this obvious Both proofs use only axioms (1)–(8) — no coordinates, no components, nothing specific to ℝⁿ. That means both facts are automatically true in Mm×n(ℝ), in Pn(ℝ), in C[a, b] — anywhere the axioms hold. This is the entire payoff of working from axioms instead of examples: prove it once, get it everywhere, permanently.

Check your recall

No peeking back up — answer from memory first, then check.

1. Which of the following is one of the eight vector space axioms?

The existence of an additive identity is axiom (3). A "multiplicative inverse for vectors" and "vector-times-vector" aren't part of the vector space axioms at all — those are field concepts, or not defined here.

2. Which of the following is a vector space over ℝ?

P₃(ℝ) satisfies all eight axioms directly. The invertible matrices fail axiom (3) — the 0 matrix isn't invertible — and aren't even closed under addition (I + (−I) = 0). The positive-first-coordinate set and the unit circle both lack a zero vector and fail closure.

3. Fill in the blank: the proof that 0v = 0 starts from 0 + 0 = 0 in the field, then applies the ___ law (axiom 6) to turn 0v into 0v + 0v.

Axiom (6), (a + b)v = av + bv, is exactly what turns (0 + 0)v into 0v + 0v — the distributive law over field addition.

4. In the proof that a vector space's zero vector is unique, suppose 0 and 0′ are both additive identities. What is the key step?

Evaluating the single expression 0 + 0′ two different ways — once treating 0′ as the identity, once treating 0 as the identity — forces 0 = 0′ directly, with no contradiction argument needed.

5. Fill in the blank: for any vector v, (−1)v equals ___, the additive inverse of v.

v + (−1)v = 1v + (−1)v = (1 + (−1))v = 0v = 0, so (−1)v satisfies the defining property of −v, and additive inverses are unique.
