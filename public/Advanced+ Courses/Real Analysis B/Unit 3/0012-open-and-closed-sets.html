Open and Closed Sets

A metric alone is enough to build the entire vocabulary of open sets, closed sets, and limit points — with no reference to numbers, only to distance.

← Lesson 11 Lesson 13 → Contents Glossary →

Definition — Open Ball In a metric space (X, d), the open ball of radius r > 0 around a point x is B(x, r) = {y ∈ X : d(x,y) < r}.
Definition — Open Set, Neighborhood A set U ⊆ X is open if for every x ∈ U, there is some r > 0 with B(x, r) ⊆ U. An open set containing x is called a neighborhood of x.
Theorem — Every Open Ball Is Open For any x ∈ X and r > 0, the set B(x, r) is open.
Proof Let y ∈ B(x, r), so d(x,y) < r. Let r' = r − d(x,y) > 0. For any z ∈ B(y, r'), the triangle inequality gives d(x,z) ≤ d(x,y) + d(y,z) < d(x,y) + r' = r. So z ∈ B(x,r), meaning B(y, r') ⊆ B(x, r). Since y was an arbitrary point of B(x,r), this shows every point of B(x,r) has a ball around it contained in B(x,r) — B(x,r) is open. ∎
Why this proof is pure Lesson 11 The only property of d used is the triangle inequality — the exact same move Lesson 11 flagged as doing most of the work. This is the pattern for the rest of the unit: definitions built from d, proofs built from the three metric axioms, nothing else.
Definition — Limit Point, Closed Set A point x ∈ X is a limit point of a set E ⊆ X if every ball B(x, r) contains a point of E other than x itself. A set E is closed if its complement X\E is open.
Theorem — Closed Sets Are Exactly the Sets Containing All Their Limit Points E is closed if and only if E contains every one of its limit points.
Proof (⇐) Suppose E contains all its limit points, and let x ∈ X\E. Since x ∉ E and E contains all its limit points, x cannot itself be a limit point of E — so some ball B(x,r) contains no point of E, i.e. B(x,r) ⊆ X\E. Since x was arbitrary, X\E is open, so E is closed.

(⇒) Suppose E is closed, i.e. X\E is open, and let x be a limit point of E. If x ∉ E, then x ∈ X\E, which is open, so some B(x,r) ⊆ X\E — meaning B(x,r) contains no point of E at all. This contradicts x being a limit point of E, which requires every ball around x to contain a point of E. So x ∈ E. ∎
Definition — Closure The closure of E, written Ē, is E together with all of its limit points.
Theorem — The Closure Is the Smallest Closed Set Containing E Ē is closed, and any closed set F with E ⊆ F satisfies Ē ⊆ F.
Proof sketch Ē contains all of E's limit points by construction, and one can check every limit point of Ē is already a limit point of E (any ball around such a point, shrunk slightly, still meets E), so Ē contains all its own limit points — closed, by the previous theorem. If F is closed and E ⊆ F, then F contains all its own limit points, and since every limit point of E is also a limit point of F (E ⊆ F), F must contain them too — so Ē = E ∪ {limit points of E} ⊆ F. ∎
Example: every set is clopen in the discrete metric In the discrete metric (Lesson 11), B(x, 1/2) = {x} for every x. So for any set U ⊆ X and any x ∈ U, the ball B(x, 1/2) = {x} ⊆ U — every set is open. Since every set is open, every complement is open too, which means every set is also closed. In a discrete metric space, every subset is simultaneously open and closed ("clopen") — a phenomenon impossible in ℝ with its usual metric, where only ∅ and ℝ itself are clopen.
Why this matters later Sets that are clopen turn out to be exactly the obstruction to a metric space being "connected" — Lesson 16 makes this precise. For now, the discrete example is a warning: intuition about open and closed sets built entirely from ℝ (where they feel like opposites) does not automatically transfer to every metric space.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does the proof that every open ball is open rely on?

The triangle inequality is exactly what bounds d(x,z) using d(x,y) and d(y,z), giving the shrunk radius that fits inside the original ball.

2. According to this lesson's theorem, when is a set E closed?

Closedness is equivalent to containing all limit points — a set with a limit point missing from itself cannot be closed.

3. What does the discrete metric example show about open and closed sets?

Since every singleton ball {x} is already contained in any set containing x, every set is open — and hence every set is closed too, since its complement is also open.

4. Fill in the blank: x is a ___ point of E if every ball around x contains a point of E other than x itself.

This is the definition of a limit point, the basis for the closed-set characterization.

5. Fill in the blank: E together with all of its limit points is called the ___ of E, and is the smallest closed set containing E.

The closure Ē is exactly E plus its limit points, and is shown to be the minimal closed set containing E.
