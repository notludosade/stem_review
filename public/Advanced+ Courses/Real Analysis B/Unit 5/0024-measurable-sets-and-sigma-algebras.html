Measurable Sets and Sigma-Algebras

Outer measure is defined on every subset of ℝ, but Lesson 23 warned it doesn't add up correctly on all of them. This lesson isolates exactly the sets where it does — and shows they form a rich, robust collection.

← Lesson 23 Lesson 25 → Contents Glossary →

Definition — Carathéodory Measurability E ⊆ ℝ is (Lebesgue) measurable if for every set A ⊆ ℝ (called a test set),

m*(A) = m*(A∩E) + m*(A\E).
Why this definition only really demands one direction Since A = (A∩E) ∪ (A\E), countable subadditivity (Lesson 23) already gives m*(A) ≤ m*(A∩E) + m*(A\E) for every set E and test set A, automatically. The Carathéodory criterion is really only asking for the reverse inequality — that splitting A along E never loses any outer measure to the split.
Theorem — Basic Closure Properties of Measurable Sets (a) ∅ and ℝ are measurable. (b) If E is measurable, so is Eᶜ. (c) If m*(E) = 0, then E is measurable. (d) If E and F are measurable, so is E∪F.
Proof (a) For any test set A: m*(A∩∅) + m*(A\∅) = 0 + m*(A) = m*(A). The same computation with ℝ in place of ∅ (using ℝᶜ = ∅) handles ℝ.

(b) The defining equation m*(A) = m*(A∩E) + m*(A\E) is literally symmetric under swapping E and Eᶜ, since A\E = A∩Eᶜ and A\Eᶜ = A∩E. So E satisfies the criterion exactly when Eᶜ does.

(c) By the why-box above, m*(A) ≤ m*(A∩E) + m*(A\E) always holds. If m*(E) = 0, monotonicity (Lesson 23) gives m*(A∩E) ≤ m*(E) = 0 and m*(A\E) ≤ m*(A). So m*(A∩E) + m*(A\E) ≤ 0 + m*(A) = m*(A), giving the reverse inequality too — equality holds, so E is measurable.

(d) Let A be any test set. Measurability of E gives m*(A) = m*(A∩E) + m*(A∩Eᶜ). Apply measurability of F to the test set A∩Eᶜ: m*(A∩Eᶜ) = m*(A∩Eᶜ∩F) + m*(A∩Eᶜ∩Fᶜ). Substituting, m*(A) = m*(A∩E) + m*(A∩Eᶜ∩F) + m*(A∩Eᶜ∩Fᶜ). Now (A∩E) ∪ (A∩Eᶜ∩F) = A∩(E∪F) (together these are exactly the parts of A lying in E, or in F but not E — which is all of A∩(E∪F)), so subadditivity gives m*(A∩E) + m*(A∩Eᶜ∩F) ≥ m*(A∩(E∪F)). Also A∩Eᶜ∩Fᶜ = A∩(E∪F)ᶜ exactly. Substituting these into the equation for m*(A) gives m*(A) ≥ m*(A∩(E∪F)) + m*(A∩(E∪F)ᶜ). Combined with the automatic reverse inequality, equality holds — so E∪F is measurable. ∎
Why property (c) already resolves ℚ Lesson 23 proved m*(ℚ) = 0. Property (c) here immediately gives that ℚ is measurable — not just "small" in outer measure, but a legitimate member of the collection integration will be built on in Unit 6.
Theorem — Half-Lines Are Measurable For every a ∈ ℝ, the set (a, ∞) is measurable.
Proof Let A ⊆ ℝ be any test set and ε > 0. Choose a countable cover {Iₙ} of A by open intervals with Σₙℓ(Iₙ) < m*(A) + ε. Each Iₙ, intersected with the point a, splits into at most two pieces: Iₙ∩(a,∞) and Iₙ∩(−∞,a], both intervals (possibly empty or degenerate), with ℓ(Iₙ) = ℓ(Iₙ∩(a,∞)) + ℓ(Iₙ∩(−∞,a]) exactly, since the two pieces partition Iₙ up to the single point a. The collection {Iₙ∩(a,∞)}ₙ covers A∩(a,∞), and {Iₙ∩(−∞,a]}ₙ covers A∩(−∞,a]. So

m*(A∩(a,∞)) + m*(A∩(−∞,a]) ≤ Σₙℓ(Iₙ∩(a,∞)) + Σₙℓ(Iₙ∩(−∞,a]) = Σₙℓ(Iₙ) < m*(A) + ε.

Since ε was arbitrary, m*(A∩(a,∞)) + m*(A\(a,∞)) ≤ m*(A). Combined with the automatic reverse inequality, (a,∞) is measurable. ∎
Why this one concrete proof matters This is the base case the whole theory of measurable sets builds on: once (a,∞) is known measurable, closure under complements and unions (the theorem above) immediately gives every interval — (−∞,a], (a,b), [a,b], and so on — measurable too, without repeating a cover-splitting argument for each one.
Definition — σ-Algebra A collection 𝔐 of subsets of ℝ is a σ-algebra if ∅ ∈ 𝔐, 𝔐 is closed under complements, and 𝔐 is closed under countable unions.
Theorem (stated) — The Measurable Sets Form a σ-Algebra The collection of Lebesgue measurable subsets of ℝ is a σ-algebra: it contains ∅, is closed under complements (proved above), and is closed under countable unions.
Why closure under countable unions is only stated here The finite case (property (d) above) already required chaining the Carathéodory criterion through two applications; extending it to a countably infinite union of measurable sets needs an additional argument — replacing the sets by an equivalent disjoint sequence, then taking a limit using continuity of outer measure along increasing unions. This is standard but adds real length without adding new ideas beyond what property (d)'s proof already demonstrates. The full argument is in the source reading below.
Where this leaves things: Borel sets and beyond Every open interval is measurable (an intersection of two measurable half-lines), and every open subset of ℝ is a countable union of open intervals — so every open set is measurable. The smallest σ-algebra containing all open sets is called the Borel σ-algebra; the theorem above shows every Borel set is Lebesgue measurable. The containment is strict: there exist Lebesgue measurable sets that are not Borel, and — recalling Lesson 23's Vitali sets — there exist subsets of ℝ that are not Lebesgue measurable at all. The Lebesgue measurable sets sit strictly between "the sets built from intervals in any reasonable way" and "every subset of ℝ."

1. What does the Carathéodory criterion require of a measurable set E?

E must split every possible test set without losing any outer measure in the split.

2. How does the proof that E∪F is measurable proceed?

Chaining the criterion through E and then F, then recombining the pieces via subadditivity, gives the needed equality for E∪F.

3. What is the key step in proving (a,∞) is measurable?

Splitting each cover interval at the single point a preserves total length exactly, which is what drives the inequality through.

4. Fill in the blank: the criterion m*(A) = m*(A∩E) + m*(A\E) for all test sets A is the ___ criterion for measurability.

Carathéodory is the standard name for this definition of measurability.

5. Fill in the blank: the smallest σ-algebra containing every open set is called the ___ σ-algebra.

Borel is the standard name for this σ-algebra, generated from open sets by complements and countable unions.
