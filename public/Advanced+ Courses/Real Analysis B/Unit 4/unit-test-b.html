1. Let f(x,y) = x²y³. What is ∂f/∂y(1,2)?

Freezing x and differentiating in y gives ∂f/∂y = 3x²y². At (1,2): 3·1·4 = 12. (∂f/∂x = 2xy³ = 16 at that point, a common mix-up.)

2. Let g(x,y) = xy²/(x²+y⁴) for (x,y) ≠ (0,0), and g(0,0) = 0. Answer both parts:

(a) What are ∂g/∂x(0,0) and ∂g/∂y(0,0)?

(b) Fill in the blank: along the path x = y², g(y²,y) = y⁴/(2y⁴) = 1/2 for every y ≠ 0, which does not approach g(0,0) = 0 — so g is ___ at the origin, despite both partials existing there.

(a) g(h,0) = 0/h² = 0 and g(0,k) = 0/k⁴ = 0 for every h,k ≠ 0, so both partials at the origin are 0. (b) Approaching along the parabola x = y² gives a limit of 1/2, not g(0,0) = 0, so g is discontinuous at the origin — again invisible to partials, which only probe the coordinate axes.

3. If f: ℝⁿ → ℝᵐ is differentiable at a with total derivative L = Df(a), which statement is guaranteed?

Differentiability means Lh is only the best linear approximation, with an error that vanishes faster than |h| — not an exact equality. That error condition (o(|h|)) is exactly what the defining limit encodes.

4. Suppose f: ℝ² → ℝ has partial derivatives everywhere, and they are continuous at (a,b). Answer both parts:

(a) Which theorem lets us conclude f is (totally) differentiable at (a,b)?

(b) Fill in the blank: this theorem's proof telescopes the increment f(a+h) − f(a) into single-variable increments and applies the ___ Value Theorem to each one.

(a) Continuity of the partial derivatives at the point is exactly the hypothesis this theorem needs. (b) Applying the single-variable Mean Value Theorem to each telescoped term, then using continuity of the partials to control the error, is the proof's core mechanism.

5. Let g(x,y) = (xy, x−y) and f(u,v) = u + v². Answer both parts about f∘g:

(a) What is Dg(2,1), the Jacobian matrix of g at (2,1)?

(b) Fill in the blank: by the chain rule, D(f∘g)(2,1) is a 1×2 row matrix. Its second entry equals ___.

(a) g's partials: ∂(xy)/∂x = y, ∂(xy)/∂y = x, ∂(x−y)/∂x = 1, ∂(x−y)/∂y = −1; at (2,1) this is [[1,2],[1,−1]]. (b) g(2,1) = (2,1), Df(u,v) = [1, 2v], so Df(2,1) = [1, 2]. D(f∘g)(2,1) = [1,2]·[[1,2],[1,−1]] = [3, 0] — the second entry, 0, matches direct differentiation of f∘g(x,y) = xy + (x−y)², whose ∂/∂y = x − 2(x−y) = 0 at (2,1).

6. In the special case n = m = k = 1, why does the Multivariable Chain Rule reduce exactly to (f∘g)′(a) = f′(g(a))·g′(a)?

When every space involved is ℝ, the Jacobian is a 1×1 matrix — an ordinary number — and matrix multiplication of two 1×1 matrices is exactly ordinary multiplication, recovering the familiar rule.

7. Let k(x,y) = x³y⁴. Answer both parts:

(a) What is ∂²k/∂x∂y at (1,2)?

(b) Fill in the blank: since k's mixed partials are polynomials, hence ___ everywhere, Clairaut's Theorem guarantees they agree, as this computation confirms.

(a) ∂k/∂y = 4x³y³, so ∂²k/∂x∂y = 12x²y³, which at (1,2) is 12·1·8 = 96. (Checking the other order: ∂k/∂x = 3x²y⁴, so ∂²k/∂y∂x = 12x²y³, the same expression.) (b) Polynomials are continuous everywhere, exactly the hypothesis Clairaut's Theorem needs.

8. What does Clairaut's Theorem require to guarantee ∂²f/∂x∂y = ∂²f/∂y∂x at a point?

Continuity of both mixed partials at the point is exactly the hypothesis Clairaut's proof uses to force the two limiting expressions for the second difference to agree.

9. Let f(x,y) = (2x−y, x+3y), a linear map. Answer both parts:

(a) What is det Df (the same everywhere, since f is linear)?

(b) Fill in the blank: since det Df ≠ 0 everywhere, the Inverse Function Theorem guarantees a local C¹ inverse near every point, with D(f⁻¹) equal to the matrix ___ of Df.

(a) Df = [[2,−1],[1,3]], so det Df = 2·3 − (−1)·1 = 6 + 1 = 7. (b) The Inverse Function Theorem gives D(f⁻¹)(f(a)) = [Df(a)]⁻¹ — the matrix inverse of the Jacobian.

10. Fill in the blank: given F(x,y) = 0 with ∂F/∂y ≠ 0 at (a,b), the formula g′(x) = −F_x/F_y for the implicitly defined function g comes from differentiating F(x,g(x)) = 0 using the ___ rule.

Applying the chain rule to F(x,g(x)) = 0 gives F_x + F_y·g′(x) = 0, which rearranges directly to the implicit differentiation formula.
