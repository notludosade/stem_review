1. Let A = {x ∈ ℝ : x³ < 5}. Is A bounded above?

2³ = 8 exceeds 5, so 2 bounds every element of A; since A is nonempty and bounded above, the Completeness Axiom guarantees sup A exists in ℝ (in fact sup A = 5^(1/3)), even though this value is irrational.

2. Fill in the blank: let aₙ be the partial sums of Σ1/2^k. The proof that Cauchy implies convergent first shows (aₙ) is bounded, then applies the ___ Theorem to extract a convergent subsequence before showing the whole sequence follows it.

Bolzano-Weierstrass is the pivotal middle step once boundedness of a Cauchy sequence is established.

3. Let K = {0} ∪ {1/n : n ∈ ℕ}. Is K compact?

Unlike {1/n} alone, K explicitly includes its missing limit point 0, making it closed as well as bounded — by Heine-Borel, closed and bounded means compact.

4. Fill in the blank: two equivalent tests for compactness were proved equivalent in this course — the sequential test (every sequence has a subsequence converging inside the set) and the ___ test (every collection of open sets covering the set has a finite subcollection that still covers it).

The open-cover test is the Heine-Borel characterization, proved equivalent to the sequential definition.

5. To prove limx→4 √x = 2 directly from the definition, which bound on |x−4| is used to control |√x − 2| = |x−4|/(√x+2)?

Restricting δ ≤ 1 keeps x within [3,5], bounding the denominator away from 0 — the standard trick for square-root limit proofs.

6. f is continuous on the compact interval [0,5]. Which theorem guarantees f attains an actual maximum value on [0,5]?

The Extreme Value Theorem supplies attainment of a maximum and minimum on a compact set; the Intermediate Value Theorem would then fill in every value between them.

7. Why can't the Mean Value Theorem be applied to f(x) = 1/x on [−1, 1]?

MVT's hypotheses require continuity on the closed interval; 1/x fails this at x = 0, so the theorem simply doesn't apply.

8. Fill in the blank: let f(x) = sin(x) on [0, π]. Since f(0) = f(π) = 0 and f is continuous and differentiable everywhere, Rolle's Theorem guarantees a point c where f′(c) = 0. That point is c = ___.

f′(x) = cos(x) = 0 at x = π/2, which lies in (0, π).

9. Let F(x) = ∫2x t² dt. What is F′(3)?

By FTC Part 1, F′(x) equals the integrand itself evaluated at x: F′(x) = x², so F′(3) = 9.

10. Consider ∫02 (3x² + 1) dx, using antiderivative G(x) = x³ + x. What is G(2) − G(0)?

G(2) = 8 + 2 = 10, G(0) = 0, so G(2) − G(0) = 10 — this evaluation shortcut, avoiding upper/lower sums entirely, is licensed by FTC Part 2.

11. The Cauchy Criterion (every Cauchy sequence of reals converges) fails for Cauchy sequences of rationals whose limit is irrational. This is because, like the Monotone Convergence Theorem, the Cauchy Criterion is really which axiom in disguise?

Both theorems ultimately trace back to completeness — the guarantee that ℝ has no gaps for a limit to fall through, a guarantee ℚ lacks.

12. Fill in the blank: for ∫12 (3x²)/(x³ + 1) dx, using u = x³ + 1 (so x = 1 → u = 2 and x = 2 → u = 9), the integral evaluates to ln(___) (simplify the fraction inside).

∫₂⁹ (1/u) du = ln|u| from 2 to 9 = ln9 − ln2 = ln(9/2).
