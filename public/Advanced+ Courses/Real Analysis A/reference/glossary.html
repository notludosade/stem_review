Unit 1 — Foundations

Field

A set with addition and multiplication satisfying the usual commutative, associative, distributive, and inverse laws — the algebraic skeleton ℝ shares with ℚ.

Ordered field

A field with a compatible order relation, letting "less than" interact sensibly with addition and multiplication — still shared by ℝ and ℚ alike.

Supremum (least upper bound)

The smallest of all upper bounds of a set — smaller than every other upper bound, yet still an upper bound itself.

Infimum (greatest lower bound)

The largest of all lower bounds of a set — the mirror image of the supremum.

Completeness Axiom

Every nonempty, bounded-above subset of ℝ has a least upper bound in ℝ — the one axiom ℚ lacks and ℝ has, underlying nearly every existence theorem in this course.

Archimedean Property

For any real number x, there is a natural number n greater than x — ℝ has no "infinite" elements, a direct consequence of completeness.

Density of ℚ in ℝ

Between any two distinct real numbers lies a rational number — the rationals are packed arbitrarily tightly throughout the real line.

Unit 2 — Sequences and Limits

Limit of a sequence

aₙ → L if for every ε > 0 there is an N such that n > N implies |aₙ − L| < ε — "gets close to" replaced by a checkable inequality, with the ε chosen first and N found in response.

Monotone Convergence Theorem

An increasing sequence bounded above converges, to its own supremum — completeness applied directly to sequences.

Subsequence

A sequence formed by selecting infinitely many terms from an original sequence, in their original order — any convergent sequence's subsequences all converge to the same limit.

Bolzano-Weierstrass Theorem

Every bounded sequence has a convergent subsequence — proved by repeated bisection, and guarantees only a convergent piece, not convergence of the whole sequence.

Cauchy sequence

A sequence whose terms eventually get arbitrarily close to each other, not to any pre-named limit — for real sequences, this turns out to be exactly equivalent to convergence.

Unit 3 — Topology of the Real Line

Open set

A set where every point has some ε-neighborhood entirely contained in the set — arbitrary unions of open sets are open, but only finite intersections are guaranteed to be.

Closed set

A set whose complement is open, equivalently a set containing all of its own limit points.

Limit point of a set

A point x such that some sequence in the set, other than x itself, converges to x — a set is closed exactly when it contains all its limit points.

Compact set

A set in which every sequence has a subsequence converging to a point still inside the set — by the Heine-Borel Theorem, exactly the closed and bounded subsets of ℝ.

Connected set

A set that cannot be split into two nonempty separated pieces — the connected subsets of ℝ with at least two points are exactly the intervals, the fact the Intermediate Value Theorem needs.

Unit 4 — Limits and Continuity of Functions

Functional limit (ε-δ)

limx→c f(x) = L if for every ε > 0 there is a δ > 0 such that 0 < |x − c| < δ implies |f(x) − L| < ε — δ plays the role a sequence limit's N once did.

Continuity at a point

f is continuous at a if limx→a f(x) = f(a) — the "0 <" restriction of the functional limit is dropped, since the function's actual value at a is now what matters.

Intermediate Value Theorem

A continuous function on [a,b] hits every value between f(a) and f(b) — proved from the fact that a continuous image of a connected set is connected.

Extreme Value Theorem

A continuous function on a compact set attains an actual maximum and minimum value, not merely a supremum and infimum.

Uniform continuity

A single δ works for a given ε across the entire domain at once, rather than a different δ being needed near each point — automatic for continuous functions on compact sets.

Unit 5 — Differentiation

Derivative

f′(a) = limx→a (f(x) − f(a))/(x − a) — exactly Unit 4's functional limit, applied to the difference quotient, with no new machinery required.

Rolle's Theorem

If f(a) = f(b), some interior point c has f′(c) = 0 — proved by locating the extremum the Extreme Value Theorem guarantees is attained.

Mean Value Theorem

Some interior point c has f′(c) equal to the average rate of change (f(b) − f(a))/(b − a) — reduces directly to Rolle's Theorem via an auxiliary function with the secant line subtracted off.

Zero derivative implies constant

If f′(x) = 0 everywhere on an interval, f is constant there — a direct corollary of the Mean Value Theorem, and the fact that later justifies "+C" in Unit 6's Fundamental Theorem of Calculus.

Unit 6 — Riemann Integration

Partition

A finite set of points a = x₀ < x₁ < ⋯ < xₙ = b dividing [a,b] into subintervals — refining a partition only ever raises lower sums and lowers upper sums.

Upper and lower sums

Sums of Mᵢ(xᵢ − xᵢ₋₁) and mᵢ(xᵢ − xᵢ₋₁), using the sup and inf of f on each subinterval — every lower sum is ≤ every upper sum, for any two partitions at all.

Riemann integral

The common value of the upper integral (inf of upper sums) and lower integral (sup of lower sums), when they coincide — otherwise f is simply not Riemann integrable.

Cauchy Criterion for Integrability

f is integrable iff for every ε > 0 some partition P has U(f,P) − L(f,P) < ε — a practical test avoiding the need to compute a sup/inf over every partition directly.

Fundamental Theorem of Calculus

Differentiation and integration are inverse operations: F(x) = ∫ₐˣ f has F′ = f (Part 1), and ∫ₐᵇ f = G(b) − G(a) for any antiderivative G (Part 2) — the single result this entire course was built toward.
