1. Why is it acceptable that the difference quotient (f(x) − f(a))/(x − a) is undefined at x = a itself, in the derivative's definition?

Unit 4, Lesson 19's "0 < |x−a|" clause is exactly what makes this work — the limit only cares about x near a, never at a itself.

2. Let f(x) = x² − 5x. Answer both parts:

(a) For x ≠ a, the difference quotient (f(x) − f(a))/(x − a) simplifies to which expression?

(b) Fill in the blank: taking the limit as x → a gives f′(a) = ___.

(a) f(x) − f(a) = (x²−a²) − 5(x−a) = (x−a)(x+a−5), so dividing by (x−a) leaves x+a−5. (b) The limit as x→a of x+a−5 is 2a−5.

3. Fill in the blank: the theorem "differentiable implies ___" is proved by writing f(x) − f(a) as the difference quotient times (x − a), which forces the product to 0 as x → a.

As x→a, the bracketed difference quotient → f′(a) and (x−a) → 0, so their product → 0, meaning f(x) → f(a) — exactly continuity at a.

4. Let f(x) = |x + 1|. Answer both parts:

(a) Is f differentiable at x = −1?

(b) Fill in the blank: the left-hand difference quotient approaches ___, while the right-hand difference quotient approaches 1.

(a) f is continuous at −1 but not differentiable there — the same corner behavior as |x| at 0. (b) For x < −1, (|x+1|−0)/(x+1) = −1; for x > −1, it equals 1 — the disagreement means the derivative doesn't exist at −1.

5. The cross term f(a)g(x), inserted and subtracted in the product rule's proof, mirrors which earlier technique?

Both proofs insert a cross term (aₙbₙ−AB = aₙ(bₙ−B)+B(aₙ−A) for sequences; the analogous split here for difference quotients) to isolate one function's own difference at a time.

6. Let f(x) = x² − 6x + 5 on [1, 5]. Answer both parts:

(a) Does Rolle's Theorem apply to f on [1,5]?

(b) Fill in the blank: the point c guaranteed by Rolle's Theorem is c = ___.

(a) f(1) = 1−6+5 = 0 and f(5) = 25−30+5 = 0, and f is a polynomial, so it's continuous and differentiable everywhere. (b) f′(x) = 2x−6 = 0 at x = 3, which lies in (1,5).

7. Why does the interior-extrema lemma's proof need both a right-hand and a left-hand inequality on the difference quotient?

The right-hand limit gives f′(c) ≤ 0 and the left-hand limit gives f′(c) ≥ 0; since differentiability forces these to be the same number, that number must be 0.

8. Let f(x) = x² on [0, 3]. Answer both parts:

(a) What is the average rate of change of f on [0,3]?

(b) Fill in the blank: the Mean Value Theorem guarantees f′(c) = 3 at c = ___.

(a) (f(3)−f(0))/(3−0) = (9−0)/3 = 3. (b) f′(x) = 2x = 3 gives c = 1.5, which lies in (0,3).

9. Fill in the blank: the corollary that a zero derivative forces a function to be constant is exactly what justifies the "+C" in every ___ computed throughout AP Calc BC.

Since any two antiderivatives of the same function share a derivative, this corollary forces them to differ by exactly one constant — the entire justification behind "+C".

10. Let f(x) = x³ + 2x + 1. Answer both parts:

(a) Since f′(x) = 3x² + 2 > 0 for every real x, what does the theorem conclude about f?

(b) Fill in the blank: f′(x) = 3x² + 2 reaches its smallest value, ___, at x = 0, and is larger everywhere else.

(a) MVT converts the pointwise fact f′(x)>0 everywhere into the global comparison f(x₁)<f(x₂) for any x₁<x₂. (b) 3x² ≥ 0 with equality at x=0, so the minimum of 3x²+2 is 2.
