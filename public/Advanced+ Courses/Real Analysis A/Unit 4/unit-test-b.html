1. In proving limx→1 (4x − 2) = 2 directly from the epsilon-delta definition, algebra shows |f(x) − 2| = 4|x − 1|. Which choice of δ (in terms of ε) makes the proof work?

Since |f(x) − 2| = 4|x − 1|, forcing this below ε requires |x − 1| < ε/4 — so δ = ε/4 suffices.

2. Let g(x) = (x² − 9)/(x − 3) for x ≠ 3, and define g(3) = 4. Answer both parts:

(a) What is limx→3 g(x)?

(b) Fill in the blank: since the limit equals ___ but g(3) = 4, g is discontinuous at x = 3.

(a) For x ≠ 3, (x²−9)/(x−3) = x+3, so the limit as x→3 is 6. (b) Since 6 ≠ 4, the limit and the function's actual value disagree, so g is discontinuous at x = 3 despite the limit existing.

3. Fill in the blank: by the ___ characterization, f is continuous at a exactly when f(xₙ) → f(a) for every sequence xₙ → a in the domain of f.

This is the equivalent, often easier-to-use characterization of continuity established in Lesson 20 alongside the epsilon-delta definition.

4. Let k(x) = (x − 2)/(x² − 16). Answer both parts:

(a) Which rule guarantees k is continuous at every point where its denominator is nonzero?

(b) Fill in the blank: k fails to be continuous only at x = ±___.

(a) x−2 and x²−16 are each continuous everywhere, so their quotient is continuous away from zeros of the denominator. (b) x² − 16 = 0 exactly at x = 4 and x = −4.

5. Suppose f is continuous everywhere, and g is continuous specifically at the point f(3). What can be concluded about g∘f at x = 3?

The composition theorem needs only f continuous at the specific point (here, x=3) and g continuous at f(3) — exactly the given hypotheses — to conclude g∘f is continuous at x=3, not necessarily anywhere else.

6. Let q(x) = x³ − 2x − 5, with q(2) = −1 and q(3) = 16. Answer both parts:

(a) What does the Intermediate Value Theorem guarantee here?

(b) Fill in the blank: IVT applies here because q is ___ on [2,3].

(a) q is continuous (a polynomial) and 0 lies between q(2) = −1 and q(3) = 16, so IVT guarantees a root somewhere in (2,3) — this is the classic example used to motivate numerical root-finding. (b) Continuity plus the sign change are exactly IVT's hypotheses.

7. A continuous function on the open interval (0, 1) can fail to attain a maximum. What property is (0,1) missing that the Extreme Value Theorem requires?

f(x) = x on (0,1) is continuous and bounded with supremum 1, but (0,1) is not compact, so the maximizing sequence has no subsequence converging to a point still inside the set.

8. Let f(x) = −x² + 6x on [0, 5]. Answer both parts:

(a) Since f is continuous on the compact set [0,5], what does the Extreme Value Theorem guarantee?

(b) Fill in the blank: the maximum value of f on [0,5] is ___.

(a) EVT guarantees attainment, not just existence of a bound. (b) Checking f(0)=0, f(5)=−25+30=5, and the vertex at x=3 gives f(3) = −9+18 = 9 — the maximum on [0,5].

9. Fill in the blank: a function is ___ continuous on a set if one δ (given ε) works for every pair of points in that set at once, rather than being chosen anew at each point.

This "one δ for the whole set" requirement is exactly what distinguishes uniform continuity from ordinary, pointwise continuity.

10. Consider f(x) = 1/x. Answer both parts:

(a) Is f uniformly continuous on (0, 2)?

(b) Fill in the blank: however, f is uniformly continuous on [1, 3], because [1,3] is ___.

(a) Near 0, points 1/n and 1/(n+1) get arbitrarily close while their images stay a fixed distance apart, defeating any single δ. (b) [1,3] is compact, so continuity there automatically upgrades to uniform continuity.
