The Subspace Topology

How any subset of a topological space inherits a topology of its own — quietly already at work every time Real Analysis A discussed a function's restricted domain.

← Lesson 5 Unit 3, Lesson 7 → Contents Glossary →

Lesson 5's f(t) = (cos t, sin t) example used [0, 2π) "as a topological space in its own right" without ever saying where its topology came from. This closing lesson of Unit 2 makes that precise: given any topological space X and any subset Y ⊆ X, Y automatically inherits a topology from X.

The definition

Definition — Subspace Topology Let (X, τ) be a topological space and Y ⊆ X. The subspace topology on Y is τY = {U ∩ Y : U ∈ τ} — every open set of Y is the intersection of Y with some open set of X.
Theorem — τY Is a Topology on Y τY satisfies (T1)–(T3), and is therefore a genuine topology on Y.
Proof (T1): ∅ = ∅ ∩ Y and Y = X ∩ Y, and ∅, X ∈ τ, so ∅, Y ∈ τY. (T2): if {Uα ∩ Y} is a collection of sets in τY, then ⋃(Uα ∩ Y) = (⋃Uα) ∩ Y, and ⋃Uα ∈ τ by (T2) for X, so the union is in τY. (T3): for U₁ ∩ Y and U₂ ∩ Y in τY, (U₁ ∩ Y) ∩ (U₂ ∩ Y) = (U₁ ∩ U₂) ∩ Y, and U₁ ∩ U₂ ∈ τ by (T3) for X, so the intersection is in τY. Set algebra distributes the topology axioms from X directly down to Y. ∎

Subspace opens need not be open in the ambient space

Example Let Y = [0, 1] with the subspace topology from (ℝ, τstd). The set [0, 1/2) is open in Y — it equals (−1, 1/2) ∩ [0, 1], and (−1, 1/2) is open in ℝ — even though [0, 1/2) is not open in ℝ itself, since 0 has no ε-ball in ℝ staying inside [0, 1/2). "Open" is always relative to which space is being discussed; a set can be open in a subspace without being open in the larger ambient space.
Why this was already implicit in Real Analysis A Real Analysis A routinely discussed "f continuous on [a, b]," including one-sided behavior at the endpoints a and b — behavior that ε-δ continuity, stated with a two-sided open interval around each point, can't literally describe at an endpoint of a closed interval. What was actually happening, made precise now: f was continuous as a function into ℝ from the subspace [a, b] ⊆ ℝ, where [a − ε, a + ε) ∩ [a, b] counts as a perfectly good open neighborhood of a in the subspace topology, even though no genuine two-sided ε-ball around a fits inside [a, b].

A useful reformulation for continuity

Theorem — Restricting the Codomain If f : X → Y is continuous and Z ⊆ Y contains the entire image f(X), then f : X → Z is also continuous, using the subspace topology on Z.
Proof sketch For V open in Z, V = U ∩ Z for some U open in Y (subspace topology definition). Since f(X) ⊆ Z, f⁻¹(V) = f⁻¹(U ∩ Z) = f⁻¹(U) ∩ f⁻¹(Z) = f⁻¹(U) ∩ X = f⁻¹(U), which is open in X since f : X → Y is continuous. ∎
Why this matters going forward This theorem is what makes it legitimate, in Lesson 5's [0, 2π) → S¹ example and throughout the rest of this course, to treat a function's codomain as "just the image" without worrying that shrinking the codomain might quietly break continuity. It doesn't — continuity only ever depended on preimages of opens, and those are unaffected by which superset of the image is nominally called the codomain.

Check your recall

No peeking back up — answer from memory first, then check.

1. According to the subspace topology definition, which subsets of Y ⊆ X count as open in Y?

The subspace topology is defined by intersecting every open set of X with Y — the resulting collection is τ_Y.

2. Why is [0, 1/2) open in the subspace [0, 1] ⊆ ℝ, even though it isn't open in ℝ itself?

Openness is relative to the ambient space being discussed — [0, 1/2) satisfies the subspace definition via intersection with an ℝ-open interval, even though it fails ℝ's own ε-ball test.

3. What does the "Restricting the Codomain" theorem let you do safely?

Continuity depends only on preimages of open sets, which are unaffected by treating the codomain as a smaller set containing the image, given the subspace topology.

4. Fill in the blank: the topology τY = {U ∩ Y : U ∈ τ} that a subset Y automatically inherits from (X, τ) is called the ___ topology.

Subspace topology is the name for this inherited structure — every open set of Y comes from intersecting Y with an open set of X.

5. Fill in the blank: Real Analysis A's discussion of continuity "on [a, b]," including behavior at the ___ where no two-sided ε-ball fits, is precisely continuity from the subspace [a, b] ⊆ ℝ.

Endpoints are exactly where the subspace topology's one-sided open neighborhoods were quietly doing work that Real Analysis A never had to name explicitly.
