Continuity via Open Sets

Real Analysis A's ε-δ definition, rewritten with no ε, no δ, and no distance — then proved to say exactly the same thing on ℝ.

← Unit 1, Lesson 3 Lesson 5 → Contents Glossary →

Real Analysis A, Unit 4, Lesson 19 defined limx→a f(x) = L using ε and δ: for every ε > 0, some δ > 0 forces |x − a| < δ to imply |f(x) − L| < ε. Continuity (Lesson 20 there) built on top of that. Both definitions need a distance to measure "close." This lesson replaces them with a definition stated purely in terms of open sets — one that makes sense for a continuous function between any two topological spaces, metric or not.

The definition

Definition — Continuous Function Let (X, τX) and (Y, τY) be topological spaces. A function f : X → Y is continuous if for every open set V ⊆ Y (V ∈ τY), the preimage f⁻¹(V) = {x ∈ X : f(x) ∈ V} is open in X (f⁻¹(V) ∈ τX).
Why preimages, and not images Images of open sets under continuous functions need not be open — f(x) = x² sends the open set (−1, 1) to [0, 1), which is not open. Preimages behave better precisely because they interact cleanly with unions and intersections (f⁻¹(⋃Vα) = ⋃f⁻¹(Vα) and f⁻¹(V₁ ∩ V₂) = f⁻¹(V₁) ∩ f⁻¹(V₂), for any function f at all), which is exactly the algebra the topology axioms are built from.

This matches ε-δ continuity exactly on ℝ

Theorem — Topological Continuity = ε-δ Continuity on ℝ Let f : ℝ → ℝ, both with the standard topology. Then f is continuous in the open-set sense above if and only if f is continuous at every point in Real Analysis A's ε-δ sense (Unit 4, Lesson 20).
Proof (⇒): topological continuity implies ε-δ continuity Suppose f⁻¹(V) is open for every open V ⊆ ℝ. Fix a ∈ ℝ and ε > 0. The set V = (f(a) − ε, f(a) + ε) is open and contains f(a), so f⁻¹(V) is open and contains a. By the ε-ball definition of open, there is δ > 0 with (a − δ, a + δ) ⊆ f⁻¹(V) — meaning |x − a| < δ implies f(x) ∈ V, i.e. |f(x) − f(a)| < ε. That is exactly ε-δ continuity at a. ∎
Proof (⇐): ε-δ continuity implies topological continuity Suppose f is ε-δ continuous at every point. Let V ⊆ ℝ be open, and let x ∈ f⁻¹(V). Since V is open and f(x) ∈ V, there is ε > 0 with (f(x) − ε, f(x) + ε) ⊆ V. By ε-δ continuity at x, there is δ > 0 such that |t − x| < δ implies |f(t) − f(x)| < ε, i.e. f((x − δ, x + δ)) ⊆ (f(x) − ε, f(x) + ε) ⊆ V, so (x − δ, x + δ) ⊆ f⁻¹(V). Since every x ∈ f⁻¹(V) has such a δ-ball inside f⁻¹(V), the set f⁻¹(V) is open. ∎
Why this proof is the real payoff of Unit 1 Both directions do nothing but unpack "open" using ε-balls and rearrange quantifiers — the entire proof is mechanical once open sets are already in hand. This is the reward for Unit 1's investment: the topological definition isn't a different notion of continuity bolted on next to the familiar one, it's a repackaging that happens to coincide exactly on ℝ, while also making sense in settings where ε-δ has no meaning at all — for instance the quotient spaces built in Unit 5.

Worked example

Example — Verifying Continuity Directly from the Definition Let X have the discrete topology and Y be any topological space. Every function f : X → Y is automatically continuous: for any open V ⊆ Y, f⁻¹(V) is some subset of X, and in the discrete topology, every subset of X is open — so f⁻¹(V) is open regardless of what it is. This is a case ε-δ language could never express (X might not even be a set of numbers), but the open-set definition handles without any extra machinery.

Continuity is defined via preimages of open sets — images of open sets need not stay open, as the lesson's why-box example (x²) shows.

3. Why is every function from a discrete space X to any topological space Y automatically continuous?

Since every subset of a discrete space is open, the preimage condition for continuity is satisfied automatically, regardless of what f actually does.
