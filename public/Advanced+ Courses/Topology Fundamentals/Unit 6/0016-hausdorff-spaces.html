Hausdorff Spaces

Naming, precisely, the property of ℝ that made "the limit" (singular) a meaningful phrase in Real Analysis A all along.

← Unit 5, Lesson 15 Lesson 17 → Contents Glossary →

Real Analysis A, Unit 2, Lesson 7 defined "aₙ → L" and every later lesson referred to the limit, as though uniqueness were obvious. It is obvious on ℝ — but Lesson 11's disjoint-balls trick and Lesson 14's compact-to-Hausdorff theorem have both already leaned on a property that makes that uniqueness possible in the first place. This lesson names it.

The definition

Definition — Hausdorff Space A topological space X is Hausdorff (or T2) if for every pair of distinct points x, y ∈ X, there exist disjoint open sets U, V with x ∈ U, y ∈ V.
Theorem — ℝⁿ Is Hausdorff (ℝⁿ, τstd) is Hausdorff.
Proof For distinct x, y ∈ ℝⁿ, let r = |x − y|/2 > 0. The balls B(x, r) and B(y, r) are open and disjoint: if z were in both, the triangle inequality would give |x − y| ≤ |x − z| + |z − y| < r + r = |x−y|, a contradiction. This is exactly the same construction used in Lesson 11's proof that compact sets are closed. ∎

Why Hausdorff is exactly what uniqueness of limits needs

Theorem — Uniqueness of Limits in a Hausdorff Space If X is Hausdorff and a sequence (xₙ) in X converges to both a and b, then a = b.
Proof Suppose toward contradiction a ≠ b. By the Hausdorff property, there are disjoint open U ∋ a, V ∋ b. Since xₙ → a, xₙ ∈ U for all n beyond some N₁ (this is exactly what "convergence to a" means topologically: xₙ → a if every open set containing a contains all but finitely many xₙ — the direct generalization of Real Analysis A's ε-N definition, with the ε-ball replaced by an arbitrary open set). Since xₙ → b, xₙ ∈ V for all n beyond some N₂. For n > max(N₁, N₂), xₙ ∈ U ∩ V — but U ∩ V = ∅, a contradiction. So a = b. ∎
Why Real Analysis A never had to worry about this Real Analysis A's Unit 2 never once questioned whether a sequence limit could be non-unique, because ℝ is Hausdorff and the proof above (specialized to ε-balls instead of general open sets) simply always works there. This lesson names exactly which structural feature was quietly doing that work the entire time.

A concrete failure: the indiscrete topology

Example — Non-Uniqueness in a Non-Hausdorff Space Let X = {a, b} with the indiscrete topology (Lesson 1): the only open sets are ∅ and X. Since a ≠ b have no disjoint open sets separating them (the only nonempty open set is X itself, containing both), X is not Hausdorff. Consider the constant sequence xₙ = a for all n. It converges to a trivially. But it also converges to b: the only open set containing b is X itself, and every xₙ = a ∈ X — so the convergence condition ("eventually inside every open set containing the limit") is satisfied for b too. This single sequence converges to two different points at once.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does it mean for X to be Hausdorff?

The Hausdorff property is exactly this pairwise separation condition — disjoint open neighborhoods for any two distinct points.

2. In the proof that ℝⁿ is Hausdorff, why is r = |x−y|/2 exactly the right radius to use?

Half the distance between x and y is exactly the largest radius that keeps the two balls from overlapping, verified directly by the triangle inequality.

3. Why does the constant sequence xₙ = a converge to both a and b in the indiscrete topology on {a, b}?

With so few open sets available, the convergence condition becomes trivially easy to satisfy for every point — including points the sequence never actually reaches.

4. Fill in the blank: the Hausdorff property is exactly what guarantees sequence limits are ___ — without it, a single sequence can converge to more than one point.

Uniqueness of limits is precisely the property this lesson traces back to the Hausdorff axiom.

5. Fill in the blank: the ___ topology on any set with two or more points is the standard example of a non-Hausdorff space.

The indiscrete topology has too few open sets to separate any two distinct points, making it fail the Hausdorff condition.
