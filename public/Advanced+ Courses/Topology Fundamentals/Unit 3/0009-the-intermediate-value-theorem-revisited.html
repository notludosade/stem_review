The Intermediate Value Theorem, Revisited

Three purely topological facts, already in hand, combine into the exact theorem Real Analysis A needed a dedicated lesson and a supremum argument to prove.

← Lesson 8 Unit 4, Lesson 10 → Contents Glossary →

Real Analysis A, Unit 4, Lesson 22 proved the Intermediate Value Theorem directly: given f continuous on [a, b] with f(a) < 0 < f(b), it constructed c = sup{x ∈ [a,b] : f(x) < 0} and showed by contradiction that f(c) can be neither positive nor negative. That proof is specific to ℝ. This closing lesson of Unit 3 rebuilds IVT from three facts this course has already proved, none of which mention ε or δ.

The three ingredients

Ingredient 1 (Lesson 7) Continuous images of connected spaces are connected: if f : X → Y is continuous and X is connected, then f(X) (as a subspace of Y) is connected.
Ingredient 2 (Lesson 7, restated from Real Analysis A Unit 3 Lesson 18) A subset of ℝ with at least two points is connected if and only if it is an interval.
Ingredient 3 (definition of interval) E ⊆ ℝ is an interval exactly when: for all p, q ∈ E and p < r < q, r ∈ E as well.

The theorem

Theorem — Intermediate Value Theorem Let f : [a, b] → ℝ be continuous, with a < b. If y₀ is any value strictly between f(a) and f(b), then there exists c ∈ (a, b) with f(c) = y₀.
Proof [a, b] is an interval, hence connected (Ingredient 2). By Ingredient 1, f([a, b]) is connected. f([a, b]) is a subset of ℝ containing both f(a) and f(b) (at least two points, since y₀ lies strictly between them, so f(a) ≠ f(b)), so by Ingredient 2 again, f([a, b]) is an interval. By Ingredient 3, since f(a), f(b) ∈ f([a,b]) and y₀ lies strictly between them, y₀ ∈ f([a, b]) too. That means y₀ = f(c) for some c ∈ [a, b] — and since y₀ ≠ f(a), f(b) (it's strictly between them), c ∈ (a, b). ∎
Why this proof is so much shorter than Real Analysis A's Real Analysis A's proof had to build its own supremum-based machinery from scratch, specific to the situation. This proof needs nothing new: it is a direct three-line consequence of facts already sitting on the shelf — one about continuity and connectedness in general (Lesson 7), and one about connectedness on ℝ specifically that this course inherited unchanged from Real Analysis A (Lesson 7's restated theorem). The genuine mathematical content is identical; what's different is how much of it had to be proved locally versus reused.

Worked example

Worked Example Let f(x) = x³ − 4x + 1 on [0, 1]. f(0) = 1 > 0 and f(1) = 1 − 4 + 1 = −2 < 0. Since f is a polynomial (continuous everywhere, hence continuous on [0,1]) and 0 lies strictly between f(1) = −2 and f(0) = 1, the theorem guarantees some c ∈ (0, 1) with f(c) = 0 — a root of x³ − 4x + 1 strictly between 0 and 1, with no need to construct c explicitly.

What genuinely generalizes beyond ℝ

Corollary — IVT for Any Connected Domain If X is any connected topological space and f : X → ℝ is continuous, then f(X) is an interval of ℝ. In particular, if f(x₁) < y₀ < f(x₂) for some x₁, x₂ ∈ X, then y₀ = f(x) for some x ∈ X.
Why this is a genuine generalization, not just a restatement Real Analysis A's IVT only ever concerned functions with domain an interval of ℝ. This corollary applies to a continuous real-valued function on any connected space at all — a connected subset of ℝ², a quotient space built in Unit 5, or a space with no metric whatsoever. The proof is unchanged: connectedness of X, plus Ingredient 1, already gives connectedness of f(X); Ingredients 2–3 are what pin down connected subsets of the codomain ℝ specifically as intervals.

1. Which theorem from Lesson 7 supplies the fact that f([a,b]) is connected, in this lesson's proof of IVT?

Since [a,b] is connected and f is continuous, Lesson 7's continuous-image theorem hands over connectedness of f([a,b]) directly.

2. Once f([a,b]) is known to be connected, what additional fact turns that into "y₀ is actually attained"?

Ingredient 2 is what upgrades "f([a,b]) is connected" into "f([a,b]) is an interval," and Ingredient 3 (the definition of interval) then forces y₀ into the set.

3. What does the corollary "IVT for Any Connected Domain" generalize beyond Real Analysis A's original theorem?

The proof only ever used connectedness of the domain, not that the domain was specifically an interval of ℝ — so it applies verbatim to any connected space at all.

4. Fill in the blank: the entire proof of IVT in this lesson rests on [a,b] being ___ — nothing about distance is used beyond that.

Connectedness of the domain is the single structural fact the whole proof is built from.

5. Fill in the blank: since f([a,b]) is a connected subset of ℝ containing at least two points, it must be an ___ — and that fact alone forces y₀ to be attained.

Interval is exactly what Ingredient 2 guarantees, and it's the property that pins y₀ into f([a,b]).
