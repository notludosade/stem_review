Path-Connectedness

A stronger, more visual cousin of connectedness — "you can walk from any point to any other without leaving the space" — and a famous space where the two properties come apart.

← Lesson 7 Lesson 9 → Contents Glossary →

Connectedness (Lesson 7) is a negative condition — no separation exists. Path-connectedness is a positive, constructive one — an explicit walk between any two points can always be found. The two properties turn out to be related but not identical, and this lesson's closing example is the standard counterexample showing exactly where they diverge.

The definition

Definition — Path, Path-Connected A path from x to y in a topological space X is a continuous function γ : [0, 1] → X with γ(0) = x and γ(1) = y (where [0,1] carries its subspace topology from ℝ). X is path-connected if for every pair of points x, y ∈ X, some path from x to y exists.

Path-connected implies connected

Theorem If X is path-connected, then X is connected.
Proof Suppose toward contradiction X = U ∪ V is a separation. Since U, V are both nonempty, pick x ∈ U and y ∈ V. By path-connectedness, there is a continuous γ : [0, 1] → X with γ(0) = x, γ(1) = y. Then γ⁻¹(U) and γ⁻¹(V) are open in [0, 1] (continuity of γ), disjoint (U, V are disjoint), nonempty (0 ∈ γ⁻¹(U), 1 ∈ γ⁻¹(V)), and their union is [0, 1] (since γ maps into U ∪ V = X). So γ⁻¹(U), γ⁻¹(V) form a separation of [0, 1]. But [0, 1] is an interval, hence connected (Lesson 7's restated theorem) — contradiction. So no separation of X exists. ∎
Why the converse fails The proof above only ever pulls a separation of X back to a separation of [0, 1] — it never builds a path forward from connectedness. That asymmetry is not a gap in the proof technique; it reflects a genuine gap between the two properties. The rest of this lesson exhibits a space that is connected but has no path at all between two of its points.

The topologist's sine curve

Construction Let S = C ∪ L, where C = {(x, sin(1/x)) : 0 < x ≤ 1} (the graph of sin(1/x) for x > 0) and L = {(0, y) : −1 ≤ y ≤ 1} (a vertical segment), both taken with the subspace topology from ℝ² (using the product topology of Unit 5 to define open sets in ℝ², previewed here informally as "open disks").

As x → 0⁺, the curve oscillates through the full range [−1, 1] infinitely often, approaching (but never smoothly joining) the wall segment L.

Theorem — S Is Connected but Not Path-Connected S = C ∪ L is connected, but there is no path in S from any point of L to any point of C.
Proof sketch — connected C alone is connected: it's the image of the connected interval (0, 1] under the continuous map x ↦ (x, sin(1/x)) (Lesson 7's continuous-image theorem). A short argument (checking that any open set containing a point of L must also intersect C, since C oscillates through every height infinitely often as x → 0⁺) shows L ⊆ cl(C). A set squeezed between a connected set and its closure is itself connected — the same style of argument Real Analysis A used for closures of connected intervals — so S = C ∪ L, sitting between C and cl(C), is connected.
Proof sketch — not path-connected Suppose toward contradiction a path γ : [0, 1] → S exists from a point of L to a point of C. Consider the last "time" t* at which γ(t) ∈ L (this set of times is closed, so a last one exists). For t slightly past t*, γ(t) ∈ C and must have first coordinate x(t) → 0⁺ as t → t*⁺ (continuity forces γ(t) to stay near L just after leaving it). But as x(t) → 0⁺, sin(1/x(t)) oscillates through [−1, 1] infinitely often in that shrinking time window — forcing the second coordinate of γ(t) to fail to converge to any single value as t → t*⁺, contradicting that γ is continuous (hence has a well-defined limit) at t*. No such path can exist.
Why this example matters It shows path-connectedness is a genuinely stronger property than connectedness — the implication in this lesson's first theorem cannot be reversed in general. It also demonstrates that "connected" does not mean "drawable without lifting your pen": S is a single connected piece by the topological definition, yet no continuous pen-stroke can actually cross from L into C.

Check your recall

No peeking back up — answer from memory first, then check.

1. What is required for X to be path-connected?

Path-connectedness is defined constructively: an explicit continuous path must exist between every pair of points.

2. In the proof that path-connected implies connected, why does a separation of X pull back to a separation of [0, 1]?

Preimages of a separation under a continuous path form a genuine separation of the domain — and since [0,1] is connected, this is a contradiction, proving no separation of X can exist.

3. What does the topologist's sine curve S demonstrate?

S is the standard counterexample: connected as a whole, yet no continuous path can cross from L into C, since the curve's oscillations near x = 0 prevent any path from having a well-defined limit there.

4. Fill in the blank: every ___ space is connected, but the topologist's sine curve shows the converse is false.

Path-connected implies connected, one-directionally — the topologist's sine curve is exactly the counterexample to the reverse implication.

5. Fill in the blank: the "not path-connected" proof fails any attempted path because sin(1/x) ___ through the full range [−1, 1] infinitely often as x → 0⁺, preventing any path's second coordinate from settling on a single limiting value.

The infinite oscillation as x → 0⁺ is exactly what blocks continuity of any hypothetical path crossing from C into L.
