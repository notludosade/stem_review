Unit 1 — Topological Spaces

Topology / Topological Space

A collection τ of subsets of a set X (called open sets), containing ∅ and X, closed under arbitrary unions and finite intersections. (X, τ) is a topological space — the axiomatic generalization of ℝ's ε-ball open sets, with no distance required.

Basis

A collection ℬ of subsets of X, covering every point (B1) and refining at every intersection (B2), whose unions generate an entire topology — a compact way to describe a topology without listing every open set.

Closed set

A set F ⊆ X whose complement X \ F is open — identical in spirit to Real Analysis A's definition, now stated for any topological space.

Closure

The smallest closed set containing A, equal to the intersection of every closed set containing A.

Interior

The largest open set contained in A, equal to the union of every open subset of A.

Boundary

∂A = cl(A) \ int(A) — what's left of the closure once the interior is removed.

Unit 2 — Continuity and Homeomorphism

Continuous function (topological)

f : X → Y is continuous if f⁻¹(V) is open in X for every open V ⊆ Y — proved equivalent to Real Analysis A's ε-δ continuity on ℝ, and applicable with no metric on either space.

Homeomorphism

A bijection f : X → Y with both f and f⁻¹ continuous. X and Y are homeomorphic (X ≅ Y) if one exists — the precise notion of "the same shape," topologically.

Topological property

Any property of a space defined entirely in terms of its open sets, and therefore automatically shared by every homeomorphic space. Boundedness is not a topological property.

Subspace topology

For Y ⊆ X, the topology τ_Y = {U ∩ Y : U open in X} — every open set of Y comes from intersecting Y with an open set of X.

Unit 3 — Connectedness

Separation

A pair of nonempty, disjoint, open sets U, V with U ∪ V = X.

Connected space

A space with no separation — equivalently, one whose only clopen subsets are ∅ and X itself. Connected subsets of ℝ with two or more points are exactly the intervals.

Path, path-connected

A path is a continuous γ : [0,1] → X with γ(0) = x, γ(1) = y. X is path-connected if every pair of points is joined by a path. Path-connected implies connected, but not conversely (the topologist's sine curve).

Intermediate Value Theorem (topological)

If f : X → ℝ is continuous and X is connected, f(X) is an interval — recovering Real Analysis A's IVT as the special case X = [a,b].

Unit 4 — Compactness

Open cover, subcover, compact

An open cover is a collection of open sets whose union is X; a subcover is a subcollection that still covers X. X is compact if every open cover has a finite subcover.

Heine-Borel Theorem

A subset K ⊆ ℝⁿ is compact if and only if K is closed and bounded — proved here via bisection and open covers rather than sequences.

Extreme Value Theorem (topological)

If f : X → ℝ is continuous and X is compact, f attains a maximum and minimum on X — proved via compactness-preservation and Heine-Borel, with no maximizing sequence.

Unit 5 — Product and Quotient Spaces

Product topology

The topology on X × Y generated by the basis {U × V : U open in X, V open in Y} — the smallest topology making both projections continuous.

Quotient map, quotient topology

For a surjection q : X → Y, the topology on Y where V is open exactly when q⁻¹(V) is open in X — the largest topology making q continuous, used to build the circle, torus, and Möbius strip as identification spaces of a square.

Unit 6 — Separation Axioms and Metrizability

Hausdorff space (T2)

Any two distinct points can be separated by disjoint open sets — exactly the property that makes sequence limits unique.

T1 space

For distinct x, y, there is an open set containing x but not y (and vice versa) — equivalently, every singleton is closed. Weaker than Hausdorff.

Regular (T3), Normal (T4)

Regular: T1, plus a point and a closed set not containing it can be separated by disjoint open sets. Normal: T1, plus any two disjoint closed sets can be. Normal ⟹ regular ⟹ Hausdorff ⟹ T1.

Metrizable

A topological space whose topology is generated by the ε-balls of some metric d. Every metrizable space is automatically normal, hence Hausdorff.

Urysohn Metrization Theorem

Every regular, Hausdorff space with a countable basis is metrizable (stated without proof).

Unit 7 — Course Capstone

Loop, homotopy

A loop is a path with γ(0) = γ(1) = x₀. Two loops are homotopic if one continuously deforms into the other while staying based at x₀.

Fundamental group π₁(X, x₀)

The set of homotopy classes of loops based at x₀, with concatenation as the group operation. π₁(S¹) ≅ ℤ (winding number); π₁(D²) is trivial.

Simply connected

Path-connected with trivial fundamental group — every loop contracts to a point.
