An Introduction to Principal Component Analysis

PCA rotates centered data onto orthogonal directions ordered by variance.

← Lesson 20 Contents Course Exam → Glossary →

PipelineCenter data, form covariance matrix C, find C's eigenvectors, sort them by descending eigenvalue, and project onto chosen eigenvectors.
InterpretationPrincipal directions are orthonormal. Each eigenvalue is variance captured along its eigenvector; keeping top components gives a lower-dimensional approximation.
Why This MattersPCA compresses correlated features while preserving as much variation as a chosen dimension permits.
