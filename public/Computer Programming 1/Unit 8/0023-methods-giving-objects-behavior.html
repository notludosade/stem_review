Methods — Giving Objects Behavior

A method is a function that lives inside a class and already knows which instance's data to work with.

Lesson 24 → Contents Glossary →

A method is defined exactly like the functions from Unit 4, except it lives inside a class — and unlike those standalone functions, it can reach the instance's own data directly, without that data being passed in as a parameter.

Python 
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        return f"{self.name} says woof!"

buddy = Dog("Buddy")
print(buddy.bark())  # Buddy says woof!
Java 
class Dog {
    String name;
    Dog(String name) { this.name = name; }

    String bark() {
        return name + " says woof!";
    }
}

Dog buddy = new Dog("Buddy");
System.out.println(buddy.bark()); // Buddy says woof!
JavaScript 
class Dog {
    constructor(name) { this.name = name; }

    bark() {
        return `${this.name} says woof!`;
    }
}

let buddy = new Dog("Buddy");
console.log(buddy.bark()); // Buddy says woof!
C++ 
class Dog {
public:
    std::string name;
    Dog(std::string name) : name(name) {}

    std::string bark() {
        return name + " says woof!";
    }
};

Dog buddy("Buddy");
std::cout << buddy.bark() << std::endl; // Buddy says woof!

bark() uses name without receiving it as a parameter the way Lesson 11's square(n) did — instead, calling buddy.bark() automatically gives the method access to buddy's own name, through self or this. Call bark() on a different Dog instance and it returns a different result, with no extra argument needed — the method already knows which instance it's running on.

This is a new kind of scope beyond the local and global scope from Lesson 12: an instance's data lives in instance scope, reachable by any method on that same instance, but still separate from every other instance of the same class.

Definition A method is a function defined inside a class, describing something instances of that class can do. self (Python) or this (Java, JavaScript, C++) refers to the specific instance a method is currently running on.
Why it matters here Bundling data with the behavior that acts on it is what actually distinguishes an object from the loose functions of Unit 4. Instead of a standalone bark(dog_name) function passed a name every time, the Dog itself knows how to bark — which is the core idea the rest of object-oriented programming builds on.
