1. Consider all four languages in this course. Which one produces a standalone executable before it is ever run?

C++ compiles ahead of time to a native executable; the others translate at or during run time.

2. Fill in the blank: in Java and C++, the JVM/OS looks for a specifically-named function or method, ___, to know where a program's execution should begin.

Python and JavaScript need no such declaration — execution just starts at the top of the file.

3. Consider this C++ code: int total = 50; followed by total = "fifty";. What happens?

The compiler rejects the type mismatch before execution — the same reassignment in JavaScript would run without error, since JavaScript is dynamically typed.

4. In Python, what does 2 ** 5 evaluate to, and what would the equivalent computation require in Java?

2 ** 5 = 32. ** is a Python-only operator; the other three languages need a library function such as Math.pow.

5. Fill in the blank: consider this JavaScript code — let total = 0; for (let i = 1; i <= 5; i++) { if (i % 2 === 0) { total = total + i; } }. After this runs, total equals ___.

i runs 1..5; only i=2 and i=4 are even, so total = 2 + 4 = 6.

6. Fill in the blank: the umbrella term for the order in which a program's statements execute — encompassing if/else, while loops, and for loops alike — is ___ ___.

Every construct in this unit is a different way of controlling that order.

7. A function called convert always runs return 5 * 9 / 5 + 32 — hardcoded to convert exactly 5°C. What is the most direct way to make it work for any Celsius value?

A parameter lets one function body work for any input value, instead of one hardcoded case.

8. Fill in the blank: a Python function is defined as def tax(price): fee = price * 0.05; return price + fee, then called as bill = tax(200). After this runs, bill holds ___.

200 * 0.05 = 10, and 200 + 10 = 210.

9. A string title has 6 characters, so its valid indices are 0 through 5, in every one of the four languages. Which of these is an invalid index for title?

A 6-character string has indices 0 through 5 — index 6 is one past the end, and out of range.

10. Fill in the blank: in JavaScript, let first = "Grace"; let last = "Hopper"; can be joined as `${first} ${last}` instead of using + concatenation. This technique is called string ___, the same term used for Python's f-strings.

Embedding the variable names directly inside the template is what makes this true interpolation.

11. A collection scores = [88, 91, 76] is visited with a Python for-each loop: for s in scores: print(s). What gets printed, in what order?

A for-each loop visits every element in order, printing each one.

12. Fill in the blank: in Java, int[] grades = {60, 70, 80}; is defined (valid indices 0 through 2). grades[2] is a valid index and returns ___.

Index 2 is the array's last valid position, holding 80. Index 3 would throw an ArrayIndexOutOfBoundsException.

13. Consider this Python snippet: with open("log.txt") as f: line = f.readline(). Which best explains why no explicit close() call appears anywhere?

The with statement's guarantee is about safe cleanup on block exit, regardless of how much of the file was read.

14. Fill in the blank: keyboard input by default comes from standard input, or ___ for short.

stdin is the default source for keyboard input, distinct from a file handle stream.

15. A Temperature class stores celsius as private and only exposes setCelsius(value), which rejects any value below -273.15 (absolute zero). What does this design guarantee that a public celsius field would not?

Encapsulation is what lets an object promise its own data can never be set to something that breaks its own rules.

16. Fill in the blank: in C++, class Robot { public: Robot(std::string id) : id(id) {} private: std::string id; }; — the id this constructor sets belongs only to this one ___, not to every Robot ever created.

Each instance keeps its own independent copy of instance-scoped data.
