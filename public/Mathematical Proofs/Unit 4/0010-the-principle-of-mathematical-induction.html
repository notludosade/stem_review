The Principle of Mathematical Induction

A technique for proving a claim about every natural number at once, without ever checking more than two cases by hand: the first one, and a generic "next" one.

← Lesson 9 Lesson 11 → Contents Glossary →

Every technique so far in this course proves a single statement, or a statement about an arbitrary but fixed object. Induction proves infinitely many statements at once — P(1), P(2), P(3), … — without checking them one at a time, by exploiting the fact that the natural numbers are built by repeatedly adding 1.

Definition — The Principle of Mathematical Induction Let P(n) be a statement depending on a natural number n. Suppose: (1) Base case: P(1) is true, and (2) Inductive step: for every k ≥ 1, P(k) → P(k+1). Then P(n) is true for every natural number n ≥ 1.
Why these two ingredients are enough for infinitely many cases Think of the inductive step as a machine: feed it a true P(k), and it hands back a true P(k+1), for any k. The base case starts the machine running with a true P(1). Run the machine once: P(1) true and P(1) → P(2) gives P(2) true. Run it again: P(2) true and P(2) → P(3) gives P(3) true. This chains forward without end, covering every natural number — a proof of infinitely many statements built from exactly two finite pieces of work.
Vocabulary — Inductive Hypothesis Inside the inductive step, the assumption "P(k) is true" (used to prove P(k+1)) is called the inductive hypothesis. It is not something you're proving — it's something you're allowed to assume, for the sole purpose of proving the implication P(k) → P(k+1). The base case is what actually gets that assumption off the ground for k = 1.
Worked example Claim: For every natural number n ≥ 1, 1 + 2 + 3 + ⋯ + n = n(n+1)/2.
Base case (n = 1): the left side is 1; the right side is 1(2)/2 = 1. Equal, so P(1) holds.
Inductive step: assume P(k) holds for some k ≥ 1, i.e., 1 + 2 + ⋯ + k = k(k+1)/2 (the inductive hypothesis). Show P(k+1): 1 + 2 + ⋯ + k + (k+1) = [k(k+1)/2] + (k+1), using the inductive hypothesis to replace the first k terms. Factor: = (k+1)[k/2 + 1] = (k+1)(k+2)/2. This is exactly the right-hand side of P(k+1) — n(n+1)/2 with n = k+1. So P(k) → P(k+1).
By induction, the formula holds for every n ≥ 1. ∎
Why the inductive step proves an implication, not a fact A common misreading of the inductive step is "prove P(k+1) is true." That's not quite it — you prove P(k) → P(k+1): if the sum formula already holds at k, then it holds at k+1. Never at any point does the inductive step assert P(k) is actually true on its own; the base case is what supplies the one confirmed true instance the chain needs to start from.

Check your recall

No peeking back up — answer from memory first, then check.

1. What are the two ingredients of a mathematical induction proof?

Exactly these two finite pieces — a starting true case and a step that always propagates truth forward — suffice to cover every natural number.

2. In the inductive step, what exactly is being proved?

The inductive step proves a conditional — if P(k) holds, then P(k+1) does too — using the inductive hypothesis P(k) as an assumption, not as an established fact on its own.

3. In the worked example, what role does the base case P(1) play in the overall argument?

Without a confirmed true base case, the inductive step's chain of implications has nothing true to start from, and the whole argument stalls before covering any n.

4. Fill in the blank: the assumption "P(k) is true," used inside the inductive step to prove P(k+1), is called the ___.

The inductive hypothesis is assumed only for the purpose of proving P(k) → P(k+1) — it is not itself something the proof establishes independently.

5. Fill in the blank: in the inductive step, the inductive hypothesis lets you replace 1 + 2 + ⋯ + k with ___.

k(k+1)/2 is exactly P(k)'s claimed value, substituted in so the algebra can proceed toward P(k+1)'s formula.
