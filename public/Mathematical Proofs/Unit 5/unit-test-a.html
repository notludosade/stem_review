1. What property must a set of cases have for a proof by cases to be valid?

Exhaustiveness — no element left out — is the one requirement. Overlap between cases is harmless as long as nothing is missing.

2. A student splits a proof about integers n into "Case 1: n ≥ 0" and "Case 2: n ≤ 0." What, if anything, is wrong with this split?

n = 0 satisfies both n ≥ 0 and n ≤ 0 — it's covered twice, not zero times. Exhaustiveness, not mutual exclusivity, is the actual requirement.

3. Fill in the blank: a case split that leaves no element of the domain out is called ___.

Exhaustive — the single property a case split needs for the resulting proof to be valid.

4. Which claim asserts uniqueness but says nothing that guarantees existence?

"At most one" is a uniqueness claim on its own — here it happens to be vacuously true, since x² = −9 has no real solution at all, so existence fails entirely.

5. Fill in the blank: before choosing a proof technique, the decision framework's first step is always to ___ the claim's quantifiers and exact condition.

You cannot choose a strategy for a claim you haven't fully parsed — unpacking always comes first.

6. Consider proving: for every integer n, n² − n is even. Answer both parts:

(a) In the case n is odd (n = 2k+1), what does n² − n simplify to?

(b) Fill in the blank: in the case n is even (n = 2k), n² − n = 4k² − 2k = 2k(2k − ___).

(a) (2k+1)² − (2k+1) = (2k+1)(2k) = 2k(2k+1), even. (b) 4k² − 2k = 2k(2k − 1), also even — both cases confirm the claim.

7. Consider proving: every real number a has a unique additive inverse b with a + b = 0. Answer both parts:

(a) What witness establishes existence?

(b) Fill in the blank: for uniqueness, assume a + b = 0 and a + c = 0. Then b = b + 0 = b + (a + c) = (b + a) + c = 0 + c = ___.

(a) −a is the standard witness. (b) The chain of equalities forces b = c, exactly the uniqueness argument's structure.

8. Claim: "There is no integer solution to 4x = 10." Answer both parts:

(a) Which technique fits best?

(b) Fill in the blank: this claim denies the existence of a solution, matching the framework's question: does it assert something is ___?

(a) 4x is always divisible by 4, but 10 is not — assuming a solution exists and reaching this impossibility is contradiction's job. (b) "Impossible" / "does not exist" claims route directly to contradiction.

9. Claim: "For every integer n ≥ 0, a set with n elements has 2ⁿ subsets." Answer both parts:

(a) Which technique fits best?

(b) Fill in the blank: specifically weak induction, since the case for k+1 elements only ever needs the case for ___ elements.

(a) Adding one element exactly doubles the subset count, a relationship induction is built to capture. (b) Only the immediately preceding case, k, is ever needed — weak induction suffices.

10. Claim: "for every integer n, if n² is divisible by 3, then n is divisible by 3." Answer both parts:

(a) Which two techniques combine naturally to prove this?

(b) Fill in the blank: the contrapositive's hypothesis, "n not divisible by 3," splits into exactly ___ cases (remainder 1 or remainder 2 when n is divided by 3).

(a) The awkward hypothesis "n² divisible by 3" is easier to handle via the contrapositive, and the contrapositive itself naturally splits by remainder. (b) Exactly two nonzero remainders mod 3 exist: 1 and 2.
