1. A layer has 5 neurons, each taking 8 inputs. What shape does its weight matrix have, and why?

One row per neuron, one column per input, is exactly what makes W @ x compute every neuron's weighted sum at once.

2. Fill in the blank: the activation function that squashes its output to between 0 and 1, and is the typical output-layer choice for a single yes/no prediction, is ___.

Sigmoid's (0, 1) range is exactly what a single probability needs.

3. A model predicts 0.01 probability for an example whose true label is 1. Why does cross-entropy score this far worse than MSE would?

-log(0.01) is large; (0.01 - 1)² is not — that gap is the whole point of choosing cross-entropy for classification.

4. Fill in the blank: each single entry in the gradient vector is a ___ — how one specific weight alone would change the loss, holding every other weight fixed.

The gradient vector is built from exactly one partial derivative per weight.

5. How does momentum change the update at each gradient descent step?

Momentum's carried-forward velocity is what smooths out zig-zagging in narrow valleys.

6. Comparing layers in a simple network. Answer both parts:

(a) Fill in the blank: a layer that sits between input and output, and is never read directly from outside the network, is a ___ layer.

(b) The output layer's shape is determined by...

Hidden layers are internal by definition; the output layer's shape follows directly from what the task requires.

7. Matching activations to their typical role. Answer both parts:

(a) max(0, z), cheap and non-saturating for positive inputs, is best matched to...

(b) A function producing a full probability distribution across several classes, summing to 1, is best matched to...

ReLU's role is almost always internal; softmax's role is almost always at a multi-class output.

8. Task-to-loss matching. Answer both parts:

(a) Classifying an email as spam or not spam is best paired with...

(b) Cross-entropy is described as being built from...

Classification tasks pair with cross-entropy, whose log-based construction is exactly what makes it steep on confident mistakes.

9. Zero-gradient points. Answer both parts:

(a) A saddle point's defining feature is that it...

(b) A local minimum, by contrast, is a point where...

Both have zero gradient, but a saddle point isn't a minimum in every direction the way a local minimum is.

10. Training behavior. Answer both parts:

(a) Adam is best described as...

(b) Fill in the blank: too large a learning rate risks ___ the minimum instead of settling into it.

Adam adapts per-weight rates; an oversized rate can still overshoot regardless of which optimizer is used.
