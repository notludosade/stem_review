1. For a parametrically defined curve with dx/dt ≠ 0, the slope dy/dx is computed as:

The chain rule gives dy/dt = (dy/dx)(dx/dt); dividing both sides by dx/dt isolates dy/dx as the ratio of the two rates against t.

2. Fill in the blank: For x(t) = t² − 6t, y(t) = t³ − 12t, dy/dx at t = 4 is ___

dx/dt = 2t − 6 = 2 and dy/dt = 3t² − 12 = 36 at t = 4, so dy/dx = 36/2 = 18.

3. For x(t) = t² − 6t, y(t) = t³ − 12t, answer both parts:

(a) Horizontal tangents (dy/dt = 0, dx/dt ≠ 0) occur at:

(b) Fill in the blank: At t = −2, the y-coordinate of the horizontal-tangent point is ___

(a) dy/dt = 3t² − 12 = 0 gives t = ±2, and dx/dt = 2t − 6 is nonzero at both (−10 and −2), so both are genuine horizontal tangents. (b) y(−2) = (−2)³ − 12(−2) = −8 + 24 = 16.

4. For a parametric curve, d²y/dx² = 3 at t = 0. The curve at that point is:

A positive second derivative means concave up, exactly as it does for an ordinary y = f(x) graph.

5. For x(t) = 6cos t, y(t) = 6sin t, t from 0 to π/2, answer both parts:

(a) The integrand √[(dx/dt)² + (dy/dt)²] simplifies to:

(b) Fill in the blank: The arc length from t = 0 to t = π/2 is ___

(a) dx/dt = −6sin t, dy/dt = 6cos t, so √[(dx/dt)² + (dy/dt)²] = √(36sin²t + 36cos²t) = 6, a constant speed. (b) L = ∫₀^(π/2) 6 dt = 6(π/2) = 3π — a quarter of the circumference of a radius-6 circle.

6. Fill in the blank: For r(t) = ⟨t² − 6t, t³ − 12t⟩, r'(4) = ___ (format: <a,b>)

r'(t) = ⟨2t − 6, 3t² − 12⟩, so r'(4) = ⟨2(4) − 6, 3(4)² − 12⟩ = ⟨2, 36⟩. Differentiation of a vector-valued function is componentwise.

7. For r(t) = ⟨7t, 24t − 16t²⟩ (feet, t in seconds), a launched projectile, answer both parts:

(a) Fill in the blank: The acceleration vector is ⟨0, ___⟩

(b) The speed at t = 0 is:

(a) v(t) = ⟨7, 24 − 32t⟩, so a(t) = v'(t) = ⟨0, −32⟩ — constant, since only gravity acts once launched. (b) v(0) = ⟨7, 24⟩, so speed = √(7² + 24²) = √(49 + 576) = √625 = 25 ft/s.

8. A point has polar coordinates (r, θ) = (4, π). Its rectangular coordinates are:

x = r cos θ = 4cos π = −4 and y = r sin θ = 4sin π = 0, so the point is (−4, 0).

9. For r = 3 + 3sin θ, answer both parts at θ = 0:

(a) Fill in the blank: dx/dθ = ___

(b) dy/dx equals:

(a) x(θ) = r cos θ, so dx/dθ = r'cos θ − r sin θ. At θ = 0: r = 3, r' = 3cos θ = 3, giving dx/dθ = 3(1) − 3(0) = 3. (b) dy/dθ = r'sin θ + r cos θ = 3(0) + 3(1) = 3, so dy/dx = 3/3 = 1.

10. For the region inside r = 2 and outside r = 1 (both full circles, θ from 0 to 2π), answer both parts:

(a) The area is given by the integral:

(b) Fill in the blank: This area equals ___

(a) The wedge between an outer and inner curve is (1/2)([f(θ)]² − [g(θ)]²)dθ, giving A = (1/2)∫₀^(2π)(2² − 1²) dθ. (b) A = (1/2)(3)(2π) = 3π.
