1. Differentiate h(x) = cos(x³). h′(x) equals:

Outside function cos(u) differentiates to −sin(u), evaluated at u = x³; inside function x³ differentiates to 3x². Multiplying gives −3x²sin(x³) — not a sign-flipped, wrong-trig-function, or missing-inner-derivative version.

2. Let p(x) = (3x² − 1)⁴. Answer both parts.

(a) p′(x) equals:

(b) Fill in the blank: Evaluate p′(1). p′(1) = ___

(a) The general power rule gives 4(3x² − 1)³ times the inner derivative 6x, for 24x(3x² − 1)³ — not 4(3x² − 1)³ (missing the inner derivative), 24x(3x² − 1)⁴ (wrong outer exponent), or 12x(3x² − 1)³ (using the wrong inner derivative 3x instead of 6x). (b) At x = 1, 3x² − 1 = 2, so p′(1) = 24(1)(2)³ = 24·8 = 192.

3. Fill in the blank: For the curve x² + 4y² = 16, implicit differentiation gives dy/dx = ___ (in terms of x and y)

Differentiating both sides: 2x + 8yy′ = 0, so y′ = −2x/(8y) = −x/(4y).

4. The curve x²y + y³ = 10 passes through the point (1, 2). Answer both parts.

(a) Differentiating implicitly, y′ (in general form) equals:

(b) Fill in the blank: the slope of the tangent line at (1, 2) is ___ (as a fraction)

(a) Differentiating: x²y′ + 2xy + 3y²y′ = 0 (Product Rule on the x²y term), so y′(x² + 3y²) = −2xy, giving y′ = −2xy/(x² + 3y²) — not with a flipped sign, a missing y² coefficient, or a missing factor of 2. (b) At (1, 2): y′ = −2(1)(2)/(1 + 3(4)) = −4/13.

5. Let f(x) = x⁵ + 2x. Since f(1) = 3, (f⁻¹)′(3) equals:

f′(x) = 5x⁴ + 2, so f′(1) = 5 + 2 = 7, and (f⁻¹)′(3) = 1/f′(1) = 1/7 — the reciprocal of f′(1), not f′(1) itself (7), and not the result of dropping the +2 term (1/5) or another miscalculation (1/3).

6. Let f(x) = x³ + 2x − 1, so f(2) = 8 + 4 − 1 = 11. Answer both parts.

(a) f′(x) equals:

(b) Fill in the blank: (f⁻¹)′(11) = ___ (as a fraction)

(a) Differentiating term by term gives f′(x) = 3x² + 2. (b) f′(2) = 3(4) + 2 = 14, so (f⁻¹)′(11) = 1/f′(2) = 1/14.

7. Fill in the blank: d/dx[cos⁻¹x] = ___

d/dx[cos⁻¹x] = −1/√(1 − x²) — the same expression as sin⁻¹x's derivative, but with the minus sign that every "co" inverse trig function carries.

8. Let g(x) = tan⁻¹(3x). Answer both parts.

(a) g′(x) equals:

(b) Fill in the blank: g′(0) = ___

(a) By the Chain Rule, d/dx[tan⁻¹(3x)] = [1/(1 + (3x)²)]·3 = 3/(1 + 9x²) — not missing the outer chain factor of 3, and not with 3x squared incorrectly. (b) g′(0) = 3/(1 + 0) = 3.

9. For k(x) = ln(x) / eˣ, the outermost rule to apply is:

ln(x) divided by eˣ is a quotient of two non-constant expressions — the outermost operation is division, so the Quotient Rule goes first, even though each piece individually is simple.

10. For f(x) = 2x⁵ − x³ + 4x, answer both parts.

(a) f″(x) equals:

(b) Fill in the blank: f‴(x) = 120x² + ___

(a) f′(x) = 10x⁴ − 3x² + 4. Differentiating again: 10x⁴ → 40x³, −3x² → −6x, and 4 → 0, giving f″(x) = 40x³ − 6x — not with an under-doubled coefficient (40x³ − 3x), a wrong leading coefficient (10x³ − 6x), or a forgotten exponent drop (40x³ − 6x²). (b) Differentiating f″(x) again: 40x³ → 120x², −6x → −6, so f‴(x) = 120x² − 6.
