Solving Systems with Cramer's Rule

A third route to the same answer — one that skips elimination and inverses entirely, in favor of a single number called a determinant.

← Lesson 36 Lesson 38 → Contents Glossary →

Cramer's Rule, dating to 1750 and named for Swiss mathematician Gabriel Cramer, solves a system using nothing but determinants — a single real number computed from a square matrix. For a 2×2 matrix [[a,b],[c,d]], the determinant is D = ad − bc — the same quantity from Lesson 36's inverse formula, just given its own name.

1. Cramer's Rule for two variables

Method — Cramer's Rule (2×2) For the system ax + by = e, cx + dy = f: let D be the determinant of the coefficient matrix [[a,b],[c,d]]. Let Dx be that same determinant but with the constants (e, f) swapped in for the x-column, and Dy with constants swapped in for the y-column. Then x = Dx / D and y = Dy / D — provided D ≠ 0.
Worked Example x + 2y = 5, 3x − y = 1. D = |1 2; 3 −1| = (1)(−1) − (2)(3) = −7. Dx = |5 2; 1 −1| = (5)(−1) − (2)(1) = −7. Dy = |1 5; 3 1| = (1)(1) − (5)(3) = −14. So x = Dx/D = −7/−7 = 1, and y = Dy/D = −14/−7 = 2 — the same (1, 2) found by elimination and by inverses in Lesson 36.

2. What a zero determinant means

Limitation Cramer's Rule always gives the unique solution when D ≠ 0. But when D = 0, the rule goes silent — it cannot tell you whether the system is dependent (infinite solutions) or inconsistent (no solution). Falling back to elimination is the only way to settle which case applies.
