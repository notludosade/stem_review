2. Domain and range, by dragging

Drag the point along the curve h(x) = √x. Watch the readout below update as you move.

Try it — Drag Along h(x) = √x

x = 0.00, h(x) = 0.00

Drag anywhere in the box. Now try to pull the point past the left edge — notice it refuses. That refusal is the domain.

The point could go anywhere along the curve, but it stopped dead at x = 0. That's the domain telling you something directly: h(x) = √x is only defined for x ≥ 0 — negative numbers don't have real square roots. And since the point never dropped below the x-axis either, the range is exactly the same shape of restriction: h(x) ≥ 0.

Check your recall

Quick ones — some review, some new.

1. A vertical line crosses a graph at two points stacked directly above each other. What does that tell you?

Two stacked points share one x (the vertical line's fixed input) but have two different y's — exactly the thing that disqualifies a graph as a function.

2. The domain of h(x) = √x is all x values ___ zero.

x ≥ 0. You felt this directly a minute ago when the draggable point refused to cross x = 0.

3. If f(x) = 3x − 2, what is f(4)?

3(4) − 2 = 12 − 2 = 10. (12 skips the −2; 2 skips the ×3; 6 multiplies 3×(4−2) in the wrong order.)
