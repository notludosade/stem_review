1. Which set of ordered pairs could represent a function?

Every x-value appears exactly once, even though every output happens to be 3. Repeated outputs never break the definition — repeated inputs do.

2. Fill in the blank: To check whether a graph represents a function, you can use the ___ line test — if any such line crosses the graph more than once, the graph fails.

A vertical line marks every point sharing one fixed x-value. Two crossings mean that x-value has two different y-values, which breaks the function definition.

3. For f(x) = 5x − 3, answer both parts:

(a) What is f(2)?

(b) Fill in the blank: f(−1) = ___.

(a) 5(2) − 3 = 10 − 3 = 7. Getting 13 adds instead of subtracts 3; getting 10 skips the −3 entirely. (b) 5(−1) − 3 = −5 − 3 = −8 — the same rule applied to a different input.

4. For f(x) = 1 / (x + 4), answer both parts:

(a) What is the domain?

(b) Fill in the blank: The range of f is all real numbers except y = ___.

(a) Division by zero is undefined at x = −4, so that's the one excluded domain value. (b) Since 1/(x+4) can never equal 0 (a nonzero numerator over any real denominator never reaches 0), y = 0 is the one excluded range value.

5. For f(x) = x² + 1, what is the average rate of change from x = 1 to x = 3?

[f(3) − f(1)] / (3 − 1) = (10 − 2) / 2 = 4.

6. A graph falls until x = 2, then rises afterward. What is x = 2?

Switching from decreasing to increasing is exactly the definition of a local minimum — the bottom of a dip.

7. If g(x) = x + 4 and f(x) = x², answer both parts:

(a) Fill in the blank: f(g(1)) = ___.

(b) What is g(f(1))?

(a) g(1) = 1 + 4 = 5 first, then f(5) = 5² = 25 — the inside function is computed first. (b) Reversing the order: f(1) = 1² = 1 first, then g(1) = 1 + 4 = 5 — composition isn't commutative, so f(g(1)) and g(f(1)) can differ.

8. Compared to y = f(x), the graph of y = f(x + 4) is shifted:

Adding inside the function shifts the graph left, not right — the reverse of what the sign seems to suggest.

9. For the piecewise function f(x) = x − 5 if x < 0, and f(x) = x² if x ≥ 0, answer both parts:

(a) What is f(−3)?

(b) Fill in the blank: f(3) = ___.

(a) −3 < 0, so the first rule applies: f(−3) = −3 − 5 = −8. (b) 3 ≥ 0, so the second rule applies instead: f(3) = 3² = 9 — same function, opposite branch.

10. If f(x) = 4x − 1 and f(2) = 7, answer both parts:

(a) Fill in the blank: f⁻¹(7) = ___.

(b) What is f⁻¹(x) in general?

(a) The inverse undoes f exactly: since f sends 2 to 7, f⁻¹ must send 7 back to 2. (b) Solving y = 4x − 1 for x gives x = (y + 1) / 4, so f⁻¹(x) = (x + 1) / 4.
