Functions

Relation

Any set of ordered pairs (x, y). Every function is a relation, but not every relation is a function.

Function

A relation in which every input (x-value) is paired with exactly one output (y-value). No x-value may repeat with a different y.

Domain

The complete set of allowable input values (x-values) for a function.

Range

The complete set of output values (y-values) a function actually produces.

Function notation, f(x)

Read aloud as "f of x." Names the function f and its output when given input x. f(3) means "the output of f when the input is 3."

Vertical Line Test

A graph represents a function exactly when no vertical line crosses it more than once. A vertical line marks all points sharing one x-value; two crossings would mean that x-value has two outputs.

Rates of Change

Average rate of change

How much the output changes per unit of input, over an interval [a, b]: [f(b) − f(a)] / (b − a). The slope of the secant line through those two points.

Secant line

The straight line connecting two points on a graph. Its slope is the average rate of change between those two points.

Increasing / decreasing

A function is increasing on an interval if outputs rise as x increases, and decreasing if outputs fall as x increases.

Local extremum

A local maximum (peak) or local minimum (dip) — a point where a graph switches between increasing and decreasing.

Composition

Composition, (f ∘ g)(x)

Also written f(g(x)). Apply g to x first, then apply f to the result. Read inside-out: the innermost function runs first.

Commutative (composition is not)

f(g(x)) and g(f(x)) are generally different functions — swapping the order of composition usually changes the result.

Transformations

Vertical / horizontal shift

f(x) + k moves the graph up (k > 0) or down (k < 0). f(x − h) moves it right (h > 0) or left (h < 0) — the sign inside acts opposite to intuition.

Vertical stretch / compression

a·f(x) stretches the graph away from the x-axis when |a| > 1, and compresses it toward the x-axis when |a| < 1.

Reflection

−f(x) flips the graph over the x-axis (negates outputs). f(−x) flips it over the y-axis (negates inputs). The two are independent.

Piecewise & Absolute Value

Piecewise function

A function defined by different formulas on different intervals of its domain. Which formula applies depends on which interval the input falls into.

Absolute value, |x|

A piecewise function equal to x when x ≥ 0 and −x when x < 0 — always a non-negative distance from 0.

Inverses

Inverse function, f⁻¹(x)

Undoes f completely: if f(a) = b, then f⁻¹(b) = a. Its graph is f's graph reflected across the line y = x.

One-to-one function

A function where no two different inputs ever share the same output. Required for an ordinary inverse to exist.

Horizontal Line Test

A function is one-to-one exactly when no horizontal line crosses its graph more than once. Mirrors the vertical line test, checking outputs instead of inputs.

Polynomial Functions

Power function

A function of the form f(x) = a·xⁿ for a real number a and non-negative integer n. The simplest building block of a polynomial.

Polynomial function

A sum of power-function terms, aₙxⁿ + ... + a₁x + a₀. Defined for every real number, with a smooth, unbroken graph.

Degree, leading term, leading coefficient

The degree is the highest exponent present. The leading term is the term with that exponent; its coefficient is the leading coefficient.

Leading Coefficient Test

The end behavior of a polynomial (what it does as x → ±∞) is decided entirely by its degree's parity (odd/even) and its leading coefficient's sign — every other term becomes negligible at the far edges.

Zero (root)

A value of x where a polynomial equals 0 — where its graph crosses or touches the x-axis. Setting any one of its factors to 0 gives one directly.

Multiplicity

If (x − r) appears k times in a polynomial's factored form, r is a zero of multiplicity k. Odd multiplicity: the graph crosses at r. Even multiplicity: it touches r and bounces back.

Turning point

A point where a graph switches from rising to falling or back. A degree-n polynomial has at most n − 1 of them.

Synthetic division

A compact shortcut for dividing a polynomial by (x − r): bring down the leading coefficient, then repeatedly multiply the last result by r and add it into the next coefficient.

Remainder Theorem

Dividing f(x) by (x − r) always leaves a remainder equal to f(r) — no separate evaluation needed.

Factor Theorem

r is a zero of f exactly when (x − r) divides f with remainder 0 — equivalently, exactly when (x − r) is a factor of f.

Rational Root Theorem

If a polynomial has integer coefficients, every rational zero p/q (fully reduced) has p dividing the constant term and q dividing the leading coefficient.

Fundamental Theorem of Algebra

Every polynomial of degree n ≥ 1 has at least one complex zero — and therefore exactly n zeros total, counting multiplicity.

Complex Conjugate Root Theorem

If a polynomial has real coefficients and a + bi (b ≠ 0) is a zero, its conjugate a − bi is guaranteed to be a zero too.

Rational Functions

Rational function

A function of the form f(x) = p(x) / q(x), where p and q are polynomials and q is not the zero polynomial.

Vertical asymptote

If q(a) = 0 and p(a) ≠ 0, the line x = a is a vertical asymptote — the graph grows without bound as x approaches a.

Hole (removable discontinuity)

If a factor (x − a) divides out of both numerator and denominator, the graph is undefined at x = a but does not blow up there — a single missing point, marked as an open circle.

Horizontal asymptote

Compares deg(p) to deg(q): if deg(p) < deg(q), y = 0; if deg(p) = deg(q), y = ratio of leading coefficients; if deg(p) > deg(q), none exists.

Slant (oblique) asymptote

When deg(p) is exactly one more than deg(q), dividing p(x) by q(x) gives a linear quotient — that line is the slant asymptote the graph approaches.

Exponential and Logarithmic Functions

Exponential function, f(x) = a·bˣ

a ≠ 0 is the initial value (f(0) = a), b > 0 and b ≠ 1 is the base. Domain: all reals. Horizontal asymptote: y = 0.

Growth factor / decay factor

The base b of an exponential function. If b > 1, the function grows; if 0 < b < 1, it decays toward its asymptote.

Logarithm, y = logb(x)

Equivalent to bʸ = x, for x > 0, b > 0, b ≠ 1. The exponent b must be raised to in order to produce x. Domain: (0, ∞). Range: all reals. Vertical asymptote: x = 0.

Common logarithm, log(x)

Shorthand for log10(x).

Natural logarithm, ln(x)

Shorthand for loge(x), where e ≈ 2.71828.

Product Rule for Logarithms

logb(MN) = logb(M) + logb(N), for M, N > 0. Multiplication inside becomes addition outside.

Quotient Rule for Logarithms

logb(M/N) = logb(M) − logb(N), for M, N > 0. Division inside becomes subtraction outside.

Power Rule for Logarithms

logb(Mⁿ) = n·logb(M), for M > 0. An exponent inside becomes a multiplying coefficient outside.

Change-of-Base Formula

logb(M) = ln(M) / ln(b) (or log(M) / log(b)). Lets any base be computed using only a calculator's LN or LOG button.

One-to-one property (exponential)

bˢ = bᵀ if and only if S = T, for like bases b. Lets a shared-base exponential equation be solved by setting exponents equal, without logs.

Extraneous solution

A candidate answer produced by valid algebra that fails to satisfy the original equation's domain — common in log equations, where every argument must stay positive.

Continuous growth/decay model, A(t) = A₀eᵏᵗ

A₀ is the starting amount, k is the continuous rate. k > 0 gives growth; k < 0 gives decay.

Half-life

The time for a decaying quantity to fall to half its starting amount: t = −ln(2)/k, independent of the starting amount.

Doubling time

The time for a growing quantity to double: t = ln(2)/k, independent of the starting amount.

Compound interest formula, A(t) = P(1 + r/n)ⁿᵗ

P is principal, r is annual rate, n is compounding periods per year, t is years.

e, defined as a limit

e = limn→∞ (1 + 1/n)ⁿ ≈ 2.718281828... — an irrational constant, the result of compounding continuously.

Trigonometric Functions

Standard position

An angle with its vertex at the origin and its initial side along the positive x-axis. The terminal side is where the initial side lands after rotating — counterclockwise for positive angles, clockwise for negative ones.

Radian

The angle swept when arc length equals the radius: s = rθ. A full rotation is 2π radians, matching 360°.

Degree/radian conversion

Degrees → radians: multiply by π/180. Radians → degrees: multiply by 180/π.

Coterminal angles

Angles that share the same terminal side: θ ± 360°·k (or θ ± 2π·k), for any whole number k.

Reference angle

The acute angle between an angle's terminal side and the nearest x-axis — always between 0° and 90° (0 and π/2 radians).

Unit circle

The circle of radius 1 centered at the origin. For angle θ in standard position, its terminal side crosses the unit circle at exactly one point.

sin θ, cos θ

Defined as the y-coordinate and x-coordinate, respectively, of the point where θ's terminal side meets the unit circle. Domain: all reals. Range: [−1, 1].

Pythagorean Identity

cos²θ + sin²θ = 1, for every angle θ — a restatement of the unit circle equation x² + y² = 1.

Quadrant signs for sin/cos

QI: both +. QII: cos −, sin +. QIII: both −. QIV: cos +, sin −.

tan θ, cot θ, sec θ, csc θ

tan θ = sin θ/cos θ. cot θ = cos θ/sin θ = 1/tan θ. sec θ = 1/cos θ. csc θ = 1/sin θ. tan and sec undefined where cos θ = 0; cot and csc undefined where sin θ = 0.

"All Students Take Calculus"

Sign mnemonic by quadrant: QI all positive, QII only sin/csc positive, QIII only tan/cot positive, QIV only cos/sec positive.

Even/odd trig functions

cos and sec are even: f(−θ) = f(θ). sin, tan, cot, csc are odd: f(−θ) = −f(θ).

SOH-CAH-TOA

sin θ = opposite/hypotenuse. cos θ = adjacent/hypotenuse. tan θ = opposite/adjacent, for an acute angle θ in a right triangle.

Cofunction identities

sin θ = cos(90° − θ), and likewise tan/cot and sec/csc — true because the two acute angles in a right triangle are always complementary.

Angle of elevation/depression

The angle between a horizontal line of sight and a line up to (elevation) or down to (depression) an observed point.

Sinusoidal function

Any function with the same wave shape as sine or cosine — a scaled, shifted version of the parent sin x or cos x graph.

Amplitude, period, midline, phase shift

For y = A sin(B(x − C)) + D: amplitude = |A|, period = 2π/|B|, phase shift = C, midline y = D.

Tangent/cotangent graph

Period π; vertical asymptotes where the denominator (cos θ for tan, sin θ for cot) equals 0.

Secant/cosecant graph

Period 2π; U-shaped branches hugging cos θ's or sin θ's hills and valleys, with asymptotes where that function is 0.

Inverse trig functions

arcsin: domain [−1,1], range [−π/2,π/2]. arccos: domain [−1,1], range [0,π]. arctan: domain all reals, range (−π/2,π/2).

Trigonometric Identities and Equations

Pythagorean identities (three forms)

sin²x + cos²x = 1, straight from the unit circle. Dividing by cos²x gives 1 + tan²x = sec²x; dividing by sin²x gives 1 + cot²x = csc²x.

Reciprocal and quotient identities

Reciprocal: csc x = 1/sin x, sec x = 1/cos x, cot x = 1/tan x. Quotient: tan x = sin x/cos x, cot x = cos x/sin x.

Verifying an identity

Strategy: start from the more complicated side and rewrite it using known identities until it matches the other side exactly.

Sum and difference identities

cos(α ± β) = cosαcosβ ∓ sinαsinβ. sin(α ± β) = sinαcosβ ± cosαsinβ. tan(α ± β) = (tanα ± tanβ)/(1 ∓ tanαtanβ).

Double-angle formulas

sin 2θ = 2 sinθ cosθ. cos 2θ = cos²θ − sin²θ = 1 − 2sin²θ = 2cos²θ − 1. tan 2θ = 2tanθ/(1 − tan²θ).

Reduction formulas

sin²θ = (1 − cos 2θ)/2. cos²θ = (1 + cos 2θ)/2 — trades a squared function for a plain cosine at double the angle.

Half-angle formulas

sin(θ/2) = ±√((1 − cosθ)/2). cos(θ/2) = ±√((1 + cosθ)/2). The ± is resolved by the quadrant θ/2 lands in, not by algebra.

Product-to-sum formulas

cosαcosβ = ½[cos(α−β) + cos(α+β)]. sinαsinβ = ½[cos(α−β) − cos(α+β)]. sinαcosβ = ½[sin(α+β) + sin(α−β)].

Sum-to-product formulas

sinα ± sinβ and cosα ± cosβ, each rewritten as 2 times a product of sine and/or cosine of half-sum and half-difference angles.

Equation quadratic in form

A trig equation containing only one function at one angle (e.g. 2sin²x − sinx − 1 = 0). Substituting u for that function turns it into an ordinary quadratic.

General solution of a trig equation

Because sin and cos repeat every 2π, every base solution must have + 2πk added (k any integer) to capture the complete, infinite solution set.

Systems, Matrices, Sequences & Probability

System of linear equations

Two or more linear equations sharing the same variables. A solution must satisfy every equation at once; in three variables, it's the single point where three planes meet.

Nonlinear system

A system where at least one equation isn't linear (e.g. a parabola and a line). Substitution and elimination still apply, but the number of solutions can exceed one.

Partial fraction decomposition

Splitting a single rational expression with distinct linear factors into a sum of simpler fractions, one per factor — the reverse of combining fractions over a common denominator.

Matrix, dimensions, entry

A rectangular array of numbers. Its dimensions are rows × columns; each individual number is an entry, located by its row and column.

Matrix addition / scalar multiplication

Two matrices add entry-by-entry, and only if their dimensions match exactly. A scalar multiplies every entry of a matrix by that same number.

Matrix multiplication

AB is defined only when A's column count matches B's row count. Each entry of the product is a sum of paired products — and AB ≠ BA in general.

Augmented matrix

A system's coefficients and constants, arranged in one matrix with a vertical bar standing in for the equals signs — set up for row operations instead of algebra on variables.

Gaussian elimination / row-echelon form

Using row swaps, row scaling, and row addition to reach 1's on the diagonal and 0's below it, after which back-substitution finishes solving the system.

Identity matrix, I

The square matrix with 1's on the main diagonal and 0's elsewhere — the matrix equivalent of the number 1, satisfying AI = IA = A.

Invertible matrix, A⁻¹

A square matrix A is invertible if some A⁻¹ exists with AA⁻¹ = I. For 2×2 [[a,b],[c,d]]: A⁻¹ = (1/(ad−bc))·[[d,−b],[−c,a]], undefined when ad − bc = 0.

Determinant, D

A single real number computed from a square matrix; for 2×2 [[a,b],[c,d]], D = ad − bc — the same quantity that decides whether an inverse exists.

Cramer's Rule

Solves ax+by=e, cx+dy=f via x = Dx/D, y = Dy/D, where Dx and Dy swap the constants into the x- or y-column of the coefficient matrix. Undefined (and uninformative) when D = 0.

Sequence, term, explicit/recursive formula

A function whose domain is the counting numbers; each output is a term. An explicit formula gives any term directly from n; a recursive formula builds each term from the ones before it.

Arithmetic sequence, common difference d

A sequence with a constant additive gap d between consecutive terms: aₙ = a₁ + (n − 1)d.

Geometric sequence, common ratio r

A sequence with a constant multiplicative factor r between consecutive terms: aₙ = a₁ · r(n−1) — an exponential function restricted to positive-integer inputs.

Series, summation notation Σ

The sum of a sequence's terms. Σ (k=1 to n) aₖ compactly means "add up aₖ for every k from 1 to n."

Arithmetic / geometric series formulas

Arithmetic: Sₙ = n(a₁ + aₙ)/2. Finite geometric (r ≠ 1): Sₙ = a₁(1 − rⁿ)/(1 − r). Infinite geometric: S = a₁/(1 − r), only when |r| < 1 — otherwise the series diverges.

Permutation, P(n, r)

Counts arrangements where order matters: P(n,r) = n!/(n − r)!.

Combination, C(n, r)

Counts selections where order doesn't matter: C(n,r) = n!/(r!(n − r)!) — the permutation count divided by the r! orderings of the chosen items.

Binomial Theorem, Pascal's Triangle

(x+y)ⁿ = Σ (k=0 to n) C(n,k)·x(n−k)·yᵏ. The coefficients C(n,k), arranged by row, form Pascal's Triangle — symmetric, each entry the sum of the two above it.

Probability

A number from 0 (impossible) to 1 (certain), equal to favorable outcomes divided by total outcomes — with counting theory supplying both counts.
