1. An engine absorbs Q_h = 1000 J and exhausts Q_c = 650 J per cycle. What is its efficiency?

e = 1 − Q_c/Q_h = 1 − 650/1000 = 1 − 0.65 = 0.35.

2. A Carnot engine operates between T_h = 800 K and T_c = 560 K. What is e_Carnot?

e_Carnot = 1 − T_c/T_h = 1 − 560/800 = 1 − 0.70 = 0.30.

3. A refrigerator removes Q_c = 330 J using W = 55 J of work. What is COP_R?

COP_R = Q_c/W = 330/55 = 6.0.

4. If Q_c increases while Q_h stays fixed, an engine's efficiency e = 1 − Q_c/Q_h:

A larger Q_c/Q_h ratio means more of the absorbed heat is being wasted as exhaust, directly lowering e.

5. As T_c approaches absolute zero (T_c → 0), with T_h fixed, e_Carnot = 1 − T_c/T_h approaches:

As T_c → 0, the ratio T_c/T_h → 0, so e_Carnot → 1 — though reaching an actual T_c = 0 reservoir is itself physically unattainable.

6. An engine has efficiency e = 0.3 and absorbs Q_h = 1400 J per cycle. Answer both parts:

(a) Fill in the blank: the work it delivers is W = ___ J.

(b) If Q_h were instead doubled while e stayed fixed at 0.3, W would:

(a) W = e × Q_h = (0.3)(1400) = 420 J. (b) W = eQ_h is directly proportional to Q_h at fixed e, so doubling Q_h doubles W.

7. A Carnot engine operates between T_h = 750 K and T_c = 450 K. Answer both parts:

(a) Fill in the blank: e_Carnot = ___ (as a decimal, e.g. 0.4).

(b) A real engine operating between these same two temperatures will have an actual efficiency that is:

(a) e_Carnot = 1 − 450/750 = 1 − 0.6 = 0.4. (b) Carnot's theorem sets this as the absolute ceiling for any engine operating between these two temperatures.

8. A device removes Q_c = 380 J from a cold space using W = 95 J of work. Answer both parts:

(a) Fill in the blank: treating this as a heat pump instead, COP_HP = ___.

(b) This device's COP_R (refrigerator mode) must be:

(a) Q_h = Q_c + W = 380 + 95 = 475 J, so COP_HP = Q_h/W = 475/95 = 5. (b) COP_R = Q_c/W = 380/95 = 4, matching COP_HP − 1 = 5 − 1 = 4.

9. A Carnot engine has e_Carnot = 0.45 while operating with a hot reservoir at T_h = 400 K. Answer both parts:

(a) Fill in the blank: solving e_Carnot = 1 − T_c/T_h for T_c gives T_c = ___ K.

(b) If this same engine instead used a different working substance (steam instead of an ideal gas) but the same T_h and T_c, its Carnot efficiency would be:

(a) T_c = T_h(1 − e_Carnot) = 400(1 − 0.45) = 400(0.55) = 220 K. (b) Carnot's theorem guarantees the ceiling depends only on the two reservoir temperatures, never on what the working substance happens to be.

10. A Carnot refrigerator operates between T_h = 320 K and T_c = 280 K. Answer both parts:

(a) Fill in the blank: using COP_R,Carnot = T_c/(T_h − T_c), COP_R,Carnot = ___.

(b) On a much hotter day, T_h rises while T_c (the desired interior temperature) stays fixed. COP_R,Carnot would:

(a) COP_R,Carnot = 280/(320 − 280) = 280/40 = 7. (b) A larger T_h − T_c gap shrinks the ratio T_c/(T_h − T_c) — exactly why air conditioners struggle more on the hottest days.
