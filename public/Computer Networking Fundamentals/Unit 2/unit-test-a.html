1. What is the defining trait of circuit switching?

Circuit switching reserves the entire path exclusively, unlike packet switching, which shares capacity on demand.

2. Fill in the blank: breaking data into small, independently addressed and routed chunks, with no dedicated path reserved in advance, is called ___.

Packet switching is what the internet is built on, in contrast to the older circuit-switched phone network.

3. Why does packet switching suit bursty computer traffic (loading a page, then sitting idle) better than circuit switching?

No exclusive reservation means idle periods are immediately available to other traffic sharing the same links.

4. What is the core benefit of splitting networking into layers?

Isolation between layers is the entire point of the model — each layer only needs to know about its immediate neighbors.

5. Fill in the blank: the TCP/IP layer that delivers data to the correct program using port numbers, rather than just the correct device, is the ___ layer.

The Transport layer (TCP or UDP) uses port numbers to distinguish between programs on the same device.

6. Comparing the OSI and TCP/IP models. Answer both parts:

(a) How many layers does the OSI model have?

(b) Which model do real, deployed internet protocols actually follow?

OSI is a widely referenced seven-layer conceptual model, but the internet's actual protocols follow the simpler, four-layer TCP/IP model.

7. What does encapsulation refer to?

Encapsulation is the wrapping process on the way out; decapsulation is the reverse, unwrapping process on arrival.

8. Fill in the blank: the Protocol Data Unit (PDU) name for data wrapped in a Link-layer header (and trailer) is a ___.

Segment (Transport), packet (Internet), and frame (Link) are each layer's specific name for its own PDU.

9. A router forwards a packet without ever inspecting the TCP header or the application data inside it. Answer both parts:

(a) What layers does a router need to read to do this job?

(b) What does this demonstrate about how layers relate to each other?

A router's job only requires its own layer's header information — it's indifferent to whatever application or protocol produced the payload.

10. Fill in the blank: decapsulation strips headers in the exact ___ order from the order they were added during encapsulation.

The last header added (Link layer) is the first one stripped on arrival, like opening nesting dolls from the outside in.
