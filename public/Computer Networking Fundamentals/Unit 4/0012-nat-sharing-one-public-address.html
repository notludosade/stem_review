NAT — Sharing One Public Address

Your laptop, phone, smart TV, and thermostat all have their own private IP address — and every one of them shares exactly one public IP address with the outside world. Here's the trick that makes that work.

← Lesson 11 Lesson 13 → Contents Glossary →

Lesson 8 introduced private IP addresses and noted they're never routed on the public internet. That raises an obvious question: if your laptop's actual address (say, 192.168.1.14) can't be used on the public internet, how does it ever successfully talk to a public web server at all? The answer is a piece of infrastructure sitting quietly in nearly every home router, translating addresses on the fly.

What NAT does

Definition NAT (Network Address Translation) is a technique, almost always performed by a router at the edge of a private network, that rewrites the private source IP address (and typically the source port too) of outgoing packets to the router's single public IP address before sending them onward — and rewrites the reverse for any response that comes back, sending it to the correct private device inside the network. From the outside internet's perspective, every device behind that router appears to share one single public IP address, because as far as any external server can tell, that's exactly what's happening.
Worked example: a request leaving a home network Your laptop (private address 192.168.1.14) sends a request to a web server. It leaves your laptop addressed from 192.168.1.14, arrives at your home router, and the router's NAT rewrites the source address to its own public address (say, 203.0.113.9) before forwarding it onward — also noting, in an internal translation table, that this particular connection belongs to 192.168.1.14. The web server only ever sees 203.0.113.9 as the sender and replies to that address. When the reply arrives back at your home router, NAT checks its translation table, sees the reply belongs to the connection originally from 192.168.1.14, and rewrites the destination address back to your laptop's private address before delivering it — all without your laptop or the web server ever being aware translation happened at all.

How NAT tells devices apart with only one public address

A household might have a dozen devices making internet requests simultaneously, but only one public IP address to share among them. NAT's translation table doesn't just track IP addresses — it tracks the combination of address and port number (Lesson 14 covers ports in full) for every active connection, so it can distinguish "this reply belongs to the laptop's web browser" from "this reply belongs to the phone's video call" even though both are sharing the exact same public IP address at the exact same moment.

Why NAT mattered so much for IPv4's survival Lesson 10 covered IPv4's address exhaustion problem directly: only about 4.3 billion addresses exist, but far more than 4.3 billion devices are connected to the internet today. NAT is the single biggest reason that gap hasn't already broken the internet — an entire household, office, or even a whole country's mobile carrier network can operate behind relatively few public addresses, with NAT translating for potentially thousands of private devices simultaneously. It's a genuinely clever workaround, but it is a workaround: NAT adds real translation overhead, complicates some kinds of direct device-to-device connections (a topic Lesson 22 touches on), and doesn't actually create any new address space — it just lets existing addresses be shared more efficiently. IPv6's vastly larger address space (Lesson 10) is the actual long-term fix; NAT bought IPv4 time, not permanence.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does NAT actually do to an outgoing packet?

NAT swaps the source address (and usually port) on the way out, and reverses that swap for the matching reply on the way back in.

2. A dozen devices on a home network are all sharing one public IP address through NAT. How does the router know which internal device a given reply belongs to?

Tracking address-port pairs is what lets NAT correctly distinguish many simultaneous connections sharing one public address.

3. Why is NAT described as a workaround rather than a permanent fix for IPv4 address exhaustion?

NAT is a genuinely useful sharing mechanism, but it doesn't solve address exhaustion at the root — IPv6's larger address space does.

4. Fill in the blank: the technique that rewrites a private device's address to a router's shared public address for outgoing traffic, and reverses it for replies, is called ___.

NAT is what lets an entire private network share a single public IP address transparently.
