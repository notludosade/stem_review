1. What's the key difference between a switch and a router?

Switches operate at the Link layer within a network; routers operate at the Internet layer, connecting networks together.

2. Fill in the blank: a router's list of known destination networks and which next hop to use for each is called its ___.

A routing table lets a router make a local, next-hop-only forwarding decision for each packet.

3. What does TTL protect a network against?

TTL decrements at every router hop and causes the packet to be discarded at 0, preventing infinite loops.

4. What does NAT do to an outgoing packet from a home network?

NAT swaps the source address (and usually port) on the way out and reverses it for the matching reply.

5. Fill in the blank: NAT's biggest practical benefit is letting many private devices share one public IPv4 address, which has significantly delayed the impact of IPv4 ___.

NAT is a workaround for address exhaustion, not a permanent fix — it shares existing addresses rather than creating new ones.

6. A home network has a dozen devices sharing one public IP address through NAT. Answer both parts:

(a) What does NAT's translation table track to distinguish each device's connections?

(b) Does an external web server see the individual private addresses of each device?

NAT hides individual private addresses from the outside internet entirely, tracking connections internally by address-port pairs.

7. What problem does DNS solve?

DNS is purely a name-to-address lookup system, functioning as the internet's phone book.

8. Fill in the blank: the server that actually holds the specific A record answer for a domain, queried last in a DNS lookup chain, is called the ___ server.

A lookup goes root → TLD → authoritative, with the authoritative server holding the final answer.

9. Why is DNS organized hierarchically rather than as one giant central lookup table? Answer both parts:

(a) What's the main reason for the hierarchy?

(b) What earlier concept in this unit uses a similar "only needs local knowledge" idea?

Both DNS delegation and router forwarding rely on each participant knowing only a small, local slice of the whole picture.

10. Fill in the blank: a resolver stores previously looked-up DNS answers temporarily, called ___, so a repeated lookup doesn't require repeating the full root-to-authoritative chain.

Caching avoids redundant lookups for domains that were resolved recently.
