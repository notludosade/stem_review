Statements, Negation, and Truth Tables

Discrete math builds proofs out of precise claims, not vague ones. This lesson pins down exactly what counts as a claim worth reasoning about, and gives you the first tool — the truth table — for tracking how its truth value can change.

← Course Contents Lesson 2 → Contents Glossary →

Discrete math is the study of structures built from separate, countable pieces — logical claims, sets, graphs, integers — as opposed to the continuous structures (real-number functions, limits, curves) that calculus studies. This course opens with logic because every later unit leans on it: a proof by induction is an argument written in exactly this language, a set-builder definition uses a predicate the way this lesson uses a statement, and a graph-coloring proof is a chain of implications. Get the vocabulary precise now, and everything after reuses it without re-explaining.

1. What counts as a statement

Definition — Statement (Proposition) A statement (or proposition) is a declarative sentence that is either true or false — never both, never neither, and never dependent on an unresolved opinion or an unbound variable. Statements are usually named with lowercase letters: p, q, r.
Statements vs. non-statements Statements: "7 is a prime number" (true). "12 is divisible by 5" (false). "Every even number greater than 2 is the sum of two primes" (this is the Goldbach conjecture — nobody knows if it's true, but it still has a definite truth value, we just haven't found it).

Not statements: "What time is it?" (a question, not declarative). "Close the door." (a command). "x + 3 = 7" on its own (true only once x is fixed — this is a predicate, covered in Lesson 3, not yet a statement). "This sentence is false." (the liar paradox — assigning it either truth value produces a contradiction, so it is deliberately excluded from the definition).

2. Negation

Definition — Negation (¬p) The negation of a statement p, written ¬p (read "not p"), is the statement that is true exactly when p is false, and false exactly when p is true. Negation is the simplest possible way to build a new statement out of an old one — it touches only one statement, where every connective in Lesson 2 combines two.

3. Truth tables

Definition — Truth Table A truth table is a table listing every possible combination of truth values for a statement's inputs, together with the resulting truth value of the whole statement for each combination. For a single statement p, there are only 2 rows (p = True, p = False), since p is either true or false with no other option.

Two rows, because p has exactly two possible truth values. This doubling pattern is the reason a truth table for n independent statements needs 2ⁿ rows — each additional statement doubles the number of combinations, the same counting idea Unit 3 turns into the multiplication principle.
Why bother with a table instead of just reasoning it out "¬p is true when p is false" sounds obvious enough not to need a table. It stops being obvious the moment you're four connectives deep in a compound statement like ¬(p ∧ q) ∨ (¬p ∧ r) — at that point, working row by row through every combination is the only reliable way to know its truth value for certain, rather than guessing. The table is mechanical on purpose: it never depends on intuition, which is exactly what makes it trustworthy as a proof tool.

1. Which of the following is a statement in the logical sense?

"144 is a perfect square" is declarative and has a definite truth value (true, since 12² = 144), unlike a request, a question, or a sentence whose truth depends on an unbound variable x.

2. Why is "This sentence is false" excluded from the definition of a statement?

If it's true, then it's false (since it says it's false); if it's false, then it's true. Neither assignment is consistent, so the definition of "statement" deliberately requires a definite, non-contradictory truth value.

3. How many rows does the truth table for ¬p have, and why?

A truth table has one row per combination of input truth values; with a single input p that can be T or F, there are exactly 2 combinations, regardless of what p actually says.

4. Fill in the blank: if p is the true statement "9 is odd," then ¬p is the statement "9 is odd" negated, which is ___.

Negation flips the truth value: since "9 is odd" is true, ¬p ("9 is not odd") is false.

5. Fill in the blank: a truth table for a compound statement built from n independent statements needs ___ rows to cover every combination.

Each additional independent statement doubles the number of combinations (each existing row splits into a T row and an F row for the new statement), so n statements produce 2ⁿ rows total.
