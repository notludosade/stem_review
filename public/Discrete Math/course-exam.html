1. Let p be false and q be true. What is the truth value of p → q?

Implication is false in exactly one case — p true, q false. With p false, that case can't occur, so p → q is automatically true.

2. What is the truth value of ∀x ∈ ∅, x is a unicorn?

A universally-quantified statement over the empty set is always true, regardless of the predicate — there's no element that could ever be a counterexample.

3. Fill in the blank: negating a "for all" (∀) statement produces a statement using the "___" quantifier instead.

¬(∀x, P(x)) is equivalent to ∃x, ¬P(x) — negating "for all" always produces an existential statement.

4. Which of these is true for every set B?

∅ ⊆ B holds vacuously for every set B, including B = ∅ itself.

5. f: ℤ → ℤ is defined by f(x) = x + 3. Which classification is correct?

x₁+3=x₂+3 forces x₁=x₂ (injective), and any target y is reached by x=y−3 (surjective) — both hold.

6. Fill in the blank: an infinite set that has a bijection with ℕ is called ___.

Countably infinite sets are exactly those in bijection with ℕ, like ℤ and ℚ.

7. A 3-person subcommittee, with no distinct roles, is chosen from 8 people. How many subcommittees are possible?

No distinct roles means order doesn't matter, so this is a combination: C(8,3) = 56, not a permutation.

8. Row 4 of Pascal's triangle is 1, 4, 6, 4, 1. What is the coefficient of x³y in the expansion of (x+y)⁴?

The Binomial Theorem pairs row 4's second coefficient (4) with x³y¹.

9. Fill in the blank: 6! = ___.

6! = 6·5·4·3·2·1 = 720.

10. Among 100 people, 40 own a car; of those 40, 30 also own a bike. What is P(Bike | Car)?

P(Bike | Car) = 30/40 = 3/4.

11. A random variable X takes value 6 with probability 0.2 and value −1 with probability 0.8. What is E[X]?

E[X] = 6(0.2) + (−1)(0.8) = 1.2 − 0.8 = 0.4.

12. Fill in the blank: flipping a fair coin 4 times, the sample space has ___ equally-likely outcomes.

Each flip independently doubles the outcome count: 2⁴ = 16.

13. A graph has 8 edges. What is the sum of all vertex degrees?

By the Handshake Theorem, the degree sum always equals 2|E| = 2(8) = 16.

14. A tree has 10 vertices. How many edges does it have?

A tree on n vertices always has exactly n − 1 edges: 10 − 1 = 9.

15. Fill in the blank: an odd cycle (like a 5-cycle or 7-cycle) has chromatic number ___.

Alternating 2 colors around an odd number of vertices always forces a clash at the seam, so a 3rd color is required.

16. Is 1 a prime number?

1 is neither prime nor composite by definition — excluding it is what preserves the Fundamental Theorem of Arithmetic's uniqueness guarantee.

17. What is 25 mod 7?

25 = 7(3) + 4, so 25 mod 7 = 4.

18. Fill in the blank: applying the Division Algorithm to a=38, b=5 gives 38 = 5(7) + ___.

5(7) = 35, and 38 − 35 = 3, which satisfies 0 ≤ r < 5.

19. In an induction proof of P(n) for all n ≥ 1, what does the inductive step prove?

The inductive step is a conditional argument — assuming P(k) to derive P(k+1) — separate from the base case's direct verification of P(1).

20. What is the characteristic equation of aₙ = 5aₙ₋₁ − 6aₙ₋₂?

Substituting aₙ → xⁿ and dividing out xⁿ⁻² gives x² = 5x − 6, matching the recurrence's own coefficients.

21. Fill in the blank: using F(0)=0, F(1)=1, F(n)=F(n−1)+F(n−2), F(7) = ___.

The sequence runs 0, 1, 1, 2, 3, 5, 8, 13 — F(7) = 13.
