Multi-Layer Perceptrons and the Forward Pass

One perceptron can only draw a straight line between classes. Stack several into layers, and that limitation disappears.

Lesson 13 → Contents Glossary →

A multi-layer perceptron (MLP) arranges perceptrons into layers: an input layer (the raw data), one or more hidden layers, and an output layer. Data flows through every layer in sequence — each layer's output becomes the next layer's input — in what's called a forward pass.

Python — NumPy 
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

# Layer 1: 2 inputs -> 3 hidden neurons
W1 = np.array([[0.2, 0.4, -0.5], [0.1, -0.3, 0.8]])
b1 = np.array([0.0, 0.1, -0.2])

# Layer 2: 3 hidden neurons -> 1 output
W2 = np.array([[0.6], [0.9], [-0.4]])
b2 = np.array([0.05])

def forward_pass(x):
    hidden = sigmoid(x @ W1 + b1)      # every hidden neuron runs Lesson 11's math at once
    output = sigmoid(hidden @ W2 + b2)  # the hidden layer's output feeds the next layer
    return output

x = np.array([1.0, 0.5])
print(forward_pass(x))   # a single number between 0 and 1

Each of the three hidden neurons is exactly Lesson 11's perceptron — its own weights, its own bias, its own activation — just computed in parallel via one matrix multiplication instead of three separate function calls. The hidden layer is what a single perceptron can't provide alone: a way to combine the raw inputs into new, learned representations before the output layer ever sees them, which is what lets an MLP separate patterns a single straight-line perceptron cannot. Real code rarely writes the matrix math out by hand like this — scikit-learn's MLPClassifier handles it directly — but the forward pass itself is precisely this sequence of layer-by-layer transformations, however it's implemented.

Definition A multi-layer perceptron (MLP) is a network of perceptrons arranged in an input layer, one or more hidden layers, and an output layer. A hidden layer transforms the input into a new, learned representation before the output layer. A forward pass is data flowing through every layer in sequence to produce a final output.
Why it matters here "Depth" in deep learning, covered starting in Unit 5, literally means stacking more hidden layers than this two-layer example — the mechanism doesn't change, only the count.
