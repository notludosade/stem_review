1. A request to an LLM API is sent at 2:00:00.000 and a response arrives at 2:00:01.200. What is that 1.2-second gap called?

Latency is exactly this: the time between sending a request and receiving a response.

2. Fill in the blank: because real API calls are priced per token, a tool used by thousands of people on the same handful of repeated questions pays that ___ again for every single one, unless a cache intervenes.

Every call has a real dollar cost, priced per token, that repeats for every request unless caching avoids it.

3. Two different tickets, both reading exactly "My account is locked", arrive an hour apart. Answer both parts about triage_ticket_cached:

(a) What happens on the second identical arrival?

(b) Fill in the blank: this dictionary that stores a previous result for instant reuse is called a ___.

(a) An identical hash key means the second request finds the first result already stored, skipping the API call. (b) That store of previous results is a cache.

4. Two tickets — "my account is locked" and "I can't log into my account" — describe the same real problem in different words. Answer both parts:

(a) Would triage_ticket_cached's hash-based cache treat these as the same request?

(b) Fill in the blank: catching near-duplicate wording like this would need a cache keyed on ___ instead of exact text.

(a) A hash-based cache only matches byte-identical text, so differently worded tickets miss. (b) Embeddings-based similarity can catch near-duplicate meaning that exact hashing misses.

5. A model's accuracy was verified once at launch and never checked again. Six months later, what could be silently happening according to Lesson 26?

A one-time launch check tells you nothing about drift quietly opening up months later.

6. Fill in the blank: appending a log entry to triage_log.jsonl on every single call is an example of ___ — building a record over time rather than checking a system once and assuming it holds forever.

Continuously logging inputs, outputs, and performance over time is exactly what monitoring means.

7. A human reviewer starts disagreeing with the model's urgency calls noticeably more often than they did at launch, with no change in how tickets are written. Answer both parts:

(a) What does this suggest?

(b) Fill in the blank: rising reviewer disagreement with no real change in the tickets themselves is exactly the kind of signal ongoing ___ is built to catch.

(a) A steady rise in disagreement, with no real change in the tickets, is exactly the kind of signal drift produces. (b) Only ongoing monitoring can surface a slow trend like this.

8. Suppose PROMPT_VERSIONS held only one prompt, overwritten each time it changed, with no history kept. What would this make impossible?

Without a previous version still on hand, there is nothing left to revert to once a regression is caught.

9. Code written against the alias "gpt-4o-mini" behaves differently one morning, with no line of code having changed. Answer both parts:

(a) What most likely happened, and what would have prevented it?

(b) Fill in the blank: locking in an exact, dated model snapshot instead of a movable name is called version ___.

(a) A movable alias can silently point to a different model over time; a pinned snapshot cannot. (b) That practice is called version pinning.

10. Answer both parts about the rollback() function from Lesson 27:

(a) What does calling it actually do?

(b) Fill in the blank: this act of reverting to a previous known-good version after a regression is called a ___.

(a) It simply switches ACTIVE_VERSION back to "v1", without touching the underlying model. (b) That reversion is called a rollback.
