# Notes

## Course outline (self-designed, informed by DeepLearning.AI / 3Blue1Brown / W&B pacing)
1. Unit 1 — What AI/ML Actually Is (taxonomy: AI vs ML vs DL; supervised/unsupervised/reinforcement)
2. Unit 2 — Data: The Fuel of AI (datasets, features/labels, cleaning, train/validation/test splits, overfitting)
3. Unit 3 — Classical Machine Learning (linear & logistic regression, decision trees, accuracy/precision/recall)
4. Unit 4 — Neural Network Fundamentals (perceptron → MLP, forward pass, loss, gradient descent, backprop intuition)
5. Unit 5 — Deep Learning Architectures (CNNs for vision, RNNs/LSTMs for sequence, Transformers/attention)
6. Unit 6 — Working with Pretrained Models & APIs (LLM APIs, embeddings, prompt engineering, fine-tuning vs RAG)
7. Unit 7 — Building a Real AI Application (define the problem, choose the approach, build, integrate)
8. Unit 8 — Deploying & Maintaining AI in Production (serving, latency/cost, monitoring/drift, versioning)
9. Unit 9 — Responsible AI in the Real World (bias, hallucination, safety, human-in-the-loop — closes the loop back to Computer Programming Ethics)

Roughly 3–4 lessons per unit (~27–30 lessons total). Final course in the strand — build order across the whole "Computer Programming" area is Ethics → Computer Programming 1 → Computer Programming 2 → AI Developer.

## Conventions
- Lives directly under `STEM+/` — flat whole-course lesson numbering, matching the other three Computer Programming courses.
- Code examples here lean Python-primary (the dominant real-world AI/ML language) rather than the four-language-parallel format used in Computer Programming 1 & 2 — flag this deliberately in Unit 1's first lesson so it doesn't read as an inconsistency.
- Units 1–5 (theory/foundations) lean more knowledge-heavy; Units 6–9 (applied) lean more skills-heavy with an actual build. Keep that balance visible — don't let the course drift into all-theory or all-tutorial.
- Unit 9 should explicitly cross-reference `../Computer Programming Ethics/` rather than re-deriving general ethics principles from scratch.
- Verification workflow: same per-unit batching as prior courses.
