Parallel Circuits

Multiple paths share the same voltage but split the current — and adding more paths only ever makes it easier for current to flow.

← Lesson 3 Lesson 5 → Contents Glossary →

Parallel Circuits In a parallel circuit, components are connected across the same two points, so each one experiences the same voltage, while current splits between the branches. Equivalent resistance: 1/Req = 1/R₁ + 1/R₂ + 1/R₃ + ...
Why voltage is identical across every parallel branch Since all parallel branches connect the exact same two points (nodes), and potential (Lesson 5, Unit 2) is a property of a location, every branch necessarily spans the same potential difference — there's only one voltage between two fixed points, regardless of how many separate paths connect them.
Why adding parallel branches always decreases equivalent resistance Adding another parallel branch is like adding another lane to a highway: it gives current an additional path to flow through without removing any existing paths, so the total opposition to current flow can only decrease (or, in the trivial case of an infinite resistor branch, stay the same) — never increase. This is the opposite behavior from series circuits, where adding more resistors only ever increases total resistance.
Example: equivalent resistance in parallel Two resistors, 6 Ω and 3 Ω, are connected in parallel. 1/Req = 1/6 + 1/3 = 1/6 + 2/6 = 3/6 = 1/2, so Req = 2 Ω — notice this is smaller than either individual resistor, as expected.
Example: current through each parallel branch A 12 V battery is connected across the two resistors above (6 Ω and 3 Ω in parallel). Each branch independently sees the full 12 V: I₁ = V/R₁ = 12/6 = 2 A, I₂ = V/R₂ = 12/3 = 4 A. Total current from the battery: Itotal = I₁ + I₂ = 2 + 4 = 6 A — matching I = V/Req = 12/2 = 6 A.

1. In a parallel circuit, each branch experiences:

Since all branches span the same two points, they all experience the same potential difference; current instead splits between branches.

2. Adding an additional resistor in parallel to an existing circuit will always:

An additional parallel path can only make it easier (or equally easy) for current to flow overall, decreasing equivalent resistance.

3. Two resistors, 4 Ω and 4 Ω, are connected in parallel. What is the equivalent resistance?

1/R_eq = 1/4 + 1/4 = 2/4 = 1/2, so R_eq = 2 Ω.

4. Fill in the blank: a circuit arrangement where components share the same two connection points, and thus the same voltage, is called a ___ circuit.

Parallel branches share voltage but split current, and equivalent resistance combines via reciprocal addition.
