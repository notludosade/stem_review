Common Asset Formats (Textures, Models, Audio) at a High Level

An unpacked archive is a folder full of unfamiliar file extensions. This lesson is a map, at a high level, of what's actually inside each major asset type — enough to recognize what you're looking at, not a deep format specification.

← Lesson 4 Lesson 6 → Contents Glossary →

Once Lesson 4's extractor has produced a folder tree, the files inside break down into a small number of asset categories, each with its own common formats. None of this requires deep technical mastery of any one format to start modding — most modding tools already understand the popular ones and handle the conversion automatically. What matters is recognizing which category a file belongs to and roughly what it controls.

Textures

A texture map is an image applied to the surface of a 3D model — color, roughness, bumps, glow, all painted onto the model's surface using a 2D image. Games commonly use DDS (DirectDraw Surface), a format pre-compressed specifically for how graphics hardware reads it, alongside more familiar formats like PNG, and plenty of studio-proprietary compressed variants. The reason DDS specifically shows up so often is performance: it's designed to be read directly by the graphics card with minimal extra processing.

Models

A mesh is the 3D geometry of an object — a grid of points, edges, and surfaces defining its shape. A model file bundles that mesh with texture coordinates (how the 2D texture wraps onto the 3D shape) and, for anything that moves, a rig or skeleton — an internal bone structure the mesh deforms around during animation. Common interchange formats include .fbx and .obj, though in-game the model is often stored in a studio-proprietary format that a modding tool converts to and from one of these interchange formats.

Audio

Sound effects and music are commonly stored as .ogg or .wav files, but many games route audio through an audio bank system — middleware like FMOD or Wwise that manages which sound plays when, with what volume and pitch variation, rather than the game code calling a raw sound file directly. Modding a bank-based game's audio often means replacing the file inside the bank while keeping the bank's own reference to it intact, not simply dropping in a new file.

Definition A proprietary format is one designed and documented (if at all) by a single studio or engine vendor, versus an open format like PNG or OBJ, published and usable by anyone — proprietary formats are what make community-built converters and extractors necessary in the first place.
Why it matters here Unit 4's asset-replacement techniques all depend on recognizing what kind of file you're editing and what format the game engine actually expects back. A texture in the wrong format, a mesh with a different vertex count than its rig expects, or a raw file dropped in place of a bank reference are the three most common ways a "simple" asset swap breaks the game instead of improving it.

Check your recall

No peeking back up — answer from memory first, then check.

1. Why does DDS show up so often as a game texture format specifically?

DDS's specific advantage is performance — it's designed for direct, low-overhead reading by graphics hardware.

2. What does a model's "rig" or "skeleton" actually provide?

A rig or skeleton is the internal bone structure that lets a mesh deform realistically when animated — separate from the mesh's raw geometry.

3. Why can't audio in a bank-based system (FMOD, Wwise) always be replaced just by dropping in a new sound file?

A bank system manages which sound plays when and how, so replacing audio usually means editing the file the bank already references, not adding a loose new one.

4. Fill in the blank: the 3D geometry of an object — points, edges, and surfaces defining its shape — is called its ___.

The mesh is the raw shape; the rig or skeleton is a separate structure describing how that shape moves.

5. Fill in the blank: a 2D image applied to a 3D model's surface to define its color, roughness, or other visual detail is called a ___ ___.

Texture maps are what most cosmetic reskins (Lesson 1) actually change.
