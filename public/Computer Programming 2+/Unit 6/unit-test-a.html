1. What is the key structural difference between a tree and a general graph?

A tree is really just a graph with the added guarantee of no cycles and exactly one path between any two nodes.

2. Fill in the blank: mapping each node to the list of nodes it directly connects to is called an ___ list.

This is the most common way to represent a graph in code.

3. What makes a BFS a "multi-source" BFS?

Seeding the queue with multiple starting nodes at once is the entire idea — everything else is standard BFS.

4. Fill in the blank: BFS gives correct shortest-path distances specifically on ___ graphs, where every edge costs the same.

Once edges have different costs, plain BFS no longer guarantees the shortest path is found first.

5. In Kahn's algorithm, if the queue empties before every node has been visited, what does that indicate?

A cycle means every course in it always has at least one unmet prerequisite, so none can ever reach in-degree zero.

6. Given the grid [['1','1','0'],['0','1','0'],['0','0','1']], the DFS scan starts at (0,0). Answer both parts:

(a) Which cells get marked visited (sunk to '0') as part of that first DFS call, and how many land cells does it cover?

(b) Fill in the blank: after DFS finishes at (2,2) as well, the total number of islands found is ___.

(a) From (0,0), DFS can move right to (0,1) then down to (1,1); (2,2)'s only land neighbors would be at (1,2) or (2,1), both water, so it isn't reached by this first call. (b) The outer loop then finds (2,2) still unvisited and starts a second DFS there, for a total of 2 islands.

7. For grid [[2,1,1],[1,1,0],[0,1,1]] (rotten orange at (0,0), fresh oranges elsewhere, 0 = empty), answer both parts:

(a) How many fresh oranges remain after minute 1 of the multi-source BFS?

(b) Fill in the blank: continuing this simulation minute by minute, every fresh orange eventually rots, and the total number of minutes elapsed is ___.

(a) (0,0) is the only initially rotten orange, and its two orthogonal neighbors, (0,1) and (1,0), are fresh — both rot during minute 1, leaving 4 of the original 6 fresh oranges (at (0,2), (1,1), (2,1), (2,2)). (b) The rot keeps spreading outward level by level — (0,2) and (1,1) rot in minute 2, (2,1) in minute 3, and (2,2) last in minute 4 — so the process takes 4 minutes total.

8. For numCourses=4 with prerequisites [[1,0],[2,0],[3,1],[3,2]] (course1 needs 0; course2 needs 0; course3 needs 1 and 2), answer both parts:

(a) What is course3's initial in-degree, and which courses start in the queue?

(b) Fill in the blank: processing the queue in order eventually visits all 4 courses with no cycle, so canFinish returns ___.

(a) Course3 lists two prerequisites (1 and 2), giving it in-degree 2; only course0 has in-degree 0 at the start, since nothing points into it. (b) Processing course0 unlocks courses 1 and 2 (dropping both to in-degree 0), and once both of those are processed, course3's in-degree finally reaches 0 too — all 4 courses get visited, so no cycle exists and canFinish returns true.

9. For edges = [[1,2],[1,3],[2,3]] processed in order (parent array initialized so each node points to itself), answer both parts:

(a) What happens when the algorithm reaches edge [2,3]?

(b) Fill in the blank: by the time edge [2,3] is processed, nodes 1, 2, and 3 already share a root because of the earlier edges [1,2] and [1,___].

(a) After processing [1,2] and [1,3], nodes 1, 2, and 3 have all been merged into one group; when [2,3] is checked, find(2) and find(3) already return the same root, so union returns false and [2,3] is the redundant edge. (b) The earlier edges [1,2] and [1,3] are exactly what already connected nodes 2 and 3 indirectly, through node 1, before edge [2,3] ever gets processed.

10. For times=[[1,2,1],[2,3,2],[1,3,5]], n=3, k=1, trace Dijkstra's algorithm. Answer both parts:

(a) After processing node 1 (distance 0) and node 2 (distance 1), what entries are in the heap, and what happens when (5,3) is eventually popped?

(b) Fill in the blank: since every node is reached, the final signal delay time (the maximum distance across all nodes) is ___.

(a) Processing node 2 relaxes the edge to node 3, pushing (3,3) — a shorter candidate than the (5,3) pushed directly from node 1; node 3 gets finalized at distance 3 first, so when the stale (5,3) entry is later popped, it's correctly skipped since node 3 is already in dist. (b) With dist = {1:0, 2:1, 3:3} covering all 3 nodes, the answer is the maximum of these, 3 — the time for the last, slowest-to-reach node to receive the signal.
