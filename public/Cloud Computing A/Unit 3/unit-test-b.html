Unit 3 Test — Version B

Storage. 10 questions covering every lesson in this unit. Score 90% or higher to clear this unit.

← Course Contents ← Version A

1. A team needs to store millions of user-uploaded files, each written once and read many times, retrieved through a simple API rather than mounted as a filesystem. Which storage model fits?

Whole-file API access at massive scale is exactly what object storage is built for.

2. Fill in the blank: block storage's low-latency, small, random reads and writes make it the right fit for a production ___'s live data files.

Databases make frequent small random reads/writes, which block storage is optimized to handle.

3. A fleet of 30 render servers all need to read and write the same shared media library at the same time. Which storage model fits, and why?

File storage exists specifically for concurrent multi-machine access, unlike block storage's single-attachment model.

4. Why would putting a busy database's data files directly on object storage cause performance problems?

The mismatch between whole-object replacement and small in-place database writes is exactly why this pairing performs poorly.

5. A provider advertises "eleven 9s" of durability for its object storage. What is this claiming?

"9s" of durability describe data-survival probability, not reachability, speed, or price.

6. A service targets 99.999% availability. Answer both parts:

(a) Roughly how much downtime per year does this allow?

(b) Compared to 99% availability, achieving 99.999% typically requires...

99.999% allows only about 5 minutes of downtime a year, and reaching that level from a lower tier demands significantly more redundancy and engineering investment.

7. Fill in the blank: each additional 9 of availability costs proportionally more engineering effort for a shrinking absolute benefit — a pattern known in general as ___.

Diminishing returns describes exactly this pattern of shrinking benefit per unit of added effort or cost.

8. What is the tradeoff of moving a file from a standard "hot" storage tier to an archive "cold" tier?

Cold/archive tiers trade slower retrieval for significantly lower cost per gigabyte.

9. Fill in the blank: instead of manually tracking every file's access pattern, engineers set up an automated ___ policy to move data between storage tiers based on a rule.

Lifecycle policies automate what would otherwise be tedious manual tier management.

10. According to this unit's decision framework, in what order should access pattern, durability/availability needs, and access frequency be evaluated?

Access pattern narrows the storage model, then durability/availability sets the guarantee level, then access frequency sets the tier — in that order.
