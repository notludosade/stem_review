1. What does Infrastructure as Code mean?

IaC treats infrastructure like source code, provisioned by a tool rather than clicked by hand.

2. Fill in the blank: storing infrastructure configuration in the same kind of ___ repository as application code is what makes each change a reviewable, revertible diff.

Version control gives infrastructure changes a history a console click never has.

3. What is the key difference between an imperative and a declarative approach to infrastructure?

Steps-to-run vs. desired-state-to-reach is the defining difference between the two.

4. Fill in the blank: an operation where running it once has the same effect as running it many times is described as ___.

Idempotency is what makes reapplying a declarative configuration file safe, no matter how many times it runs.

5. What is configuration drift?

Drift comes specifically from changes the IaC file doesn't know about.

6. Two engineers each provision a "staging" environment manually through a console, on different days. Answer both parts:

(a) Compared to using an IaC file for both, the two manual environments are likely to be...

(b) Switching both to the same IaC configuration file would mainly improve...

The same configuration file applied twice produces structurally identical results, unlike repeated manual clicks.

7. An infrastructure change is made by editing a console setting directly, with no record of who changed it or why. Answer both parts:

(a) Compared to a version-controlled IaC change, this console edit is missing...

(b) If this change isn't reflected in the IaC file, it will eventually be classified as...

Unreviewed console changes both lack a history and can silently become drift.

8. An imperative "create 3 servers" script is accidentally run twice by a retrying pipeline. Answer both parts:

(a) The likely result is...

(b) A declarative "desired count = 3" configuration run twice would instead result in...

Declarative tools compare against desired state and only act on the gap, unlike imperative scripts that just re-execute steps.

9. A declarative IaC tool is applied against an environment that already matches its configuration file exactly. Answer both parts:

(a) The tool will...

(b) This safe-to-reapply behavior is called...

Idempotency guarantees reapplying an unchanged configuration is always a no-op.

10. A firewall rule is opened manually for an emergency fix and never added to the IaC file. Answer both parts:

(a) Three months later, this unrecorded rule is an example of...

(b) Running scheduled reconciliation regularly would have...

Regular reconciliation is what actually surfaces silent drift before it becomes a mystery.
