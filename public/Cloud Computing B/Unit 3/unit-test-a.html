1. What is the core difference between Continuous Delivery and Continuous Deployment?

The manual release gate is the entire distinction between the two.

2. Fill in the blank: the manual approval step that, if removed, turns Continuous Delivery into Continuous Deployment is called a ___.

Removing the release gate is literally the only change needed to go from Delivery to Deployment.

3. What makes a rollback so fast in a blue-green deployment?

Keeping the old environment alive is what makes an instant switch back possible.

4. How does a canary release limit the impact of a bad deployment?

A small initial traffic slice bounds a canary's blast radius.

5. Why can flipping a feature flag off mitigate an incident faster than a rollback?

Skipping the entire build-test-deploy cycle is what makes a flag flip so fast.

6. A team's test suite and canary monitoring are mature enough that a human approval step adds delay without adding real safety. Answer both parts:

(a) Removing the release gate entirely would move this team from Delivery to...

(b) This decision is best described as...

Moving to Continuous Deployment reflects trust in the pipeline, not an obligation.

7. A regulated company requires a human to sign off before any change reaches production. Answer both parts:

(a) This company is practicing...

(b) Keeping this gate primarily reflects...

A kept gate can reflect a deliberate business or regulatory need, not pipeline quality.

8. A new version is deployed to the green environment while blue keeps serving all live traffic. Answer both parts:

(a) Once green is verified, traffic is switched by...

(b) If a bug appears right after the switch, blue-green means users affected before rollback are...

Blue-green's switch has only two states, unlike canary's gradual traffic shifting.

9. A canary release starts at 5% of traffic and a bug is caught before the percentage ever increases further. Answer both parts:

(a) The number of users who ever saw the bug was limited to roughly...

(b) Catching the bug this early specifically required...

Canary's advantage depends on monitoring good enough to detect a problem in a thin traffic slice.

10. A deploy runs a database migration and then breaks. Answer both parts:

(a) A straightforward rollback of the application code alone might be unsafe because...

(b) The safer response in a case like this is usually...

Database migrations are one of the few changes a simple rollback can't cleanly undo.
