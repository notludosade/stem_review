1. A Dog class inherits from Animal and overrides makeSound(). If speak() is called through a reference typed as Animal but pointing to a Dog instance, which version of makeSound() runs?

Dynamic dispatch resolves the method based on the object's actual runtime type, not the variable's declared type.

2. Fill in the blank: in C++, without the virtual keyword on a base class method, calling it through a base-class pointer to a derived object uses ___ binding instead of dynamic dispatch.

Without virtual, C++ resolves the call at compile time (static/early binding) based on the pointer's declared type.

3. Which best describes "defensive" (LBYL — look before you leap) error handling?

LBYL checks preconditions up front; EAFP (its counterpart) attempts the operation and handles the resulting exception.

4. Fill in the blank: in Python, using EAFP style to access a dictionary key that might not exist, the exception type typically caught is ___.

Accessing a missing dictionary key in Python raises a KeyError, which EAFP-style code wraps in a try/except.

5. Which operation is O(1) at the front of a singly linked list but O(n) at the front of a dynamic array?

A linked list just rewires one pointer to insert at the front; an array must shift every existing element over.

6. Fill in the blank: a stack follows ___ order — the last element added is the first removed.

LIFO (Last In, First Out) is the defining property of a stack, as opposed to a queue's FIFO order.

7. What is missing from a recursive function that causes infinite recursion (and eventually a stack overflow)?

Without a base case that the recursive calls actually reach, the function keeps calling itself until the call stack overflows.

8. Fill in the blank: naive recursive Fibonacci recomputes the same subproblems repeatedly; caching computed results to avoid this is called ___.

Memoization stores results of expensive calls so repeated subproblems can be looked up instead of recomputed.

9. Binary search requires which precondition to work correctly?

Binary search repeatedly halves the search range by comparing to a midpoint — that only works if the data is sorted.

10. Fill in the blank: an algorithm whose runtime grows as the square of the input size is described as O(___).

O(n²) describes quadratic growth, typical of algorithms like bubble sort that compare every pair of elements.

11. Which best describes a memory leak?

A leak is memory that stays allocated (and unreachable/unused) because nothing ever frees or garbage-collects it.

12. Fill in the blank: in C++, a raw pointer that still points to memory which has already been freed is called a ___ pointer.

A dangling pointer references memory that's no longer valid, which is why dereferencing it causes undefined behavior.

13. What is the purpose of a unit test?

Unit tests check small, isolated pieces of behavior automatically, so regressions are caught quickly and repeatably.

14. Fill in the blank: the debugging strategy of repeatedly narrowing down which half of the code contains a bug, analogous to binary search, is called ___.

Bisecting applies binary search's halving strategy to isolating a bug instead of finding a value in a list.

15. Why does C++ alone typically need a separate header file (.h) from its implementation (.cpp) when organizing a multi-file program?

C++'s separate compilation model needs a declaration (header) visible wherever a class or function is used, distinct from its one definition (implementation file).

16. Fill in the blank: combining OOP, error handling, a hash map, sorting, and ownership into one working program, as this course's final project does, is called a ___ project.

A capstone project integrates everything learned across a course into one cohesive piece of work.
