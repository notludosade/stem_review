1. Cat inherits from Animal but does not override speak(). What happens when you call cat.speak()?

Cat automatically has everything Animal defines, including speak(), until Cat provides its own override.

2. Fill in the blank: Dog defines its own speak() that replaces Animal's version whenever it's called on a Dog instance. This is called ___ the method.

Overriding replaces the parent's version for that specific subclass, without touching Animal's own speak().

3. What is the defining feature of an interface, regardless of which language you're using?

Flyable only names fly() — it says nothing about how each implementing class actually flies.

4. Fill in the blank: JavaScript's style of treating any object with a fly() method as "Flyable," with no formal declared contract, is called ___ typing.

"If it walks like a duck and quacks like a duck" — JavaScript relies purely on the method existing, with no compiler check.

5. In C++, what specifically causes speak() to run the correct overridden version when called through an Animal* pointer?

Without virtual, C++ uses static dispatch and would call Animal's version for every element, based on the pointer's declared type rather than the object's real type.

6. Both parts are about how a subclass's constructor relates to its parent's constructor:

(a) In Python, Dog(Animal) defines no constructor of its own. Which constructor actually runs when you create a Dog?

(b) Fill in the blank: in Java, the keyword Dog's constructor uses to explicitly call Animal's constructor is ___(name).

(a) Python and JavaScript's Dog classes skip defining a constructor because the parent's runs automatically when there isn't one to override. (b) Java requires the subclass to explicitly initialize the inherited parts of the object via super(name); C++ does the equivalent with Animal(name) in its initializer list.

7. Both parts are about C++'s way of expressing an interface-like requirement:

(a) How does C++ create interface-like behavior without a dedicated interface keyword?

(b) Fill in the blank: in C++, you mark a method pure virtual, with no implementation, by writing = ___ after its declaration.

(a) virtual std::string fly() = 0; declares a pure virtual method — no body, and any subclass must supply one to become instantiable. (b) The = 0 is what marks the method pure virtual instead of giving it an ordinary body.

8. Both parts trace the same polymorphic loop in two different languages. (Dog.speak() returns "{name} says Woof!" and Cat.speak() returns "{name} says Meow!", as established elsewhere in this unit.)

(a) In Java: List<Animal> animals = List.of(new Dog("Rex"), new Cat("Tom")); for (Animal a : animals) System.out.println(a.speak()); — what prints, in order?

(b) What must be true about C++'s Animal::speak() for an equivalent loop over std::vector<Animal*> to call each object's overridden version correctly?

(a) Java's for-each loop calls speak() on each object; each one runs its own overridden version, in list order. (b) Without virtual, C++ would call Animal's version for every element regardless of the object's real type — the exact scenario Lesson 1 flagged for later.

9. Both parts are about C++'s std::vector<Animal*> animals = { new Dog("Buddy"), new Cat("Whiskers") };

(a) Why does this store Animal* pointers instead of plain Animal values?

(b) Fill in the blank: this bug — truncating a subclass object down to just its base-class part — is called object ___.

(a) Pointers (or references) preserve the object's actual type, which is what virtual dispatch depends on. (b) Object slicing is exactly the bug that storing by value would introduce here.

10. Both parts compare how strictly each language enforces an interface-like contract:

(a) Which language enforces interface-like contracts only by convention, with nothing preventing a missing method until it's actually called?

(b) Fill in the blank: Python's compiler-checked-at-runtime enforcement is opt-in — a class only gets it by inheriting ___ and marking methods @abstractmethod.

(a) JavaScript has no interface keyword and no abc-style module — a missing fly() only surfaces as a crash when called. (b) from abc import ABC, abstractmethod is what gives Python this enforcement, and only for classes that opt in.
