Vector Fields

Every function so far has assigned a number, or at most a fixed vector at one point, to an input. A vector field assigns a whole arrow to every single point in the plane at once.

← Lesson 15 Lesson 17 → Contents Glossary →

1. An arrow at every point

Definition — Vector Field A vector field in the plane, F(x,y) = ⟨P(x,y), Q(x,y)⟩, assigns a vector — not a number — to every point (x,y) in its domain. In space, F(x,y,z) = ⟨P,Q,R⟩ does the same with a third component. Drawn on paper, a vector field looks like a whole grid of arrows, one rooted at each sample point, each with its own length and direction.
Method — Recognizing Common Field Shapes A radial field like F = ⟨x,y⟩ points directly away from (or toward) the origin everywhere — the velocity field of something expanding outward from a source. A rotational field like F = ⟨−y,x⟩ circles around the origin, always perpendicular to the position vector — like a fluid spinning in place. A gradient field F = ∇f, built from some scalar function f, always points toward increasing f — a shape Lesson 18 studies closely.
Worked Example F(x,y) = ⟨−y, x⟩ at (1,0): F(1,0) = ⟨0, 1⟩ — straight up, perpendicular to the position vector ⟨1,0⟩, confirming rotational behavior. Compare G(x,y) = ⟨x, y⟩ at (1,0): G(1,0) = ⟨1, 0⟩ — pointing directly away from the origin, along the same line as the position vector itself, confirming radial behavior.
Why This Matters Wind velocity across a map, the flow of a river, the force of gravity or an electric field around a charge — these are the physical quantities vector fields exist to model. Every remaining lesson in this unit and the next two builds on exactly this object: line integrals measure work done moving through a field, and Green's, Stokes', and the Divergence Theorem all describe how a field behaves across a whole region at once.

1. A vector field F(x,y) = ⟨P(x,y), Q(x,y)⟩ assigns to each point (x,y):

Unlike f(x,y), whose output is a bare number, a vector field's output at every point is itself a vector — magnitude and direction both.

2. For F(x,y) = ⟨-y, x⟩, F(1, 0) = ___ (format: <a,b>)

F(1,0) = ⟨-(0), 1⟩ = ⟨0, 1⟩.

3. F(x,y) = ⟨x, y⟩ is an example of a:

At every point, F points in the same direction as the position vector itself — directly away from the origin.

4. F(x,y) = ⟨-y, x⟩ is an example of a:

F(x,y) = ⟨-y,x⟩ is always perpendicular to the position vector ⟨x,y⟩, circling the origin rather than pointing toward or away from it.
