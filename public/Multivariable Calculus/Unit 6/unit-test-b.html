1. A vector field F(x,y) = ⟨P(x,y), Q(x,y)⟩ differs from a scalar field f(x,y) because its output at each point is:

A vector field assigns an entire arrow, not a bare number, to every point in its domain.

2. Fill in the blank: for F(x,y) = ⟨3x, -2y⟩, F(2, 4) = ___ (format: <a,b>)

F(2,4) = ⟨3(2), -2(4)⟩ = ⟨6, -8⟩.

3. For C parametrized by r(t), t ∈ [a,b], ∫C F · dr is computed as:

The line integral dots the field, evaluated along the path, with the path's own tangent vector.

4. Traversing curve C backward, from B to A instead of A to B, changes ∫C F · dr by:

r'(t) reverses direction when the path is reversed, flipping the sign of the dot product at every instant.

5. A potential function f for a conservative field F satisfies:

By definition, a conservative field is exactly the gradient of its potential function.

6. For F(x,y) = ⟨x, y⟩, answer both parts:

(a) At every point, this field points:

(b) Fill in the blank: F(3, 4) = ___ (format: <a,b>)

(a) F = ⟨x,y⟩ points the same direction as the position vector at every point — a source, radiating outward. (b) F(3,4) = ⟨3,4⟩.

7. For F(x,y) = ⟨x,y⟩ along r(t) = ⟨3t, t⟩, t from 0 to 1, answer both parts:

(a) F(r(t)) · r'(t) simplifies to:

(b) Fill in the blank: ∫C F · dr = ___

(a) r'(t) = ⟨3,1⟩, F(r(t)) = ⟨3t,t⟩, so the dot product is 3t(3) + t(1) = 9t + t = 10t. (b) ∫₀¹ 10t dt = 5.

8. For F(x,y) = ⟨2xy³, 3x²y²+4⟩, answer both parts:

(a) Fill in the blank: ∂P/∂y at (1, 1) = ___

(b) Since ∂P/∂y = ∂Q/∂x everywhere (and the domain is all of ℝ²), F is:

(a) ∂P/∂y = 6xy², so at (1,1) it's 6 (and ∂Q/∂x = 6xy² = 6 too — they match). (b) Equal mixed partials on all of ℝ² (simply connected) means F is conservative.

9. For F(x,y) = ⟨2xy³, 3x²y²+4⟩, answer both parts:

(a) A potential function f with ∇f = F is:

(b) Fill in the blank: f(1, 1) = ___

(a) ∫2xy³ dx = x²y³ + g(y); matching ∂f/∂y = 3x²y² + g'(y) to Q = 3x²y²+4 gives g'(y)=4, so g(y)=4y, and f = x²y³+4y. (b) f(1,1) = 1 + 4 = 5.

10. Using f(x,y) = x²y³ + 4y as a potential function for F, for any path C from (0,0) to (1,1), answer both parts:

(a) Fill in the blank: f(0, 0) = ___

(b) Fill in the blank: ∫C F · dr = ___

(a) f(0,0) = 0. (b) By the Fundamental Theorem for Line Integrals, ∫_C F·dr = f(1,1) - f(0,0) = 5 - 0 = 5, for any path at all.
