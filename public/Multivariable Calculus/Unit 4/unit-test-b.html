1. For f(x,y) ≥ 0 on R, the double integral ∬R f dA is best described as:

A nonnegative double integral generalizes "area under a curve" to "volume under a surface."

2. Fill in the blank: ∬R (3x + y) dA over R = [0,2] × [0,1] equals ___

∫₀²∫₀¹ (3x+y) dy dx = ∫₀² [3xy + y²/2]₀¹ dx = ∫₀² (3x + 0.5) dx = [1.5x² + 0.5x]₀² = 6 + 1 = 7.

3. Fubini's theorem, applied to a rectangle R with continuous f, guarantees:

Both iteration orders are valid and produce the same value for continuous f on a rectangle.

4. A Type I region is described as:

Type I has constant bounds on x and curve bounds on y — the opposite of Type II.

5. If ρ(x,y,z) is a density function on solid E, ∭E ρ dV equals:

Integrating a density function over a solid accumulates mass — the same idea as integrating a linear density to get total mass in 1D.

6. For f(x,y) = x²y over R = [0,3] × [0,1], answer both parts:

(a) ∫₀¹ x²y dy equals:

(b) Fill in the blank: ∬R x²y dA = ___

(a) ∫₀¹ x²y dy = x²[y²/2]₀¹ = x²/2. (b) ∫₀³ x²/2 dx = (1/2)[x³/3]₀³ = (1/2)(9) = 4.5.

7. The region D is bounded by y = x² and y = 4x. Answer both parts:

(a) These curves intersect at:

(b) Fill in the blank: for D = {0 ≤ x ≤ 4, x² ≤ y ≤ 4x}, the area ∬D 1 dA = ___

(a) x² = 4x gives x(x−4) = 0, so x = 0 or x = 4. (b) ∫₀⁴(4x − x²)dx = [2x² − x³/3]₀⁴ = 32 − 64/3 = 32/3 ≈ 10.667.

8. For D = {0 ≤ x ≤ 4, x² ≤ y ≤ 4x}, answer both parts:

(a) ∬D x dA is set up as:

(b) Fill in the blank: this double integral equals ___

(a) The lower bound x² must be listed first for the inner integral. (b) ∫x²4x x dy = 4x² − x³, and ∫₀⁴(4x² − x³)dx = 256/3 − 64 = 64/3 ≈ 21.333.

9. E is the solid under z = 16 − x² − y², above the xy-plane. Answer both parts:

(a) The innermost integral's bounds for z are:

(b) Fill in the blank: the shadow region D (where 16 − x² − y² ≥ 0) is a disk of radius ___

(a) The solid runs from the xy-plane up to the paraboloid ceiling. (b) 16 − x² − y² ≥ 0 means x² + y² ≤ 16, a disk of radius 4.

10. For f(x,y,z) = xy²z over the box [0,2] × [0,3] × [0,2], answer both parts:

(a) Fill in the blank: ∫₀³ y² dy = ___

(b) Fill in the blank: ∭ xy²z dV = ___

(a) ∫₀³ y² dy = [y³/3]₀³ = 9. (b) Since integrand and box both separate: (∫₀²x dx)(9)(∫₀²z dz) = (2)(9)(2) = 36.
