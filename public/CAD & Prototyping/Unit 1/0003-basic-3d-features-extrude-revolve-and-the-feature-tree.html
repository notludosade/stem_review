Basic 3D Features — Extrude, Revolve, and the Feature Tree

A flat sketch becomes a solid through one of a small number of basic operations — and every one of them gets recorded, in order, in a history that later features depend on.

← Lesson 2 Unit 2, Lesson 4 → Contents Glossary →

Lessons 1 and 2 built and parameterized flat sketches. Neither one is a 3D part yet. This lesson covers the two most common operations that turn a 2D profile into a solid, and the record-keeping structure — the feature tree — that ties every step of a model's history together.

Extrude: push a profile along an axis

Definition An extrude feature takes a closed 2D sketch profile and pushes it a specified distance perpendicular to the sketch plane, sweeping out a solid. Common variants: blind (a fixed distance), through all (all the way through existing geometry), and symmetric (extruding half the distance in each direction from the sketch plane).

Extrude is the default way to turn a flat outline — a rectangle, an L-shape, a profile with holes already cut into it — into a block, a plate, or a wall with that cross-section.

Revolve: spin a profile around an axis

Definition A revolve feature takes a 2D sketch profile and rotates it around a specified axis, sweeping out a solid of revolution. The angle is itself a parameter — commonly a full 360° for a bolt, a knob, or a bottle, but a partial revolve (say, 180°) is equally valid for a part that's only a slice of a full round shape.
Example A bolt's shaft and head are almost always modeled with a single revolve: sketch just the outline of one half of the bolt's cross-section (a 2D profile that looks like the bolt sliced down the middle), then revolve it 360° around its centerline. Every point on that profile sweeps out a circle, and the whole solid appears from one sketch.

The feature tree

Definition The feature tree (or history tree) is the sequential list every CAD program keeps of every feature applied to a model — each sketch, extrude, revolve, fillet, hole, and so on, in the order it was created. Each feature is built on top of the geometry that exists at that point in the tree, not the finished part as it looks today.

This has a direct consequence: editing an earlier feature doesn't just change that one feature — it forces every feature listed after it in the tree to recompute, because each one depends on the geometry the previous ones left behind.

Worked Example — A Bracket's Feature Tree A simple bracket might be built as: Sketch1 (the base outline) → Extrude1 (the flat base plate) → Sketch2 (drawn on Extrude1's top face, for a mounting boss) → Extrude2 (the boss) → Fillet1 (rounding the base plate's corners). Change Sketch1's width, and Extrude1 recomputes to the new size — which forces Sketch2's plane (Extrude1's top face) to move, which forces Extrude2 to recompute in its new position, which forces Fillet1 to re-round whatever corners exist at that point. One edit, four downstream recomputations, entirely automatic.
Why order matters Because every feature depends on what came before it, the order features appear in the tree is part of the design, not just bookkeeping. Two models with identical final geometry can behave completely differently when edited, depending on which feature was built first and what later features reference. Lesson 6 comes back to this directly: what it actually takes to edit a feature tree without breaking the features built on top of it.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does an extrude feature do to a 2D sketch profile?

Extrude pushes a flat profile along an axis perpendicular to its sketch plane, turning a 2D outline into a 3D solid.

2. Why can a bolt's entire head-and-shaft shape usually be modeled from a single 2D sketch?

A revolve feature sweeps a 2D profile around an axis, so a single half-cross-section profile is enough to generate the entire rotationally symmetric solid.

3. In the bracket example, why does editing Sketch1's width also change Fillet1's result, even though Fillet1 never directly references Sketch1?

Changes cascade down the tree: Sketch1 → Extrude1 → Sketch2 → Extrude2 → Fillet1, each depending on the one before it, so an early change forces every later feature to recompute.

4. Fill in the blank: the sequential, ordered record of every feature applied to a CAD model is called the ___.

The feature tree (or history tree) records each feature in creation order, and each one builds on the geometry that existed at that point.

5. Fill in the blank: because every feature depends on what came before it, the ___ features appear in the tree is part of the design itself, not just bookkeeping.

Two models with identical final geometry can behave very differently when edited, depending purely on feature order and what later features chose to reference.
