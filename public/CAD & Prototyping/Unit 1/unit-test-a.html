1. A 2D sketch has a single unconstrained line (4 DOF). A coincident constraint pins one endpoint to the origin (−2 DOF), and a length dimension is added (−1 DOF). How many degrees of freedom remain?

4 − 2 − 1 = 1 DOF remains — the free endpoint can still rotate around the fixed one at a fixed radius, since no angle has been set yet.

2. Fill in the blank: a constraint that fixes an actual measurement, like a length or an angle, rather than just a relationship between entities, is called a ___ constraint.

Dimensional constraints fix numbers (length, radius, angle); geometric constraints fix relationships (coincident, parallel, tangent) without specifying a number.

3. A plate has width = 120mm, margin = 15mm, and 4 evenly spaced holes. Using spacing = (width − 2×margin) / (holes − 1), what is the hole spacing?

spacing = (120 − 2×15) / (4 − 1) = (120 − 30) / 3 = 90 / 3 = 30mm.

4. Fill in the blank: the practical payoff of parametric design is that a redesign affecting many dependent dimensions becomes a matter of changing just ___ number, instead of manually re-editing every dimension by hand.

A parameter referenced by a formula propagates automatically everywhere it's used — that's the entire point of building the relationship in the first place.

5. A designer needs to model a doorknob's shaft, which is symmetric all the way around a central axis. Which basic 3D feature is the natural choice?

A revolve sweeps a 2D profile around an axis — exactly what's needed for any part that's symmetric all the way around a centerline, like a doorknob shaft.

6. A model has Sketch1 → Extrude1 (a base plate) → Sketch2 (drawn on Extrude1's top face) → Extrude2 (a boss). Answer both parts:

(a) If Sketch1's width is edited, what happens to Extrude2?

(b) Fill in the blank: the sequential, ordered record of Sketch1, Extrude1, Sketch2, and Extrude2 that determines this cascade is called the ___.

(a) Every feature depends on what came before it, so an edit to Sketch1 cascades through Extrude1 and Sketch2 to reach Extrude2. (b) This ordered record is the feature tree (history tree).

7. A sketch still shows blue (unconstrained-looking) geometry after several dimensions have been added. Answer both parts:

(a) What does this most likely indicate?

(b) Fill in the blank: for this sketch to become fully constrained, its remaining degrees of freedom must reach ___.

(a) Underdefined geometry (DOF > 0) is commonly shown in a different color than fully constrained geometry. (b) Fully constrained means exactly 0 DOF remain.

8. A designer types the number "20" directly into a hole-spacing dimension, instead of writing a formula referencing the plate's width and hole count. Answer both parts:

(a) What happens to that hole spacing if the plate's width is later changed?

(b) Fill in the blank: a dimension defined as a fixed, typed-in number rather than a formula is sometimes called ___ modeling.

(a) A fixed number has no relationship to any other parameter, so nothing updates it automatically. (b) This is the "dumb" (direct) modeling contrasted with parametric modeling.

9. A part is a flat L-shaped bracket with constant thickness throughout. Answer both parts:

(a) Which basic 3D feature is the natural way to create this part from its 2D profile?

(b) Fill in the blank: an extrude to a fixed, specified distance (rather than through-all or symmetric) is called a ___ extrude.

(a) A constant-thickness flat shape is exactly what extrude is built for. (b) "Blind" extrude means a fixed, specified distance, as opposed to through-all or symmetric variants.

10. Model A builds rounded corners first, then adds a mounting-hole sketch that references those rounded edges. Model B builds a flat base first, adds a mounting-hole sketch referencing the original flat face, and rounds the corners last. Both models currently look identical. Answer both parts:

(a) Which model's mounting-hole sketch is more likely to fail to rebuild if the corner rounding is later resized?

(b) Fill in the blank: because every feature depends on what came before it, the ___ features appear in the tree is part of the design itself, not just bookkeeping.

(a) Two models can look identical yet behave completely differently under edits, purely based on what each feature chose to reference. (b) Feature order is itself a real design decision, not incidental bookkeeping.
