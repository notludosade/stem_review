Parametric Design — Features Driven by Parameters, Not Fixed Numbers

Type in "20mm" and a redesign means hunting down every place 20mm appears. Define it as a formula instead, and a redesign means changing one number.

← Lesson 1 Lesson 3 → Contents Glossary →

Lesson 1 fully constrained a sketch with fixed dimensions. That's necessary, but it's not the whole story — a fully constrained sketch can still be "dumb," in the sense that every number in it is typed in by hand, independent of every other number. Parametric modeling fixes that.

What "parametric" actually means

Definition In a parametric model, dimensions and features are driven by named parameters (variables) and expressions relating them, instead of independent fixed numbers. Change one parameter, and every dimension that references it — directly or through a formula — recomputes automatically.

Contrast this with plain "dumb" direct modeling, where a dimension is just a number: changing it changes that one feature and nothing else. In a parametric model, a dimension can instead be an expression like (width − 2 × margin) / (holes − 1) — a formula, not a constant — so it updates itself whenever width, margin, or holes changes anywhere in the design.

Worked Example — A Mounting Plate A plate has parameters width = 100mm, margin = 10mm (the gap from each edge to the nearest hole), and holes = 5 (evenly spaced). The spacing between adjacent holes is defined as a formula, not typed in directly: spacing = (width − 2×margin) / (holes − 1) = (100 − 20) / 4 = 20mm. Later, the plate needs to widen to fit a bigger enclosure — a redesign bumps width to 140mm and margin to 12mm. Every hole shifts automatically to the new spacing of (140 − 24) / 4 ≈ 38.7mm, with zero manual editing of individual holes.
spacing = (width − 2 × margin) / (holes − 1)
Why this matters for design iteration Real designs get revised constantly — a part that has to fit a new enclosure, a redesign that adds a mounting hole, a change requested after the first prototype fails a test. Without parametric relationships, every one of those changes means manually finding and re-editing every dependent dimension by hand: slow, and one missed dimension away from a part that no longer actually fits together. Parametric design turns "redesign the plate" into "change one number and let the model recompute."

Parameters can drive more than distances

A parameter isn't limited to linear dimensions. Common CAD tools let a parameter drive a pattern count (how many holes), a feature's size (a fillet radius, a boss diameter), or even whether a feature exists at all — some tools let a formula suppress an optional feature entirely when a condition isn't met, letting one model represent several configurations of the same basic part.

1. What is the defining feature of a parametric model, as opposed to plain "dumb" direct modeling?

Parametric modeling ties dimensions together through formulas referencing named parameters, so one change can propagate through the whole design.

2. A plate has width = 140mm, margin = 12mm, and 4 evenly spaced holes. Using spacing = (width − 2×margin) / (holes − 1), what is the hole spacing?

spacing = (140 − 2×12) / (4 − 1) = (140 − 24) / 3 = 116 / 3 ≈ 38.7mm.

3. Besides linear distances, what else can a parameter reasonably drive in a parametric model?

Parameters can drive pattern counts, feature sizes, and conditional suppression of whole features — not just distances.

4. Fill in the blank: instead of typing a fixed number, a parametric dimension can be defined as a ___ referencing other named parameters.

A formula/expression is what lets a dimension recompute automatically whenever the parameters it references change.
