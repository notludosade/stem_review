Slicing Settings and Their Quantitative Effects on Strength, Accuracy, and Print Time

Layer height isn't just a quality slider — it's a direct multiplier on how many layers a print needs, and that number drives almost everything else.

← Lesson 13 Lesson 15 → Contents Glossary →

Lesson 13 introduced layer height and infill conceptually. This lesson puts numbers on them — specifically, the layer-count math that drives print time and dimensional accuracy, and the strength logic behind why walls often matter more than infill.

The slicer's job

Definition A slicer converts a 3D model into layer-by-layer toolpath instructions (G-code) for the printer, based on settings the user sets: layer height, infill percentage, wall (perimeter) count, print speed, and more.

Layer count — the number underneath print time

number of layers = part height / layer height
Worked Example — Layer Count at Two Settings A part is 40mm tall. At 0.20mm layer height: 40 / 0.20 = 200 layers. Switching to a finer 0.12mm layer height: 40 / 0.12 ≈ 333 layers — about 67% more layers for the same part. Since most of a print's time comes from depositing material layer by layer, this is roughly proportional to added print time for the vertical portion of the print — though not exactly 1:1, since the horizontal travel distance per layer stays about the same regardless of layer height, so the relationship is close to, but not perfectly, linear.

Why walls often add more strength per gram than infill

Diminishing returns from infill, and why walls matter more for bending Infill density isn't linearly free — going from a moderate to a very high infill percentage adds a lot of material and print time for comparatively little extra strength, because the outer walls (perimeters) already carry a large share of most loads regardless of what's inside. This mirrors basic beam theory: material far from a part's neutral bending axis (the outer surface) contributes far more to bending strength and stiffness than material near the center. Increasing the number of perimeter walls (shell thickness) is often a more material-efficient way to add strength to a part loaded in bending than simply cranking up infill percentage — a genuinely useful rule of thumb, though exact numbers vary enough by geometry and material that they're best confirmed with a real test print rather than treated as a fixed formula.

Accuracy: fewer visible steps on angled surfaces

A curved or angled surface printed in discrete flat layers always shows some "stair-stepping" — visible ridges where each layer's edge doesn't perfectly match the ideal smooth surface. Finer layer height directly reduces the height of each visible step, which is exactly why layer height is often the first setting tightened when a part's surface finish or dimensional accuracy on angled features matters more than print speed.

1. A part is 24mm tall, printed at 0.15mm layer height. How many layers does it need?

number of layers = 24 / 0.15 = 160.

2. Why does switching from 0.20mm to a finer 0.12mm layer height increase print time, but not by an exactly proportional amount?

More, thinner layers mean more total layer changes and more total horizontal travel passes — but each individual layer's travel distance doesn't shrink just because the layer got thinner, so the relationship is close to, but not perfectly, linear.

3. Why can increasing wall (perimeter) count add more bending strength per gram of material than increasing infill percentage?

This is the same logic as beam theory: outer material does more work resisting bending than material near the neutral axis, so walls are often the more efficient place to add strength.
