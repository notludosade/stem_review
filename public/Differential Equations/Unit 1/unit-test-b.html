1. Which function solves dy/dx = −3y?

y = e^(−3x) differentiates to y′ = −3e^(−3x) = −3y, matching for every x.

2. Fill in the blank: the order of d²y/dx² + 5(dy/dx) − 2y = 0 is ___.

The highest derivative appearing is d²y/dx², so the order is 2.

3. Consider y = e^(3x) as a candidate solution of y′ − 3y = 0. Answer both parts:

(a) Does it solve the equation?

(b) Fill in the blank: for this y, y′(0) = ___

(a) y′ = 3e^(3x), so y′ − 3y = 3e^(3x) − 3e^(3x) = 0 for every x — a valid solution. (b) y′(0) = 3e⁰ = 3.

4. Which equation is separable?

e^(x−y) = e^x·e^(−y) is already a product of a pure function of x and a pure function of y. The other three subtract x and y before any operation that could split them apart.

5. Solve dy/dx = 3xy, y(0) = 2. Answer both parts:

(a) The general solution (before applying the initial condition) is:

(b) Fill in the blank: applying y(0) = 2 gives C = ___

(a) Separating gives dy/y = 3x dx; integrating gives ln|y| = 3x²/2 + C₁, so y = Ce^(3x²/2). (b) y(0) = Ce⁰ = C = 2.

6. Solve dy/dx = 2y/x (x > 0), y(1) = 3. Answer both parts:

(a) The general solution (before applying the initial condition) is:

(b) Fill in the blank: applying y(1) = 3 gives C = ___

(a) Separating gives dy/y = (2/x) dx; integrating gives ln|y| = 2 ln x + C₁ = ln(x²) + C₁, so y = Cx². (b) y(1) = C(1)² = C = 3.

7. Fill in the blank: applying an initial condition to y = Ce^(4x) pins the constant down to one specific value, producing the ___ solution.

The general solution is the entire family indexed by C; an initial condition selects one member of that family — the particular solution.

8. For dy/dx + (3/x)y = 2 (x > 0), the integrating factor μ(x) is:

μ(x) = e^(∫(3/x)dx) = e^(3ln x) = x³.

9. Solve dy/dx + 3y = 9, y(0) = 4. Answer both parts:

(a) The integrating factor μ(x) is:

(b) Fill in the blank: with y = 3 + Ce^(−3x), applying y(0) = 4 gives C = ___

(a) μ(x) = e^(∫3 dx) = e^(3x). (b) 4 = 3 + Ce⁰ = 3 + C, so C = 1.

10. Solve dy/dx + 2y = 10, y(0) = 8. Answer both parts:

(a) The general solution (before applying the initial condition) is:

(b) Fill in the blank: applying y(0) = 8 gives C = ___

(a) μ(x) = e^(2x) gives d/dx[e^(2x)y] = 10e^(2x), so e^(2x)y = 5e^(2x) + C and y = 5 + Ce^(−2x). (b) 8 = 5 + Ce⁰ = 5 + C, so C = 3.
