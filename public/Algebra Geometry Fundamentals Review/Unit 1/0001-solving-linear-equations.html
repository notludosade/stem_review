Solving Linear Equations

Every algebra technique in this course eventually comes back to one move: doing the same thing to both sides of an equation until x is alone.

Lesson 2 → Contents Glossary →

A linear equation is any equation where the variable appears only to the first power — no x², no x under a root, no x in a denominator. That means its graph is a straight line, and it means solving it always comes down to the same handful of legal moves, repeated until x sits by itself on one side.

The one rule that solves every linear equation

Definition An equation is a statement that two expressions are equal. The addition/subtraction property of equality and the multiplication/division property of equality say you may add, subtract, multiply, or divide both sides by the same nonzero quantity without changing what values of x make the equation true. Solving a linear equation is just applying these properties, in the right order, to strip away everything surrounding x — usually undoing addition/subtraction first, then multiplication/division, mirroring order of operations in reverse.

Why this always works Whatever you do to one side, you must do to the other — that's what keeps the equation true for the same x. Slide until both sides read the same number: that's x = 5, and it's the only x that works, because a linear equation's graph (a straight, non-horizontal line) crosses any fixed value exactly once.

Worked example, step by step

Solve 3x + 5 = 20 Step 1 — Subtract 5 from both sides (undo the "+5"): 3x = 15.
Step 2 — Divide both sides by 3 (undo the "×3"): x = 5.
Check — Substitute back into the original: 3(5) + 5 = 15 + 5 = 20. ✓
A messier one: 2(x − 4) + 3x = x + 12 Step 1 — Distribute: 2x − 8 + 3x = x + 12.
Step 2 — Combine like terms on the left: 5x − 8 = x + 12.
Step 3 — Subtract x from both sides (get variables on one side): 4x − 8 = 12.
Step 4 — Add 8 to both sides: 4x = 20.
Step 5 — Divide by 4: x = 5.

Two special cases

No solution vs. all real numbers Solving can also reveal that an equation has no solution — if the variable cancels out and leaves a false statement (like 2x + 3 = 2x + 5 simplifies to 3 = 5, which is never true) — or that it's true for all real numbers — if the variable cancels and leaves a true statement (like 2x + 3 = 2x + 3 simplifies to 3 = 3). Both are legitimate answers, not mistakes.

Check your recall

No peeking back up — answer from memory first, then check.

1. Solve: 4x − 7 = 13. What is x?

Add 7 to both sides: 4x = 20. Divide by 4: x = 5.

2. What does solving reveal about 5x + 2 = 5x − 1?

Subtracting 5x from both sides leaves 2 = −1, which is never true — so no value of x makes this equation true.

3. Solve: 2(x + 3) = 2x + 6. What does this tell you?

Distributing gives 2x + 6 = 2x + 6 — the same expression on both sides, true no matter what x is.

4. Fill in the blank: solving 3(2x − 1) = 5x + 5 gives x = ___.

Distribute: 6x − 3 = 5x + 5. Subtract 5x from both sides: x − 3 = 5. Add 3 to both sides: x = 8.
