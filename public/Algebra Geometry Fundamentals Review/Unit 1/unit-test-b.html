1. Solve: 4x + 7 = 31. What is x?

Subtract 7 from both sides: 4x = 24. Divide by 4: x = 6.

2. Fill in the blank: solving 3(x + 2) = 3x + 6 simplifies to the true statement 6 = 6, so the equation is true for ___.

When the variable cancels and leaves a true statement, every real number satisfies the equation.

3. Solve: −4x ≤ 20. What is the solution?

Dividing both sides by −4 flips the inequality sign: x ≥ −5.

4. Fill in the blank: the graph of x < 5 uses a(n) ___ circle at 5, since 5 itself is not included in the solution.

Strict inequalities (< or >) exclude the boundary value, shown with an open (hollow) circle.

5. Which value IS part of the solution set of 2 ≤ x < 6?

The "≤" includes 2 itself; the strict "<" excludes 6. Of these choices, only 2 is in the solution set.

6. Solve the system y = 2x − 3 and y = −x + 9. Answer both parts:

(a) What is x?

(b) What is y?

Setting 2x − 3 = −x + 9 gives 3x = 12, so x = 4; then y = 2(4) − 3 = 5.

7. Solve the system 3x + y = 10 and x − y = 2. Answer both parts:

(a) What is x?

(b) What is y?

Adding the two equations cancels y: 4x = 12, so x = 3; substituting back, 3 − y = 2, so y = 1.

8. Answer both parts about number of solutions:

(a) How many solutions does the system y = −x + 4 and y = −x − 1 have?

(b) How many solutions does the system y = −x + 4 and 3y = −3x + 12 have?

(a) Same slope, different intercepts — parallel lines that never meet. (b) Dividing the second equation by 3 gives y = −x + 4, the exact same line, so every point on it is a solution.

9. Solve: 3(x − 1) + 5 = 2x + 4. Answer both parts:

(a) Fill in the blank: distributing 3(x − 1) gives ___.

(b) Fill in the blank: solving the full equation gives x = ___.

Distributing gives 3x − 3 + 5 = 2x + 4, or 3x + 2 = 2x + 4. Subtracting 2x and 2 from both sides gives x = 2.

10. Two numbers have a sum of 20 and a difference of 4. Answer both parts:

(a) What is the larger number?

(b) What is the smaller number?

Setting up x + y = 20 and x − y = 4 and adding gives 2x = 24, so x = 12 and y = 8.
