1. A program dereferences a wild pointer pointing into memory the process has never had mapped. What happens?

The kernel enforces address-space isolation, and a segfault is that enforcement terminating an illegal access.

2. Fill in the blank: the optional file the OS can write at the moment of a crash, capturing the process's full memory and register state, is called a ___.

A core dump preserves the exact state of a process at the instant it died, for later inspection.

3. Why does a backtrace usually get read starting from its top frame, not the bottom?

Starting at the innermost frame — where things actually went wrong — and reading downward is what makes a backtrace useful.

4. Fill in the blank: an operation the C standard places no requirement on at all — permitting literally any outcome, including an apparently correct one — is called ___.

Undefined behavior is the total absence of any requirement, which is exactly what lets compilers optimize as if it never occurs.

5. How does implementation-defined behavior differ from undefined behavior?

Implementation-defined behavior has a documented, consistent floor per compiler; undefined behavior has none at all.

6. An 8-bit signed int at its maximum value has 1 added to it, and separately, an 8-bit unsigned int at its maximum value has 1 added to it. Answer both parts:

(a) Is the signed case's result defined by the C standard?

(b) Is the unsigned case's result defined by the C standard?

Signed overflow is UB; unsigned overflow is one of the few overflow cases the standard defines precisely, wrapping predictably.

7. A programmer writes an overflow check like if (x + 1 < x), hoping to catch signed overflow before it happens. Answer both parts:

(a) Is the compiler allowed to assume this condition is always false?

(b) What is the practical risk of writing this check?

Trusting that UB never happens is precisely what licenses an optimizer to eliminate code that exists only to handle it.

8. Compare a systems language like C to a managed language like Python. Answer both parts:

(a) Which category gives the programmer manual control over memory with no runtime safety net?

(b) Which category automatically enforces safety, like bounds checking, at some performance cost?

Manual control with no net versus automatic safety at a cost is the core split between the two categories.

9. A managed language's garbage collector reclaims heap memory automatically. Answer both parts:

(a) Does this eliminate the need for an explicit free() call?

(b) What real cost does garbage collection introduce that manual memory management doesn't?

Garbage collection removes free()-related bugs but isn't free itself — it spends CPU time and occasionally pauses the program.

10. A team is building firmware for a microcontroller with 2KB of RAM and no operating system underneath it. Answer both parts:

(a) Which category of language best fits this workload?

(b) Why?

Extremely constrained hardware with no OS underneath is exactly where a systems language's lack of runtime overhead matters most.
