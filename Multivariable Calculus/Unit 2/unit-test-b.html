1. For f(x, y) = x² + y², the level curve f(x,y) = 25 is:

x² + y² = 25 is a circle of radius √25 = 5.

2. Fill in the blank: for f(x, y) = 4x²y − 2y³, fx(1, 3) = ___

fx = 8xy (treating y as constant), so fx(1,3) = 8(1)(3) = 24.

3. At a point where ∇f ≠ 0, the gradient vector points:

The gradient points toward the fastest increase in f, which must be perpendicular to the level curve's "no change" direction.

4. Two mixed partial derivatives fxy and fyx are guaranteed equal at a point when:

Clairaut's theorem requires continuity of the mixed partials near the point — it is not an unconditional guarantee.

5. For w = f(x, y), x = x(t), y = y(t), dw/dt equals:

Each variable contributes its partial derivative times its own rate of change with respect to t; the contributions add.

6. For f(x, y) = x²y³ + 3x, answer both parts:

(a) fx(x, y) equals:

(b) Fill in the blank: fy(1, 2) = ___

(a) fx = 2xy³ + 3. (b) fy = 3x²y², so fy(1,2) = 3(1)(4) = 12.

7. For f(x, y) = x² + xy − y², answer both parts at (1, 3):

(a) Fill in the blank: fx(1, 3) = ___

(b) Fill in the blank: ∇f(1, 3) = ___ (format: <a,b>)

(a) fx = 2x + y, so fx(1,3) = 2 + 3 = 5. (b) fy = x − 2y, so fy(1,3) = 1 − 6 = −5, giving ∇f(1,3) = ⟨5, -5⟩.

8. For f(x, y) = x³y², answer both parts:

(a) Fill in the blank: fxy(1, 1) = ___

(b) fxy(1,1) = fyx(1,1) here because:

(a) fx = 3x²y², so fxy = 6x²y, giving fxy(1,1) = 6. (b) x³y² is a polynomial, so every partial derivative is continuous everywhere — exactly Clairaut's hypothesis.

9. For z = x²y, x(t) = 3t, y(t) = t − 1, answer both parts:

(a) dz/dt equals:

(b) Fill in the blank: at t = 2, dz/dt = ___

(a) fx = 2xy, fy = x², so dz/dt = 2xy(dx/dt) + x²(dy/dt). (b) At t=2: x=6, y=1, dx/dt=3, dy/dt=1, giving dz/dt = 2(6)(1)(3) + 36(1) = 36 + 36 = 72.

10. For f(x, y) = √(36 − x² − y²), answer both parts:

(a) The domain of f is:

(b) Fill in the blank: the level curve f(x,y) = 0 is a circle of radius ___

(a) The expression under the square root needs 36 − x² − y² ≥ 0. (b) Setting f = 0: 36 − x² − y² = 0, so x² + y² = 36, a circle of radius 6 — the outer boundary of the domain.
