1. For f(x, y) = x² + y², the level curve f(x,y) = 16 is:

x² + y² = 16 is a circle of radius √16 = 4.

2. Fill in the blank: for f(x, y) = 3x²y − y³, fx(2, 1) = ___

fx = 6xy (treating y as constant), so fx(2,1) = 6(2)(1) = 12.

3. At a point where ∇f ≠ 0, the gradient vector ∇f is:

The gradient points in the direction of steepest increase, which is always perpendicular to the direction along which f doesn't change — the level curve.

4. Clairaut's theorem lets you conclude fxy = fyx at a point when:

Continuity of the mixed partials near the point is the condition Clairaut's theorem requires — not automatic for every function.

5. For z = f(x, y), x = x(t), y = y(t), dz/dt equals:

Each variable contributes its partial derivative times its own rate of change with respect to t, and the two contributions add.

6. For f(x, y) = x³y² + 2x, answer both parts:

(a) fx(x, y) equals:

(b) Fill in the blank: fy(1, 2) = ___

(a) fx = 3x²y² + 2. (b) fy = 2x³y, so fy(1,2) = 2(1)(2) = 4.

7. For f(x, y) = x² − xy + y², answer both parts at (2, 1):

(a) Fill in the blank: fx(2, 1) = ___

(b) Fill in the blank: ∇f(2, 1) = ___ (format: <a,b>)

(a) fx = 2x − y, so fx(2,1) = 4 − 1 = 3. (b) fy = −x + 2y, so fy(2,1) = −2 + 2 = 0, giving ∇f(2,1) = ⟨3, 0⟩.

8. For f(x, y) = x²y³, answer both parts:

(a) Fill in the blank: fxy(1, 1) = ___

(b) fxy(1,1) = fyx(1,1) here because:

(a) fx = 2xy³, so fxy = 6xy², giving fxy(1,1) = 6. (b) x²y³ is a polynomial, so all its partials are continuous everywhere — exactly Clairaut's theorem's hypothesis.

9. For z = xy², x(t) = t + 1, y(t) = 2t, answer both parts:

(a) dz/dt equals:

(b) Fill in the blank: at t = 1, dz/dt = ___

(a) fx = y², fy = 2xy, so dz/dt = y²(dx/dt) + 2xy(dy/dt). (b) At t=1: x=2, y=2, dx/dt=1, dy/dt=2, giving dz/dt = 4(1) + 2(2)(2)(2) = 4 + 16 = 20.

10. For f(x, y) = √(41 − x² − y²), answer both parts:

(a) The domain of f is:

(b) Fill in the blank: the level curve f(x,y) = 5 is a circle of radius ___

(a) The expression under the square root needs 41 − x² − y² ≥ 0. (b) Setting f = 5: 41 − x² − y² = 25, so x² + y² = 16, a circle of radius 4.
