The Chain Rule for Multivariable Functions

A particle moving through the plane sees f(x,y) change along its path. The gradient from Lesson 5 turns out to be exactly the tool that predicts how fast — as a single dot product.

1. Differentiating f along a moving path

Definition — Chain Rule Along a Path If z = f(x, y) and x = x(t), y = y(t) are both differentiable, then dz/dt = (∂f/∂x)(dx/dt) + (∂f/∂y)(dy/dt). Recognizing the right-hand side as a dot product: dz/dt = ∇f(x(t), y(t)) · r'(t), where r(t) = ⟨x(t), y(t)⟩ is the position and r'(t) the tangent (velocity) vector from AP Calculus BC's Unit 9. The gradient meets the tangent vector, and their dot product is the rate of change of f felt by a particle walking that exact path.
Method — The General Chain Rule (Tree Diagram) When x and y each depend on two new variables, say x = x(s,t) and y = y(s,t), each partial of z picks up one term per path from z down to that variable: ∂z/∂s = (∂f/∂x)(∂x/∂s) + (∂f/∂y)(∂y/∂s), and ∂z/∂t is built the same way, swapping every ∂s for ∂t. Sketching z branching to x and y, and each of those branching again, makes it easy to see — and count — every term the rule needs.
Worked Example f(x, y) = x²y, with x(t) = cos t, y(t) = sin t. fx = 2xy, fy = x², dx/dt = −sin t, dy/dt = cos t. So dz/dt = 2xy(−sin t) + x²(cos t). At t = 0: x = 1, y = 0, giving dz/dt = 2(1)(0)(0) + (1)²(1) = 1. Checking directly: z(t) = cos²t sin t, so z'(t) = −2sin²t cos t + cos³t, and z'(0) = 0 + 1 = 1 — matches.
Why This Matters This is the multivariable Chain Rule doing exactly what the single-variable one always did — differentiating a composition — but now the "inside function" is a whole path through the plane. Lesson 7 specializes dz/dt to the case where the path is a straight line through a point in a chosen direction, turning it into the directional derivative.

1. For z = f(x,y) with x = x(t), y = y(t), the Chain Rule gives dz/dt as:

Each variable's contribution is its partial derivative times its own rate of change with respect to t, and the two contributions add.

2. For f(x,y) = x²y, x(t) = cos t, y(t) = sin t, dz/dt at t = 0 equals ___

dz/dt = 2xy(−sin t) + x²(cos t); at t=0, x=1, y=0, giving 2(1)(0)(0) + 1²(1) = 1.

3. dz/dt can be rewritten as which dot product?

∇f = ⟨f_x, f_y⟩ and r'(t) = ⟨dx/dt, dy/dt⟩; their dot product f_x·dx/dt + f_y·dy/dt is exactly the Chain Rule sum.
