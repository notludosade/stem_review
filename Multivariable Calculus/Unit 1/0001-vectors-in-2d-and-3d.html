Vectors in 2D and 3D

Single-variable calculus tracked one number changing at a time. Multivariable calculus needs quantities with both a size and a direction — vectors are the object that carries both at once.

Lesson 2 → Contents Glossary →

1. A number with a direction attached

Definition — Vector A vector is a quantity with both magnitude and direction, written as an ordered tuple of components: v = ⟨a, b⟩ in the plane, or v = ⟨a, b, c⟩ in space. Geometrically, v is the arrow from the origin to the point (a, b) — or, placed anywhere, any arrow with that same length and direction. This is different from a point, which only marks a location with no direction of its own.
Method — Vector Arithmetic Vectors add and scale componentwise: ⟨a₁,b₁⟩ + ⟨a₂,b₂⟩ = ⟨a₁+a₂, b₁+b₂⟩ and k⟨a,b⟩ = ⟨ka, kb⟩. The magnitude (length) of v = ⟨a,b,c⟩ is |v| = √(a² + b² + c²), a straight application of the Pythagorean theorem (twice, in 3D). A unit vector has magnitude 1; dividing any nonzero vector by its own magnitude, v/|v|, always produces a unit vector pointing the same direction.
Worked Example v = ⟨3, 4⟩: |v| = √(3² + 4²) = √25 = 5. Its unit vector is v/|v| = ⟨3/5, 4/5⟩, and indeed √((3/5)² + (4/5)²) = 1. In space, w = ⟨1, 2, 2⟩: |w| = √(1 + 4 + 4) = √9 = 3.
Why This Matters Position, velocity, force, and — starting next unit — the gradient of a function are all naturally vectors, not bare numbers. Bundling magnitude and direction into one algebraic object is what lets the rest of this course extend derivative and integral ideas beyond a single x-axis, with the same addition and scaling rules doing the work in 2D, 3D, or beyond.

1. The magnitude of v = ⟨a, b, c⟩ is:

Magnitude comes from the Pythagorean theorem applied to the components — squared, summed, then square-rooted.

2. For v = ⟨3, 4⟩, |v| = ___

|v| = √(3² + 4²) = √25 = 5 — the classic 3-4-5 right triangle.

3. A unit vector in the same direction as v is found by:

v/|v| keeps every component's proportion (so the direction is unchanged) while rescaling the whole vector to length exactly 1.

4. ⟨1, 2⟩ + 3⟨2, -1⟩ equals:

Scale first: 3⟨2,-1⟩ = ⟨6,-3⟩. Then add componentwise: ⟨1+6, 2+(-3)⟩ = ⟨7, -1⟩.
