Local Extrema and the Second Derivative Test

A critical point on a surface can be a peak, a valley, or something single-variable calculus never had to name: a saddle, rising one way and falling another at the exact same point.

← Lesson 8 Lesson 10 → Contents Glossary →

1. Where the gradient vanishes

Definition — Critical Point A point (a,b) in the domain of f is a critical point if ∇f(a,b) = ⟨0, 0⟩, or if fx or fy fails to exist there. Every local maximum or minimum of a differentiable f occurs at a critical point — but not every critical point is an extremum. A saddle point is a critical point where f increases in some directions and decreases in others, with no genuine max or min happening there at all.
Method — The Second Derivative Test At a critical point (a,b), compute D = fxx(a,b)·fyy(a,b) − [fxy(a,b)]². Then: D > 0 and fxx > 0 → local minimum. D > 0 and fxx < 0 → local maximum. D < 0 → saddle point. D = 0 → the test is inconclusive; some other method is needed.
Worked Example f(x,y) = x³ − 3x + y². Critical points: fx = 3x² − 3 = 0 gives x = ±1; fy = 2y = 0 gives y = 0. So (1,0) and (−1,0) are the two critical points. Second partials: fxx = 6x, fyy = 2, fxy = 0. At (1,0): D = (6)(2) − 0 = 12 > 0 and fxx = 6 > 0 → local minimum. At (−1,0): D = (−6)(2) − 0 = −12 < 0 → saddle point, even though fxx < 0 there might suggest a max at a glance.
Why This Matters In one variable, a critical point was either a max, a min, or neither — there was no third geometric shape to worry about. In two or more variables, curvature can genuinely differ by direction, and the saddle point is the honest new possibility that shows up. Unit 8's Lagrange multipliers reuse this exact classification problem, just with a constraint added on top.
