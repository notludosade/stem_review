Line Integrals of Scalar and Vector Fields

A definite integral summed a function along a straight interval of the x-axis. A line integral sums a field along any curved path at all — and for a vector field, it measures work.

← Lesson 16 Lesson 18 → Contents Glossary →

1. Integrating along a curve instead of an axis

Definition — Line Integral of a Scalar Field For a curve C parametrized by r(t), t ∈ [a,b], and a scalar field f, the line integral ∫C f ds = ∫ab f(r(t)) |r'(t)| dt — f sampled along the path, weighted by arc length. Reversing the direction C is traversed doesn't change ∫C f ds, since |r'(t)| ≥ 0 regardless of direction.
Definition — Line Integral of a Vector Field For an oriented curve C (a direction of travel is specified) and a vector field F, the line integral ∫C F · dr = ∫ab F(r(t)) · r'(t) dt — the dot product accumulates only the part of F acting along the direction of travel at each instant. This is exactly W = F·d generalized to a curved path and a non-constant force: ∫C F · dr represents the work done by F moving an object along C. Unlike the scalar case, reversing C's orientation flips the sign: ∫−C F · dr = −∫C F · dr.
Worked Example F(x,y) = ⟨y, x⟩ along C: r(t) = ⟨t, t²⟩, t from 0 to 1. r'(t) = ⟨1, 2t⟩, and F(r(t)) = ⟨t², t⟩. So F(r(t)) · r'(t) = t²(1) + t(2t) = 3t². Then ∫C F · dr = ∫01 3t² dt = 1. Traversing the same curve backward (from (1,1) to (0,0)) would give −1 — the identical path, opposite sign.
Why This Matters Every physical notion of "work done moving through a force field" — a satellite's orbit through gravity, a charge moving through an electric field — is exactly this line integral. Lesson 18 identifies a special class of vector field where this work only depends on the start and end points, never the path taken in between — and Lesson 20's Green's Theorem turns a line integral around a closed curve into a double integral over the region it encloses.

1. The line integral of a vector field F along oriented curve C, parametrized by r(t), t ∈ [a,b], is:

The vector field's line integral dots F with the tangent vector r'(t) — the scalar-field version instead uses |r'(t)| for arc length weighting.

2. For F(x,y) = ⟨y, x⟩ along r(t) = ⟨t, t²⟩, t from 0 to 1, ∫C F · dr = ___

F(r(t))·r'(t) = 3t², so ∫₀¹ 3t² dt = [t³]₀¹ = 1.

3. If −C denotes the same curve as C but traversed in the opposite direction, then:

Reversing the direction of travel flips the sign of r'(t), which flips the sign of the dot product F · r'(t) at every instant — and so flips the whole integral.

4. The scalar line integral ∫C f ds uses which factor to weight f along the curve?

ds = |r'(t)| dt converts "integrate with respect to t" into "integrate with respect to actual arc length traveled" — a scalar weight, not a vector dot product.
