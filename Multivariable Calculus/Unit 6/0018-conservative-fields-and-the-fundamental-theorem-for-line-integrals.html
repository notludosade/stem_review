Conservative Fields and the Fundamental Theorem for Line Integrals

For one special class of vector field, a line integral stops caring about the path at all — only where you started and where you ended up.

← Lesson 17 Lesson 19 → Contents Glossary →

1. When a field is somebody's gradient

Definition — Conservative Vector Field A vector field F is conservative if F = ∇f for some scalar function f, called a potential function. The Fundamental Theorem for Line Integrals states: if F = ∇f and C is any curve from point A to point B, ∫C F · dr = f(B) − f(A) — the exact same "evaluate an antiderivative at the endpoints" structure as single-variable FTC Part 2, now with a potential function playing the antiderivative's role.
Method — Testing for Conservativeness For F = ⟨P, Q⟩ on an open, simply connected domain (no holes), F is conservative if and only if ∂P/∂y = ∂Q/∂x everywhere on that domain — this is Clairaut's theorem applied to a potential function's mixed partials. The simply-connected requirement is not a technicality to skip: on a domain with a hole, a field can satisfy ∂P/∂y = ∂Q/∂x everywhere and still fail to be conservative.
Worked Example F(x,y) = ⟨y, x⟩ (Lesson 17's field): ∂P/∂y = ∂(y)/∂y = 1, and ∂Q/∂x = ∂(x)/∂x = 1 — equal, and the domain is all of ℝ² (simply connected), so F is conservative. Finding f: integrating P with respect to x gives f = xy + g(y); differentiating with respect to y and matching to Q = x gives g′(y) = 0, so f(x,y) = xy. By the Fundamental Theorem, ∫C F · dr from (0,0) to (1,1) = f(1,1) − f(0,0) = 1 − 0 = 1 — matching Lesson 17's answer, computed there the hard way along one specific parabola.
Why This Matters Gravity and electrostatic force are conservative fields — which is precisely why "conservation of energy" works: the work done moving between two points never depends on the route taken. Lesson 20's Green's Theorem later shows that a conservative field's line integral around any closed loop is always exactly 0 — no work at all is needed to return to where you started.
