1. A vector field F(x,y) = ⟨P(x,y), Q(x,y)⟩ assigns to each point in its domain:

Unlike a scalar field, a vector field's output at every point carries both magnitude and direction.

2. Fill in the blank: for F(x,y) = ⟨2x, -y⟩, F(3, 1) = ___ (format: <a,b>)

F(3,1) = ⟨2(3), -(1)⟩ = ⟨6, -1⟩.

3. For C parametrized by r(t), t ∈ [a,b], the line integral ∫C F · dr equals:

A vector field's line integral dots F with the tangent vector r'(t) at each instant.

4. If -C denotes curve C traversed in the opposite direction, ∫-C F · dr equals:

Reversing direction flips the sign of r'(t) at every instant, which flips the sign of the entire line integral.

5. A vector field F is conservative if:

A conservative field is, by definition, the gradient of some scalar potential function.

6. For F(x,y) = ⟨-x, -y⟩, answer both parts:

(a) At every point, this field points:

(b) Fill in the blank: F(2, 3) = ___ (format: <a,b>)

(a) F = -⟨x,y⟩ always points opposite the position vector, i.e. straight toward the origin — a sink. (b) F(2,3) = ⟨-2,-3⟩.

7. For F(x,y) = ⟨x,y⟩ along r(t) = ⟨t, 2t⟩, t from 0 to 1, answer both parts:

(a) F(r(t)) · r'(t) simplifies to:

(b) Fill in the blank: ∫C F · dr = ___

(a) r'(t) = ⟨1,2⟩, F(r(t)) = ⟨t,2t⟩, so the dot product is t(1) + 2t(2) = t + 4t = 5t. (b) ∫₀¹ 5t dt = 5/2 = 2.5.

8. For F(x,y) = ⟨3x²y, x³+2y⟩, answer both parts:

(a) Fill in the blank: ∂P/∂y at (1, 2) = ___

(b) Since ∂P/∂y = ∂Q/∂x everywhere (and the domain is all of ℝ²), F is:

(a) ∂P/∂y = 3x², so at (1,2) it's 3(1)² = 3 (and ∂Q/∂x = 3x² = 3 too — they match). (b) Equal mixed partials on a simply connected domain (all of ℝ²) means F is conservative.

9. For F(x,y) = ⟨3x²y, x³+2y⟩, answer both parts:

(a) A potential function f with ∇f = F is:

(b) Fill in the blank: f(1, 2) = ___

(a) ∫3x²y dx = x³y + g(y); matching ∂f/∂y = x³ + g'(y) to Q = x³+2y gives g'(y)=2y, so g(y)=y², and f = x³y+y². (b) f(1,2) = (1)(2) + 4 = 6.

10. Using f(x,y) = x³y + y² as a potential function for F, for any path C from (0,0) to (1,2), answer both parts:

(a) Fill in the blank: f(0, 0) = ___

(b) Fill in the blank: ∫C F · dr = ___

(a) f(0,0) = 0. (b) By the Fundamental Theorem for Line Integrals, ∫_C F·dr = f(1,2) - f(0,0) = 6 - 0 = 6, for any path at all.
