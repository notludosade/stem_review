Double Integrals Over General Regions

Real regions are almost never rectangles. Letting the inner integral's bounds be functions instead of constants is all it takes to integrate over any shape bounded by curves.

← Lesson 10 Lesson 12 → Contents Glossary →

1. Bounds that are curves, not constants

Definition — Type I and Type II Regions A Type I region is D = {(x,y) : a ≤ x ≤ b, g1(x) ≤ y ≤ g2(x)} — bounded left and right by constants, top and bottom by curves in x. A Type II region swaps the roles: D = {(x,y) : c ≤ y ≤ d, h1(y) ≤ x ≤ h2(y)}. Every double integral over a general region reduces to one of these two shapes, or several pieces stitched together, each of a single type.
Method — Setting Up the Iterated Integral For a Type I region: ∬D f dA = ∫ab ∫g₁(x)g₂(x) f(x,y) dy dx. The inner integral's bounds are functions of x because, at each fixed x, y only ranges between the region's lower and upper curve there — exactly the "top minus bottom" idea from AP Calculus BC's area-between-curves lessons, now feeding an integrand instead of just 1.
Worked Example D is bounded by y = x² (below) and y = x (above), which intersect at x = 0 and x = 1. This is Type I: 0 ≤ x ≤ 1, x² ≤ y ≤ x. For f(x,y) = x + y: ∫x²x (x+y) dy = [xy + y²/2]x²x = (x² + x²/2) − (x³ + x⁴/2) = 3x²/2 − x³ − x⁴/2. Then ∫01 (3x²/2 − x³ − x⁴/2) dx = [x³/2 − x⁴/4 − x⁵/10]01 = 1/2 − 1/4 − 1/10 = 3/20.
Why This Matters Nearly every physical region — a lamina cut into an odd shape, the footprint of a building, the cross-section of a lens — is bounded by curves, not straight edges. Type I and Type II setups are what make "integrate over this exact shape" tractable by hand, and the same curve-as-bound idea reappears directly in Unit 5 once polar coordinates enter the picture.
