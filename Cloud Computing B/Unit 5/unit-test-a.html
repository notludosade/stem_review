1. What does a container orchestrator do?

Orchestration automates management of many containers across many machines.

2. Fill in the blank: the smallest deployable unit an orchestrator schedules, usually one container, is called a ___.

A pod, not an individual container, is the actual unit the orchestrator schedules.

3. What role does the control plane play in a cluster?

The control plane coordinates scheduling across the whole cluster, not node by node by hand.

4. Fill in the blank: an orchestrator's automatic, unattended recovery of crashed pods back to the desired replica count is called ___.

Self-healing continuously reconciles actual state against the declared desired state.

5. How is orchestrator-level scaling similar to an auto scaling group from Cloud Computing A?

Both apply the same demand-driven elastic scaling principle at different layers.

6. A fleet grows from 3 containers to 30 over several months. Answer both parts:

(a) Managed manually, the operational effort required to track placement and crashes...

(b) Managed by an orchestrator, going from 3 to 30 mainly requires...

Orchestration keeps operational effort flat as fleet size grows, unlike manual management.

7. A main application container and a tightly-coupled logging helper must always run on the same machine. Answer both parts:

(a) The orchestrator guarantees this co-location by scheduling them together as a single...

(b) The machine this pod actually runs on is called a...

Grouping into a pod guarantees co-location on the same node.

8. A cluster has five nodes, and a new pod needs to be scheduled. Answer both parts:

(a) The decision of which node the pod lands on is made by...

(b) This decision is made by looking at...

Cluster-wide scheduling, not per-node manual judgment, is the control plane's job.

9. A service's desired replica count is 6. A node hosting 2 of those pods fails entirely. Answer both parts:

(a) The orchestrator responds by...

(b) This automatic recovery requires...

Self-healing is specifically automatic and unattended.

10. A deploy accidentally sets a service's desired replica count to 0. Answer both parts:

(a) The orchestrator will...

(b) This shows that self-healing depends on...

Self-healing enforces whatever desired state it's given, correct or not.
