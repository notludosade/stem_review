1. Dev finishes a feature and files a deployment ticket that Ops picks up days later, deploying code they didn't write. What is this handoff called?

"The wall" (or "throwing it over the wall") names this handoff between siloed Dev and Ops teams.

2. Fill in the blank: the team historically judged on shipping features quickly, rather than production uptime, is called ___.

Development owns feature velocity, in contrast to Ops's focus on stability.

3. What does this unit argue DevOps fundamentally changes?

DevOps is a cultural and organizational shift that tools support but don't define.

4. Fill in the blank: an incident review built on the premise that the process usually deserves scrutiny more than the individual involved is called a ___ postmortem.

Blameless postmortems focus on systemic causes instead of individual blame.

5. Which of these best describes a deployment (CI/CD) pipeline?

The pipeline is an automated, repeatable sequence, not a single manual event.

6. A team stores the exact packaged output of a successful build and test run, then deploys that same package unchanged. Answer both parts:

(a) Fill in the blank: this packaged, versioned output is called a ___.

(b) Deploying this exact artifact, instead of rebuilding from source again at deploy time, mainly protects against...

Reusing the tested artifact guarantees the thing verified is the thing that ships.

7. As cloud infrastructure became faster to provision and scale, the ticket-based handoff between Dev and Ops did not get any faster. Answer both parts:

(a) The effect of that mismatch was that the wall became...

(b) This gap between fast infrastructure and a slow handoff is exactly the problem...

The human handoff, not the infrastructure, became the bottleneck as everything else sped up.

8. Classify each practice. Answer both parts:

(a) A shared on-call rotation between Dev and Ops is an example of...

(b) A container orchestrator that automatically restarts a crashed process is an example of...

Who gets paged is an organizational choice; an orchestrator's self-healing behavior is a specific piece of software.

9. A production outage traces back to an engineer who made a reasonable call given what they knew at the time. Answer both parts:

(a) A blameless postmortem process would treat this engineer's decision as...

(b) The review would instead look for...

Blameless postmortems assume the process, not the person, is usually the more useful place to find a fix.

10. Order and naming. Answer both parts:

(a) The very first stage of a deployment pipeline is a developer's change being...

(b) Fill in the blank: confirming a deployed change is actually healthy for real users, covered in Unit 6, is the job of ___.

The pipeline starts at commit and doesn't really end until the running system is being watched.
