1. A team defines its servers and networking in a version-controlled file that a tool reads to provision resources automatically. What is this practice called?

IaC is defined by version-controlled configuration driving automated provisioning.

2. Fill in the blank: unlike a console click, an infrastructure change stored under ___ leaves a reviewable, revertible history.

Version control is what turns an infrastructure change into a reviewable diff.

3. A configuration file states "there should be 3 servers" and lets the tool figure out what to change. What kind of approach is this?

Stating a desired end state, rather than a sequence of steps, is the declarative approach.

4. Fill in the blank: declarative IaC tools are built to be ___ by design, meaning reapplying the same file repeatedly is always safe.

Idempotency guarantees repeated application has the same effect as applying once.

5. What does reconciliation actually do?

Reconciliation is the ongoing process that actually catches and corrects drift.

6. A team needs identical staging and production environments and uses the same IaC configuration file for both. Answer both parts:

(a) Compared to provisioning each manually through a console, this approach is more likely to result in...

(b) This IaC file is treated by the team roughly the same way as...

IaC's core promise is treating infrastructure with the same rigor as application code.

7. An infrastructure change is proposed as a pull request against an IaC file, reviewed by a teammate, then merged. Answer both parts:

(a) Compared to a direct console edit, this process provides...

(b) If this change later needs to be undone, the team can rely on...

Version-controlled infrastructure changes are just as revertible as application code changes.

8. An imperative script and a declarative configuration file are each applied twice against an environment. Answer both parts:

(a) The imperative script, applied twice, is likely to...

(b) The declarative file, applied twice, is likely to...

Declarative tools compare against desired state; imperative scripts simply re-execute their steps.

9. A CI/CD pipeline occasionally retries an IaC apply step automatically after a network blip. Answer both parts:

(a) With a declarative, idempotent tool, an accidental duplicate apply will...

(b) This safety under repeated application is specifically called...

Idempotency is exactly what makes an accidental retry harmless.

10. A security audit finds a server setting that doesn't match its IaC file, with no record of who changed it. Answer both parts:

(a) This mismatch is an example of...

(b) A scheduled process that would have surfaced this earlier is called...

Regular reconciliation catches drift long before an audit has to find it.
