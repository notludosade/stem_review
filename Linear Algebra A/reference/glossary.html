Vectors and Structure

Span

Set of every linear combination of given vectors.

Basis

A linearly independent set that spans the space.

Rank

Dimension of a matrix's column space; equivalently, its number of pivots.

Determinant

Signed area or volume scale of a square matrix.

Eigenvalues and Applications

Eigenvalue

Scalar λ for which Av=λv has a nonzero solution.

Eigenspace

The null space of A−λI for a fixed eigenvalue λ.

Diagonalization

Factorization A=PDP⁻¹ using an eigenvector basis.

Stochastic Matrix

Nonnegative transition matrix whose probability columns sum to one.

Principal Component Analysis

Projection onto covariance eigenvectors ordered by captured variance.
