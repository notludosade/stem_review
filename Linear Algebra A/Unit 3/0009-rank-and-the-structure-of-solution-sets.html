Rank and the Structure of Solution Sets

One number, read straight off row echelon form, that predicts exactly how many solutions a system has — before you even finish solving it.

← Lesson 8 Lesson 10 → Contents Glossary →

Lesson 8 ended with "run elimination and see what happens." This lesson names the thing you're actually watching for — rank — and turns it into a complete, three-way classification of every possible solution set a system can have.

1. Rank

Definition — Rank The rank of a matrix is the number of pivot positions (equivalently, the number of nonzero rows) in its row echelon form. Extra equations that don't add new information — duplicates, or combinations of other rows — reduce to a zero row during elimination and don't raise the rank.
Why rank, not just "number of equations" Writing down five equations doesn't guarantee five pieces of independent information — one might just be 2 times another. Rank measures the information that survives elimination, which is what actually determines whether a system pins down a unique answer.

2. Classifying the solution set

Theorem — Rank and Solutions For a system with n variables, let r = rank(A) and r′ = rank([A | b]) (the augmented matrix). Exactly one of three cases holds: r′ > r — no solution (some row reduces to 0 = nonzero). r′ = r = n — exactly one solution. r′ = r < n — infinitely many solutions, with n − r free variables.

Check your recall

1. What does the rank of a matrix measure?

Rank counts genuinely independent rows after elimination — redundant rows collapse to zero and don't count.

2. A 3×3 matrix reduces to row echelon form [[1,2,3],[0,1,4],[0,0,0]]. What is its rank?

Two rows have pivots (nonzero leading entries); the bottom row is entirely zero and contributes nothing — rank 2.

3. Fill in the blank: if rank(A) = rank([A|b]) = n (the number of variables), the system has a ___ solution.

Full rank matching the number of variables means every variable is pinned down by its own pivot — exactly one solution.

4. If rank(A) < rank([A|b]), what does that tell you about the system?

Adding column b raised the rank, which only happens when some row becomes 0 = (nonzero) — a contradiction, so no solution exists.

5. Fill in the blank: for a system in n = 4 variables with rank(A) = rank([A|b]) = 2, there are ___ free variables.

Free variables = n − r = 4 − 2 = 2 — two variables can be chosen freely, with the other two determined in terms of them.
