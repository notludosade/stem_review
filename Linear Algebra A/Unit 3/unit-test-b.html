1. For the system −2x + 4y = 1, 3x + y = −6, what is the coefficient matrix A?

Read the coefficients row by row, leaving constants out: row 1 is (−2, 4), row 2 is (3, 1).

2. Fill in the blank: for A = [[2, 0], [0, 5]] and b = (8, 15), x = A⁻¹b = ___.

A⁻¹ = [[0.5, 0], [0, 0.2]], so A⁻¹b = (0.5·8, 0.2·15) = (4, 3).

3. Answer both parts:

(a) Which of these IS a valid elementary row operation?

(b) Fill in the blank: the three allowed row operations always preserve the ___ set of the system.

(a) Any nonzero scalar is allowed — here −1/2 works fine. (b) That's the entire reason these three operations were chosen: none of them can add or remove a valid solution.

4. For the row echelon matrix [[2, 1, 5], [0, 0, 0], [0, 0, 0]], answer both parts:

(a) What is its rank?

(b) Fill in the blank: if this is the coefficient matrix of a 3-variable system whose augmented matrix also has rank 1, there is/are ___ free variable(s).

(a) Only the first row has a pivot; the other two are entirely zero — rank 1. (b) Free variables = n − r = 3 − 1 = 2.

5. Why append b as an extra column to form [A | b], instead of solving with A and b kept separate?

Every row operation needs to update the constants alongside the coefficients — keeping them in one matrix makes that automatic.

6. Answer both parts:

(a) A system in n = 3 variables has rank(A) = 2 and rank([A|b]) = 2. What kind of solution set does it have?

(b) Fill in the blank: for a system in n = 2 variables with rank(A) = rank([A|b]) = 1, there is/are ___ free variable(s).

(a) Equal ranks below n means the system is consistent but underdetermined — infinitely many solutions, with n − r = 1 free variable. (b) Free variables = n − r = 2 − 1 = 1.

7. Fill in the blank: a row that reduces entirely to zeros during elimination contributes ___ to the rank.

Only rows with a pivot count toward rank — an all-zero row carries no independent information.

8. For R1 = [1, −1, 2 | 5] and R2 = [−2, 3, 1 | −4], answer both parts about R2 = R2 + 2R1:

(a) What is the new R2?

(b) Fill in the blank: the entry in the first column of the new R2 is always ___ after this operation.

(a) (−2+2·1, 3+2·−1, 1+2·2 | −4+2·5) = (0, 1, 5 | 6). (b) Adding a chosen multiple of R1 to R2 is specifically designed to zero out that column.

9. A 2-equation, 2-unknown system's second equation is exactly −3 times the first. What is rank(A)?

The second row is a scalar multiple of the first, so it reduces entirely to zero during elimination — only one independent row remains, rank 1.

10. For the system 3x − y = 7, x + y = 5, answer both parts:

(a) Adding the two equations eliminates y. What is x?

(b) Fill in the blank: y = ___.

(a) 4x = 12, so x = 3. (b) From x + y = 5: y = 5 − 3 = 2.
