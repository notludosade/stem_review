Systems as Matrix Equations

Every system of linear equations, repackaged as a single matrix equation — and one route to solving it, when the matrix cooperates.

← Lesson 6 Lesson 8 → Contents Glossary →

Precalculus solved systems of two or three equations by hand, one substitution or elimination at a time. Every one of those systems can be rewritten as a single matrix equation — and once it is, all the matrix machinery from Unit 2 becomes available to solve it.

1. From system to matrix equation

Definition — Matrix Form of a System A system of linear equations a₁₁x₁ + a₁₂x₂ + ⋯ = b₁, a₂₁x₁ + a₂₂x₂ + ⋯ = b₂, … can be written as Ax = b, where A is the coefficient matrix (just the numbers in front of the variables), x is the column vector of unknowns, and b is the column vector of constants on the right-hand side.
Worked Example 2x + 3y = 7 and −x + 4y = 2 becomes A = [[2, 3], [−1, 4]], x = [x, y]ᵀ, b = [7, 2]ᵀ. Multiplying Ax back out reproduces both original equations exactly — matrix multiplication was built precisely so that this works.

2. Solving with the inverse

Rule — Solving Ax = b If A is invertible, multiply both sides on the left by A⁻¹: A⁻¹Ax = A⁻¹b, which simplifies to x = A⁻¹b — a single matrix-vector product hands you the entire solution at once.
Why this only sometimes works x = A⁻¹b requires A⁻¹ to exist in the first place — and Lesson 6 was explicit that not every square matrix has one. When A is singular, this method simply doesn't apply; the system might still have infinitely many solutions or none at all, but a different tool (Lesson 8's elimination) is needed to tell which.

Check your recall

1. In the matrix equation Ax = b built from a system, what does A contain?

The variables move into the vector x, and the constants move into b — A is left holding only the coefficients.

2. For the system 3x − y = 5, 2x + y = 0, what is the coefficient matrix A?

Read the coefficients straight off each equation, row by row: row 1 is (3, −1), row 2 is (2, 1).

3. Fill in the blank: x = A⁻¹b only works as a solution method when A is ___.

A⁻¹ has to exist for this method to even be written down — a singular A needs a different approach entirely.

4. For A = [[1, 0], [0, 2]] and b = [4, 6]ᵀ, what is x = A⁻¹b?

A⁻¹ = [[1, 0], [0, 0.5]], so A⁻¹b = (1·4, 0.5·6) = (4, 3) — directly matches solving x = 4 and 2y = 6 by hand.

5. If the coefficient matrix A of a system is singular, what does that tell you about x = A⁻¹b?

A singular coefficient matrix only rules out this particular method — the system itself could still have no solution or infinitely many, a distinction Lesson 9 resolves with rank.
