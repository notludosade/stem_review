1. For the system 5x + 2y = 9, −x + 3y = −4, what is the coefficient matrix A?

Read the coefficients row by row, leaving the constants out: row 1 is (5, 2), row 2 is (−1, 3).

2. Fill in the blank: for A = [[1, 0], [0, 3]] and b = (5, 9), x = A⁻¹b = ___.

A⁻¹ = [[1, 0], [0, 1/3]], so A⁻¹b = (1·5, (1/3)·9) = (5, 3).

3. Answer both parts:

(a) Which of these is NOT a valid elementary row operation?

(b) Fill in the blank: the target form reached by forward elimination is called row ___ form.

(a) Scaling by 0 destroys a row's information rather than preserving the solution set — the scalar must be nonzero. (b) Forward elimination aims for row echelon form: staggered pivots, zero rows at the bottom.

4. For the row echelon matrix [[1, 4, −2], [0, 0, 5], [0, 0, 0]], answer both parts:

(a) What is its rank?

(b) Fill in the blank: if this is the coefficient matrix of a 3-variable system whose augmented matrix also has rank 2, there is/are ___ free variable(s).

(a) Two rows have pivots (columns 1 and 3); the bottom row is zero, giving rank 2. (b) Free variables = n − r = 3 − 2 = 1.

5. What does the augmented matrix [A | b] let you do?

Appending b as an extra column keeps every piece of the system in one place, so row operations can act on coefficients and constants together.

6. Answer both parts:

(a) A system in n = 2 variables has rank(A) = 1 and rank([A|b]) = 2. What kind of solution set does it have?

(b) Fill in the blank: a system in n = 3 variables with rank(A) = rank([A|b]) = 3 has a ___ solution.

(a) rank([A|b]) > rank(A) means some row became 0 = (nonzero) — a contradiction. (b) Full rank matching the variable count pins down every variable exactly.

7. Fill in the blank: the rank of a matrix equals the number of ___ positions in its row echelon form.

Each pivot marks one row's worth of genuinely independent information; rows without one are redundant and don't count.

8. For R1 = [1, 2, 3 | 10] and R2 = [3, 5, 1 | 4], answer both parts about R2 = R2 − 3R1:

(a) What is the new R2?

(b) Fill in the blank: the entry in the first column of the new R2 is always ___ after this operation.

(a) (3−3·1, 5−3·2, 1−3·3 | 4−3·10) = (0, −1, −8 | −26). (b) That's the entire purpose of subtracting a multiple of R1 — it zeroes out the pivot column in R2.

9. A 3-equation system's third equation is exactly the sum of the first two. Compared to using just those first two (independent) equations, rank(A):

A row that's a combination of other rows always reduces to all zeros during elimination — it never contributes a new pivot.

10. For the system 2x + y = 8, x − y = 1, answer both parts:

(a) Adding the two equations eliminates y. What is x?

(b) Fill in the blank: y = ___.

(a) 3x = 9, so x = 3. (b) From x − y = 1: y = x − 1 = 2.
