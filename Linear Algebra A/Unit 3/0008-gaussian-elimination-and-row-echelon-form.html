Gaussian Elimination and Row Echelon Form

A systematic, row-by-row way to solve any system — invertible coefficient matrix or not.

← Lesson 7 Lesson 9 → Contents Glossary →

x = A⁻¹b was fast, but it stalled the moment A was singular. Gaussian elimination is the more general tool — it works on every system, tells you exactly how many solutions exist, and is really just "elimination," the technique from Precalculus, repackaged as row operations on a matrix.

1. The augmented matrix

Definition — Augmented Matrix The augmented matrix [A | b] appends the constants column b onto the coefficient matrix A, separated by a vertical bar. It holds the entire system — every coefficient and every constant — without ever writing a variable name.

2. Row operations and row echelon form

Definition — Elementary Row Operations Three moves are allowed, and each one preserves the solution set exactly: (1) swap two rows, (2) multiply a row by a nonzero constant, and (3) add a multiple of one row to another. Multiplying a row by 0 is not allowed — that would destroy information, not just rearrange it.
Definition — Row Echelon Form (REF) A matrix is in row echelon form when: every row of all zeros sits at the bottom, and each row's leading nonzero entry (its pivot) sits strictly to the right of the pivot in the row above it. Reaching this form is the goal of forward elimination.
Why this works even when A is singular Unlike x = A⁻¹b, elimination never assumes an inverse exists. It just keeps simplifying rows. If A turns out to be singular, that shows up naturally as a row of zeros appearing on the left side — Lesson 9 turns that observation into a full classification of how many solutions the system has.

Check your recall

1. Which of these is NOT a valid elementary row operation?

Scaling by 0 would erase a row's information entirely rather than just rearrange it — the allowed scalar must be nonzero.

2. Which matrix is in row echelon form?

Each row's pivot (leading nonzero entry) sits strictly right of the one above it: column 1, then column 2, then column 3. The other options either have a zero row on top, a later pivot to the left of an earlier one, or two rows both leading in column 1.

3. Fill in the blank: after reaching [[1,1,1|6],[0,−1,−3|−11],[0,0,10|30]], back-substitution gives 10z = 30, so z = ___.

10z = 30 gives z = 3 directly — the whole point of reaching row echelon form is that the last row solves for one variable immediately.

4. What does the augmented matrix [A | b] represent?

Appending b as an extra column keeps every coefficient and every constant in one grid, ready for row operations, with no variable names needed.

5. Fill in the blank: if elimination produces a row [0, 0, 0 | 5] (all zeros on the left, nonzero on the right), the system has ___.

That row claims 0 = 5, a contradiction no values of the variables can satisfy — the system is inconsistent and has no solution at all.
