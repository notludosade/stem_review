Linear Transformations in Computer Graphics

Scaling, rotation, reflection, and shear are matrix multiplications applied to every vertex.

← Lesson 18 Lesson 20 → Contents Glossary →

Core MatricesScaling uses [[sx,0],[0,sy]]. Rotation by θ uses [[cosθ,−sinθ],[sinθ,cosθ]]. Matrix products compose transformations; order matters.
Homogeneous CoordinatesTranslation is not linear in 2D, but 3×3 homogeneous matrices represent it by embedding (x,y) as (x,y,1).
Why This MattersGraphics pipelines apply the same compact transformation to thousands of vertices.
Try It — Rotate (1,0)

Check your recall

1. Which transformation is not linear in ordinary 2D coordinates?

A linear map must send 0 to 0; nonzero translation does not.

2. Rotating (1,0) counterclockwise 90° gives ___.

cos90=0 and sin90=1.

3. In general, AB and BA:

Matrix multiplication is not commutative.
