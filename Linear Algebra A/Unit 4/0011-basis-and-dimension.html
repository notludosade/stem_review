Basis and Dimension

The smallest set of vectors that still reaches everywhere — and the single number that counts how many it takes.

← Lesson 10 Lesson 12 → Contents Glossary →

Span (Lesson 2) asked what a set of vectors can reach. Independence (Lesson 10) asked whether every vector in the set is necessary. Put them together and you get exactly the right amount of vectors to describe a whole space — no redundancy, no gaps.

1. Basis

Definition — Basis A basis for a vector space V is a set of vectors that is both (1) linearly independent and (2) spans V. Every vector in V can then be written as a linear combination of basis vectors in exactly one way.
The Standard Basis For ℝⁿ, the standard basis is e₁ = (1, 0, …, 0), e₂ = (0, 1, 0, …, 0), …, eₙ = (0, …, 0, 1). Any vector (v₁, …, vₙ) is instantly v₁e₁ + v₂e₂ + ⋯ + vₙeₙ — the components you already write are secretly basis coefficients.

2. Dimension

Fact — Dimension Every basis of a given (finite-dimensional) vector space V has exactly the same number of vectors. That shared number is the dimension of V, written dim(V). ℝⁿ has dimension n — matched by the n vectors in its standard basis.
Why "independent" and "spans" are both needed Independent alone isn't enough — {(1, 0)} is independent in ℝ² but only spans a line, missing most of the plane. Spanning alone isn't enough either — {(1, 0), (0, 1), (1, 1)} spans ℝ² but is dependent (three vectors in a 2-dimensional space always are). Only the combination pins down a basis. One shortcut: if a set already has exactly dim(V) vectors, checking either condition alone is enough — the other comes along for free.

Check your recall

1. A basis for a vector space V must be:

Both conditions are required together — independence alone can undershoot the space, and spanning alone can carry redundant vectors.

2. What is the standard basis for ℝ³?

The standard basis has a single 1 in a different position each time — three vectors for ℝ³, matching its dimension.

3. Fill in the blank: the dimension of ℝ⁴ is ___.

The standard basis of ℝ⁴ has exactly 4 vectors — dimension always matches the size of any basis.

4. Is {(1, 1), (1, −1)} a basis for ℝ²?

det = (1)(−1) − (1)(1) = −2 ≠ 0 confirms independence, and matching the dimension (2 vectors for ℝ²) means spanning comes along automatically.

5. Can any set of 3 vectors form a basis for ℝ²?

ℝ² has dimension 2, so no independent set there can exceed 2 vectors — any 3rd vector is forced to be some combination of the first two.
