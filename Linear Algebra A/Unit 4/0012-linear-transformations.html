Linear Transformations

Every matrix is secretly a function that moves the entire plane — and every "nice" function that moves the plane turns out to be some matrix.

← Lesson 11 Lesson 13 → Contents Glossary →

So far, matrices have mostly been arithmetic objects. This lesson gives them a second life: a matrix A defines a function T(v) = Av that takes every vector in ℝⁿ to a new one in ℝᵐ. That function is a linear transformation, and it's the geometric heart of the rest of this course.

1. What makes a transformation linear

Definition — Linear Transformation A function T: ℝⁿ → ℝᵐ is a linear transformation if it satisfies both: T(u + v) = T(u) + T(v), and T(cv) = cT(v), for all vectors u, v and scalars c. Every matrix-vector product T(v) = Av automatically satisfies both, straight from the distributive and scalar rules of matrix multiplication.
Why linearity is a strong restriction Linear transformations always send 0 to 0, always send lines through the origin to lines through the origin (or collapse them to a point), and always keep evenly spaced grid lines evenly spaced. A function that curves, bends, or shifts the origin away from 0 is not linear, no matter how smooth it looks.

2. A matrix is completely determined by where it sends the basis

Fact — Columns Are Images of the Basis For T(v) = Av with A an m × n matrix, column j of A is exactly T(eⱼ) — the image of the j-th standard basis vector. Knowing where T sends every basis vector is enough to know where it sends everything, since every vector is a combination of basis vectors.

Check your recall

1. Which two properties define a linear transformation T?

Additivity and homogeneity (scalar compatibility) are the entire definition — nothing about invertibility, doubling, or T(0) being nonzero is required (in fact T(0) is always 0).

2. For A = [[2, 0], [0, 3]] and v = (4, 5), what is T(v) = Av?

Av = (2·4 + 0·5, 0·4 + 3·5) = (8, 15) — a diagonal matrix simply scales each coordinate by its own factor.

3. Fill in the blank: for T(v) = Av, T(e1) always equals the ___ column of A.

Multiplying A by e1 = (1, 0, …, 0) picks out exactly column 1 of A.

4. Which 2×2 matrix reflects every vector across the x-axis?

Reflecting across the x-axis keeps x the same and negates y: (x, y) ↦ (x, −y), exactly what [[1,0],[0,−1]] does. The second option reflects across the y-axis instead; the third swaps coordinates (a reflection across y = x); the fourth is the identity, no change at all.

5. A 2×2 matrix transforms the unit square into a parallelogram with 3 times the original area. What does that tell you about the transformation?

Because a linear transformation treats every region of the plane uniformly, the area-scaling factor measured on the unit square (here, 3) applies everywhere — a fact Unit 5 makes precise with the determinant.
