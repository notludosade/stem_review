1. A set of vectors {v1, …, vk} is linearly independent when:

Only the trivial-solution condition defines independence — unit length, set size, and distinctness are all separate (and not equivalent) properties.

2. Fill in the blank: the set containing only the zero vector, {0}, is always linearly ___.

c·0 = 0 for every scalar c, so a nontrivial solution always exists — {0} can never be independent.

3. For v1 = (3, 2) and v2 = (6, 4), answer both parts:

(a) What is ad − bc for this pair?

(b) Fill in the blank: so {v1, v2} is linearly ___.

(a) (3)(4) − (2)(6) = 12 − 12 = 0. (b) v2 = 2v1 exactly, so the pair is dependent — matching the zero determinant.

4. Answer both parts:

(a) A basis for a vector space V must be:

(b) Fill in the blank: the dimension of ℝ⁵ is ___.

(a) Both conditions are required together. (b) The standard basis of ℝ⁵ has 5 vectors, so dim(ℝ⁵) = 5.

5. What is the standard basis for ℝ²?

The standard basis vectors each have a single 1 in a different coordinate — for ℝ², that's (1,0) and (0,1).

6. For v1 = (2, 3) and v2 = (4, 6), answer both parts:

(a) Is {v1, v2} a basis for ℝ²?

(b) Fill in the blank: any set of more than n vectors in an n-dimensional space is automatically linearly ___.

(a) ad − bc = (2)(6) − (3)(4) = 0, confirming v2 is a multiple of v1. (b) Exceeding the dimension always forces dependence — there's no room for another independent direction.

7. Fill in the blank: for any linear transformation T, T(0) = ___.

T(c·0) = cT(0) for every c; the only vector satisfying that for all c is the zero vector itself, so T(0) = 0 always.

8. For A = [[1, 2], [3, −1]] and v = (2, 1), answer both parts:

(a) What is T(v) = Av?

(b) Fill in the blank: T(e2), the image of e2, equals column 2 of A = ___.

(a) Av = (1·2+2·1, 3·2+−1·1) = (4, 5). (b) Column 2 of A is (2, −1) — always the image of e2.

9. A linear transformation scales the unit square's area by a factor of 3. What happens to the area of any other region under the same transformation?

Linearity applies uniformly across the whole plane — the same scaling factor measured on the unit square holds everywhere else too.

10. For A = [[0, 1], [1, 0]], answer both parts:

(a) Geometrically, what does T(v) = Av do to the plane?

(b) Fill in the blank: T((3, 7)) = ___.

(a) This matrix swaps coordinates: (x, y) ↦ (y, x), which is exactly reflection across y = x. (b) Swap the coordinates of (3, 7) to get (7, 3).
