Linear Independence and Dependence

Does every vector in a set pull its own weight, or is at least one of them redundant — already reachable from the others?

← Lesson 9 Lesson 11 → Contents Glossary →

Unit 1 asked which points a set of vectors could reach (span). This unit asks a sharper question: is every vector in that set actually necessary, or could you throw one away and reach exactly the same span? The precise tool for answering it is linear independence.

1. The precise definition

Definition — Linear Independence Vectors v₁, …, vₖ are linearly independent if the only solution to c₁v₁ + c₂v₂ + ⋯ + cₖvₖ = 0 is the trivial solution c₁ = c₂ = ⋯ = cₖ = 0. If some nontrivial solution exists (not all cᵢ zero), the set is linearly dependent.
Why this is the right question A nontrivial solution to c₁v₁ + ⋯ + cₖvₖ = 0 means at least one vector can be solved for in terms of the others — it's redundant, contributing nothing new to the span. Independence is exactly the absence of that redundancy.

2. Two precise edge cases

Fact — A Single Nonzero Vector Any single nonzero vector v is automatically linearly independent. The equation cv = 0 with v ≠ 0 forces c = 0 — no other solution is possible, so only the trivial one exists.
Fact — The Zero Vector Alone The set {0} (just the zero vector, by itself) is automatically linearly dependent. c·0 = 0 holds for every scalar c — c = 1 is a perfectly good nontrivial solution, so the trivial solution is never the only one.

3. Testing two vectors in ℝ²

Test — Two Vectors in ℝ² For v1 = (a, b) and v2 = (c, d), the set {v1, v2} is linearly independent exactly when ad − bc ≠ 0 — the same quantity from Lesson 6's inverse formula. Geometrically: independent means the two vectors point in genuinely different directions; dependent means one is a scalar multiple of the other (parallel, or one of them is 0).

Check your recall

1. A set of vectors is linearly independent when:

Independence is defined entirely through the trivial-solution condition on c₁v₁ + ⋯ + cₖvₖ = 0 — magnitude, spanning all of ℝⁿ, and simply avoiding 0 are all separate (and not equivalent) properties.

2. Is a single nonzero vector v always linearly independent?

Since v ≠ 0, cv = 0 has no room for a nonzero c to work — c = 0 is forced, which is exactly the trivial-solution-only condition for independence.

3. Fill in the blank: the set {0}, containing only the zero vector, is always linearly ___.

c·0 = 0 for every scalar c, so a nontrivial solution (like c = 1) always exists — {0} can never be independent.

4. Are v1 = (2, 1) and v2 = (4, 2) linearly independent?

v2 is exactly twice v1 — a nontrivial combination like 2v1 − v2 = 0 exists, so the pair is dependent, matching ad − bc = 0.

5. Fill in the blank: for two vectors v1 = (a, b), v2 = (c, d) in ℝ², the set is independent exactly when ad − bc ≠ ___.

ad − bc = 0 is exactly the condition for the two vectors to be parallel (or one to be zero) — the dependent case.
