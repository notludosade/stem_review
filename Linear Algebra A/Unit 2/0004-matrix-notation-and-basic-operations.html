Matrix Notation and Basic Operations

A rectangular grid of numbers — vectors' bigger, two-dimensional sibling — and the operations that carry straight over from Unit 1.

← Lesson 3 Lesson 5 → Contents Glossary →

Unit 1 built everything out of vectors — ordered lists of numbers. A matrix is the natural next step: a whole grid of numbers, organized into rows and columns. Every vector is secretly already a matrix (a single column, or a single row) — so it's no surprise that matrix addition and scalar multiplication look exactly like the vector versions from Lesson 1.

1. Matrix notation

Definition — Matrix A matrix is a rectangular array of numbers, usually named with a capital letter. A matrix with m rows and n columns has dimensions m × n (rows first, then columns). Each individual number is an entry; the entry in row i, column j is written aᵢⱼ.

A square matrix has equal rows and columns (m = n) — Units 5 and 6 (determinants, eigenvalues) apply only to square matrices. The zero matrix has every entry equal to 0, and plays the same role among matrices that the zero vector plays among vectors.

2. Addition, subtraction, and scalar multiplication

Rule — Addition and Subtraction Two matrices can be added or subtracted only if they have the same dimensions — then every entry combines with the entry in the matching position. A 2×3 matrix can never be added to a 3×2 one, even though both have six entries.
Rule — Scalar Multiplication Multiplying a matrix by a scalar c multiplies every entry by c. No dimension restriction — this works on a matrix of any size.
Why this feels familiar Both rules are identical to Lesson 1's vector rules, just applied entry-by-entry across a 2-D grid instead of a 1-D list. That's not a coincidence — an m × n matrix is, underneath the notation, a vector with mn components, arranged on a grid purely for readability.

3. The transpose

Definition — Transpose The transpose of an m × n matrix A, written Aᵀ, is the n × m matrix formed by turning every row of A into a column: entry (i, j) of Aᵀ is entry (j, i) of A. A 2×3 matrix transposes into a 3×2 one — the dimensions swap.
Worked Example A = [[1, 2, 3], [4, 5, 6]] is 2×3. Aᵀ = [[1, 4], [2, 5], [3, 6]] is 3×2. Row 1 of A, (1, 2, 3), became column 1 of Aᵀ.

1. Two matrices can be added only if they have:

Addition pairs up entries by matching position, so both matrices need the same number of rows and the same number of columns — not merely the same total entry count.

2. For A = [[2, 0], [−1, 3]] and B = [[4, 1], [2, −5]], what is A + B?

Add entry-by-entry: (2+4, 0+1; −1+2, 3+(−5)) = (6, 1; 1, −2).

3. Fill in the blank: the transpose of a 2×3 matrix has dimensions ___.

Transposing swaps rows and columns, so an m × n matrix becomes n × m — here, 2×3 becomes 3×2.

4. A matrix with equal numbers of rows and columns is called:

"Square" refers only to matching row and column counts — later lessons add extra structure (identity, diagonal) on top of that shape.

5. For A = [[1, −2], [3, 5]], what is 2A?

Scalar multiplication scales every entry: 2·(1, −2; 3, 5) = (2, −4; 6, 10).
