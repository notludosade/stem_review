The Identity Matrix and Matrix Inverses

The matrix that acts like the number 1 — and the fact that, unlike with real numbers, not every nonzero matrix gets to have a reciprocal.

← Lesson 5 Lesson 7 → Contents Glossary →

Ordinary numbers have a multiplicative identity (1) and, for anything nonzero, a reciprocal. Matrices have direct analogues of both — but the analogy breaks in one important way, and knowing exactly where is the whole point of this lesson.

1. The identity matrix

Definition — Identity Matrix The identity matrix Iₙ is the n × n square matrix with 1's down the main diagonal and 0's everywhere else. For every matrix A of compatible size, AI = IA = A — multiplying by I changes nothing, exactly like multiplying a real number by 1.
2×2 and 3×3 identity matrices I₂ = [[1, 0], [0, 1]]. I₃ = [[1, 0, 0], [0, 1, 0], [0, 0, 1]].

2. Matrix inverses

Definition — Inverse A square matrix A is invertible (or nonsingular) if there exists a matrix A⁻¹ with AA⁻¹ = A⁻¹A = I. If no such matrix exists, A is singular. Only square matrices are even eligible to have an inverse.
Formula — 2×2 Inverse For A = [[a, b], [c, d]]: A⁻¹ = (1 / (ad − bc)) · [[d, −b], [−c, a]] — provided ad − bc ≠ 0. Swap the diagonal entries, negate the off-diagonal entries, then scale everything by 1/(ad − bc).
Why ad − bc = 0 breaks everything That quantity ad − bc is a preview of Unit 5's determinant. When it's 0, the formula above asks you to divide by zero — the inverse simply doesn't exist for that matrix, the same way 0 has no reciprocal among real numbers. Not every square matrix is invertible, no matter how it looks; this has to be checked, never assumed.

Check your recall

1. For a matrix A of compatible size, what is AI?

The identity matrix is the multiplicative identity for matrices — multiplying by it, in either order, leaves A completely unchanged.

2. For A = [[3, 2], [1, 1]], what is A⁻¹?

ad − bc = (3)(1) − (2)(1) = 1, so A⁻¹ = (1/1)·[[1, −2], [−1, 3]] = [[1, −2], [−1, 3]].

3. Fill in the blank: a 2×2 matrix [[a, b], [c, d]] is invertible exactly when ad − bc ≠ ___.

The 2×2 inverse formula divides by ad − bc, so that quantity must be nonzero for the inverse to exist at all.

4. Which of these matrices is singular (has no inverse)?

For [[2,4],[1,2]]: ad − bc = (2)(2) − (4)(1) = 0. The formula would divide by zero, so no inverse exists — row 2 is exactly half of row 1, which is exactly the kind of "redundant" matrix that turns out to be singular.

5. Fill in the blank: a square matrix with determinant 0 is called ___ (has no inverse).

"Singular" and "invertible" are opposites for square matrices — every square matrix is exactly one or the other, decided entirely by whether its determinant is 0.
