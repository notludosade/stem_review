1. For A = [[7, 3], [2, 5]], what is det(A)?

ad − bc = (7)(5) − (3)(2) = 35 − 6 = 29.

2. Fill in the blank: for B = [[4, −5], [2, 1]], det(B) = ___.

(4)(1) − (−5)(2) = 4 + 10 = 14.

3. For A = [[2, 0, 1], [3, 1, 4], [1, −2, 5]], answer both parts:

(a) What is the minor M₁₁?

(b) Fill in the blank: det(A) = ___.

(a) M₁₁ = det[[1,4],[−2,5]] = 5 + 8 = 13. (b) M₁₃ = det[[3,1],[1,−2]] = −6 − 1 = −7. det(A) = 2(13) − 0 + 1(−7) = 26 − 7 = 19.

4. If det(A) = −6, answer both parts:

(a) After swapping two rows of A, the new determinant is:

(b) Fill in the blank: if instead you scale one row of A by 2, the new determinant is ___.

(a) A row swap negates the determinant: −(−6) = 6. (b) Scaling a row by k multiplies the determinant by k: 2 × −6 = −12.

5. If det(A) = 10 and you add −4 times row 3 to row 1, what is the new determinant?

Adding a multiple of one row to another never changes the determinant.

6. For the lower triangular matrix [[2, 0, 0], [0, −3, 0], [5, 9, 4]], answer both parts:

(a) What is its determinant?

(b) Fill in the blank: this shortcut (just multiply the diagonal) works because the matrix is ___.

(a) 2 × (−3) × 4 = −24. (b) The product-of-the-diagonal shortcut only applies to triangular (or diagonal) matrices.

7. Fill in the blank: a matrix with two identical rows always has determinant ___ (swapping those two rows should negate the determinant, but leaves the matrix unchanged — the only number equal to its own negative).

Swapping identical rows changes nothing, yet a swap must negate the determinant: det = −det forces det = 0.

8. Answer both parts:

(a) Which of these is NOT a consequence of det(A) = 0 for a square matrix A?

(b) Fill in the blank: if det(A) ≠ 0, then Ax = b has exactly ___ solution for every b.

(a) det(A) = 0 rules out invertibility entirely — it's the one option that's false. (b) A nonzero determinant guarantees exactly one solution for every choice of b.

9. Is A = [[5, −1], [10, −2]] invertible?

Row 2 is exactly 2 times row 1, so det(A) = −10 + 10 = 0 — A is singular.

10. Answer both parts:

(a) A linear transformation's matrix has det(A) = −2. By what factor does it scale area?

(b) Fill in the blank: if a transformation's matrix has det = 1, area is scaled by a factor of ___.

(a) The area-scaling factor is |det(A)| = |−2| = 2 — a negative determinant flips orientation but area is never negative. (b) det = 1 means area is preserved exactly.
