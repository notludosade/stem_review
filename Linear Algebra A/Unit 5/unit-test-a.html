1. For A = [[5, 2], [3, 4]], what is det(A)?

ad − bc = (5)(4) − (2)(3) = 20 − 6 = 14.

2. Fill in the blank: for B = [[6, −2], [1, 3]], det(B) = ___.

(6)(3) − (−2)(1) = 18 + 2 = 20.

3. For A = [[1, 2, 3], [0, 4, 5], [1, 0, 6]], answer both parts:

(a) What is the minor M₁₁?

(b) Fill in the blank: det(A) = ___.

(a) M₁₁ = det[[4,5],[0,6]] = 24 − 0 = 24. (b) M₁₂ = det[[0,5],[1,6]] = −5, M₁₃ = det[[0,4],[1,0]] = −4. det(A) = 1(24) − 2(−5) + 3(−4) = 24 + 10 − 12 = 22.

4. If det(A) = 8, answer both parts:

(a) After swapping two rows of A, the new determinant is:

(b) Fill in the blank: if instead you scale one row of A by −3, the new determinant is ___.

(a) A row swap always negates the determinant: −8. (b) Scaling a row by k multiplies the determinant by k: −3 × 8 = −24.

5. If det(A) = −5 and you add 7 times row 2 to row 1, what is the new determinant?

Adding a multiple of one row to another never changes the determinant, regardless of the multiple.

6. For the lower triangular matrix [[3, 0, 0], [7, −2, 0], [1, 4, 5]], answer both parts:

(a) What is its determinant?

(b) Fill in the blank: this shortcut (just multiply the diagonal) works because the matrix is ___.

(a) 3 × (−2) × 5 = −30. (b) Triangular matrices (upper or lower) have determinant equal to the product of their diagonal entries.

7. Fill in the blank: a matrix with an entire row of zeros always has determinant ___.

Every term in a cofactor expansion along a zero row multiplies by 0, so the whole determinant is 0.

8. Answer both parts:

(a) A square matrix A is invertible exactly when:

(b) Fill in the blank: if det(A) = 0, the columns of A are linearly ___.

(a) This is the exact if-and-only-if condition. (b) det(A) = 0 and dependent columns are equivalent conditions.

9. Is A = [[4, 2], [6, 3]] invertible?

Row 2 is exactly 1.5 times row 1, so det(A) = 12 − 12 = 0 — A is singular.

10. Answer both parts:

(a) A linear transformation's matrix has det(A) = 5. By what factor does it scale area?

(b) Fill in the blank: a matrix with det = 0 collapses the plane onto a ___.

(a) The area-scaling factor is exactly |det(A)|. (b) A zero determinant means zero area-scaling everywhere — the image collapses to a line (or a single point).
