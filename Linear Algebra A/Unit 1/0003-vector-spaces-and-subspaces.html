Vector Spaces and Subspaces

Which subsets of ℝⁿ are self-contained enough — closed under everything Lesson 1 defined — to be a vector space in their own right?

← Lesson 2 Lesson 4 → Contents Glossary →

Every example so far has lived in all of ℝ² or ℝ³. This lesson asks a narrower question: given some subset of ℝⁿ — a line, a plane, a quadrant — does vector addition and scalar multiplication stay inside that subset, or can it leak out? Subsets that never leak get a name of their own.

1. Vector spaces, briefly

Definition — Vector Space A vector space is a set of objects (called vectors) that can be added together and multiplied by scalars, obeying the algebra rules you already rely on without thinking — addition is commutative and associative, scalar multiplication distributes over addition, there's a zero vector, and every vector has an additive inverse. ℝⁿ, under the operations from Lesson 1, is the running example for the whole course.

This course stays almost entirely inside ℝⁿ, so the ten-item axiom checklist rarely needs to be verified from scratch. What comes up constantly instead is the question below.

2. Subspaces: a vector space living inside a bigger one

Definition — Subspace A subset W of a vector space V is a subspace of V if W is itself a vector space, using V's same addition and scalar multiplication.
The Subspace Test Instead of re-checking all ten vector space axioms, it's enough to confirm three things about a nonempty subset W of ℝⁿ: (1) W contains the zero vector, (2) W is closed under addition (u, w ∈ W ⟹ u + w ∈ W), and (3) W is closed under scalar multiplication (u ∈ W, c ∈ ℝ ⟹ cu ∈ W). Fail any one of the three, and W is not a subspace.
Why only three conditions Commutativity, associativity, distributivity — every algebra rule from the full vector space definition — is already true of every vector in ℝⁿ, since W's vectors are ℝⁿ vectors. The only things that could possibly break by shrinking down to a subset are staying inside the subset (closure) and having a zero to start from. Everything else comes along for free.

Four candidate subsets of ℝ². Click through each and watch which of the three conditions it actually satisfies.

Try It — Is It a Subspace?

W = {(x, y) : y = 2x} — a line through the origin.

Contains 0? Yes — (0, 0) satisfies y = 2x. Add two points: (1, 2) + (3, 6) = (4, 8), and 8 = 2(4) ✓. Scale one: 5·(1, 2) = (5, 10), and 10 = 2(5) ✓.

A subspace — every line through the origin is.

W = {(x, y) : y = 2x + 1} — a line that misses the origin.

Contains 0? (0, 0) would need 0 = 2(0) + 1 = 1. False.

Not a subspace — fails at condition 1 before addition or scaling even matter.

W = {(x, y) : x ≥ 0, y ≥ 0} — the first quadrant, including its edges.

Contains 0? Yes. Closed under addition? Yes — two nonnegative pairs always add to a nonnegative pair. Scale (2, 3) by −1: (−2, −3), and −2 ≥ 0 is false.

Not a subspace — passes conditions 1 and 2, but fails condition 3: negative scalars push points outside the quadrant.

W = {(x, y) : xy = 0} — the union of the x-axis and the y-axis.

Contains 0? Yes. Scale any axis point by any c — it stays on the same axis, so condition 3 holds. Add (1, 0) + (0, 1) = (1, 1), and 1·1 = 1 ≠ 0.

Not a subspace — passes conditions 1 and 3, but fails condition 2: two points from different axes add to a point on neither.

Check your recall

1. Which three conditions make up the subspace test for a nonempty W ⊆ ℝⁿ?

Every other vector-space axiom is inherited automatically from ℝⁿ; only these three closure-style conditions can actually fail for a subset.

2. Is the line y = 2x + 1 a subspace of ℝ²?

Any line that doesn't pass through the origin immediately fails condition 1 of the subspace test — there's no need to even check the other two.

3. Fill in the blank: the smallest possible subspace of any vector space is just ___.

{0} trivially passes all three conditions: it contains 0, 0 + 0 = 0 stays inside, and c·0 = 0 stays inside for every scalar c.

4. W = {(x, y) : xy = 0} (the union of the two coordinate axes) fails to be a subspace because:

Scaling any single axis point keeps it on the same axis, so condition 3 holds — but adding a point from each axis lands off both, breaking condition 2.

5. The first quadrant {(x, y) : x ≥ 0, y ≥ 0} fails to be a subspace because:

Two nonnegative pairs always add to a nonnegative pair, so addition is fine — but c = −1 applied to (2, 3) gives (−2, −3), outside the quadrant.
