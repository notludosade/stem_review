1. For u = (1, 4) and w = (3, −2), what is u + w?

Add component-wise: (1 + 3, 4 + (−2)) = (4, 2).

2. Fill in the blank: for v = (−2, 5), the scalar multiple −4v = ___.

Scale every component by −4: (−4·−2, −4·5) = (8, −20).

3. For v = (6, 8), answer both parts:

(a) What is ‖v‖?

(b) Fill in the blank: if w = 2v, then ‖w‖ = ___.

(a) ‖v‖ = √(6² + 8²) = √100 = 10. (b) Scaling a vector by 2 scales its magnitude by the same factor: ‖2v‖ = 2‖v‖ = 20.

4. For v1 = (1, 0) and v2 = (0, 1), answer both parts:

(a) What is span{v1, v2}?

(b) Fill in the blank: span{v1} by itself (just one nonzero vector) is a ___ through the origin.

(a) c1(1,0) + c2(0,1) = (c1, c2) reaches every point as c1, c2 range over all reals. (b) Scaling a single nonzero vector by every real number traces out exactly one line through the origin.

5. Which of these is NOT one of the three subspace-test conditions?

Set size is never part of the test — a subspace can be infinite ({0} aside). Only the three closure-and-origin conditions matter.

6. For W = {(x, y) : y = −3x}, answer both parts:

(a) Is W a subspace of ℝ²?

(b) Fill in the blank: if instead W' = {(x, y) : y = −3x + 2}, W' fails the subspace test because it does not contain the ___.

(a) Every point (x, −3x) passes both closure checks, and (0, 0) satisfies the rule, so W is a subspace. (b) Shifting the line off the origin means (0, 0) no longer satisfies y = −3x + 2 (0 ≠ 2), so condition 1 fails immediately.

7. Fill in the blank: the magnitude of the zero vector is ___.

‖0‖ = √(0² + 0² + ⋯) = 0 — the only vector with zero length.

8. For v1 = (2, −1) and v2 = (1, 3), answer both parts:

(a) What is 2v1 + v2?

(b) Fill in the blank: −v1 + 2v2 = ___.

(a) 2v1 = (4, −2), plus v2 = (1, 3) gives (5, 1). (b) −v1 = (−2, 1), 2v2 = (2, 6), and their sum is (0, 7).

9. If v2 is a nonzero scalar multiple of v1, span{v1, v2} equals:

Every combination c1v1 + c2v2 reduces to a single scalar times v1, since v2 already points along v1's direction — no new territory is reached.

10. Answer both parts:

(a) Are (2, −5) and (−5, 2) equal vectors?

(b) Fill in the blank: for (x, 4) to equal (9, y), x = ___.

(a) Vector equality requires every matching component to agree, not just the same multiset of numbers. (b) Matching first components requires x = 9 (and matching second components would require y = 4).
