Vectors and Vector Operations

A quantity with both size and direction — and the two operations, addition and scalar multiplication, that everything else in this course is built from.

Lesson 2 → Contents Glossary →

Precalculus treated a system of equations as a search for the point where two lines cross. Linear algebra rebuilds that idea from the ground up, starting with a single object: the vector. Everything in this course — matrices, systems, eigenvectors — is a statement about vectors and the two operations defined on them in this lesson.

1. What a vector is

Definition — Vector A vector in ℝⁿ is an ordered list of n real numbers, written v = (v₁, v₂, …, vₙ). Each vᵢ is a component. Geometrically, a vector in ℝ² or ℝ³ is drawn as an arrow from the origin to the point with those coordinates — the arrow has both a length (magnitude) and a direction, which is the whole reason it's not just "a point."

Two vectors are equal exactly when every one of their components matches. (3, 5) and (5, 3) are different vectors, even though they use the same two numbers — order is part of the identity of a vector, not just decoration.

2. Adding vectors and scaling them

Rule — Vector Addition Vectors add component-wise, and only if they live in the same ℝⁿ: (u₁, u₂) + (w₁, w₂) = (u₁ + w₁, u₂ + w₂).
Rule — Scalar Multiplication Multiplying a vector by a real number c (a scalar) scales every component: c(v₁, v₂) = (cv₁, cv₂). c > 1 stretches the arrow, 0 < c < 1 shrinks it, and c < 0 reverses its direction entirely.
Why addition looks like "tip-to-tail" Draw u starting at the origin, then draw w starting from u's tip instead of the origin. The arrow from the origin to w's new tip lands exactly on u + w, every time. That's not a coincidence to memorize — it falls straight out of adding coordinates: moving u₁ right and u₂ up, then w₁ right and w₂ up, moves you the same total distance as one component-wise sum.

3. Magnitude and the zero vector

Definition — Magnitude (Norm) The magnitude (or norm) of v = (v₁, …, vₙ), written ‖v‖, is its length as an arrow: ‖v‖ = √(v₁² + v₂² + ⋯ + vₙ²) — the Pythagorean theorem, extended to n coordinates.
Definition — Zero Vector The zero vector, written 0 = (0, 0, …, 0), is the unique vector with ‖0‖ = 0. It's the additive identity: v + 0 = v for every vector v, and it's the one vector with no direction at all — a fact that matters a great deal once Unit 4 asks which sets of vectors are "independent."

1. What distinguishes a vector from a single number?

An ordered list of components gives a vector direction (which way it points) on top of magnitude (how long it is) — a single real number has magnitude but no direction to speak of.

2. For u = (3, −1) and w = (−2, 4), what is u + w?

Add component-wise: (3 + (−2), −1 + 4) = (1, 3).

3. Fill in the blank: for v = (2, −5), the scalar multiple −3v = ___.

Scale every component by −3: (−3·2, −3·−5) = (−6, 15).

4. What is the magnitude of v = (3, 4)?

‖v‖ = √(3² + 4²) = √25 = 5.

5. Fill in the blank: the vector (0, 0, …, 0), the unique additive identity, is called the ___ vector.

Adding it changes nothing (v + 0 = v), the same role 0 plays among ordinary numbers.
