1. What does Big-O notation describe?

Big-O ignores hardware speed and constant factors, focusing purely on the shape of growth as n grows.

2. What is the Big-O time complexity of this function?
def print_all(items): for x in items: print(x)

The single loop visits each of the n elements exactly once, no matter how large items is — the same shape as sum_list.

3. Fill in the blank: of O(1), O(n), and O(n²), the class that grows the slowest as input size increases is O(___).

O(1), constant time, costs the same number of operations no matter how large the input gets — the best class in the ranking.

4. What is the worst-case time complexity of linear search?

In the worst case, linear search looks at every single element before finding a match or running out of elements.

5. Why must binary search's input already be sorted?

Without sorted order, discarding half the remaining data based on one comparison would be unsafe — the target could be on either side.

6. Binary search runs on the sorted list [2, 4, 6, 8, 10, 12, 14] (indices 0–6) looking for target 10. Answer both parts:

(a) What index does binary search return?

(b) Fill in the blank: this search takes ___ total comparisons to find the target.

(a) mid = 3 → value 8, too low, search the right half. mid = 5 → value 12, too high, search back left. mid = 4 → value 10, a match — index 4. (b) That trace took three comparisons: at mid 3, then 5, then 4.

7. Answer both parts about scaling:

(a) For a sorted list of about 1,000,000 elements, roughly how many comparisons does binary search need in the worst case?

(b) Fill in the blank: if the data isn't sorted and will only be searched once, ___ search is often still the more practical choice, since sorting first costs time too.

(a) Each comparison halves the remaining range, so a million elements collapse to one match in roughly 20 steps. (b) Binary search's O(log n) advantage only pays off once the sorting precondition is already satisfied.

8. Bubble sort begins on [5, 3, 4, 1]. Answer both parts:

(a) After one full pass, what is the array?

(b) Fill in the blank: bubble sort's time complexity, O(n²), is called ___ time.

(a) Comparing adjacent pairs left to right: (5,3) swaps to [3,5,4,1], then (5,4) swaps to [3,4,5,1], then (5,1) swaps to [3,4,1,5]. (b) O(n²) comes from its nested-loop structure, the same shape as any doubly-nested loop.

9. Answer both parts about merge sort:

(a) What technique gives merge sort O(n log n) instead of O(n²)?

(b) Fill in the blank: merge sort's base case is a list of length ___ or less, already trivially sorted.

(a) Halving the problem recursively, combined with an O(n) merge step at each level, is exactly what produces O(n log n) overall. (b) A list of 0 or 1 elements needs no further splitting or merging — it's already sorted by definition.

10. Answer both parts about quicksort and real-world sorting:

(a) How does quicksort partition a list?

(b) Fill in the blank: real code rarely hand-writes bubble sort or merge sort, because every mainstream language already ships a fast, built-in O(n log n) ___ function.

(a) Partitioning around a pivot, then recursively sorting each side, is quicksort's core move. (b) Python's sorted(), Java's Collections.sort(), JavaScript's Array.prototype.sort(), and C++'s std::sort() all already provide this out of the box.
