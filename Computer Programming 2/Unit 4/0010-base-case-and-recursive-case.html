Base Case and Recursive Case

A function that calls itself sounds like it shouldn't work. It does — as long as it always gets closer to a stopping point.

Lesson 11 → Contents Glossary →

Recursion is a function calling itself to solve a smaller version of the same problem. Every recursive function needs two parts: a base case — the simplest input, answered directly with no further recursive call — and a recursive case — the general input, which calls the function again on something smaller, moving toward the base case. Below, factorial(n) multiplies n by the factorial of everything smaller than it, stopping at 0.

Python 
def factorial(n):
    if n == 0:                      # base case
        return 1
    return n * factorial(n - 1)     # recursive case

print(factorial(5))  # 120
Java 
static int factorial(int n) {
    if (n == 0) {                    // base case
        return 1;
    }
    return n * factorial(n - 1);     // recursive case
}

System.out.println(factorial(5)); // 120
JavaScript 
function factorial(n) {
    if (n === 0) {                   // base case
        return 1;
    }
    return n * factorial(n - 1);     // recursive case
}

console.log(factorial(5)); // 120
C++ 
int factorial(int n) {
    if (n == 0) {                     // base case
        return 1;
    }
    return n * factorial(n - 1);      // recursive case
}

std::cout << factorial(5) << std::endl; // 120

All four are nearly identical here — recursion itself is one of the rare ideas in this course that doesn't meaningfully differ by language. factorial(5) calls factorial(4), which calls factorial(3), and so on, until factorial(0) hits the base case and returns 1 without calling itself again. Each pending multiplication then completes on the way back: 1 * 1, then 2 * 1, then 3 * 2, and so on up to 120.

Definition Recursion is a function calling itself on a smaller version of its own problem. The base case is the simplest input, answered directly with no further recursive call. The recursive case is the general input, which calls the function again on something smaller.
Why it matters here A recursive function with no base case — or one that never actually gets closer to it — is the function-call equivalent of Computer Programming 1's infinite while loop: it never stops on its own. Instead of freezing the program, it typically crashes it outright once it runs out of room to keep track of all those pending calls — exactly what the next lesson explains.

factorial(0) is the base case here — it returns 1 directly, with no further call.

factorial(n) calling factorial(n - 1) is the recursive case — each call works on a strictly smaller n.
