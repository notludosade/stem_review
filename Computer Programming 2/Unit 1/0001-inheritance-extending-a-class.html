Inheritance — Extending a Class

Computer Programming 1 taught you to define a class. Now: how one class can build on another instead of starting from scratch.

Lesson 2 → Contents Glossary →

Many related classes share the same core data and behavior, with only a few differences. Inheritance lets a new class — the subclass — acquire everything a parent class (or superclass) already defines, then add to it or override specific pieces. Below, Animal defines a generic speak(); Dog inherits from it and overrides speak() with its own version.

Python 
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return f"{self.name} makes a sound."

class Dog(Animal):
    def speak(self):
        return f"{self.name} says Woof!"

buddy = Dog("Buddy")
print(buddy.speak())  # Buddy says Woof!
Java 
class Animal {
    String name;
    Animal(String name) { this.name = name; }

    String speak() {
        return name + " makes a sound.";
    }
}

class Dog extends Animal {
    Dog(String name) { super(name); }

    @Override
    String speak() {
        return name + " says Woof!";
    }
}

Dog buddy = new Dog("Buddy");
System.out.println(buddy.speak()); // Buddy says Woof!
JavaScript 
class Animal {
    constructor(name) { this.name = name; }

    speak() {
        return `${this.name} makes a sound.`;
    }
}

class Dog extends Animal {
    speak() {
        return `${this.name} says Woof!`;
    }
}

let buddy = new Dog("Buddy");
console.log(buddy.speak()); // Buddy says Woof!
C++ 
class Animal {
public:
    std::string name;
    Animal(std::string name) : name(name) {}

    virtual std::string speak() {
        return name + " makes a sound.";
    }
};

class Dog : public Animal {
public:
    Dog(std::string name) : Animal(name) {}

    std::string speak() override {
        return name + " says Woof!";
    }
};

Dog buddy("Buddy");
std::cout << buddy.speak() << std::endl; // Buddy says Woof!

Python's class Dog(Animal): and C++'s class Dog : public Animal both name the parent class right in the class header; Java and JavaScript spell it out with extends. Notice Dog never redefines a constructor in Python or JavaScript — it simply inherits Animal's automatically. Java and C++ require a bit more ceremony: their Dog constructors explicitly call the parent constructor — super(name) in Java, Animal(name) in C++'s initializer list — before doing anything else. One detail to bank for later: C++'s speak() is marked virtual in Animal. Leave that word alone for now — Lesson 3 explains exactly why it's there and what breaks without it.

Definition Inheritance is a mechanism where a subclass acquires the data and methods of a parent class (superclass), and may override or extend them. A subclass that overrides a method replaces the parent's version with its own when called on an instance of the subclass.
Why it matters here Computer Programming 1's functions let you reuse a single block of logic by calling it repeatedly. Inheritance is the same instinct applied to whole classes: instead of copying Animal's fields and methods into every new kind of animal, related classes share one definition and only write down what's actually different. A codebase with a hundred kinds of animal still has one place that defines what "having a name" means.

Check your recall

1. What does a subclass get from its parent class through inheritance?

Dog automatically has everything Animal defines, plus its own overridden speak().

2. In the Java and C++ examples, why does Dog's constructor explicitly call the parent constructor?

Python and JavaScript's Dog classes skip this because they don't define their own constructor at all — the parent's runs automatically.

3. What happens when Dog overrides Animal's speak() method?

Overriding replaces the parent's version for that specific subclass, without touching Animal itself.

4. Fill in the blank: a class that acquires the data and methods of a parent class is called a ___.

Also sometimes called a "derived class" or "child class."

5. Fill in the blank: when a subclass replaces a parent's method with its own version, that's called an ___.

Dog's speak() overrides Animal's speak() in every one of the four examples above.
