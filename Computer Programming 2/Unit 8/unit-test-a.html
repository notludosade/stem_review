Unit 8 Test — Version A

Capstone — Putting It Together. 10 points across every lesson in this unit — 5 questions worth 1 point, 5 worth 1 point split across two parts. Score 90% or higher to clear this unit.

1. Lesson 23 puts a Circle class in its own file (shapes.py, Circle.java, shapes.js) separate from main. What is a module, in the sense this lesson uses the word?

shapes.py, Circle.java, and shapes.js are each a module in exactly this sense — a file whose contents get reused elsewhere.

2. Python, Java, and JavaScript each split Circle across two files. C++ needs three. Answer both parts:

(a) Why does C++ alone need a separate header file to make this work?

(b) Fill in the blank: the file that declares what a class offers — separate from the .cpp file defining how it actually works — is called a ___ file.

(a) Because C++ compiles files independently, main.cpp needs shapes.h to know Circle's shape without ever seeing shapes.cpp. (b) shapes.h is exactly this header file.

3. In the capstone's TaskManager, get_task raises TaskNotFoundError when an id isn't found, instead of returning something like None or -1. What does this demonstrate, going back to Unit 2?

TaskNotFoundError extends Exception (Python), RuntimeException (Java), Error (JavaScript), or std::runtime_error (C++) — a custom exception built the same way Unit 2 taught, applied to a new problem.

4. Why does TaskManager store its tasks in a hash map (a dict, HashMap, Map, or unordered_map, depending on the language) keyed by id, rather than a list?

This is the hash map lookup idea reused for a concrete reason: get_task doesn't need to scan every task, just hash the id directly to its slot.

5. tasksByPriority() in every language version calls a built-in sort function rather than a hand-written sorting algorithm. What idea from earlier in the course does this reuse?

tasksByPriority calls sorted(), List.sort(), Array.sort(), or std::sort() — a built-in sort, exactly the lesson from earlier in the course about not writing sorting algorithms by hand when a good one already exists.

6. The C++ version of the capstone wraps the whole TaskManager in a unique_ptr. Answer both parts:

(a) What does this accomplish?

(b) Fill in the blank: tying a resource's cleanup to its owner's stack lifetime, the idea unique_ptr applies here, is the C++ idiom known by the acronym ___.

(a) unique_ptr gives the TaskManager one clear owner, freeing its heap memory automatically. (b) This is RAII — Resource Acquisition Is Initialization — the same idea introduced with smart pointers, applied to a real class here.

7. The lesson suggests extending TaskManager with a totalEstimatedHours method that walks a task's subtasks. Answer both parts:

(a) Which unit's central idea would that extension exercise mainly draw on?

(b) Fill in the blank: a function that solves a problem by calling itself on a smaller version of the same problem — exactly what totalEstimatedHours needs to do to walk nested subtasks — is called ___.

(a) The lesson explicitly ties this suggested extension back to Unit 4's recursion, not shown directly in the TaskManager code itself. (b) Recursion is exactly the tool needed to walk subtasks nested at any depth.

8. The lesson also suggests writing a few unit tests for TaskManager, including one that checks get_task actually raises an error for a missing id. Answer both parts:

(a) Which earlier lesson's idea is this testing exercise a direct application of?

(b) Fill in the blank: the specific custom exception this test expects get_task to raise for a missing id is named ___.

(a) This exercise is Lesson 21's unit-testing idea, aimed at TaskManager instead of factorial. (b) TaskNotFoundError is exactly the custom exception from Unit 2 that get_task raises.

9. The four language versions represent one task's data differently: Python uses a tuple, JavaScript uses a plain object literal, Java uses a small Task class, and C++ uses a struct. Answer both parts:

(a) What do Java's Task class and C++'s Task struct have in common that Python's tuple and JavaScript's object literal don't?

(b) Fill in the blank: in C++, Task is declared using the keyword ___ rather than class, though the two are nearly interchangeable for a simple data holder like this.

(a) Java's Task class and C++'s Task struct both give description and priority named, declared fields — Python's tuple and JavaScript's object literal are more generic containers. (b) struct Task { std::string description; int priority; }; is the C++ version's declaration.

10. Fill in the blank: a project deliberately designed to combine ideas from many earlier lessons at once — rather than isolating just one — is called a ___ project.

TaskManager is exactly this: one small program combining OOP, error handling, a hash map, sorting, and ownership, from across the whole course at once.
