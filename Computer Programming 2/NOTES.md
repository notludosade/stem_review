# Notes

## Course outline (self-designed, informed by CS50 / MIT 6.006 pacing)
1. Unit 1 — OOP Deep Dive (inheritance, interfaces/protocols/abstract classes, polymorphism)
2. Unit 2 — Error Handling & Exceptions (try/catch/throw, custom exceptions, defensive vs corrective handling)
3. Unit 3 — Core Data Structures (stacks, queues, linked lists, hash maps/dictionaries)
4. Unit 4 — Recursion (base/recursive case, call stack, classic examples)
5. Unit 5 — Algorithms & Complexity (Big-O, linear vs binary search, bubble → merge/quick sort)
6. Unit 6 — Memory Models (garbage collection vs manual memory, pointers/references, ownership)
7. Unit 7 — Testing & Debugging (unit tests, assertions, debugging strategy)
8. Unit 8 — Capstone: Putting It Together (designing one small multi-file program, concept-level)

Roughly 3 lessons per unit (~24 lessons total).

## Conventions
- Lives directly under `STEM+/` — flat whole-course lesson numbering, matching `Precalculus/` and `Computer Programming 1/`.
- Continues the four-language-tab pattern and shared components from Computer Programming 1 (`mountTabs`, `pre.code-block`, consistent Python/Java/JavaScript/C++ ordering) — don't re-invent, reuse.
- Unit 6 (Memory Models) is the one place C++ genuinely diverges in kind, not just syntax, from the other three — budget an extra lesson there if the four-way comparison gets too crowded to stay readable in one lesson.
- Verification workflow: same per-unit batching as prior courses.
