Linked Lists

Computer Programming 1's arrays and lists sit in one contiguous block of memory. A linked list scatters its elements — and gains something valuable by doing so.

Lesson 9 → Contents Glossary →

A linked list is a chain of nodes, where each node holds a value and a reference to the next node. The list itself is just a reference to the first node — the head. None of these languages requires a linked list to be hand-built (Java ships java.util.LinkedList, C++ ships std::list and std::forward_list) but building one from scratch, using Lesson 1's class knowledge, shows exactly what those built-in versions are doing underneath.

Python 
class Node:
    def __init__(self, value, next=None):
        self.value = value
        self.next = next

head = Node(1)
head = Node(0, head)  # insert new head
print(head.value, head.next.value)  # 0 1
Java 
class Node {
    int value;
    Node next;
    Node(int value, Node next) {
        this.value = value;
        this.next = next;
    }
}

Node head = new Node(1, null);
head = new Node(0, head); // insert new head
System.out.println(head.value + " " + head.next.value); // 0 1
JavaScript 
class Node {
    constructor(value, next = null) {
        this.value = value;
        this.next = next;
    }
}

let head = new Node(1);
head = new Node(0, head); // insert new head
console.log(head.value, head.next.value); // 0 1
C++ 
struct Node {
    int value;
    Node* next;
    Node(int value, Node* next) : value(value), next(next) {}
};

Node* head = new Node(1, nullptr);
head = new Node(0, head); // insert new head
std::cout << head->value << " " << head->next->value << std::endl; // 0 1

All four build the exact same shape: the new node's next points at the old head, then the variable named head is reassigned to the new node — an insertion at the front, done in one step, regardless of how many nodes already exist. Compare that to inserting at the front of Unit 6's array-backed list, where every existing element has to shift over by one to make room. The C++ version introduces -> formally: head->value is shorthand for "follow the pointer, then access the member," equivalent to (*head).value. C++ also uses struct here instead of class — functionally almost identical, except a struct's members are public by default, which is convenient for a bare data holder like Node.

Definition A node holds a value and a reference to the next node. A linked list is a chain of nodes, accessed starting from its head — the first node.
Why it matters here Lesson 16 of Computer Programming 1 introduced dynamic lists that can grow — but growing at the front still means shifting every element over. A linked list makes inserting or removing at any known position genuinely cheap, at a real cost: there's no way to jump straight to "the fifth element" the way an array's index does — you have to walk the chain from the head, one next at a time. Unit 5's Big-O lesson gives this trade-off a precise name.

1. What does each node in a linked list hold?

Each node only knows about the one node that comes after it.

2. Why is inserting at the front of a linked list cheap regardless of its length?

Contrast this with an array-backed list, where inserting at the front shifts every existing element.

3. What is the real trade-off a linked list makes in exchange for cheap insertion anywhere?

An array's numbers[5] is instant; a linked list has to follow next five times to reach the same position.
