Floyd-Warshall

Running Bellman-Ford from every vertex would solve all-pairs shortest paths in Θ(V²E). Floyd-Warshall does it in Θ(V³) with a three-line dynamic program — by asking a single, elegant question about intermediate vertices.

← Lesson 13 Lesson 15 → Contents Glossary →

Bellman-Ford (Lesson 13) solves single-source shortest paths. If you need shortest paths between every pair of vertices, one option is running Bellman-Ford once per source, for Θ(V) · Θ(VE) = Θ(V²E) total. Floyd-Warshall instead directly computes all-pairs shortest paths with a dynamic program indexed by which intermediate vertices are allowed — a different DP shape than any CP2+ covered, and one that generalizes cleanly regardless of edge sign, as long as no negative cycle exists.

The key idea — restricting which vertices a path may pass through

Definition Let distk(i, j) be the length of the shortest path from i to j that uses only vertices {1, ..., k} as intermediate stops (i and j themselves are always allowed as endpoints, regardless of k). dist0(i, j) is just the direct edge weight (i, j), or infinity if no edge exists (0 if i = j).
The recurrence distk(i, j) = min( distk−1(i, j), distk−1(i, k) + distk−1(k, j) ). In words: the best path using intermediates up to k either doesn't use vertex k at all (first term, unchanged from k−1), or it does use k exactly once as a stopover (second term — go from i to k, then k to j, each using only intermediates up to k−1, since a shortest path never needs to visit vertex k twice). This is the same "combine two subproblems, don't repeat" logic Lesson 6 used for merge sort — but here the subproblem parameter is "which vertices are allowed," not "which array half."

The algorithm

Algorithm 
function floydWarshall(graph):
    dist = V x V matrix, dist[i][j] = weight(i, j) if edge exists, 0 if i == j, else infinity
    for k in 1..V:
        for i in 1..V:
            for j in 1..V:
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    // after the loop, dist[i][j] = true shortest path from i to j for all pairs
    return dist
Why the loop order (k outermost) is not arbitrary The recurrence for distk depends only on distk−1 values — so by the time the algorithm processes a given k in the outer loop, every dist[i][j] entry in the matrix already holds distk−1(i,j), exactly what the recurrence needs. Because the update dist[i][k] + dist[k][j] < dist[i][j] only ever reads row k and column k (never overwrites them during the same k-iteration in a way that corrupts itself — dist[k][k] never improves below 0 absent a negative cycle), the matrix can be updated in place without a separate previous-iteration copy, which is what makes the algorithm's actual code even simpler than the recurrence suggests.
Runtime and when to prefer it over repeated Bellman-Ford Three nested loops over V vertices: Θ(V³), beating Θ(V²E) whenever E is asymptotically larger than V (i.e., in dense graphs, where E approaches V²). For sparse graphs, running Bellman-Ford from every source can actually be faster — the right choice depends on graph density, the same kind of trade-off Lesson 10 flagged between Kruskal's and Prim's.
Negative cycle detection, again Exactly as with Bellman-Ford, if dist[i][i] becomes negative for any vertex i after the algorithm runs, that means there's a negative-weight cycle reachable from and back to i — the diagonal of the final matrix is the negative-cycle check for Floyd-Warshall, just as the extra relaxation pass was for Bellman-Ford.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does distk(i, j) represent in Floyd-Warshall's dynamic program?

The subproblem parameter is which intermediate vertices are allowed, not a source vertex or an edge count.

2. Why must the recurrence's outer loop iterate over k (the allowed-intermediate-vertex limit) before i and j?

Each dist_k layer depends entirely on the previous layer's values, so k must be the outermost loop to guarantee correctness.

3. When is Floyd-Warshall preferable to running Bellman-Ford once per source vertex?

The comparison is purely about graph density: Θ(V³) versus Θ(V²E), so density determines which is asymptotically better.

4. Fill in the blank: Floyd-Warshall's dynamic program is indexed by which vertices are allowed as ___ stops along a path, rather than by source vertex.

This is the defining idea that makes Floyd-Warshall's DP shape different from any single-source shortest-path algorithm.

5. Fill in the blank: after Floyd-Warshall finishes, a negative value on the ___ of the distance matrix (dist[i][i] < 0) indicates a negative-weight cycle reachable from vertex i.

dist[i][i] should always be exactly 0 in a graph with no negative cycle, so any negative value there is the tell-tale sign of one.
