1. Consider the graph with vertices S, M, N and edges S→M (weight 3), S→N (weight 9), M→N (weight −5). What is the correct shortest-path distance from S to N?

The path S→M→N costs 3 + (−5) = −2, cheaper than the direct S→N edge (9) — the same kind of negative-edge shortcut that makes Dijkstra's algorithm unreliable and requires Bellman-Ford instead.

2. A graph has 8 vertices and no negative-weight cycle. Answer both parts about running Bellman-Ford on it:

(a) How many rounds of edge relaxation are guaranteed to make every shortest-path distance correct?

(b) Fill in the blank: if an additional relaxation pass after those rounds still updates some distance, the graph must contain a reachable ___ that makes shortest path undefined.

(a) With no negative cycle, every shortest path uses at most |V|−1 = 7 edges, and each full relaxation round guarantees one more edge's worth of paths are correct. (b) Any change beyond that many rounds can only come from repeatedly looping a negative cycle, since every simple-path distance is already settled.

3. In a Floyd-Warshall run, suppose dist₂(1, 4) = 15 using only intermediates from {1,2}. Allowing vertex 3 as an intermediate opens a new path 1→3→4 with cost dist₂(1,3) + dist₂(3,4) = 5 + 9 = 14. Answer both parts:

(a) What does dist₃(1, 4) equal once vertex 3 is considered?

(b) Fill in the blank: dist₀(i, j) — the base case before any vertex is allowed as an intermediate — is defined using ___ intermediate vertices, just the direct edge weight (or infinity if none exists).

(a) dist_k(i,j) = min(dist_(k−1)(i,j), dist_(k−1)(i,k)+dist_(k−1)(k,j)) = min(15, 5+9) = min(15,14) = 14. (b) At k=0, no intermediate vertex is allowed yet, so only direct edges count.

4. Fill in the blank: Floyd-Warshall's Θ(V³) runtime beats repeated Bellman-Ford's Θ(V²E) specifically when the graph is ___, meaning E is large relative to V.

Floyd-Warshall's fixed Θ(V³) cost wins out once the edge count E is large enough — for sparse graphs with few edges, running Bellman-Ford once per source can actually be the faster choice instead.

5. A directed graph has edges W→X, X→Y, Y→W, and Y→Z. Which set of vertices forms a strongly connected component?

W, X, and Y can each reach each other around the cycle W→X→Y→W. Z is reachable from Y but has no edge back to Y, W, or X, so it can't be part of their component.

6. Answer both parts about the two classical SCC algorithms:

(a) In Tarjan's algorithm, what does low[v] represent for a vertex v?

(b) Fill in the blank: Kosaraju's algorithm requires building the ___ graph — every edge flipped from the original — before running its second DFS pass.

(a) That smallest-reachable-discovery-time value is exactly what lets Tarjan's algorithm detect, in a single pass, the moment a vertex's subtree can't reach back above it. (b) Kosaraju's second pass must run on this reversed graph, using the finish-time order from the first pass, to keep each run confined to one component.

7. In the flow network S→P (capacity 6), S→Q (capacity 10), P→Q (capacity 2), P→T (capacity 9), Q→T (capacity 7), what is the bottleneck capacity of the augmenting path S→P→T?

The bottleneck is the minimum residual capacity along the path: min(6, 9) = 6, limited by the S→P edge even though P→T could carry more.

8. Using the network from question 7, suppose 6 units of flow are sent along S→P→T. Answer both parts:

(a) What is the residual capacity of the backward edge T→P in the resulting residual graph?

(b) Fill in the blank: the residual capacity of a forward edge (u, v) equals its original capacity minus the current ___ on that edge.

(a) A backward edge's residual capacity always equals the current flow on the corresponding forward edge — here f(P,T) = 6. (b) That's the general formula for any forward residual capacity: c(u,v) − f(u,v).

9. For the network S→A (capacity 6), S→B (capacity 6), A→B (capacity 2), A→T (capacity 6), B→T (capacity 6), what is the capacity of the s-t cut S = {s, A}, T = {B, t}?

Edges crossing from S to T are S→B (6), A→B (2), and A→T (6), summing to 14 — larger than the true minimum cut of 12 (from S={s}, using only S→A and S→B), consistent with flow never exceeding any cut's capacity.

10. Answer both parts about the max-flow min-cut theorem:

(a) Why must the total flow value from s to t never exceed the capacity of any s-t cut (S, T)?

(b) Fill in the blank: the theorem's proof defines S as exactly the set of vertices ___ from s in the final residual graph, once no augmenting path remains.

(a) Any flow from s to t is forced to physically cross from the S side to the T side somewhere, so it can never exceed the total capacity available to cross there. (b) That reachable set is precisely what the proof uses to construct the specific cut whose capacity equals the maximum flow.
