Max-Flow Min-Cut

The maximum flow through a network exactly equals the minimum-capacity cut separating source from sink — a theorem that both proves Ford-Fulkerson correct and gives a second, completely different lens for the same number.

← Lesson 16 Lesson 18 → Contents Glossary →

Lesson 16 left one question unanswered: how do we know Ford-Fulkerson's algorithm — stop when no augmenting path exists — actually reaches the maximum possible flow, rather than just some locally-stuck value? The answer is one of the cleanest duality theorems in algorithms: max-flow equals min-cut, exactly. This closes Unit 4 by tying graph algorithms back to the cut concept Unit 3 introduced for MSTs (Lesson 11) — the same word, "cut," now doing a related but distinct job.

Cuts in a flow network

Definition — s-t cut An s-t cut is a partition of the vertices into sets S (containing source s) and T (containing sink t, T = V−S). Its capacity is the sum of capacities of all edges going from S to T (edges from T to S don't count toward the cut's capacity). Every unit of flow from s to t must cross from S to T somewhere, so the total flow value can never exceed any cut's capacity — this direction (flow ≤ any cut) is immediate; the theorem's real content is that equality is achievable.
Theorem — max-flow min-cut The maximum flow value from s to t equals the minimum capacity over all s-t cuts.
Proof — via Ford-Fulkerson's stopping condition Run Ford-Fulkerson until no augmenting path exists in the residual graph Gf. Let S be the set of vertices reachable from s in Gf at that point, and T = V−S (t ∉ S, since if t were reachable, an augmenting path would still exist, contradicting termination). Consider the cut (S, T): for every original edge (u,v) with u∈S, v∈T, it must be saturated (f(u,v) = c(u,v)) — otherwise its residual forward edge would still have capacity, making v reachable from S, contradicting v∈T. Similarly, for every edge (v,u) with v∈T, u∈S, its flow must be exactly 0 — otherwise a residual backward edge (u,v) would exist, again making v reachable from S. So the net flow crossing this specific cut equals exactly its capacity: full capacity forward, zero flow backward. Since flow value always equals net flow across any cut (a consequence of conservation at every vertex other than s, t), the current flow value equals this cut's capacity exactly. Combined with flow ≤ every cut's capacity (shown above), this flow is simultaneously a valid flow and equal to some cut's capacity — so it must be maximum, and that cut must be minimum.
Reading a min-cut off Lesson 16's worked example In Lesson 16's network (S→A cap 10, S→B cap 10, A→B cap 1, A→T cap 10, B→T cap 10), the max flow found was 20. The cut S = {s}, T = {A, B, t} has capacity c(S→A) + c(S→B) = 10+10 = 20 — matching the max flow exactly, confirming it's a minimum cut (and, since flow can never exceed any cut, no cut can have capacity below 20 either).
Why this theorem matters beyond confirming Ford-Fulkerson's correctness Max-flow min-cut turns a huge range of "what's the bottleneck" questions — network reliability, bipartite matching capacity, project selection with dependencies — into flow problems, because whatever real-world quantity a min-cut represents (fewest links whose failure disconnects a network, minimum resources to block all paths) can now be computed by running a flow algorithm instead of reasoning about cuts directly. This duality — one problem, two completely different-looking optimal-value characterizations — is a recurring theme this course will meet again in Unit 8's discussion of LP duality's cousin, the approximation-algorithm bounds of Lesson 33.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does the capacity of an s-t cut (S, T) count?

Only forward-crossing edges (S to T) count toward a cut's capacity, since those are the edges any s-to-t flow must actually pass through.

2. In the max-flow min-cut proof, why must every original edge from S to T be saturated once Ford-Fulkerson terminates?

S is defined as exactly the vertices reachable from s in the final residual graph, so any unsaturated forward edge would extend that reachable set, which is a contradiction.

3. What is the key insight max-flow min-cut provides beyond just proving Ford-Fulkerson correct?

The duality between max flow and min cut is what makes flow algorithms broadly applicable to bottleneck-style problems beyond literal network flow.

4. Fill in the blank: at Ford-Fulkerson's termination, every original edge crossing the found cut from S to T must be ___ , meaning its flow equals its full capacity.

A saturated edge has no leftover residual capacity, which is exactly the condition consistent with the far endpoint being unreachable.

5. Fill in the blank: in the max-flow min-cut proof, set S is defined as exactly the vertices ___ from s in the final residual graph, once no augmenting path remains.

Reachability in the final residual graph is exactly what defines the specific cut used to complete the proof.
