1. Which pair of constants (c, n₀) could be used to prove 7n² + 2n = O(n²)?

Since 2n ≤ 2n² for n ≥ 1, 7n² + 2n ≤ 7n² + 2n² = 9n² — so c=9, n₀=1 is a valid working pair. The definition only asks for some c and n₀ that work, not the tightest possible choice.

2. Let f(n) = 10n³ + 4n². Which is the strongest true statement among these?

For n ≥ 1, 4n² ≤ 4n³, so 10n³ + 4n² ≤ 14n³, and trivially 10n³ + 4n² ≥ 10n³ — giving Θ(n³) with c₁=10, c₂=14, n₀=1. It is not O(n²) (the cubic term dominates), not Ω(n⁴) (n³ grows slower), and not o(n³) since the ratio f(n)/n³ tends to 10, not 0.

3. For the recursion tree of T(n) = 5T(n/5) + n, what is the total work at each level?

Node count multiplies by 5 each level while per-node work divides by 5, so the product stays fixed at n every level — the same constant-per-level pattern the lesson demonstrated for 2T(n/2) + n, just with a different branching factor.

4. Which Master Theorem case applies to T(n) = 8T(n/2) + n², and what does T(n) solve to?

a=8, b=2, so n^(log_b a) = n^(log₂8) = n³. f(n)=n² is polynomially smaller than n³ (by ε=1), which is Case 1, giving T(n) = Θ(n³) — not Θ(n²), which is what the leaf-level work equals, not the total.

5. Fill in the blank: log n = o(n) is true because lim(n→∞) (log n)/n = ___.

log n grows strictly slower than any positive power of n, so the ratio (log n)/n vanishes in the limit — confirming the little-o relationship, since little-o requires the ratio to hit exactly 0.

6. Consider T(n) = 3T(n/9) + n. Answer both parts:

(a) What is n^(log_b a) for this recurrence, and which Master Theorem case applies?

(b) Fill in the blank: since Case 3 applies, T(n) = Θ(___), matching the non-recursive work term exactly.

(a) log₉3 = 1/2 since 9^0.5 = 3, so n^(log_b a) = n^0.5; f(n)=n is polynomially larger (by ε=0.5), and the regularity check a·f(n/b) = 3·(n/9) = n/3 ≤ (1/3)·n confirms Case 3. (b) Case 3 gives T(n) = Θ(f(n)) = Θ(n) — the root's own work dominates the recursion entirely.

7. Consider T(n) = T(n/5) + T(4n/5) + n. Answer both parts:

(a) Why can't this recurrence be solved directly with the Master Theorem?

(b) Fill in the blank: since every level's total work is bounded by n, and the longest root-to-leaf path (the repeated 4n/5 branch) has Θ(log n) levels, the tree method gives T(n) = O(n log ___).

(a) Unevenly-sized recursive calls fall outside the Master Theorem's required form, exactly like the T(n/3) + T(2n/3) + n example from the lesson. (b) Since n/5 + 4n/5 = n, every level does at most n total work; the deepest path (always the 4n/5 branch) takes Θ(log n) levels since 5/4 < 5, giving an overall bound of O(n log n).

8. A dynamic array starts at capacity 1 and quadruples its capacity on each resize, copying all existing elements every time. Answer both parts:

(a) What is the amortized cost per push?

(b) Fill in the blank: whether capacity doubles, triples, or quadruples on resize, the total resize cost stays O(n) because each is a case of ___ growth rather than a fixed additive increment.

(a) Regardless of the multiplier, resizes become exponentially rarer as the array grows, so the total resize cost is a geometric series bounded by O(n) — keeping the amortized cost per push at O(1). (b) Any constant multiplicative (geometric) growth factor achieves this; a fixed additive increment instead would force Θ(n) resizes and Θ(n²) total cost.

9. Using Φ = 2·(size) − capacity for the doubling dynamic array, answer both parts:

(a) Fill in the blank: immediately after a resize, size = capacity/2, so Φ = 2·(capacity/2) − capacity = ___.

(b) For a non-resizing push (actual cost 1), Φ increases by 2 because size grows by 1. What is the amortized cost ĉᵢ for this push?

(a) Right after a resize, potential resets to its minimum of 0. (b) ĉᵢ = cᵢ + ΔΦ = 1 + 2 = 3, matching the flat amortized charge the potential method derives for every push, resizing or not.

10. In the accounting method, every push is charged a flat amortized cost of 3. Answer both parts:

(a) Why must the sum of charged (amortized) costs always be at least the sum of actual costs?

(b) Fill in the blank: a resize at size m needs to draw down banked credit to cover its actual cost of m + ___ (the copy plus the new insertion).

(a) The invariant "credit never goes negative" is exactly what forces the charged total to stay at or above the actual total at every point in the sequence, not just at the end. (b) A resizing push actually costs m+1 (copying m existing elements, then inserting the new one); the credit banked from recent non-resizing pushes covers the gap between the flat charge of 3 and this true cost.
