1. In the formal definition f(n) = O(g(n)), why must the bound c·g(n) only be required to hold for n ≥ n₀, rather than for all n?

The threshold n₀ is exactly what lets asymptotic notation ignore a finite prefix of small-input exceptions, since the definition only cares about the function's behavior from some point onward.

2. Let f(n) = 5n² + 2n. Which is the strongest true statement among these?

Since n ≤ n² for n ≥ 1, 5n² + 2n ≤ 7n², and trivially 5n² + 2n ≥ 5n² — so c₁ = 5, c₂ = 7, n₀ = 1 pins down Θ(n²) exactly. It grows faster than any O(n) or O(n log n) bound and slower than any Ω(n³) bound.

3. For the recursion tree of T(n) = 3T(n/3) + n, what happens to the total work at each level as you go deeper?

Each level has 3 times as many nodes as the last, but each node's subproblem (and its non-recursive work) is 1/3 the size — 3 × (n/3) = n at every level, the same constant-per-level pattern the lesson showed for 2T(n/2) + n.

4. Which Master Theorem case applies to T(n) = 9T(n/3) + n, and what does T(n) solve to?

a=9, b=3, so n^(log_b a) = n^(log₃9) = n². f(n)=n is polynomially smaller than n² (by ε=1), which is exactly Case 1 — the leaves dominate, giving T(n) = Θ(n²).

5. Fill in the blank: n log n = o(n²) is true because lim(n→∞) (n log n)/n² = ___.

(n log n)/n² simplifies to (log n)/n, which vanishes as n grows — confirming the little-o relationship, since little-o requires the ratio to hit exactly 0 in the limit.

6. Consider T(n) = 4T(n/4) + n. Answer both parts:

(a) What is n^(log_b a) for this recurrence, and which Master Theorem case applies?

(b) Fill in the blank: T(n) = Θ(n log ___).

(a) a=4, b=4, so n^(log₄4) = n¹ = n; f(n)=n matches it exactly, which is Case 2. (b) Case 2 gives T(n) = Θ(n^(log_b a) · log n) = Θ(n log n).

7. Consider T(n) = T(n/4) + T(3n/4) + n. Answer both parts:

(a) Why can't this recurrence be solved directly with the Master Theorem?

(b) Fill in the blank: since every level's total work is bounded by n, and the longest root-to-leaf path (the repeated 3n/4 branch) has Θ(log n) levels, the tree method gives T(n) = O(n log ___).

(a) Uneven subproblem sizes fall outside the Master Theorem's required shape entirely, exactly like the T(n/3) + T(2n/3) + n example from the lesson. (b) Since n/4 + 3n/4 = n, every level does at most n total work; the deepest path (always taking the 3n/4 branch) takes Θ(log n) levels since 4/3 < 4, giving an overall bound of O(n log n).

8. A dynamic array starts at capacity 1 and triples its capacity (instead of doubling) on each resize, copying all existing elements every time it resizes. Answer both parts:

(a) What is the amortized cost per push?

(b) Fill in the blank: like doubling, tripling still produces total resize cost O(n) because both are examples of ___ growth in capacity, rather than a fixed additive increment.

(a) Resizes happen at sizes 1, 3, 9, ..., roughly log₃n times, and the total resize cost is a geometric series bounded by O(n) regardless of whether the multiplier is 2 or 3 — so the amortized cost per push stays O(1). (b) Any constant multiplicative growth factor keeps resizes exponentially rare; a fixed additive increment instead would force Θ(n) resizes and Θ(n²) total cost.

9. Using the potential function Φ = 2·(size) − capacity for the doubling dynamic array, answer both parts:

(a) What is Φ immediately after a resize, when size = capacity/2?

(b) Fill in the blank: for a resizing push at size m (just before the resize), Φ(before) = 2m − m = ___.

(a) Right after a resize, size = capacity/2, so Φ = 2(capacity/2) − capacity = 0 — potential resets to its minimum. (b) Just before the next resize, size = capacity = m, so Φ = 2m − m = m, exactly enough banked potential to pay for copying m elements.

10. In the accounting method, every push on the dynamic array is charged a flat amortized cost of 3, regardless of whether it resizes. Answer both parts:

(a) What does the "credit" banked on an element represent?

(b) Fill in the blank: because every push is charged the same flat amortized cost, the invariant that credit never goes ___ is what guarantees the bound holds for every operation.

(a) Charging more than the actual cost on non-resizing pushes banks the surplus as credit, drawn down exactly when a resize needs to pay for copying beyond its own charged amount. (b) The whole method's correctness rests on credit never going negative — if it can't, every operation's charged cost already covers its true cost.
