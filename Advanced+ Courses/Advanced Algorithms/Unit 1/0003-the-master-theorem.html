The Master Theorem

The last lesson kept solving different recurrences to the same three patterns by hand. The Master Theorem is the formula that names those three patterns and tells you which one applies without drawing a single tree.

← Lesson 2 Lesson 4 → Contents Glossary →

Every recurrence in the last lesson had the form T(n) = a·T(n/b) + f(n), and every tree resolved into one of three outcomes: work dominated by the leaves, work spread evenly across all Θ(log n) levels, or work dominated by the root. The Master Theorem is exactly that trichotomy, stated as a comparison between f(n) and n^(log_b a) — the size of the last level of the tree, if it were doing no work-per-node shrinkage at all.

The statement

Theorem — Master Theorem For T(n) = a·T(n/b) + f(n) with a ≥ 1, b > 1, let n^(log_b a) be the "watershed" function. Then:
· Case 1: if f(n) = O(n^(log_b a − ε)) for some ε > 0, then T(n) = Θ(n^(log_b a)). (Leaves dominate.)
· Case 2: if f(n) = Θ(n^(log_b a)), then T(n) = Θ(n^(log_b a) · log n). (Every level contributes equally.)
· Case 3: if f(n) = Ω(n^(log_b a + ε)) for some ε > 0, and the regularity condition a·f(n/b) ≤ c·f(n) holds for some c < 1 and large n, then T(n) = Θ(f(n)). (Root dominates.)
Why n^(log_b a) is the number to compare against n^(log_b a) is exactly the leaf count of the recursion tree — a full tree of branching factor a and depth log_b n has a^(log_b n) = n^(log_b a) leaves (a change-of-base identity). Comparing f(n) against this quantity is exactly asking: does the non-recursive work at each level grow slower, equal to, or faster than the rate at which leaves are accumulating? That's precisely the three-way split the recursion tree method uncovered by hand.
Applying it — merge sort's recurrence T(n) = 2T(n/2) + n: a=2, b=2, so n^(log_b a) = n^(log₂2) = n¹ = n. Compare f(n)=n against n: they're equal, i.e. f(n) = Θ(n^(log_b a)). That's Case 2, giving T(n) = Θ(n log n) — matching the tree-method answer from the previous lesson exactly, but now derived in one line.
Applying it — binary search's recurrence T(n) = T(n/2) + O(1): a=1, b=2, so n^(log_b a) = n⁰ = 1. Compare f(n)=O(1) against 1: they match, so Case 2 applies, giving T(n) = Θ(1 · log n) = Θ(log n) — the familiar bound, now with a formal derivation rather than an appeal to "halving each time."
Worked example — Case 1 T(n) = 4T(n/2) + n: a=4, b=2, n^(log_b a) = n^(log₂4) = n². Compare f(n)=n against n²: n = O(n^(2−ε)) for ε=1, so Case 1 applies. T(n) = Θ(n²) — the leaves alone account for the total, and the linear work done at internal nodes is asymptotically irrelevant.
Worked example — Case 3 T(n) = 2T(n/2) + n²: a=2, b=2, n^(log_b a) = n. Compare f(n)=n² against n: n² = Ω(n^(1+ε)) for ε=1, and the regularity condition holds since 2·(n/2)² = n²/2 ≤ (1/2)·n². Case 3 applies: T(n) = Θ(n²) — the root's own work already swamps everything the recursion contributes.
Why the theorem doesn't cover every recurrence The three cases have a genuine gap: f(n) must be polynomially larger or smaller than n^(log_b a), not just asymptotically larger or smaller by any margin. T(n) = 2T(n/2) + n log n falls exactly between Case 2 and Case 3 — f(n) = n log n is asymptotically larger than n^(log_b a) = n but not polynomially larger (n log n / n = log n → ∞, but no fixed ε makes n log n = Ω(n^(1+ε))). The Master Theorem is silent here; only the recursion tree method from the previous lesson (or the more general Akra-Bazzi method, beyond this course's scope) resolves it. That's the gap the previous lesson's fallback exists to fill.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does n^(log_b a) represent in the recursion tree for T(n) = a·T(n/b) + f(n)?

A tree with branching factor a and depth log_b n has a^(log_b n) leaves, which equals n^(log_b a) by a change-of-base identity.

2. T(n) = 4T(n/2) + n falls into which Master Theorem case, and why?

n^(log_b a) = n^(log₂4) = n², and n is polynomially smaller than n² (by ε=1), placing it squarely in Case 1 — the leaves dominate.

3. Why does T(n) = 2T(n/2) + n log n fall outside all three Master Theorem cases?

The gap between Case 2 and Case 3 requires a genuine polynomial separation (n^(log_b a + ε)); a merely logarithmic factor like log n falls through that gap entirely.

4. Fill in the blank: Case 3 of the Master Theorem additionally requires the ___ condition, ensuring the recursive work doesn't grow to rival the root's own work.

Without a·f(n/b) ≤ c·f(n) for some c<1, the recursive contributions could in principle still add up to something comparable to f(n), undermining the "root dominates" conclusion.

5. Fill in the blank: Cases 1 and 3 both require f(n) to differ from n^(log_b a) ___ — by a fixed power ε, not just by any growing factor.

The theorem's cases only cover polynomial separations; a merely asymptotic-but-not-polynomial gap (like a log factor) is exactly what falls through the cracks between the cases.
