1. Which Master Theorem case applies to T(n) = 16T(n/4) + n², and what does T(n) solve to?

a=16, b=4, so n^(log₄16) = n² (since 4²=16); f(n)=n² matches it exactly, which is Case 2, giving T(n) = Θ(n² log n).

2. Fill in the blank: for T(n) = 2T(n/4) + n^1.5, n^(log_b a) = n^0.5, and since f(n) = n^1.5 is polynomially larger and the regularity condition holds, Case 3 applies, giving T(n) = Θ(n^___).

Case 3 gives T(n) = Θ(f(n)) = Θ(n^1.5), matching f(n)'s own exponent.

3. A divide-and-conquer algorithm checks whether an array is sorted by recursively checking each half is sorted, then directly comparing the last element of the left half to the first element of the right half. Why is this direct comparison necessary in addition to the two recursive calls?

Strong induction only discharges "each half is sorted"; the cross-boundary comparison is the non-recursive combine step that needs its own direct proof.

4. Fill in the blank: a divide-and-conquer algorithm counts array elements exceeding threshold T by splitting into halves, recursively counting each half, and adding the counts. This is correct because each element belongs to exactly one ___, and whether it exceeds T doesn't depend on which one it's in.

Each element sits in exactly one half, and the threshold comparison is independent of the split, so summing both halves' counts covers every element exactly once.

5. The cut property is stated for a cut whose minimum-weight crossing edge is unique. If two edges crossing a cut are tied for minimum weight, which statement is correct?

Dropping strict uniqueness still lets the exchange-argument proof go through for whichever tied edge is chosen first.

6. Fill in the blank: in an exchange-argument proof for Prim's algorithm, swapping in the minimum-weight edge crossing the current cut never increases an optimal tree's weight, because any edge already in that tree crossing the same cut must weigh at least as much as the ___-weight edge Prim's chooses.

Minimality across the cut is exactly what guarantees the swap never worsens the solution.

7. How does Bellman-Ford detect a negative-weight cycle reachable from the source?

After V−1 iterations, all shortest paths (if no negative cycle exists) are finalized; any edge still relaxable on iteration V proves a negative cycle exists.

8. By the Max-Flow Min-Cut theorem, the maximum flow in a network equals:

Max-flow min-cut proves the maximum achievable flow exactly equals the smallest-capacity cut separating source from sink — flow can never exceed any cut's capacity, and Ford-Fulkerson terminates exactly when it reaches that bound.

9. In bitmask DP for a problem like the Traveling Salesman Problem, what does each bit of the integer state represent?

Encoding "which subset of items has been visited" as bits of an integer is exactly what lets bitmask DP compress an exponential state space into an array index.

10. Fill in the blank: recasting the Fibonacci recurrence as a matrix power and using repeated squaring computes the nth Fibonacci number in O(___) time, instead of the ordinary DP's O(n).

Repeated squaring computes a matrix power in O(log n) multiplications, generalizing to any linear recurrence expressible as a matrix.

11. Both segment trees and Fenwick trees answer range queries with point updates in O(log n). What key difference distinguishes them?

Fenwick trees trade generality for simplicity — built around a bit trick that only works for invertible operations like sum, whereas segment trees handle min/max/gcd and other non-invertible aggregates too.

12. Disjoint Set Union with both path compression and union by rank achieves what amortized time per operation?

The potential-method analysis (Unit 1's technique, paid off in Unit 6) shows path compression plus union by rank together yield O(α(n)) amortized time — the inverse Ackermann function grows so slowly it's effectively constant.

13. Which algorithm guarantees Θ(n+m) time on every input, without relying on hashing or on preprocessing a data structure larger than the pattern itself?

Rabin-Karp's guarantee is average-case only (worst case degrades under collisions), and suffix arrays pay an upfront preprocessing cost — KMP alone guarantees Θ(n+m) unconditionally via its failure function.

14. Fill in the blank: KMP searches for pattern P = "aba" (lps = [0, 0, 1]) in text T = "ababab". It reports ___ total matches (at positions 0 and 2, overlapping).

Matches occur at position 0 and position 2; after each match, KMP continues via j = lps[j−1] rather than restarting from j = 0, finding the second overlapping match without rescanning any text character.

15. If a polynomial-time algorithm were discovered for any single NP-complete problem, what would follow?

Because any two NP-complete problems reduce to each other, a fast algorithm for one chains into a fast algorithm for all of NP.

16. Fill in the blank: Subset Sum, proven NP-complete via reduction from 3-SAT, asks whether some subset of a set of integers sums to exactly a ___ value.

Subset Sum's decision question is whether some subset hits an exact target sum, proven NP-complete via a digit-encoding reduction from 3-SAT.
