Matrix Exponentiation

Computing the nth Fibonacci number the ordinary DP way takes Θ(n) steps. Recasting the recurrence as a matrix power and using repeated squaring computes it in Θ(log n) — a technique that generalizes to any linear recurrence.

← Lesson 20 Lesson 22 → Contents Glossary →

The ordinary Fibonacci DP (F(n) = F(n−1) + F(n−2)) computes F(n) in Θ(n) time and O(1) space if only the last two values are kept. That's already efficient — but for very large n (say, n up to 10¹⁸, as competitive-programming problems sometimes demand), even Θ(n) is too slow. Matrix exponentiation recasts the linear recurrence as repeated matrix multiplication, then applies fast exponentiation (the same repeated-squaring idea behind computing xⁿ in Θ(log n) multiplications instead of n) to compute F(n) in Θ(log n) matrix multiplications.

Recasting the recurrence as a matrix

The key transformation Define the vector [F(n), F(n−1)]ᵀ. Observe: [F(n+1), F(n)]ᵀ = [[1,1],[1,0]] · [F(n), F(n−1)]ᵀ (multiplying out: F(n+1) = 1·F(n) + 1·F(n−1), and F(n) = 1·F(n) + 0·F(n−1) — both correct by definition). Call M = [[1,1],[1,0]]. Applying M repeatedly: [F(n+1), F(n)]ᵀ = Mⁿ · [F(1), F(0)]ᵀ. So computing F(n) reduces entirely to computing Mⁿ, a single 2×2 matrix raised to the nth power.
Why fast exponentiation applies directly to matrices Fast exponentiation for computing xⁿ relies only on associativity of multiplication: x⁸ = ((x²)²)², computed with 3 multiplications instead of 7, by repeatedly squaring and combining based on n's binary representation. Matrix multiplication is associative (Lesson 20 depended on exactly this fact), so the identical squaring trick applies unchanged: Mⁿ can be computed with O(log n) matrix multiplications, each costing O(1) for a fixed 2×2 size (or O(k³) for a general k×k matrix, still independent of n).
Algorithm 
function matrixPower(M, n):
    if n == 0: return identity matrix
    if n is odd: return M * matrixPower(M, n - 1)
    half = matrixPower(M, n / 2)
    return half * half

function fibonacci(n):
    M = [[1,1],[1,0]]
    result = matrixPower(M, n)
    return result[0][1]        // extracts F(n) from M^n
Runtime Θ(log n) matrix multiplications, each O(1) for the fixed 2×2 Fibonacci matrix — total Θ(log n), an exponential improvement over the already-linear Θ(n) DP, meaningful once n is astronomically large (n=10¹⁸ takes roughly 60 matrix multiplications instead of 10¹⁸ additions).
Why this generalizes beyond Fibonacci Any linear recurrence of fixed order — a(n) = c₁a(n−1) + c₂a(n−2) + ... + cₖa(n−k) for fixed constants cᵢ — can be encoded the same way: a k×k companion matrix whose repeated multiplication advances the recurrence by one step each time, then fast-exponentiated exactly as here. This is the same "find the right algebraic recasting, then apply a general-purpose fast technique" move Strassen's algorithm (Lesson 8) made for matrix multiplication itself — recognizing that a problem is secretly an instance of "compute Mⁿ" is often the harder half of applying this technique.

1. What matrix M satisfies [F(n+1), F(n)]ᵀ = M · [F(n), F(n−1)]ᵀ for the Fibonacci recurrence?

Multiplying [[1,1],[1,0]] by [F(n),F(n-1)]^T reproduces exactly the Fibonacci recurrence in the top entry and an identity carry-over in the bottom.

2. Why does fast exponentiation (repeated squaring) apply just as well to matrices as to ordinary numbers?

Associativity — not commutativity, which matrices generally lack — is the only property repeated squaring actually needs.

3. What is the runtime of computing F(n) via matrix exponentiation, and why is it an improvement over the ordinary Fibonacci DP?

Repeated squaring's logarithmic step count is what makes this an exponential improvement over the already-linear ordinary DP, mattering for extremely large n.

4. Fill in the blank: repeated squaring works for matrices because matrix multiplication satisfies ___ , the only property the technique actually depends on.

Associativity is what allows grouping repeated multiplications into halves for the squaring trick, regardless of whether the operands are numbers or matrices.

5. Fill in the blank: any fixed-order linear recurrence can be advanced one step at a time by multiplying by a fixed ___ matrix, generalizing the Fibonacci-specific M used in this lesson.
