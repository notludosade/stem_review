1. A tree has root R (weight 8) with two leaf children C (weight 5) and D (weight 2). Using the include/exclude tree DP for maximum weight independent set, what is the maximum weight achievable?

Selecting both leaves gives 5+2=7, but selecting R alone gives 8 — more than the leaves combined, since R's weight outweighs both children put together. All three vertices can't be picked together, since each leaf is adjacent to R.

2. Answer both parts about the tree DP algorithm:

(a) Why can't a single "best value for this subtree" (without separately tracking include and exclude) correctly combine at the parent's level?

(b) Fill in the blank: the tree DP's Θ(V) runtime comes from the work at each vertex being proportional to its ___ count, and these sum to Θ(V) across the whole tree.

(a) The parent needs to know whether picking itself would conflict with an already-selected child, which only the separate include/exclude values preserve. (b) Summing each vertex's proportional-to-child-count work across the entire tree gives the linear Θ(V) total.

3. Fill in the blank: representing a subset of visited cities as bits lets dp[mask][j] be stored in an ordinary ___ instead of a hash map or tree, since every subset maps to a unique integer index.

Because each bitmask maps to a unique integer from 0 through 2ⁿ−1, an ordinary array can index dp[mask][j] directly — no hashing or tree lookups needed.

4. In a 3-city TSP instance (cities 0, 1, 2) with dist(0,1)=6, dist(0,2)=9, dist(1,2)=14, and dp[{0}][0] = 0. Answer both parts:

(a) What does dp[{0,2}][2] equal?

(b) Fill in the blank: given dp[{0,1}][1] = 6, dp[{0,1,2}][2] = dp[{0,1}][1] + dist(1,2) = 6 + 14 = ___.

(a) The only way to have visited exactly {0,2} and be standing at city 2 is having come directly from city 0, so dp[{0,2}][2] = dp[{0}][0] + dist(0,2) = 0 + 9 = 9. (b) Extending that partial tour to also visit city 1, arriving last, adds dist(1,2) = 14, giving 20.

5. For n=15 cities, bitmask DP costs on the order of 15²·2¹⁵ ≈ 7.4×10⁶ operations, while brute force costs roughly 14! ≈ 8.7×10¹⁰ operations. What does this contrast illustrate?

Both approaches are exponential, but 2ⁿ grows far slower than n! — a genuine, large practical improvement that still isn't a polynomial-time algorithm, so it doesn't conflict with TSP's NP-hardness.

6. For matrices B₁ (20×2), B₂ (2×30), B₃ (30×4), answer both parts:

(a) What is the total cost of computing (B₁B₂)B₃?

(b) Fill in the blank: the alternative parenthesization B₁(B₂B₃) costs ___ total — dramatically cheaper than the other order this time.

(a) B₁B₂ costs 20·2·30=1,200 (producing a 20×30 matrix), then (B₁B₂)B₃ costs 20·30·4=2,400 — total 3,600. (b) B₂B₃ costs 2·30·4=240 (producing a 2×4 matrix), then B₁(B₂B₃) costs 20·2·4=160 — total 400, showing the cheaper order can go either way depending on the actual dimensions.

7. Fill in the blank: unlike an ordinary merge sort's fixed halfway split, the matrix chain DP's split point k must range over every possibility, because the optimal split isn't known in advance — it isn't always the fixed ___ of the chain.

Merge sort always splits exactly in half; matrix chain multiplication has no such guarantee, so every split point must be tried and compared.

8. Answer both parts about the matrix chain DP's structure:

(a) Suppose you tried to fill in dp[i][j] for all pairs ordered by increasing j alone, instead of by increasing chain length. What could go wrong?

(b) Fill in the blank: the number of intervals [i, j] the matrix chain DP considers is Θ(___), before even accounting for the split points tried within each one.

(a) The recurrence needs both sub-chains already solved, and ordering by j alone doesn't guarantee that a shorter chain [i,k] embedded inside a longer one has been finished first. (b) There are Θ(n²) distinct intervals [i,j], each then considering up to n split points, giving the overall Θ(n³).

9. Using M = [[1,1],[1,0]] as the Fibonacci matrix, what is M raised to the power 0, i.e., M⁰?

Just as x⁰=1 for ordinary numbers, M⁰ is defined as the identity matrix — the base case fast exponentiation returns immediately without any multiplication.

10. Answer both parts about matrix exponentiation's runtime:

(a) For n = 10¹², roughly how many matrix multiplications does matrix exponentiation need to compute F(n)?

(b) Fill in the blank: encoding a fixed-order linear recurrence as repeated multiplication by a companion matrix lets fast exponentiation compute its nth term in Θ(___) matrix multiplications.

(a) log₂(10¹²) = 12·log₂(10) ≈ 12·3.32 ≈ 39.9, so roughly 40 squaring-based multiplications suffice — versus 10¹² additions for the ordinary linear DP. (b) That logarithmic multiplication count is the entire payoff of recasting a recurrence as a matrix power.
