1. A decision problem is in NP if:

NP membership is entirely about efficient verifiability of a proposed certificate for a "yes" instance — it says nothing about how quickly (or whether) such a certificate can be found.

2. Consider the reduction Independent Set ≤ₚ Vertex Cover: given (G, k) for Independent Set, output (G, |V|−k) for Vertex Cover. Answer both parts:

(a) Why is this reduction correct?

(b) Fill in the blank: reading "a fast algorithm for B gives one for A" contrapositively is the entire point of a reduction — it shows a reduction transfers ___ from a problem already known to lack an efficient algorithm onto a new one, without solving either problem directly.

(a) An edge with both endpoints in S would mean neither is in V∖S, so V∖S wouldn't cover that edge — this equivalence is exactly what the O(1) transformation (touching only the number k, not the graph) preserves. (b) A ≤ₚ B says B is at least as hard as A, so if A has no polynomial-time algorithm, chaining a hypothetical fast algorithm for B after the reduction would give A one too — a contradiction, which is how hardness (not easiness) transfers.

3. Which correctly distinguishes "NP-hard" from "NP-complete"?

NP-hardness is purely a statement about being a reduction target for every problem in NP; NP-completeness adds the further requirement that the problem also has polynomial-time-verifiable certificates itself.

4. The Cook-Levin theorem proves SAT is NP-complete. Answer both parts:

(a) Why does this proof differ fundamentally from a reduction like Independent Set ≤ₚ Vertex Cover?

(b) Fill in the blank: because SAT's NP-hardness is confirmed by this one foundational construction, every later NP-completeness proof can instead chain back through a reduction from SAT (or 3-SAT), rather than repeating a from-scratch simulation of an arbitrary NP ___.

(a) A specific reduction relates exactly two named problems; Cook-Levin instead reduces the entire abstract class of NP verifiers into SAT directly, which needed a fundamentally different argument. (b) Every NP problem has, by definition, a polynomial-time verifier — Cook-Levin's construction encodes that verifier's computation as a formula, which is exactly why later proofs never need to repeat it.

5. In the 3-SAT ≤ₚ Independent Set reduction (one triangle of 3 vertices per clause, plus edges between a literal and its negation across different triangles), why must an independent set of size k choose exactly one vertex per triangle?

Triangle edges force at most one vertex per clause to be selected, which is exactly what makes each selected vertex correspond to one satisfied literal per clause — the cross-triangle edges then rule out contradictory variable assignments.

6. Lesson 30 showed Independent Set ≤ₚ Vertex Cover; a later lesson showed 3-SAT ≤ₚ Independent Set. Answer both parts:

(a) What can be concluded about Vertex Cover from these two reductions, without any new construction?

(b) Fill in the blank: this chaining relies on the ___ of polynomial-time reductions — if A ≤ₚ B and B ≤ₚ C, then A ≤ₚ C.

(a) No new gadget construction was needed — Vertex Cover inherits NP-hardness purely by chaining an already-established reduction onto Independent Set's newly-proven hardness. (b) Transitivity of reductions is exactly the mechanism: hardness passes through a chain of reductions without ever needing a fresh argument at each link.

7. The reduction Hamiltonian Cycle ≤ₚ TSP (decision version) builds a complete graph with edge weight 1 for edges in the original graph G and weight 2 for every other edge, then asks whether a tour of total weight ≤ |V| exists. Answer both parts:

(a) Why does a tour of weight exactly |V| correspond to a Hamiltonian cycle in G?

(b) Fill in the blank: this reduction finally justifies the claim, first deferred when bitmask dynamic programming solved TSP exactly but only in exponential time, that TSP is ___-complete.

(a) Since exactly |V| edges are traversed on any tour, hitting a total weight of |V| forces every single edge used to be weight 1, i.e. an edge that actually exists in G. (b) Hamiltonian Cycle is already NP-complete, and this polynomial-time reduction (touching every edge once, so O(|V|²)) shows TSP is too — bitmask DP's Θ(n²·2ⁿ) runtime was never in tension with this, since it is still exponential.

8. For a minimization problem, an algorithm is a c-approximation if:

The approximation ratio is a worst-case multiplicative bound on returned cost relative to the true optimum, guaranteed for every instance, not a statement about which instances are solved exactly.

9. The greedy Vertex Cover algorithm repeatedly picks an uncovered edge (u, v), adds both endpoints to the cover, and removes every edge touching u or v, until no edges remain. Let M be the set of picked edges. Answer both parts:

(a) Why is M a matching (no two edges in M share an endpoint)?

(b) Fill in the blank: since the algorithm's cover contains exactly 2 vertices per edge in M, and OPT ≥ |M| (M's edges are pairwise disjoint, so covering all of them needs at least one distinct vertex each), the cover's size is at most ___ times OPT.

(a) Removing every edge touching a picked edge's endpoints as soon as it's picked is exactly what forces pairwise disjointness among all picked edges. (b) |C| = 2|M| ≤ 2·OPT, a 2-approximation built from nothing more than counting a matching's disjointness.

10. According to the course's closing capstone, Lesson 33's LP-relaxation bound for Vertex Cover is explicitly described as which earlier result "wearing a one-sided disguise"?

Max-flow min-cut proves an exact equality between two differently-structured problems; LP relaxation proves only a one-sided bound the same way, which the capstone frames as the same "certify via a second structure" idea in weakened form.
