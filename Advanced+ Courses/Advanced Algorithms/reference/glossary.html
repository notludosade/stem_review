Unit 1 — Algorithm Analysis, Rigorously

Big-O notation (O)

An asymptotic upper bound: f(n) = O(g(n)) if there exist constants c > 0 and n₀ such that f(n) ≤ c·g(n) for all n ≥ n₀.

Big-Omega notation (Ω)

An asymptotic lower bound: f(n) = Ω(g(n)) if there exist constants c > 0 and n₀ such that f(n) ≥ c·g(n) for all n ≥ n₀.

Big-Theta notation (Θ)

A tight asymptotic bound: f(n) = Θ(g(n)) exactly when f(n) = O(g(n)) and f(n) = Ω(g(n)) both hold.

Recursion tree method

Solving a recurrence by drawing the full tree of recursive calls, summing the work done at each level, and adding the levels together.

Master Theorem

A formula that solves recurrences of the form T(n) = aT(n/b) + f(n) by comparing f(n) against n^(log_b a), without needing a recursion tree.

Amortized analysis

Analyzing the average cost per operation over a worst-case sequence of operations, rather than bounding every individual operation's worst case separately.

Potential method

A technique for amortized analysis that defines a potential function over the data structure's state, charging each operation its actual cost plus the change in potential.

Unit 2 — Divide and Conquer

Strong induction

An induction proof where the inductive step may assume the claim holds for all smaller cases, not just the immediately preceding one — the natural fit for divide-and-conquer correctness proofs.

Inversion

A pair of elements in a sequence that are out of their sorted relative order; counting inversions measures how far a sequence is from sorted.

Median of medians

A worst-case linear-time algorithm for selecting the k-th smallest element, using a carefully chosen pivot guaranteed to eliminate a constant fraction of elements each round.

Strassen's algorithm

A divide-and-conquer matrix multiplication algorithm that multiplies two n×n matrices using 7 recursive multiplications instead of 8, achieving a sub-cubic time complexity.

Unit 3 — Greedy Algorithms & MSTs

Exchange argument

A proof technique for greedy correctness that shows any optimal solution can be transformed into the greedy solution, one swap at a time, without ever making it worse.

Minimum spanning tree (MST)

A subset of a weighted graph's edges that connects all vertices with no cycles, at the minimum possible total edge weight.

Kruskal's algorithm

An MST algorithm that repeatedly adds the globally cheapest edge that doesn't create a cycle, using Union-Find to detect cycles.

Prim's algorithm

An MST algorithm that grows a single tree from an arbitrary start vertex, repeatedly adding the cheapest edge connecting the tree to a new vertex.

Cut property

For any cut (partition of vertices into two sets), the minimum-weight edge crossing the cut belongs to some MST — the theorem that proves both Kruskal's and Prim's correct.

Huffman coding

A greedy algorithm that builds an optimal prefix-free binary code for a set of symbols by repeatedly merging the two lowest-frequency nodes.

Unit 4 — Advanced Graph Algorithms

Bellman-Ford algorithm

A single-source shortest-path algorithm that handles negative edge weights and can detect negative cycles, by relaxing every edge |V|-1 times.

Floyd-Warshall algorithm

An all-pairs shortest-path dynamic program that considers, for each vertex k, whether routing through k improves any pair's shortest path — in Θ(V³).

Strongly connected component (SCC)

A maximal set of vertices in a directed graph where every vertex can reach every other vertex within the set.

Kosaraju's algorithm

An SCC algorithm using two depth-first search passes — one on the graph, one on its reverse — ordered by finishing times.

Tarjan's algorithm

A single-pass DFS algorithm for finding SCCs, using a discovery-time/low-link invariant tracked on a stack.

Ford-Fulkerson algorithm

A max-flow algorithm that repeatedly finds an augmenting path in the residual graph and pushes flow along it until none remain.

Max-flow min-cut theorem

The maximum flow from source to sink in a flow network exactly equals the minimum total capacity of any cut separating them.

Unit 5 — Advanced Dynamic Programming

DP on trees

Dynamic programming where each subproblem corresponds to a subtree, and a node's state combines the states of a variable number of children.

Bitmask DP

A dynamic programming technique where a DP state includes a subset of elements, encoded as the bits of an integer — used for problems like the Traveling Salesman Problem.

Traveling Salesman Problem (TSP)

The problem of finding the minimum-weight tour that visits every vertex in a weighted graph exactly once and returns to the start; NP-complete in its decision form.

Matrix chain multiplication

The problem of choosing the parenthesization of a chain of matrix multiplications that minimizes total scalar multiplication cost, solved with an interval DP.

Matrix exponentiation

Computing the nth term of a linear recurrence in Θ(log n) by expressing the recurrence as a matrix power and using repeated squaring.

Unit 6 — Advanced Data Structures

Segment tree

A binary tree data structure supporting range queries (sum, min, max) and point updates on an array, both in Θ(log n).

Fenwick tree (Binary Indexed Tree)

A compact tree structure supporting prefix-sum queries and point updates in Θ(log n), built entirely from a bit trick on the index.

AVL tree

A self-balancing binary search tree that maintains Θ(log n) height by rebalancing via rotations after every insertion and deletion.

Disjoint Set Union (Union-Find)

A data structure tracking a partition of elements into disjoint sets, supporting near-constant amortized find and union operations via union-by-rank and path compression.

Trie

A tree structure that stores a set of strings by shared prefix, letting prefix and membership queries run in time proportional to the query string's length.

Unit 7 — String Algorithms

Knuth-Morris-Pratt (KMP) algorithm

A substring search algorithm that precomputes a failure function describing how much of a partial match can be reused after a mismatch, achieving Θ(n+m) time.

Rabin-Karp algorithm

A substring search algorithm that hashes every window of the text and only performs a full character comparison when hashes collide.

Rolling hash

A hash function that can be updated in O(1) as a text window slides forward by one character, without rehashing the entire window.

Suffix array

A sorted array of all suffixes of a string (by starting index), enabling pattern search against the text in O(m log n) after one preprocessing pass.

Unit 8 — Complexity & Intractability

P

The class of decision problems solvable by a polynomial-time algorithm.

NP

The class of decision problems whose yes-instances have a certificate verifiable in polynomial time.

Polynomial-time reduction (≤ₚ)

A ≤ₚ B means any instance of problem A can be transformed, in polynomial time, into an instance of problem B with the same yes/no answer — transferring hardness from B to A's proof, not the other way around.

NP-hard

A problem B is NP-hard if every problem in NP reduces to B in polynomial time.

NP-complete

A problem that is both NP-hard and itself in NP — the hardest problems within NP.

Boolean satisfiability (SAT)

The problem of determining whether some assignment of true/false to variables makes a given Boolean formula evaluate to true; the first problem proven NP-complete.

Cook-Levin theorem

The 1971/1973 theorem (Cook, Levin) proving SAT is NP-complete, by directly encoding an arbitrary polynomial-time NP verifier's computation as a Boolean formula.

3-SAT

SAT restricted to formulas in conjunctive normal form with exactly 3 literals per clause; equally hard as general SAT, and the usual starting point for NP-completeness reductions.

Approximation algorithm

A polynomial-time algorithm for an NP-hard optimization problem that guarantees a solution within a provable factor of the true optimum.

c-approximation

An approximation algorithm whose returned solution cost is provably at most c times the optimal cost (minimization) or at least OPT/c (maximization), for every instance.

LP relaxation

Relaxing an integer linear program's integrality constraints (e.g. xᵥ ∈ {0,1}) to a continuous range (0 ≤ xᵥ ≤ 1), producing a polynomial-time-solvable linear program whose optimum bounds the original.
