1. Which of the following best describes the logical structure of an exchange argument?

The exchange argument never needs to reason about the whole solution space at once — it only needs a single non-worsening swap step, repeated until the hypothetical optimal solution has been transformed into greedy's.

2. A proposed greedy rule for interval scheduling is "always pick the interval with the fewest overlaps with other remaining intervals." What would show this rule is wrong, using the exchange-argument mindset?

A failed exchange-argument attempt (or a direct counterexample showing the rule can select fewer intervals than optimal) is exactly the sign a greedy rule is genuinely wrong, not just unproven.

3. In Kruskal's algorithm, what does it mean when find(u) equals find(v) for a candidate edge (u, v)?

Two vertices already in the same Union-Find set are already connected by some path, so joining them again would close a cycle rather than extend the growing forest.

4. In the cut property's proof by contradiction, what goes wrong if a supposedly minimum spanning tree T excludes the unique minimum-weight edge e crossing some cut?

Since e is assumed the unique minimum-weight edge crossing the cut, any other cut-crossing edge f in the cycle must be strictly heavier, so replacing f with e strictly lowers the tree's weight — contradicting T being minimum.

5. Fill in the blank: once the key lemma justifies merging the two least-frequent symbols, an inductive argument on the shrinking number of remaining ___ completes Huffman's correctness proof.

Once the two smallest symbols are merged into a single combined node, the remaining problem has the identical structure with one fewer symbol, so induction on the symbol count finishes the argument.

6. Consider intervals J1=[0,2], J2=[1,4], J3=[3,6], J4=[5,8]. Using the earliest-finish-time greedy rule, answer both parts:

(a) Fill in the blank: greedy selects J1 first since it has the earliest finish time (2); the next interval it selects (skipping any that start before time 2) is J___.

(b) Why does greedy skip J2 = [1,4] even though it finishes earlier than J3?

(a) J1 finishes at 2 (earliest overall); J2 starts at 1 (before time 2, so it conflicts) and is skipped; J3 starts at 3 (≥2, feasible) and is selected next. (b) J2's start (1) is before J1's finish (2), so selecting it would overlap the interval already committed to — regardless of how J2's own finish time compares to J3's or J4's.

7. Run Prim's algorithm starting at vertex P on this graph: edges P–Q=3, P–R=7, Q–R=2, Q–S=6, R–S=4. Answer both parts:

(a) Which edge does Prim's algorithm add second (immediately after its first pick)?

(b) Fill in the blank: Prim's first pick is P–Q with weight 3, since it is the minimum-weight edge crossing the cut ({P}, {Q, R, S}); the total weight of the completed MST is ___.

(a) After visited={P,Q}, the crossing edges are P–R=7, Q–R=2, Q–S=6; the minimum is Q–R=2. (b) The three MST edges are P–Q(3), Q–R(2), R–S(4), totaling 3+2+4=9.

8. Answer both parts about Kruskal's and Prim's algorithms:

(a) For a dense graph (E close to V²), which factor makes Prim's algorithm (with a binary heap) an appealing choice over Kruskal's?

(b) Fill in the blank: whichever algorithm is used, only the total weight of a minimum spanning tree is guaranteed unique when ties exist — the exact ___ of edges may differ between valid MSTs.

(a) Both algorithms are close to Θ(E log V) asymptotically, but Prim's log-V-per-edge cost can be more favorable than sorting all E edges when E is large relative to V — a practical, not fundamental, distinction. (b) Only the total weight is guaranteed unique across all MSTs of a graph; the exact edge set can differ whenever weights tie.

9. Answer both parts about the cut property and the two MST algorithms:

(a) Which cut does Prim's algorithm examine at a given step, and which cut does Kruskal's examine when considering a candidate edge (u,v) with find(u) ≠ find(v)?

(b) Fill in the blank: because both algorithms are just repeatedly finding the minimum-weight edge crossing some cut, the cut property certifies both correct at once — the only difference is which ___ each one happens to examine at a given step.

(a) Prim's grows a single tree from a starting vertex, so its cut is (visited, unvisited); Kruskal's grows a forest, so its cut is (one connected component, everything else). (b) Both algorithms reduce to the same underlying theorem — only the specific cut examined at each step differs.

10. Build a Huffman tree for symbols with frequencies M:4, N:5, P:7, Q:20. Answer both parts:

(a) Fill in the blank: the algorithm merges M and N first (the two smallest), producing a node of weight ___.

(b) After merging M and N into a weight-9 node, which merge happens next?

(a) M(4)+N(5)=9, the two smallest frequencies merged first. (b) After that merge, the remaining nodes are {9, P:7, Q:20}; the two smallest are 9 and P(7), which merge next into weight 16 — leaving Q(20) to merge last at the root, giving Q the shortest (1-bit) codeword.
