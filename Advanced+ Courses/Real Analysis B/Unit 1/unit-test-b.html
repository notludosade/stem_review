1. Let fₙ(x) = x/n for x ∈ ℝ. Which statement correctly describes its convergence?

For each fixed x, x/n → 0, so the pointwise limit is 0. But over the unbounded domain ℝ, sup|x/n − 0| is infinite for every n (x can always be taken large enough), so no single N works for every x at once — the convergence is not uniform on all of ℝ.

2. For which series does the Weierstrass M-test fail to give a useful conclusion on the stated domain?

For xⁿ on [0,1), sup|xⁿ| = 1 for every n (approached as x→1⁻), so the best possible bound is Mₙ = 1, and Σ1 diverges — the M-test's hypothesis simply isn't met, so it gives no information either way.

3. Fill in the blank: the Uniform Cauchy Criterion states (fₙ) converges uniformly on S iff for every ε > 0 there is N such that m, n ≥ N implies supx∈S|fₙ(x) − fₘ(x)| < ε — the exact same statement as the ordinary Cauchy criterion for sequences, with |·| replaced by a ___ over the whole domain.

Taking the supremum over the whole domain S is exactly what upgrades the ordinary Cauchy criterion into the uniform one.

4. Which of the following is the correct contrapositive use of the continuity theorem (the "Discontinuity Test")?

This is the exact contrapositive of "uniform limit of continuous functions is continuous" — a discontinuous pointwise limit of continuous functions rules out uniform convergence.

5. In the proof that f is integrable given fₙ → f uniformly, which step uses the bound |fₙ(x) − f(x)| < ε/(4(b−a)) for every x ∈ [a,b]?

The uniform bound controls U(f,P) − L(f,P) in terms of U(fₙ,P) − L(fₙ,P), which is already small by the Cauchy Criterion for Integrability applied to fₙ.

6. Consider fₙ(x) = xⁿ, now restricted to S = [0, 1/2]. Answer both parts.

(a) What is supx∈[0,1/2]|xⁿ − 0|, and what does it tell you about uniform convergence here?

(b) Fill in the blank: this shows uniform convergence can hold on a ___ set even though the same sequence fails to converge uniformly on the larger set [0, 1).

(a) On [0,1/2], the maximum of xⁿ occurs at x = 1/2, giving (1/2)ⁿ → 0. (b) Restricting to a smaller set removes the obstruction near x = 1, so uniform convergence can hold there even when it fails on [0,1).

7. Consider the series Σ xⁿ/(n²·2ⁿ) on the interval [−1, 1]. Answer both parts.

(a) Which x-independent bound Mₙ works for the Weierstrass M-test here, given |x| ≤ 1 on [−1, 1]?

(b) Fill in the blank: since Mₙ = 1/(n²2ⁿ) ≤ 1/n² for n ≥ 1 and Σ1/n² converges, the Comparison Test shows ΣMₙ converges, so the M-test proves the original series converges ___ on [−1, 1].

(a) Since |x| ≤ 1, |xⁿ/(n²2ⁿ)| ≤ 1/(n²2ⁿ). (b) 1/(n²2ⁿ) ≤ 1/n² for n ≥ 1, and Σ1/n² converges, so ΣMₙ converges and the M-test gives uniform convergence.

8. In the continuity proof, δ is chosen so that |x − x₀| < δ implies |fₙ(x) − fₙ(x₀)| < ε/3, using continuity of a single fₙ. Answer both parts.

(a) Why is it valid to fix a single n ≥ N first, and only then find this δ for that particular fₙ?

(b) Fill in the blank: this proof strategy would break down under mere ___ convergence, since then N could depend on x and no single fixed n might work at both x and x₀ simultaneously.

(a) Uniform convergence's N works everywhere at once, so fixing n ≥ N is safe before choosing δ from fₙ's own continuity. (b) Under pointwise convergence, N could depend on x, so no single n would necessarily control both |f(x)−fₙ(x)| and |fₙ(x₀)−f(x₀)| at once.

9. Suppose gₙ → g uniformly on [a, b] and each gₙ is Riemann integrable. Answer both parts about why ∫ₐᵇgₙ → ∫ₐᵇg.

(a) Which inequality is the key step in proving the integrals converge?

(b) Fill in the blank: since gₙ → g uniformly, sup|g − gₙ| → 0, so the bound (b−a)·sup|g − gₙ| forces the integrals to ___.

(a) This is the standard bound: an integral is at most (interval length) × (bound on the integrand). (b) Since the uniform-convergence supremum shrinks to 0, the whole right-hand side shrinks to 0, forcing the integrals to converge to each other.

10. Let fₙ(x) = sin(nx)/√n on ℝ, as in the counterexample. Answer both parts.

(a) What happens to (fₙ′) even though fₙ → 0 uniformly?

(b) Fill in the blank: this shows that unlike continuity and integration, ___ is the one operation that a uniform limit of the original sequence does not automatically preserve.

(a) Differentiating sin(nx)/√n gives √n·cos(nx), whose amplitude grows without bound, so the derivative sequence doesn't converge. (b) Differentiation depends on rate of change, which uniform closeness of function values does not control — the reason it breaks the pattern of Lessons 3 and 4.
