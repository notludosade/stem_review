Pointwise vs. Uniform Convergence

Real Analysis A studied sequences of numbers. Now the terms of the sequence are themselves functions — and it turns out there are two genuinely different ways for a sequence of functions to converge.

Lesson 2 → Contents Glossary →

A sequence of functions f₁, f₂, f₃, … assigns, at every fixed x, an ordinary sequence of real numbers f₁(x), f₂(x), f₃(x), …. The most natural way to define convergence of the whole sequence is to require that number-sequence to converge at every x. That natural definition is called pointwise convergence — and it turns out to be too weak to preserve properties like continuity, as the example below shows.

Definition — Pointwise Convergence A sequence of functions (fₙ) defined on a set S converges pointwise to a function f on S if, for every x ∈ S, limn→∞ fₙ(x) = f(x). Spelled out with quantifiers: for every x ∈ S and every ε > 0, there exists N (which may depend on both x and ε) such that n ≥ N implies |fₙ(x) − f(x)| < ε.
Example: a pointwise limit that isn't continuous Let fₙ(x) = xⁿ on S = [0, 1]. For 0 ≤ x < 1, xⁿ → 0 as n → ∞ (Real Analysis A, geometric-type sequences). For x = 1, xⁿ = 1 for every n, so the sequence converges to 1. So (fₙ) converges pointwise to f(x) = 0 for x ∈ [0, 1) and f(1) = 1 — a discontinuous function, even though every single fₙ is a polynomial, continuous everywhere. Pointwise convergence alone does not preserve continuity.
Why pointwise convergence lets N depend on x In the example above, fix ε = 1/2 and watch what N has to be as x creeps toward 1. For x = 0.5, |xⁿ| drops below 1/2 by n = 1. For x = 0.99, it takes roughly n = 69 before 0.99ⁿ < 1/2. For x = 0.9999, it takes far longer still. As x → 1⁻, the N needed to get within ε of the limit grows without bound — there is no single N that works for every x at once. Pointwise convergence permits exactly this: a different N, chosen after x is fixed, for every point.

The fix is to demand one N that works everywhere at once — chosen only from ε, before any x is considered.

Definition — Uniform Convergence A sequence of functions (fₙ) defined on a set S converges uniformly to f on S if, for every ε > 0, there exists N (depending only on ε, not on x) such that for all n ≥ N and all x ∈ S simultaneously, |fₙ(x) − f(x)| < ε. Equivalently: supx∈S |fₙ(x) − f(x)| → 0 as n → ∞.
Why this is the same move as uniform continuity Real Analysis A drew exactly this distinction once before: pointwise continuity lets δ depend on the point x₀, while uniform continuity demands one δ that works across the whole domain. Uniform convergence is the identical idea one level up — instead of a single function's δ depending on where you evaluate it, a whole sequence's N is allowed (pointwise) or forbidden (uniform) from depending on where you evaluate the sequence.
Example: the same sequence, convergent uniformly on a smaller set fₙ(x) = xⁿ does not converge uniformly on [0, 1) — the supremum of |xⁿ − 0| over [0, 1) is 1 for every n (approached as x → 1⁻), which never shrinks to 0. But restricted to [0, 1/2], the same sequence converges uniformly to 0: supx∈[0,1/2] xⁿ = (1/2)ⁿ, which does shrink to 0 as n → ∞. Uniform convergence can hold on a smaller set even when it fails on a larger one — the obstruction was always the behavior near x = 1.

Check your recall

No peeking back up — answer from memory first, then check.

1. What is the key difference between pointwise and uniform convergence?

Both definitions require fₙ(x) → f(x) at every x; the difference is purely whether N is allowed to depend on x (pointwise) or must be chosen uniformly across the whole domain (uniform).

2. Why does fₙ(x) = xⁿ fail to converge uniformly on [0, 1)?

The supremum of |xⁿ − 0| over [0, 1) stays at 1 for every n (approached near x = 1), so no single N can bring every point within ε simultaneously.

3. What does the example fₙ(x) = xⁿ on [0, 1] demonstrate?

Every fₙ = xⁿ is continuous, but the pointwise limit — 0 on [0,1) and 1 at x=1 — is discontinuous at x = 1.

4. Fill in the blank: convergence in which a single N works for every point of the domain simultaneously is called ___ convergence.

Uniform convergence demands one N, depending only on ε, that works across the whole domain at once.

5. Fill in the blank: convergence in which N is permitted to depend on x is called ___ convergence.

Pointwise convergence only requires fₙ(x) → f(x) at each x separately, allowing N to depend on x.
