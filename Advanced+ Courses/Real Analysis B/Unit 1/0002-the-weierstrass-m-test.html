The Weierstrass M-Test

Checking sup|fₙ(x) − f(x)| → 0 by hand is often hopeless for an infinite series of functions. The M-test turns that check into a single ordinary series of numbers.

← Lesson 1 Lesson 3 → Contents Glossary →

For a series of functions g₁(x) + g₂(x) + g₃(x) + …, "converges uniformly" means the sequence of partial sums sₙ(x) = g₁(x) + … + gₙ(x) converges uniformly to some sum function s(x). Computing supx|sₙ(x) − s(x)| directly is often intractable — but there's a sufficient condition that reduces the whole question to an ordinary series of numbers.

The Uniform Cauchy Criterion A sequence of functions (fₙ) converges uniformly on S if and only if, for every ε > 0, there exists N such that m, n ≥ N implies supx∈S |fₙ(x) − fₘ(x)| < ε. This is exactly the Cauchy criterion for sequences (Real Analysis A, Lesson 13), with the absolute value replaced by a supremum over the whole domain.
Theorem — The Weierstrass M-Test Let (gₙ) be a sequence of functions on S, and suppose there exist numbers Mₙ ≥ 0 with |gₙ(x)| ≤ Mₙ for every x ∈ S and every n. If the series ΣMₙ converges, then the series Σgₙ(x) converges uniformly (and absolutely, at every x) on S.
Proof Let sₙ(x) = g₁(x) + … + gₙ(x). For n > m, |sₙ(x) − sₘ(x)| = |gm+1(x) + … + gₙ(x)| ≤ |gm+1(x)| + … + |gₙ(x)| ≤ Mm+1 + … + Mₙ, by the triangle inequality and the hypothesis |gₖ(x)| ≤ Mₖ. Since ΣMₙ converges, its partial sums form a Cauchy sequence of numbers (Real Analysis A, Cauchy criterion for series), so Mm+1 + … + Mₙ → 0 as m, n → ∞ — and crucially, this bound does not depend on x. So given ε > 0, the same N that makes the number-series tail small works for every x ∈ S at once: |sₙ(x) − sₘ(x)| < ε for all x, all m, n ≥ N. By the Uniform Cauchy Criterion, (sₙ) converges uniformly. ∎
Why the bound Mₙ being independent of x is the whole trick The proof never mentions x except to bound |gₙ(x)| from above by a single number Mₙ that works for every x. Once that's done, the entire rest of the argument is a statement about the number-series ΣMₙ — no x in sight. Any uniformity in the number-series' convergence transfers automatically to uniformity in x, precisely because the bound never depended on which x was chosen. This is why the M-test converts a hard-to-check uniform statement into an easy-to-check ordinary one.
Example: Σ sin(nx)/n² converges uniformly on all of ℝ Let gₙ(x) = sin(nx)/n². Since |sin(nx)| ≤ 1 for every real x and every n, |gₙ(x)| ≤ 1/n² = Mₙ for every x ∈ ℝ. The series ΣMₙ = Σ1/n² is a convergent p-series (p = 2 > 1, Real Analysis A). By the M-test, Σ sin(nx)/n² converges uniformly on all of ℝ — a single argument covering the entire real line at once, with no case-by-case analysis of x needed.
Example: where the M-test doesn't apply For gₙ(x) = xⁿ on S = [0, 1), the tightest possible bound is Mₙ = supx∈[0,1)|xⁿ| = 1 for every n (approached as x → 1⁻). Since ΣMₙ = Σ1 diverges, the M-test simply gives no information here — it does not prove non-uniform convergence, it just fails to prove uniform convergence. (Lesson 1 already showed this series's underlying sequence isn't uniformly convergent on [0,1) by a separate, direct argument.)

Check your recall

No peeking back up — answer from memory first, then check.

1. What does the Weierstrass M-test require to conclude Σgₙ(x) converges uniformly?

The M-test needs an x-independent bound Mₙ on each term, with ΣMₙ itself a convergent series of numbers.

2. Why does the bound Mₙ need to be independent of x for the proof to work?

An x-independent bound is exactly what converts a statement that must hold uniformly in x into a plain statement about a number series.

3. Why does the M-test fail to apply to Σxⁿ on [0, 1)?

Since sup of xⁿ on [0,1) is 1, the best possible Mₙ is 1, and Σ1 diverges, so the M-test's hypothesis is simply not met here.

4. Fill in the blank: the Uniform ___ Criterion says (fₙ) converges uniformly iff sup|fₙ(x) − fₘ(x)| → 0 as m, n → ∞.

The Uniform Cauchy Criterion is the direct analogue of the ordinary Cauchy criterion, with the supremum making the closeness uniform in x.

5. Fill in the blank: the Weierstrass ___ reduces proving uniform convergence of a function series to checking convergence of an ordinary number series ΣMₙ.

The M-test is named for Weierstrass and works by bounding each term with an x-independent Mₙ.
