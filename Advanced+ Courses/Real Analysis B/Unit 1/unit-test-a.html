1. Consider fₙ(x) = xⁿ on S = [0, 1]. Which statement is correct about its mode of convergence?

The pointwise limit is 0 on [0,1) and 1 at x=1 — discontinuous at x=1. Since every fₙ is continuous, a uniform limit would have to be continuous too, so the convergence cannot be uniform on [0,1].

2. Which condition must the numbers Mₙ satisfy for the Weierstrass M-test to conclude Σgₙ(x) converges uniformly on S?

The M-test needs an x-independent bound Mₙ on each term, with ΣMₙ itself a convergent series of numbers — that bound is what lets the same N work for every x at once.

3. Fill in the blank: (fₙ) converges uniformly on S if and only if, for every ε > 0, there is N such that m, n ≥ N implies supx∈S|fₙ(x) − fₘ(x)| < ε. This is called the Uniform ___ Criterion.

This is the Uniform Cauchy Criterion — the exact analogue of the ordinary Cauchy criterion, with the absolute value replaced by a supremum over the whole domain.

4. Suppose fₙ → f uniformly on S and each fₙ is continuous at x₀ ∈ S. What can be concluded?

Uniform convergence of continuous functions is exactly strong enough to guarantee the limit function is continuous at x₀.

5. Suppose fₙ → f uniformly on [a, b] and each fₙ is Riemann integrable there. Which conclusion is guaranteed?

Uniform convergence of integrable functions guarantees both integrability of the limit and convergence of the integrals to the limit's integral.

6. Consider fₙ(x) = xⁿ on [0, 1]. Answer both parts.

(a) What is the pointwise limit function f(x) on [0, 1]?

(b) Fill in the blank: since every fₙ is continuous but the pointwise limit is ___ at x = 1, the convergence cannot be uniform on [0, 1].

(a) xⁿ → 0 for 0 ≤ x < 1, and xⁿ = 1 for every n at x = 1, giving this split limit. (b) The limit is discontinuous at x = 1, and a uniform limit of continuous functions is always continuous — so this convergence cannot be uniform.

7. Consider the series Σ cos(nx)/n³ on all of ℝ. Answer both parts.

(a) Which bound Mₙ, independent of x, can be used in the Weierstrass M-test?

(b) Fill in the blank: since Σ1/n³ is a convergent p-series (p = 3 > 1), the M-test shows Σcos(nx)/n³ converges ___ on all of ℝ.

(a) |cos(nx)| ≤ 1 for every real x, so |cos(nx)/n³| ≤ 1/n³. (b) Σ1/n³ converges (p = 3 > 1), so by the M-test the series converges uniformly on all of ℝ.

8. In the proof that a uniform limit of continuous functions is continuous, the key inequality is |f(x) − f(x₀)| ≤ |f(x) − fₙ(x)| + |fₙ(x) − fₙ(x₀)| + |fₙ(x₀) − f(x₀)|. Answer both parts.

(a) Which property supplies a single n making both the first and third terms small, for every x ∈ S at once?

(b) Fill in the blank: the middle term |fₙ(x) − fₙ(x₀)| is made small by the ___ of fₙ at x₀, using a δ found after n is already fixed.

(a) Uniform convergence supplies one N working across all of S, so a single fixed n ≥ N bounds the error at both x and x₀ at once. (b) Once n is fixed, fₙ's own continuity at x₀ supplies the δ controlling the middle term.

9. The "moving bump" sequence fₙ — a triangular spike of height n and width 2/n centered at 0 — satisfies fₙ(x) → 0 pointwise everywhere on [0,1], yet ∫₀¹ fₙ = 1 for every n. Answer both parts.

(a) What does this example show about the hypothesis of the Uniform Convergence and Integration theorem?

(b) Fill in the blank: since lim ∫₀¹fₙ = 1 but ∫₀¹(lim fₙ) = ∫₀¹0 = 0, the interchange of limit and integral genuinely ___ here.

(a) The spike's area stays fixed at 1 even as it converges pointwise to 0, so pointwise convergence is not enough — the theorem's uniform-convergence hypothesis is doing real work. (b) The two sides genuinely disagree (1 ≠ 0), so the interchange fails without uniform convergence.

10. Let fₙ(x) = x + sin(nx)/n² on [0, 1]. Answer both parts.

(a) What does fₙ′(x) equal, and what does it converge to uniformly?

(b) Fill in the blank: since fₙ(0) = 0 converges trivially and (fₙ′) converges uniformly, the Differentiable Limit Theorem guarantees (fₙ) converges uniformly to a differentiable f with f′(x) = ___ for every x ∈ [0, 1].

(a) Differentiating gives fₙ′(x) = 1 + cos(nx)/n, and sup|cos(nx)/n| ≤ 1/n → 0, so fₙ′ → 1 uniformly. (b) The theorem gives f′ = g = 1 on [0,1], matching direct inspection: fₙ(x) → x uniformly, so f(x) = x and f′(x) = 1.
