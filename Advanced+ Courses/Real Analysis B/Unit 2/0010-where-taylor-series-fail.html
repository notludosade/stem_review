Where Taylor Series Can Fail

eˣ and sin(x) were both analytic everywhere — it would be easy to walk away thinking every C^∞ function is. It isn't, and the counterexample closes this unit by showing exactly how the remainder term can refuse to vanish.

← Lesson 9 Lesson 11 → Contents Glossary →

Lemma — Exponential Decay Beats Any Power For every integer n ≥ 0, limx→0 e−1/x²/xⁿ = 0.
Proof Take x > 0 (the case x < 0 is identical by symmetry) and let u = 1/x², so u → ∞ as x → 0⁺. Then e−1/x²/xⁿ = e−u·uⁿ/2. Fix any integer m > n/2. Since eᵘ = Σk=0∞ uᵏ/k! (Lesson 9) and every term is positive for u > 0, the single term k = m gives eᵘ ≥ uᵐ/m!. So e−u ≤ m!/uᵐ, and e−u·uⁿ/2 ≤ m!·un/2 − m → 0 as u → ∞, since n/2 − m < 0. ∎
Why this lemma is the whole example, in miniature This is exactly the factorial-beats-exponential idea from Lesson 6 and Lesson 9's remainder bounds, turned around: there, factorial growth in the denominator forced a remainder to 0; here, the exponential's own Taylor series is reused to show e−1/x² decays faster than any power of x grows, as x → 0. That's strong enough decay to kill every derivative at 0 — which is exactly the trap.
Definition Let f(x) = e−1/x² for x ≠ 0, and f(0) = 0.
Claim — f is C^∞ at 0, and f(k)(0) = 0 for every k For x ≠ 0, each derivative f(k)(x) works out (by induction, differentiating with the chain rule at each step) to a polynomial in 1/x times e−1/x² — a finite sum of terms of the form 1/xᵐ · e−1/x². By the Lemma, every such term → 0 as x → 0, so f(k−1)(x) − f(k−1)(0) all → 0 as well, meaning each difference quotient [f(k−1)(h) − f(k−1)(0)]/h (itself a sum of terms 1/hᵐ⁺¹·e−1/h²) also → 0 as h → 0 by the Lemma. So f(k)(0) exists and equals 0, for every k.
Why f(0) = 0 is not a technicality The formula e−1/x² is not even defined at x = 0, so the value f(0) = 0 has to be built in by hand. But it's exactly the value the Lemma forces every derivative toward — this isn't a convenient choice competing with some other natural value; it's the only value under which f is even continuous at 0, let alone differentiable.
Conclusion — f is not analytic at 0 Since f(k)(0) = 0 for every k, f's Taylor series centered at 0 is Σk=0∞ 0·xᵏ = 0 — the identically-zero series, which trivially converges everywhere. But f(x) = e−1/x² ≠ 0 for every x ≠ 0. So the Taylor series converges on all of ℝ, yet equals f(x) only at the single point x = 0. f is C^∞ at 0 — infinitely differentiable, with no gap in the derivatives — but not analytic at 0.
Why this doesn't contradict Taylor's Theorem Taylor's Theorem (Lesson 9) still holds here — it guarantees a ξ making Rₙ(x) = f(n+1)(ξ)/(n+1)!·xⁿ⁺¹ exact, for every n. What fails is the strategy that worked for eˣ and sin(x): there, a single bound B on |f(n+1)| independent of n forced Rₙ(x) → 0. Here, the derivatives f(k)(x) for x near but not at 0 grow without any such uniform bound as k increases (the polynomial-in-1/x factor grows with k even as the exponential factor shrinks) — so the remainder is not forced to 0, and indeed cannot be, since Rₙ(x) = f(x) − 0 = f(x) ≠ 0 for every n when x ≠ 0. The theorem is silent about which case you're in; it only supplies the formula, not a guarantee that the formula shrinks.

Unit 2 in one line

Power series inherit uniform convergence automatically on compact subintervals (Lessons 6–7), which licenses term-by-term differentiation and integration (Lesson 8) and forces a power series's coefficients to be its own Taylor coefficients. Turning that around, a Taylor series can always be written down from a C^∞ function's derivatives (Lesson 9) — but as this lesson shows, writing it down is not the same as it converging back to the function. Analyticity is a genuinely stronger property than infinite differentiability, and the gap between them is exactly what e−1/x² lives in.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does the Lemma establish?

The Lemma shows the exponential decay term e^(−1/x²) beats any polynomial power of 1/x, forcing the ratio to 0 no matter how large n is.

2. What is f's Taylor series at 0, and what does f actually equal near 0?

Every derivative at 0 is 0, so the series is trivially 0 everywhere — while f itself is nonzero away from 0, so the series never equals f except at the single point 0.

3. Why doesn't this example contradict Taylor's Theorem from Lesson 9?

Taylor's Theorem always gives an exact remainder formula; whether that remainder vanishes as n grows is a separate question the theorem does not answer, and here it does not vanish.

4. Fill in the blank: e−1/x² is infinitely differentiable at 0 but not ___ at 0.

Being C^∞ does not imply analytic — this function is the standard example separating the two properties.

5. Fill in the blank: every derivative of e−1/x² at x = 0 equals ___.

The Lemma forces every derivative at 0 to vanish, making the Taylor series identically 0.
