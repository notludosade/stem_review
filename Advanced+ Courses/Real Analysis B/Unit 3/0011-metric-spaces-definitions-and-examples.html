Metric Spaces: Definitions and Examples

Real Analysis A did everything with |x − y|. This unit asks what actually made those arguments work — and the answer turns out to need almost nothing about ℝ at all.

← Lesson 10 Lesson 12 → Contents Glossary →

Every ε–δ argument in Real Analysis A used |x − y| as "the distance between x and y" — but it only ever used three facts about that quantity: it's never negative (and only 0 when x = y), it doesn't care about order (|x−y| = |y−x|), and it satisfies the triangle inequality. This lesson isolates exactly those three facts and studies any set equipped with a function that has them.

Definition — Metric Space A metric on a set X is a function d: X × X → ℝ satisfying, for all x, y, z ∈ X: (1) positivity: d(x,y) ≥ 0, with d(x,y) = 0 if and only if x = y; (2) symmetry: d(x,y) = d(y,x); (3) triangle inequality: d(x,z) ≤ d(x,y) + d(y,z). The pair (X, d) is called a metric space.
Why this is exactly the right generalization Nothing here mentions order, addition, or any algebraic structure on X at all — only the three properties an ε–δ argument actually consumes. Any proof from Real Analysis A that manipulated |x − y| using only positivity, symmetry, and the triangle inequality (which is most of them) carries over to any metric space verbatim, with d(x,y) in place of |x − y|. The rest of this unit will confirm this directly: convergence, continuity, and compactness all get redefined using d alone.
Example 1: ℝ with the absolute value metric d(x,y) = |x − y| on X = ℝ is a metric — this is precisely Real Analysis A's setting, now viewed as one example among many rather than the only possible one.
Example 2: the discrete metric On any set X whatsoever — no structure required, not even a notion of "number" — define d(x,y) = 0 if x = y, and d(x,y) = 1 if x ≠ y. Positivity and symmetry are immediate. For the triangle inequality: if x = z, the left side is 0 and the inequality holds trivially; if x ≠ z, the left side is 1, and the right side d(x,y) + d(y,z) is at least 1 (since y can't equal both x and z when x ≠ z, at least one term is 1). This is a genuine metric on any set — X could be a set of colors, or of prime numbers, or of anything at all.
Why the discrete metric matters It shows metric spaces are a strictly broader idea than "subsets of ℝ or ℝⁿ with the usual distance." A metric is any function satisfying the three axioms — the set X itself carries no built-in geometry. Everything geometric in a metric space comes entirely from d.
Example 3: C[a,b] with the sup metric Let X = C[a,b], the set of continuous functions on [a,b]. Define d(f,g) = supx∈[a,b]|f(x) − g(x)| (finite, since a continuous function on [a,b] is bounded). Positivity and symmetry are immediate from the same properties of the absolute value. For the triangle inequality: |f(x) − h(x)| ≤ |f(x) − g(x)| + |g(x) − h(x)| ≤ d(f,g) + d(g,h) for every x ∈ [a,b], so taking the supremum over x on the left gives d(f,h) ≤ d(f,g) + d(g,h).
Why this example is the whole point of the unit d(fₙ, f) = supx|fₙ(x) − f(x)| is exactly the quantity Unit 1 required to go to 0 for uniform convergence. In other words: fₙ → f uniformly on [a,b] means exactly fₙ → f in the metric space (C[a,b], d). Uniform convergence was never a special new idea — it was ordinary convergence, in a metric space whose points are entire functions rather than numbers. This unit will make that identification precise once "convergence in a metric space" is defined in Lesson 13.

1. Why does d(x,y) = (x − y)² fail to be a metric on ℝ?

(x−y)² is always non-negative and symmetric, but the specific numbers 0, 1, 2 show the triangle inequality genuinely fails.

2. What does the discrete metric demonstrate about metric spaces in general?

The discrete metric is defined on an arbitrary set with no assumed structure, showing the three axioms are all a metric space genuinely requires.

3. What does the sup metric d(f,g) on C[a,b] connect back to?

The sup metric's distance is literally the same quantity Unit 1 required to shrink to 0 for uniform convergence, reframing it as ordinary convergence in a function space.

4. Fill in the blank: d(x,z) ≤ d(x,y) + d(y,z) is called the ___ inequality.

This is the triangle inequality, the third of the three metric axioms.

5. Fill in the blank: the ___ metric assigns distance 0 to a point from itself and 1 to any two distinct points, and is defined on any set whatsoever.

The discrete metric is the standard name for this simplest possible metric on an arbitrary set.
