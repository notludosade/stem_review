Connectedness

Real Analysis A defined connectedness with closures and proved it means "interval" — for ℝ only. This lesson generalizes the definition, resolves a fact Lesson 12 deliberately left open, and proves the theorem that makes the Intermediate Value Theorem an instance of something much bigger.

← Lesson 15 Unit 4, Lesson 17 → Contents Glossary →

Definition — Separated Sets, Connected Two nonempty sets A, B ⊆ X are separated if Ā ∩ B = ∅ and A ∩ B̄ = ∅, using the closure of Lesson 12. A set E ⊆ X is connected if it cannot be written as E = A ∪ B for nonempty separated sets A, B; otherwise E is disconnected.
Why these definitions transfer unchanged This is exactly Real Analysis A's definition (Unit 3, Lesson 18), with Ē now Lesson 12's general closure instead of the closure of a subset of ℝ. Nothing in the definition of separation or connectedness ever used ℝ's order or algebra — only closure, which Lesson 12 already built for any metric space.
Theorem — The Clopen Characterization of Disconnection A metric space X is disconnected if and only if X has a nonempty proper subset that is clopen (both open and closed).
Proof (⇒) Suppose X = A ∪ B for nonempty separated A, B. First, A ∩ B = ∅: if x ∈ A ∩ B, then x ∈ B ⊆ B̄, so x ∈ A ∩ B̄, contradicting separation. Now, Ā ∩ B = ∅ and Ā ⊆ X = A ∪ B together force Ā ⊆ A; combined with the general fact A ⊆ Ā, this gives Ā = A, so A is closed. By the identical argument, B̄ = B, so B is closed. Since A ∩ B = ∅ and A ∪ B = X, B = X\A — so A, being closed with a closed complement, is also open. A is a nonempty, proper (since B is nonempty), clopen subset of X.

(⇐) Suppose U is a nonempty, proper, clopen subset of X. Let A = U and B = X\U. Since U is closed, Ā = U, so Ā ∩ B = U ∩ (X\U) = ∅. Since U is open, X\U is closed, so B̄ = B = X\U, giving A ∩ B̄ = U ∩ (X\U) = ∅. So A and B are separated, both nonempty (U is proper and nonempty), with A ∪ B = X. X is disconnected. ∎
Why this resolves what Lesson 12 flagged Lesson 12's discrete-metric example noted every subset is clopen, and promised that clopen sets were "exactly the obstruction to a metric space being connected." This theorem makes that precise: a space is disconnected exactly when it owns a clopen set that is neither ∅ nor the whole space.
Example: the discrete metric is always disconnected Let X carry the discrete metric (Lesson 11) with at least two points. Pick any point x ∈ X; {x} is clopen (Lesson 12: every subset of a discrete space is clopen), nonempty, and proper (since X has another point). By the theorem, X is disconnected. This matches intuition — a discrete space has no "gap-free" structure to hold it together at all.
Theorem — Continuous Images of Connected Sets Are Connected If f: X → Y is continuous and X is connected, then f(X) is connected.
Proof Suppose toward contradiction that f(X) is disconnected: f(X) = A ∪ B for nonempty separated A, B ⊆ Y. Let U = f⁻¹(A) and V = f⁻¹(B). Since A ∩ B = ∅ and A ∪ B = f(X), U and V partition X: disjoint, and U ∪ V = X. Both are nonempty, since A, B ⊆ f(X) are nonempty.

Claim: Ū ∩ V = ∅. Let x ∈ V, so f(x) ∈ B. Since Ā ∩ B = ∅, f(x) ∉ Ā — meaning some ball B(f(x), ε) contains no point of A (otherwise every ball around f(x) would meet A, making f(x) a limit point of A or a member of A, landing it in Ā). By continuity of f at x, some δ > 0 gives f(B(x,δ)) ⊆ B(f(x),ε). Since B(f(x),ε) ∩ A = ∅, no point of B(x,δ) maps into A — so B(x,δ) ∩ U = ∅. Thus x is not a limit point of U, and x ∉ U (since x ∈ V and U ∩ V = ∅), so x ∉ Ū. As x ∈ V was arbitrary, Ū ∩ V = ∅.

By the symmetric argument (swap A ↔ B, U ↔ V), U ∩ V̄ = ∅. So U and V are separated, nonempty, with U ∪ V = X — meaning X is disconnected. This contradicts the hypothesis. So f(X) must be connected. ∎
Why this theorem was worth waiting for Real Analysis A's Lesson 18 stated that "continuous functions preserve connectedness" as a fact to be proved "once continuity is defined" in full generality — and flagged this as the missing piece behind the Intermediate Value Theorem's "no gaps" intuition. Lesson 14's ε–δ definition of continuity in a metric space is exactly what this proof needed; the theorem above is that promise, kept.
Corollary: the Intermediate Value Theorem, recovered Let f: [a,b] → ℝ be continuous. Real Analysis A's characterization theorem (Unit 3, Lesson 18) says [a,b] is connected, since it's an interval. By the theorem just proved, f([a,b]) is therefore connected in ℝ. By that same characterization theorem applied again — this time to the image — a connected subset of ℝ is an interval. So f([a,b]) is an interval containing f(a) and f(b): every value between them is attained. That is exactly the Intermediate Value Theorem, now seen as one instance of "continuous images of connected sets are connected," a fact with nothing special to do with ℝ at all.

Unit 3 in one line: replace |x−y| with an abstract distance d, and open sets, convergence, continuity, compactness, and connectedness all survive intact — with completeness the one property that genuinely depends on which space you're in, and "closed and bounded implies compact" the one shortcut that depends on being in ℝⁿ specifically.

Check your recall

No peeking back up — answer from memory first, then check.

1. According to the Clopen Characterization theorem, when is a metric space disconnected?

A nonempty proper clopen subset is exactly the witness that splits the space into two separated pieces.

2. Why is every discrete metric space with two or more points disconnected?

Lesson 12 showed every subset of a discrete space is clopen; picking any single point gives a proper, nonempty, clopen witness to disconnection.

3. In the proof that continuous images of connected sets are connected, what tool produces the ball B(x,δ) with B(x,δ) ∩ U = ∅?

Continuity at x turns the ball around f(x) that misses A into a ball around x that misses U = f⁻¹(A).

4. Fill in the blank: a set that is both open and closed is called ___.

Clopen sets are exactly the obstruction to connectedness, per this lesson's characterization theorem.

5. Fill in the blank: the Intermediate Value Theorem is recovered as the special case of "continuous images of ___ sets are ___" applied to an interval (same word both blanks).

Connected is the property preserved by continuous images, and intervals are exactly the connected subsets of ℝ.
