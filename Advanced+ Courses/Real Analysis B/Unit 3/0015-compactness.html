Compactness

Real Analysis A proved compact and "closed and bounded" coincide for subsets of ℝ, and flagged that this was special. This lesson shows exactly how special — and gives a concrete function space where it genuinely fails.

← Lesson 14 Lesson 16 → Contents Glossary →

Definition — Sequentially Compact A set K ⊆ X in a metric space is sequentially compact if every sequence of points in K has a subsequence converging to a point also in K.
Definition — Open Cover, Compact An open cover of K is a collection of open sets whose union contains K. A finite subcover is a finite subcollection of these whose union still contains K. K is compact if every open cover of K has a finite subcover.
Why both definitions are unchanged from Real Analysis A These are exactly the two definitions from Real Analysis A, Unit 3, Lessons 16–17 — restated with K ⊆ X for a general metric space instead of K ⊆ ℝ. Neither definition ever referenced ℝ's algebra, only convergence, sequences, and open sets — all of which Lessons 12–14 already generalized.
Theorem — Compact Implies Sequentially Compact In any metric space, if K is compact, then K is sequentially compact.
Proof Suppose K is compact, and let (xₙ) be a sequence in K. Suppose toward contradiction that no subsequence of (xₙ) converges to a point of K. Then for every x ∈ K, x is not the limit of any subsequence, so there is some rx > 0 such that B(x, rx) contains xₙ for only finitely many indices n (otherwise infinitely many terms would lie in every ball around x, letting a subsequence be extracted converging to x). The collection {B(x, rx) : x ∈ K} is an open cover of K. By compactness, finitely many of these balls, say around x₁, …, xk, already cover K. But each such ball contains only finitely many terms of the sequence, so their union contains only finitely many terms in total. Yet every xₙ lies in K, hence in this union — and the sequence has infinitely many terms (indices). Finitely many balls cannot contain infinitely many distinct terms without some ball repeating infinitely often, which contradicts "only finitely many terms" for every ball in the finite subcover. This contradiction shows some subsequence must converge to a point of K — K is sequentially compact. ∎
Why the converse is stated, not proved, here The reverse direction — sequentially compact implies compact — is also true in any metric space, making the two notions fully equivalent. But its proof needs an extra idea not yet built here, total boundedness (roughly: K can be covered by finitely many balls of any fixed radius, how ever small), combined with a Lebesgue-number argument extending covers built from small balls into a genuine finite subcover of any open cover. Both directions together are proved in full in Rudin's Principles of Mathematical Analysis, Chapter 2 — this course states the equivalence and uses it, but the deeper direction is left to that source rather than re-derived here.
Theorem (stated) — Generalized Heine-Borel, for ℝⁿ A set K ⊆ ℝⁿ (with the Euclidean metric) is compact if and only if K is closed and bounded.
Why this is the same proof as Real Analysis A, one dimension heavier Real Analysis A's Heine-Borel proof (Unit 3, Lesson 17) bisected an interval in half at each step, using the pigeonhole principle to always keep a half that resists a finite subcover. The ℝⁿ version runs the identical argument, subdividing a box into 2ⁿ sub-boxes at each step instead of an interval into 2 halves — still finitely many pieces, so the same pigeonhole conclusion holds. The extra dimensions change nothing about the logic, only the bookkeeping.
Why "closed and bounded" is special to ℝⁿ — and genuinely fails elsewhere The equivalence compact ⟺ sequentially compact holds in every metric space, with no exceptions. The stronger fact — that closed and bounded alone is enough — depends on ℝⁿ's specific structure, and fails outright once the space is infinite-dimensional.
Example: a closed, bounded, non-compact set in C[0,1] Let B = {f ∈ C[0,1] : d(f, 0) ≤ 1} be the closed unit ball in (C[0,1], dsup) — closed by definition (it's exactly the set where a certain distance is ≤ 1) and bounded (every f ∈ B satisfies d(f,0) ≤ 1). Let fₙ(x) = xⁿ; each fₙ ∈ B, since 0 ≤ xⁿ ≤ 1 on [0,1]. Suppose some subsequence (fnk) converged in this metric — i.e. uniformly — to some f ∈ C[0,1]. Uniform convergence forces pointwise convergence to the same limit, but fnk(x) = xnk → 0 for every x ∈ [0,1) and → 1 at x = 1 — a discontinuous pointwise limit. By Unit 1, Lesson 3, a uniform limit of continuous functions must be continuous, contradicting this pointwise limit's discontinuity. So no subsequence of (fₙ) converges in (C[0,1], d) at all — B is not sequentially compact, hence (by the equivalence above) not compact, despite being closed and bounded.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does the proof that compact implies sequentially compact construct, for a sequence with no convergent subsequence?

The contradiction comes from finitely many "escape balls," each capturing only finitely many terms, being unable to jointly contain an infinite sequence.

2. What extra idea does the converse (sequentially compact implies compact) require, beyond what this lesson proves?

Total boundedness plus a Lebesgue-number style argument is the missing ingredient for the harder direction, left to the cited source.

3. What does the closed unit ball in C[0,1] example demonstrate?

fₙ(x) = xⁿ lies in the closed unit ball but has no subsequence converging in the sup metric, since any pointwise limit of a subsequence would be discontinuous — contradicting Unit 1's continuity theorem.

4. Fill in the blank: a set where every sequence has a subsequence converging within the set is called ___ compact.

Sequentially compact is the sequence-based definition, proved equivalent to the open-cover definition of compact.

5. Fill in the blank: K is compact if every open cover of K has a ___ subcover.

The finite-subcover property is the open-cover definition of compactness.
