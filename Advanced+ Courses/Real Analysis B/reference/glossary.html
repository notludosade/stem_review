Unit 1 — Uniform Convergence

Pointwise convergence

fₙ → f pointwise if fₙ(x) → f(x) for every fixed x, with the rate of convergence allowed to depend on x — the weaker of the two convergence notions for sequences of functions.

Uniform convergence

fₙ → f uniformly if sup_x|fₙ(x) − f(x)| → 0 — a single rate of convergence that works for every x at once, strong enough to preserve continuity and integrability.

Weierstrass M-Test

If |fₙ(x)| ≤ Mₙ for every x and ∑Mₙ converges, then ∑fₙ converges uniformly — turns a function-series convergence check into an ordinary numerical series check.

Uniform limit of continuous functions

If fₙ → f uniformly and each fₙ is continuous, then f is continuous — the theorem that makes uniform convergence worth the extra hypothesis.

Unit 2 — Power Series

Power series

A series of the form ∑aₙ(x−c)ⁿ — a series of functions of a very restricted kind, whose set of convergence is forced to be an interval centered at c.

Radius of convergence

The value R such that a power series converges absolutely for |x−c| < R and diverges for |x−c| > R, with the endpoints requiring separate checking.

Analytic function

A function equal to its own Taylor series in some neighborhood of every point — strictly stronger than being infinitely differentiable (C^∞).

Taylor series

The power series ∑f⁽ⁿ⁾(c)/n!·(x−c)ⁿ built from a function's derivatives at c — guaranteed to match a power series's own coefficients wherever that series converges, but not guaranteed to converge back to an arbitrary C^∞ function.

Unit 3 — Metric Spaces

Metric space

A set X with a distance function d(x,y) satisfying nonnegativity, symmetry, the triangle inequality, and d(x,y)=0 exactly when x=y — the minimal structure Real Analysis A's ℝ-arguments actually needed.

Open ball

Bᵣ(x) = {y ∈ X : d(x,y) < r} — the metric-space replacement for an ε-neighborhood, from which open sets, closed sets, and limit points are all built.

Complete metric space

A metric space in which every Cauchy sequence converges to a point of the space — not automatic in general, and genuinely false in some natural function spaces.

Continuity (topological)

f: X → Y is continuous if the preimage of every open set is open — equivalent to the ε–δ definition, but expressible with no numbers at all.

Compactness (sequential)

Every sequence in the space has a subsequence converging to a point of the space — equivalent to "closed and bounded" only in ℝⁿ, and genuinely different in general metric spaces.

Connectedness

A space that cannot be split into two disjoint nonempty open sets — the property underlying the Intermediate Value Theorem, generalized past intervals of ℝ.

Unit 4 — Multivariable Differentiation

Partial derivative

The derivative of a multivariable function along a single coordinate direction, holding all others fixed — necessary but not sufficient for genuine differentiability.

Total derivative

A linear map Df(a) such that f(a+h) = f(a) + Df(a)h + o(|h|) as h→0 — the single best linear approximation in every direction at once, strictly stronger than existence of all partial derivatives.

Jacobian matrix

The matrix of partial derivatives representing the total derivative Df(a) in coordinates — composing two differentiable functions multiplies their Jacobians, exactly.

Clairaut's Theorem

If the mixed partials ∂²f/∂x∂y and ∂²f/∂y∂x are both continuous near a point, they're equal there — continuity of the mixed partials is genuinely necessary, not just a technicality.

Inverse Function Theorem

If Df(a) is invertible, f is locally invertible near a with a differentiable inverse — the multivariable generalization of "nonzero derivative implies local invertibility," with the Jacobian standing in for the derivative.

Unit 5 — Lebesgue Measure

Outer measure

m*(A) = inf of ∑ℓ(Iₙ) over all countable interval covers of A — assigns every subset of ℝ a size, agrees with ordinary length on intervals, and gives ℚ measure zero.

Carathéodory measurability criterion

A set E is measurable if m*(A) = m*(A∩E) + m*(A∩Eᶜ) for every test set A — the condition isolating exactly the sets on which outer measure behaves additively.

Sigma-algebra

A collection of sets closed under complements and countable unions (hence countable intersections too) — the measurable sets form one, rich enough to contain every open set.

Countable additivity

m(⋃Eₙ) = ∑m(Eₙ) for any countable collection of disjoint measurable sets — the property that makes Lebesgue measure a genuine measure, not just a size assignment.

Measure-zero set / almost everywhere

A set E with m(E)=0; a property holding "almost everywhere" (a.e.) holds except possibly on a measure-zero set — the language that finally explains why Dirichlet's function is Riemann-non-integrable but Lebesgue-trivial.

Measurable function

f: ℝ → ℝ such that {f>c} is measurable for every c — unlike Riemann integrability, this property survives every pointwise limit of measurable functions unconditionally.

Unit 6 — The Lebesgue Integral

Simple function

A measurable function taking only finitely many values — the building block the Lebesgue integral is defined from first, then extended by approximation.

Lebesgue integral (nonnegative f)

∫fdm = sup{∫φdm : φ simple, 0≤φ≤f} — defined via approximation from below by simple functions, requiring no partition of the domain into intervals at all.

Positive and negative parts

f⁺ = max(f,0), f⁻ = max(−f,0), so f = f⁺−f⁻ and |f| = f⁺+f⁻ — the device that extends the nonnegative-function integral to functions taking both signs.

Lebesgue integrability

f is Lebesgue integrable if ∫f⁺dm and ∫f⁻dm are both finite, equivalently if ∫|f|dm < ∞ — strictly more functions qualify than under Riemann's definition, with full agreement wherever both apply.

Monotone Convergence Theorem (MCT)

If 0≤fₙ↗f pointwise, then lim∫fₙdm = ∫fdm — the tool that lets a limit pass through a Lebesgue integral whenever the sequence increases, no uniform convergence required.

Fatou's Lemma

∫(liminf fₙ)dm ≤ liminf∫fₙdm for nonnegative measurable fₙ — an inequality only, since mass can escape in the limit but never appear from nowhere.

Dominated Convergence Theorem (DCT)

If fₙ→f pointwise and |fₙ|≤g for a fixed integrable g, then lim∫fₙdm = ∫fdm — replaces MCT's monotonicity requirement with domination by a single integrable function.
