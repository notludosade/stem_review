1. Let fₙ(x) = sin(x)/n on ℝ. What is true about (fₙ) and (fₙ′)?

Here n only scales the outer amplitude, so both fₙ and fₙ′ = cos(x)/n converge uniformly to 0.

2. Fill in the blank: let g(x) = Σ e⁻ⁿ sin(nx) on ℝ. Since |sin(nx)| ≤ 1 and Σe⁻ⁿ converges, the M-test gives uniform convergence, so g is ___ on ℝ.

Uniform convergence of continuous partial sums forces the sum function to be continuous.

3. Which statement correctly relates a power series's radius of convergence to its interval of convergence?

The radius alone only pins down the open interval of guaranteed absolute convergence; endpoints must be checked separately.

4. Fill in the blank: since a power series's coefficients are forced to equal its own Taylor coefficients, every power series is automatically ___ at its center.

Since f already equals its Taylor series on its interval of convergence, it is analytic there by definition.

5. What is the unifying theme of generalizing from ℝ to metric spaces?

Most machinery only ever used the three metric axioms and transfers verbatim — but completeness and compactness-equivalence genuinely depend on which space you're in.

6. Fill in the blank: the closed unit ball in C[0,1] under the sup metric is closed and bounded but not compact — since fₙ(x)=xⁿ has no uniformly convergent subsequence. This shows "closed and bounded implies compact" is special to ___-dimensional Euclidean space.

The Heine-Borel theorem is stated only for ℝⁿ; it fails in infinite-dimensional spaces like C[0,1].

7. Let f: ℝ² → ℝ³ be given by f(x,y) = (x²+y, xy, y²−x). What is the Jacobian matrix Df(1,2)?

Each row is the gradient of a component: ∇(x²+y)=(2x,1), ∇(xy)=(y,x), ∇(y²−x)=(−1,2y); evaluated at (1,2) these give the rows shown.

8. Fill in the blank: for g(x,y) = (x², xy), Dg(2,1) = [[4,0],[1,2]], det = 8 ≠ 0. This means the Jacobian is ___, so g has a local C¹ inverse near (2,1) by the Inverse Function Theorem.

A nonzero determinant means the Jacobian is invertible, exactly what the Inverse Function Theorem needs.

9. Why does outer measure m* fail to be a genuine (countably additive) measure on every subset of ℝ?

Vitali sets break countable additivity — exactly why the measurable sets are isolated as a smaller, well-behaved collection.

10. Fill in the blank: for E = ℚ∩[0,3] and test set A = [0,3], m*(A∩E) + m*(A\E) = 0 + 3 = 3 = m*(A). This equality for every test set confirms E satisfies the ___ criterion for measurability.

This equality holding for every test set A is exactly the Carathéodory criterion.

11. For a nonnegative measurable function f and measurable set E, ∫_E f dm is defined as:

Approximating f from below by simple functions and taking the supremum of their integrals is Lebesgue's construction, made precise.

12. Fill in the blank: let fₙ = χ_[0,n], increasing to f = χ_[0,∞). Then lim ∫fₙ dm = ∞, matching ∫f dm = ∞. This shows MCT allows the common limit value L to be ___ (an extended real number), not only finite.

MCT's proof explicitly allows the common limit to be +∞, as when the increasing sequence has no finite integral bound.
