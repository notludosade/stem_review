The Inverse and Implicit Function Theorems

Single-variable calculus says a function with nonzero derivative is locally invertible. This capstone lesson generalizes that fact with the Jacobian in place of the derivative — and shows implicit differentiation, a technique from prerequisite calculus, was quietly leaning on it the whole time.

← Lesson 20 Unit 5, Lesson 22 → Contents Glossary →

Why this starts from a single-variable fact From single-variable calculus: if f is C¹ near a and f'(a) ≠ 0, then f is invertible on some interval around a, its inverse is differentiable, and (f⁻¹)'(f(a)) = 1/f'(a). The condition f'(a) ≠ 0 is a 1×1 matrix being invertible. The Inverse Function Theorem below is exactly this fact with "matrix invertible" replacing "nonzero."
Theorem (stated) — The Inverse Function Theorem Let f: ℝⁿ → ℝⁿ be C¹ (all partial derivatives exist and are continuous) in a neighborhood of a, and suppose Df(a) is an invertible matrix. Then there is a neighborhood U of a and a neighborhood V of f(a) such that f: U → V is a bijection, its inverse f⁻¹: V → U is also C¹, and D(f⁻¹)(f(a)) = [Df(a)]⁻¹.
Why this theorem is only stated, not proved, here Its proof genuinely needs a tool this course hasn't built: the Contraction Mapping (Banach Fixed Point) Theorem, used to construct the local inverse as the fixed point of an iterative scheme, followed by an estimate showing that fixed point varies continuously (in fact C¹) with the input. This is a substantial, self-contained piece of machinery — proved in full in the source reading below — genuinely beyond what's practical to build from scratch in one lesson.
Theorem — The Implicit Function Theorem (a special case, derived from the Inverse Function Theorem) Let F: ℝ² → ℝ be C¹ near (a,b), with F(a,b) = 0 and ∂F/∂y(a,b) ≠ 0. Then there is an interval around a and a C¹ function g defined on it, with g(a) = b, such that F(x, g(x)) = 0 for all x in that interval, and

g'(x) = − [∂F/∂x(x,g(x))] / [∂F/∂y(x,g(x))].
Proof (assuming the Inverse Function Theorem) Define Φ: ℝ² → ℝ² by Φ(x,y) = (x, F(x,y)). Its Jacobian is DΦ(x,y) = [[1, 0], [∂F/∂x, ∂F/∂y]], with determinant ∂F/∂y — nonzero at (a,b) by hypothesis, so DΦ(a,b) is invertible. Since F is C¹, so is Φ. By the Inverse Function Theorem, Φ has a C¹ local inverse Φ⁻¹ near Φ(a,b) = (a, 0).

Because Φ never changes its first coordinate, Φ⁻¹ can't either: Φ⁻¹(x, z) = (x, g(x, z)) for some C¹ function g. Define g(x) = g(x, 0). Then Φ(x, g(x)) = Φ(Φ⁻¹(x,0)) = (x, 0), and by the definition of Φ, this says (x, F(x, g(x))) = (x, 0) — so F(x, g(x)) = 0 for every x near a, with g(a) = b since Φ(a,b) = (a,0) means Φ⁻¹(a,0) = (a,b). Since Φ⁻¹ is C¹, so is g.

For the derivative formula, differentiate F(x, g(x)) = 0 with respect to x using the Chain Rule (Lesson 19), treating x ↦ (x, g(x)) as a map into ℝ²: ∂F/∂x(x,g(x))·1 + ∂F/∂y(x,g(x))·g'(x) = 0. Since ∂F/∂y(a,b) ≠ 0 (and by continuity, ∂F/∂y(x,g(x)) ≠ 0 for x near a), solving gives g'(x) = −∂F/∂x(x,g(x)) / ∂F/∂y(x,g(x)). ∎
Why this is a satisfying place to end the unit Implicit differentiation — treating y as a function of x inside an equation F(x,y) = 0 and differentiating both sides — is a computational technique from prerequisite calculus. The proof above shows exactly why it's valid: F(x,y)=0 genuinely does define y as a C¹ function of x near any point where ∂F/∂y ≠ 0, and the formula g'(x) = −Fₓ/F_y is not a trick but a direct consequence of the chain rule applied to that function's existence. A technique used without proof before this course now has one, built from the Inverse Function Theorem and Lesson 19's chain rule together.

Unit 4 in one line: partial derivatives alone can be misleading, but once a single linear map (the total derivative, represented by the Jacobian) captures every direction at once, differentiability in several variables recovers continuity, a chain rule, a theory of higher-order derivatives, and — where the Jacobian is invertible — local invertibility, exactly as in one variable.

1. What does the Inverse Function Theorem require of Df(a)?

An invertible Jacobian at a is the direct generalization of a nonzero derivative in one variable.

2. How is the Implicit Function Theorem derived from the Inverse Function Theorem in this lesson?

Φ's first coordinate is forced to stay x, so its local inverse's second coordinate function, evaluated at z=0, is exactly the implicit function g.

3. Where does the formula g'(x) = −Fₓ/F_y come from?

The chain rule applied to F(x,g(x))=0 gives Fₓ + F_y·g'(x) = 0, which rearranges directly to the implicit differentiation formula.

4. Fill in the blank: the Inverse Function Theorem's key hypothesis is that the Jacobian matrix be ___ at the point.

An invertible Jacobian is exactly what's needed to guarantee a local inverse exists.

5. Fill in the blank: the technique of differentiating an equation F(x,y)=0 to find dy/dx, now justified by this lesson's theorem, is called ___ differentiation.

Implicit differentiation is the prerequisite-calculus technique that the Implicit Function Theorem rigorously justifies.
