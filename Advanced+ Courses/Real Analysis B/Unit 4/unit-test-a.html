1. Let f(x,y) = x³y². What is ∂f/∂x(2,1)?

Freezing y and differentiating in x gives ∂f/∂x = 3x²y². At (2,1): 3·4·1 = 12. (∂f/∂y = 2x³y = 16 at that point, a common mix-up.)

2. Let g(x,y) = x²y/(x⁴+y²) for (x,y) ≠ (0,0), and g(0,0) = 0. Answer both parts:

(a) What are ∂g/∂x(0,0) and ∂g/∂y(0,0)?

(b) Fill in the blank: along the path y = x², g(x,x²) = x⁴/(2x⁴) = 1/2 for every x ≠ 0, which does not approach g(0,0) = 0 — so g is ___ at the origin, despite both partials existing there.

(a) g(h,0) = 0/h⁴ = 0 and g(0,k) = 0/k² = 0 for every h,k ≠ 0, so both partials at the origin are 0. (b) Approaching along the parabola y = x² gives a limit of 1/2, not g(0,0) = 0, so g is discontinuous at the origin — the partials, which only see the coordinate axes, miss this entirely.

3. If f is differentiable at a with total derivative L = Df(a), which limit condition is guaranteed to hold?

This little-o error condition is exactly what makes L the best linear approximation to f near a, in every direction h at once — not just along the coordinate axes.

4. Suppose all partial derivatives of f: ℝⁿ → ℝ exist near a and are continuous at a. Answer both parts:

(a) What can be concluded?

(b) Fill in the blank: total differentiability of f at a always implies f is ___ at a — something mere existence of partial derivatives does not guarantee (Lesson 17's counterexample).

(a) This is the C¹-implies-differentiable theorem, proved via the single-variable Mean Value Theorem applied one coordinate at a time. (b) Differentiability always forces continuity, exactly restoring what partial derivatives alone could not guarantee.

5. Let g(x,y) = (x+y, x−y) and f(u,v) = u² − v². Answer both parts about f∘g:

(a) What is Dg(x,y), the Jacobian matrix of g?

(b) Fill in the blank: by the chain rule, D(f∘g)(1,3) = Df(g(1,3))·Dg(1,3) is a 1×2 row matrix. Its first entry equals ___.

(a) g's partials are all constants: ∂(x+y)/∂x = 1, ∂(x+y)/∂y = 1, ∂(x−y)/∂x = 1, ∂(x−y)/∂y = −1. (b) g(1,3) = (4,−2), and Df(u,v) = [2u, −2v], so Df(4,−2) = [8, 4]. Then D(f∘g)(1,3) = [8,4]·[[1,1],[1,−1]] = [12, 4] — matching direct differentiation of f∘g(x,y) = 4xy, whose ∂/∂x = 4y = 12 at (1,3).

6. If n = m = k = 1 in the Multivariable Chain Rule D(f∘g)(a) = Df(g(a))·Dg(a), what single-variable statement does it reduce to?

In one dimension the Jacobian "matrices" are just the numbers f′(g(a)) and g′(a), and matrix multiplication becomes ordinary multiplication — recovering the familiar chain rule exactly.

7. Let h(x,y) = x⁴y³. Answer both parts:

(a) What is ∂²h/∂x∂y at (1,2)?

(b) Fill in the blank: this computation illustrates Clairaut's Theorem, because h's mixed partials, being polynomials, are ___ everywhere, guaranteeing ∂²h/∂x∂y = ∂²h/∂y∂x.

(a) ∂h/∂y = 3x⁴y², so ∂²h/∂x∂y = 12x³y², which at (1,2) is 12·1·4 = 48. (Checking the other order: ∂h/∂x = 4x³y³, so ∂²h/∂y∂x = 12x³y², the same expression, confirming agreement.) (b) Polynomials are continuous everywhere, exactly the hypothesis Clairaut's Theorem needs.

8. The example f(x,y) = xy(x²−y²)/(x²+y²), f(0,0) = 0, has ∂²f/∂x∂y(0,0) = 1 but ∂²f/∂y∂x(0,0) = −1. What allows this disagreement?

Clairaut's Theorem requires the mixed partials to be continuous at the point to force equality; here both mixed partials exist everywhere but are discontinuous exactly at the origin, which is exactly where they disagree.

9. Let f(x,y) = (x+y, x²+y). Answer both parts:

(a) What is det Df(1,1)?

(b) Fill in the blank: since det Df(1,1) ≠ 0, the Jacobian matrix is ___, so by the Inverse Function Theorem f has a local C¹ inverse near (1,1).

(a) Df(x,y) = [[1,1],[2x,1]], so Df(1,1) = [[1,1],[2,1]], with determinant 1·1 − 1·2 = −1. (b) A nonzero determinant means the Jacobian matrix is invertible, exactly the hypothesis the Inverse Function Theorem requires.

10. Fill in the blank: because F(x,y) = 0 genuinely defines y as a C¹ function of x near any point where ∂F/∂y ≠ 0, the classical technique of ___ differentiation — differentiating an equation without first solving for y — is now rigorously justified.

Implicit differentiation is the prerequisite-calculus technique the Implicit Function Theorem, derived from the Inverse Function Theorem, now justifies in full.
