The Lebesgue Integral of Simple Functions

Unit 5 built measure. This lesson starts spending it: defining an integral for the simplest measurable functions, then extending it to every nonnegative measurable function by approximation — closing the loop opened three lessons ago.

← Unit 5, Lesson 26 Lesson 28 → Contents Glossary →

Definition — Simple Function A measurable function φ: ℝ → ℝ is simple if it takes only finitely many distinct values.
Definition — Canonical Form If φ is simple with distinct values a₁,…,aₙ, let Eᵢ = {x : φ(x) = aᵢ}. Each Eᵢ is measurable (Eᵢ = {φ≥aᵢ} ∩ {φ≤aᵢ}, an intersection of measurable sets), the Eᵢ are pairwise disjoint, and their union is the whole domain. Writing φ = Σᵢ₌₁ⁿ aᵢχ_{Eᵢ} in this form is φ's canonical form.
Definition — Integral of a Nonnegative Simple Function For φ = Σᵢ₌₁ⁿ aᵢχ_{Eᵢ} in canonical form with each aᵢ ≥ 0, and a measurable set E, define

∫_E φ dm = Σᵢ₌₁ⁿ aᵢ · m(Eᵢ∩E).
Theorem — Well-Definedness Under Any Disjoint Representation If φ = Σⱼ₌₁ᵏ bⱼχ_{Fⱼ} for any pairwise disjoint measurable sets F₁,…,F_k with bⱼ ≥ 0 (and φ = 0 off ⋃Fⱼ), then Σⱼbⱼm(Fⱼ∩E) equals ∫_E φ dm as computed from the canonical form.
Proof Let φ = Σᵢaᵢχ_{Eᵢ} be the canonical form. Each Eᵢ = ⋃ⱼ (Eᵢ∩Fⱼ), a disjoint union, so by finite additivity (Unit 5, Lesson 25), m(Eᵢ∩E) = Σⱼm(Eᵢ∩Fⱼ∩E). Then

Σᵢaᵢm(Eᵢ∩E) = ΣᵢΣⱼaᵢm(Eᵢ∩Fⱼ∩E).

On any Eᵢ∩Fⱼ that is nonempty, φ equals both aᵢ and bⱼ there, so aᵢ = bⱼ; when Eᵢ∩Fⱼ is empty, the term m(Eᵢ∩Fⱼ∩E) is 0 regardless. So every term aᵢm(Eᵢ∩Fⱼ∩E) equals bⱼm(Eᵢ∩Fⱼ∩E), and

ΣᵢΣⱼaᵢm(Eᵢ∩Fⱼ∩E) = ΣᵢΣⱼbⱼm(Eᵢ∩Fⱼ∩E) = ΣⱼbⱼΣᵢm(Eᵢ∩Fⱼ∩E) = Σⱼbⱼm(Fⱼ∩E),

using finite additivity again in the last step (Fⱼ = ⋃ᵢ(Eᵢ∩Fⱼ), disjoint). So Σⱼbⱼm(Fⱼ∩E) = Σᵢaᵢm(Eᵢ∩E). ∎
Why well-definedness has to be proved at all A simple function can be written as a combination of indicators in more than one way — for instance combining two simple functions produces a natural representation that isn't automatically the canonical one. Without this theorem, ∫φdm might depend on which representation happened to be written down; the common-refinement argument above shows it never does.
Theorem — Linearity and Monotonicity of the Simple Integral For nonnegative simple functions φ, ψ and constant c ≥ 0: ∫_E(cφ)dm = c∫_Eφdm; ∫_E(φ+ψ)dm = ∫_Eφdm + ∫_Eψdm; and if φ ≤ ψ everywhere, ∫_Eφdm ≤ ∫_Eψdm.
Why these follow from well-definedness Given canonical forms φ=Σaᵢχ_{Eᵢ} and ψ=Σbⱼχ_{Fⱼ}, the sets Eᵢ∩Fⱼ form a common disjoint refinement on which both φ and ψ are constant; φ+ψ equals the (generally non-canonical) simple function Σᵢⱼ(aᵢ+bⱼ)χ_{Eᵢ∩Fⱼ}, and the well-definedness theorem computes its integral as ΣᵢⱼaᵢM(Eᵢ∩Fⱼ∩E) + ΣᵢⱼbⱼM(Eᵢ∩Fⱼ∩E) = ∫φdm + ∫ψdm. Monotonicity and scaling follow the same way, term by term on the common refinement. The full bookkeeping is in the source reading below.
Example — Dirichlet's function, finally integrated Dirichlet's function f(x) = 1 for x∈ℚ, 0 for x∉ℚ is itself a simple function: f = 1·χ_ℚ + 0·χ_{[0,1]\ℚ}, already in canonical form (ℚ∩[0,1] and its complement are both measurable, by Unit 5). Its integral over [0,1] is

∫₀¹ f dm = 1 · m(ℚ∩[0,1]) + 0 · m([0,1]\ℚ) = 1 · 0 + 0 · 1 = 0.
Why this is the payoff promised in Lesson 22 Lesson 22 showed Dirichlet's function is bounded, "simple-looking," and yet not Riemann integrable at all — no upper or lower Darboux sum ever converges. Here, with the Lebesgue integral, it isn't just integrable — it's one of the easiest functions to integrate, precisely because m(ℚ) = 0 makes the value-1 piece invisible to measure. The gap opened four lessons ago is now closed in full.
Definition — Integral of a Nonnegative Measurable Function For a measurable function f ≥ 0 and measurable set E, define

∫_E f dm = sup { ∫_E φ dm : φ simple, 0 ≤ φ ≤ f everywhere }.
Why this recovers "partitioning the range," as previewed in Lesson 22 A simple function beneath f is exactly a finite partition of f's range into value-bands, each paired with the (measurable) set of points landing in that band. Taking the supremum over all such simple functions beneath f is the rigorous version of "chop the range into pieces, measure how much of the domain lands in each piece, and refine" — Lebesgue's idea, made precise.

When f is itself simple, this new definition agrees with the simple-function integral already defined: φ = f is one of the candidates in the supremum, and monotonicity shows no simple ψ ≤ f can give a strictly larger integral — so the supremum is attained exactly at ∫_Efdm as already defined.

1. What is a simple function?

Finitely many values, each attained on a measurable set, is exactly the simple-function definition.

2. Why does the well-definedness theorem need to be proved?

The common-refinement argument shows any valid disjoint representation gives the same integral value.

3. What is ∫₀¹ f dm for Dirichlet's function f?

Since the set where f=1 has measure zero, its contribution to the integral vanishes entirely.

4. Fill in the blank: the integral of a nonnegative measurable f is defined as the sup of integrals of ___ functions bounded above by f.

Approximating from below by simple functions is exactly how the general nonnegative integral is defined.

5. Fill in the blank: writing φ = Σaᵢχ_{Eᵢ} using the distinct values of φ is called the ___ form.

Canonical form uses φ's own distinct values to build a unique disjoint representation.
