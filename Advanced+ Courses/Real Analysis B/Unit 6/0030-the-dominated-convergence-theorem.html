The Dominated Convergence Theorem

MCT needed monotonicity. This lesson drops that requirement entirely — replacing it with a single dominating integrable function — and finally builds, in full, the counterexample Lesson 4 called "beyond this course's scope."

← Lesson 29 Lesson 31 → Contents Glossary →

Example — the moving bump, finally constructed Let fₙ = n·χ_{(0,1/n)}. For every fixed x > 0, once n > 1/x the interval (0,1/n) no longer contains x, so fₙ(x) = 0 eventually; and fₙ(0) = 0 always. So fₙ → 0 pointwise everywhere. Yet ∫fₙdm = n·m((0,1/n)) = n·(1/n) = 1 for every single n. So lim∫fₙdm = 1 ≠ 0 = ∫(lim fₙ)dm.
Why this is Lesson 4's promise kept Lesson 4 (Unit 1) needed a "moving bump" — height growing, width shrinking, area fixed — to show pointwise convergence alone can't justify swapping a limit with an integral, and called its full construction "beyond this course's scope" at the time, since Riemann integration had no simple language for it. Here, the same idea is a two-line computation: a rectangle of height n and width 1/n has area 1 regardless of n, and Lebesgue measure computes that area exactly. The obstruction is visible immediately: fₙ is not dominated by any single integrable function, since sup_n fₙ(x) grows like 1/x near 0, and ∫₀¹(1/x)dx diverges.
Lemma — Fatou's Lemma If f₁, f₂, f₃, … ≥ 0 are measurable, then ∫(liminf_n fₙ)dm ≤ liminf_n ∫fₙdm.
Proof Let gₖ = inf_{n≥k}fₙ, measurable and nonnegative (Lesson 26), and increasing in k (a larger k takes an infimum over fewer terms). By definition, gₖ → liminf_n fₙ pointwise, so MCT gives ∫(liminf_nfₙ)dm = limₖ∫gₖdm.

For every n ≥ k, gₖ ≤ fₙ (gₖ is an infimum including the fₙ term), so ∫gₖdm ≤ ∫fₙdm by monotonicity, for every n ≥ k. Taking the infimum over n≥k on the right: ∫gₖdm ≤ inf_{n≥k}∫fₙdm. Letting k → ∞: limₖ∫gₖdm ≤ limₖ(inf_{n≥k}∫fₙdm) = liminf_n∫fₙdm.

Combining, ∫(liminf_nfₙ)dm ≤ liminf_n∫fₙdm. ∎
Why Fatou's Lemma is only an inequality The moving bump above shows equality can genuinely fail: liminf_nfₙ = 0 (the limit exists and is 0), so ∫(liminf fₙ)dm = 0, while liminf_n∫fₙdm = 1. Fatou's Lemma says the integral of the liminf can never exceed the liminf of the integrals — mass can disappear in the limit (as it does here, escaping to a shrinking sliver near 0), but it can never appear from nowhere.
Theorem — Dominated Convergence Theorem (DCT) Let f₁, f₂, f₃, … be measurable with fₙ(x) → f(x) for every x, and suppose there is an integrable g ≥ 0 (∫gdm < ∞) with |fₙ(x)| ≤ g(x) for every n and every x. Then f is integrable and

limₙ→∞ ∫fₙdm = ∫f dm.
Proof Since |fₙ| ≤ g for every n and fₙ → f, taking the limit gives |f| ≤ g, so ∫|f|dm ≤ ∫gdm < ∞ and f is integrable (Lesson 28).

Both g+fₙ ≥ 0 and g−fₙ ≥ 0 (from |fₙ|≤g), so Fatou's Lemma applies to each. Applying it to g+fₙ, whose pointwise limit is g+f:

∫(g+f)dm ≤ liminf_n∫(g+fₙ)dm.

By additivity (Lesson 29), ∫(g+f)dm = ∫gdm+∫fdm and ∫(g+fₙ)dm = ∫gdm+∫fₙdm, so this reads ∫gdm+∫fdm ≤ ∫gdm + liminf_n∫fₙdm. Since ∫gdm < ∞, it cancels from both sides: ∫fdm ≤ liminf_n∫fₙdm.

Applying Fatou's Lemma to g−fₙ, whose pointwise limit is g−f:

∫(g−f)dm ≤ liminf_n∫(g−fₙ)dm = ∫gdm − limsup_n∫fₙdm,

using liminf(−aₙ) = −limsup(aₙ). Since ∫(g−f)dm = ∫gdm−∫fdm, canceling ∫gdm gives −∫fdm ≤ −limsup_n∫fₙdm, i.e., limsup_n∫fₙdm ≤ ∫fdm.

Combining both bounds: limsup_n∫fₙdm ≤ ∫fdm ≤ liminf_n∫fₙdm. Since liminf ≤ limsup always, all three quantities are equal, so lim_n∫fₙdm exists and equals ∫fdm. ∎
Why domination is exactly what the moving bump lacked DCT's hypothesis needs one fixed integrable g bounding every fₙ at once. For the moving bump, any such g would have to satisfy g(x) ≥ sup_nfₙ(x) for every x, and sup_nfₙ(x) is unbounded as x→0⁺ (some fₙ hits height n right next to 0, for every n) — no integrable function can dominate a family whose peaks grow without bound as their supports shrink. Domination is precisely the hypothesis that rules out mass silently escaping to a single point, which is exactly the failure mode Fatou's Lemma leaves open and DCT closes off.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does the moving-bump example fₙ = n·χ_{(0,1/n)} demonstrate?

The bump's height and shrinking width conspire to keep area fixed at 1 even as the sequence converges pointwise to 0.

2. How does Fatou's Lemma's proof use the Monotone Convergence Theorem?

The infimum-from-n-onward sequence gₖ is always increasing, regardless of whether fₙ itself is, letting MCT apply unconditionally.

3. Why can't any integrable function dominate the moving bump sequence?

The pointwise supremum of the family blows up near 0, which is exactly what domination by a single integrable function rules out.

4. Fill in the blank: the Dominated Convergence Theorem is proved by applying ___'s Lemma to both g+fₙ and g−fₙ.

Fatou's Lemma applied twice, once to each combination, sandwiches limsup and liminf of the integrals between the same two bounds.

5. Fill in the blank: the hypothesis |fₙ| ≤ g for a fixed integrable g is called requiring g to hold, or ___, the sequence.

g "dominates" every fₙ at once, which is where the theorem's name comes from.
