The Monotone Convergence Theorem

Lesson 28 needed exactly one missing tool twice: to prove general additivity of the integral, and to finish comparing Lebesgue's integral with Riemann's. This lesson proves that tool, then spends it on both debts at once.

Theorem — Monotone Convergence Theorem (MCT) Let f₁ ≤ f₂ ≤ f₃ ≤ ⋯ be nonnegative measurable functions with fₙ(x) → f(x) for every x. Then f is measurable and

limₙ→∞ ∫fₙ dm = ∫f dm.
Proof f is measurable as a pointwise limit of measurable functions (Lesson 26). Since fₙ ≤ fₙ₊₁ ≤ f for every n, monotonicity of the integral (Lesson 27) gives ∫fₙdm ≤ ∫fₙ₊₁dm ≤ ∫fdm, so {∫fₙdm} is an increasing sequence of extended reals bounded above by ∫fdm. Hence L := limₙ∫fₙdm exists (possibly +∞) and L ≤ ∫fdm.

For the reverse inequality, fix a simple function φ with 0 ≤ φ ≤ f, and fix a constant c ∈ (0,1). Let Eₙ = {x : fₙ(x) ≥ c·φ(x)}. Each Eₙ is measurable, and Eₙ ⊆ Eₙ₊₁ since fₙ ≤ fₙ₊₁.

Claim: ⋃ₙEₙ is the whole domain. Fix x. If φ(x) = 0, then fₙ(x) ≥ 0 = c·φ(x) for every n, so x ∈ E₁. If φ(x) > 0, then since c < 1, c·φ(x) < φ(x) ≤ f(x); since fₙ(x) → f(x), eventually fₙ(x) > c·φ(x), so x ∈ Eₙ for some n.

Now for each n: ∫fₙdm ≥ ∫_{Eₙ}fₙdm ≥ ∫_{Eₙ}(c·φ)dm = c·∫_{Eₙ}φdm (the middle inequality since fₙ ≥ c·φ on Eₙ by definition; the first since Eₙ is a subset of the whole domain and fₙ≥0 elsewhere). Writing φ = Σᵢaᵢχ_{Fᵢ} in canonical form, ∫_{Eₙ}φdm = Σᵢaᵢm(Fᵢ∩Eₙ), and since Eₙ increases to the whole domain, Fᵢ∩Eₙ increases to Fᵢ, so m(Fᵢ∩Eₙ) → m(Fᵢ) by Continuity from Below (Lesson 25). Hence ∫_{Eₙ}φdm → ∫φdm as n → ∞.

Taking n → ∞ in ∫fₙdm ≥ c·∫_{Eₙ}φdm gives L ≥ c·∫φdm. This holds for every c ∈ (0,1), so letting c → 1 gives L ≥ ∫φdm. This holds for every simple φ ≤ f, so taking the supremum over φ gives L ≥ ∫fdm.

Combined with L ≤ ∫fdm from the first paragraph, L = ∫fdm. ∎
Why c < 1, not c = 1 Taking c = 1 directly would only guarantee fₙ(x) ≥ φ(x) in the limit, not for any finite n — the claim that ⋃Eₙ covers the domain genuinely needs strict inequality c·φ(x) < f(x) to force fₙ(x) past that threshold after finitely many steps. Proving the bound for every c < 1 and then sending c → 1 is what lets the strict slack do its job without weakening the final conclusion.
Lemma (stated) — Dyadic Simple Approximation Every nonnegative measurable f is the pointwise limit of an increasing sequence of nonnegative simple functions φₙ ↗ f, defined by φₙ(x) = k/2ⁿ when k/2ⁿ ≤ f(x) < (k+1)/2ⁿ for 0 ≤ k < n·2ⁿ, and φₙ(x) = n when f(x) ≥ n.
Why this construction is only stated, not verified line by line Checking φₙ ≤ φₙ₊₁ and φₙ(x) → f(x) is routine index-chasing — each dyadic interval at level n splits into two at level n+1, so refining n can only raise the truncated value or hold it fixed, and the truncation error shrinks like 1/2ⁿ. The idea (approximate f by rounding down to the nearest multiple of 1/2ⁿ, capped at n) is the only part worth carrying forward; the verification is in the source reading below.
Corollary — Additivity for Nonnegative Measurable Functions If f, g ≥ 0 are measurable, then ∫(f+g)dm = ∫fdm + ∫gdm.
Proof Let φₙ ↗ f and ψₙ ↗ g be dyadic simple approximations as above. Then φₙ+ψₙ is simple, and φₙ+ψₙ ↗ f+g pointwise (a sum of increasing sequences increases, and pointwise limits add). By MCT applied three times — to φₙ, to ψₙ, and to φₙ+ψₙ:

∫(f+g)dm = limₙ∫(φₙ+ψₙ)dm = limₙ[∫φₙdm + ∫ψₙdm] = limₙ∫φₙdm + limₙ∫ψₙdm = ∫fdm + ∫gdm,

using simple-function linearity (Lesson 27) for the middle step. ∎
Why this is the fact Lesson 28 flagged as missing Lesson 28's Domain-Partition Additivity Lemma split one function over a partition of the domain — elementary, needing only simple-function bookkeeping. This corollary combines two different functions over the same domain, and there was no way around approximating both by increasing simple sequences and passing a limit through the integral — exactly what MCT supplies.
Lemma — A Nonnegative Function with Zero Integral Is Zero Almost Everywhere If h ≥ 0 is measurable and ∫hdm = 0, then h = 0 a.e.
Proof Let Sₙ = {x : h(x) ≥ 1/n}. Then (1/n)χ_{Sₙ} ≤ h, so by monotonicity, (1/n)m(Sₙ) ≤ ∫hdm = 0, forcing m(Sₙ) = 0 for every n. Since {h > 0} = ⋃ₙSₙ, a countable union of null sets, {h>0} is null (Lesson 25). So h = 0 outside a measure-zero set, i.e., a.e. ∎
Corollary — Completing the Riemann-Lebesgue Comparison (Lesson 28) If f is Riemann integrable on [a,b], then f is Lebesgue integrable on [a,b] with ∫_a^bf(x)dx = ∫_{[a,b]}f dm.
Proof Since f is Riemann integrable, I := ∫_a^bf(x)dx = sup_PL(f,P) = inf_PU(f,P). Choose a sequence of partitions Pₙ, each refining Pₙ₋₁, with L(f,Pₙ) → I and U(f,Pₙ) → I (possible by definition of sup and inf, taking common refinements to arrange a single nested sequence achieving both limits at once). Let φₙ be the step function equal to inf f on each subinterval of Pₙ, and ψₙ equal to sup f on each subinterval; both are simple, with ∫φₙdm = L(f,Pₙ) and ∫ψₙdm = U(f,Pₙ) exactly, since m of an interval is its length (Lesson 23).

Refining a partition can only raise each subinterval's infimum and lower its supremum, so φₙ ≤ φₙ₊₁ ≤ f ≤ ψₙ₊₁ ≤ ψₙ pointwise. Since f is bounded (Riemann integrability implies boundedness), φₙ − φ₁ is an increasing sequence of nonnegative measurable functions, so MCT applies: φₙ − φ₁ ↗ g − φ₁ for some measurable g, i.e., φₙ ↗ g pointwise, with ∫φₙdm → ∫gdm, so ∫gdm = limL(f,Pₙ) = I.

Symmetrically, −ψₙ is increasing (since ψₙ is decreasing) and bounded, so MCT applied to −ψₙ + ψ₁ gives −ψₙ ↗ −h for some measurable h, i.e., ψₙ ↘ h pointwise, with ∫ψₙdm → ∫hdm, so ∫hdm = limU(f,Pₙ) = I.

Since φₙ ≤ f ≤ ψₙ for every n, taking limits gives g ≤ f ≤ h. And ∫(h−g)dm = ∫hdm − ∫gdm = I − I = 0 (using the additivity corollary above, since h−g ≥ 0). By the lemma above, h − g = 0 a.e., so g = h a.e., forcing g = f = h a.e. (since g≤f≤h forces f to be sandwiched to equal both). A function equal a.e. to the measurable function g is itself measurable (it differs from g only on a null set, which is measurable), so f is measurable, hence Lebesgue integrable on [a,b] (bounded on a finite-measure set, Lesson 28), and

∫_{[a,b]}f dm = ∫_{[a,b]}g dm = I = ∫_a^bf(x)dx. ∎
Why this closes Lesson 28's debt in full Lesson 28 could show a Riemann integrable f is bounded, hence Lebesgue integrable — but proving the two integral values agree needed exactly the limit-interchange MCT supplies, applied once to the increasing lower step functions directly and once to the decreasing upper step functions via negation. Both debts flagged last lesson — general additivity, and the Riemann comparison — are now fully repaid by the same theorem.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does the Monotone Convergence Theorem conclude?

MCT lets the limit pass inside the integral for increasing sequences of nonnegative measurable functions.

2. Why does the proof use c < 1 rather than c = 1 when defining Eₙ = {fₙ ≥ cφ}?

Only strict inequality guarantees the covering claim ⋃Eₙ = domain; c is then sent to 1 afterward.

3. How does the proof handle the decreasing sequence ψₙ (upper step functions) using only MCT?

Negating a decreasing sequence turns it into an increasing one MCT can act on directly.

4. Fill in the blank: general additivity for nonnegative measurable functions is proved using ___ simple approximations, then MCT three times.

Rounding down to multiples of 1/2ⁿ, capped at n, is the dyadic approximation construction.

5. Fill in the blank: a nonnegative measurable function with ∫hdm = 0 must equal ___ almost everywhere.

The sets {h≥1/n} must all be null, and their union is {h>0}, forcing h=0 outside a null set.
