Measurable Functions

Sets are only half the story. This capstone lesson names the functions the new integral will act on — and proves the exact structural gap that broke Riemann integration in Lesson 22 no longer exists.

← Lesson 25 Unit 6, Lesson 27 → Contents Glossary →

Definition — Measurable Function f: ℝ → ℝ is (Lebesgue) measurable if {x : f(x) > c} is a measurable set for every c ∈ ℝ.
Theorem — Equivalent Characterizations For f: ℝ → ℝ, the following are equivalent: (i) {f>c} measurable for every c; (ii) {f≥c} measurable for every c; (iii) {f<c} measurable for every c; (iv) {f≤c} measurable for every c.
Proof (i) ⟺ (iv): {f≤c} = {f>c}ᶜ, measurable exactly when {f>c} is (closure under complements). (ii) ⟺ (iii): identically, {f<c} = {f≥c}ᶜ.

(i) ⟹ (ii): {f≥c} = ⋂ₙ₌₁^∞ {f > c − 1/n} (if f(x)≥c, then f(x)>c−1/n for every n; conversely if f(x)>c−1/n for every n, then f(x)≥c by letting n→∞). A countable intersection of measurable sets is measurable (De Morgan's law plus closure under complements and countable unions), so {f≥c} is measurable.

(ii) ⟹ (i): {f>c} = ⋃ₙ₌₁^∞ {f ≥ c + 1/n}, a countable union of measurable sets, hence measurable. ∎
Theorem — Continuous Functions Are Measurable If f: ℝ → ℝ is continuous, then f is measurable.
Proof {f>c} = f⁻¹((c,∞)) is open, since f is continuous and (c,∞) is open. Every open subset of ℝ is a countable union of open intervals, and every open interval is measurable (Lesson 24), so every open set is measurable by closure under countable unions. Hence {f>c} is measurable for every c, so f is measurable. ∎
Theorem — Sums of Measurable Functions Are Measurable If f, g: ℝ → ℝ are measurable, then f + g is measurable.
Proof {f+g > c} = ⋃_{r∈ℚ} ({f>r} ∩ {g>c−r}). If f(x)+g(x) > c, then f(x) > c − g(x), and by density of ℚ (Real Analysis A, Unit 1, Lesson 6) some rational r lies strictly between c−g(x) and f(x), giving f(x) > r and g(x) > c−r. Conversely, if f(x)>r and g(x)>c−r for some rational r, adding gives f(x)+g(x) > c. So the two sets are equal. The right side is a countable union (indexed by ℚ, which is countable) of measurable sets ({f>r} and {g>c−r} measurable, so their intersection is too), hence measurable. So {f+g>c} is measurable for every c, and f+g is measurable. ∎
Why ℚ makes an uncountable-looking union countable Written naively, "some real number strictly between c−g(x) and f(x)" ranges over an uncountable set of candidates. Density of ℚ (first proved in Real Analysis A, Unit 1) guarantees a rational witness always exists, and restricting the union to r ∈ ℚ shrinks it to a countable union — exactly what closure under countable unions can handle. Products, maxima, and minima of measurable functions are measurable by similar, if less elegant, arguments; the source reading below works them out in full.
Lemma — Countable Sups and Infs of Measurable Functions Are Measurable If f₁, f₂, f₃, … are measurable, then sup_n fₙ and inf_n fₙ are measurable.
Proof {sup_n fₙ > c} = ⋃ₙ{fₙ>c}: if sup_n fₙ(x) > c, some fₙ(x) > c (otherwise every fₙ(x) ≤ c, forcing the sup ≤ c); conversely if fₙ(x) > c for some n, the sup is at least that large. The right side is a countable union of measurable sets, hence measurable, so sup_n fₙ is measurable. Symmetrically, {inf_n fₙ < c} = ⋃ₙ{fₙ<c}, giving inf_n fₙ measurable. ∎
Theorem — Pointwise Limits of Measurable Functions Are Measurable If f₁, f₂, f₃, … are measurable and fₙ(x) → f(x) for every x, then f is measurable.
Proof Define gₖ = sup_{n≥k} fₙ, measurable for each k by the lemma above. Then limsup_n fₙ = inf_k gₖ, measurable by the lemma applied again, this time to the countable family {gₖ}. Since fₙ(x) → f(x) for every x, the limit exists and equals the limsup: f(x) = limₙfₙ(x) = limsup_n fₙ(x) for every x. So f = inf_k gₖ, measurable. ∎
Why this is the theorem Lesson 22 was missing Lesson 22's sharpest warning was that a pointwise limit of Riemann integrable functions (each fₙ integrable with integral 0) could fail to be Riemann integrable at all — Dirichlet's function itself was the limit, and Riemann's framework simply couldn't see it. This theorem proves the exact structural fix: a pointwise limit of measurable functions is always measurable. Since Dirichlet's function is itself measurable (it's ⋃ₙ{fₙ>c}-buildable directly, or simply because {f>c} is either ∅, ℚ, or ℝ for every c, all measurable), the limit process that broke Riemann integration causes no damage here. Unit 6 builds the integral for which this measurability is exactly the right hypothesis.

Unit 5 in one line: outer measure gives every subset of ℝ a notion of size, the Carathéodory criterion isolates exactly the measurable sets on which that size is countably additive, and measurable functions — including every pointwise limit of measurable functions — are exactly the functions built to be integrated against that measure.

1. What does it mean for f to be measurable?

Measurability of every superlevel set {f>c} is the defining condition, equivalent to the same for ≥, <, or ≤.

2. Why are continuous functions measurable?

Continuity makes every {f>c} open, and every open set is measurable as a countable union of open intervals.

3. What does the pointwise-limit theorem in this lesson repair, compared to Lesson 22?

Lesson 22's fₙ example showed Riemann integrability can vanish in a pointwise limit; measurability, by contrast, is always preserved.

4. Fill in the blank: the proof that f+g is measurable writes {f+g>c} as a union indexed by ___ numbers r, using density of ℚ.

Restricting to rational r turns what looks like an uncountable union into a countable one, which measurability can handle.

5. Fill in the blank: when fₙ(x) → f(x) for every x, f equals the ___ of the sequence fₙ, which is built from countable sups and infs.

The limsup, built as inf_k(sup_{n≥k}fₙ), equals the ordinary limit whenever the limit exists, and is measurable by the sup/inf lemma.
