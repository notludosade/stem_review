Outer Measure on the Real Line

Lesson 22 asked for a notion of "size" general enough to assign ℚ a length of zero. This lesson builds the first candidate — outer measure — and proves it does exactly that, while still agreeing with ordinary length on intervals.

← Lesson 22 Lesson 24 → Contents Glossary →

Definition — Outer Measure For A ⊆ ℝ, the (Lebesgue) outer measure of A is

m*(A) = inf { Σₙ ℓ(Iₙ) : A ⊆ ⋃ₙ Iₙ, each Iₙ an open interval },

the infimum taken over all countable covers of A by open intervals, where ℓ((a,b)) = b − a.
Why "cover by open intervals" is the right starting point Every subset of ℝ, however strange, can be covered by countably many open intervals (the whole real line is one such cover). Taking the infimum of total cover length over all such covers is the most direct way to ask "how much room does A need," without presupposing anything about A's structure in advance.
Theorem — Basic Properties of Outer Measure (a) m*(∅) = 0. (b) Monotonicity: A ⊆ B ⟹ m*(A) ≤ m*(B). (c) Countable Subadditivity: m*(⋃ₙ Aₙ) ≤ Σₙ m*(Aₙ), for any countable collection of sets Aₙ ⊆ ℝ.
Proof (a) For any ε > 0, ∅ ⊆ (0, ε), a cover of total length ε; since ε was arbitrary, m*(∅) = 0.

(b) Any countable cover of B by open intervals is also a cover of A (since A ⊆ B), so the infimum defining m*(A) is taken over at least as many covers as the infimum defining m*(B) — hence m*(A) ≤ m*(B).

(c) Fix ε > 0. For each n, choose a countable cover {Iₙ,ₖ}ₖ of Aₙ by open intervals with Σₖ ℓ(Iₙ,ₖ) < m*(Aₙ) + ε/2ⁿ (possible since m*(Aₙ) is an infimum). The combined collection {Iₙ,ₖ}ₙ,ₖ is countable (a countable union of countable collections) and covers ⋃ₙ Aₙ, with total length Σₙ Σₖ ℓ(Iₙ,ₖ) < Σₙ [m*(Aₙ) + ε/2ⁿ] = Σₙ m*(Aₙ) + ε. So m*(⋃ₙ Aₙ) < Σₙ m*(Aₙ) + ε for every ε > 0, hence m*(⋃ₙ Aₙ) ≤ Σₙ m*(Aₙ). ∎
Why the ε/2ⁿ split is worth noticing Splitting a single ε-budget across countably many pieces so the n-th piece gets ε/2ⁿ (total Σε/2ⁿ = ε) is a recurring trick anywhere a countable family of individually-controllable approximations needs to be combined into one — the same shape of argument used for series estimates earlier in analysis.
Theorem — Outer Measure Agrees with Length on Intervals m*([a,b]) = b − a.
Proof m*([a,b]) ≤ b − a: for any ε > 0, [a,b] ⊆ (a−ε, b+ε), a single-interval cover of length b−a+2ε. Since ε was arbitrary, m*([a,b]) ≤ b − a.

m*([a,b]) ≥ b − a: let {Iₙ} be any countable cover of [a,b] by open intervals. Since [a,b] is compact (closed and bounded, hence compact by the generalized Heine–Borel theorem, Unit 3 Lesson 15), finitely many of the Iₙ already cover [a,b]; it suffices to show any finite cover of [a,b] by open intervals I₁,…,I_k has Σᵢℓ(Iᵢ) ≥ b−a. Starting from a ∈ [a,b], pick an interval I_{j₁} = (c₁,d₁) containing a; if d₁ > b, then ℓ(I_{j₁}) > b−a and the finite sum already exceeds b−a. Otherwise d₁ ∈ [a,b], so some other interval I_{j₂}=(c₂,d₂) among the remaining ones must contain d₁ (the cover covers [a,b], and d₁ is in it), with c₂ < d₁ < d₂. Continuing this chain — each new interval's left endpoint below the previous interval's right endpoint, and each new right endpoint strictly larger than the last (since there are only k intervals, the process must terminate) — the chain reaches an interval I_{jₘ} with dₘ > b, since [a,b] is covered and the chain's right endpoints strictly increase each step. Summing ℓ(I_{jᵢ}) = dᵢ − cᵢ along the chain telescopes (each cᵢ₊₁ < dᵢ) to at least dₘ − c₁ > b − a. Since the full sum over all k intervals is at least this chain's sum, Σᵢℓ(Iᵢ) ≥ b − a. Combined with countable subadditivity applied to the original cover, m*([a,b]) ≥ b − a. The full bookkeeping of the chaining argument is in the source reading below. ∎
Why Unit 3's Heine-Borel theorem resurfaces here The generalized Heine-Borel theorem (Unit 3, Lesson 15) — closed and bounded subsets of ℝⁿ are exactly the compact ones — is precisely what reduces "every countable cover has total length ≥ b−a" down to "every finite cover does," which is the only version the chaining argument above can handle. Without compactness, an infinite cover could in principle use infinitely many arbitrarily short intervals to sneak under any fixed budget — compactness rules this out.
Corollary — Countable Sets Have Outer Measure Zero If A ⊆ ℝ is countable, then m*(A) = 0. In particular, m*(ℚ) = 0.
Proof Enumerate A = {x₁, x₂, x₃, …} (finite sets are handled the same way with the list truncated). For ε > 0, cover xₙ by the interval Iₙ = (xₙ − ε/2ⁿ⁺¹, xₙ + ε/2ⁿ⁺¹), of length ε/2ⁿ. Then A ⊆ ⋃ₙ Iₙ with Σₙ ℓ(Iₙ) = Σₙ ε/2ⁿ = ε. Since ε was arbitrary, m*(A) = 0. ∎
Why this directly answers Lesson 22 m*(ℚ) = 0 is exactly the fact Lesson 22 asked for: a rigorous sense in which ℚ, despite being dense, has "zero length." Dirichlet's function is 1 exactly on a set of outer measure zero — the beginning of why it should be integrable with integral 0 once integration is rebuilt around measure, in Unit 6.
Why not every set gets a well-behaved outer measure Outer measure is defined for every subset of ℝ, but it turns out not to be countably additive on all of them — there exist sets (Vitali sets, built using the Axiom of Choice by collecting one representative from each coset of ℚ acting on [0,1] by translation) for which m* fails to add up correctly over disjoint pieces. This is exactly why Lesson 24 doesn't stop here, and instead isolates a specific collection of "measurable" sets on which outer measure behaves the way a genuine notion of length should.

Check your recall

No peeking back up — answer from memory first, then check.

1. How is m*(A) defined?

Outer measure takes the best (smallest total length) countable cover of A by open intervals.

2. What makes the "≥" direction of m*([a,b]) = b−a harder than the "≤" direction?

Compactness reduces the problem to finite covers, where a chaining argument along overlapping intervals gives the needed length bound.

3. Why does countable subadditivity's proof split ε as ε/2ⁿ across the sets Aₙ?

Geometric-series budgeting lets countably many individual slack allowances add up to a single controllable total.

4. Fill in the blank: the property m*(⋃ₙAₙ) ≤ Σₙm*(Aₙ) is called countable ___.

Subadditivity is the standard name for this inequality-only version of additivity.

5. Fill in the blank: every countable subset of ℝ, including ℚ, has outer measure ___.

Covering each of countably many points by an exponentially shrinking interval forces total outer measure zero.
