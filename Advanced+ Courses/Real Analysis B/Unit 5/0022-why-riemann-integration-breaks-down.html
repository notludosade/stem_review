Why Riemann Integration Breaks Down

Real Analysis A already flagged one bounded function the Riemann integral can't handle. This lesson diagnoses exactly why, and shows the damage is worse than one bad example — even a limit of perfectly well-behaved functions can escape integrability entirely.

← Lesson 21 Lesson 23 → Contents Glossary →

Why this starts by revisiting Dirichlet's function Real Analysis A's Unit 6 (Lesson 31) flagged Dirichlet's function — f(x) = 1 for x rational, 0 for x irrational — as "a bounded-but-not-integrable example," without proving it in full. This lesson proves it, and asks what exactly goes wrong.
Theorem — Dirichlet's Function Is Not Riemann Integrable on [0,1] Let f(x) = 1 if x ∈ ℚ, 0 if x ∉ ℚ. For every partition P of [0,1], U(f,P) = 1 and L(f,P) = 0.
Proof Every subinterval of every partition of [0,1], no matter how small, contains both a rational number (density of ℚ) and an irrational number (density of the irrationals). So on every subinterval, sup f = 1 and inf f = 0. Then U(f,P) = Σ(1)·Δxᵢ = 1 (the sum of all subinterval lengths), and L(f,P) = Σ(0)·Δxᵢ = 0, for every partition P whatsoever. Since U(f,P) − L(f,P) = 1 for every P, the Cauchy Criterion for integrability (Real Analysis A, Unit 6) can never be satisfied for any ε < 1 — f is not Riemann integrable. ∎
Why this happens: the diagnosis The problem isn't that f takes extreme or unbounded values — it only ever takes the values 0 and 1. The problem is that ℚ, the set where f = 1, is dense — spread into every subinterval no matter how small — even though ℚ is countable and intuitively ought to occupy "zero length" within [0,1]. The Riemann integral only ever examines a function through sup and inf on intervals, and that lens cannot distinguish "a dense set that should have zero total length" from "genuinely occupying an interval's worth of space." Fixing this requires a way to directly measure the size of a set like ℚ — the subject of the rest of this unit.

The damage from this gap is not confined to one exotic function. The next example shows integrability itself can vanish in the limit.

Example: a limit of integrable functions that isn't integrable Enumerate ℚ ∩ [0,1] as q₁, q₂, q₃, … (possible since ℚ is countable). Define fₙ(x) = 1 if x ∈ {q₁,…,qₙ}, and 0 otherwise — the indicator of the first n rationals in the list.

Each fₙ is Riemann integrable, with ∫₀¹ fₙ = 0. Given ε > 0, build a partition with tiny subintervals of total width less than ε surrounding each of the n points q₁,…,qₙ, and the rest of [0,1] left as remaining subintervals. On the tiny subintervals, sup fₙ ≤ 1; everywhere else, since every remaining subinterval still contains an irrational (in fact almost every point of it is irrational), inf fₙ = 0, and sup fₙ = 0 as well unless it happens to still contain one of the finitely many marked points — refine further so it doesn't. This gives U(fₙ,P) ≤ 1·(width of tiny intervals) < ε, and L(fₙ,P) = 0. Since U − L can be made smaller than any ε, fₙ is integrable, and squeezing between 0 and ε forces ∫₀¹ fₙ = 0.

fₙ → f pointwise, where f is Dirichlet's function. If x is irrational, fₙ(x) = 0 = f(x) for every n. If x = qₖ for some k, then fₙ(x) = 1 = f(x) for every n ≥ k. So fₙ(x) → f(x) for every x ∈ [0,1].

Yet f itself is not Riemann integrable, by the theorem above.
Why this example is the real warning Every fₙ here is about as well-behaved as a function can be — bounded, integrable, with integral exactly 0 — and the sequence converges everywhere, pointwise, to a specific limit. Yet that limit function is not Riemann integrable at all. Integrability itself fails to survive a pointwise limit. Since limits are the basic currency of analysis, an integral that can lose integrability this easily is a serious structural gap, not a curiosity about one strange function.
Lebesgue's idea, previewed Riemann's integral chops up the domain into small intervals and asks how f behaves on each piece. Lebesgue's integral, built over the rest of this unit and the next, instead chops up the range of f into small pieces and asks how much of the domain — measured directly, by a notion of size general enough to correctly assign ℚ a size of zero — maps into each piece. Building that notion of size precisely is the task of the next three lessons.

Check your recall

No peeking back up — answer from memory first, then check.

1. Why is U(f,P) = 1 and L(f,P) = 0 for every partition P, for Dirichlet's function?

Density of both ℚ and its complement in every subinterval forces sup f = 1 and inf f = 0 there, no matter how the partition is chosen.

2. What does the fₙ example demonstrate?

Each fₙ is integrable with integral 0, and fₙ → f pointwise, yet the Dirichlet function limit f is not Riemann integrable.

3. What is Lebesgue's proposed fix, previewed in this lesson?

Assigning a genuine notion of size (measure) to sets, then chopping up the range instead of the domain, is the core idea Lebesgue's integral is built on.

4. Fill in the blank: ℚ being ___ in every subinterval is exactly why Dirichlet's function has U(f,P)=1 and L(f,P)=0 always.

Density of the rationals (and irrationals) in every subinterval is exactly the phenomenon Riemann sums cannot see past.

5. Fill in the blank: fixing the gap in Riemann integration requires a genuine notion of ___ for sets, general enough to assign ℚ a value of zero.

Measure is exactly the notion of size this unit builds, precise enough to handle dense countable sets correctly.
