Countable Additivity and Measure-Zero Sets

Lesson 24 isolated the measurable sets. This lesson proves what makes them worth isolating: on this collection, outer measure becomes genuinely, countably additive — and the language of "almost everywhere" falls directly out of it.

← Lesson 24 Lesson 26 → Contents Glossary →

Why measure gets its own name from here on For a measurable set E, write m(E) = m*(E) — the same outer measure computation, just restricted to the collection where it behaves well. From this lesson on, m is called (Lebesgue) measure, reserving m* for outer measure on arbitrary, possibly non-measurable sets.
Lemma — Finite Additivity If E and F are measurable and disjoint, then m(E∪F) = m(E) + m(F).
Proof E∪F is measurable (Lesson 24). Apply the Carathéodory criterion for E, using the test set A = E∪F itself: m*(E∪F) = m*((E∪F)∩E) + m*((E∪F)\E). Since E, F are disjoint, (E∪F)∩E = E and (E∪F)\E = F. So m(E∪F) = m*(E∪F) = m(E) + m(F). ∎
Why choosing A = E∪F is the trick The Carathéodory criterion holds for every test set A — choosing A to be exactly the union under study turns the abstract splitting condition into precisely the additivity statement being sought, with nothing left over.

By induction, finite additivity extends immediately to any finite collection of pairwise disjoint measurable sets: m(E₁∪⋯∪Eₙ) = m(E₁) + ⋯ + m(Eₙ).

Theorem — Countable Additivity If E₁, E₂, E₃, … are measurable and pairwise disjoint, then ⋃ₙEₙ is measurable and m(⋃ₙEₙ) = Σₙm(Eₙ).
Proof Measurability of ⋃ₙEₙ and the inequality m(⋃ₙEₙ) ≤ Σₙm(Eₙ) both follow from countable subadditivity (Lesson 23), which holds for arbitrary sets. For the reverse inequality: fix N. By finite additivity, m(⋃ₙ₌₁ᴺEₙ) = Σₙ₌₁ᴺm(Eₙ). Since ⋃ₙ₌₁ᴺEₙ ⊆ ⋃ₙEₙ, monotonicity gives m(⋃ₙEₙ) ≥ m(⋃ₙ₌₁ᴺEₙ) = Σₙ₌₁ᴺm(Eₙ). This holds for every N, so letting N → ∞, m(⋃ₙEₙ) ≥ Σₙ₌₁^∞m(Eₙ). Combined with the inequality from subadditivity, m(⋃ₙEₙ) = Σₙm(Eₙ). ∎
Why disjointness is not optional here Without disjointness, overlapping sets would have their shared parts counted once on the left (as part of the union) but potentially many times on the right (once per set containing them) — countable additivity would simply be false. Countable subadditivity (Lesson 23) is what remains true without disjointness; countable additivity is the strictly stronger fact that holds only once overlaps are ruled out.
Corollary — Continuity from Below If E₁ ⊆ E₂ ⊆ E₃ ⊆ ⋯ are measurable sets, then m(⋃ₙEₙ) = limₙ→∞ m(Eₙ).
Proof Disjointify: let F₁ = E₁ and Fₙ = Eₙ\Eₙ₋₁ for n ≥ 2. Each Fₙ is measurable (an intersection of measurable sets, since Eₙ∩Eₙ₋₁ᶜ = (Eₙᶜ∪Eₙ₋₁)ᶜ is measurable by closure under complements and unions), and the Fₙ are pairwise disjoint by construction. Telescoping, ⋃ₙ₌₁ᴺFₙ = Eₙ for every N, and ⋃ₙFₙ = ⋃ₙEₙ. By countable additivity, m(⋃ₙEₙ) = m(⋃ₙFₙ) = Σₙ₌₁^∞m(Fₙ) = limₙ→∞ Σₙ₌₁ᴺm(Fₙ) = limₙ→∞ m(⋃ₙ₌₁ᴺFₙ) = limₙ→∞ m(Eₙ), using finite additivity for the second-to-last step. ∎
Why disjointification resurfaces here Lesson 24 deferred the proof that measurable sets are closed under arbitrary countable unions, noting it needs replacing a sequence of sets with an equivalent disjoint one. The F₁, F₂, … construction above is exactly that technique, now made concrete in a setting where it pays off immediately.
Definition — Measure-Zero (Null) Sets A measurable set N is a measure-zero set (or null set) if m(N) = 0.
Corollary — Countable Unions of Null Sets Are Null If N₁, N₂, … are measurable with m(Nₙ) = 0 for every n, then m(⋃ₙNₙ) = 0.
Proof By countable subadditivity, m(⋃ₙNₙ) ≤ Σₙm(Nₙ) = Σₙ0 = 0. Since measure is never negative, m(⋃ₙNₙ) = 0. ∎
Definition — Almost Everywhere A property P(x) is said to hold almost everywhere (a.e.) on a set S if {x ∈ S : P(x) fails} is a measure-zero set.
Why this finally closes the loop from Lesson 22 Dirichlet's function f equals 0 everywhere except on ℚ, and m(ℚ) = 0 (Lesson 23). So f = 0 almost everywhere on [0,1]. Lesson 22 asked for a framework rich enough to treat f as "essentially zero" despite being nonzero on a dense set — "almost everywhere" is exactly that framework, precise and now fully justified. Unit 6 builds an integral for which a function equal to 0 a.e. integrates to exactly 0, resolving Lesson 22's opening problem completely.

Check your recall

No peeking back up — answer from memory first, then check.

1. What choice of test set makes the finite additivity proof work?

Testing the criterion against the union itself turns the abstract splitting condition directly into the additivity equation.

2. How is the "≥" half of countable additivity's proof obtained?

Finite additivity gives the sum for any first N sets, and monotonicity lets that bound pass to the full countable union as N grows.

3. Why does a countable union of measure-zero sets have measure zero?

Subadditivity alone, without needing disjointness, already forces the union's measure to be at most a sum of zeros.

4. Fill in the blank: countable additivity requires the sets Eₙ to be pairwise ___.

Without disjointness, overlapping regions would be overcounted on the right-hand side of the additivity equation.

5. Fill in the blank: a property that fails only on a measure-zero set is said to hold almost ___.

Almost everywhere is the standard term for a property holding outside a set of measure zero.
