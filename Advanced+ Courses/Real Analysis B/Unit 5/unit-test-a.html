1. For Dirichlet's function f(x) = 1 if x ∈ ℚ, 0 if x ∉ ℚ, what are U(f,P) and L(f,P) for every partition P of [0,1]?

Every subinterval, however small, contains both a rational and an irrational point, so sup f = 1 and inf f = 0 there, no matter how the partition is refined — giving U(f,P) = 1 and L(f,P) = 0 always.

2. Enumerate ℚ∩[0,1] as q₁,q₂,q₃,…, and let fₙ(x) = 1 if x ∈ {q₁,…,qₙ}, else 0. Answer both parts:

(a) What is ∫₀¹fₙ dx (Riemann) for each n?

(b) Fill in the blank: as n → ∞, fₙ → f pointwise, where f is Dirichlet's function — which is not Riemann ___, showing integrability itself can fail to survive a pointwise limit.

(a) Each fₙ is nonzero at only finitely many points, which can be covered by intervals of arbitrarily small total width, so U(fₙ,P) can be made less than any ε while L(fₙ,P) = 0, forcing the integral to 0. (b) fₙ converges pointwise everywhere to Dirichlet's function, which is not Riemann integrable at all — integrability does not survive the limit.

3. Answer both parts about outer measure:

(a) What is m*([2,7])?

(b) Fill in the blank: what is m*({2,7}), the two-point set consisting only of 2 and 7? ___

(a) Outer measure agrees with ordinary length on intervals: m*([2,7]) = 7 − 2 = 5. (b) Every finite (hence countable) set has outer measure zero — cover each point by an exponentially shrinking interval and sum the lengths to any ε.

4. Which property does countable subadditivity of outer measure state?

Countable subadditivity is only an inequality — the outer measure of a union is at most the sum of the outer measures, never automatically equal, since the sets may overlap.

5. E ⊆ ℝ is Lebesgue measurable exactly when which equation holds, for every test set A ⊆ ℝ?

This is the Carathéodory criterion: E splits every possible test set A without losing any outer measure in the split. Since subadditivity already gives "≤" for free, this is really only demanding the reverse inequality.

6. Let N ⊂ [0,1] be a set with m*(N) = 0 (for instance, N = ℚ∩[0,1]). Answer both parts:

(a) Is N measurable?

(b) Fill in the blank: since N is measurable, by closure of measurable sets under complements, Nᶜ (the complement of N) is also ___.

(a) The subadditivity inequality m*(A) ≤ m*(A∩N) + m*(A\N) always holds, and when m*(N) = 0, monotonicity forces the reverse inequality too, so equality holds and N is measurable. (b) The measurable sets are closed under complements, so Nᶜ is measurable whenever N is.

7. Let E₁,E₂,E₃,… be pairwise disjoint measurable sets with m(Eₙ) = 1/2ⁿ for n = 1,2,3,…. Answer both parts:

(a) By countable additivity, what is m(⋃ₙ₌₁^∞ Eₙ)?

(b) Fill in the blank: this relies on ___ additivity, which — unlike subadditivity — requires the sets to be pairwise disjoint.

(a) The geometric series Σ_{n=1}^∞ 1/2ⁿ = 1/2 + 1/4 + 1/8 + ⋯ sums to 1. (b) Countable additivity is the theorem that turns countable subadditivity's inequality into an equality, exactly when the sets are pairwise disjoint.

8. Fill in the blank: a property P(x) is said to hold "almost everywhere" on a set S if the set of points in S where P(x) fails is a ___ set.

A set of measure zero (a "null" set) is exactly the kind of exception a property is allowed to have and still be said to hold almost everywhere.

9. Let f(x) = x², a continuous function. Answer both parts:

(a) Is f measurable?

(b) Fill in the blank: for c = 4, the set {x : f(x) > 4} equals (−∞,−2) ∪ (2,∞), a union of two ___ intervals, hence measurable.

(a) f⁻¹((c,∞)) is open whenever f is continuous, and every open set is measurable. (b) x² > 4 exactly when |x| > 2, giving two open half-lines, each measurable, so their union is measurable.

10. Fill in the blank: unlike Riemann integrability, if f₁,f₂,f₃,… are measurable functions with fₙ(x) → f(x) for every x, then f is always guaranteed to be ___.

Building f as the limsup of the fₙ (an inf of sups), which is measurable by the countable-sup/inf lemma, shows the pointwise limit of measurable functions is always measurable — exactly the repair Riemann integrability lacked.
