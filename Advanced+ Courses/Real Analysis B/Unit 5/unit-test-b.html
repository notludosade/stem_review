1. Why is Dirichlet's function f(x) = 1 (x∈ℚ), 0 (x∉ℚ) not Riemann integrable on [0,1]?

Density of both ℚ and its complement in every subinterval, no matter how small, forces U(f,P) = 1 and L(f,P) = 0 for every partition P, so the Cauchy criterion for integrability can never be satisfied.

2. Let fₙ = the indicator of the first n rationals in an enumeration of ℚ∩[0,1]. Answer both parts:

(a) Is each fₙ Riemann integrable?

(b) Fill in the blank: even though every fₙ is Riemann integrable, the pointwise limit — Dirichlet's function — is not Riemann integrable at all, showing Riemann integrability is not preserved under pointwise ___.

(a) Finitely many marked points can always be surrounded by intervals of arbitrarily small total width, forcing U(fₙ,P) − L(fₙ,P) below any ε, so fₙ is integrable with integral squeezed to 0. (b) The limit function fails to be Riemann integrable at all — integrability itself does not survive the pointwise limit.

3. Answer both parts about outer measure:

(a) What is m*((−3,5))?

(b) Fill in the blank: what is m*(ℤ), the outer measure of the set of all integers? ___

(a) Outer measure agrees with ordinary length on intervals: m*((−3,5)) = 5 − (−3) = 8. (b) ℤ is countable, and every countable set has outer measure zero — the same covering argument that gives m*(ℚ) = 0 applies verbatim.

4. Which of these is guaranteed by monotonicity of outer measure?

Any countable cover of B by open intervals also covers A ⊆ B, so the infimum defining m*(A) is taken over at least as many covers, giving m*(A) ≤ m*(B). The converse direction, and equality claims, do not follow.

5. Countable subadditivity already gives m*(A) ≤ m*(A∩E) + m*(A\E) for every set E and test set A. What extra condition does the Carathéodory criterion for measurability of E actually require?

Since the "≤" direction is automatic from subadditivity, the Carathéodory criterion is really only asking that splitting A along E never lose any outer measure — the reverse inequality.

6. Let E = (2,∞), known to be measurable. Answer both parts:

(a) Which set is guaranteed measurable by closure under complements?

(b) Fill in the blank: since (−∞,2] and [5,9] are both measurable, their union is measurable too, by closure of measurable sets under ___.

(a) The Carathéodory criterion is symmetric under swapping E and Eᶜ, so Eᶜ is measurable whenever E is. (b) Measurable sets are closed under (countable, hence finite) unions, so the union of two measurable sets is always measurable.

7. Let Fₙ = [n, n+1) for n = 0,1,2,…,9 — ten pairwise disjoint measurable intervals, each of length 1. Answer both parts:

(a) What is m(⋃ₙ₌₀^9 Fₙ)?

(b) Fill in the blank: since there are only finitely many sets here, this relies on ___ additivity applied to pairwise disjoint measurable sets.

(a) Ten disjoint intervals of length 1 each sum to measure 10, by finite additivity. (b) Finite additivity (which extends countable additivity's proof by induction) is exactly what applies to a finite disjoint collection like this one.

8. Dirichlet's function f equals 0 everywhere except on ℚ, and m(ℚ) = 0. Which statement is correct?

The set where f fails to be 0 is exactly ℚ∩[0,1], which has measure zero — so f equals 0 outside a null set, which is precisely the definition of "almost everywhere."

9. Let f(x) = x³, a continuous function. Answer both parts:

(a) Is f measurable?

(b) Fill in the blank: for c = 8, {x : f(x) > 8} = (2,∞), which is measurable because it is an ___ interval (in fact a half-line).

(a) Every continuous function is measurable, as the preimage of an open set under a continuous map is open, and every open set is measurable. (b) x³ > 8 exactly when x > 2, giving the open half-line (2,∞), which is measurable.

10. Fill in the blank: the key structural repair over Riemann integration is that pointwise limits of ___ functions are always measurable, even though pointwise limits of Riemann integrable functions need not be Riemann integrable.

Measurability, built from countable sups and infs, is preserved under pointwise limits unconditionally — exactly the structural property Riemann integrability lacked.
