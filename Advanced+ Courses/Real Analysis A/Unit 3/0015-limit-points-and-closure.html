Limit Points and Closure

Extending Unit 2's "limit point of a sequence" to sets in general — and the operation that seals up any leftover gaps.

← Lesson 14 Lesson 16 → Contents Glossary →

Unit 2, Lesson 11 defined a limit point of a sequence. This lesson defines the analogous idea for a set, and shows it gives a second, equivalent way to characterize closed sets — one that connects directly back to sequences.

Limit points of a set

Definition — Limit Point of a Set A point x is a limit point of a set A if every interval (x − ε, x + ε) contains a point of A different from x itself. (x need not belong to A.)
Example For A = (0, 1), every point of [0, 1] is a limit point of A — including 0 and 1, which are not themselves in A. For A = {1, 1/2, 1/3, 1/4, …}, the only limit point is 0 (which is not in A), matching the sequence-limit intuition from Unit 2: the terms 1/n bunch up arbitrarily close to 0 as n grows.

A sequential characterization

Theorem x is a limit point of A if and only if there exists a sequence (aₙ) of points in A, with aₙ ≠ x for every n, such that aₙ → x.
Proof sketch (⇒) If x is a limit point, then for each n, the interval (x − 1/n, x + 1/n) contains some point aₙ ∈ A with aₙ ≠ x; this builds a sequence with aₙ → x directly (given any ε > 0, the Archimedean Property gives N with 1/N < ε, and then |aₙ − x| < 1/n ≤ 1/N < ε for all n ≥ N). (⇐) If such a sequence exists, then given any ε > 0, convergence gives some aₙ with |aₙ − x| < ε and aₙ ≠ x, aₙ ∈ A — exactly what the limit-point definition requires. ∎
Why this connects Unit 2 directly to Unit 3 This theorem is the bridge between the two units: every topological fact about limit points of sets can now be checked using sequence machinery already built (epsilon-N proofs, the Archimedean Property), rather than reasoning about intervals from scratch each time.

Closed sets, restated via limit points

Theorem A set F is closed if and only if F contains all of its limit points.
Why this matches Lesson 14's definition A set failing to contain one of its limit points has a "hole" arbitrarily close to points still in the set — and the complement, near that hole, cannot be open, since every interval around the missing limit point pokes back into F. This is exactly Lesson 14's open-complement definition, just viewed from the inside of F rather than the outside.
Example [0, 1] contains all its limit points (every point of [0, 1] itself), so it's closed — matching Lesson 14. (0, 1) is missing the limit points 0 and 1, so it's not closed — again matching Lesson 14.

Closure

Definition — Closure The closure of a set A, written Ā, is A together with all of its limit points. Ā is always closed, and it is the smallest closed set containing A.
Example The closure of (0, 1) is [0, 1]. The closure of ℚ is all of ℝ, since every real number is a limit point of ℚ (density of ℚ in ℝ, Unit 1, Lesson 6) — a strikingly compact way to restate a fact that took a full Archimedean-Property argument to prove back in Unit 1.
