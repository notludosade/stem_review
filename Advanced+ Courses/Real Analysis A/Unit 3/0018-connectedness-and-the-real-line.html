Connectedness and the Real Line

The topological property behind "no gaps to jump across" — and the hidden engine of the Intermediate Value Theorem.

← Lesson 17 Unit 4, Lesson 19 → Contents Glossary →

This closing lesson of Unit 3 defines connectedness and proves exactly which subsets of ℝ have it — a fact Unit 4 will use directly to prove the Intermediate Value Theorem without any hand-waving about "no gaps."

Separated sets and connectedness

Definition — Separated Sets Two sets A, B ⊆ ℝ are separated if Ā ∩ B = ∅ and A ∩ B̄ = ∅ (neither set contains a limit point of the other, using the closure from Lesson 15).
Definition — Connected Set A set E ⊆ ℝ is connected if it cannot be written as E = A ∪ B for two nonempty separated sets A and B.
Example (0, 1) ∪ (2, 3) is not connected: A = (0, 1) and B = (2, 3) are separated (their closures, [0,1] and [2,3], don't meet the other set), and their union recovers the whole set — so it splits cleanly into two disconnected pieces. By contrast, (0, 1) itself resists any such split, though showing that directly from the definition takes some care.

The characterization theorem

Theorem A set E ⊆ ℝ with at least two points is connected if and only if E is an interval (that is, whenever a, b ∈ E and a < c < b, then c ∈ E as well).
Proof sketch — connected ⇒ interval Contrapositive: suppose E is not an interval, so some a, b ∈ E and c ∉ E satisfy a < c < b. Then A = E ∩ (−∞, c) and B = E ∩ (c, ∞) are both nonempty (containing a and b respectively), their union is E (since c ∉ E), and they are separated (they sit on opposite sides of the fixed point c, with a gap between their closures at c itself). So E is not connected.
Proof sketch — interval ⇒ connected Contrapositive: suppose an interval E splits as E = A ∪ B for nonempty separated A, B. Pick a ∈ A, b ∈ B, WLOG a < b. Since E is an interval, [a, b] ⊆ E. Let c = sup(A ∩ [a, b]). Since A and B are separated, c cannot be a limit point of B, and a careful case check (whether c ∈ A or c ∈ B) leads to a contradiction in both cases — using the epsilon characterization of supremum (Unit 1, Lesson 4) to find points of the other set arbitrarily close to c either way. So no such split exists, and E is connected.
Why this theorem is exactly what IVT needs The Intermediate Value Theorem (Unit 4) will show that a continuous function's image of an interval has "no gaps" — and this theorem is precisely what makes that statement precise: an interval is connected, continuous functions preserve connectedness (a fact proved once continuity is defined), and connected subsets of ℝ are exactly the intervals. IVT falls out of these three facts almost immediately once continuity is in hand.
