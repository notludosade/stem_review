1. Which of the following sets is open?

For any x ∈ (0, 1), taking ε = min(x, 1 − x) keeps (x − ε, x + ε) entirely inside (0, 1). The others each fail at an endpoint or single point, where no surrounding interval fits inside the set.

2. Fill in the blank: a set F ⊆ ℝ is closed exactly when its complement ℝ \ F is ___.

Closed is defined entirely in terms of the complement being open — there is no independent definition.

3. What is the only limit point of A = {1, 1/2, 1/3, 1/4, …}?

The terms 1/n bunch up arbitrarily close to 0 as n grows, so every interval around 0 contains points of A other than 0 itself — and 0 is the only such point.

4. Why is (0, 1) not compact?

(0, 1) is bounded but not closed — this sequence stays inside (0,1) yet its limit escapes the set, which is exactly what compactness forbids.

5. Fill in the blank: for subsets of ℝ with at least two points, the characterization theorem shows that being connected is exactly equivalent to being a(n) ___.

"Interval" and "connected" turn out to be exactly the same property for subsets of ℝ with two or more points.

6. Let A = (2, 5). Answer both parts:

(a) What is the closure Ā of A = (2, 5)?

(b) Fill in the blank: the closure of a set A is A together with all of its ___ points, and it is always the smallest closed set containing A.

(a) 2 and 5 are limit points of (2,5) not contained in it, so adding them gives the closure [2,5]. (b) Closure is A together with all of its limit points, the smallest closed set containing A.

7. Consider the collection of open sets (−1 − 1/n, 1 + 1/n) for n ∈ ℕ. Answer both parts:

(a) What is ⋂ₙ (−1 − 1/n, 1 + 1/n) over all n ∈ ℕ?

(b) Fill in the blank: this intersection is not open, which shows that only a ___ intersection of open sets is guaranteed to be open (unlike unions, which stay open for arbitrary collections).

(a) Every set in the collection contains [−1,1], but as n grows the bounds 1 + 1/n shrink toward 1, so any point strictly outside [−1,1] is eventually excluded — leaving exactly [−1,1], which is closed, not open. (b) Only finite intersections of open sets are guaranteed to stay open.

8. Consider the open cover {(−n, n) : n ∈ ℕ} of ℝ. Answer both parts:

(a) Does this cover have a finite subcover of ℝ?

(b) Fill in the blank: by the Heine-Borel Theorem, a set K ⊆ ℝ is compact if and only if every open cover of K has a ___ subcover.

(a) Any finite subcollection's union is bounded, so it cannot cover the unbounded ℝ — exactly why ℝ is not compact. (b) The Heine-Borel Theorem defines compactness via the finite-subcover property.

9. Let K = [−3, 3]. Answer both parts:

(a) Is K compact, using the sequential definition?

(b) Fill in the blank: the sequential definition of compactness requires that the convergent subsequence's limit also lie inside ___ — the extra condition beyond what Bolzano-Weierstrass alone guarantees for any bounded sequence.

(a) [−3,3] is closed and bounded, so it satisfies the sequential compactness definition. (b) Bolzano-Weierstrass gives a convergent subsequence for free from boundedness; compactness additionally requires the limit not escape the set K.

10. Let E = (0, 2) ∪ (3, 5). Answer both parts:

(a) Is E connected?

(b) Fill in the blank: A and B are separated because their closures, [0,2] and [3,5], do not meet the other set — there is a gap between them at every point from 2 to ___.

(a) Since c = 2.5 (say) lies between points of E but not in E itself, E fails the interval condition, so it's disconnected. (b) The gap runs from 2 to 3, exactly where E has no points at all.
