Open and Closed Sets

The two basic shapes a subset of ℝ can have — and why they are not opposites of each other.

← Unit 2, Lesson 13 Lesson 15 → Contents Glossary →

Units 1 and 2 studied numbers and sequences of numbers. This unit studies sets of real numbers — specifically, the structural properties that determine how functions defined on those sets can behave. Everything in Unit 4 (continuity, the Intermediate Value Theorem) rests on the vocabulary built here.

Open sets

Definition — Open Set A set O ⊆ ℝ is open if for every point x ∈ O, there exists ε > 0 such that the interval (x − ε, x + ε) is entirely contained in O.
Example The open interval (0, 1) is open: for any x ∈ (0, 1), let ε = min(x, 1 − x); then (x − ε, x + ε) stays inside (0, 1). By contrast, [0, 1) is not open — at x = 0, every interval (−ε, ε) contains negative numbers, which are outside [0, 1), no matter how small ε is.

Closed sets

Definition — Closed Set A set F ⊆ ℝ is closed if its complement ℝ \ F is open.
Example The closed interval [0, 1] is closed: its complement (−∞, 0) ∪ (1, ∞) is open (each piece is open, and a union of open sets is open — proved below). The set of rationals ℚ is neither open nor closed: every interval around any rational contains irrationals (so ℚ isn't open), and every interval around any irrational contains rationals (so ℝ \ ℚ isn't open either, meaning ℚ isn't closed).
Why "not open" doesn't mean "closed" Open and closed are not opposites — they're independent properties tested by different conditions. A set can be neither (like ℚ, shown above), and a set can be both simultaneously (ℝ itself, and the empty set ∅, are each both open and closed — a fact worth checking directly against both definitions). This is the single most common misconception when this vocabulary is first introduced.

Closure under unions and intersections

Theorem An arbitrary union of open sets is open. A finite intersection of open sets is open.
Proof (union) Let {Oα} be any collection of open sets, and let x ∈ ⋃Oα. Then x ∈ Oα for some particular α, and since Oα is open, there is ε > 0 with (x − ε, x + ε) ⊆ Oα ⊆ ⋃Oα. So ⋃Oα is open. ∎
Why the intersection claim is only finite Intersecting infinitely many open sets can fail to be open: consider ⋂ₙ(−1/n, 1/n) over all n ∈ ℕ. Every set in the intersection is open, but the intersection itself is just {0} — a single point, which contains no interval around itself at all, so it is not open. Finiteness in the intersection claim is not a technicality; it's the exact place the argument breaks for infinitely many sets.

By De Morgan's Laws, the corresponding statement for closed sets flips: a finite union of closed sets is closed, and an arbitrary intersection of closed sets is closed.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does it mean for a set O to be open?

The defining condition of openness is that every point has "breathing room" — an entire surrounding interval — inside the set.

2. Why is ℚ (the rationals) neither open nor closed?

Both directions have to be checked separately against the two definitions — ℚ fails both, showing open/closed are not exhaustive opposites.

3. Why does ⋂ₙ(−1/n, 1/n) over all n ∈ ℕ fail to be open, even though every set in the intersection is open?

This is exactly why the union theorem is stated for arbitrary collections but the intersection theorem is restricted to finite ones.

4. Fill in the blank: a set F is closed exactly when its complement ℝ \ F is ___.

Closed is defined entirely in terms of the complement being open — there is no independent definition.

5. Fill in the blank: an arbitrary union of open sets is open, but only a ___ intersection of open sets is guaranteed to be open.

Finite is the required qualifier — infinite intersections of open sets can collapse to a single non-open point, as the ⋂(−1/n, 1/n) example shows.
