Compactness

The property that will make continuous functions in Unit 4 behave as well as possible — attaining maximums, not just approaching them.

← Lesson 15 Lesson 17 → Contents Glossary →

This lesson introduces compactness via sequences — the definition easiest to work with directly, given Unit 2's toolkit — and previews the open-cover definition that Lesson 17 will show is equivalent.

The sequential definition

Definition — Compact Set (sequential) A set K ⊆ ℝ is compact if every sequence of points in K has a subsequence that converges to a point also in K.
Why "converges to a point in K" is the crucial extra clause Bolzano-Weierstrass (Unit 2, Lesson 12) already guarantees a convergent subsequence for any bounded set of terms — that part is free. What compactness adds is that the limit doesn't escape the set. This is exactly where boundedness alone falls short: (0, 1) is bounded, but the sequence 1/2, 1/3, 1/4, … (all inside (0, 1)) converges only to 0, which is outside (0, 1) — so (0, 1) is not compact, even though it's bounded.

Worked examples

Example — [0, 1] is compact Any sequence in [0, 1] is bounded, so by Bolzano-Weierstrass it has a convergent subsequence, converging to some x. Since [0, 1] is closed (Lesson 14) and contains all its limit points (Lesson 15), and x is a limit of points in [0,1], x must itself be in [0, 1]. So [0, 1] is compact.
Example — ℝ itself is not compact The sequence 1, 2, 3, 4, … lies in ℝ but has no convergent subsequence at all (every subsequence is itself unbounded, hence divergent, matching Unit 2 Lesson 11's aₙ = n example). ℝ fails the definition immediately — being closed is not enough on its own; boundedness is also required.

The two ingredients: closed and bounded

Theorem (preview of Lesson 17) A set K ⊆ ℝ is compact if and only if K is closed and bounded.
Why this is stated as a preview, not proved yet The (⇒) direction — compact implies closed and bounded — follows quickly from the sequential definition and is left as a short exercise (an unbounded set has a sequence with no convergent subsequence at all, and a non-closed set has a sequence converging outside itself). The (⇐) direction — closed and bounded implies compact — is genuinely more work, and is exactly the content of the Heine-Borel Theorem, proved in full next lesson using an entirely different definition of compactness (open covers) that turns out to be equivalent to this one.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does the sequential definition of compactness require, beyond what Bolzano-Weierstrass already guarantees for bounded sets?

Bolzano-Weierstrass supplies the convergent subsequence for free given boundedness; compactness's extra demand is that the limit doesn't escape K.

2. Why is (0, 1) not compact?

(0, 1) is bounded but not closed — this exact sequence shows the compactness definition failing because the limit escapes the set.

3. Why is ℝ itself not compact?

ℝ is closed but unbounded — the failure here is on the boundedness side, the opposite reason from (0,1)'s failure.

4. Fill in the blank: a set where every sequence of its points has a subsequence converging to a point still inside the set is called ___.

Compact is the term this lesson defines, previewing that it will turn out to be equivalent to "closed and bounded."

5. Fill in the blank: the theorem previewed at the end of this lesson states that a set is compact if and only if it is ___.

Closed and bounded together is exactly the characterization the Heine-Borel Theorem proves in full next lesson.
