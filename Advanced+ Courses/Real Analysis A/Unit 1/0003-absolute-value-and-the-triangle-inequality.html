Absolute Value and the Triangle Inequality

The single inequality that every "gets arbitrarily close" argument in this course will secretly be built from.

← Lesson 2 Lesson 4 → Contents Glossary →

"How close" two numbers are needs a precise measure before "arbitrarily close" (Lesson 1's phrase) can mean anything. That measure is absolute value: |a − b| is the distance between a and b on the number line.

Definition — Absolute Value For a in ℝ, |a| = a if a ≥ 0, and |a| = −a if a < 0. Directly from this definition: |a| ≥ 0 always, |a| = |−a|, and |a| = 0 if and only if a = 0.

The triangle inequality

Every distance-based argument later in this course — every epsilon-N or epsilon-delta proof — leans on one inequality relating the absolute value of a sum to the absolute values of its parts.

Theorem — Triangle Inequality For any a, b in ℝ: |a + b| ≤ |a| + |b|.
Proof From the definition, −|a| ≤ a ≤ |a| and −|b| ≤ b ≤ |b| (each of these is immediate: a either equals |a| or −|a|, and the other is farther from 0). Adding these two inequalities: −(|a| + |b|) ≤ a + b ≤ |a| + |b|. This exact pattern — a number x satisfying −c ≤ x ≤ c — is equivalent to |x| ≤ c. Applying that here with x = a + b and c = |a| + |b| gives |a + b| ≤ |a| + |b|. ∎
Why it's called "triangle" Picture a, b, and a + b as the side lengths of a path: going straight from 0 to a + b can never be longer than going from 0 to a and then from a to a + b — exactly the geometric triangle inequality (one side of a triangle is never longer than the sum of the other two), transplanted onto the number line.

A reverse form, used constantly

Corollary — Reverse Triangle Inequality For any a, b in ℝ: | |a| − |b| | ≤ |a − b|.
Proof Write a = (a − b) + b, and apply the triangle inequality directly: |a| = |(a − b) + b| ≤ |a − b| + |b|. Subtract |b| from both sides: |a| − |b| ≤ |a − b|. Swapping the roles of a and b in the same argument gives |b| − |a| ≤ |a − b| as well. Since | |a| − |b| | is whichever of |a| − |b| or |b| − |a| is nonnegative, and both are bounded above by |a − b|, the result follows. ∎
Worked Example Suppose you know |x − 3| < 0.1 and want to bound |x² − 9|. Factor: x² − 9 = (x − 3)(x + 3), so |x² − 9| = |x − 3| · |x + 3|. Since |x − 3| < 0.1, x is within 0.1 of 3, so |x + 3| < 6.1 (by the triangle inequality applied to x + 3 = (x − 3) + 6). Combining: |x² − 9| < 0.1 × 6.1 = 0.61. This exact technique — bound one factor using the triangle inequality, then multiply — reappears constantly once limit proofs begin in Unit 2.

1. What does |a − b| represent geometrically?

Absolute value of a difference is exactly the distance-measuring tool this course needs to make "close" precise.

2. The proof of the triangle inequality relies most directly on which fact?

Adding the two bracketing inequalities for a and b, then recognizing the −c ≤ x ≤ c pattern, is the entire proof.

3. In the worked example bounding |x² − 9|, why was the triangle inequality applied to x + 3 rather than to x − 3?

Since |x² − 9| = |x − 3| · |x + 3|, both factors needed a bound — the triangle inequality supplied the bound on |x + 3| given the known bound on |x − 3|.
