Field and Order Axioms

The short list of rules that + and · and < have to obey — everything else in this course is proved from these, plus one more axiom still to come.

← Lesson 1 Lesson 3 → Contents Glossary →

Lesson 1 argued that "the real numbers have no gaps" needs a precise meaning before it can be proved. Getting there takes two steps: first, pin down the arithmetic and ordering rules ℝ obeys (this lesson); then add the one extra axiom — completeness — that ℚ satisfies too except for the gaps (Lesson 5).

The field axioms

Definition — Field A field is a set F with two operations, + and ·, satisfying: closure (a + b and a · b are in F), associativity and commutativity for both operations, distributivity of · over +, an additive identity 0 and multiplicative identity 1 (with 0 ≠ 1), an additive inverse −a for every a, and a multiplicative inverse a−1 for every a ≠ 0.

Both ℚ and ℝ satisfy every one of these — they're both fields. This is exactly why ordinary algebra (moving terms across an equals sign, canceling factors) works the same way in both. Nothing in the field axioms alone distinguishes ℝ from ℚ.

The order axioms

Definition — Ordered Field A field F is ordered if it has a relation < satisfying: trichotomy (for any a, b in F, exactly one of a < b, a = b, b < a holds), transitivity (a < b and b < c implies a < c), compatibility with addition (a < b implies a + c < b + c for any c), and compatibility with multiplication (a < b and c > 0 implies ac < bc).

ℚ and ℝ are both ordered fields too. So far, still no difference between them — everything stated so far is equally true of ℚ. That's deliberate: it means every proof in this lesson is a proof about any ordered field, reusable later without modification.

Proving something small from the axioms alone

To see the axioms actually doing work rather than just being a checklist, here's a fact you've used constantly without proof: multiplying by zero gives zero.

Claim For any a in an ordered field F, a · 0 = 0.
Proof Start from 0 + 0 = 0 (0 is the additive identity). Multiply both sides by a: a · (0 + 0) = a · 0. Distributivity turns the left side into a·0 + a·0, giving a·0 + a·0 = a·0. Now add −(a·0) (the additive inverse of a·0, guaranteed to exist by the field axioms) to both sides: a·0 + a·0 + −(a·0) = a·0 + −(a·0), which simplifies to a·0 + 0 = 0, and therefore a·0 = 0. ∎
Why bother proving something this obvious The point isn't that a·0 = 0 was ever in doubt — it's that the proof used only the field axioms: the identity property of 0, distributivity, and the existence of additive inverses. Nothing about "numbers" as a familiar object was assumed. This is the discipline the entire course runs on: every later theorem, no matter how intuitive, gets built the same way, from axioms already established.

An axiom ℚ and ℝ both satisfy — and one they don't

Every axiom in this lesson holds for ℚ exactly as much as for ℝ. That means the field and order axioms alone cannot be what makes the √2-approximating sequence from Lesson 1 converge in ℝ but not in ℚ. Whatever distinguishes them has to come from somewhere else — the completeness axiom, still ahead in Lesson 5, once Lesson 4 has built the vocabulary (bounds, supremum) needed to even state it.

Check your recall

No peeking back up — answer from memory first, then check.

1. Which of the following is guaranteed by the field axioms for any nonzero element a?

A multiplicative inverse for every nonzero element is one of the field axioms directly. Ordering facts and supremum are separate concepts covered in later lessons.

2. Do the field and order axioms, by themselves, distinguish ℝ from ℚ?

Both ℚ and ℝ satisfy every field and order axiom in this lesson. The real distinguishing property, completeness, is still ahead.

3. In the proof that a · 0 = 0, what happened right after applying distributivity to a · (0 + 0)?

Adding −(a·0) to both sides is what isolates and proves a·0 = 0, without ever assuming the result or dividing by a (which would additionally require a ≠ 0).

4. Fill in the blank: a set with + and · satisfying the field axioms, plus a < relation satisfying trichotomy, transitivity, and compatibility with + and ·, is called an ___.

An ordered field is exactly a field plus a compatible order relation — both ℚ and ℝ qualify.

5. Fill in the blank: since the field and order axioms don't distinguish ℝ from ℚ, the real distinguishing property must be the ___ axiom, covered in Lesson 5.

Completeness is the one axiom that ℝ has and ℚ lacks — everything in this lesson is shared ground between the two.
