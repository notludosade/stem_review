1. What does the statement "|aₙ − L| < ε for every n > N" actually say?

The condition applies to every n greater than N, not just one term — the whole tail of the sequence must stay inside the band.

2. Fill in the blank: to prove lim (1/n) = 0 using ε = 0.001 as the challenge value, scratch work requires choosing N with N > ___.

Solving 1/n < ε for n gives n > 1/ε. With ε = 0.001, 1/ε = 1000.

3. If lim aₙ = 6 and lim bₙ = 3, what is lim (aₙ/bₙ) by the quotient rule?

Since B = 3 ≠ 0, the quotient rule applies directly: 6/3 = 2.

4. For the sequence (aₙ) = (1, 1/2, 1/3, 1/4, …), which of the following is a valid subsequence?

Strictly increasing indices is the one requirement — a subsequence can skip terms and must preserve order, but can't reorder or repeat.

5. Fill in the blank: unlike the ordinary convergence definition, the Cauchy condition never mentions a candidate ___ — only how close pairs of the sequence's own terms get to each other.

The defining feature of the Cauchy condition is comparing terms to each other, never to an external candidate limit L.

6. Let aₙ = 5 − 1/(2n) (so a₁ = 4.5, a₂ = 4.75, a₃ ≈ 4.83, …, increasing toward 5). Answer both parts:

(a) Is the Monotone Convergence Theorem applicable to (aₙ)?

(b) Fill in the blank: by the Monotone Convergence Theorem, (aₙ) converges to ___.

(a) 1/(2n) > 0 shrinks toward 0, so each term is larger than the last while never exceeding 5. (b) sup{aₙ} = 5, so the theorem guarantees convergence to 5.

7. Let bₙ = (−1)ⁿ/(n+1) + 2. Answer both parts:

(a) Does Bolzano-Weierstrass guarantee (bₙ) has a convergent subsequence?

(b) Fill in the blank: since (−1)ⁿ/(n+1) → 0 regardless of parity, the entire sequence (bₙ) actually converges to ___.

(a) Boundedness alone is the theorem's entire hypothesis. (b) |(−1)ⁿ/(n+1)| ≤ 1/(n+1) → 0, so bₙ → 0 + 2 = 2.

8. Compute lim ((5n² − 2)/(n² + 4n)) using the algebraic limit laws. Answer both parts:

(a) After dividing numerator and denominator by n², what does the expression become?

(b) Fill in the blank: applying the limit laws, lim ((5n² − 2)/(n² + 4n)) = ___.

(a) Dividing every term by n² rewrites the expression using pieces already known to converge to 0. (b) Numerator → 5, denominator → 1, so the quotient is 5.

9. Consider proving lim ((3n − 1)/n) = 3 directly from the definition. Answer both parts:

(a) What does |(3n−1)/n − 3| simplify to?

(b) Fill in the blank: using ε = 0.005, scratch work requires choosing N with N > 1/ε = ___.

(a) (3n − 1)/n − 3 = (3n − 1 − 3n)/n = −1/n, so the absolute value is 1/n. (b) Forcing 1/n < ε requires n > 1/ε; with ε = 0.005, 1/0.005 = 200.

10. Let aₙ = (−1)ⁿ · (2 + 1/n). Answer both parts:

(a) What are the limit points of (aₙ)?

(b) Fill in the blank: because (aₙ) has two distinct limit points, 2 and −2, the sequence must ___.

(a) Even-indexed terms 2 + 1/n → 2; odd-indexed terms −(2 + 1/n) → −2. (b) Two distinct limit points mean the whole sequence cannot converge — it must diverge.
