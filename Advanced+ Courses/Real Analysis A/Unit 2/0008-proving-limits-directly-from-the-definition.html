Proving Limits Directly from the Definition

The scratch-work-then-proof pattern behind every epsilon-N argument you'll write in this course.

← Lesson 7 Lesson 9 → Contents Glossary →

Lesson 7's definition names what convergence means. Actually proving that a specific sequence converges to a specific limit means finding an N for every ε — and that finding is usually done as private scratch work, kept separate from the clean proof that gets written up.

Worked example: proving 1/n → 0

Claim lim (1/n) = 0.
Scratch work (not part of the final proof) The goal is |1/n − 0| < ε, i.e. 1/n < ε (since n > 0, 1/n is already positive). Solving for n: n > 1/ε. So if N is any natural number with N ≥ 1/ε (the Archimedean Property from Unit 1, Lesson 6, guarantees one exists), then every n > N automatically satisfies n > 1/ε, hence 1/n < ε. That's the N to use.
Proof Let ε > 0. By the Archimedean Property, choose a natural number N with N > 1/ε. Then for any n > N: n > 1/ε, so 1/n < ε (dividing 1 by a larger positive number gives a smaller result). Since 1/n > 0, |1/n − 0| = 1/n < ε. This holds for every n > N, so lim (1/n) = 0. ∎
Why the scratch work stays separate from the proof Scratch work runs backward — starting from the desired conclusion (1/n < ε) and solving for what N needs to be. A proof has to run forward — starting from "let ε > 0" and "let n > N," and arriving at the conclusion. Presenting the backward scratch work as if it were the forward proof is a common mistake; the two serve different purposes; and only the forward version is a valid proof.

A second example, with more algebra

Claim lim ((2n + 1)/n) = 2.
Scratch work |(2n+1)/n − 2| = |(2n + 1 − 2n)/n| = |1/n| = 1/n. Same target as before: want 1/n < ε, so need n > 1/ε.
Proof Let ε > 0. By the Archimedean Property, choose N with N > 1/ε. For any n > N: |(2n+1)/n − 2| = |1/n| = 1/n < 1/N < ε (using n > N implies 1/n < 1/N, and N > 1/ε implies 1/N < ε). So |(2n+1)/n − 2| < ε for every n > N, and lim ((2n+1)/n) = 2. ∎
Pattern to reuse Both proofs follow the same three moves: (1) simplify |aₙ − L| algebraically into something recognizable, (2) find, via scratch work, how large n needs to be to force that expression below ε, (3) write the forward proof using the Archimedean Property to actually produce that N. Nearly every direct convergence proof in this course follows exactly this shape.

Check your recall

No peeking back up — answer from memory first, then check.

1. Why is scratch work kept separate from the final written proof?

Scratch work solves backward for what N needs to be; the actual proof must start from "let ε > 0" and proceed forward to the conclusion.

2. In proving lim (1/n) = 0, what role did the Archimedean Property play?

Without the Archimedean Property, there would be no guarantee that a suitable N even exists — it's the theorem that supplies N.

3. In the second example, |(2n+1)/n − 2| simplified to which expression?

(2n+1)/n − 2 = (2n + 1 − 2n)/n = 1/n exactly, reducing the problem to the same form as the first example.

4. Fill in the blank: solving backward from |aₙ − L| < ε to figure out how large n needs to be is called ___, and is not itself the proof.

Scratch work is the private, backward-reasoning phase that informs the choice of N, kept separate from the forward-reasoning proof.

5. Fill in the blank: unlike scratch work, a valid written proof must reason ___ — starting from "let ε > 0" and arriving at the conclusion.

Forward reasoning, from assumption to conclusion, is what distinguishes a proof from the backward scratch work that produced it.
