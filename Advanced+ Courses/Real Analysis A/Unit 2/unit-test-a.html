1. In the definition lim aₙ = L — for every ε > 0 there exists N such that |aₙ − L| < ε for all n > N — what is N allowed to depend on?

N is chosen in response to ε — that dependency is exactly what the quantifier order "for every ε, there exists an N" encodes.

2. Fill in the blank: to prove lim (1/n) = 0 using ε = 0.01 as the challenge value, scratch work requires choosing N with N > ___.

The scratch work solves 1/n < ε for n, giving n > 1/ε. With ε = 0.01, 1/ε = 100.

3. If lim aₙ = 5 and lim bₙ = −2, what is lim (aₙ · bₙ) by the product rule?

The product rule gives lim(aₙbₙ) = A·B = 5 × (−2) = −10.

4. Which of the following is a valid subsequence of (aₙ) = (2, 4, 6, 8, 10, …)?

A subsequence requires strictly increasing indices — it can skip terms, but can never reorder or repeat an index.

5. Fill in the blank: a sequence (aₙ) is Cauchy if for every ε > 0 there is N such that |aₘ − aₙ| < ε for all m, n > N — meaning terms get arbitrarily close to ___ rather than to some fixed candidate limit L.

The Cauchy condition never mentions a limit L — it compares pairs of the sequence's own terms to each other.

6. Let aₙ = 3 − 1/n (so a₁ = 2, a₂ = 2.5, a₃ = 8/3, …, increasing toward 3). Answer both parts:

(a) Is (aₙ) increasing and bounded above, so the Monotone Convergence Theorem applies?

(b) Fill in the blank: by the Monotone Convergence Theorem, (aₙ) converges to sup{aₙ}, which here equals ___.

(a) Since 1/n > 0 always shrinks, each term is larger than the last and never reaches 3. (b) sup{aₙ} = 3, so the Monotone Convergence Theorem guarantees convergence to 3.

7. Let aₙ = (−1)ⁿ · (1 + 1/n). Answer both parts:

(a) Does the Bolzano-Weierstrass Theorem guarantee a convergent subsequence of (aₙ)?

(b) Fill in the blank: the even-indexed terms of (aₙ) = (−1)ⁿ(1 + 1/n) converge to ___.

(a) Boundedness alone is the entire hypothesis of Bolzano-Weierstrass — no monotonicity is required. (b) For even n, (−1)ⁿ = 1, so aₙ = 1 + 1/n → 1.

8. Compute lim ((4n² + n)/(2n² + 3)) using the algebraic limit laws. Answer both parts:

(a) After dividing numerator and denominator by n², what does the expression become?

(b) Fill in the blank: applying the sum and quotient rules, lim ((4n² + n)/(2n² + 3)) = ___.

(a) Dividing every term by n² rewrites the expression in terms of pieces already known to converge. (b) The numerator → 4 and denominator → 2, so the quotient rule gives 4/2 = 2.

9. Consider proving lim ((n+2)/n) = 1 directly from the definition. Answer both parts:

(a) What does |(n+2)/n − 1| simplify to?

(b) Fill in the blank: using ε = 0.02, scratch work requires choosing N with N > 2/ε = ___.

(a) (n+2)/n − 1 = (n + 2 − n)/n = 2/n. (b) Forcing 2/n < ε requires n > 2/ε; with ε = 0.02, 2/0.02 = 100.

10. Let aₙ = (−1)ⁿ · n/(n+1). Answer both parts:

(a) What are the limit points of (aₙ)?

(b) Fill in the blank: since (aₙ) has two different limit points, 1 and −1, the sequence itself must ___ (that is, fail to converge).

(a) Even-indexed terms n/(n+1) → 1; odd-indexed terms −n/(n+1) → −1. (b) A convergent sequence forces every subsequence to the same limit, so two different limit points mean the sequence must diverge.
