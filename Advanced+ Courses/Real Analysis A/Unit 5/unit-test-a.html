1. The derivative f′(a) is defined as which kind of limit?

f′(a) is defined as an ordinary functional limit (Unit 4, Lesson 19), applied specifically to the difference quotient — no new kind of limit is introduced.

2. Let f(x) = x² + 3x. Answer both parts:

(a) For x ≠ a, the difference quotient (f(x) − f(a))/(x − a) simplifies to which expression?

(b) Fill in the blank: taking the limit as x → a of that simplified expression gives f′(a) = ___.

(a) f(x) − f(a) = (x²−a²) + 3(x−a) = (x−a)(x+a+3), so dividing by (x−a) leaves x+a+3 for x≠a. (b) The limit of x+a+3 as x→a is a+a+3 = 2a+3.

3. Fill in the blank: every differentiable function is ___, though the converse can fail, as f(x) = |x| at x = 0 shows.

Writing f(x)−f(a) as the difference quotient times (x−a) forces it to 0 as x→a, since the quotient converges to f′(a) and (x−a)→0 — this is exactly why differentiability implies continuity.

4. Let f(x) = |x − 2|. Answer both parts:

(a) Is f differentiable at x = 2?

(b) Fill in the blank: the right-hand difference quotient approaches ___, while the left-hand difference quotient approaches −1.

(a) f is continuous at 2 (it's a composition of continuous functions) but not differentiable there. (b) For x > 2, (|x−2|−0)/(x−2) = 1; for x < 2, it equals −1 — since these disagree, the two-sided limit defining f′(2) doesn't exist.

5. In proving the product rule (fg)′(a) = f′(a)g(a) + f(a)g′(a) directly from the definition, which algebraic move is key?

This additive-insertion trick mirrors the same technique from Unit 2, Lesson 9's sequence product rule — it isolates one function's own difference quotient in each of the two resulting pieces.

6. Let f(x) = x² − 4x on [0, 4]. Answer both parts:

(a) Does Rolle's Theorem apply to f on [0,4]?

(b) Fill in the blank: the point c guaranteed by Rolle's Theorem, where f′(c) = 0, is c = ___.

(a) f(0)=0 and f(4)=16−16=0, and polynomials are continuous and differentiable everywhere, so Rolle's Theorem's hypotheses hold. (b) f′(x) = 2x − 4 = 0 exactly at x = 2, which lies in (0,4).

7. If f is differentiable at an interior point c ∈ (a,b) where f(c) is the maximum value of f on [a,b], what must f′(c) equal?

The right-hand difference quotient forces f′(c) ≤ 0 and the left-hand one forces f′(c) ≥ 0; since differentiability means both one-sided limits must agree, the only value satisfying both is 0.

8. Let f(x) = x² on [1, 4]. Answer both parts:

(a) What is the average rate of change of f on [1,4]?

(b) Fill in the blank: the Mean Value Theorem guarantees f′(c) = 5 at c = ___.

(a) (f(4)−f(1))/(4−1) = (16−1)/3 = 5. (b) f′(x) = 2x = 5 gives c = 2.5, which indeed lies in (1,4).

9. Fill in the blank: if f′(x) = 0 for every x on an interval, then f must be ___ on that interval.

For any x₁ < x₂, MVT gives some c with f′(c) = (f(x₂)−f(x₁))/(x₂−x₁) = 0, forcing f(x₂) = f(x₁) — since this holds for every pair, f is constant.

10. Let f(x) = x³ + x. Answer both parts:

(a) Since f′(x) = 3x² + 1 > 0 for every real x, what does the Mean-Value-Theorem-based monotonicity theorem conclude about f?

(b) Fill in the blank: f′(x) = 3x² + 1 reaches its smallest value, ___, at x = 0, and is larger everywhere else — so it is always positive.

(a) MVT turns the pointwise fact f′(x)>0 at every point into the global comparison f(x₁)<f(x₂) for any x₁<x₂. (b) 3x² ≥ 0 always, with equality at x=0, so 3x²+1's minimum value is 1 — still positive.
