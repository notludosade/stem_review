Rolle's Theorem

If a function starts and ends at the same height, it must have a flat spot somewhere in between — the special case that unlocks the Mean Value Theorem.

← Lesson 26 Lesson 28 → Contents Glossary →

This lesson proves the special case f(a) = f(b) first, using the Extreme Value Theorem (Unit 4, Lesson 23) directly. Lesson 28 then shows the general Mean Value Theorem reduces to this exact case with one algebraic trick.

Theorem — Rolle's Theorem Let f be continuous on [a, b] and differentiable on (a, b), with f(a) = f(b). Then there exists c ∈ (a, b) with f′(c) = 0.

Proof, using the Extreme Value Theorem

Proof By the Extreme Value Theorem (Unit 4, Lesson 23), f attains a maximum and minimum on [a, b] (which is compact). Case 1: both the max and min occur at the endpoints a and b. Since f(a) = f(b), the max and min values are equal, so f is constant on [a, b], meaning f′(c) = 0 for every c ∈ (a, b). Case 2: at least one of the max or min occurs at some interior point c ∈ (a, b). Since c is an interior extremum and f is differentiable there, a short argument (below) shows f′(c) = 0 directly. ∎
Lemma — Interior Extrema Have Zero Derivative If f is differentiable at c ∈ (a, b) and f(c) is the maximum (or minimum) of f on [a, b], then f′(c) = 0.
Proof Suppose f(c) is a maximum. For x > c near c: (f(x) − f(c))/(x − c) ≤ 0 (numerator ≤ 0 since f(c) is the max, denominator > 0), so taking the limit as x → c⁺ gives f′(c) ≤ 0. For x < c near c: (f(x) − f(c))/(x − c) ≥ 0 (numerator ≤ 0, denominator < 0, so the quotient is ≥ 0), so the limit as x → c⁻ gives f′(c) ≥ 0. Since f is differentiable at c, both one-sided limits must equal the same f′(c) — and the only number that is simultaneously ≤ 0 and ≥ 0 is 0. So f′(c) = 0. ∎
Why both one-sided inequalities are needed Either inequality alone only bounds f′(c) on one side. It's specifically because c is an interior point — so both one-sided limits exist and must agree — that squeezing from both sides forces f′(c) to be exactly 0. This is exactly why the theorem requires differentiability on the open interval (a,b): an extremum at an endpoint a or b only has one side to check, and the argument breaks down (endpoints of [a,b] genuinely can have nonzero one-sided derivative there).
Example f(x) = x² − 2x on [0, 2]: f(0) = 0 = f(2), continuous and differentiable everywhere. Rolle's Theorem guarantees some c ∈ (0,2) with f′(c) = 0. Indeed f′(x) = 2x − 2 = 0 at x = 1 ∈ (0,2), confirming the theorem concretely.

No peeking back up — answer from memory first, then check.

1. What does Rolle's Theorem conclude, given f(a) = f(b)?

Rolle's Theorem guarantees a single interior point with zero derivative — not that f is constant everywhere (Case 1 aside).

2. Which earlier theorem does Rolle's Theorem's proof rely on to guarantee f attains a maximum and minimum on [a,b]?

The Extreme Value Theorem is exactly what guarantees the max and min are actually attained somewhere on the compact interval [a,b].

3. In the interior-extrema lemma's proof, why does squeezing from both sides force f′(c) = 0?

This is the squeeze that makes the lemma work — both one-sided bounds agreeing forces the shared value to be exactly 0.

4. Fill in the blank: the interior-extrema lemma specifically requires the extremum to occur at an ___ point of [a,b], not an endpoint.

Interior is essential — only interior points have both one-sided difference quotients available to squeeze the derivative to 0.

5. Fill in the blank: the theorem guaranteeing a zero-derivative point when f(a) = f(b) is called ___.

Rolle's Theorem is the special case that Lesson 28's Mean Value Theorem will generalize.
