The Extreme Value Theorem

Why a continuous function on a closed, bounded interval doesn't just approach a maximum — it actually attains one.

← Lesson 22 Lesson 24 → Contents Glossary →

Unit 3, Lesson 16 built compactness specifically to make this theorem work. This lesson delivers on that setup: compactness is exactly the ingredient that upgrades "the function's values have a supremum" to "the function actually reaches that supremum somewhere."

Theorem — Extreme Value Theorem If f is continuous on a compact set K, then f attains both a maximum and a minimum value on K — that is, there exist c, d ∈ K with f(c) ≥ f(x) ≥ f(d) for all x ∈ K.

Step 1 — continuous image of compact is bounded

Lemma If f is continuous on a compact set K, then f(K) is bounded.
Proof Suppose not: then for every n, there is xₙ ∈ K with |f(xₙ)| > n. Since K is compact, (xₙ) has a subsequence (xnₖ) converging to some x ∈ K (Unit 3, Lesson 16's sequential definition). By continuity, f(xnₖ) → f(x), so (f(xnₖ)) is convergent, hence bounded (Unit 2, Lesson 9's "convergent implies bounded" fact). But |f(xnₖ)| > nₖ → ∞, a contradiction. So f(K) is bounded. ∎

Step 2 — the bound is attained

Proof of the theorem By Step 1, f(K) is bounded, so s = sup f(K) exists (completeness axiom, Unit 1 Lesson 5). By the epsilon characterization of supremum, for each n there is xₙ ∈ K with f(xₙ) > s − 1/n, so f(xₙ) → s. Since K is compact, (xₙ) has a subsequence xnₖ → c for some c ∈ K. By continuity, f(xnₖ) → f(c). But f(xnₖ) is a subsequence of f(xₙ) → s, so f(xnₖ) → s too (Unit 2, Lesson 11: subsequences inherit the limit). Since limits are unique, f(c) = s — the supremum is actually attained at c. The minimum follows by the same argument applied to −f. ∎
Why compactness, specifically, is the missing ingredient On (0, 1) (not compact — bounded but not closed), f(x) = x is continuous and bounded, with supremum 1, but no point of (0,1) actually attains it. Compactness is precisely what rules this out: it guarantees the maximizing sequence xₙ has a subsequence converging to a point still inside the set, which is exactly the extra ingredient (0,1) lacks.
Connecting back to Unit 3 Since compact subsets of ℝ are exactly the closed and bounded sets (Heine-Borel, Unit 3 Lesson 17), the Extreme Value Theorem is most often stated as: a continuous function on a closed, bounded interval [a, b] attains a maximum and minimum. This is the exact form used without proof throughout AP Calc BC (for instance, to justify that optimization problems on a closed interval always have a solution).

1. What does the Extreme Value Theorem guarantee, beyond just boundedness of f(K)?

Attainment — not just existence of a bound — is the theorem's real content, and exactly what compactness supplies.

2. Why does f(x) = x on (0, 1) fail to attain its supremum, even though it's continuous and bounded?

This is exactly the failure mode compactness rules out — the limit of the maximizing sequence escapes the set.

3. In the theorem's proof, why does f(xnₖ) → s, even though (xₙ) itself might not converge?

f(xₙ) itself converges to s by construction; the subsequence-inherits-the-limit fact from Unit 2 carries that convergence to the specific subsequence f(x_{n_k}).

4. Fill in the blank: the Extreme Value Theorem requires f to be continuous on a ___ set in order to guarantee the maximum and minimum are attained.

Compactness is precisely the hypothesis needed — bounded alone (as (0,1) shows) is not enough.

5. Fill in the blank: the proof sets s equal to the ___ of f(K), then shows a point c ∈ K exists with f(c) = s.

Supremum is the value the proof shows is actually attained, using compactness to extract a convergent subsequence.
