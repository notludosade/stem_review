The Epsilon-Delta Definition of a Functional Limit

AP Calc BC's "as x approaches a" made precise — and connected directly to Unit 2's sequence limits.

← Unit 3, Lesson 18 Lesson 20 → Contents Glossary →

AP Calc BC introduced limits of functions using dynamic language — "as x gets closer to a, f(x) gets closer to L." This lesson replaces that language with the same kind of static, quantifier-based definition Unit 2 used for sequences, and this course now writes proofs directly from it.

The definition

Definition — Functional Limit Let f be a function defined on a set containing an interval around a (except possibly at a itself). We say limx→a f(x) = L if: for every ε > 0, there exists δ > 0 such that whenever 0 < |x − a| < δ, it follows that |f(x) − L| < ε.

The structure directly parallels Unit 2's ε-N definition: ε still measures how close the output must land to the target L, but δ (a distance in the input) replaces N (an index) as the "how far is close enough" quantity being solved for.

Worked example

Worked Example Prove limx→3 (2x + 1) = 7 directly from the definition. Scratch work: |f(x) − L| = |(2x+1) − 7| = |2x − 6| = 2|x − 3|. To force this below ε, need |x − 3| < ε/2 — so δ = ε/2 works. Proof: Let ε > 0. Choose δ = ε/2. Suppose 0 < |x − 3| < δ. Then |(2x+1) − 7| = 2|x − 3| < 2δ = ε. So the limit holds. ∎
Why the scratch-work/proof split from Unit 2 still applies Exactly the same methodology from Unit 2, Lesson 8 carries over unchanged: work backward from |f(x) − L| < ε to discover what δ needs to be, then write the proof forward, starting from the chosen δ. The only change is that the "distance" being controlled is now in the input (|x − a|) rather than an index n.

Whenever x stays within δ of a, f(x) is guaranteed to stay within ε of L.

Check your recall

No peeking back up — answer from memory first, then check.

1. In the epsilon-delta definition, what does δ measure?

δ is a distance in the input (x from a), playing the role N played for sequences — the "how close is close enough" quantity solved for.

2. Why does the definition require 0 < |x − a| rather than allowing x = a?

Excluding x = a is what lets the limit definition apply even to functions undefined at the point itself — a key feature carried through to derivatives in Unit 5.

3. In the worked example proving lim(2x+1) = 7 as x→3, why did scratch work land on δ = ε/2?

The algebraic simplification |(2x+1)−7| = 2|x−3| directly determines the needed δ, exactly mirroring Unit 2's scratch-work technique.

4. Fill in the blank: in the functional limit definition, ___ measures the allowed distance from x to a.

Delta is the input-side tolerance, playing the same structural role N played for sequences in Unit 2.

5. Fill in the blank: just as in Unit 2, finding the right δ is done through ___ kept separate from the forward proof.

Scratch work — backward reasoning to discover δ — is kept distinct from the forward proof, exactly as established in Unit 2, Lesson 8.
