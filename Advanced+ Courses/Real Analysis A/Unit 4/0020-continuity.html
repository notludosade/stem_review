Continuity

"You can draw it without lifting your pen" made precise, plus a second, sequential definition that turns out to say exactly the same thing.

← Lesson 19 Lesson 21 → Contents Glossary →

Continuity is simply the case where a function's limit at a point matches its actual value there. This lesson makes that precise and gives an equivalent, often more convenient, sequential test — mirroring Unit 3, Lesson 15's sequential characterization of limit points.

The epsilon-delta definition

Definition — Continuity at a Point f is continuous at a point a in its domain if limx→a f(x) = f(a). Spelled out: for every ε > 0, there exists δ > 0 such that whenever |x − a| < δ (x in the domain of f), it follows that |f(x) − f(a)| < ε.
Why this drops the "0 <" restriction from Lesson 19 Lesson 19's functional-limit definition explicitly excluded x = a (0 < |x − a|), since a limit doesn't need f to be defined at a at all. Continuity requires the opposite: f(a) must exist, and the limit must actually equal it — so x = a is allowed back in, since |f(a) − f(a)| = 0 < ε trivially holds there anyway.

A sequential characterization

Theorem f is continuous at a if and only if for every sequence (xₙ) in the domain of f with xₙ → a, it follows that f(xₙ) → f(a).
Why this is often the easier tool for proving discontinuity To prove f is not continuous at a, it's often far easier to exhibit one specific sequence xₙ → a for which f(xₙ) does not converge to f(a), than to negate the epsilon-delta definition directly. This mirrors exactly how Unit 2, Lesson 11's subsequence divergence test made proving non-convergence of sequences easier than working straight from the definition.
Example — a function discontinuous at 0 Let f(x) = 1 if x is rational, 0 if x is irrational (this "indicator of ℚ" function, sometimes called Dirichlet's function). Take xₙ = a rational sequence converging to any point c (possible by density of ℚ, Unit 1 Lesson 6): f(xₙ) = 1 for all n, so f(xₙ) → 1. But taking yₙ = an irrational sequence converging to the same c gives f(yₙ) → 0. Since 1 ≠ 0, f is discontinuous at every single point c ∈ ℝ.

1. What does it mean for f to be continuous at a point a?

Continuity is exactly the case where the limit (Lesson 19) matches the function's actual value at that point.

2. Why is exhibiting a single sequence xₙ → a with f(xₙ) not converging to f(a) often the easiest way to prove discontinuity?

The sequential characterization's "if and only if" means one bad sequence is a complete, rigorous disproof.

3. In the Dirichlet's function example, why is f discontinuous at every point c ∈ ℝ?

Density of both ℚ and its complement near every real number is exactly what makes this function discontinuous absolutely everywhere.
