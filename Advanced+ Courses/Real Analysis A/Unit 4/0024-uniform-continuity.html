Uniform Continuity

The closing lesson of Unit 4: a single δ that works everywhere at once — and why compactness is again exactly what makes that possible.

← Lesson 23 Unit 5, Lesson 25 → Contents Glossary →

Lesson 20's continuity is a pointwise property — δ is allowed to depend on both ε and the point a. This closing lesson of Unit 4 asks when a single δ can be made to work at every point simultaneously, and shows compactness is again the deciding factor — setting up Unit 6's construction of the Riemann integral, which depends on exactly this property.

The definition

Definition — Uniform Continuity f is uniformly continuous on a set A if: for every ε > 0, there exists δ > 0 such that for all x, y ∈ A, |x − y| < δ implies |f(x) − f(y)| < ε.
Why "uniform" is the operative word Compare to Lesson 20's ordinary continuity: there, δ is chosen after both ε and a point a are fixed, so different points can demand different δ's. Here, one δ must work for every pair of points in A at once — the same tolerance, uniformly, everywhere. Every uniformly continuous function is continuous (immediate from the definitions), but the converse can fail, as the next example shows.

A continuous function that is not uniformly continuous

Example f(x) = 1/x is continuous on (0, 1) but not uniformly continuous there. Intuitively: near x = 0, the function's slope grows without bound, so keeping outputs within a fixed ε forces δ to shrink as x → 0 — no single δ can work near 0 and also further out. Concretely, for x = 1/n and y = 1/(n+1) (both in (0,1)), |x − y| = 1/(n(n+1)) → 0, yet |f(x) − f(y)| = |n − (n+1)| = 1 always — so no δ can force the outputs within, say, ε = 1/2 for pairs this close together as n grows.

The theorem: compactness forces uniformity

Theorem If f is continuous on a compact set K, then f is uniformly continuous on K.
Proof sketch Suppose not: then there is some ε > 0 such that for every δ = 1/n, there exist xₙ, yₙ ∈ K with |xₙ − yₙ| < 1/n but |f(xₙ) − f(yₙ)| ≥ ε. Since K is compact, (xₙ) has a subsequence xnₖ → c ∈ K. Since |xnₖ − ynₖ| < 1/nₖ → 0, the corresponding ynₖ → c as well (squeezed toward the same limit). By continuity of f at c, both f(xnₖ) → f(c) and f(ynₖ) → f(c), so |f(xnₖ) − f(ynₖ)| → 0 — contradicting |f(xₙ) − f(yₙ)| ≥ ε for every n, including these. So f must be uniformly continuous on K. ∎
Why (0,1) failing to be compact is exactly what 1/x exploits 1/x's counterexample sequences xₙ = 1/n, yₙ = 1/(n+1) converge to 0 — which is not in (0,1). On a compact set, this escape route is closed off: the proof's contradiction depends entirely on the limit point c staying inside K, which compactness guarantees and (0,1)'s missing endpoint does not.

1. What is the key difference between ordinary continuity and uniform continuity?

Uniformity means one δ serves the whole set simultaneously, not chosen separately at each point as in ordinary continuity.

2. Why is f(x) = 1/x not uniformly continuous on (0, 1)?

The unbounded steepness of 1/x near 0 is exactly what defeats any single uniform δ.

3. In the theorem's proof, what role does compactness of K play in reaching the contradiction?

Compactness's guarantee that the limit stays inside K is exactly what 1/x's counterexample on (0,1) is missing.

Uniformly continuous is the term this lesson defines, contrasted with the pointwise flavor of ordinary continuity.

Compactness is once again the deciding structural property, exactly as it was in the Extreme Value Theorem.
