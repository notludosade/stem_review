1. Solve: 5x − 3 = 22. What is x?

Add 3 to both sides: 5x = 25. Divide by 5: x = 5.

2. Fill in the blank: solving 6x − 2 = 6x + 5 simplifies to the false statement −2 = 5, so the equation has ___ solution.

When the variable cancels and leaves a false statement, no value of x makes the equation true.

3. Solve: −3x > 12. What is the solution?

Dividing both sides by −3 flips the inequality sign: x < −4.

4. Fill in the blank: the graph of x ≥ −2 uses a(n) ___ circle at −2, since −2 is included in the solution.

≥ and ≤ include the boundary value itself, shown with a closed (filled) circle.

5. Which value is NOT part of the solution set of −1 < x ≤ 4?

The strict "<" excludes −1 itself; the "≤" includes 4. Only −1 is excluded from the solution set.

6. Solve the system y = 3x − 2 and y = −2x + 8. Answer both parts:

(a) What is x?

(b) What is y?

Setting 3x − 2 = −2x + 8 gives 5x = 10, so x = 2; then y = 3(2) − 2 = 4.

7. Solve the system 2x + y = 9 and x − y = 3. Answer both parts:

(a) What is x?

(b) What is y?

Adding the two equations cancels y: 3x = 12, so x = 4; substituting back, 4 − y = 3, so y = 1.

8. Answer both parts about number of solutions:

(a) How many solutions does the system y = 2x + 1 and y = 2x − 3 have?

(b) How many solutions does the system y = 2x + 1 and 2y = 4x + 2 have?

(a) Same slope, different intercepts — the lines are parallel and never meet. (b) Dividing the second equation by 2 gives y = 2x + 1, the exact same line, so every point on it is a solution.

9. Solve: 2(x − 3) + 4 = 3x − 5. Answer both parts:

(a) Fill in the blank: distributing 2(x − 3) gives ___.

(b) Fill in the blank: solving the full equation gives x = ___.

Distributing gives 2x − 6 + 4 = 3x − 5, or 2x − 2 = 3x − 5. Adding 5 and subtracting 2x from both sides gives x = 3.

10. Two numbers have a sum of 15 and a difference of 3. Answer both parts:

(a) What is the larger number?

(b) What is the smaller number?

Setting up x + y = 15 and x − y = 3 and adding gives 2x = 18, so x = 9 and y = 6.
