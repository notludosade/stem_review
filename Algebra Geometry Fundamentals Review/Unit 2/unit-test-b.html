1. Which of these is NOT a quadratic equation?

7x + 4 = 0 has no x² term (a = 0), which makes it linear, not quadratic.

2. For y = 3x² − 2x + 5, which way does the parabola open?

a = 3 is positive, and a positive leading coefficient always opens a parabola upward.

3. If (x − 4)(x + 2) = 0, what are the solutions?

x − 4 = 0 gives x = 4; x + 2 = 0 gives x = −2.

4. Fill in the blank: x² + 9x + 20 = 0 factors as (x + 4)(x + 5) = 0. Its less negative (larger) solution is x = ___.

The factors give x = −4 or x = −5; the larger (less negative) of the two is −4.

5. A quadratic has a negative discriminant. How many real solutions does it have?

A negative discriminant means the quadratic formula asks for the square root of a negative number, which has no real value.

6. Solve 2x² + 7x − 4 = 0 using the quadratic formula. Answer both parts:

(a) What is the discriminant?

(b) What is the positive solution?

Discriminant = 7² − 4(2)(−4) = 49 + 32 = 81. x = (−7 ± 9)/4, giving x = 0.5 or x = −4 — the positive one is 0.5.

7. For x² − 14x + 49 = 0, answer both parts:

(a) What is the discriminant?

(b) What is the repeated solution?

Discriminant = 196 − 196 = 0, so there's one repeated solution: x = −b/(2a) = 14/2 = 7. (Check: x² − 14x + 49 = (x − 7)².)

8. Solve x² − 3x − 18 = 0 by factoring. Answer both parts:

(a) Fill in the blank: x² − 3x − 18 factors as (x − 6)(x + ___).

(b) Fill in the blank: the two solutions are x = 6 and x = ___.

−6 and 3 multiply to −18 and add to −3, so x² − 3x − 18 = (x − 6)(x + 3) = 0, giving x = 6 or x = −3.

9. For x² + 4x + 9 = 0, answer both parts:

(a) What is the sign of the discriminant?

(b) How many real solutions does the equation have?

Discriminant = 16 − 36 = −20, which is negative — so the equation has no real solutions.

10. A rectangle's length is 4 more than its width, and its area is 45. Answer both parts:

(a) What is the width?

(b) What is the length?

w(w + 4) = 45 leads to w² + 4w − 45 = 0, which factors as (w + 9)(w − 5) = 0. Width must be positive, so w = 5 and length = 9.
