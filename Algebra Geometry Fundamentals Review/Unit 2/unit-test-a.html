1. Which of these is NOT a quadratic equation?

5x − 2 = 0 has no x² term (a = 0), which makes it linear, not quadratic.

2. For y = −2x² + 3x − 1, which way does the parabola open?

a = −2 is negative, and a negative leading coefficient always opens a parabola downward.

3. If (x + 6)(x − 1) = 0, what are the solutions?

x + 6 = 0 gives x = −6; x − 1 = 0 gives x = 1.

4. Fill in the blank: x² + 7x + 10 = 0 factors as (x + 2)(x + 5) = 0. Its more negative solution is x = ___.

The factors give x = −2 or x = −5; the more negative of the two is −5.

5. A quadratic has discriminant exactly 0. How many real solutions does it have?

A discriminant of 0 means the ± in the quadratic formula adds or subtracts nothing, collapsing to one repeated solution.

6. Solve 2x² − 3x − 2 = 0 using the quadratic formula. Answer both parts:

(a) What is the discriminant?

(b) What is the positive solution?

Discriminant = (−3)² − 4(2)(−2) = 9 + 16 = 25. x = (3 ± 5)/4, giving x = 2 or x = −0.5 — the positive one is 2.

7. For x² − 10x + 25 = 0, answer both parts:

(a) What is the discriminant?

(b) What is the repeated solution?

Discriminant = 100 − 100 = 0, so there's one repeated solution: x = −b/(2a) = 10/2 = 5. (Check: x² − 10x + 25 = (x − 5)².)

8. Solve x² − 2x − 15 = 0 by factoring. Answer both parts:

(a) Fill in the blank: x² − 2x − 15 factors as (x − 5)(x + ___).

(b) Fill in the blank: the two solutions are x = 5 and x = ___.

−5 and 3 multiply to −15 and add to −2, so x² − 2x − 15 = (x − 5)(x + 3) = 0, giving x = 5 or x = −3.

9. For x² + 2x + 5 = 0, answer both parts:

(a) What is the sign of the discriminant?

(b) How many real solutions does the equation have?

Discriminant = 4 − 20 = −16, which is negative — so the equation has no real solutions.

10. A rectangle's length is 3 more than its width, and its area is 40. Answer both parts:

(a) What is the width?

(b) What is the length?

w(w + 3) = 40 leads to w² + 3w − 40 = 0, which factors as (w + 8)(w − 5) = 0. Width must be positive, so w = 5 and length = 8.
