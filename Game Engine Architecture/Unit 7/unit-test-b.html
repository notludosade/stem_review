1. Why do engines typically write core systems in a compiled language but gameplay logic in a scripting language?

The split matches each language's strength to what each layer actually needs.

2. Fill in the blank: a distinct, loadable collection of game state — a menu, a level, a loading screen — is called a ___.

A scene is the loadable unit a state machine transitions between.

3. Why must the scene graph resolve world transforms after physics runs, not before?

Rendering needs post-physics positions, so the scene graph resolves after physics.

4. Fill in the blank: seeing a script edit take effect immediately in a running game, with no recompile, is called ___.

Hot-reloading is scripting's key iteration-speed advantage.

5. What guarantee does a state machine provide that a handful of independent boolean flags doesn't?

Structural enforcement of exactly one active state is the core guarantee.

6. Answer both parts about Unit 1's engine-vs-game distinction applied to scripting:

(a) The scripting layer is specifically meant to hold...

(b) This connects directly back to...

Scripting is the natural home for the game-specific logic Unit 1 first distinguished.

7. From the Paused state, only two transitions are defined: back to Playing, or to Menu. Answer both parts:

(a) Jumping directly from Paused to GameOver would...

(b) Transitioning from Paused back to Playing should...

Only explicitly defined transitions are valid, and resuming preserves prior state.

8. Trace a platformer frame: player holds right, scripting sets velocity, physics integrates and checks collision. Answer both parts:

(a) Scripting must run before physics because...

(b) The render pipeline draws the result...

Each stage depends on fresh output from the one before it, ending in rendering last.

9. Answer both parts about compiled core vs. scripting iteration speed:

(a) Recompiling the engine core to test a gameplay tweak typically costs...

(b) A scripting layer with hot-reload avoids this cost by...

Hot-reload avoids the recompile-and-restart cost that a compiled core always pays.

10. Answer both parts about the capstone's full-frame architecture:

(a) The state machine's role at the start of a frame is to determine...

(b) Fill in the blank: the game loop typically drives the ECS using a ___ timestep, for the stability reasons covered in Unit 2 and Unit 5.

The state machine gates which scene runs; a fixed timestep keeps physics stable within it.
