1. What does "hot-reloading" a script actually mean?

Hot-reloading applies a script edit live, without a recompile or restart.

2. Fill in the blank: a system always in exactly one of a fixed set of named states, moving only via defined transitions, is a ___.

A state machine enforces exactly one active state at a time.

3. Why does the scripting system typically run before the physics system in a single frame?

Physics needs fresh gameplay intent before it integrates that frame.

4. Fill in the blank: a separate, usually interpreted language embedded in an engine to write game-specific logic is the ___.

The scripting layer is where game-specific logic is meant to live.

5. What happens to a level's scene when the game transitions from Playing to Paused?

Pausing selectively stops update() while the scene stays loaded and still renders.

6. A designer wants to try five different jump heights in an afternoon. Answer both parts:

(a) Through the compiled engine core, each change costs...

(b) Through a scripting layer with hot-reload, each change instead costs...

Hot-reload is exactly what removes the recompile-and-restart cost for gameplay tuning.

7. A codebase uses independent booleans isPaused, isInMenu, and isGameOver instead of a state machine. Answer both parts:

(a) The risk with this approach is that...

(b) A state machine fixes this by making "exactly one state" a property of...

A state machine structurally rules out invalid combinations that loose booleans allow.

8. Answer both parts about a platformer frame trace:

(a) When the player's feet AABB overlaps a platform, collision response...

(b) After physics resolves this, the scene graph and renderer must run...

Rendering must always reflect state after physics has resolved collisions.

9. Answer both parts about why engines don't write everything in a scripting language:

(a) An interpreted language doing millions of physics operations every frame would be...

(b) The engine core and gameplay logic split exists because the two layers have...

Performance and iteration speed are genuinely competing goals, which is why the split exists.

10. Answer both parts about the underlying rule behind subsystem ordering:

(a) Fill in the blank: the piece streaming assets into a fixed memory budget, running underneath every other subsystem, is the ___.

(b) Nearly every subsystem ordering decision in this capstone traces back to...

Freshness of input between stages explains the whole frame's ordering, tracing back to Lesson 4.
