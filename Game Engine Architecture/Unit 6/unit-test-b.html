1. When does the import pipeline typically convert a source asset into its runtime form?

Conversion happens once ahead of time so runtime loading itself stays cheap.

2. Fill in the blank: the fixed amount of fast memory a game may use for assets at any one time is its ___.

The memory budget is the hard ceiling asset loading has to respect.

3. What does streaming decide, based on the player's position?

Streaming manages memory residency based on proximity to the player.

4. Fill in the blank: the fast-loading, engine-native format produced by the import pipeline is called a ___.

Runtime assets are the import pipeline's output format, optimized for the engine.

5. What does "evicting" an asset mean?

Eviction removes an asset from memory, not from disk.

6. A .blend file stores an artist's entire editable scene, layers included. Answer both parts:

(a) The engine only actually needs, at runtime...

(b) This gap between editing needs and runtime needs is exactly why...

The import pipeline bridges the gap between editor-friendly and runtime-friendly formats.

7. Answer both parts connecting asset memory management to Systems Programming's heap lesson:

(a) A leaked asset reference is dangerous for the same underlying reason as...

(b) The key difference is that a leaked game asset on a console tends to...

Same lifetime-tracking problem as heap leaks, but with a much smaller, harder ceiling.

8. Answer both parts about a mountain village example:

(a) A house at the far edge of the village, still visible but distant, renders at...

(b) A house well past the village entirely might be...

LOD scales rendering detail with distance; streaming controls whether the asset is loaded at all.

9. Why does the engine convert a texture ahead of time, rather than at game launch?

Baking conversion in ahead of time keeps actual game launches fast.

10. Answer both parts about why streaming and LOD are usually paired:

(a) Using only LOD, without streaming, would still leave...

(b) Using only streaming, without LOD, would still render...

Each technique alone leaves the other problem unsolved, which is why they're paired.
