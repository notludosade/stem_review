1. What is a "source asset"?

Source assets are editor-facing, distinct from the converted runtime format.

2. Fill in the blank: when a needed asset would push memory past budget, an existing asset gets ___ to make room.

Eviction frees memory by unloading an asset judged least likely needed soon.

3. Why does a distant object benefit from a lower level of detail?

LOD trades invisible extra detail for real, measurable rendering savings.

4. Fill in the blank: the automated process converting a source asset into a runtime-ready format is the ___.

The import pipeline bridges editor formats and runtime formats.

5. What determines a game's memory budget?

The budget is externally fixed by the hardware the game targets.

6. A 4096×4096 .png texture goes through the import pipeline. Answer both parts:

(a) The import pipeline compresses it into a GPU-native format and generates...

(b) This conversion happens...

Import bakes conversion in once so runtime loading itself stays cheap.

7. A player leaves a forest zone and enters a cave. Answer both parts:

(a) The forest's high-resolution textures, no longer visible or needed, get...

(b) A leaked asset reference on a console is especially dangerous because...

Eviction manages the same reference-lifetime problem from systems programming, at a harder ceiling.

8. Answer both parts about why streaming and LOD are usually paired:

(a) Streaming alone bounds...

(b) LOD alone bounds...

Each technique solves one half of the problem; together they cover both memory and rendering cost.

9. Answer both parts comparing this to Software Engineering's build pipeline:

(a) Baking a texture into a runtime format ahead of time mirrors...

(b) A .blend file storing a full editable scene, versus the runtime mesh actually shipped, illustrates...

Editor and runtime formats are deliberately different, optimized for different needs.

10. Answer both parts about a mountain village with 40 houses:

(a) A house right next to the player renders at...

(b) Fill in the blank: a house far past the village entirely might not be loaded into memory yet at all, waiting on ___ to bring it in as the player approaches.

LOD adjusts rendering detail; streaming decides whether an asset is loaded at all.
