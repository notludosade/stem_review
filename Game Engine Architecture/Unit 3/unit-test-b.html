1. What is the "diamond problem" specifically about?

It's specifically about ambiguous inherited-method resolution from two parents.

2. Fill in the blank: a plain bundle of data with no attached logic, like Position or Health, is called a ___.

A component holds data only; systems hold the logic.

3. Why do real ECS implementations usually store each component type contiguously in its own array?

Contiguous per-type storage is a deliberate, performance-driven layout choice.

4. Fill in the blank: needing a class to inherit from two unrelated parent classes at once is called ___.

This is what a flying, swimming boss would require in a strict tree.

5. What actually determines whether a system processes a given entity?

A system's query determines matching purely by component presence.

6. Enemy splits into FlyingEnemy and SwimmingEnemy branches, then design asks for a flying, swimming boss. Answer both parts:

(a) A team stuck with this tree is forced to choose between bad options like...

(b) None of those options actually...

Every available fix under strict inheritance gets worse, not better, as the tree deepens.

7. An entity gains a Velocity component it didn't have before, with Position already attached. Answer both parts:

(a) Next update tick, the Movement System (needs Position + Velocity) would now...

(b) Achieving this required...

Adding a component changes what systems apply, with zero hierarchy changes needed.

8. In the pseudocode world.query(Position, Velocity), answer both parts:

(a) This query returns...

(b) An entity with only a Health component would...

A query requires presence in every listed component store simultaneously.

9. Answer both parts about why this problem hits games especially hard:

(a) Game design routinely asks for...

(b) A tree-shaped hierarchy assumes relationships are...

Games' demand for flexible combination is exactly what a stable tree structure resists.

10. Answer both parts about a minimal ECS's three pieces:

(a) The piece that runs once per game-loop tick, updating matching entities' data, is the...

(b) Fill in the blank: a map from entity ID to that component type's data, one per component type, is a ___.

Systems process data; component stores hold it, keyed by entity ID.
