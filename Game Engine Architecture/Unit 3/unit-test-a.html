1. What specifically breaks a deep inheritance hierarchy of game object types?

Cross-branch behavior combinations are exactly what a tree structure can't represent cleanly.

2. Fill in the blank: an identifier with no behavior and no data of its own is called an ___.

An entity is just an ID that components attach data to.

3. What does a system's "query" actually do?

A query filters entities down to those with the matching component combination.

4. Fill in the blank: the ambiguity over which parent's method a child inherits, when two parents both define it, is the ___.

This is the named problem behind multiple inheritance ambiguity.

5. Where does game logic actually live in an ECS?

Systems hold all behavior; components remain pure data.

6. A team needs a boss enemy that both flies and swims. Answer both parts:

(a) In a deep inheritance hierarchy, this type...

(b) Why does this problem hit games especially hard compared to other domains?

Cross-cutting behavior demands are common in game design and hostile to tree structures.

7. An entity has Position and Sprite components, but no Velocity component. Answer both parts:

(a) The Render System (needs Position + Sprite) would...

(b) The Movement System (needs Position + Velocity) would...

Each system only processes entities matching its own exact component requirements.

8. Answer both parts about why ECS commonly stores components in per-type arrays:

(a) Storing all Position data contiguously in one array, rather than scattered across entity objects, mainly improves...

(b) This layout choice is driven primarily by...

Contiguous, per-type storage is a deliberate performance optimization for large-scale iteration.

9. Answer both parts about how ECS resolves Lesson 7's diamond problem:

(a) A flying, swimming boss in an ECS is represented as...

(b) Adding a new behavior to an existing entity in an ECS requires...

Composition avoids the tree-shaped ancestry problem inheritance runs into.

10. Answer both parts about a minimal ECS's structure:

(a) Fill in the blank: the piece that hands out fresh entity IDs and tracks which are alive is the ___.

(b) In the pseudocode movement system, multiplying velocity by dt each tick connects back to...

Delta time from Unit 2 shows up again in every per-frame system update, including movement.
