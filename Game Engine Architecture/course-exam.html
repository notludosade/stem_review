1. What is the defining property of a game engine?

Reusability across unrelated games is the core defining property.

2. Fill in the blank: engines expose ___ building blocks — like arbitrary named data fields — rather than hard-coding concepts specific to one game's rules.

Genericness is what keeps engine code reusable across unrelated games.

3. Why do engines separate rendering, physics, audio, and other subsystems instead of writing one combined update function?

Independent development, testing, and replacement is the concrete payoff of separation.

4. What are the three phases of a basic game loop, in order?

Input is read first, the world advances next, and the result is drawn last.

5. Fill in the blank: always advancing the simulation by the same constant time step, running update() multiple times if needed, is a ___ timestep.

Fixed timestep is defined by its constant, unchanging step size.

6. What does multiplying a movement value by delta time actually accomplish?

Delta time converts a per-frame change into a true per-second rate.

7. What specifically breaks a deep inheritance hierarchy of game object types?

Cross-branch behavior combinations are exactly what a tree structure can't represent cleanly.

8. Fill in the blank: an identifier with no behavior and no data of its own, which components attach to, is an ___.

An entity is just an ID; components carry the actual data.

9. What does a system's "query" actually do?

A query filters entities down to those matching a required component combination.

10. What is rasterization's specific job in the render pipeline?

Rasterization sits between vertex and fragment processing, identifying covered pixels.

11. Fill in the blank: a tree of objects where each node's transform is stored relative to its parent is a ___.

Scene graphs store transforms relative to a parent, not in absolute world space.

12. What does frustum culling actually do?

Culling removes invisible objects from the render workload, saving GPU time.

13. What does "axis-aligned" mean about an AABB?

Never rotating is exactly what keeps an AABB overlap test cheap.

14. Fill in the blank: updating a rigid body's velocity and position each small timestep by accumulating forces is numerical ___.

Integration accumulates force effects across discrete timesteps.

15. Why do most teams use an existing physics engine instead of writing their own?

Difficulty and maturity of existing solutions drive reuse over reinvention.

16. What is a "source asset"?

Source assets are editor-facing, distinct from the converted runtime format.

17. Fill in the blank: the fixed amount of fast memory a game may use for assets at any one time is its ___.

The memory budget is the hard ceiling asset loading has to respect.

18. Why does a distant object benefit from a lower level of detail?

LOD trades invisible extra detail for real rendering-cost savings.

19. Fill in the blank: seeing a script edit take effect immediately in a running game, with no recompile, is called ___.

Hot-reloading is scripting's key iteration-speed advantage over the compiled core.

20. What guarantee does a state machine provide that a handful of independent boolean flags doesn't?

Structural enforcement of exactly one active state is the core guarantee.

21. Why does the scripting system typically run before the physics system in a single frame?

Physics needs fresh gameplay intent from scripting before it integrates that frame.
