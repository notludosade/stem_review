1. What does the fragment/pixel processing stage compute?

Fragment processing produces final per-pixel color after rasterization finds which pixels matter.

2. Fill in the blank: an instruction telling the GPU to render one object is called a ___.

A draw call is the per-object GPU rendering instruction.

3. Why is a parent-child transform hierarchy preferred over storing every object's world position directly?

Automatic propagation from a single high-level change is the hierarchy's main payoff.

4. Fill in the blank: the stage that determines exactly which screen pixels a triangle covers is ___.

Rasterization sits between vertex processing and fragment processing.

5. What is the view frustum?

The frustum is specifically the camera's visible region of space.

6. Answer both parts about why GPU hardware is built around a fixed pipeline:

(a) This fixed structure exists mainly because it enables...

(b) Fill in the blank: engines plug custom logic into the vertex and fragment stages using small programs called ___.

Shaders are the custom programs that plug into fixed, hardware-parallel pipeline stages.

7. In the two-joint arm example, rotating only the shoulder slider is done. Answer both parts:

(a) The elbow's local rotation value...

(b) What actually changes is the elbow's...

Only the derived world position changes; local transforms are untouched by a parent's rotation.

8. An open-world scene has 50,000 objects total, but the camera can only geometrically see a few thousand. Answer both parts:

(a) Without frustum culling, the engine would waste GPU time on...

(b) Culling happens...

Culling saves GPU work by removing invisible objects before rendering begins.

9. Answer both parts about a character's shoulder vertex in vertex processing:

(a) Vertex processing moves that point from a position relative to the character's own origin to...

(b) This computation accounts for...

Vertex processing combines object, camera, and screen information into one final screen position.

10. Answer both parts about draw call overhead:

(a) Each draw call carries its own...

(b) Fill in the blank: combining many small objects into fewer, larger draw calls is called ___.

Batching reduces the number of fixed-overhead draw calls needed for the same visual result.
