1. What is rasterization's specific job in the render pipeline?

Rasterization determines which pixels a triangle covers, between vertex and fragment stages.

2. Fill in the blank: a tree of objects where each node's transform is stored relative to its parent is called a ___.

This is the structure defined at the top of Lesson 11.

3. What does frustum culling actually accomplish?

Culling removes invisible objects from the render workload without touching scene data.

4. Fill in the blank: the block of memory holding final pixel colors that get displayed on screen is the ___.

The framebuffer holds the pipeline's final output image.

5. What happens to a node's local transform when its parent rotates?

Local transforms remain constant; world transforms are recomputed from the full parent chain.

6. Answer both parts about the render pipeline's stages:

(a) Vertex processing's job is to...

(b) Fill in the blank: after rasterization identifies which pixels a triangle covers, the ___ processing stage computes each pixel's actual color.

Vertex processing positions triangles; fragment processing colors the pixels they cover.

7. A character's shoulder rotates, carrying the whole arm with it automatically. Answer both parts:

(a) This works because each joint below the shoulder stores its transform...

(b) Without this hierarchy, moving the arm would require...

Parent-relative storage is what makes a single high-level change propagate automatically.

8. A scene renders 1,000 tiny separate draw calls instead of 10 large ones, at the same total triangle count. Answer both parts:

(a) The 1,000-draw-call version is likely...

(b) Engines often address this by...

Draw call overhead is fixed per call, so batching fewer, larger calls tends to be faster.

9. Answer both parts about why the render pipeline's structure is fixed:

(a) GPUs are built as specialized hardware around this sequence because it enables...

(b) A game engine's role in this pipeline is mainly to...

Engines write shaders for the programmable stages; rasterization stays fixed hardware.

10. Answer both parts about a large open-world scene:

(a) Of 50,000 total objects, the camera in a canyon can typically see...

(b) Fill in the blank: each object that survives culling typically costs one ___, an instruction telling the GPU to render it now.

Culling drastically reduces what needs a draw call each frame in a large scene.
