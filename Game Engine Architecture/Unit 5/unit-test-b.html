1. What is broad phase's job in collision detection?

Broad phase is a cheap filter, leaving the exact test to narrow phase.

2. Fill in the blank: an object treated as a solid, non-deformable shape that forces can act on is a ___.

This is the object type physics integration operates on.

3. What does "collision response" specifically refer to?

Collision response happens after detection, resolving overlap and updating velocity.

4. Fill in the blank: the smallest, non-rotated rectangle fully containing an object is its ___.

AABB is the term for this bounding shape used in broad phase.

5. Why does a larger integration timestep introduce more error into a physics simulation?

The constant-during-one-step assumption weakens as the step grows larger.

6. An AABB overlap test is extremely cheap to run. Answer both parts:

(a) This is because it reduces to comparing...

(b) This cheapness is exactly why AABB checks are used at...

Cheap axis-range comparisons are exactly what makes AABB checks suitable for broad phase's scale.

7. In semi-implicit Euler integration under gravity, at dt = 0.1s starting from rest. Answer both parts:

(a) After step one, velocity has changed because...

(b) Each subsequent step's position change grows larger than the last because...

Accumulating velocity under constant acceleration is what produces accelerating fall.

8. Answer both parts about why teams reuse an existing physics engine:

(a) This mirrors the argument from Unit 1 about engines generally, because physics is...

(b) Common general-purpose physics engines named in this unit include...

Physics is a shared hard problem, which is why mature dedicated libraries exist and get reused.

9. Answer both parts about narrow phase:

(a) Narrow phase runs its expensive, exact check on...

(b) This two-stage design exists mainly to...

The broad/narrow split exists specifically to keep per-frame collision detection affordable.

10. Answer both parts about physics engine responsibilities:

(a) Keeping a rope's joints connected while it swings under load is handled by...

(b) Fill in the blank: a rule that must keep holding true even while everything else in the simulation moves is called a ___.

Constraints are exactly what a physics engine solves for persistent relationships like joints.
