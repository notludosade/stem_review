1. What is the defining property of a game engine?

Reusability across unrelated games is the core defining property.

2. Fill in the blank: engines expose ___ building blocks — like arbitrary named data fields — rather than hard-coding concepts specific to one game's rules.

Genericness is what keeps engine code reusable across unrelated games.

3. Why do engines separate rendering, physics, audio, and other subsystems instead of writing one combined update function?

Independent development, testing, and replacement is the concrete payoff of separation.

4. Fill in the blank: the property that lets one engine support unrelated genres like racing games and puzzle games is that its systems are ___.

Reusable, general-purpose systems are what let one engine serve very different genres.

5. A studio hard-codes "if enemy touches player, subtract 10 health" directly into the engine's core collision-detection code. What's the real cost?

Blurring the engine/game line costs future reusability, not compilation or raw speed.

6. Answer both parts about why teams build on existing engines:

(a) The core problems an engine solves (rendering, physics, audio) are...

(b) Fill in the blank: writing a custom engine from scratch wastes ___ that could instead go into what's actually unique about the game.

Reusing a proven engine avoids re-solving already-solved, hard problems.

7. A "mana" resource is rendered and stored by the engine, but its meaning and rules are written entirely in game code. Answer both parts:

(a) This split shows that...

(b) If the engine's core hard-coded "mana" as a built-in concept, an unrelated game (say, a farming sim) built on it would...

Keeping the engine ignorant of specific rules is what keeps it usable by unrelated games.

8. In a "player fires a weapon" sequence, order matters. Answer both parts:

(a) Which subsystem is the very first to react to the button press?

(b) Which subsystem moves the resulting bullet forward each frame and checks what it hits?

Input detects the press first; physics owns movement and collision afterward.

9. Answer both parts about id Software writing custom engines:

(a) A studio like id Software builds a fully custom engine mainly when...

(b) For most teams, that same tradeoff...

Custom engines make sense only when the engine itself is a competitive differentiator.

10. Answer both parts defining a "subsystem":

(a) A subsystem is best described as...

(b) Fill in the blank: the subsystem that gives game-specific logic a place to live, often in a separate, faster-to-iterate language, is ___.

Scripting is the subsystem dedicated to holding game-specific logic.
