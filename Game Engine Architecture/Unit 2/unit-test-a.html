1. What are the three phases of a basic game loop, in order?

Input is read first, the world advances next, and the result is drawn last.

2. Fill in the blank: the amount of real time, in seconds, that elapsed since the last frame is called ___.

Delta time is the elapsed-seconds value multiplied into per-second rates.

3. Why is a fixed timestep generally preferred for physics simulation?

Consistent step size is what keeps physics numerically stable and reproducible.

4. Fill in the blank: the phase that must always run last, so the screen shows this frame's changes rather than a stale state, is ___.

Render must reflect the freshest state, which only exists after update runs.

5. A character moves with position += 5; and no delta time multiplier. What happens if frame rate doubles?

Without delta time, speed is tied directly to how many frames occur per second.

6. Answer both parts about why a game needs a continuously running loop:

(a) Unlike a word processor that just waits for input, a game world must...

(b) Fill in the blank: the first phase of the loop, responsible for reading what the player did since the last frame, is process ___.

A game must actively drive its own world forward every frame, starting with reading input.

7. A single frame takes an unusually long 250ms (a "hitch"). Answer both parts:

(a) Under variable timestep, a fast-moving object could...

(b) Under fixed timestep, that same 250ms would instead be simulated as...

Fixed timestep breaks a large gap in real time into several small, physically consistent steps.

8. Answer both parts about why the missing-delta-time bug is easy to miss:

(a) On a developer's own machine at a fairly steady frame rate, code without delta time...

(b) The bug becomes obvious specifically when...

The bug is silent on one consistent machine and only surfaces under different conditions.

9. Answer both parts about a character holding "move right" every frame:

(a) Each frame, update() moves the character...

(b) Sixty small position changes across sixty frames in one second is what makes holding a direction look like...

Many small per-frame updates are what produce the illusion of smooth motion.

10. Answer both parts defining the two timestep strategies:

(a) Fill in the blank: passing update() the real, measured duration of the previous frame is a ___ timestep.

(b) A fixed timestep, by contrast, is defined by...

Variable timestep uses the real elapsed duration; fixed timestep uses a constant step regardless of it.
