1. Why must render always run after update in the game loop, never before?

Rendering must reflect the freshest state, which only exists once update has run.

2. Fill in the blank: how many times per second the game loop completes is called ___.

Frame rate, in FPS, is loop completions per second.

3. What is the main tradeoff a fixed timestep accepts in exchange for stable, reproducible physics?

Decoupling simulation steps from render timing means update() may run a different number of times per rendered frame.

4. Fill in the blank: the top-level loop that repeatedly processes input, updates the world, and renders it for the life of a game is the ___.

This is the term defined at the top of Lesson 4.

5. What does correctly multiplying a movement value by delta time actually accomplish?

Delta time converts a per-frame change into a true per-second rate, independent of frame rate.

6. Answer both parts about why a game can't just wait for player input like a word processor does:

(a) A game world must keep advancing even when...

(b) Fill in the blank: the third and final phase of the loop, which draws the current world state, is ___.

The loop must keep the world moving on its own, ending each cycle with render.

7. A ball moves at a steady 100 pixels/second and a 250ms hitch occurs. Answer both parts:

(a) Under variable timestep, the ball would jump...

(b) Under fixed timestep, that same distance would instead be covered as...

Fixed timestep breaks a real-time gap into many small steps instead of one giant leap.

8. A character moves with position += 5 * delta_time; at both 30 FPS and 120 FPS. Answer both parts:

(a) After exactly one real second at either frame rate, the character has moved...

(b) The difference between the two frame rates instead shows up as...

Correct delta-time use keeps total distance per second constant regardless of frame rate.

9. Answer both parts about the game loop's basic shape:

(a) The phase that reads what the player did since the last frame is called...

(b) The loop keeps repeating these phases...

The loop runs continuously, starting each cycle by reading input.

10. Answer both parts about why fixed timestep suits physics specifically:

(a) Physics math (springs, collisions, gravity) generally assumes...

(b) A key benefit of fixed timestep is that simulation results become...

Consistent step size keeps physics stable and reproducible regardless of hardware speed.
