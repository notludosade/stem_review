Paths, Cycles, and Connectivity

Lesson 13 defined a graph as a static picture. This lesson asks about movement through it — what counts as a valid route, when a route loops back on itself, and whether every vertex can even be reached from every other one at all.

1. Walks, paths, and cycles

Definitions — Walk, Path, Cycle A walk is any sequence of vertices v₀, v₁, ..., vₖ where consecutive vertices are joined by an edge — repeats are allowed. A path is a walk that never repeats a vertex. A cycle is a path of length ≥ 3 with one exception: it's allowed to return to its starting vertex at the very end (vₖ = v₀), with no other repeats anywhere in between.
Worked example In the 4-cycle from Lesson 13 (V={A,B,C,D}, edges forming a square A–B–C–D–A): A, B, C is a path (no repeats). A, B, C, D, A is a cycle (only the start/end vertex repeats, and it closes the loop). A, B, A, B is a walk but not a path (B and A both repeat in the middle).

2. Connectivity

Definition — Connected Graph and Connected Component A graph is connected if there is a path between every pair of vertices. If it isn't, it breaks into connected components — maximal groups of vertices that are mutually reachable, with no edges at all between different components. Every vertex belongs to exactly one connected component (including a graph with no edges at all, where every vertex is its own component of size 1).
Why "exactly one component" should sound familiar "Every vertex belongs to exactly one component" is the same partition structure Unit 2's set operations kept assuming implicitly — connected components split V into disjoint, non-overlapping pieces that cover every vertex, exactly like how A and Aᶜ partition a universal set U into two disjoint pieces that cover everything. Connectivity is really a question about how many pieces a graph's vertex set naturally splits into.

1. What distinguishes a path from a general walk?

A walk only requires consecutive vertices to be joined by an edge; a path adds the extra requirement that no vertex is visited twice.

2. Which of these correctly describes a cycle?

A cycle is a path that closes the loop back to its own starting vertex, with that single exception being the only repeat allowed.

3. A graph has 7 vertices and splits into 3 connected components. Which statement must be true?

Connected components always partition the vertex set — every vertex is in exactly one component, with components of possibly different sizes and, by definition, no edges crossing between them.

4. Fill in the blank: a graph with only 1 connected component (containing every vertex) is called ___.

A connected graph has a path between every pair of vertices, which is exactly the same as saying it has only one connected component.

5. Fill in the blank: a graph on 5 vertices with zero edges has ___ vertex(es) per connected component, and 5 components total.

With no edges at all, no two vertices are mutually reachable, so every vertex is its own isolated component of size 1.
