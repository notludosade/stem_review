Trees and Graph Coloring

This closing lesson of Unit 5 covers two ideas that look unrelated at first — the most cycle-free graphs possible, and the classic problem of coloring a map so no two neighbors match — and both turn out to matter far beyond graph theory itself.

1. Trees

Definition — Tree A tree is a connected graph with no cycles. A vertex of degree 1 in a tree is called a leaf.
Theorem — Edge Count A tree on n vertices has exactly n − 1 edges — never more, never fewer. Removing any single edge disconnects a tree (it has no cycle to route around the missing edge), and adding any single edge to a tree creates exactly one cycle (connecting two vertices that already had a unique path between them).
Worked example A tree on 6 vertices has exactly 5 edges. This isn't a coincidence to verify case by case — it's provable by induction (Unit 7's central proof technique): a single vertex (n=1) has 0 = n−1 edges trivially, and every larger tree can be built by attaching one new leaf at a time, each attachment adding exactly 1 vertex and exactly 1 edge, preserving n − 1 at every step.
Why trees matter beyond this lesson A tree is the minimal connected structure — the fewest possible edges that still keep every vertex reachable from every other. That "no wasted edges, no redundant path" property is exactly why file systems, decision trees, and the call structure of a recursive function (Unit 7) are all modeled as trees: it's the natural shape for anything built by repeatedly branching from a single starting point with no way back to where you've already been.

2. Graph coloring

Definition — Proper Coloring and Chromatic Number A proper coloring of a graph assigns a color to every vertex so that no two adjacent vertices (connected by an edge) share a color. The chromatic number χ(G) is the minimum number of colors any proper coloring of G needs.
Worked examples A tree (or any graph with no cycles) always has χ(G) = 2 (or 1, if it has no edges at all) — alternate two colors outward from any starting vertex, and since there's no cycle to force a clash, it always works. An odd cycle (like a 5-cycle) needs χ(G) = 3: alternating 2 colors around an odd number of vertices always forces the last vertex to match one of its neighbors, no matter where you start. A complete graph Kₙ (every vertex connected to every other) needs χ(G) = n, since every pair of vertices is adjacent and therefore needs a distinct color.

1. A tree has 9 vertices. How many edges does it have?

Every tree on n vertices has exactly n − 1 edges, regardless of its specific shape — here, 9 − 1 = 8.

2. Why does an odd cycle (like a 5-cycle) need 3 colors instead of 2?

With an odd number of vertices in a ring, a strict 2-color alternation can't close the loop without a clash at the seam — a 3rd color is required to break the parity problem.

3. What is the chromatic number of K₅, the complete graph on 5 vertices (every pair connected)?

In a complete graph, every vertex is adjacent to every other vertex, so all 5 must receive distinct colors — χ(K₅) = 5.

4. Fill in the blank: a vertex of degree 1 in a tree is called a ___.

A leaf is a tree vertex connected to exactly one other vertex — an endpoint of the tree.

5. Fill in the blank: the minimum number of colors needed for a proper coloring of a graph G is called its ___.

χ(G), the chromatic number, is defined as the smallest number of colors any proper coloring of G can achieve.
