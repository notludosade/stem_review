Cardinality and Countability

Lesson 5 defined a bijection as a perfect pairing between two sets. This lesson uses that pairing to compare the sizes of infinite sets — and the first payoff is deeply counterintuitive: a proper subset of a set can still be "the same size" as the whole thing.

← Lesson 5 Lesson 7 → Contents Glossary →

1. Cardinality

Definition — Cardinality The cardinality of a finite set A, written |A|, is the number of elements it has: |{2,4,6}| = 3. Two sets A and B have equal cardinality (|A| = |B|) if a bijection f: A → B exists — this definition is exactly what Lesson 5 built toward, and unlike "count the elements," it still makes sense when A and B are infinite.

2. Countable sets

Definition — Countable and Countably Infinite A set is countable if it is finite, or if a bijection exists between it and ℕ. An infinite countable set is countably infinite, and has cardinality denoted ℵ₀ ("aleph-null"). Intuitively: a set is countable exactly when you could list its elements in a sequence — first, second, third, ... — eventually reaching (the "index" of) any particular element, even if the list never ends.
Worked example — ℤ is countably infinite ℤ = {..., −2, −1, 0, 1, 2, ...} looks "twice as big" as ℕ, since it has all of ℕ's elements plus every negative number too. But the zigzag pairing f: ℕ → ℤ, f(n) = n/2 if n is even, −(n+1)/2 if n is odd, is a genuine bijection: f(0)=0, f(1)=−1, f(2)=1, f(3)=−2, f(4)=2, f(5)=−3, and so on, hitting every integer exactly once. Since a bijection to ℕ exists, |ℤ| = |ℕ| = ℵ₀ — despite ℕ ⊂ ℤ being a proper subset. This never happens for finite sets (a proper subset always has strictly smaller cardinality); it's specifically a feature of infinite sets, and is often taken as their defining property.

3. Uncountable sets

ℝ is uncountable — Cantor's diagonal argument, sketched Not every infinite set is countable. Cantor proved ℝ is uncountable — strictly larger than ℕ — with a proof by contradiction: suppose you could list every real number between 0 and 1 in a sequence r₁, r₂, r₃, .... Write each as an infinite decimal, then build a new number d by taking the nth digit of rₙ and changing it (e.g. add 1, wrapping 9 to 0). This d differs from every rₙ in at least the nth digit, so d can't be anywhere on the supposedly complete list — contradicting the assumption that the list contained every real number. Since no listing can be complete, ℝ cannot be put in bijection with ℕ.
Why the distinction matters Countability isn't just a curiosity — it's the line between "a computer program could in principle enumerate every element, given unlimited time" and "it structurally cannot." ℤ, ℚ, and the set of all finite-length strings over any finite alphabet (like every possible computer program's source code) are all countable, which is exactly why enumeration-based arguments work on them. ℝ is not, which is part of why "pick a real number uniformly at random" behaves very differently from "pick an integer" in probability theory.

1. Two sets have equal cardinality exactly when:

Equal cardinality is defined by the existence of a bijection — a perfect pairing — which works for finite and infinite sets alike, unlike "same elements" or "same size by counting."

2. ℕ ⊂ ℤ is a proper subset, yet |ℕ| = |ℤ|. Why is this not a contradiction?

This "proper subset, same cardinality" behavior is a genuine feature of infinite sets, not a paradox — the zigzag bijection between ℕ and ℤ is a real, verifiable pairing, and this property is often used as the defining characteristic that separates infinite sets from finite ones.

3. What does Cantor's diagonal argument prove?

The diagonal argument shows any proposed complete listing of the reals in [0,1] must miss at least one real number (the constructed diagonal number), so no bijection with ℕ can exist — ℝ is strictly larger than any countable set.

4. Fill in the blank: an infinite set that has a bijection with ℕ is called ___.

Countably infinite is the term for an infinite set whose elements can be put in bijection with (equivalently, listed against) the natural numbers.

5. Fill in the blank: using this course's convention that ℕ includes 0, the zigzag bijection f: ℕ → ℤ maps f(___) = 0, the very first pair in the listing.

f(0) = 0/2 = 0, since 0 is even and is the first element of ℕ under this course's convention — the pairing starts at n = 0, not n = 1.
