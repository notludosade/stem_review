Functions, Injections, and Surjections

You've used functions informally since algebra. This lesson defines one as a special kind of relation between two sets, then asks two separate questions about it — does it ever repeat an output, and does it hit every possible output — that turn out to be exactly what Lesson 6 needs to compare the sizes of infinite sets.

1. Functions between sets

Definition — Function A function f: A → B assigns to every element of A exactly one element of B. A is the domain; B is the codomain. The range (or image) of f is the subset of B actually hit: {f(x) : x ∈ A} ⊆ B — the range can be smaller than the codomain, but every element of A must map to something, and to only one thing.
Worked example f: ℤ → ℤ defined by f(x) = x² is a function: every integer has exactly one square. Its codomain is ℤ, but its range is only the perfect squares {0, 1, 4, 9, 16, ...} — a proper subset of the codomain, since negative numbers and non-squares are never hit.

2. Injections (one-to-one)

Definition — Injection f: A → B is injective (one-to-one) if different inputs always give different outputs: ∀x₁, x₂ ∈ A, f(x₁) = f(x₂) → x₁ = x₂. Equivalently, no element of B is hit more than once.
Worked example f: ℝ → ℝ, f(x) = 2x + 1 is injective: if 2x₁ + 1 = 2x₂ + 1 then x₁ = x₂. But g: ℝ → ℝ, g(x) = x² is not injective — g(2) = g(−2) = 4, two different inputs landing on the same output.

3. Surjections (onto)

Definition — Surjection f: A → B is surjective (onto) if every element of the codomain gets hit: ∀y ∈ B, ∃x ∈ A, f(x) = y. Equivalently, range(f) = B exactly, with nothing in the codomain left over.
Worked example f: ℝ → ℝ, f(x) = 2x + 1 is also surjective: for any target y, x = (y−1)/2 maps to it. But h: ℤ → ℤ, h(x) = 2x is not surjective — its range is only the even integers, so odd targets like 3 are never hit.
Definition — Bijection f: A → B is a bijection if it is both injective and surjective — every element of B is hit by exactly one element of A. f(x) = 2x + 1 above is a bijection from ℝ to ℝ.
Why bijections matter beyond this lesson A bijection between A and B is a perfect pairing — it matches every element of A to a unique element of B with nothing left over on either side. That's exactly what it means for two sets to be "the same size," and it's the only definition of size that still works once a set is infinite, where you can't just count elements one by one. Lesson 6 builds directly on this: a set is defined as countable exactly when a bijection (or injection, for the weaker version) to ℕ exists.

1. f: ℝ → ℝ, f(x) = x² is not injective because:

Injectivity fails exactly when two distinct inputs share an output; 2 ≠ −2 but f(2) = f(−2) = 4 is precisely that kind of collision.

2. h: ℤ → ℤ, h(x) = 2x is not surjective because:

Surjectivity requires every codomain element to be hit; since h(x) = 2x only ever produces even integers, odd targets in the codomain ℤ are left uncovered.

3. A bijection is defined as a function that is:

A bijection needs both properties at once: no repeated outputs (injective) and no uncovered codomain elements (surjective) — a perfect one-to-one pairing between the two sets.

4. Fill in the blank: the subset of the codomain actually hit by a function is called its ___.

The range (or image) is {f(x) : x ∈ A} — it can be a proper subset of the codomain when the function isn't surjective.

5. Fill in the blank: two sets are considered "the same size," even when infinite, exactly when a ___ exists between them.

A bijection pairs every element of one set with a unique element of the other, with nothing left over on either side — the definition of "same size" that still makes sense for infinite sets.
