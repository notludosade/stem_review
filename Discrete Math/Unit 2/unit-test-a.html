1. Let A = {1, 2, 3, 4, 5} and B = {4, 5, 6, 7}. What is A ∪ B?

Union collects everything in A, B, or both — every element from either set, listed once each.

2. Which of these statements is true for every set B?

∅ ⊆ B holds vacuously for every B, since there is no element of ∅ that could ever fail to be in B. The other three statements are only true for special choices of B, if ever.

3. f: ℤ → ℤ is defined by f(x) = x + 5. Which classification is correct?

x₁+5 = x₂+5 forces x₁=x₂ (injective), and for any target y, x = y−5 maps to it (surjective) — both hold, so f is a bijection.

4. Fill in the blank: |{a, b, c, d}| = ___.

Cardinality of a finite set is just its element count — this set lists 4 distinct elements.

5. Which of the following sets is countable?

ℚ is countably infinite (a zigzag pairing over numerator/denominator grids puts it in bijection with ℕ), while ℝ, any interval of ℝ, and the power set of ℝ are all uncountable.

6. Consider the set {x ∈ ℤ : x² = 9}. Answer both parts:

(a) What is its roster notation?

(b) Fill in the blank: the set {2, 4, 6, 8} can be written in set-builder notation as {x ∈ ℤ : x is even and 0 < x < ___}.

(a) Both 3 and −3 square to 9, so the roster notation lists both. (b) Any bound strictly between 8 and 10 works (9 or 10 are both natural choices), since it must include 8 but exclude 10 and beyond.

7. Let A = {1, 2} and B = {1, 2, 3}. Answer both parts:

(a) Is A ⊂ B (a proper subset)?

(b) Fill in the blank (yes/no): is ∅ ⊆ A?

(a) Every element of A (1 and 2) is in B, and B has an extra element B lacks in A, so A is a proper subset. (b) The empty set is a subset of every set, including A, vacuously.

8. f: {1, 2, 3} → {a, b} is defined by f(1) = a, f(2) = a, f(3) = b. Answer both parts:

(a) Is f injective?

(b) Fill in the blank (yes/no): is f surjective — does it hit both a and b?

(a) Two different inputs (1 and 2) share the same output a, so injectivity fails. (b) The range is {a, b} = the full codomain, so f is surjective even though it isn't injective.

9. Consider g: ℕ → {even natural numbers}, g(n) = 2n. Answer both parts:

(a) Does g establish that ℕ and the even naturals have equal cardinality?

(b) Fill in the blank: g(5) = ___.

(a) g(n) = 2n never repeats an output and hits every even natural exactly once, so it's a genuine bijection — the "proper subset, same cardinality" pattern from Lesson 6. (b) g(5) = 2 × 5 = 10.

10. Let U = {1,...,8}, A = {1, 2, 3, 4}, B = {3, 4, 5, 6}. Answer both parts:

(a) What is (A ∪ B)ᶜ relative to U?

(b) Fill in the blank: by De Morgan's law, (A ∪ B)ᶜ = Aᶜ ∩ ___ᶜ.

(a) A ∪ B = {1,2,3,4,5,6}, so its complement in U is what's left: {7,8}. (b) De Morgan's law: the complement of a union is the intersection of the complements, (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ.
