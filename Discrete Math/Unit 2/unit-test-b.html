1. Let A = {2, 3, 4, 5, 6} and B = {5, 6, 7, 8}. What is A ∩ B?

Intersection keeps only elements in both sets; 5 and 6 are the only values appearing in both A and B.

2. For A = {5, 10, 15}, is ∅ ⊆ A true, and why?

∅ ⊆ A holds for every set A, regardless of its contents — there's no element of ∅ that could ever violate the subset condition.

3. f: ℝ → ℝ is defined by f(x) = 3x − 2. Which classification is correct?

3x₁−2 = 3x₂−2 forces x₁=x₂ (injective), and for any target y, x = (y+2)/3 maps to it (surjective) — both hold, so f is a bijection.

4. Fill in the blank: |{w, x, y, z, 1, 2}| = ___.

Cardinality of a finite set is just its element count — this set lists 6 distinct elements.

5. Which of the following sets is uncountable?

Any interval of real numbers is uncountable, by the same diagonal argument used for all of ℝ — ℤ, ℚ, and the set of finite-length strings over a finite alphabet are all countable.

6. Consider the set {x ∈ ℤ : x² = 25}. Answer both parts:

(a) What is its roster notation?

(b) Fill in the blank: the set {1, 3, 5, 7, 9} can be written in set-builder notation as {x ∈ ℤ : x is odd and 0 < x < ___}.

(a) Both 5 and −5 square to 25, so the roster notation lists both. (b) Any bound strictly greater than 9 and at most 11 works (10 or 11 are both natural choices), since it must include 9 but exclude 11 and beyond.

7. Let A = {2, 4} and B = {1, 2, 3, 4, 5}. Answer both parts:

(a) Is A ⊂ B (a proper subset)?

(b) Fill in the blank (yes/no): is ∅ ⊆ B?

(a) Every element of A is in B, and B has extra elements A lacks, so A is a proper subset. (b) The empty set is a subset of every set, including B, vacuously.

8. f: {x, y} → {1, 2, 3} is defined by f(x) = 1, f(y) = 2. Answer both parts:

(a) Is f injective?

(b) Fill in the blank (yes/no): is f surjective — does it hit 1, 2, and 3?

(a) f(x)=1 and f(y)=2 are distinct outputs for distinct inputs, so f is injective. (b) 3 is never hit by f, so the range {1,2} is a proper subset of the codomain {1,2,3} — f is not surjective.

9. Consider g: ℕ → {odd natural numbers ≥ 1}, g(n) = 2n + 1. Answer both parts:

(a) Does g establish that ℕ and the odd naturals ≥ 1 have equal cardinality?

(b) Fill in the blank: g(4) = ___.

(a) g never repeats a value and covers every odd natural number starting from 1 (using this course's convention that 0 ∈ ℕ), so it's a genuine bijection. (b) g(4) = 2(4) + 1 = 9.

10. Let U = {1,...,10}, A = {1, 2, 3, 4, 5}, B = {4, 5, 6, 7}. Answer both parts:

(a) What is (A ∩ B)ᶜ relative to U?

(b) Fill in the blank: by De Morgan's law, (A ∩ B)ᶜ = Aᶜ ∪ ___ᶜ.

(a) A ∩ B = {4,5}, so its complement in U is everything else: {1,2,3,6,7,8,9,10}. (b) De Morgan's law: the complement of an intersection is the union of the complements, (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ.
