1. g(0) = 3, and g(n) = 2·g(n−1) for n ≥ 1. What is g(4)?

g(1)=6, g(2)=12, g(3)=24, g(4)=48 — each step doubles the previous term.

2. In an induction proof of P(n) for all n ≥ 0, what must the inductive step establish?

The inductive step is the conditional argument "if P(k), then P(k+1)" — the base case handles P(0) separately.

3. What is the characteristic equation of aₙ = 6aₙ₋₁ + 7aₙ₋₂?

Substituting aₙ → xⁿ and dividing out xⁿ⁻² gives x² = 6x + 7, matching the recurrence's coefficients directly.

4. Fill in the blank: using F(0)=0, F(1)=1, F(n)=F(n−1)+F(n−2), F(8) = ___.

The sequence runs 0, 1, 1, 2, 3, 5, 8, 13, 21 — F(8) = 21.

5. Why does proving every integer n > 1 has a prime factorization typically use strong induction?

A composite n's factors a and b can be any pair of smaller values, not necessarily n−1, so the proof needs the flexibility of assuming the claim for any smaller case — exactly what strong induction provides.

6. Claim: for n ≥ 1, 1 + 3 + 5 + ... + (2n−1) = n². Answer both parts:

(a) What does the base case (n=1) check?

(b) Fill in the blank: the inductive step assumes 1+3+...+(2k−1) = k², then must prove k² + (2k+1) = (k+___)².

(a) Both sides equal 1 at n=1, confirming the base case. (b) k² + 2k + 1 = (k+1)², exactly the formula with n replaced by k+1.

7. A sequence is defined h(0)=2, h(1)=5, h(n)=h(n−1)+h(n−2) for n≥2. Answer both parts:

(a) How many base cases does this definition need?

(b) Fill in the blank: h(4) = ___.

(a) Since h(n) references both h(n−1) and h(n−2), two starting values are needed to bottom out. (b) h: 2, 5, 7, 12, 19 — h(4) = 19.

8. Solve aₙ = 2aₙ₋₁ + 3aₙ₋₂, with a₀=5, a₁=7. Answer both parts:

(a) What are the roots of the characteristic equation x² = 2x + 3?

(b) Fill in the blank: solving A+B=5 and 3A−B=7 (from the initial conditions) gives A=3, B=___.

(a) x² − 2x − 3 = 0 factors as (x−3)(x+1) = 0. (b) A+B=5 and 3A−B=7 add to 4A=12, A=3, so B=5−3=2 — closed form aₙ = 3(3ⁿ) + 2(−1)ⁿ.

9. Using aₙ = 3(3ⁿ) + 2(−1)ⁿ for the recurrence above (a₂ = 29 from a₂=2a₁+3a₀=2(7)+3(5)). Answer both parts:

(a) What is a₃ using the closed form?

(b) Fill in the blank: verifying directly via the recurrence, a₃ = 2a₂ + 3a₁ = 2(29) + 3(7) = ___.

(a) a₃ = 3(27) + 2(−1) = 81 − 2 = 79. (b) 2(29) + 3(7) = 58 + 21 = 79, matching the closed form exactly.

10. To prove a closed-form solution correct for ALL n of a 2nd-order recurrence. Answer both parts:

(a) Which proof technique is appropriate?

(b) Fill in the blank: the inductive step substitutes the assumed-correct values at n−1 and n−2 back into the original ___ to derive the n-th case.

(a) Since the recurrence reaches back two terms, the inductive step needs both n−1 and n−2 assumed correct — strong induction. (b) Plugging the assumed values into the original recurrence relation is exactly what derives the n-th case.
