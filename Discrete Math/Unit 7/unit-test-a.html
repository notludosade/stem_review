1. g(0) = 2, and g(n) = 3·g(n−1) for n ≥ 1. What is g(3)?

g(1)=6, g(2)=18, g(3)=54 — each step multiplies the previous term by 3.

2. In an induction proof of P(n) for all n ≥ 1, what must the base case establish?

The base case directly verifies the smallest case, P(1) — the inductive step is a separate piece that shows each case implies the next.

3. What is the characteristic equation of aₙ = 4aₙ₋₁ + 5aₙ₋₂?

Substituting aₙ → xⁿ and dividing out xⁿ⁻² gives x² = 4x + 5, matching the recurrence's coefficients directly.

4. Fill in the blank: using F(0)=0, F(1)=1, F(n)=F(n−1)+F(n−2), F(7) = ___.

The sequence runs 0, 1, 1, 2, 3, 5, 8, 13 — F(7) = 13.

5. Why does proving a fact about trees (built by repeatedly attaching one leaf at a time) often require strong induction rather than ordinary induction?

Strong induction's extra flexibility — assuming the claim for any or all smaller cases, not just the immediately preceding one — is what a lot of structural graph arguments actually need.

6. Claim: for n ≥ 1, 2 + 4 + 6 + ... + 2n = n(n+1). Answer both parts:

(a) What does the base case (n=1) check?

(b) Fill in the blank: the inductive step assumes 2+4+...+2k = k(k+1), then must prove 2+4+...+2k+2(k+1) = (k+___)(k+2).

(a) Both sides equal 2 at n=1, confirming the base case. (b) The goal for k+1 is exactly the formula with n replaced by k+1: (k+1)(k+2).

7. A sequence is defined h(0)=1, h(1)=3, h(n)=h(n−1)+h(n−2) for n≥2. Answer both parts:

(a) How many base cases does this definition need?

(b) Fill in the blank: h(4) = ___.

(a) Since h(n) references both h(n−1) and h(n−2), two starting values are needed to bottom out. (b) h: 1, 3, 4, 7, 11 — h(4) = 11.

8. Solve aₙ = 3aₙ₋₁ + 4aₙ₋₂, with a₀=3, a₁=7. Answer both parts:

(a) What are the roots of the characteristic equation x² = 3x + 4?

(b) Fill in the blank: solving A+B=3 and 4A−B=7 (from the initial conditions) gives A=2, B=___.

(a) x² − 3x − 4 = 0 factors as (x−4)(x+1) = 0. (b) A+B=3 and 4A−B=7 add to 5A=10, A=2, so B=3−2=1 — closed form aₙ = 2(4ⁿ) + (−1)ⁿ.

9. Using aₙ = 2(4ⁿ) + (−1)ⁿ for the recurrence above. Answer both parts:

(a) What is a₃ using the closed form?

(b) Fill in the blank: verifying directly via the recurrence, a₃ = 3a₂ + 4a₁ = 3(33) + 4(7) = ___.

(a) a₃ = 2(64) + (−1) = 128 − 1 = 127. (b) 3(33) + 4(7) = 99 + 28 = 127, matching the closed form exactly.

10. To prove a closed-form solution correct for ALL n of a 2nd-order recurrence. Answer both parts:

(a) Which proof technique is appropriate?

(b) Fill in the blank: the inductive step substitutes the assumed-correct closed-form values at n−1 and n−2 into the ___ to show the closed form also holds at n.

(a) Since the recurrence reaches back two terms, the inductive step needs both n−1 and n−2 assumed correct — strong induction. (b) Plugging the assumed values into the original recurrence relation is exactly what derives the n-th case.
