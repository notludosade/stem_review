Divisibility and the Division Algorithm

Unit 6 turns to the integers themselves. This opening lesson formalizes something you've used since grade school — division with a remainder — as a theorem with a precise guarantee, which the rest of the unit leans on constantly.

← Lesson 15 Lesson 17 → Contents Glossary →

1. Divisibility

Definition — Divides (a | b) For integers a and b, a divides b, written a | b, if there exists an integer k such that b = a·k. Read a | b as "a divides b" or "b is a multiple of a." Every integer divides 0 (take k = 0), and 1 divides every integer.
Worked example 7 | 21, since 21 = 7·3. But 7 ∤ 22 (7 does not divide 22), since no integer k satisfies 22 = 7k.
Basic Properties If a | b and a | c, then a | (b + c) — dividing two numbers means dividing their sum too. If a | b and b | c, then a | c (transitivity). These follow directly from the definition: b = ak and c = am give b + c = a(k+m), and c = bm = a(km).

2. The Division Algorithm

Theorem — The Division Algorithm For any integer a and any positive integer b, there exist unique integers q (the quotient) and r (the remainder) such that a = bq + r, with 0 ≤ r < b. This holds for every integer a — including negative a — as long as b is positive.
Worked example a = 47, b = 5: 47 = 5(9) + 2, so q = 9, r = 2. a = −47, b = 5: −47 = 5(−10) + 3, so q = −10, r = 3 — note the remainder is still required to be non-negative (0 ≤ r < 5), which is why q rounds further down (to −10, not −9) to keep r in range.
Why "unique" matters The Division Algorithm doesn't just say q and r exist — it says exactly one valid pair does. That uniqueness is what makes "the remainder of a divided by b" a well-defined single number rather than a matter of choice, and it's exactly what Lesson 18's modular arithmetic depends on: every integer has one, and only one, remainder when divided by a fixed modulus, which is what lets "a mod n" behave like a genuine, single-valued operation instead of an ambiguous one.
Relating back to divisibility a | b exactly when the Division Algorithm applied to b and a produces remainder r = 0. Divisibility is the special case of division where nothing is left over.

1. Does 9 divide 108?

108 = 9 × 12 exactly, with no remainder, so 9 | 108.

2. Applying the Division Algorithm to a = −23, b = 7, what are q and r?

−23 = 7(−4) + 5, and r = 5 satisfies 0 ≤ r < 7 — the remainder must stay non-negative, which forces q down to −4 rather than −3.

3. What does the Division Algorithm guarantee about q and r for fixed a and positive b?

The theorem guarantees exactly one valid (q, r) pair with 0 ≤ r < b, for any integer a (positive, negative, or zero) and positive b.

4. Fill in the blank: a | b exactly when dividing b by a leaves a remainder of ___.

Divisibility is exactly the case where the Division Algorithm's remainder is 0 — nothing left over.

5. Fill in the blank: in a = bq + r, the value r (required to satisfy 0 ≤ r < b) is called the ___.

r is the remainder, and its range restriction (0 ≤ r < b) is exactly what makes it unique for given a and b.
