1. Which of the following IS a statement in the logical sense?

"91 is a prime number" is declarative with a definite truth value (false, since 91 = 7 × 13) — the others are a question, a command, and a predicate with an unbound variable.

2. A truth table for a compound statement built from 4 independent simple statements needs how many rows?

Each independent statement doubles the number of combinations: 2⁴ = 16 rows are needed to cover every combination of truth values for 4 statements.

3. Let p = "5 is even" (false) and q = "5 is prime" (true). What is the truth value of p → q?

p → q is false in only one case: p true and q false. With p false here, that case is impossible, so the implication is automatically true.

4. Fill in the blank: if p is True and q is False, then p ∧ q is ___.

Conjunction requires both sides true; since q is False here, p ∧ q is false regardless of p.

5. What is the truth value of "every element of the empty set is greater than 1,000,000"?

A universally-quantified claim over the empty set is always true, no matter what the predicate says — there's no element left that could ever be a counterexample.

6. Consider the biconditional p ↔ q. Answer both parts:

(a) If p is False and q is False, what is p ↔ q?

(b) Fill in the blank: p ↔ q is logically equivalent to (___ → q) ∧ (q → p).

(a) p ↔ q only checks whether both sides agree; false-false counts as agreement, so it's true. (b) The biconditional unpacks to (p → q) ∧ (q → p) — both implications holding at once.

7. Consider the statement ∃x ∈ ℝ, x² = −1. Answer both parts:

(a) Which of these is the correct negation?

(b) Fill in the blank: since no real number squared is negative, this negation ∀x ∈ ℝ, x² ≠ −1 is ___.

(a) Negating ∃ turns it into ∀ of the negated predicate: ∀x ∈ ℝ, x² ≠ −1. (b) No real number's square is negative, so this universal claim is true — consistent with the original ∃ statement being false.

8. Let D = {4, 6, 8, 9} and P(x) = "x is even." Answer both parts:

(a) What is the truth value of ∀x ∈ D, P(x)?

(b) Fill in the blank: over the same D, ∃x ∈ D, P(x) is ___.

(a) 9 ∈ D is odd, so it falsifies "every element is even." (b) 4 (or 6, or 8) ∈ D is even, so the existential claim is satisfied.

9. Let D = {x ∈ ℤ : x is both even and odd} — the empty set, since no integer is both. Answer both parts:

(a) What is the truth value of ∀x ∈ D, x = 7?

(b) Fill in the blank: for the same empty D, ∃x ∈ D, x = 7 is ___.

(a) A universal claim over an empty domain is always vacuously true, regardless of what it claims. (b) An existential claim over an empty domain is always false, since nothing exists to witness it.

10. Let p = False, q = True, r = False. Answer both parts:

(a) What is the truth value of (p ∨ q) ∧ r?

(b) Fill in the blank: for the same values, ¬(p ∧ r) is ___.

(a) p ∨ q is true, but conjunction needs both sides true, and r is false, so the whole expression is false. (b) p ∧ r is false (since both p and r are false), so its negation is true.
