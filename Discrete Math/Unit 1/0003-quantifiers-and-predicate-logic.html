Quantifiers and Predicate Logic

Lesson 1 set "x + 3 = 7" aside as not-yet-a-statement, because its truth depends on x. This lesson finishes the job: quantifiers turn a predicate into a genuine statement by saying how many x it has to hold for — and one edge case, the empty domain, is where a lot of people's intuition first goes wrong.

1. Predicates

Definition — Predicate A predicate is a sentence containing one or more variables that becomes a statement once every variable is either replaced with a specific value or bound by a quantifier. P(x) = "x is even" is not a statement on its own — P(4) is the true statement "4 is even," P(7) is the false statement "7 is even," and neither replacement is forced until you supply one.

2. The universal and existential quantifiers

Definition — Universal Quantifier (∀) ∀x ∈ D, P(x) ("for all x in D, P(x)") is true exactly when P(x) is true for every single element x of the domain D. One counterexample — one x in D where P(x) is false — makes the whole universal statement false.
Definition — Existential Quantifier (∃) ∃x ∈ D, P(x) ("there exists an x in D such that P(x)") is true exactly when P(x) is true for at least one element x of the domain D. It takes only one example to make an existential statement true, and it takes checking (or ruling out) every element to make it false.
Worked example Let D = {1, 2, 3, 4, 5} and P(x) = "x is even." ∀x ∈ D, P(x) is false — x = 1 is a counterexample. ∃x ∈ D, P(x) is true — x = 2 (or x = 4) witnesses it. Changing the domain changes the answer: over D = {2, 4}, the same ∀ statement becomes true, since every element left in the domain happens to be even.

3. Vacuous truth

Vacuous truth — the empty-domain case What is ∀x ∈ ∅, P(x) — a universal claim over the empty set, which has no elements at all? It is true, for every predicate P, no exceptions. This is called a vacuous truth. It follows directly from Lesson 2's implication table: ∀x ∈ D, P(x) unpacks to "for every x, if x ∈ D then P(x)" — and when D is empty, the hypothesis "x ∈ D" is false for every possible x, so the implication is true every single time, the same "promise never tested" reasoning from Lesson 2. The mirror case, ∃x ∈ ∅, P(x), is false for every P — there is nothing in the empty domain to witness it, so an existential claim over ∅ can never be satisfied. Watch for this the other way around too: it's a common mistake to assume an empty-domain claim must be false just because "nothing is in there to check" — the correct reading is the opposite for ∀.

4. Negating quantified statements

Rule — Negating a Quantifier ¬(∀x ∈ D, P(x)) is logically equivalent to ∃x ∈ D, ¬P(x). ¬(∃x ∈ D, P(x)) is logically equivalent to ∀x ∈ D, ¬P(x). In words: to deny "all of them do," it suffices to produce one that doesn't — the negation of ∀ is ∃ of the negation, and vice versa. Every ∀ that flips to ∃ (and back) when negated is the quantifier version of De Morgan's laws, which Lesson 4 restates for sets.
Worked example Claim: "All primes are odd." Formally, ∀x ∈ Primes, x is odd. This is false — its negation, ∃x ∈ Primes, x is not odd, is true, witnessed by x = 2, the one even prime. Notice the negation only needed one counterexample, not a full re-proof.

Click through each element of the domain to test P(x) = "x is even," then see whether ∀x P(x) and ∃x P(x) hold. Try shrinking the domain to empty and see what happens to both.

Check your recall

No peeking back up — answer from memory first, then check.

1. What makes ∀x ∈ D, P(x) false?

A universal statement claims P(x) holds for every element; a single counterexample is enough to break that claim, regardless of how many other elements do satisfy P.

2. What is the truth value of ∀x ∈ ∅, P(x), for any predicate P?

A universal statement over an empty domain is vacuously true for every predicate P — there's no element that could ever falsify it, exactly the "promise never tested" logic behind implication with a false hypothesis.

3. What is the correct negation of ∀x ∈ D, P(x)?

Negating a universal claim only requires exhibiting one element where the predicate fails, which is exactly what ∃x ∈ D, ¬P(x) asserts.

4. Fill in the blank: ∃x ∈ ∅, P(x) is always ___, for any predicate P, since the empty domain has no element that could witness it.

An existential claim needs at least one witnessing element; with no elements at all in the domain, it can never be satisfied, so it is always false over the empty set.

5. Fill in the blank: the statement "all primes are odd" is false, and the single counterexample that proves it is x = ___.

2 is prime and even, so it satisfies ¬P(x) for P(x) = "x is odd" — exactly one counterexample is enough to falsify the universal claim.
