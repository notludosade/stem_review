Logical Connectives

Negation builds a new statement from one. This lesson builds new statements from two — AND, OR, implication, and the biconditional — and the one that trips everyone up at first (implication) turns out to be the most important for how the rest of this course writes proofs.

1. Conjunction and disjunction

Definition — Conjunction (p ∧ q) and Disjunction (p ∨ q) The conjunction p ∧ q ("p and q") is true exactly when both p and q are true. The disjunction p ∨ q ("p or q") is true when at least one of p, q is true — this is the inclusive or, true even when both are true, unlike the "pick one" or of everyday speech.

2. Implication

Definition — Implication (p → q) The implication p → q ("if p then q," p is the hypothesis, q is the conclusion) is false in exactly one case: p true and q false. In every other case — including when p is false — p → q is true.

Why p → q is true whenever p is false This is the part of the table everyone questions first. Think of p → q as a promise: "if p, then I guarantee q." The only way to break that promise is for p to actually happen and q to fail. If p never happens, the promise was never tested — it wasn't broken, so it counts as kept. "If you finish your homework, I'll give you $10" is not a lie just because you never finished the homework; it only becomes a lie if you finish it and don't get paid. This exact idea reappears in Lesson 3 as vacuous truth: a universally-quantified claim about an empty set is true for precisely this reason — the "if you're in this set" condition is never triggered, so the implication is never broken.

3. Biconditional

Definition — Biconditional (p ↔ q) The biconditional p ↔ q ("p if and only if q," often abbreviated "iff") is true exactly when p and q have the same truth value — both true or both false. It is shorthand for (p → q) ∧ (q → p): the implication holding in both directions at once.

Worked example Let p = "n is divisible by 2" and q = "n is even." p ↔ q is true for every integer n, because the two conditions are just different phrasings of the same fact — this is exactly the kind of claim a "theorem states an if-and-only-if" sentence is asserting: both directions hold, with no exceptions.

1. If p is false, what is the truth value of p → q?

p → q is false in exactly one case: p true and q false. Whenever p is false, that case can't happen, so the implication is true no matter what q is.

2. p ∨ q is false in exactly which case?

Disjunction requires at least one of p, q true; the only row where neither is true — both false — is the one false row.

3. p ↔ q is logically equivalent to which combination?

The biconditional asserts the implication holds in both directions simultaneously — p implies q, and q implies p — which is exactly (p → q) ∧ (q → p), not the weaker "at least one direction" version with ∨.

4. Fill in the blank: "If pigs can fly, then 2 + 2 = 5" has a false hypothesis, so as a whole implication it is ___.

Since the hypothesis "pigs can fly" is false, the implication is automatically true regardless of the conclusion's own truth value — exactly the "promise never tested" reasoning from this lesson.

5. Fill in the blank: out of the four rows in its truth table, p → q is false in exactly ___ row(s).

Implication is false only when p is true and q is false — one row out of the four possible combinations of p and q.
