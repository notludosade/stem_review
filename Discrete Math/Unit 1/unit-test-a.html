1. Which of the following is NOT a statement in the logical sense?

"Sit down" is a command, not a declarative sentence with a truth value — the other three are all statements (two true, and "100 is divisible by 4" is false, but all three have a definite truth value).

2. A truth table for a compound statement built from 3 independent simple statements needs how many rows?

Each independent statement doubles the number of combinations: 2³ = 8 rows are needed to cover every combination of truth values for 3 statements.

3. Let p = "it is raining" (currently false) and q = "the ground is wet" (currently true). What is the truth value of p → q?

p → q is false in exactly one case: p true and q false. With p false, that case can't occur, so the implication is true regardless of q's value.

4. Fill in the blank: if p is True and q is False, then p ∨ q is ___.

Disjunction is true whenever at least one side is true; p is True here, so p ∨ q is true regardless of q.

5. What is the truth value of the statement "every element of the empty set is negative"?

A universally-quantified statement over an empty domain is always true — there is no element that could ever serve as a counterexample, the same "promise never tested" logic behind implication with a false hypothesis.

6. Consider the biconditional p ↔ q. Answer both parts:

(a) p ↔ q is true precisely when:

(b) Fill in the blank: p ↔ q is logically equivalent to (p → q) ∧ (q → ___).

(a) The biconditional is true exactly when both sides agree, true-true or false-false. (b) It unpacks to the implication holding in both directions: (p → q) ∧ (q → p).

7. Consider the statement ∀x ∈ ℤ, x² ≥ 0. Answer both parts:

(a) Which of these is the correct negation?

(b) Fill in the blank: since every integer squared is ≥ 0, this negation ∃x ∈ ℤ, x² < 0 is ___.

(a) Negating ∀ turns it into ∃ of the negated predicate: ∃x ∈ ℤ, x² < 0. (b) No integer squared is ever negative, so this existential claim is false — consistent with the original ∀ statement being true.

8. Let D = {2, 3, 5, 7} and P(x) = "x is odd." Answer both parts:

(a) What is the truth value of ∀x ∈ D, P(x)?

(b) Fill in the blank: over the same D, ∃x ∈ D, P(x) is ___.

(a) 2 ∈ D is even, so it falsifies "every element is odd." (b) 3 (or 5, or 7) ∈ D is odd, so the existential claim is satisfied.

9. Let D = {x ∈ ℤ : x > 5 and x < 5} — the empty set, since no integer is both. Answer both parts:

(a) What is the truth value of ∀x ∈ D, x = 100?

(b) Fill in the blank: for the same empty D, ∃x ∈ D, x = 100 is ___.

(a) A universal claim over an empty domain is always vacuously true. (b) An existential claim over an empty domain is always false, since there is nothing to witness it — the exact mirror of part (a).

10. Let p = True, q = False, r = True. Answer both parts:

(a) What is the truth value of (p ∧ q) ∨ r?

(b) Fill in the blank: for the same values, ¬(p ∨ r) is ___.

(a) p ∧ q is false, but disjunction only needs one true side, and r is true, so the whole expression is true. (b) p ∨ r is true (since both p and r are true), so its negation is false.
