Unit 1 — Logic & Propositional Calculus

Statement (Proposition)

A declarative sentence that is either true or false, never both and never neither — the basic unit of logical reasoning.

Negation (¬p)

The statement that is true exactly when p is false, and false exactly when p is true.

Truth Table

A table listing every combination of truth values for a statement's inputs, together with the resulting truth value of the whole statement.

Conjunction (∧) and Disjunction (∨)

p ∧ q ("and") is true only when both are true; p ∨ q ("or," inclusive) is true when at least one is true.

Implication (p → q)

False in exactly one case — p true and q false — and true in every other case, including whenever p is false.

Biconditional (p ↔ q)

True exactly when p and q share the same truth value; equivalent to (p → q) ∧ (q → p).

Predicate

A sentence containing a variable that becomes a statement once the variable is replaced with a value or bound by a quantifier.

Vacuous Truth

A universally-quantified statement over an empty domain is always true, since there is no element left that could ever serve as a counterexample.

Unit 2 — Sets & Functions

Set

An unordered collection of distinct elements, written by roster notation ({1,2,3}) or set-builder notation ({x : ...}).

Empty Set (∅)

The unique set with no elements; ∅ is a subset of every set, including itself, vacuously.

Subset (⊆) and Proper Subset (⊂)

A ⊆ B means every element of A is in B; A ⊂ B additionally requires A ≠ B.

Union, Intersection, Difference, Complement

A∪B (in either), A∩B (in both), A−B (in A but not B), Aᶜ (in the universal set but not A) — the set-level mirrors of ∨, ∧, and ¬.

Function (f: A → B)

Assigns to every element of domain A exactly one element of codomain B.

Injection

A function where different inputs always produce different outputs — no element of the codomain is hit more than once.

Surjection

A function where every element of the codomain is hit by at least one input.

Bijection

A function that is both injective and surjective — a perfect pairing between two sets.

Cardinality

|A|, the size of a set; two sets share a cardinality exactly when a bijection exists between them.

Countable / Countably Infinite

A set is countable if finite or in bijection with ℕ; an infinite countable set (like ℤ or ℚ) has cardinality ℵ₀.

Unit 3 — Combinatorics

Multiplication Principle

If a task is a sequence of independent choices with n₁, n₂, ..., nₖ options, the total ways to complete it is n₁·n₂·...·nₖ.

Addition Principle

If a task can be done by one of several mutually-exclusive methods, the total ways is the sum of each method's count.

Factorial (n!)

The product n·(n−1)·...·1, with 0! = 1 by convention; counts the arrangements of n distinct items.

Permutation, P(n,r)

Counts arrangements of r items chosen from n, where order matters: P(n,r) = n!/(n−r)!.

Combination, C(n,r)

Counts selections of r items from n, where order doesn't matter: C(n,r) = n!/(r!(n−r)!).

Pascal's Triangle / Pascal's Identity

C(n,r) = C(n−1,r−1) + C(n−1,r); arranging these by row produces the triangle where each entry is the sum of the two above it.

Binomial Theorem

(x+y)ⁿ = Σ C(n,k)·x^(n−k)·yᵏ — Pascal's triangle row n gives the expansion's coefficients directly.

Unit 4 — Discrete Probability

Sample Space

The set S of every possible outcome of an experiment.

Event

Any subset E ⊆ S of the sample space.

Probability (Equally Likely Outcomes)

P(E) = |E| / |S|, when every outcome in a finite sample space is equally likely.

Conditional Probability

P(A|B) = P(A∩B) / P(B) — the probability of A once B is already known to have happened.

Independence

A and B are independent when P(A∩B) = P(A)·P(B), equivalently P(A|B) = P(A).

Random Variable

A function X: S → ℝ assigning a real number to every outcome of the sample space.

Expected Value

E[X] = Σ x·P(X=x) — the long-run probability-weighted average of a random variable, not a prediction about any single trial.

Unit 5 — Graph Theory

Graph (Vertices and Edges)

G = (V,E): a set of vertices and a set of edges, each an unordered pair of vertices.

Degree / Handshake Theorem

deg(v) counts edges incident to v; the sum of all degrees always equals 2|E|.

Walk, Path, Cycle

A walk allows repeated vertices; a path never repeats one; a cycle is a path of length ≥3 that returns to its start.

Connected Graph / Connected Component

A graph is connected if a path exists between every pair of vertices; otherwise it splits into components that partition V.

Tree

A connected graph with no cycles; a tree on n vertices always has exactly n−1 edges.

Proper Coloring

An assignment of colors to vertices so that no two adjacent vertices share a color.

Chromatic Number, χ(G)

The minimum number of colors any proper coloring of G requires.

Unit 6 — Number Theory

Divides (a | b)

a | b if some integer k satisfies b = a·k.

Division Algorithm

For integer a and positive integer b, unique integers q, r exist with a = bq + r and 0 ≤ r < b.

Prime Number

An integer p > 1 whose only positive divisors are 1 and p; 1 itself is excluded from this definition by design.

Fundamental Theorem of Arithmetic

Every integer n > 1 has a prime factorization that is unique up to the order the primes are listed in.

Congruence Modulo n (a ≡ b mod n)

Holds when n | (a−b), equivalently when a and b leave the same remainder when divided by n.

Modular Arithmetic (a mod n)

The unique remainder of a divided by n; addition and multiplication both respect congruence mod n.

Unit 7 — Recursion, Induction & Recurrence Relations

Recursive Definition

Defines a sequence or set via base case(s) plus a rule building later cases from earlier, smaller ones.

Mathematical Induction

Proves P(n) for all n ≥ n₀ via a base case P(n₀) plus an inductive step showing P(k) implies P(k+1).

Strong Induction

Like induction, but the inductive step may assume P(m) for every m from n₀ up to k, not just P(k) alone.

Linear Homogeneous Recurrence Relation

aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ + ... + cₖaₙ₋ₖ for fixed constants — the Fibonacci recurrence is the order-2 case with c₁=c₂=1.

Characteristic Equation

Substituting aₙ → xⁿ into a linear recurrence and dividing out the smallest power gives an algebraic equation whose roots build the closed-form solution.

Closed Form

An explicit formula for aₙ in terms of n directly, with no reference to earlier terms — proven correct for every n by (typically strong) induction.
