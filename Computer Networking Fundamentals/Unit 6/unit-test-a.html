1. In HTTP's request-response pattern, who is allowed to initiate an exchange?

HTTP is strictly request-then-response, always initiated by the client.

2. Fill in the blank: after the start line, headers, and a required blank line, the optional final part of an HTTP message is the ___.

The body carries the actual content, if any — often empty for a GET request but present in most responses.

3. A response arrives with status code 500. What category does this fall into?

500 (Internal Server Error) is a 5xx code — the request was fine, but the server failed to handle it.

4. What does it mean that HTTP is stateless?

Each request is handled as an independent event, with no built-in memory linking it to prior requests.

5. Fill in the blank: the mechanism that lets a stateless protocol like HTTP still keep users "logged in," by having the browser automatically re-send proof of identity on every request, is a ___.

Cookies are a workaround built on top of stateless HTTP, not a violation of statelessness itself.

6. What does HTTPS add on top of ordinary HTTP, and what protocol does the work? Answer both parts:

(a) What does HTTPS add?

(b) Which protocol actually performs that encryption?

HTTPS is ordinary HTTP encrypted by TLS, which wraps the TCP connection before any HTTP data is sent.

7. Why does TLS verify a server's identity with a certificate, rather than only encrypting the data?

A certificate protects against connecting to an impersonator, a distinct problem from simply encrypting data in transit.

8. Fill in the blank: an API built directly on top of standard HTTP, treating URLs as resources and HTTP methods as actions on them, is called a ___ API.

REST (Representational State Transfer) reuses HTTP's existing methods and status codes rather than inventing new ones.

9. A REST API needs to permanently remove a specific resource. Answer both parts:

(a) Which HTTP method is conventionally used?

(b) Why do REST APIs reuse existing HTTP methods instead of inventing custom action names?

Reusing HTTP's existing, universally supported machinery avoids reinventing it from scratch.

10. Fill in the blank: rather than HTML, a REST API commonly returns structured data in a format like ___, which a program can parse directly without any human reading it.

JSON is a common format for API responses meant to be consumed by another program rather than displayed as a web page.
