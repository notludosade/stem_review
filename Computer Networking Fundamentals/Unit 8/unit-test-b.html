1. A home router blocks unsolicited inbound connections from the internet by default, while allowing outbound connections and their replies. What kind of protection does this provide?

This default rule is a major reason home devices aren't constantly probed directly by anyone on the internet.

2. Fill in the blank: the more permissive firewall approach, which allows all traffic except what's explicitly blocked, is called a(n) ___ approach.

A denylist (default-allow) is only as good as how complete its list of known threats is kept, unlike an allowlist's default-block stance.

3. Why is a default-deny (allowlist) approach generally considered stronger than default-allow (denylist)?

Default-deny doesn't require anticipating every specific threat in advance.

4. Why might an attacker use IP spoofing during a denial-of-service attack?

Spoofed source addresses can hide an attacker's real identity and complicate address-based blocking.

5. Fill in the blank: capturing and reading network traffic not addressed to the reader, using software that captures traffic on a local network segment, is called ___.

Sniffing is exactly the vulnerability HTTPS/TLS encryption is designed to close, by making captured data unreadable.

6. How does TLS's certificate verification defend specifically against a man-in-the-middle attack? Answer both parts:

(a) What does certificate verification check?

(b) What should a user do if a certificate warning appears?

Certificate warnings exist specifically to catch a man-in-the-middle attack in progress.

7. What's the key difference between what ping and traceroute each reveal?

Traceroute's hop-by-hop detail is exactly what lets it narrow down where along a path a failure occurs, unlike ping's simple reachable/unreachable result.

8. Fill in the blank: the lightweight Internet-layer protocol built for diagnostics and error reporting, rather than carrying application data, is ___.

ICMP underlies both ping and traceroute's diagnostic messages.

9. A traceroute shows the first two hops (home router, ISP gateway) responding normally, but every hop beyond that times out. Answer both parts:

(a) What does this rule out?

(b) Where does this narrow the likely problem to?

The last responding hop marks the boundary of what's confirmed working, narrowing the search to just beyond it.

10. Fill in the blank: in the bottom-up troubleshooting order (Link, Internet, DNS, Transport, Application), checking the actual HTTP status code returned by a service happens at the ___ layer, last.

The Application layer is checked last, after every lower layer has already been confirmed to be working.
