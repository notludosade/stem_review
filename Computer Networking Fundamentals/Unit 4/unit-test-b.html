1. A device connects multiple computers within a single office and forwards traffic between them using MAC addresses. What kind of device is this?

Forwarding by MAC address within one network is a switch's job — a router forwards between separate networks using IP addresses instead.

2. Fill in the blank: the specific router a device sends traffic to whenever the destination isn't on its own local network is called its ___.

The default gateway is the exit point out of a local network, typically a home router.

3. Why can a chain of routers get a packet to its destination even though no single router knows the full route in advance?

Local, next-hop-only decisions repeated at each hop are sufficient — no router needs the full path in advance.

4. Why is NAT needed at all, given that private IP addresses aren't routable on the public internet?

NAT is exactly the bridge between an unroutable private address and the routable public internet.

5. Fill in the blank: NAT is described as a workaround rather than a permanent fix, because it doesn't create new address space — it only shares existing addresses more efficiently against IPv4's ___.

IPv6's larger address space is the actual long-term fix; NAT only bought IPv4 additional time.

6. A laptop at 192.168.1.14 sends a request through a home router with public address 203.0.113.9. Answer both parts:

(a) What source address does the destination web server actually see?

(b) How does the reply eventually reach the correct laptop specifically?

The web server only ever sees the router's public address; NAT's internal table is what routes the reply back to the correct private device.

7. What is a domain name?

A domain name is purely a human-friendly label; DNS is what maps it to the actual IP address needed for routing.

8. Fill in the blank: the piece of software, usually run by an ISP or a public service, that performs a DNS lookup on a device's behalf is called a ___.

A resolver queries the root, TLD, and authoritative servers on the requesting device's behalf.

9. In a full DNS lookup, in what order are servers queried? Answer both parts:

(a) Which server is queried first?

(b) Which server holds the actual final answer (the A record)?

The lookup chain goes root → TLD → authoritative, getting more specific at each step until the final answer is found.

10. Fill in the blank: the DNS record type that maps a domain name to an IPv4 address, held by the authoritative server, is called an ___.

An A record is exactly the answer type returned at the end of a successful DNS lookup.
