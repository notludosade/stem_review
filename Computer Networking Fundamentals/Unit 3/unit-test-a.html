1. Where does a MAC address come from, and how permanent is it?

MAC addresses are manufacturer-assigned and essentially fixed, unlike IP addresses which can change per network.

2. Fill in the blank: a MAC address is only meaningful for ___ — it gets replaced with a new one at every router along a packet's path.

Unlike an IP address, a MAC address only matters on the local network segment for the immediate next hop.

3. Why can no octet in a dotted-decimal IPv4 address ever exceed 255?

255 in binary is 11111111 — the largest value 8 bits can hold.

4. Two devices on two completely different home networks both have the address 192.168.1.5 at the same time. Is this a conflict?

Private ranges are never routed on the public internet, so they can be reused freely across separate networks.

5. Fill in the blank: in 192.168.1.0/24, the number ___ tells you how many of the 32 bits are the network portion.

CIDR notation states the network-bit count directly after the slash.

6. In a subnet, which two addresses are always reserved and never assigned to an individual device? Answer both parts:

(a) The address with every host bit set to 0 is called the:

(b) The address with every host bit set to 1 is called the:

The network address identifies the subnet itself; the broadcast address reaches every device on it — neither is assignable to one device.

7. A subnet has 4 host bits. How many usable host addresses does it have?

Usable hosts = 2^h − 2, subtracting the reserved network and broadcast addresses.

8. Fill in the blank: the depletion of the pool of available IPv4 addresses, forcing reliance on smaller reclaimed blocks and address-sharing techniques like NAT, is called ___.

Address exhaustion is a real, ongoing consequence of IPv4's fixed 32-bit address ceiling.

9. Why did IPv6 use a 128-bit address instead of, say, extending IPv4 to 64 bits? Answer both parts:

(a) Why couldn't IPv4 simply be extended in place?

(b) Given that a new protocol was unavoidable, why go all the way to 128 bits?

Since any protocol change breaks compatibility regardless of the new size chosen, IPv6's designers chose a size large enough to avoid needing another overhaul.

10. Fill in the blank: each of the eight 16-bit, colon-separated groups in an IPv6 address is called a ___.

A hextet is IPv6's equivalent to IPv4's octet.
