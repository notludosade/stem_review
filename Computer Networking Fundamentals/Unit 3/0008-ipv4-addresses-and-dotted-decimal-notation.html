IPv4 Addresses and Dotted-Decimal Notation

The address that actually gets a packet from one side of the world to the other — and the arithmetic hiding just underneath its familiar dotted-decimal look.

← Lesson 7 Lesson 9 → Contents Glossary →

Lesson 7 drew the line: MAC addresses handle one hop; something else has to handle the whole end-to-end journey. That something is the IP address — the Internet layer's addressing system, and the address that actually shows up in the header a router reads to decide where to forward a packet next.

What an IPv4 address is

Definition An IPv4 address is a 32-bit number, almost always written in dotted-decimal notation — four numbers between 0 and 255, separated by dots, like 192.168.1.14. Each of the four numbers is called an octet, because it represents exactly 8 bits (1 byte) of the full 32-bit address. "IPv4" means "Internet Protocol version 4" — the version this lesson covers, and the version that's been the internet's dominant addressing system since the 1980s (Lesson 10 covers why a newer version, IPv6, exists at all).
From binary to dotted-decimal, by hand The 32-bit binary address 11000000.10101000.00000001.00001110 splits naturally into four 8-bit chunks (that's exactly what the dots in dotted-decimal notation mark). Converting each 8-bit chunk to decimal: 11000000 = 192, 10101000 = 168, 00000001 = 1, 00001110 = 14. Written in dotted-decimal: 192.168.1.14. This is precisely why each octet's decimal value is capped at 255 — that's 11111111, the largest value 8 bits can represent.
Why the 0-255 ceiling isn't arbitrary An octet is 8 bits, and 8 bits can represent exactly 2⁸ = 256 distinct values — 0 through 255. Seeing "300" or "256" anywhere in a supposed IP address is an immediate signal that something is malformed, because no single octet can ever hold a value that large. Recognizing this ceiling instantly, without doing the binary math every time, is worth building as a reflex — Lesson 9's subnetting math leans on the same fact constantly.

Public vs. private IP addresses

Definition A public IP address is globally unique and routable across the open internet — no two devices on the public internet can share one at the same time. A private IP address is only meaningful inside one local network (like a home or office LAN) and is reused by millions of different private networks simultaneously, because private addresses are never routed across the public internet at all. Three specific ranges are reserved for private use: 10.0.0.0–10.255.255.255, 172.16.0.0–172.31.255.255, and 192.168.0.0–192.168.255.255 — if a device's address starts with 192.168, it's almost certainly a private address on someone's home network, not a globally unique one.
Worked example: why address reuse is fine here Your neighbor's laptop and your own laptop might both have the private address 192.168.1.14 at the exact same moment, on their own separate home networks, with zero conflict — because private addresses are never used to route traffic across the public internet; they only need to be unique within their own local network. Lesson 12 (NAT) explains the exact mechanism that lets every device on your private home network share your ISP's single public address when talking to the outside world.

Every IPv4 address has two parts

An IPv4 address isn't one flat, arbitrary number — part of it identifies which network a device belongs to, and part of it identifies that specific device within that network. Exactly how that split is drawn is the entire subject of Lesson 9's subnetting and CIDR notation; this lesson is only establishing what the raw address itself looks like and where its 0-255-per-octet limit comes from.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does each of the four numbers in a dotted-decimal IPv4 address (like the "192" in 192.168.1.14) represent?

Four 8-bit octets make up the full 32-bit IPv4 address, with dots marking the boundary between them.

2. Why can no single octet in an IPv4 address ever exceed 255?

255 in binary is 11111111 — the largest value 8 bits can hold, which is exactly one octet's worth.

3. Two devices on two completely different home networks both have the address 192.168.1.14 at the same time. Is this a problem?

Private ranges are reused across millions of separate networks simultaneously since they're never routed on the public internet.

4. Fill in the blank: each of the four dot-separated, 8-bit segments of an IPv4 address is called an ___.

Four octets — 32 bits total — make up a full IPv4 address.
