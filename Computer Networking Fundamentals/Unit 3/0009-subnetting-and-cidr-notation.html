Subnetting and CIDR Notation

Lesson 8 left one question hanging: how much of a 32-bit IPv4 address identifies the network, and how much identifies the specific device? This lesson is the arithmetic that answers it.

← Lesson 8 Lesson 10 → Contents Glossary →

Every IPv4 address is split into two parts: a network portion, shared by every device on the same local network, and a host portion, unique to one specific device within that network. Where exactly that split happens isn't fixed — it's configurable, and that configurability is the whole subject of this lesson.

Subnet masks and CIDR notation

Definitions A subnet is a logically visible subdivision of a larger network. A subnet mask marks exactly where the network/host split happens in a 32-bit address, using a run of 1-bits (network portion) followed by a run of 0-bits (host portion) — like 11111111.11111111.11111111.00000000, written in dotted-decimal as 255.255.255.0. CIDR notation (Classless Inter-Domain Routing) writes the same information far more compactly: instead of a full second dotted-decimal number, it just writes a slash followed by the count of 1-bits — 192.168.1.0/24 means "the first 24 bits are the network portion," which is exactly the same information as pairing that address with the mask 255.255.255.0.
Reading a CIDR prefix 192.168.1.0/24: 24 network bits, leaving 32 − 24 = 8 host bits — exactly one full octet's worth, so every device on this subnet shares 192.168.1 and only the last number varies (192.168.1.1, 192.168.1.2, etc.). 10.0.0.0/16: 16 network bits, leaving 16 host bits — a much larger subnet, where every device shares only 10.0 and both of the last two octets can vary.

Network address, broadcast address, and usable hosts

Definitions The network address is the address within a subnet where every host bit is 0 — it identifies the subnet itself and is never assigned to an individual device. The broadcast address is the address where every host bit is 1 — sending to it reaches every device on that subnet at once, and it's likewise never assigned to a single device. Every other address in between is available to assign to an actual device, so the number of usable hosts in a subnet with h host bits is 2h − 2 (the −2 accounts for the network and broadcast addresses being reserved, not usable).

Why the network/host split is configurable at all, instead of fixed A fixed split (say, always exactly one octet for hosts) would force every subnet in the world to be the same size — wildly wasteful for a home network with 5 devices, and completely inadequate for a data center with 50,000. CIDR's configurable prefix length lets a network administrator size a subnet to the actual number of devices it needs to hold: a small home network might use a /28 (16 total addresses, 14 usable), while a large organization might use a /16 (65,536 total addresses). This flexibility is precisely why CIDR replaced IPv4's older, rigid "class-based" addressing system in the 1990s — the "classless" in Classless Inter-Domain Routing is a direct reference to abandoning those fixed-size classes.
Worked example, done by hand Subnet 192.168.1.0/26: 26 network bits leave 6 host bits, so usable hosts = 2⁶ − 2 = 62. The network address is 192.168.1.0 (all host bits 0). The broadcast address is 192.168.1.63 (all 6 host bits set to 1, since 2⁶ − 1 = 63, and 0 + 63 = 63). Usable device addresses run from 192.168.1.1 through 192.168.1.62 — 62 addresses, matching the count above.

Check your recall

No peeking back up — answer from memory first, then check.

1. What does the "/24" in 192.168.1.0/24 mean?

CIDR notation directly states the network-bit count, equivalent to a full subnet mask like 255.255.255.0 for /24.

2. Why are the network address and broadcast address of a subnet never assigned to an individual device?

This is exactly why usable-host count is 2^h − 2, subtracting these two reserved addresses.

3. Why does CIDR's configurable prefix length matter, compared to a fixed-size subnet for every network?

Sizing subnets to actual need, instead of one fixed size for everyone, is exactly what "classless" addressing enables.

4. Fill in the blank: a subnet with 6 host bits (like a /26) has 2⁶ − 2 = ___ usable host addresses.

2⁶ = 64 total addresses; subtract 2 for the reserved network and broadcast addresses, leaving 62 usable.
