Writing Networked Programs. 10 questions covering every lesson in this unit. Score 90% or higher to clear this unit.

1. Creating a socket is conceptually similar to which other programming operation?

The socket-as-file-handle analogy captures the create/read-write/close pattern shared by both.

2. Fill in the blank: the socket operation, used only by a server, that puts a socket into a state waiting for incoming connection attempts is ___.

Listen() prepares a server socket to accept incoming connections, unlike a client's connect().

3. When a program calls send() and recv() on a TCP socket, what's happening underneath, according to this unit?

The socket API hides TCP's reliability machinery entirely — it still runs, just not written by the programmer.

4. In a peer-to-peer file-sharing system, how does distributing a file differ from client-server distribution?

Peers redistribute pieces among themselves, spreading load instead of concentrating it on one server.

5. Fill in the blank: the main risk of the client-server model is that the server becomes a ___ — if it goes down, every dependent client loses service simultaneously.

Centralizing the server side creates a single point of failure that peer-to-peer designs avoid.

6. In the end-to-end traced exchange, what happens before any message data is sent? Answer both parts:

(a) What process runs first?

(b) What client-side function call triggers this process?

connect() triggers TCP's three-way handshake before any application data is exchanged.

7. When the frame arrives at the server, in what order are headers stripped?

Decapsulation reverses encapsulation's order, matching Lesson 6.

8. Fill in the blank: as the message's packet passes through each router, the router reads only the ___ header to decide where to forward it next.

Routers operate at the Internet layer, reading only the IP header — never the TCP header or the message content itself.

9. The traced exchange used a tiny custom message ("World") instead of a real HTTP request. Answer both parts:

(a) Does that make the trace inapplicable to loading a real website?

(b) What principle from earlier in the course explains why?

Layering is exactly what makes the lower-layer steps identical regardless of the specific application payload.

10. Fill in the blank: once the server's Transport layer strips the TCP header, it uses the destination ___ number to deliver the message to the correct listening program.

Demultiplexing by destination port, as covered in Lesson 14, is what finally delivers data to the right program.
