Career Pathways

A step up from the pathways above: more courses, and picked for career-level rigor rather than the shortest coherent route. Where a regular pathway strings together 4–5 courses toward one outcome, a career pathway pulls in the deep-CS and systems-level courses too, on the theory that a career, unlike a course sequence, doesn't get to skip the unglamorous fundamentals.

Career Pathway

General Programmer

Computer Programming 1 → Computer Programming 2 → Computer Programming Ethics → Computer Programming 2+ → Software Engineering → Data Handling: CB → Systems Programming & Architecture: CS → Computer Networking Fundamentals → Advanced Algorithms — 9 courses, 241 lessons, one capstone. The deepest generalist route on the site: fundamentals, data structures, professional ethics, interview-grade algorithmic patterns, software engineering process, databases, systems-level computing, networking, and rigorous algorithm theory.

 Career Pathway

AI Developer: CB/RWA

Computer Programming 1 → Computer Programming 2 → Data Handling: CB → AI Developer → Applied Machine/Deep Learning → Cloud Computing A → Cloud Computing B / DevOps — 7 courses, 171 lessons, one capstone. Career-based (CB) and real-world-application (RWA) focused: everything the regular AI & Data pathway covers, then deeper network-building math, tuning real models by hand, and actually shipping and running an AI system in the cloud instead of stopping at a working notebook.
