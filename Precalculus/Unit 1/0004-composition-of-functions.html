Composition of Functions

Feeding the output of one function straight into another.

← Lesson 3 Lesson 5 → Contents Glossary →

You already chain operations without thinking about it: "add 2, then square it" is two steps applied one after another. Composition is just the formal name — and notation — for exactly that.

Definition The composition (f ∘ g)(x), also written f(g(x)), means: first apply g to x, then apply f to whatever g produced.
Why it works Read f(g(x)) from the inside out, not left to right: g(x) is computed first because it's the innermost thing being fed into f. This trips people up constantly — the function written second is applied first.

Below, g(x) = x + 2 and f(x) = x². Type a number and watch it flow through both steps. Switch the tab to reverse the order and see whether you get the same answer.

Try x = 3 on both tabs. f(g(3)) = 25, but g(f(3)) = 11 — composition is not commutative. Order isn't a technicality here; it changes the answer.

2. Composition can restrict the domain further

A composed function is only defined where both steps succeed. Here, g(x) = √x and f(x) = 1/x, so f(g(x)) = 1/√x. Drag along the line and watch for where it breaks.

Try It — Where Is f(g(x)) Defined?

—

Drag left past 0 first, then hover right around 0 itself — two different reasons it fails.

Left of 0, g(x) = √x already fails — negative numbers have no real square root, so f never even gets a number to work with. Right at 0, g(0) = 0 succeeds, but then f(0) = 1/0 fails. Either function can be the one that breaks — the composition's domain is whatever's left after both restrictions apply.

Check your recall

1. If g(x) = x + 2 and f(x) = x², what is f(g(3))?

g(3) = 5 first, then f(5) = 25. Getting 11 means you computed g(f(3)) instead — the reversed order.

2. For g(x) = x + 2 and f(x) = x², is f(g(x)) always equal to g(f(x))?

You saw it directly in the widget: f(g(3)) = 25 while g(f(3)) = 11. Composition is generally not commutative.

3. In f(g(x)), the function applied first is ___.

Read inside-out: g(x) is computed first, and its output becomes f's input.
