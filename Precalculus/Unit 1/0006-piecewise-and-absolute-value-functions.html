Piecewise & Absolute Value Functions

A function whose rule changes depending on which input you plug in.

← Lesson 5 Lesson 7 → Contents Glossary →

Every function so far has had one formula, used for every input. A piecewise function breaks that pattern — different formulas apply on different intervals of the domain, and you have to check which interval your input lands in before you know which formula to use.

1. The simplest piecewise function: |x|

Definition |x| (absolute value of x) is secretly piecewise: |x| = x when x ≥ 0, and |x| = −x when x < 0. Either way, the result is x's distance from 0 — never negative.

Absolute value is the gentle case — both branches actually agree at the boundary. That's not guaranteed. Here's a function where they don't:

Why it matters for Calculus This graph jumps at x = 0 — the two branches don't meet. In Calculus this gets a name: p is discontinuous at x = 0. Whether the pieces of a piecewise function meet up or not becomes the whole question once you study limits and continuity.

Check your recall

1. If f(x) = |x| and x = −7, what is f(x)?

−7 is negative, so the |x| = −x branch applies: −(−7) = 7. Absolute value output is never negative.

2. A piecewise function can use a different formula for:

The domain — the set of inputs — is split into intervals, and each interval gets its own formula. Which formula applies depends on where x falls, not on the output.

3. The absolute value function |x| has a sharp point, called a ___, at x = 0.

The two linear branches meet at x = 0 but at different slopes, producing a sharp corner rather than a smooth curve.
