Inverse Functions

Undoing a function completely — and why that isn't always possible.

← Lesson 6 Lesson 8 → Contents Glossary →

If a function takes x to y, its inverse takes y right back to x. Not every function has one — but when it does, it's a mirror image of the original, in a very literal, drawable sense.

1. The inverse is a reflection across y = x

Definition If f(a) = b, then the inverse function f⁻¹ satisfies f⁻¹(b) = a. Every point (a, b) on f's graph corresponds to a point (b, a) on f⁻¹'s graph — the same coordinates, swapped.

Drag the point on f(x) = 2x + 1 and watch its mirror image trace out f⁻¹.

Try It — Mirror Across y = x

—

Solid curve: f. Dashed curve: f⁻¹, graphed independently — watch the mirrored point land on it exactly.

Why it works Swapping a point's coordinates is exactly what solving for the inverse does algebraically: start with y = 2x + 1, swap x and y to get x = 2y + 1, then solve for y to get f⁻¹(x) = (x − 1) / 2. The graph just shows that swap happening visually.

2. Not every function has one

An inverse can only "send y back to a single x" if that y only ever came from one x in the first place. Test it: drag the horizontal line across g(x) = x².

Try It — Horizontal Line Test

—

This is the horizontal line test — the mirror image of the vertical line test from Lesson 1. The vertical line test asked "does one input give two outputs?" The horizontal line test asks "does one output come from two inputs?" A function needs to pass both tests to have an ordinary inverse: it must be a function to begin with, and it must be one-to-one.

2. A function has an ordinary inverse only if it is:

If two different inputs shared an output (many-to-one), the inverse wouldn't know which one to send that output back to.

3. The horizontal line test checks whether a function is ___.

A horizontal line crossing more than once reveals two inputs sharing one output — the function isn't one-to-one, so it has no ordinary inverse.
