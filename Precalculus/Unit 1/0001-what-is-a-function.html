What Is a Function, Really?

The one idea everything else in this course — and next year's Calculus — is built on top of.

Lesson 2 → Contents Glossary →

Almost every topic in precalculus is really the study of one question: given some function, what does it look like and how does it behave? Polynomials, exponentials, logarithms, sine and cosine — they're all just different kinds of functions. So before any of that, we need to be precise about what a function actually is.

The core idea

Informally, a function is a rule that takes an input and produces an output. That's the intuition you already have. The precise version adds one strict condition:

Definition A function is a rule that assigns to each input exactly one output. Give it the same input twice, you always get the same output back.

That word "exactly" is the entire concept. A rule that sometimes gives an input two different outputs is not a function — it's just a relation (any pairing of inputs and outputs, functions included). Every function is a relation; not every relation is a function.

A function

f(x) = x2

Every real number x produces exactly one output: square it. Input 3, always get 9. Input −3, always get 9. Two different inputs are allowed to share an output — that's fine. What's not allowed is one input producing two different outputs.

Not a function

x2 + y2 = 9

This is a relation (a circle of radius 3) but not a function of x. Plug in x = 0: y could be 3 or −3. One input, two outputs — it fails the definition immediately.

Function notation

We write f(x) — read aloud as "f of x" — to name a function f and describe its output for input x. This is notation, not multiplication: f(x) does not mean f times x.

So if f(x) = 2x + 1, then:

f(3) = 2(3) + 1 = 7

"f(3)" means "plug 3 in for every x in the rule, then evaluate." This is the notation you'll use constantly from here through Calculus — get comfortable reading it aloud, not just writing it.

Domain and range

Two more terms, both about the set of values involved rather than a single input/output pair:

Domain The complete set of allowable inputs. For f(x) = 1/x, the domain is every real number except 0 — dividing by zero isn't defined, so 0 is excluded.
Range The complete set of outputs the function actually produces. For f(x) = x2, the range is all numbers ≥ 0 — squaring a real number never produces a negative result.

The vertical line test

Reading a definition off an equation is one thing; reading it off a graph is another. The vertical line test gives you a fast visual shortcut, and it's a direct consequence of the definition above — not a separate rule to memorize.

Every point on a vertical line shares the same x-value. So: if a vertical line crosses a graph more than once, that x-value has more than one y-value — which is exactly the thing a function isn't allowed to do.

Why it works Vertical line test = "does any x-value repeat with a different y?" asked visually instead of algebraically. It's the same question as the definition, just seen rather than computed.

Check your recall

No peeking back up — answer from memory first, then check.

1. By definition, what makes a relationship between two variables a function?

The condition is on inputs, not outputs: one input can never split into two different outputs. Two different inputs sharing an output is completely fine.

2. What is the domain of a function?

The output side of that same idea is the range. "Every real number" is only the domain when nothing (like division by zero) restricts it — not a general truth.

3. Why does the vertical line test work for identifying functions on a graph?

A vertical line is the set of all points with one fixed x. If it hits the graph twice, that one x-value has two y-values — a direct violation of the definition.

4. Fill in the blank: f(x) is read aloud as "f ___ x."

It's notation, not multiplication — "f of x," naming the output of function f for input x.

5. For a set of points to represent a function, no two points may share the same ___.

Repeated y-values are fine — repeated x-values (with different y's) are the one thing that breaks the definition.
