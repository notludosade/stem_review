1. Why does the equation x = y² − 1 fail to define y as a function of x?

Solving for y gives y = ±√(x + 1). For any x greater than −1, both the positive and negative root work — one input, two outputs, which the definition forbids.

2. Fill in the blank: If every vertical line crosses a graph at most ___ time, the graph passes the vertical line test.

One crossing per vertical line means every x-value has at most one y-value — exactly the condition a function must satisfy.

3. For g(x) = −2x + 6, answer both parts:

(a) What is g(−3)?

(b) Fill in the blank: g(1) = ___.

(a) −2(−3) + 6 = 6 + 6 = 12. (b) −2(1) + 6 = −2 + 6 = 4 — same rule, a different input.

4. For h(x) = √(x − 5), answer both parts:

(a) What is the domain?

(b) Fill in the blank: The range of h is y ≥ ___.

(a) A square root needs a nonnegative radicand: x − 5 ≥ 0 means x ≥ 5. (b) The smallest output occurs at the domain's left endpoint, h(5) = 0, and outputs grow without bound from there, so the range is y ≥ 0.

5. For f(x) = x² − 2x, answer both parts:

(a) What is the average rate of change from x = 0 to x = 4?

(b) Fill in the blank: The average rate of change from x = −1 to x = 1 is ___.

(a) [f(4) − f(0)] / (4 − 0) = (8 − 0) / 4 = 2. (b) f(−1) = 1 + 2 = 3 and f(1) = 1 − 2 = −1, so [f(1) − f(−1)] / (1 − (−1)) = (−1 − 3) / 2 = −2.

6. A graph rises until x = −1, then falls afterward. What is x = −1?

Switching from increasing to decreasing is exactly the definition of a local maximum — the top of a peak.

7. If f(x) = x² and g(x) = x − 2, answer both parts:

(a) Fill in the blank: g(f(3)) = ___.

(b) What is f(g(3))?

(a) f(3) = 3² = 9 first, then g(9) = 9 − 2 = 7. (b) Reversing the order: g(3) = 3 − 2 = 1 first, then f(1) = 1² = 1 — the outputs differ because composition isn't commutative.

8. Compared to y = f(x), the graph of y = f(x) − 6 is shifted:

Subtracting outside the function acts directly on the output, moving every point straight down by 6.

9. For the piecewise function f(x) = 2x if x ≤ 1, and f(x) = x + 5 if x > 1, answer both parts:

(a) What is f(1)?

(b) Fill in the blank: f(2) = ___.

(a) x = 1 satisfies x ≤ 1, so the first rule applies: f(1) = 2(1) = 2, not the second rule. (b) x = 2 > 1, so the second rule applies instead: f(2) = 2 + 5 = 7 — crossing the boundary switches branches.

10. Fill in the blank: A function must be ___ (pass the horizontal line test) before it can have an ordinary inverse.

If two different inputs shared an output, the inverse wouldn't know which one to send that output back to — the function must be one-to-one first.
