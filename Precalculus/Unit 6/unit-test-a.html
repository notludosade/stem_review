1. For the system y = 3x − 2 and y = −2x + 8, answer both parts:

(a) What is the solution?

(b) Since this system has exactly one solution, it is classified as:

(a) Setting 3x − 2 = −2x + 8 gives 5x = 10, so x = 2; substituting back gives y = 3(2) − 2 = 4. The point (2, 4) satisfies both equations. (b) Since the two lines have different slopes (3 and −2), they cross at exactly one point — a system with a single solution is consistent (it has a solution) and independent (the equations aren't equivalent).

2. Fill in the blank: The standard strategy for a 3×3 system eliminates one variable from two different pairs of equations, producing two equations in the remaining ___ unknowns.

Removing one variable from two separate equation-pairs leaves two equations in the two variables that remain — exactly the two-variable problem from Lesson 32, solvable by substitution or elimination.

3. Solve the nonlinear system y = x² − 2x − 3 and y = 2x − 3. What are the solutions?

Substituting the line into the parabola gives x² − 4x = 0, which factors to x(x − 4) = 0, so x = 0 or x = 4. Plugging back into y = 2x − 3 gives (0, −3) and (4, 5) — the two crossing points.

4. Answer both parts about matrix dimensions:

(a) Which pair of matrices can be added together?

(b) If B is a 3×2 matrix, what are the dimensions of the scalar product 4B?

(a) Addition combines entries in matching positions, so both matrices need identical dimensions. Only the two 2×3 matrices share that. (b) Scalar multiplication just rescales every entry in place — it never changes a matrix's dimensions, so 4B is still 3×2.

5. Fill in the blank: For matrices A (size 2×3) and B (size 3×4), the product AB is defined and has dimensions 2 × ___.

A product's dimensions are A's row count by B's column count (the "outer" dimensions) — a 2×3 matrix times a 3×4 matrix gives a 2×4 result.

6. For the system x − y = 2, 4x + y = 13, answer both parts:

(a) What is the augmented matrix for this system?

(b) After Gaussian elimination, the augmented matrix reduces to [1 0 | 3 ; 0 1 | 1]. What is the solution (x, y)?

(a) Each row lists a coefficient of x, a coefficient of y, then the constant after the bar, in the order the equations are written: row 1 is (1, −1 | 2), row 2 is (4, 1 | 13). (b) A reduced augmented matrix in the form [1 0 | c₁ ; 0 1 | c₂] directly reads off x = c₁ and y = c₂, so the solution is (3, 1) — which checks out: 3 − 1 = 2 and 4(3) + 1 = 13.

7. For the system 2x + y = 7, x − 3y = −2, answer both parts:

(a) What is the determinant D of the coefficient matrix?

(b) What is Dx, the determinant with the constants substituted into the x-column?

(a) D = |2 1; 1 −3| = (2)(−3) − (1)(1) = −6 − 1 = −7. (b) Substituting the constants (7, −2) into the x-column gives Dx = |7 1; −2 −3| = (7)(−3) − (1)(−2) = −21 + 2 = −19.

8. An arithmetic sequence has a₁ = 8 and d = −3. What is a₉ (the 9th term)?

aₙ = a₁ + (n − 1)d, so a₉ = 8 + 8(−3) = 8 − 24 = −16.

9. For the arithmetic sequence with a₁ = 4 and a₂₀ = 80, answer both parts:

(a) Fill in the blank: the sum of the first 20 terms S₂₀ = 20(4 + 80)/2 = ___.

(b) Fill in the blank: the common difference d of this sequence is ___.

(a) Sₙ = n(a₁ + aₙ)/2, so S₂₀ = 20(4 + 80)/2 = 20(84)/2 = 840. (b) aₙ = a₁ + (n − 1)d, so a₂₀ = 4 + 19d = 80 gives 19d = 76, so d = 4.

10. A committee of 4 people is chosen from 10 candidates, with no distinction in role among the 4 chosen. How many committees are possible?

Since order doesn't matter among the 4 chosen, this is a combination: C(10,4) = 10!/(4!6!) = 210 — far fewer than the permutation count P(10,4) = 5040.
