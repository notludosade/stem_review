Matrices, Vectors, and Their Operations

A rectangular grid of numbers, stripped of variable names — a small set of rules for combining two of them into a third — and the special one-row or one-column case that shows up everywhere: the vector.

← Lesson 34 Lesson 36 → Contents Glossary →

A matrix is a rectangular array of numbers, enclosed in brackets, usually named with a capital letter. A row runs horizontally, a column runs vertically, and each number is an entry. A matrix with m rows and n columns has dimensions m × n. Strip the x's and y's out of a system of linear equations and only the coefficients remain — arranged in rows and columns, that's a matrix, and it's exactly the representation the next few lessons build on.

1. Addition, subtraction, and scalar multiplication

Rule — Addition and Subtraction Two matrices can be added or subtracted only if they have the same dimensions — then each entry combines with the entry in the same position. There's no way to add a 2×3 matrix to a 3×2 one; the entries simply don't correspond.
Rule — Scalar Multiplication Multiplying a matrix by a single number (a scalar) multiplies every entry by that number. This works for a matrix of any size, with no matching-dimension requirement.

2. Matrix multiplication

Rule — Multiplying Two Matrices A product AB is only defined when A's number of columns matches B's number of rows — the "inner dimensions" must agree. The result has A's row count and B's column count (the "outer dimensions"). Each entry of AB is found by pairing a row of A with a column of B, multiplying corresponding entries, and adding. Crucially, matrix multiplication is not commutative: AB and BA can have different dimensions entirely, or both be defined and still come out unequal.
Worked Example A = [[2, 0], [1, 3]], B = [[4, −1], [2, 5]]. Entry (row 1, col 1) of AB: (2)(4) + (0)(2) = 8. Entry (1,2): (2)(−1) + (0)(5) = −2. Entry (2,1): (1)(4) + (3)(2) = 10. Entry (2,2): (1)(−1) + (3)(5) = 14. So AB = [[8, −2], [10, 14]].

4. Vectors: the one-row (or one-column) special case

Definition A vector is an ordered list of numbers — equivalently, a 1×n matrix (a row vector) or an n×1 matrix (a column vector). Written in component form, a 2D vector looks like v = ⟨3, −2⟩ or as a column [[3], [−2]]. Geometrically, a vector represents a magnitude (length) and a direction — drawn as an arrow from one point to another, most often from the origin. Two arrows with the same length and direction represent the same vector, no matter where they're drawn; only the components matter, not the starting point.
Why "just a matrix with one row" undersells what a vector does Treating a vector as a skinny matrix is technically accurate and useful — it means every addition, subtraction, and scalar-multiplication rule from Section 1 applies to vectors with zero new rules to learn. But a vector also carries geometric meaning a general matrix doesn't: a displacement, a velocity, a force. That dual identity — "a matrix by the rules, an arrow by the meaning" — is exactly why vectors get their own name instead of just being called "a matrix."

5. Vector operations

Rule — Vector Addition and Scalar Multiplication Vector addition is component-wise, same as matrix addition: ⟨3, −2⟩ + ⟨1, 4⟩ = ⟨4, 2⟩. Geometrically, this is "tip-to-tail": draw the second vector starting where the first one ends, and the sum is the arrow from the very start to the very end. Scalar multiplication scales every component: 2⟨3, −2⟩ = ⟨6, −4⟩ — geometrically, a vector twice as long, pointing the same direction (or the opposite direction, for a negative scalar).
Rule — Magnitude The magnitude (length) of v = ⟨x, y⟩ is ‖v‖ = √(x² + y²) — literally the Pythagorean theorem, treating the vector as the hypotenuse of a right triangle formed by its components. A unit vector has magnitude exactly 1; dividing any nonzero vector by its own magnitude produces a unit vector pointing the same direction.
Worked Example For v = ⟨3, −4⟩: ‖v‖ = √(3² + (−4)²) = √(9 + 16) = √25 = 5. The unit vector in v's direction is v/5 = ⟨3/5, −4/5⟩ — check: ‖⟨3/5, −4/5⟩‖ = √(9/25 + 16/25) = √(25/25) = 1.

6. The dot product: where vectors and matrix multiplication meet again

Rule — Dot Product For v = ⟨v₁, v₂⟩ and w = ⟨w₁, w₂⟩, the dot product is v · w = v₁w₁ + v₂w₂ — a single number, not a vector. Notice this is exactly the "multiply corresponding entries and add" step from Section 2's matrix multiplication rule, applied to a row vector times a column vector. The dot product of two vectors pointing in similar directions is positive; pointing in opposite directions, negative; and exactly zero when the vectors are perpendicular.

1. Two matrices can be added only if they have:

Addition combines entries in matching positions, so both matrices need the same number of rows and the same number of columns for every entry to have a partner.

2. For a product AB to be defined, A's column count must match B's ___ count.

A's columns and B's rows are the two "inner" dimensions in A's rows × columns, B's rows × columns — they must agree for each entry's row-times-column pairing to make sense.

3. For A = [[2,0],[1,3]] and B = [[4,−1],[2,5]], entry (2,2) of AB is:

Row 2 of A is (1,3), column 2 of B is (−1,5): (1)(−1) + (3)(5) = −1 + 15 = 14.

4. A vector is best described as:

A vector is a row or column matrix — every matrix operation still applies — but it's also interpreted geometrically as an arrow with length and direction.

5. Fill in the blank: for v = ⟨3, −4⟩, ‖v‖ = ___.

‖v‖ = √(3² + (−4)²) = √25 = 5.

6. If v · w = 0 for two nonzero vectors, what does that tell you?

A dot product of zero between two nonzero vectors is exactly the condition for perpendicularity — it's often used as the definition.
