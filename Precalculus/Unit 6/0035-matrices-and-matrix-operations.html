Matrices and Matrix Operations

A rectangular grid of numbers, stripped of variable names — and a small set of rules for combining two of them into a third.

← Lesson 34 Lesson 36 → Contents Glossary →

A matrix is a rectangular array of numbers, enclosed in brackets, usually named with a capital letter. A row runs horizontally, a column runs vertically, and each number is an entry. A matrix with m rows and n columns has dimensions m × n. Strip the x's and y's out of a system of linear equations and only the coefficients remain — arranged in rows and columns, that's a matrix, and it's exactly the representation the next few lessons build on.

1. Addition, subtraction, and scalar multiplication

Rule — Addition and Subtraction Two matrices can be added or subtracted only if they have the same dimensions — then each entry combines with the entry in the same position. There's no way to add a 2×3 matrix to a 3×2 one; the entries simply don't correspond.
Rule — Scalar Multiplication Multiplying a matrix by a single number (a scalar) multiplies every entry by that number. This works for a matrix of any size, with no matching-dimension requirement.

2. Matrix multiplication

Rule — Multiplying Two Matrices A product AB is only defined when A's number of columns matches B's number of rows — the "inner dimensions" must agree. The result has A's row count and B's column count (the "outer dimensions"). Each entry of AB is found by pairing a row of A with a column of B, multiplying corresponding entries, and adding. Crucially, matrix multiplication is not commutative: AB and BA can have different dimensions entirely, or both be defined and still come out unequal.
Worked Example A = [[2, 0], [1, 3]], B = [[4, −1], [2, 5]]. Entry (row 1, col 1) of AB: (2)(4) + (0)(2) = 8. Entry (1,2): (2)(−1) + (0)(5) = −2. Entry (2,1): (1)(4) + (3)(2) = 10. Entry (2,2): (1)(−1) + (3)(5) = 14. So AB = [[8, −2], [10, 14]].

1. Two matrices can be added only if they have:

Addition combines entries in matching positions, so both matrices need the same number of rows and the same number of columns for every entry to have a partner.

2. For a product AB to be defined, A's column count must match B's ___ count.

A's columns and B's rows are the two "inner" dimensions in A's rows × columns, B's rows × columns — they must agree for each entry's row-times-column pairing to make sense.

3. For A = [[2,0],[1,3]] and B = [[4,−1],[2,5]], entry (2,2) of AB is:

Row 2 of A is (1,3), column 2 of B is (−1,5): (1)(−1) + (3)(5) = −1 + 15 = 14.
