Sequences, Arithmetic Sequences, and Geometric Sequences

Systems are behind you. A sequence is just a function whose inputs are 1, 2, 3, … — and two special kinds of sequence turn out to be everywhere.

← Lesson 37 Lesson 39 → Contents Glossary →

1. Sequences and their notation

Definition — Sequence A sequence is a function whose domain is the counting numbers (1, 2, 3, …) instead of all real numbers. Each output is called a term, written a₁, a₂, a₃, …. An explicit formula gives aₙ directly from n, so any term can be found without computing the ones before it. A recursive formula instead defines aₙ using earlier terms — and must state the starting term(s) explicitly, since there's nothing earlier to build the first term from.

2. Arithmetic sequences

Definition — Arithmetic Sequence An arithmetic sequence has a constant difference between consecutive terms, called the common difference d. Its explicit formula is aₙ = a₁ + (n − 1)d — add d exactly (n − 1) times to the first term to reach the nth.
Worked Example a₁ = 5, d = 4: the sequence runs 5, 9, 13, 17, 21, …. The explicit formula aₙ = 5 + 4(n − 1) gives the 10th term directly: a₁₀ = 5 + 4(9) = 41, with no need to list the nine terms before it.

3. Geometric sequences

Definition — Geometric Sequence A geometric sequence has a constant ratio between consecutive terms, called the common ratio r — found by dividing any term by the one before it. Its explicit formula is aₙ = a₁ · r(n−1). A geometric sequence is really an exponential function restricted to positive-integer inputs — though unlike an exponential function's base, r is allowed to be negative.
Worked Example a₁ = 3, r = 2: the sequence runs 3, 6, 12, 24, 48, …, doubling each time. The explicit formula aₙ = 3 · 2(n−1) gives a₇ = 3 · 2⁶ = 3 · 64 = 192 directly.

1. A sequence is a function whose domain is:

A sequence assigns a term to each positive integer 1, 2, 3, … — that restricted domain is exactly what separates a sequence from an ordinary function.

2. In a geometric sequence, dividing any term by the one before it gives the common ___.

A geometric sequence changes by a constant multiplicative factor rather than a constant additive amount — that factor is the common ratio, found by dividing consecutive terms.

3. For the arithmetic sequence with a₁ = 5, d = 4, the 10th term is:

a₁₀ = a₁ + (10−1)d = 5 + 9(4) = 5 + 36 = 41.
