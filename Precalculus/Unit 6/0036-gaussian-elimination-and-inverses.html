Solving Systems with Gaussian Elimination and Inverses

Lessons 32–33's elimination, repackaged as row operations on a matrix — plus a second route that solves the whole system in one multiplication.

← Lesson 35 Lesson 37 → Contents Glossary →

1. Augmented matrices

Definition — Augmented Matrix Strip a system's variables away and keep only its coefficients and constants, separated by a vertical bar in place of the equals signs. x + 2y = 5 and 3x − y = 1 becomes [ 1 2 | 5 ; 3 −1 | 1 ] — the same information, arranged for row operations instead of algebra on variables.

2. Gaussian elimination

Method — Row Operations Three moves are allowed, each preserving the system's solution: multiply a row by a nonzero constant, add one row to another, or swap two rows. The goal is row-echelon form — 1's down the main diagonal, 0's below it — after which back-substitution (Lessons 32–33) finishes the job. A row that reduces to all zeros signals infinitely many solutions; a row that reduces to "0 = nonzero" signals no solution at all.

3. Matrix inverses

Definition — Invertible Matrix The identity matrix I has 1's on the main diagonal and 0's elsewhere — the matrix equivalent of the number 1. A square matrix A is invertible if some A⁻¹ exists with AA⁻¹ = I. Only square matrices can be invertible, and not every square matrix is. For a 2×2 matrix [[a, b], [c, d]], A⁻¹ = (1 / (ad − bc)) · [[d, −b], [−c, a]] — undefined exactly when ad − bc = 0.
Method — Solving with an Inverse Write the system as AX = B, where A is the coefficient matrix, X holds the variables, and B holds the constants. Multiplying both sides by A⁻¹ on the left gives X = A⁻¹B — the entire solution in one matrix multiplication, provided A is invertible.
Worked Example — Both Methods, Same System x + 2y = 5, 3x − y = 1. Elimination: R2 − 3R1 turns [3, −1 | 1] into [0, −7 | −14], so y = 2, and back-substituting gives x = 1. Inverse: A = [[1,2],[3,−1]], det = (1)(−1) − (2)(3) = −7, so A⁻¹ = (1/−7)[[−1,−2],[−3,1]] = [[1/7, 2/7],[3/7, −1/7]]. Then X = A⁻¹B gives x = (5/7)+(2/7) = 1 and y = (15/7)−(1/7) = 2. Both routes land on (1, 2).

Check your recall

1. The goal of Gaussian elimination's row operations is to reach:

Row-echelon form — 1's on the diagonal, 0's below — sets the matrix up for straightforward back-substitution, the same final step used in Lessons 32–33.

2. Only a ___ matrix can possibly have a multiplicative inverse.

Invertibility requires AA⁻¹ = A⁻¹A = I, which forces A to have the same number of rows as columns — a non-square matrix can't satisfy this in both directions.

3. For A = [[1,2],[3,−1]], the determinant ad − bc equals:

ad − bc = (1)(−1) − (2)(3) = −1 − 6 = −7, matching the worked example's inverse computation.
