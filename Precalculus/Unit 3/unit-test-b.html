1. Which of these does NOT satisfy the definition of an exponential function f(x) = a·bˣ (a ≠ 0, b > 0, b ≠ 1)?

f(x) = 6·1ˣ has base b = 1, which is explicitly excluded — 1ˣ is always 1, so this collapses to a constant function, not a genuine exponential one.

2. f(x) = 800·(0.75)ˣ models the value of a car, in dollars, after x years. As x increases, f(x):

The base 0.75 is between 0 and 1, so this is decay — the value shrinks toward the horizontal asymptote of $0 as years pass, not toward some other fixed floor.

3. For h(x) = log(x + 4), answer both parts:

(a) What is the domain?

(b) Fill in the blank: the graph has a vertical asymptote at x = ___.

(a) The argument x + 4 must be positive, so x > −4 — the domain shifts left by 4 compared to plain log(x). (b) The excluded boundary value x = −4 is exactly where the vertical asymptote sits, since the graph plunges toward −∞ as x → −4⁺.

4. For log₅(x/25), answer both parts:

(a) log₅(x/25) is equivalent to:

(b) Fill in the blank: using that rewritten form, log₅(x/25) at x = 125 equals ___.

(a) The Quotient Rule turns log₅(x/25) into log₅(x) − log₅(25), and log₅(25) = 2 since 5² = 25. (b) At x = 125, the rewritten form gives log₅(125) − 2 = 3 − 2 = 1 — matching log₅(125/25) = log₅(5) = 1 directly.

5. Fill in the blank: using the change-of-base formula, log₇(20) = ln(20) / ln(___).

The change-of-base formula puts the original base in the denominator: log_b(M) = ln(M)/ln(b), so here that's 7.

6. For 3ˣ = 40, answer both parts:

(a) Solve for x:

(b) Fill in the blank: x ≈ ___ (nearest hundredth).

(a) Taking ln of both sides gives x·ln(3) = ln(40), so x = ln(40)/ln(3) — the target's log divided by the base's log. (b) ln(40) ≈ 3.689 and ln(3) ≈ 1.099, so x ≈ 3.689/1.099 ≈ 3.36.

7. Solve log₃(x) + 2 = 5 for x: x = ___.

Isolating gives log₃(x) = 3, and converting to exponential form gives x = 3³ = 27.

8. For the radioactive sample A(t) = 300e−0.03t (t in years), answer both parts:

(a) This model describes:

(b) Fill in the blank: the sample's half-life is ln(2)/0.03 ≈ ___ years (nearest tenth).

(a) k = −0.03 is negative, so this is continuous decay at a rate of 3% per year — the actual half-life would need the separate calculation ln(2)/|k|, not just k itself. (b) That separate calculation gives ln(2)/0.03 ≈ 0.6931/0.03 ≈ 23.1 years.

9. An investment grows continuously with k = 0.04 per year. Its doubling time is ln(2)/0.04 ≈ ___ years (nearest whole number).

Doubling time = ln(2)/k = 0.6931/0.04 ≈ 17.3, which rounds to 17 years.

10. Answer both parts about the number e:

(a) Which of these expressions has a value that approaches e as n increases without bound?

(b) Fill in the blank: rounded to two decimal places, e ≈ ___.

(a) e is defined as the limit of (1 + 1/n)ⁿ as n → ∞ — the other expressions approach 1, 0, or don't converge to e at all. (b) That limit's value is e ≈ 2.71828, which rounds to 2.72.
