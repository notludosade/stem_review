1. Which of the following is a genuine exponential function of the form f(x) = a·bˣ (a ≠ 0, b > 0, b ≠ 1)?

f(x) = 3·(0.5)ˣ has a nonzero initial value and a positive base other than 1. Each distractor fails one restriction: b = 1 collapses to a constant, a = 0 gives the zero function, and a negative base isn't allowed.

2. For f(x) = a·bˣ with a > 0 and b > 1, as x increases without bound, f(x):

A base greater than 1 makes bˣ grow larger every time x increases — with a positive initial value, the whole function grows without bound as x grows.

3. For g(x) = log₅(x − 2), answer both parts:

(a) What is the domain?

(b) Fill in the blank: the graph has a vertical asymptote at x = ___.

(a) A logarithm needs a positive argument, so x − 2 > 0 gives x > 2 — the whole domain shifts right by 2 compared to plain log₅(x). (b) The excluded boundary value x = 2 is exactly where the vertical asymptote sits, since the graph plunges toward −∞ as x → 2⁺.

4. For log₃(9x), answer both parts:

(a) log₃(9x) is equivalent to:

(b) Fill in the blank: using that rewritten form, log₃(9x) at x = 3 equals ___.

(a) The Product Rule turns log₃(9x) into log₃(9) + log₃(x), and log₃(9) = 2 since 3² = 9. (b) At x = 3, the rewritten form gives 2 + log₃(3) = 2 + 1 = 3 — matching log₃(27) = 3 directly, since 3³ = 27.

5. Fill in the blank: log₂(x⁵) = ___ · log₂(x).

The Power Rule brings the exponent down as a multiplying coefficient: log_b(Mⁿ) = n·log_b(M), so here n = 5.

6. For 4ˣ = 50, answer both parts:

(a) Solve for x:

(b) Fill in the blank: x ≈ ___ (nearest hundredth).

(a) Taking ln of both sides and applying the Power Rule gives x·ln(4) = ln(50), so x = ln(50)/ln(4) — the target's log divided by the base's log, not the other way around. (b) ln(50) ≈ 3.912 and ln(4) ≈ 1.386, so x ≈ 3.912/1.386 ≈ 2.82.

7. Solve log₂(x) − 3 = 1 for x: x = ___.

Isolating gives log₂(x) = 4, and converting to exponential form gives x = 2⁴ = 16.

8. For the bacteria population P(t) = 500e0.08t (t in hours), answer both parts:

(a) This model describes:

(b) Fill in the blank: the population's doubling time is ln(2)/0.08 ≈ ___ hours (nearest tenth).

(a) In A(t) = A₀ekt, the constant k is read directly as the continuous rate — here k = 0.08 > 0, so it's growth at 8% per hour, not a doubling time (which would require computing ln(2)/k separately). (b) That separate calculation gives ln(2)/0.08 ≈ 0.6931/0.08 ≈ 8.66, which rounds to 8.7 hours.

9. A radioactive isotope has decay constant k = −0.02 per year. Its half-life is ln(2)/0.02 ≈ ___ years (nearest whole number).

Half-life = ln(2)/|k| = 0.6931/0.02 ≈ 34.7, which rounds to 35 years.

10. A bank compounds $1 at 100% annual interest continuously (n → ∞). Answer both parts:

(a) After one year, the balance approaches:

(b) Fill in the blank: after two years, the balance approaches e² ≈ $___ (nearest cent).

(a) Continuous compounding is exactly the limit (1 + 1/n)ⁿ as n → ∞, which is the definition of e ≈ 2.71828 — not 2, not 1, and not unbounded. (b) With continuous compounding, the balance after t years is eᵗ, so after two years it's e² ≈ 7.389, which rounds to $7.39.
