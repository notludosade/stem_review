Exponential Functions and Their Graphs

A function family where the input sits in the exponent, not the base — and where growth feeds on itself.

← Lesson 13 Lesson 15 → Contents Glossary →

Every function family so far — polynomial, rational — has had x in the base and a fixed number in the exponent (x², x³, x⁻¹). An exponential function flips that arrangement: the variable is the exponent, and the base stays fixed. That single swap produces completely different behavior.

1. The exponential function, defined

Definition An exponential function has the form f(x) = a·bˣ, where a ≠ 0 is the initial value (f(0) = a) and b > 0, b ≠ 1 is the base (also called the growth or decay factor).

The restriction b ≠ 1 isn't arbitrary: 1ˣ = 1 for every x, which is just a constant function, not a genuine exponential one. And b must stay positive, or fractional exponents like b^(1/2) would produce complex numbers for some inputs.

2. Growth, decay, and the asymptote

Rules For f(x) = a·bˣ with a > 0: if b > 1, f models growth — it increases, faster and faster, as x increases. If 0 < b < 1, f models decay — it decreases toward 0 as x increases. Either way, the domain is all real numbers, the range is all positive reals (if a > 0) or all negative reals (if a < 0), the y-intercept is (0, a), and y = 0 is always a horizontal asymptote.

Notice what never changes across every case in the widget above: the curve never touches the x-axis, no matter how flat or steep it gets. An exponential function's output can shrink toward zero, but reaching it exactly would require bˣ = 0 for some real x — which never happens, since a positive base raised to any real power stays positive.

Check your recall

1. In f(x) = a·bˣ, which restriction applies to b?

b must be positive so that bˣ is defined (and real) for every real x, and b ≠ 1 is required because 1ˣ collapses to the constant function 1, not a genuine exponential.

2. For f(x) = a·bˣ with a > 0 and 0 < b < 1, the function:

A base strictly between 0 and 1 shrinks every time x increases by 1, so the function decays toward its horizontal asymptote as x grows — the opposite behavior from a base greater than 1.

3. For any exponential function f(x) = a·bˣ, the horizontal asymptote is y = ___.

Since a positive base raised to any real power is always positive, a·bˣ can shrink arbitrarily close to 0 but never reach or cross it — y = 0 is the asymptote regardless of a or b.
