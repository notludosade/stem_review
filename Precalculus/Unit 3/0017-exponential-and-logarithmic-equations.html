Exponential and Logarithmic Equations

The whole reason logs exist: pulling a variable down out of an exponent, so ordinary algebra can reach it.

← Lesson 16 Lesson 18 → Contents Glossary →

An equation like 5ˣ = 30 can't be solved with the algebra from earlier units — x is stuck in the exponent, out of reach of addition or division. Taking a logarithm of both sides is precisely the move that brings it back down.

1. Solving exponential equations

Method To solve bx = N: take log (or ln) of both sides, then apply the Power Rule from Lesson 16 to bring the exponent down: x·ln(b) = ln(N), so x = ln(N) / ln(b).

(If both sides already share the same base — like 3⁴ˣ⁻⁷ = 3²ˣ⁻¹ — the one-to-one property lets you skip logs entirely and just set the exponents equal: 4x − 7 = 2x − 1. That shortcut only works when a common base is available; the log method below always works.)

Worked Example Solve 5ˣ = 30: take ln of both sides → ln(5ˣ) = ln(30) → x·ln(5) = ln(30) → x = ln(30) / ln(5) ≈ 2.113.

2. Solving logarithmic equations

Method To solve an equation with a single log expression, isolate it, then convert to exponential form using the definition: logb(S) = c means bᶜ = S.
Worked Example Solve 2ln(x) + 3 = 7: subtract 3 and divide by 2 → ln(x) = 2 → convert to exponential form → x = e² ≈ 7.389.

3. The extraneous-solution trap

Logarithms are only defined for positive arguments — so squaring, cross-multiplying, or combining logs during solving can manufacture a solution that satisfies the simplified equation but not the original one. Every candidate answer has to be checked against the original equation's domain.

Worked Example Solve log(x) + log(x − 3) = 1: combine via the Product Rule → log(x(x − 3)) = 1 → x(x − 3) = 10 → x² − 3x − 10 = 0 → (x − 5)(x + 2) = 0 → x = 5 or x = −2.

Taking a log of both sides to free a variable from an exponent is a move that resurfaces constantly in Calculus — implicit differentiation and certain integrals lean on exactly this trick. It's worth being fully comfortable with the mechanics now, not just the answer.
