Properties of Logarithms

Every exponent rule, translated: multiplication becomes addition, division becomes subtraction, powers become multiplication.

← Lesson 15 Lesson 17 → Contents Glossary →

Because logb(x) is defined by "the exponent that gives x," every rule for combining exponents has a matching rule for combining logs. The exponent rule bᵐ·bⁿ = bᵐ⁺ⁿ turns multiplication into addition — so it should be no surprise that the matching log rule does too.

1. The Product Rule for Logarithms

Rule logb(MN) = logb(M) + logb(N), for M, N > 0.

3. The Change-of-Base Formula

Rule logb(M) = ln(M) / ln(b) (or, using common logs, log(M) / log(b)). This is what makes a calculator's LOG and LN buttons enough to compute a logarithm in any base.
Worked Example To compute log5(12) on a calculator that only has LN: log5(12) = ln(12) / ln(5) ≈ 2.4849 / 1.6094 ≈ 1.5440.

1. logb(MN) equals:

Multiplying inside the log turns into adding outside the log — the Product Rule, matching the exponent rule bᵐ·bⁿ = bᵐ⁺ⁿ.

2. logb(Mⁿ) equals:

An exponent inside the log becomes a multiplying coefficient outside the log — the Power Rule. This is the single most useful rule for solving equations where the variable sits in an exponent.

3. Change-of-base formula: logb(M) = ln(M) / ln(___).

The new base (whatever's convenient — usually e or 10) goes in the denominator, with the original base b as its argument.

OpenStax Precalculus 2e, §4.5 "Logarithmic Properties" proves all four rules above from the exponent rules and the definition of a logarithm. Paul's Online Math Notes on Logarithm Properties covers the same rules with additional worked examples.

These three rules are the actual working tools of logarithms — Lesson 17 uses the Power Rule specifically to solve equations where x sits in an exponent, which is most of what logarithms are for in practice. If the Product/Quotient/Power split ever gets fuzzy, it's worth re-deriving each one from the matching exponent rule rather than memorizing them as three unrelated facts.
