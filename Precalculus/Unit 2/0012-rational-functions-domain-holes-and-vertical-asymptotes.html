Rational Functions I: Domain, Holes & Vertical Asymptotes

A whole new function family — one whose most interesting behavior happens at the values it can't take.

← Lesson 11 Lesson 13 → Contents Glossary →

Every function so far this unit has been a polynomial — defined everywhere, with no gaps. A rational function is a ratio of two polynomials, p(x) / q(x), and the moment a polynomial shows up in a denominator, some x-values stop being allowed. Where those excluded values are, and what the graph actually does there, is this lesson's whole subject.

1. Domain: start by ruling values out

Definition A rational function has the form f(x) = p(x) / q(x), where p and q are polynomials and q is not the zero polynomial. Its domain is every real number except the zeros of q(x) — division by zero is simply not defined.

Take the simplest possible case, g(x) = 1 / (x − 1). The denominator is zero only at x = 1, so that's the one value excluded from the domain. Drag along the graph below and watch what happens as x closes in on 1 from either side.

Try It — Approaching an Excluded Value

—

The dashed line marks x = 1 — not part of the graph, just a boundary the curve never crosses. On either side, g(x) shoots off toward ±∞.

Rule Vertical asymptote: if q(a) = 0 and the numerator p(a) ≠ 0, the line x = a is a vertical asymptote — the graph grows without bound as x approaches a from at least one side, and a is excluded from the domain with no way to patch it.

2. A shared zero changes everything

Every excluded value comes from a zero of the denominator — but not every one behaves like the asymptote above. Watch what happens when the numerator happens to share that same zero.

Take f(x) = (x + 3)(x − 2) / [(x − 2)(x + 1)]. The denominator is zero at both x = 2 and x = −1 — two candidates for excluded values. But the factor (x − 2) appears in the numerator too, and it cancels: for every x ≠ 2, f(x) = (x + 3) / (x + 1) exactly. The (x + 1) factor has no such partner to cancel against.

Try It — Same Zero Denominator, Two Different Outcomes

—

x = −1 (no cancellation): a true vertical asymptote. x = 2 (cancels): the graph looks completely continuous through there — except for a single missing point, the hole.

Rule Hole (removable discontinuity): if a factor (x − a) divides out of both the numerator and denominator, the graph is undefined at x = a but does not blow up there — it behaves exactly like the simplified function everywhere else, with one point removed. Marked on a graph as an open circle. Always cancel common factors first to tell holes and asymptotes apart before graphing.
