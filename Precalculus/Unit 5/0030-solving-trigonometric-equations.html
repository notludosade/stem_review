Solving Trigonometric Equations

Every identity from this unit was a tool for rewriting. This lesson is where the rewriting finally pays off — turning a messy trig equation into one an inverse function can finish off.

← Lesson 29 Lesson 31 → Contents Glossary →

A trigonometric equation asks: for which x is this true? Because sine and cosine repeat every 2π, a single answer is almost never the whole answer — a trig equation with any solution at all has infinitely many, spaced one period apart.

1. The basic strategy

Method — Solving sinx = c or cosx = c Use the inverse function to find one solution in the function's restricted range, then use symmetry to find the others inside one period, then add 2πk (k any integer) to sweep out every remaining period. For sinx = 1/2: sin⁻¹(1/2) = π/6 gives one solution; π − π/6 = 5π/6 gives the other (sine is positive in both Quadrant I and II); the complete solution is x = π/6 + 2πk or x = 5π/6 + 2πk.
Method — Equations quadratic in form An equation like 2sin²x − sinx − 1 = 0 is just a quadratic wearing a disguise. Substitute u = sinx, factor (2u + 1)(u − 1) = 0 as ordinary algebra, solve for u, then solve sinx = u for x using the basic strategy above. Any equation containing only one trig function, at only one angle, can be attacked this way.
Method — Reducing to one function first An equation mixing sin²x and cosx, for instance, isn't quadratic in form until an identity fixes that. Substituting the Pythagorean identity sin²x = 1 − cos²x turns it into an equation in cosx alone — then the substitution method above applies. Every identity from Lessons 26–29 exists partly for exactly this purpose.

The equation contains only sinx (and its square), all at the same angle x — substituting u for exactly that function turns it into an ordinary quadratic in u. Any other substitution leaves sinx and the new variable mixed together.

2. Because sine has period 2π, the complete solution to sinx = c adds ___ to each base angle (k any integer).

One period of sine is 2π wide, so every solution repeats every 2π — the complete family is base angle + 2πk, not just the one or two solutions inside a single period.
