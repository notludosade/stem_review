1. Starting from sin²x + cos²x = 1, answer both parts:

(a) Dividing through by cos²x produces which identity?

(b) Dividing through by sin²x instead produces which identity?

(a) Dividing sin²x + cos²x = 1 through by cos²x gives tan²x + 1 = sec²x. (b) Dividing by sin²x instead gives 1 + cot²x = csc²x — the sibling identity to part (a).

2. Fill in the blank: Because cosine is an even function, cos(−x) = ___.

An even function satisfies f(−x) = f(x). Cosine's graph is symmetric about the y-axis, so cos(−x) = cos x — no sign flip, unlike sine or tangent.

3. Using cos(α − β) = cosα cosβ + sinα sinβ, what is cos(15°) if 15° = 45° − 30°?

cos(45° − 30°) = cos45°cos30° + sin45°sin30° = (√2/2)(√3/2) + (√2/2)(1/2) = √6/4 + √2/4 = (√6 + √2)/4, using the difference formula's plus sign.

4. If tanα = 1 and tanβ = 2, answer both parts:

(a) What is tan(α + β)?

(b) What is tan(α − β)?

(a) tan(α + β) = (tanα + tanβ)/(1 − tanαtanβ) = (1 + 2)/(1 − 1·2) = 3/(−1) = −3. (b) tan(α − β) = (tanα − tanβ)/(1 + tanαtanβ) = (1 − 2)/(1 + 1·2) = −1/3.

5. Which of the three equivalent forms of cos 2θ is most useful when you want an equation purely in cosθ, with no sinθ at all?

2cos²θ − 1 is written entirely in terms of cosθ, so it lets you solve for cosθ directly without also needing sinθ. The last option isn't a valid form of cos 2θ at all.

6. Answer both parts about the half-angle formulas:

(a) Fill in the blank: cos(θ/2) = ±√((1 + cosθ) / ___).

(b) Which of these is the correct half-angle formula for sin(θ/2)?

(a) Replacing θ with θ/2 in the reduction formula cos²θ = (1 + cos2θ)/2 and taking a square root gives cos(θ/2) = ±√((1 + cosθ)/2). (b) The parallel reduction formula sin²θ = (1 − cos2θ)/2 leads to sin(θ/2) = ±√((1 − cosθ)/2) — same denominator, but a minus sign inside instead of a plus.

7. Express sin75° sin15° as a sum, then evaluate it.

sinα sinβ = ½[cos(α−β) − cos(α+β)]. With α = 75°, β = 15°: ½[cos60° − cos90°] = ½[½ − 0] = 1/4.

8. Answer both parts about the sum-to-product formulas:

(a) Which formula correctly expresses sinα − sinβ as a product?

(b) Which formula correctly expresses sinα + sinβ as a product?

(a) sinα − sinβ pairs a cosine of the half-sum with a sine of the half-difference. (b) sinα + sinβ swaps which half gets which function: a sine of the half-sum with a cosine of the half-difference. Mixing up the two, or adding a stray minus sign, names one of the other sum-to-product formulas instead.

9. Fill in the blank: To turn sin²x + cosx = 1 into an equation in a single function, replace sin²x using the ___ identity, leaving an equation in cosx alone.

Substituting sin²x = 1 − cos²x (the Pythagorean identity) removes sine entirely, leaving −cos²x + cosx = 0 — a quadratic-form equation in cosx alone, solvable with the usual substitution method.

10. Answer both parts about choosing a sinusoidal model:

(a) A cosine model is preferred over a sine model for a set of periodic data when:

(b) A sine model requires no phase shift when the data's starting value is:

(a) A cosine model begins a cycle at a maximum or minimum. (b) A sine model begins a cycle at the midline. Matching whichever fits the data's actual starting point removes the need for a phase shift.
