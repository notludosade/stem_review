Significant Figures — Precision vs. Accuracy

A measurement with ten decimal places isn't more correct — it might just be dishonest about how well you actually know it.

← Lesson 4 Lesson 6 → Contents Glossary →

Calculators happily produce ten digits after a decimal point. Real measurements are never that certain. This lesson is about reporting a number at the precision it actually deserves — no more, no less.

Precision vs. accuracy — two different things

Definition Accuracy is how close a measurement is to the true value. Precision is how consistent repeated measurements are with each other — and separately, how many meaningful digits a single measurement reports.
Example A scale that reads 152.3 g, 152.4 g, and 152.2 g on three tries of the same object is precise (tightly clustered) — but if the object actually weighs 140 g, it's not accurate. A scale could also be accurate on average while being wildly imprecise, swinging from 130 g to 150 g around a true value of 140 g.

A measuring tool can be precise without being accurate, accurate without being precise, both, or neither. They're independent properties, and confusing them is a common mistake — a long decimal expansion looks precise, but says nothing about whether it's accurate.

Significant figures: how many digits actually mean something

Definition Significant figures are the digits in a measurement that carry real meaning — every reliably known digit, plus one estimated digit at the end. Reporting more digits than that overstates how well the quantity is actually known.
Example A ruler marked in millimeters lets you reliably read whole millimeters, plus one estimated digit beyond that — so a length might honestly be reported as 24.3 mm (3 significant figures), not 24.3827 mm. The extra digits imply a precision the ruler simply cannot deliver.

Rules for counting significant figures

1. Nonzero digits Always significant. 342 has 3 significant figures.
2. Zeros between nonzero digits Always significant. 4008 has 4 significant figures.
3. Leading zeros Never significant — they only locate the decimal point. 0.0042 has 2 significant figures.
4. Trailing zeros after a decimal point Always significant. 4.200 has 4 significant figures — the zeros signal the measurement was known that precisely.

Rules for calculating with significant figures

A calculation can never produce a result more precise than its least-precise input — the whole point of the rule is to stop a calculator's extra decimal places from implying false precision.

Multiplication and division The result gets the same number of significant figures as the input with the fewest. 4.2 (2 sig figs) × 3.14159 (6 sig figs) = 13.19... on a calculator, but should be reported as 13 (2 sig figs).
Addition and subtraction The result gets the same number of decimal places as the input with the fewest decimal places. 12.11 + 18.0 = 30.11 on a calculator, but should be reported as 30.1 (matching 18.0's one decimal place).
Why this matters in engineering Reporting a dimension as 4.28371 cm when it was actually measured to the nearest 0.1 cm doesn't just look sloppy — it can mislead a downstream engineer into believing a part is machined to a tolerance it was never actually held to, with real safety consequences in some contexts.

Check your recall

No peeking back up — answer from memory first, then check.

1. A scale gives three readings tightly clustered around 152 g for an object that actually weighs 140 g. This scale is:

Tightly clustered readings mean high precision — but if that cluster isn't near the true value, it isn't accurate.

2. How many significant figures does 0.0042 have?

Leading zeros only locate the decimal point and are never significant — only the 4 and 2 count.

3. When multiplying 4.2 by 3.14159, why should the result be reported as 13, not 13.19?

The multiplication rule caps the result's significant figures at whichever input has the fewest — here, 4.2's 2 significant figures.

4. Fill in the blank: how close a measurement is to the true value is called ___, which is a separate property from precision.

Accuracy measures closeness to the true value; precision measures consistency and reported digit count — the two are independent.

5. Fill in the blank: when adding or subtracting measurements, the result should be rounded to match the fewest number of ___ among the inputs, not the fewest significant figures.

Addition and subtraction use a decimal-place rule, distinct from multiplication and division's significant-figure rule.
