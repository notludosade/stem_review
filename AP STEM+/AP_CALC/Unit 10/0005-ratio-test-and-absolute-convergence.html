The Ratio Test and Absolute Convergence

Factorials and exponentials defeat comparison tests — there's no simple p-series to measure them against. The ratio test measures a series against itself instead.

← Lesson 4 Lesson 6 → Contents Glossary →

1. Comparing consecutive terms

Method — The Ratio Test Let L = limₙ→∞ |aₙ₊₁/aₙ|. If L < 1, Σaₙ converges absolutely. If L > 1 (or L = ∞), Σaₙ diverges. If L = 1, the test is inconclusive — a different test is needed. This test is the standard tool whenever factorials or exponentials appear, since consecutive-term ratios collapse n! and rⁿ into something a limit can actually handle.
Definition — Absolute vs. Conditional Convergence Σaₙ converges absolutely if Σ|aₙ| converges — a strictly stronger statement. Σaₙ converges conditionally if Σaₙ converges but Σ|aₙ| diverges. Absolute convergence always implies ordinary convergence, but not the reverse: the alternating harmonic series from Lesson 4 converges, yet Σ|(−1)ⁿ⁺¹/n| = Σ1/n diverges (the harmonic series) — so it converges only conditionally.
Worked Example Does Σ 2ⁿ/n! converge? Ratio: |aₙ₊₁/aₙ| = [2ⁿ⁺¹/(n+1)!] · [n!/2ⁿ] = 2/(n+1) → 0 as n → ∞. L = 0 < 1, so it converges absolutely — factorial growth in the denominator overwhelms exponential growth in the numerator, something no p-series comparison could show directly.

2. Two verdicts on the same series

Toggle between a series that converges absolutely and one that converges only conditionally — both pass, but for different reasons.
