The Divergence Test and Integral Test

Most series don't have a clean formula like the geometric series. These two tests trade the exact sum for a faster yes-or-no answer.

← Lesson 1 Lesson 3 → Contents Glossary →

1. A quick way to rule out convergence

Method — The nth Term (Divergence) Test If limₙ→∞ aₙ ≠ 0, or that limit doesn't exist, then Σaₙ diverges. This test can only prove divergence — if limₙ→∞ aₙ = 0, the test is inconclusive, and a different test is needed. Terms shrinking to 0 is necessary for convergence, but never sufficient on its own.
Method — The Integral Test If f is positive, continuous, and decreasing for x ≥ 1, and aₙ = f(n), then Σaₙ and ∫₁^∞ f(x) dx either both converge or both diverge. A series with awkward discrete terms is traded for an improper integral, which the Unit 6 toolkit already knows how to evaluate.
Worked Example — Where the Divergence Test Fails The harmonic series Σ 1/n has limₙ→∞ 1/n = 0 — the divergence test is inconclusive. But ∫₁^∞ (1/x) dx = limₜ→∞ [ln t − ln 1] = ∞, an improper integral that diverges. By the integral test, Σ 1/n diverges — proof that "terms shrink to 0" alone never guarantees convergence.

2. Two very different-looking series, side by side

Toggle between Σ(1/n) and Σ(1/n²). Both have terms shrinking to 0, but their partial sums behave completely differently.
