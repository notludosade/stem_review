The Alternating Series Error Bound

Knowing a series converges is one thing. Knowing exactly how far a partial sum can be from the true answer, without computing infinitely many terms, is another.

← Lesson 5 Lesson 7 → Contents Glossary →

1. The next term bounds the error

Method — Alternating Series Error Bound If Σ(−1)ⁿ⁺¹bₙ satisfies the alternating series test and converges to L, then the error after stopping at Sₙ is bounded by the very next term: |L − Sₙ| ≤ bₙ₊₁. No limit, no integral, no infinite tail to estimate — just look at the size of the first term left out.
Why This Works Each partial sum overshoots L in the opposite direction from the one before, by a strictly smaller amount each time (since bₙ is decreasing). That means L is always trapped between any two consecutive partial sums, Sₙ and Sₙ₊₁ — so the gap from Sₙ to L can never exceed the gap from Sₙ to Sₙ₊₁, which is exactly bₙ₊₁.
Worked Example Approximate Σ(−1)ⁿ⁺¹/n! (which converges to 1/e ≈ 0.3679) using S₄ = 1 − 1/2 + 1/6 − 1/24 = 0.625 − ... = 0.375. The error bound is b₅ = 1/5! = 1/120 ≈ 0.00833. Check: |0.3679 − 0.375| ≈ 0.0071, which is indeed ≤ 0.00833 — the bound holds, and it required computing only one extra term, not the true sum.

2. Watching the bound shrink with the true error

Advance n and compare the guaranteed error ceiling bₙ₊₁ against the actual gap between Sₙ and the known limit ln 2. The bound is never tight, but it's never wrong either.

Check your recall

1. For a convergent alternating series, |L − Sₙ| is bounded by:

The very next term left out of the partial sum is exactly the size of the largest possible overshoot — no term further down the tail can matter more, since the terms only keep shrinking.

2. For Σ(−1)ⁿ⁺¹/2ⁿ, stopping at S₃, the error bound is b₄ = ___

bₙ = 1/2ⁿ, so b₄ = 1/2⁴ = 1/16 = 0.0625 — the first term excluded from S₃ is the fourth term, and its size caps the error.

3. This error bound applies to:

The bound relies on the overshoot-and-undershoot pattern that alternating, decreasing terms produce — a series that converges by some other mechanism (like the ratio test) has no such guarantee from this bound.
