Taylor Polynomials and the Lagrange Error Bound

A polynomial that matches a function's value and every derivative at one point turns out to approximate the function everywhere nearby — and the approximation's error can be capped without knowing the true value at all.

← Lesson 6 Lesson 8 → Contents Glossary →

1. Building a polynomial from derivatives

Definition — Taylor Polynomial The degree-n Taylor polynomial of f centered at x = a is Pₙ(x) = f(a) + f'(a)(x−a) + f''(a)(x−a)²/2! + ... + f⁽ⁿ⁾(a)(x−a)ⁿ/n! — the unique degree-n polynomial that matches f's value and its first n derivatives at a. For f(x) = eˣ centered at a = 0, every derivative equals eˣ, so f⁽ᵏ⁾(0) = 1 for every k, giving Pₙ(x) = Σₖ₌₀ⁿ xᵏ/k!.
Method — The Lagrange Error Bound The remainder Rₙ(x) = f(x) − Pₙ(x) satisfies |Rₙ(x)| ≤ M/(n+1)! · |x−a|ⁿ⁺¹, where M is any upper bound for |f⁽ⁿ⁺¹⁾(c)| on the interval between a and x. This caps the approximation's error without ever computing f(x) exactly — larger n or a smaller distance |x−a| both shrink the bound.
Worked Example Approximate e^0.5 with P₄(x) centered at 0: P₄(0.5) = 1 + 0.5 + 0.5²/2! + 0.5³/3! + 0.5⁴/4! = 1.648438. True value e^0.5 ≈ 1.648721, actual error ≈ 0.000284. Lagrange bound: since f⁽⁵⁾(c) = eᶜ is largest at c = 0.5 on [0, 0.5], take M = e^0.5 ≈ 1.6487: bound = 1.6487/5! · 0.5⁵ ≈ 0.000429. The actual error (0.000284) falls comfortably under the bound (0.000429), exactly as guaranteed.

1. Pₙ(x), the degree-n Taylor polynomial at x = a, matches f at a in:

A degree-n polynomial has exactly n+1 coefficients to spend, which is enough to match f(a) plus n derivatives — matching every derivative would require infinitely many terms, which is exactly what a full Taylor series (Lesson 9) does.

2. For f(x) = eˣ at a = 0, the x³ coefficient of Pₙ(x) (n ≥ 3) is 1/3! = ___

Since every derivative of eˣ at 0 equals 1, each coefficient is simply 1/k! — for k = 3, that's 1/6 ≈ 0.1667.

3. Increasing n in the Lagrange error bound M/(n+1)! · |x−a|ⁿ⁺¹ typically:

The factorial in the denominator eventually dominates any fixed base raised to a growing power, so for a fixed x the bound shrinks toward 0 as n grows — the same factorial-beats-exponential idea from the ratio test in Lesson 5.
