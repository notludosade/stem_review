1. Σ (from n=0 to ∞) 9·(2/3)ⁿ:

a = 9, r = 2/3, and |r| < 1, so the series converges to a/(1−r) = 9/(1/3) = 27.

2. Fill in the blank: Σ (from n=0 to ∞) 8·(1.1)ⁿ ___, since |r| = 1.1 ≥ 1

A geometric series converges only when |r| < 1. Here r = 1.1, so |r| ≥ 1 means the series diverges outright — the formula a/(1−r) doesn't apply.

3. For Σ (from n=1 to ∞) 1/(n+3), answer both parts:

(a) Since limₙ→∞ 1/(n+3) = 0, the divergence test:

(b) Fill in the blank: By the integral test, since ∫₁^∞ 1/(x+3) dx diverges, Σ 1/(n+3) ___

(a) A limit of 0 rules nothing out — the divergence test only detects a nonzero (or nonexistent) limit as proof of divergence. (b) ∫₁^∞ 1/(x+3) dx = limₜ→∞ [ln(t+3) − ln 4] = ∞, an improper integral that diverges, so by the integral test the series diverges too.

4. For Σ (from n=1 to ∞) 1/(n³ + 2), answer both parts:

(a) Fill in the blank: Since 0 < 1/(n³+2) < 1/n³ for all n ≥ 1, and Σ1/n³ converges (p = 3 > 1), direct comparison shows this series ___

(b) Using bₙ = 1/n³, limₙ→∞ (aₙ/bₙ) equals:

(a) A series squeezed underneath a known convergent series is itself squeezed into converging. (b) limₙ→∞ [1/(n³+2)]/[1/n³] = limₙ→∞ n³/(n³+2) = 1, a finite positive constant, so limit comparison agrees with the direct comparison result.

5. Σ(−1)ⁿ⁺¹ · 2n/(n+3) has bₙ = 2n/(n+3), and limₙ→∞ bₙ = 2 ≠ 0. This series:

Terms not shrinking to 0 dooms any series, alternating or not — the nth term (divergence) test applies directly and proves divergence, without ever needing the alternating series test.

6. For Σ (from n=1 to ∞) 4ⁿ/n!, the ratio |aₙ₊₁/aₙ| = 4/(n+1). Answer both parts:

(a) Fill in the blank: L = limₙ→∞ 4/(n+1) = ___

(b) Since L = 0 < 1, this series:

(a) As n → ∞, 4/(n+1) → 0. (b) L = 0 < 1 is the strongest possible ratio-test outcome, proving absolute convergence directly — factorial growth in the denominator overwhelms exponential growth in the numerator.

7. Fill in the blank: For Σ(−1)ⁿ⁺¹/4ⁿ, stopping at S₃, the error bound is b₄ = ___

bₙ = 1/4ⁿ, so b₄ = 1/4⁴ = 1/256 ≈ 0.0039 — the first term excluded from S₃ caps the error.

(b) Fill in the blank: Using M = e^0.4 ≈ 1.49182 on [0, 0.4], the Lagrange error bound for P₃(0.4) is M/4!·(0.4)⁴ ≈ ___

9. For Σ (from n=0 to ∞) (2x)ⁿ, the ratio test gives limₙ→∞ |2x| = |2x|. The radius of convergence is:

The series converges when |2x| < 1, i.e. |x| < 1/2, so R = 1/2 — the endpoints x = ±1/2 would still need to be checked separately with a different test.

10. Starting from the Maclaurin series for f(x) = 1/(1−x), answer both parts:

(a) The Maclaurin series (Taylor series centered at x = 0) for f(x) = 1/(1−x) is:

(b) Fill in the blank: Substituting x/2 for x in that series gives a Maclaurin series for ___

(a) "Maclaurin" simply names the special case a = 0 of a Taylor series, and 1/(1−x) = Σxⁿ for |x| < 1. (b) Replacing every x with x/2 gives 1/(1−x/2) = Σ(x/2)ⁿ, which simplifies to 2/(2−x).
