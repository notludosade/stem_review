1. The statement limx→3 f(x) = 7 tells you that as x gets arbitrarily close to 3 (from either side, without ever equaling 3), f(x) gets arbitrarily close to 7. This description:

A limit is about behavior near c, not the value at c — f(3) could be undefined, could equal 7, or could equal something else entirely; the limit statement itself doesn't decide that.

2. Let h(x) = 2x − 1 for x < 2, and h(x) = x + 3 for x ≥ 2. Answer both parts about the behavior at x = 2:

(a) What is limx→2⁻ h(x)?

(b) Fill in the blank: Since limx→2⁻ h(x) = 3 and limx→2⁺ h(x) = 5 disagree, limx→2 h(x) = ___.

(a) For x < 2, h(x) = 2x − 1, so as x → 2⁻, h(x) → 2(2) − 1 = 3. (b) The right-hand limit is 2 + 3 = 5 ≠ 3, so the two-sided limit does not exist (DNE).

3. limx→2 (3x² − 5x + 1) equals:

Since 3x² − 5x + 1 is a polynomial, it's continuous everywhere, so the limit laws let you substitute x = 2 directly: 3(4) − 5(2) + 1 = 12 − 10 + 1 = 3. No factoring, table, or Squeeze Theorem is needed here.

4. A function g(x) satisfies −x² ≤ g(x) ≤ x² for all x near 0. By the Squeeze Theorem, limx→0 g(x):

Since both bounding functions −x² and x² approach 0 as x → 0, the Squeeze Theorem forces g's limit to also equal 0, regardless of how g behaves in between.

5. Answer both parts about evaluating limits algebraically:

(a) limx→5 (x² − 25)/(x − 5) equals:

(b) Fill in the blank: Rationalizing the numerator, limx→0 (√(x + 9) − 3)/x = ___ (as a fraction).

(a) Factoring gives (x − 5)(x + 5)/(x − 5) = x + 5 for x ≠ 5, and substituting x = 5 gives 5 + 5 = 10. (b) Multiplying by the conjugate √(x + 9) + 3 turns the numerator into (x + 9) − 9 = x, which cancels the x in the denominator, leaving 1/(√(x + 9) + 3); substituting x = 0 gives 1/(3 + 3) = 1/6.

6. Let f(x) = x² + 1 for x ≠ 3, and f(3) = 8. Answer both parts:

(a) Which continuity condition fails for f at x = 3?

(b) Fill in the blank: To repair this discontinuity, f(3) should be redefined to equal ___.

limx→3 f(x) = 3² + 1 = 10 and f(3) = 8 — both exist individually, but they disagree, so exactly the third continuity condition fails. Redefining f(3) = 10 would make it match the limit, removing the (removable) discontinuity entirely.

7. A function r(x) has a vertical asymptote at x = 5, where r(x) grows without bound on both sides. What type of discontinuity does r have at x = 5?

Growing without bound near a point is exactly the signature of an infinite discontinuity — and unlike a removable discontinuity, there's no single value you could assign at x = 5 to fix it.

8. Let g(x) = 1 / ((x − 3)(x + 5)). Answer both parts:

(a) The vertical asymptotes of g occur at:

(b) Fill in the blank: A rational function has a vertical asymptote at x = c only if the denominator is zero at c and the numerator is ___ zero there.

(a) The denominator (x − 3)(x + 5) is zero exactly at x = 3 and x = −5, and the numerator (1) is never zero, so both are genuine vertical asymptotes rather than holes. (b) If the numerator were also zero at c, the shared factor would cancel before any division by zero occurs, producing a removable hole instead of an asymptote.

9. Fill in the blank: For f(x) = (5x + 1)/(x − 3), since the numerator and denominator have equal degree, the horizontal asymptote is y = ___.

With equal degrees in numerator and denominator, the horizontal asymptote is the ratio of leading coefficients: 5/1 = 5, matching what pushing x toward ±∞ in a table would show.

10. Let f(x) = x³ − x − 4, a polynomial (so continuous everywhere), with f(1) = −4 and f(2) = 2. Answer both parts:

(a) Which fact justifies using the IVT to guarantee a root of f in (1, 2)?

(b) Fill in the blank: The IVT guarantees at least ___ value(s) of c in (1, 2) with f(c) = 0 — it does not guarantee there is only one.

(a) The IVT only requires continuity on the closed interval and the target value (here 0) lying between the two endpoint values — whether f is increasing, both endpoint signs, or f's degree are all irrelevant to applying the theorem. (b) The theorem promises existence, not uniqueness — there could be exactly one root or, for a wigglier function, several; the IVT is satisfied by any single one of them.
