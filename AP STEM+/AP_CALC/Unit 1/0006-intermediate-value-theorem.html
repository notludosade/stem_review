The Intermediate Value Theorem

Continuity's biggest payoff yet: proving a value is hit without ever computing exactly where.

← Lesson 5 Unit 2, Lesson 1 → Contents Glossary →

Everything so far has been about describing behavior: does a limit exist, is a function continuous, where does it blow up. The Intermediate Value Theorem (IVT) does something different — it's a tool for proving existence. It lets you guarantee a solution exists without ever solving for it.

1. The theorem

Theorem Intermediate Value Theorem: if f is continuous on the closed interval [a, b], and k is any value between f(a) and f(b), then there exists at least one c in [a, b] such that f(c) = k.

The intuition is exactly Lesson 4's continuity definition paying off: a continuous function has no jumps, no holes, no breaks — its graph is one unbroken pen stroke from (a, f(a)) to (b, f(b)). To get from f(a) up (or down) to f(b) without lifting the pen, the curve has no choice but to pass through every height in between, including k. Continuity is what rules out the function "jumping over" k entirely.

2. Proving a root exists, without finding it

The single most common use of the IVT: showing an equation has a solution, even when solving it exactly is hard or impossible by hand. Take f(x) = x³ − 2x − 5. This is a polynomial, so it's continuous everywhere. Evaluate it at two convenient points:

Worked Example f(2) = 8 − 4 − 5 = −1. f(3) = 27 − 6 − 5 = 16. f is continuous on [2, 3], and 0 is between −1 and 16 — so by the IVT, there exists some c in (2, 3) with f(c) = 0. A root exists in that interval, guaranteed, without factoring or using the cubic formula at all.

3. "At least one" — not "exactly one"

The theorem's wording is deliberate: it guarantees existence, not uniqueness. A wiggly enough continuous function can cross the same target height many times.
