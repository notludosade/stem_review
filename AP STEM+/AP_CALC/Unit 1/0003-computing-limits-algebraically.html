Computing Limits Algebraically

Turning "estimate from a table" into "prove it exactly" — plus a theorem for when nothing simplifies.

← Lesson 2 Lesson 4 → Contents Glossary →

Tables and graphs are how you discover a limit. Algebra is how you prove it exactly, without relying on how many decimal places a table happened to show. Three tools cover almost every limit you'll meet this unit: direct substitution backed by the limit laws, algebraic rewriting when substitution fails, and — for the rare case where nothing simplifies — the Squeeze Theorem.

1. The limit laws

Rule If limx→c f(x) = A and limx→c g(x) = B both exist, then: lim [f(x) + g(x)] = A + B, lim [f(x)·g(x)] = A·B, and lim [f(x)/g(x)] = A/B (provided B ≠ 0). For any polynomial or rational function, this means direct substitution works wherever the function is actually defined.

The catch is exactly the case Lessons 1–2 kept hitting: substitution fails when it produces 0/0. That's not proof the limit doesn't exist — it's a sign the expression needs to be rewritten before substituting.

2. Factor and cancel

Take limx→3 (x² − 9)/(x − 3). Substituting x = 3 gives 0/0. But the numerator factors:

Worked Example (x² − 9)/(x − 3) = (x − 3)(x + 3)/(x − 3) = x + 3, for every x ≠ 3.
So limx→3 (x² − 9)/(x − 3) = limx→3 (x + 3) = 3 + 3 = 6 — now direct substitution works, because the (x − 3) causing the 0/0 has been cancelled away.

Rationalizing works the same way when a square root causes the 0/0: for limx→0 (√(x + 4) − 2)/x, multiply top and bottom by the conjugate √(x + 4) + 2. The numerator becomes (x + 4) − 4 = x, which cancels the x in the denominator, leaving 1/(√(x + 4) + 2) — and substituting x = 0 now gives 1/(2 + 2) = 1/4. Same idea as factoring: rewrite until the offending factor cancels, then substitute.

3. When nothing cancels: the Squeeze Theorem

Some functions won't factor or rationalize into anything simpler at all. g(x) = x²sin(1/x) is one — as x → 0, 1/x swings toward infinity and sin(1/x) oscillates endlessly between −1 and 1, with no algebraic simplification available. But notice: since sin of anything is always between −1 and 1, g(x) is always trapped between −x² and x², no matter how wildly it oscillates.

Theorem Squeeze Theorem: if f(x) ≤ g(x) ≤ h(x) for all x near c, and limx→c f(x) = limx→c h(x) = L, then limx→c g(x) = L too — g is squeezed to the same limit as its bounds, whatever g itself is doing in between.

If picking which technique to use — factor, rationalize, or squeeze — feels like guessing, ask. There's a real pattern to it (0/0 with a visible common factor → factor; 0/0 with a square root → rationalize; oscillation with no algebra available → squeeze), and it's worth naming explicitly before the next lesson moves on to continuity.
