Selecting Procedures for Calculating Derivatives

Every rule so far is in the toolbox now. The only new skill is knowing which one to reach for first.

← Lesson 4 Lesson 6 → Contents Glossary →

Between Unit 2 and this unit, you now have ten-plus rules: Power, Sum/Difference, Constant Multiple, Product, Quotient, all six trig derivatives, exponential, log, Chain, implicit, and inverse-function rules. Real functions rarely need just one. The new skill is entirely diagnostic: look at a function's outermost structure, and that tells you which rule to apply first.

1. The outermost-operation checklist

Checklist Ask what the last operation would be if you were plugging in a number by hand:
• Terms added or subtracted → differentiate each term separately (Sum/Difference Rule).
• Two non-constant expressions multiplied → Product Rule.
• One expression divided by another → Quotient Rule.
• A function applied to something other than plain x → Chain Rule.
Apply that one rule first. Whatever smaller pieces remain inside get the same treatment, recursively.
Worked Example h(x) = x²·sin(3x). Plugging in a number, the last step is a multiplication of x² and sin(3x) — so the Product Rule goes first: h′(x) = (x²)′·sin(3x) + x²·(sin(3x))′. The second factor's derivative needs the Chain Rule: (sin(3x))′ = cos(3x)·3. Assembling: h′(x) = 2x·sin(3x) + 3x²·cos(3x).

Six functions, one question each: which rule handles the outermost layer? Pick a rule to see if you're right, then move to the next one.

2. Combining three rules in one function

Nothing stops the checklist from applying more than twice. Bigger functions just mean more recursive steps — never a new idea.

Worked Example k(x) = [sin(x)·eˣ] / (x² + 1). Outermost: a quotient — Quotient Rule first, with f(x) = sin(x)·eˣ and g(x) = x² + 1: k′(x) = [f′(x)·g(x) − f(x)·g′(x)] / g(x)². Finding f′(x) needs a second rule — f itself is a product: f′(x) = cos(x)·eˣ + sin(x)·eˣ. And g′(x) = 2x, from the Power and Sum Rules. Assembling: k′(x) = {[cos(x)eˣ + sin(x)eˣ](x²+1) − sin(x)eˣ·(2x)} / (x²+1)². Three rules — Quotient, Product, Power — each doing exactly one job, in the order the checklist points to.

Check your recall

1. For k(x) = (x² + 1)·tan(x), the outermost rule to apply is:

Plugging in a number, the last step is multiplying (x²+1) by tan(x) — two non-constant factors multiplied together, which is exactly the Product Rule's job, not a quotient, a composition, or an addition.

2. For k(x) = cos(x³ − 2x), the outermost rule to apply is:

cos is being applied to x³ − 2x, not to plain x — that "function of something other than x" shape is precisely the Chain Rule's signal, not a product, quotient, or sum at the outer layer.

3. For k(x) = eˣ / sin(x), the outermost rule to apply is the ___ Rule.

eˣ divided by sin(x) is a quotient of two non-constant expressions — the outermost operation is division, so the Quotient Rule goes first.
