Differentiating Inverse Trigonometric Functions

Six new derivatives, all built from one lesson's rule and a right triangle.

← Lesson 3 Lesson 5 → Contents Glossary →

Lesson 3's rule — g′(x) = 1/f′(g(x)) — works for any invertible f. Plug in sin, cos, or tan for f, and a short trip through a right triangle turns the answer into something purely algebraic.

1. Deriving d/dx[sin⁻¹x]

Derivation Let f(x) = sin x, so g(x) = sin⁻¹x. By Lesson 3's rule: g′(x) = 1/f′(g(x)) = 1/cos(sin⁻¹x). Let θ = sin⁻¹x, so sin θ = x. Picture a right triangle with angle θ, opposite side x, hypotenuse 1 — then the adjacent side is √(1 − x²) by the Pythagorean theorem, so cos θ = √(1 − x²). Substituting: d/dx[sin⁻¹x] = 1/√(1 − x²).

2. The full set of six

Rules d/dx[sin⁻¹x] = 1/√(1−x²) · d/dx[cos⁻¹x] = −1/√(1−x²) · d/dx[tan⁻¹x] = 1/(1+x²)
d/dx[cot⁻¹x] = −1/(1+x²) · d/dx[sec⁻¹x] = 1/(|x|√(x²−1)) · d/dx[csc⁻¹x] = −1/(|x|√(x²−1))

As with the ordinary trig derivatives back in Unit 2, each "co" function's derivative carries the minus sign. The AP Calculus BC exam draws almost entirely on the first three — sin⁻¹, cos⁻¹, and tan⁻¹ — so those are worth memorizing cold; the other three are here for completeness.

Worked Example Let f(x) = tan x, so g(x) = tan⁻¹x. By Lesson 3's rule: g′(x) = 1/f′(g(x)) = 1/sec²(tan⁻¹x) = cos²(tan⁻¹x). Let θ = tan⁻¹x, so tan θ = x — picture a right triangle with opposite x, adjacent 1, hypotenuse √(1 + x²). Then cos θ = 1/√(1+x²), so cos²θ = 1/(1+x²). Substituting: d/dx[tan⁻¹x] = 1/(1 + x²) — defined for every real x, with no blow-up anywhere, since tan⁻¹x has no vertical tangents.

Check your recall

1. d/dx[sin⁻¹x] equals:

The triangle derivation gives cos(sin⁻¹x) = √(1−x²) with no minus sign and no extra x on top — the minus sign belongs to cos⁻¹x's derivative, and 1/(1+x²) belongs to tan⁻¹x's.

2. d/dx[tan⁻¹x] equals:

From cos²(tan⁻¹x) = 1/(1+x²), the denominator has a plus sign and a squared x — not a minus sign, and not an unsquared x.

3. sin⁻¹x has a vertical tangent (an undefined derivative) at x = ±___.

1/√(1−x²) is undefined exactly when 1 − x² = 0, which happens at x = ±1 — the domain endpoints of sin⁻¹x.
