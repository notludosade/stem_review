Implicit Differentiation

Not every curve is the graph of a single function — but the Chain Rule can still find its slope.

← Lesson 1 Lesson 3 → Contents Glossary →

The circle x² + y² = 9 can't be solved for a single y = f(x) — solving gives y = ±√(9 − x²), two different functions glued together at x = ±3. Implicit differentiation finds the slope anyway, without ever solving for y first.

1. The method

Method Treat y as an unknown function of x. Differentiate both sides of the equation with respect to x. By the Chain Rule, every term containing y picks up an extra factor of y′ (dy/dx) when differentiated. Then solve algebraically for y′.
Worked Example Differentiate x² + y² = 9 with respect to x: d/dx[x²] + d/dx[y²] = d/dx[9] → 2x + 2y·y′ = 0. Solving for y′: y′ = −x/y.

2. It works for any implicit relation

The method doesn't care how complicated the equation gets — the same two steps (differentiate both sides, solve for y′) apply every time.

Worked Example Differentiate x³ + y³ = 6xy: d/dx[x³] + d/dx[y³] = d/dx[6xy]. The left side gives 3x² + 3y²y′. The right side needs the Product Rule (6x and y are both functions of x): 6y + 6xy′. So 3x² + 3y²y′ = 6y + 6xy′. Collecting y′ terms: 3y²y′ − 6xy′ = 6y − 3x², so y′ = (6y − 3x²) / (3y² − 6x) = (2y − x²) / (y² − 2x).

Notice the answer involves both x and y — that's normal for implicit differentiation, and unavoidable whenever the curve can't be solved for y explicitly in the first place.

Check your recall

1. When implicitly differentiating a term containing y, the Chain Rule requires you to:

Since y is implicitly a function of x, differentiating a y-term is a Chain Rule application — the derivative of the "inside function" y is y′, tacked on as a multiplying factor, not a division or a constant treatment.

2. For x² + y² = 9, implicit differentiation gives y′ equal to:

From 2x + 2yy′ = 0, solving gives y′ = −2x/2y = −x/y — x on top, y on the bottom, with a negative sign, not the reciprocal or a positive ratio.

3. On x² + y² = 9, the tangent line is horizontal (y′ = 0) exactly where x = ___.

y′ = −x/y equals 0 only when its numerator x is 0 — the top and bottom of the circle, where the tangent line is flat.
