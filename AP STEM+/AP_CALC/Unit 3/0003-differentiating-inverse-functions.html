Differentiating Inverse Functions

If you know how fast f is moving, you already know how fast its inverse is moving — just flip it.

← Lesson 2 Lesson 4 → Contents Glossary →

If g = f⁻¹, then by definition x = f(g(x)) for every x. That's an implicit relation between x and g(x) — exactly the setup from Lesson 2. Differentiating it implicitly is all it takes to find g′.

1. The inverse function derivative rule

Derivation Start from x = f(g(x)). Differentiate both sides with respect to x. The left side gives 1. The right side needs the Chain Rule (f applied to the inside function g(x)): f′(g(x))·g′(x). So 1 = f′(g(x))·g′(x). Solving for g′(x): g′(x) = 1 / f′(g(x)).
Worked Example Let f(x) = x³ + x. Then f(1) = 1 + 1 = 2, so f⁻¹(2) = 1. Since f′(x) = 3x² + 1, f′(1) = 4. By the rule: (f⁻¹)′(2) = 1/f′(1) = 1/4 — found without ever solving x³ + x = y for x.

Drag the solid point along f(x) = x³ + x. Its mirror image — the point reflected across the diagonal y = x — sits on the graph of f⁻¹ itself.

f(x) = x³ + x, x ∈ [−1.3, 1.3] — chosen so f′(x) = 3x² + 1 is never zero. The dashed curve is f⁻¹, drawn by reflecting f's own points across y = x. The numeric check inverts f near the dragged point using Newton's method.

2. Why the caveat matters

The rule g′(x) = 1/f′(g(x)) breaks down the moment f′(g(x)) = 0 — dividing by zero is never allowed, so the inverse simply has no derivative there.

Worked Example Let f(x) = x³, so g(x) = f⁻¹(x) = x^(1/3) (cube root). At x = 0: f′(0) = 3(0)² = 0. The rule gives g′(0) = 1/0, which is undefined — and indeed, ∛x has a vertical tangent at the origin, the same example from Unit 2 Lesson 3's discussion of where a derivative can fail to exist.

Geometrically this makes sense: reflecting a flat tangent line (slope 0) across y = x produces a vertical tangent line (undefined slope) — flat and vertical are mirror images of each other.

Check your recall

1. Differentiating x = f(g(x)) with the Chain Rule and solving for g′(x) gives:

From 1 = f′(g(x))·g′(x), solving for g′(x) means dividing both sides by f′(g(x)) — giving g′(x) = 1/f′(g(x)), not its reciprocal, not with f and g swapped, and not with g(x) left in the denominator undivided.

2. For f(x) = x³ + x, since f(1) = 2, (f⁻¹)′(2) equals:

f′(x) = 3x² + 1, so f′(1) = 4, and (f⁻¹)′(2) = 1/f′(1) = 1/4 — the reciprocal of f′(1), not f′(1) itself, and not the result of forgetting the "+1" term or miscomputing f′(1).

3. The inverse function rule requires f′(g(x)) ≠ ___, or the inverse's derivative fails to exist there.

g′(x) = 1/f′(g(x)) is a fraction — it's undefined exactly when its denominator, f′(g(x)), equals 0.
