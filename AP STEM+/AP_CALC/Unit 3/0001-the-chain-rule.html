The Chain Rule

Every rule so far handled sums, products, and quotients of functions. This one handles functions stuffed inside other functions.

← Unit 2, Lesson 7 Lesson 2 → Contents Glossary →

sin(x²) isn't a product of sin(x) and x² — it's sin applied to the output of x². That's composition, not multiplication, and none of the Product or Quotient Rules apply to it. The Chain Rule is what differentiates a composite function.

1. Statement of the rule

Rule If F(x) = f(g(x)), then F′(x) = f′(g(x)) · g′(x). In Leibniz notation, with y = f(u) and u = g(x): dy/dx = dy/du · du/dx.

In words: differentiate the outside function, leave the inside function alone, then multiply by the derivative of the inside function.

Worked Example Differentiate h(x) = sin(x²): outside function f(u) = sin(u), inside function g(x) = x². f′(u) = cos(u), g′(x) = 2x. So h′(x) = cos(x²) · 2x.

2. The general power rule

Rule A common special case: if F(x) = [g(x)]ⁿ, then F′(x) = n[g(x)]n−1 · g′(x) — the ordinary Power Rule, with an extra factor of g′(x) tacked on because the base itself is a function of x.
Worked Example Differentiate p(x) = (x² + 1)³: here g(x) = x² + 1, n = 3, g′(x) = 2x. So p′(x) = 3(x² + 1)² · 2x = 6x(x² + 1)².

Check your recall

1. If F(x) = f(g(x)), the Chain Rule gives F′(x) as:

The outside function's derivative is evaluated at the untouched inside function, g(x) — then multiplied (not added) by the inside function's own derivative, g′(x).

2. d/dx[sin(x²)] equals:

Outside function sin(u) differentiates to cos(u), evaluated at u = x²; inside function x² differentiates to 2x. Multiplying gives 2x·cos(x²), not a mismatched pairing of the two.

3. d/dx[g(x)]ⁿ = n[g(x)]n−1 · ___.

The general power rule is just the Chain Rule applied to f(u) = uⁿ: the ordinary Power Rule term n[g(x)]ⁿ⁻¹, times the inside function's derivative g′(x).
