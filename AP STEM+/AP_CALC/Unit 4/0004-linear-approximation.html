Linear Approximation

Zoom in far enough on any smooth curve, and it looks like a straight line — its own tangent line. That line is easy to compute with, and close to the curve nearby.

← Lesson 3 Lesson 5 → Contents Glossary →

Every derivative rule in this course builds the tangent line at a point. This lesson asks what that tangent line is good for, beyond just being a slope: near the point of tangency, it's a remarkably good stand-in for the curve itself — one that's built entirely from arithmetic, no matter how nasty the original function is.

1. The linearization formula

Formula The linearization of f at x = a is L(x) = f(a) + f′(a)(x − a) — exactly the tangent line's equation, just renamed. For x near a, f(x) ≈ L(x): the tangent line's height stands in for the curve's actual height, and the approximation gets worse the farther x strays from a.
Worked Example Approximate √4.1 without a calculator's square-root button. Let f(x) = √x, a = 4 (a perfect square close to 4.1). f(4) = 2, f′(x) = 1/(2√x), so f′(4) = 0.25. Then L(4.1) = 2 + 0.25(4.1 − 4) = 2 + 0.025 = 2.025 — matching the true value 2.02485... to three decimal places, from nothing but a square root you already knew and one derivative.

2. When the approximation over- or under-shoots

Formula — Concavity decides the direction A curve that is concave up (f″ > 0) always lies above its tangent lines, so L(x) underestimates f(x) for x ≠ a. A curve that is concave down (f″ < 0) lies below its tangent lines, so L(x) overestimates f(x). √x is concave down (its rate of growth keeps shrinking), which is why the estimate 2.025 came in very slightly above the true 2.02485.

Check your recall

1. L(x) = f(a) + f′(a)(x − a) approximates f near x = a using the:

f(a) is the point of tangency and f′(a) is the tangent line's slope — L(x) is nothing but the tangent line's equation, renamed for this use. A secant needs two curve points, a normal line is perpendicular to the tangent, and neither matches this formula.

2. Using f(x) = √x and a = 4 (so f(4) = 2, f′(4) = 0.25), the linearization estimate for √4.1 is L(4.1) = ___.

L(4.1) = f(4) + f′(4)(4.1 − 4) = 2 + 0.25(0.1) = 2 + 0.025 = 2.025.

3. For a concave-up function, the linearization L(x) always ___ the true value f(x), for x ≠ a.

Concave up means the curve bends upward away from its tangent lines, sitting above them everywhere except the point of tangency itself — so the tangent line's height, L(x), falls short of the true f(x).
