1. For a parametric curve x = x(t), y = y(t) with dx/dt ≠ 0, the derivative dy/dx equals:

The chain rule gives dy/dt = (dy/dx)(dx/dt); solving for dy/dx divides the rate of y by the rate of x, both taken against the shared parameter t.

2. Fill in the blank: For x(t) = t² + 2t, y(t) = t³ + 3t², dy/dx at t = 2 is ___

dx/dt = 2t + 2 = 6 and dy/dt = 3t² + 6t = 24 at t = 2, so dy/dx = 24/6 = 4.

3. For x(t) = t² − 4, y(t) = t³ − 3t, answer both parts:

(a) Horizontal tangents (dy/dt = 0, dx/dt ≠ 0) occur at:

(b) Fill in the blank: At t = 1, the y-coordinate of the horizontal-tangent point is ___

(a) dy/dt = 3t² − 3 = 0 gives t = ±1, and dx/dt = 2t is nonzero at both (−2 and 2), so both are genuine horizontal tangents. (b) y(1) = 1³ − 3(1) = 1 − 3 = −2.

4. For a parametric curve, d²y/dx² = −7 at t = 1. The curve at that point is:

A negative second derivative means concave down — the same rule that applies to an ordinary y = f(x) graph applies here too.

5. For x(t) = 4cos t, y(t) = 4sin t, t from 0 to π/2, answer both parts:

(a) The integrand √[(dx/dt)² + (dy/dt)²] simplifies to:

(b) Fill in the blank: The arc length from t = 0 to t = π/2 is ___

(a) dx/dt = −4sin t, dy/dt = 4cos t, so √[(dx/dt)² + (dy/dt)²] = √(16sin²t + 16cos²t) = 4, a constant speed. (b) L = ∫₀^(π/2) 4 dt = 4(π/2) = 2π — a quarter of the circumference of a radius-4 circle, matching known geometry.

6. Fill in the blank: For r(t) = ⟨t² + 2t, t³ + 3t²⟩, r'(2) = ___ (format: <a,b>)

r'(t) = ⟨2t + 2, 3t² + 6t⟩, so r'(2) = ⟨2(2) + 2, 3(2)² + 6(2)⟩ = ⟨6, 24⟩. Differentiation of a vector-valued function is componentwise.

7. For r(t) = ⟨24t, 32t − 16t²⟩ (feet, t in seconds), a launched projectile, answer both parts:

(a) Fill in the blank: The acceleration vector is ⟨0, ___⟩

(b) The speed at t = 0 is:

(a) v(t) = ⟨24, 32 − 32t⟩, so a(t) = v'(t) = ⟨0, −32⟩ — constant, since only gravity acts once launched. (b) v(0) = ⟨24, 32⟩, so speed = √(24² + 32²) = √(576 + 1024) = √1600 = 40 ft/s.

8. Converting a polar point (r, θ) to rectangular coordinates uses:

x = r cos θ and y = r sin θ come directly from right-triangle trigonometry, with r as the hypotenuse and θ measured from the positive x-axis.

9. For r = 2 − 2cos θ, answer both parts at θ = π/2:

(a) Fill in the blank: dx/dθ = ___

(b) dy/dx equals:

(a) x(θ) = r cos θ, so dx/dθ = r'cos θ − r sin θ. At θ = π/2: r = 2, r' = 2sin θ = 2, giving dx/dθ = 2(0) − 2(1) = −2. (b) dy/dθ = r'sin θ + r cos θ = 2(1) + 2(0) = 2, so dy/dx = 2/(−2) = −1.

10. For one loop of r = 3sin θ, θ from 0 to π, answer both parts:

(a) The area enclosed is given by the integral:

(b) Fill in the blank: This area equals ___

(a) Each thin wedge has area (1/2)r²dθ, giving A = (1/2)∫₀^π (3sin θ)² dθ. (b) ∫₀^π sin²θ dθ = π/2, so A = (1/2)(9)(π/2) = 9π/4.
