1. A curve as two functions of t

Definition — Parametric Curve A parametric curve is given by x = x(t), y = y(t) for t in some interval. As t increases, the point (x(t), y(t)) traces a path — one that can loop, cross itself, or double back, none of which a single y = f(x) can do. Every y = f(x) graph is a special case: let x(t) = t, y(t) = f(t).
Method — The Parametric Derivative Since both x and y depend on t, the chain rule gives dy/dt = (dy/dx)·(dx/dt), so dy/dx = (dy/dt) / (dx/dt), wherever dx/dt ≠ 0. A horizontal tangent occurs where dy/dt = 0 (and dx/dt ≠ 0); a vertical tangent occurs where dx/dt = 0 (and dy/dt ≠ 0). If both vanish at once, the point needs closer inspection — it's often a cusp or self-crossing, not a clean tangent.
Worked Example x(t) = t² − 2t, y(t) = t³ − 3t. dx/dt = 2t − 2, dy/dt = 3t² − 3. At t = 2: dx/dt = 2, dy/dt = 9, so dy/dx = 9/2. Setting dy/dt = 0 gives t = ±1. At t = 1, dx/dt is also 0 — an indeterminate point. At t = −1, dx/dt = −4 ≠ 0, giving a genuine horizontal tangent at (x(−1), y(−1)) = (3, 2).

2. Watching the tangent line turn

Slide t to move the point along the curve. The tangent line's slope is dy/dx = (dy/dt)/(dx/dt) at that instant.

1. For a parametric curve, dy/dx equals:

The chain rule gives dy/dt = (dy/dx)(dx/dt), and solving for dy/dx divides the rate of y by the rate of x, both taken with respect to the shared parameter t.

2. For x(t) = t² − 2t, y(t) = t³ − 3t, dy/dx at t = 2 is ___

dx/dt = 2(2) − 2 = 2 and dy/dt = 3(2)² − 3 = 9, so dy/dx = 9/2.

3. If dx/dt and dy/dt are both 0 at the same t, the point:

Dividing 0 by 0 gives no information about the slope directly — such points are often cusps or self-crossings and need a separate limit argument.
