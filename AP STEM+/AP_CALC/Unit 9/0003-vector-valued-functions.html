Vector-Valued Functions

x(t) and y(t) have been two separate functions so far. Bundling them into one arrow-valued function r(t) makes differentiating and integrating a curve feel like differentiating a single object.

← Lesson 2 Lesson 4 → Contents Glossary →

1. Packing x(t) and y(t) into one arrow

Definition — Vector-Valued Function A vector-valued function r(t) = ⟨x(t), y(t)⟩ assigns a vector — not a number — to each t. It carries exactly the same information as the parametric pair x(t), y(t); the arrow from the origin to r(t) just points at the same traced curve. In three dimensions, r(t) = ⟨x(t), y(t), z(t)⟩ extends the idea with no new ideas required.
Method — Differentiating and Integrating Componentwise Both operations act on each component separately: r'(t) = ⟨x'(t), y'(t)⟩ and ∫r(t) dt = ⟨∫x(t) dt, ∫y(t) dt⟩ + C, where C is a constant vector. r'(t) is itself a vector — it points in the direction the curve is heading at that instant, tangent to the path.
Worked Example r(t) = ⟨t² − 2t, t³ − 3t⟩ — the same curve from Lessons 1–2, now in vector form. r'(t) = ⟨2t − 2, 3t² − 3⟩. At t = 2: r'(2) = ⟨2, 9⟩, a tangent vector pointing right and steeply up — its slope 9/2 matches the dy/dx found in Lesson 1, since slope is just rise over run of this same vector. Integrating: ∫r'(t) dt = ⟨t² − 2t, t³ − 3t⟩ + C, recovering r(t) itself up to a constant vector.

Differentiation of a vector-valued function is componentwise — each coordinate function is differentiated on its own, and the results stay packaged as a vector.
