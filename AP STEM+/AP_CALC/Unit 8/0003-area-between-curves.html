Area Between Curves

A single integral found the area under one curve. Subtracting one function from another before integrating finds the area trapped between two.

← Lesson 2 Lesson 4 → Contents Glossary →

1. Integrating with respect to x

Method — Area Between Two Curves, wrt x If f(x) ≥ g(x) on [a, b], the area trapped between them is A = ∫ab [f(x) − g(x)] dx. Each infinitesimal rectangle has width dx and height equal to the gap between the top curve and the bottom curve — a straightforward extension of "area under one curve," which is just this formula with g(x) = 0.
Worked Example Find the area between y = x + 2 and y = x² . Intersections: x² = x + 2 → (x − 2)(x + 1) = 0 → x = −1, 2. Testing x = 0 shows the line sits above the parabola on this interval. A = ∫₋₁² [(x + 2) − x²] dx = [x²/2 + 2x − x³/3]₋₁² = 10/3 − (−7/6) = 9/2.

2. Watching the gap sum into an area

Slide n to add more rectangles, each spanning the vertical gap between the two curves at its midpoint. The total converges to 9/2.

3. Integrating with respect to y

Method — Area Between Two Curves, wrt y Some regions are more naturally described by their left and right boundaries as functions of y. If f(y) ≥ g(y) (f to the right of g) on [c, d], then A = ∫cd [f(y) − g(y)] dy — the same idea with the axes' roles swapped. This is often the shorter path when the region's top and bottom would otherwise require splitting a wrt-x integral into two pieces.
Worked Example Find the area between x = 4 − y² and the y-axis (x = 0). Intersections: 4 − y² = 0 → y = ±2. At y = 0, x = 4 − y² = 4 sits to the right of x = 0, so it is the right-hand boundary. A = ∫₋₂² [(4 − y²) − 0] dy = [4y − y³/3]₋₂² = 32/3.

Check your recall

1. To integrate wrt x for the area between two curves, the integrand should be:

Subtracting the lower curve from the upper curve leaves exactly the vertical gap's height at each x, which is what a Riemann rectangle needs to fill the region correctly.

2. The area between y = x + 2 and y = x² is ___

∫₋₁² [(x+2) − x²] dx = 10/3 − (−7/6) = 9/2, using the intersection points x = −1 and x = 2 as the bounds.

3. Integrating with respect to y instead of x is most useful when:

When a wrt-x setup would force splitting the region into multiple pieces because the top or bottom function changes, describing the same region by its left and right boundaries as functions of y often avoids the split entirely.
