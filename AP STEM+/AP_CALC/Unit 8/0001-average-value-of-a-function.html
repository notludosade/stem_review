1. The average value formula

Definition — Average Value of a Function The average value of a continuous function f on [a, b] is favg = (1/(b − a)) ∫ab f(x) dx. It generalizes the average of finitely many numbers to a continuum: divide the total accumulated area by the width of the interval it accumulated over.
Theorem — Mean Value Theorem for Integrals If f is continuous on [a, b], there exists at least one point c in [a, b] where f(c) = favg — the function actually attains its own average value somewhere in the interval, not just in principle.
Worked Example Find the average value of f(x) = x² on [0, 3], and a point c where f(c) equals it. favg = (1/3)∫₀³x² dx = (1/3)[x³/3]₀³ = (1/3)(9) = 3. Setting c² = 3 gives c = √3 ≈ 1.73, which does lie in [0, 3] as the theorem guarantees.
