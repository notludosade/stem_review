Arc Length of a Smooth Curve

Every technique so far has measured area or volume under a curve. This one measures the curve itself — how long is it, if you walked along it?

← Lesson 7 Contents Glossary →

1. Length as an integral

Method — Arc Length of y = f(x) For a smooth curve y = f(x) on [a, b], the arc length is L = ∫ab √(1 + [f′(x)]²) dx. The idea: a tiny piece of curve of horizontal width dx and vertical rise f′(x)dx has length √(dx² + [f′(x)dx]²) by the Pythagorean theorem, which factors to dx·√(1 + [f′(x)]²) — then those tiny lengths accumulate the same way area or volume did.
Worked Example — A Sanity Check Against Geometry Find the arc length of y = √(1 − x²) from x = 0 to x = 1 — a quarter of the unit circle. f′(x) = −x/√(1−x²), so 1 + [f′(x)]² = 1/(1−x²). L = ∫₀¹ dx/√(1−x²) = [arcsin x]₀¹ = π/2 — exactly a quarter of the unit circle's circumference 2π, confirming the formula against a shape whose length is already known.

2. Distance traveled along a path

Method — Distance Traveled, Parametrically (BC) Lesson 2 found 1D distance traveled as ∫|v(t)|dt. If a particle's position is instead a 2D path (x(t), y(t)), its speed is √([x′(t)]² + [y′(t)]²), and distance traveled = ∫ab √([x′(t)]² + [y′(t)]²) dt — the same Pythagorean idea as arc length, now applied to a path traced out over time rather than a graph traced out over x. Unit 9 develops parametric curves fully; this is the one piece needed now.
Worked Example A particle's position is x(t) = 3t², y(t) = 2t³ for t in [0, 1]. x′(t) = 6t, y′(t) = 6t². Distance = ∫₀¹ √(36t² + 36t⁴) dt = ∫₀¹ 6t√(1+t²) dt. Substituting u = 1+t²: = 3∫₁² √u du = 2[u^(3/2)]₁² = 2(2√2 − 1) = 4√2 − 2 ≈ 3.657.

1. The arc length formula for y = f(x) on [a, b] comes from:

A tiny segment of curve has horizontal leg dx and vertical leg f′(x)dx, so its own length is the hypotenuse √(dx² + [f′(x)dx]²) — integrating that accumulates the total length.

2. The arc length of y = √(1−x²) from x = 0 to x = 1 is ___ (use "pi" for π)

∫₀¹dx/√(1−x²) = [arcsin x]₀¹ = π/2, matching a quarter of the unit circle's circumference exactly.

3. For a 2D path (x(t), y(t)), distance traveled generalizes ∫|v(t)|dt to:

Speed along a 2D path is the magnitude of the velocity vector — the Pythagorean combination of both component rates — and integrating that magnitude over time gives total distance traveled.

Arc length integrals are notorious for producing messy antiderivatives — even simple-looking curves often need a calculator's numerical integration in practice, and that's expected, not a sign of a mistake. Ask for a parametric example with a calculator-only numerical answer if curious how that plays out on the exam.
