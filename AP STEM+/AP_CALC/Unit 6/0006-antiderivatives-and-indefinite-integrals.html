Antiderivatives and Indefinite Integrals

FTC Part 2 needs an antiderivative to evaluate a definite integral. This lesson builds a toolkit for finding one — by running differentiation rules in reverse.

← Lesson 5 Lesson 7 → Contents Glossary →

1. Antiderivatives and the constant of integration

Definition — Antiderivative & Indefinite Integral F is an antiderivative of f if F′(x) = f(x). Since the derivative of any constant is 0, if F is one antiderivative of f, so is F(x) + C for every constant C — an entire family of curves, each a vertical shift of the others. The indefinite integral ∫f(x) dx = F(x) + C denotes this whole family at once.

2. Basic antiderivative rules

Rules — Reversing Common Derivatives ∫xⁿ dx = xn+1/(n+1) + C (n ≠ −1, the reverse Power Rule) · ∫(1/x) dx = ln|x| + C · ∫eˣ dx = eˣ + C · ∫sin(x) dx = −cos(x) + C · ∫cos(x) dx = sin(x) + C · ∫sec²(x) dx = tan(x) + C. As with derivatives, constant multiples and sums split apart: ∫(f + g) dx = ∫f dx + ∫g dx.
Worked Example ∫(3x² − 4x + 5) dx = x³ − 2x² + 5x + C — each term reverses the Power Rule independently, and a single C covers the whole sum.
Worked Example ∫(sin(x) + eˣ) dx = −cos(x) + eˣ + C — two different rules, applied term by term.

3. Solving for the constant: initial-value problems

Worked Example — Initial-Value Problem If F′(x) = 6x and F(1) = 5, first find the general antiderivative: F(x) = 3x² + C. Then use the known point to pin down C: 3(1)² + C = 5, so C = 2, and F(x) = 3x² + 2 is the one specific member of the family that passes through (1, 5).

4. Finding the constant, live

F′(x) = 2x, so every antiderivative has the form F(x) = x² + C. Slide C until the curve passes through the marked target point (2, 3) — there's exactly one value of C that works.

Check your recall

1. The general antiderivative of f(x) = x³ is:

The reverse Power Rule raises the exponent by 1 and divides by the new exponent: x³ → x⁴/4. The other options mix up differentiating instead of integrating, or forget to divide.

2. ∫(sin(x) + eˣ) dx = −cos(x) + eˣ + ___

Every indefinite integral carries an arbitrary constant of integration — leaving it off is one of the most common lost points on the AP exam.

3. If F′(x) = 6x and F(1) = 5, then F(x) equals:

The general antiderivative is 3x² + C; plugging in F(1) = 5 gives 3 + C = 5, so C = 2.
