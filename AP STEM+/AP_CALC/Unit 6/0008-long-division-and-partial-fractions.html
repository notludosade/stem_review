Long Division, Completing the Square, and Partial Fractions

Some rational integrands need algebra before any integration rule applies at all — reshaping them into pieces the earlier lessons already know how to handle.

← Lesson 7 Lesson 9 → Contents Glossary →

1. Long division for improper rational integrands

Method — Long Division First When the numerator's degree is greater than or equal to the denominator's, the fraction is improper — divide first. Polynomial long division rewrites it as a polynomial plus a proper fraction, and the polynomial part integrates by the Power Rule while the leftover fraction is handled separately.
Worked Example ∫ (x² + 1)/(x − 1) dx: dividing gives (x² + 1)/(x − 1) = x + 1 + 2/(x − 1). Integrating term by term: x²/2 + x + 2 ln|x − 1| + C.

2. Completing the square for irreducible quadratics

Method — Completing the Square A quadratic denominator with no real roots won't factor into linear pieces — but completing the square reshapes it into (x + h)² + k², matching the standard form ∫ du/(u² + a²) = (1/a) arctan(u/a) + C.
Worked Example ∫ 1/(x² + 2x + 5) dx: completing the square gives x² + 2x + 5 = (x + 1)² + 4. So the integral becomes ∫ 1/((x + 1)² + 2²) dx = (1/2) arctan((x + 1)/2) + C.

3. Partial fractions with a repeated linear factor

Distinct linear factors were already covered back in Precalculus Lesson 34. A repeated linear factor needs one extra term per power, up to its multiplicity.

Worked Example Decompose 1/[(x − 2)(x + 1)²]. Since (x + 1) is squared, the setup needs three terms: A/(x − 2) + B/(x + 1) + C/(x + 1)². Clearing denominators: 1 = A(x + 1)² + B(x − 2)(x + 1) + C(x − 2). Substituting x = 2 gives A = 1/9; substituting x = −1 gives C = −1/3; matching x² coefficients gives B = −1/9. Integrating each piece: (1/9) ln|x − 2| − (1/9) ln|x + 1| + (1/3)/(x + 1) + C.
