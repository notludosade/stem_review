The Fundamental Theorem of Calculus, Part 1, and Accumulation Functions

A definite integral with a variable upper bound is itself a function of that bound — and its derivative turns out to need no new work at all.

← Lesson 2 Lesson 4 → Contents Glossary →

1. Accumulation functions

Definition — Accumulation Function For a fixed lower bound a, g(x) = ∫ax f(t) dt defines a new function of x — the running total of signed area swept out as the upper bound slides from a to x. This is called an accumulation function.

2. The Fundamental Theorem of Calculus, Part 1

Theorem — FTC Part 1 If f is continuous on [a, b] and g(x) = ∫ax f(t) dt for x in [a, b], then g is differentiable and g′(x) = f(x). Differentiating an accumulation function simply hands back the original integrand — integration and differentiation undo each other.
Worked Example g(x) = ∫2x (t² + 1) dt. By FTC Part 1, g′(x) = x² + 1 directly — no antiderivative needed, and the lower bound 2 never even enters the derivative.
Worked Example — With the Chain Rule h(x) = ∫0x² sin(t) dt. The upper bound is x², not x, so FTC Part 1 combines with the Chain Rule: h′(x) = sin(x²) · 2x — the integrand evaluated at the upper bound, times that bound's own derivative.

3. Reading g's shape from f's graph

Fact — Behavior of an Accumulation Function Since g′(x) = f(x), every shape-reading tool from Unit 5 transfers directly: g is increasing wherever f(x) > 0, decreasing wherever f(x) < 0, and has a critical point wherever f(x) = 0. If f goes from negative to positive at x = c, g has a local minimum there (First Derivative Test) — because area is being subtracted just before c and added just after.

FTC Part 1 is the reason accumulation-function questions on the AP exam almost never require actually finding an antiderivative — the derivative of g is just f, read straight off a graph or formula. Ask for a version where the lower bound itself is a function of x (both bounds moving) if that variant still feels unclear.
