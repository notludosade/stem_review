1. For a function f continuous on [2, 8] and differentiable on (2, 8), the Mean Value Theorem guarantees a c in (2, 8) where f′(c) equals:

The MVT's conclusion is f′(c) = (f(b) − f(a))/(b − a). Here b − a = 8 − 2 = 6, so f′(c) must equal (f(8) − f(2))/6 — the secant line's slope across the whole interval.

2. For f(x) = x² − 6x + 5, the critical point is at x =:

f′(x) = 2x − 6, which equals 0 exactly when x = 3 — the one point where the derivative is zero, so it's the only critical point.

3. For g(x) = x³ − 12x, answer both parts:

(a) The critical points are:

(b) Fill in the blank: the First Derivative Test classifies x = −2 as a local ___.

(a) g′(x) = 3x² − 12 = 3(x − 2)(x + 2), zero at x = −2 and x = 2. (b) g′ is positive for x < −2, negative for −2 < x < 2 — a change from positive to negative, the signature of a local maximum.

4. For f(x) = x³ − 3x² on [−1, 3], answer both parts:

(a) The critical points inside the interval are:

(b) Fill in the blank: the absolute maximum value of f on [−1, 3] is ___.

(a) f′(x) = 3x² − 6x = 3x(x − 2), zero at x = 0 and x = 2, both inside (−1, 3). (b) Evaluating every candidate: f(−1) = −4, f(0) = 0, f(2) = −4, f(3) = 0 — the largest value, 0, is the absolute maximum (attained at both x = 0 and x = 3).

5. Fill in the blank: an inflection point requires the sign of f″ to actually ___, not merely equal zero at that point.

f″(x) = 0 alone isn't enough — an inflection point requires the sign of f″ to genuinely flip on either side of that point, marking a true change in concavity.

6. For p(x) = 2x³ − 6x, answer both parts:

(a) p″(x) equals:

(b) Fill in the blank: using the Second Derivative Test, x = 1 (a critical point of p) is classified as a local ___.

(a) p′(x) = 6x² − 6, so p″(x) = 12x. (b) At x = 1: p″(1) = 12 > 0, and the Second Derivative Test says positive concavity at a critical point signals a local minimum.

7. A curve that is increasing and concave down looks like:

Increasing (f′ > 0) means climbing; concave down (f″ < 0) means curving over — exactly the shape of a hilltop approach, still climbing but leveling off. A valley bottom is the concave-up case instead, and straight lines have no concavity at all.

8. To reduce a two-variable optimization formula to a single variable, you should:

A constraint equation relates the two variables in the problem, so solving it for one variable and substituting is what collapses the formula down to a single variable the Candidates Test can handle.

9. A rectangular garden has one side against an existing wall (no fencing needed there) and 40 m of fencing for the other three sides. Let x be the side parallel to the wall, and y each of the two perpendicular sides, so x + 2y = 40. Answer both parts:

(a) Writing area as a single-variable function of x, A(x) equals:

(b) Fill in the blank: the value of x that maximizes the area is x = ___ meters.

(a) Solving the constraint for y: y = 20 − x/2. Then A(x) = x·y = x(20 − x/2) = 20x − x²/2. (b) A′(x) = 20 − x = 0 gives x = 20; since A″(x) = −1 < 0 and A(0) = A(40) = 0 at the endpoints, x = 20 is the absolute maximum.

10. For the circle x² + y² = 169, answer both parts:

(a) Differentiating x² + y² = 169 implicitly with respect to x gives dy/dx equals:

(b) Fill in the blank: at the point (5, 12) on this circle, dy/dx = ___.

(a) Differentiating both sides with respect to x: 2x + 2y(dy/dx) = 0, so dy/dx = −x/y. (b) At (5, 12): dy/dx = −5/12.
