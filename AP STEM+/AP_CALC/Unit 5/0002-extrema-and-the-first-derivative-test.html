Extrema and the First Derivative Test

The sign of f′ is a map of the whole function's terrain — where it climbs, where it descends, and exactly where a peak or valley must be hiding.

← Lesson 1 Lesson 3 → Contents Glossary →

Lesson 1's Mean Value Theorem has an immediate corollary: if f′ is positive everywhere on an interval, f must be increasing there (a decreasing f would force some tangent to point downward, contradicting a positive average slope, and vice versa). That one fact — sign of f′ tells direction of f — is the entire engine behind this lesson.

1. Extreme values and critical points

Theorem — Extreme Value Theorem If f is continuous on a closed interval [a, b], then f attains both an absolute maximum and an absolute minimum somewhere in [a, b]. Continuity and a closed, bounded interval are both required — an open interval or a jump can let a function approach a value forever without ever reaching it.
Definition — Critical point A point c in the domain of f is a critical point if f′(c) = 0 or f′(c) is undefined. Every local extremum of a differentiable function occurs at a critical point — but not every critical point is a local extremum, which is exactly why a test is needed.

2. The First Derivative Test

Test — First Derivative Test At a critical point c: if f′ changes from positive to negative, f has a local maximum at c. If f′ changes from negative to positive, f has a local minimum at c. If f′ doesn't change sign, c is neither.
Worked Example f(x) = x³ − 3x. f′(x) = 3x² − 3 = 3(x−1)(x+1), zero at x = −1 and x = 1. f′ is positive for x < −1, negative for −1 < x < 1, positive for x > 1. So x = −1 is a local maximum (+ to −) and x = 1 is a local minimum (− to +).

Check your recall

1. A critical point of f occurs where:

Critical points are defined by the first derivative being zero or undefined — not the function itself, not the second derivative, and not some other target value.

2. If f′(x) > 0 on an interval, f is ___ there.

A positive derivative means every tangent line points upward — the MVT corollary guarantees the function itself is climbing on that interval.

3. For f(x) = x³ − 3x, the First Derivative Test classifies x = −1 as a:

f′ changes from positive to negative at x = −1, the signature of a local maximum. It's only local, not global — the cubic climbs without bound as x grows, so no global maximum exists at all.

Mixing up "critical point" with "local extremum" is the most common slip here — every local extremum is a critical point, but plenty of critical points (like x=0 for f(x)=x³) are neither max nor min.
