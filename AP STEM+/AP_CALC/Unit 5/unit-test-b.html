1. Rolle's Theorem applies to a function f on [a, b] — continuous on [a, b], differentiable on (a, b) — only when we also know:

Rolle's Theorem is the special case of the MVT where the two endpoint values are equal, f(a) = f(b) — the average rate of change is then 0, which is exactly why the guaranteed tangent is horizontal.

2. For f(x) = x^(2/3), which of the following is a critical point?

f′(x) = (2/3)x^(−1/3), which is undefined at x = 0 (never zero for x ≠ 0). A critical point occurs where f′ is zero or undefined — this is an example of the "undefined" case.

3. For h(x) = x³ − 27x, answer both parts:

(a) The critical points are:

(b) Fill in the blank: the First Derivative Test classifies x = 3 as a local ___.

(a) h′(x) = 3x² − 27 = 3(x − 3)(x + 3), zero at x = −3 and x = 3. (b) h′ is negative for −3 < x < 3 and positive for x > 3 — a change from negative to positive, the signature of a local minimum.

4. For f(x) = x³ − 3x² on [−2, 1], answer both parts:

(a) The only critical point inside the interval is:

(b) Fill in the blank: the absolute minimum value of f on [−2, 1] is ___.

(a) f′(x) = 3x² − 6x = 3x(x − 2), zero at x = 0 and x = 2 — but x = 2 lies outside (−2, 1), so only x = 0 is an interior critical point. (b) Evaluating every candidate: f(−2) = −20, f(0) = 0, f(1) = −2 — the smallest value, −20, is the absolute minimum, occurring at the endpoint x = −2.

5. Fill in the blank: f is concave down on an interval exactly where f″(x) is ___.

Concave down means f′ is decreasing, which is exactly what f″(x) < 0 (a negative second derivative) says.

6. For q(x) = 2x³ − 24x, answer both parts:

(a) q″(x) equals:

(b) Fill in the blank: using the Second Derivative Test, x = −2 (a critical point of q) is classified as a local ___.

(a) q′(x) = 6x² − 24, so q″(x) = 12x. (b) At x = −2: q″(−2) = −24 < 0, and the Second Derivative Test says negative concavity at a critical point signals a local maximum.

7. If f′(x) < 0 and f″(x) < 0 on an interval, the curve on that interval is:

f′ < 0 means the curve is falling; f″ < 0 means it's curving downward — together, "decreasing, concave down," the shape of a curve falling away over a ledge.

8. In an optimization problem, after finding the critical points of the single-variable function, the next step is to:

Critical points alone can't identify the absolute extremum — the Candidates Test (Lesson 3) requires comparing every critical point's value against the domain's endpoints too, since an endpoint can beat every interior critical point.

9. An open-top box with a square base of side x has volume 32 ft³, so x²y = 32 where y is the height. Surface area (base plus four sides, no top) is S(x) = x² + 4xy. Answer both parts:

(a) Substituting y = 32/x² into S(x) = x² + 4xy gives S(x) equals:

(b) Fill in the blank: the value of x that minimizes the surface area is x = ___ feet.

(a) S(x) = x² + 4x(32/x²) = x² + 128/x. (b) S′(x) = 2x − 128/x² = 0 gives 2x³ = 128, so x³ = 64 and x = 4 — the unique positive critical point, and the domain's behavior at the boundaries (S → ∞ as x → 0⁺ or x → ∞) confirms it's the minimum.

10. For the curve xy = 12, answer both parts:

(a) Differentiating xy = 12 implicitly with respect to x (using the Product Rule) gives:

(b) Fill in the blank: at the point (3, 4) on this curve, dy/dx = ___.

(a) The Product Rule applied to xy gives x(dy/dx) + y(1), so differentiating xy = 12 gives x(dy/dx) + y = 0. (b) Solving for dy/dx: dy/dx = −y/x. At (3, 4): dy/dx = −4/3.
