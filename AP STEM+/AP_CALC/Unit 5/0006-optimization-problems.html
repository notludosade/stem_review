Optimization Problems

The Candidates Test was never just an abstract exercise — it's the exact tool that turns a real design constraint into a single best answer.

← Lesson 5 Lesson 7 → Contents Glossary →

Every skill this unit needs is already built: reduce a real-world setup to a single-variable function, then hand it straight to Lesson 3's Candidates Test. The only new work is the modeling step — turning words into that one function.

1. The strategy

Strategy — Solving an optimization problem (1) Introduce variables and, if helpful, draw a figure. (2) Identify the quantity to maximize or minimize. (3) Write a formula for it — this may involve more than one variable. (4) Write a constraint equation relating those variables, and substitute using a constraint equation to reduce the formula to one variable. (5) Determine the domain from the problem's physical limits. (6) Apply the Candidates Test to that single-variable function on that domain.
Worked Example A 24 in. by 36 in. sheet of cardboard becomes an open-top box by cutting a square of side x from each corner and folding up the flaps. The base becomes (24−2x) by (36−2x), and the height is x, so V(x) = x(24−2x)(36−2x). Physically, 0 < x < 12 (past x=12 the shorter side vanishes). V is continuous on the closed interval [0,12], so the Candidates Test applies: V′(x) = 12x² − 240x + 864 = 0 gives x ≈ 4.7 inside (0,12), and comparing V(0) = 0, V(4.7) ≈ 1825.4, V(12) = 0 shows the maximum volume, about 1825.4 in³, occurs at x ≈ 4.7.

1. To reduce a two-variable formula to one variable, you should:

A constraint equation relates the two variables in the problem (like the fixed cardboard dimensions), so solving it for one variable and substituting is what collapses the formula down to a single variable the Candidates Test can handle.

2. Since V is continuous on the closed interval [0,12], the Candidates Test guarantees an absolute ___.

Even though the physical setup only makes sense on the open interval (0,12), extending to the closed [0,12] lets the Extreme Value Theorem guarantee an absolute maximum exists — and the Candidates Test finds exactly where.
