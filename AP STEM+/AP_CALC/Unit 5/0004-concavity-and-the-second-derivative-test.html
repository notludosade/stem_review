Concavity and the Second Derivative Test

f′ told you which way the curve is heading. f″ tells you how it's bending — and gives a shortcut for classifying extrema without a sign chart.

← Lesson 3 Lesson 5 → Contents Glossary →

Applying the increasing/decreasing logic from Lesson 2 to f′ itself — instead of f — describes concavity. f″ is nothing new mathematically; it's just Lesson 2's derivative-sign reasoning, one derivative order up.

1. Concavity

Definition — Concavity f is concave up on an interval where f′ is increasing (equivalently, f″(x) > 0) — the curve bends upward, like a cup. f is concave down where f′ is decreasing (f″(x) < 0) — the curve bends downward, like a frown.
Definition — Inflection point An inflection point is a point where concavity actually changes — f″ changes sign there (typically where f″(x) = 0 or is undefined, though that alone isn't sufficient; the sign must genuinely flip).

2. The Second Derivative Test

Test — Second Derivative Test At a critical point c where f′(c) = 0: if f″(c) > 0, f has a local minimum at c (concave up, curving away from below). If f″(c) < 0, f has a local maximum at c (concave down). If f″(c) = 0, the test is inconclusive — fall back to the First Derivative Test from Lesson 2.
Worked Example f(x) = x³ − 3x, same function as Lessons 2 and 3. f″(x) = 6x. At x = −1: f″(−1) = −6 < 0, confirming the local maximum found earlier. At x = 1: f″(1) = 6 > 0, confirming the local minimum. And f″(x) = 0 at x = 0, where f″ changes sign — an inflection point, even though x = 0 isn't a critical point at all.

Check your recall

1. f is concave up on an interval where:

Concave up means f′ is increasing, which is exactly what f″(x) > 0 says. The f′-based options describe whether f itself is increasing or decreasing — a different question about direction, not bending.

2. An inflection point is where the sign of f″ ___.

f″(x) = 0 alone isn't enough — an inflection point requires the sign of f″ to actually flip on either side, marking a genuine change in concavity.

3. For f(x) = x³ − 3x, the Second Derivative Test classifies x = 1 as a:

f″(1) = 6 > 0, so the curve is concave up at x = 1 — the Second Derivative Test's signature for a local minimum. It is also a critical point, but "critical point" alone doesn't classify which kind of extremum (or non-extremum) it is.
