The Mean Value Theorem

Somewhere between two points on a smooth curve, the instantaneous rate of change must match the average rate of change — no gap allowed.

← Unit 4, Lesson 5 Lesson 2 → Contents Glossary →

Units 1–4 built the derivative and learned to compute and apply it. Unit 5 turns the derivative into a lens for understanding a function's whole shape — where it rises, falls, curves, and peaks. It starts with a theorem that guarantees the derivative can't avoid matching the average, even once.

1. The theorem

Theorem — Mean Value Theorem (MVT) If f is continuous on [a, b] and differentiable on (a, b), then there exists at least one c in (a, b) such that f′(c) = (f(b) − f(a)) / (b − a). In words: the instantaneous slope at c equals the average slope across the whole interval — the secant line and some tangent line are parallel.
Special Case — Rolle's Theorem If, in addition, f(a) = f(b), the average rate of change is 0 — so the MVT guarantees a c in (a, b) with f′(c) = 0: a horizontal tangent somewhere strictly between two equal function values.
Worked Example Let f(x) = x³ − 3x² + 4 on [0, 3]. f(0) = 4 and f(3) = 27 − 27 + 4 = 4, so f(0) = f(3) — Rolle's Theorem applies. f′(x) = 3x² − 6x = 3x(x − 2), which is 0 at x = 0 and x = 2. Only x = 2 lies in the open interval (0, 3), so c = 2 is the guaranteed value.

Check your recall

1. The Mean Value Theorem guarantees a point c where f′(c) equals:

The MVT's conclusion is f′(c) = (f(b)−f(a))/(b−a) — exactly the secant line's slope across [a,b]. "Tangent slope" is circular (f′(c) already is a tangent slope), and the other two options describe different quantities entirely.

2. Rolle's Theorem is the special case of the MVT where f(a) = ___.

When the two endpoint values are equal, f(a) = f(b), the average rate of change is 0, so Rolle's Theorem guarantees a horizontal tangent instead of just some parallel tangent.

3. For f(x) = x³ − 3x² + 4 on [0,3], the value of c guaranteed by Rolle's Theorem is:

f′(x) = 3x(x−2) = 0 at x = 0 and x = 2, but x = 0 is an endpoint, not interior to (0,3) — only x = 2 qualifies as the guaranteed c.
