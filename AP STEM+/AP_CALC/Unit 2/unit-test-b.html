1. The difference quotient [f(a + h) − f(a)] / h computes:

For any fixed nonzero h, the difference quotient is only an average rate of change (a secant slope) — it only becomes the exact derivative, f′(a), in the limit as h shrinks to 0.

2. For g(x) = x³, use the symmetric difference quotient [g(a + h) − g(a − h)] / (2h) to estimate g′(4) with h = 0.1. Answer both parts:

(a) g(4.1) − g(3.9) is closest to:

(b) Fill in the blank: [g(4.1) − g(3.9)] / 0.2 rounds to ___ (to two decimal places).

(a) g(4.1) = 4.1³ = 68.921 and g(3.9) = 3.9³ = 59.319, so their difference is 68.921 − 59.319 = 9.602. (b) Dividing by 2h = 0.2 gives 9.602 / 0.2 = 48.01, very close to the exact derivative g′(4) = 3(4)² = 48.

3. The Leibniz notation dy/dx and the Lagrange notation f′(x) both refer to:

The two notations are simply different styles for naming the identical concept — Leibniz notation emphasizes a ratio of tiny changes, Lagrange notation is more compact, but neither changes what's being computed.

4. f(x) = x^(2/3) is continuous at x = 0 but has a cusp there, with the one-sided slopes heading to −∞ and +∞. This function is an example of:

x^(2/3) is continuous everywhere, including at 0, yet its derivative fails to exist there because of the cusp — proving continuity alone never guarantees differentiability. ("Differentiability without continuity" is impossible outright, since differentiable always implies continuous.)

5. For h(x) = 3x⁴ + 5x³ − 2x + 8, answer both parts:

(a) h′(x) equals:

(b) Fill in the blank: h″(x) = 36x² + ___.

(a) Term by term: d/dx[3x⁴] = 12x³, d/dx[5x³] = 15x², d/dx[−2x] = −2, d/dx[8] = 0 — giving 12x³ + 15x² − 2. (b) Differentiating again: 12x³ → 36x², 15x² → 30x, and −2 → 0, so h″(x) = 36x² + 30x.

6. For f(x) = 4cos(x) + sin(x), answer both parts:

(a) f′(x) equals:

(b) Fill in the blank: f′(0) = ___.

(a) d/dx[4cos x] = −4sin x, and d/dx[sin x] = cos x, so f′(x) = −4sin x + cos x. (b) At x = 0: f′(0) = −4sin(0) + cos(0) = 0 + 1 = 1.

7. Fill in the blank: d/dx[3 ln x] = ___ (in terms of x).

Since d/dx[ln x] = 1/x, the Constant Multiple Rule carries the 3 through unchanged: d/dx[3 ln x] = 3/x.

8. d/dx[cot x] equals:

Cotangent's derivative is −csc²x — the "co" function pairs with the minus sign (as cosine did in the sin/cos pair), and shouldn't be confused with tangent's derivative (sec²x, no minus sign) or cosecant's own derivative (−csc x cot x).

9. For p(x) = x³·sin(x), answer both parts:

(a) p′(x) equals:

(b) Fill in the blank: p′(0) = ___.

(a) With f(x) = x³ (f′ = 3x²) and g(x) = sin x (g′ = cos x), the Product Rule gives p′(x) = 3x²sin x + x³cos x. (b) At x = 0: p′(0) = 3(0)²sin(0) + 0³cos(0) = 0.

10. For q(x) = sin(x) / (x + 3), answer both parts:

(a) q′(x) equals:

(b) Fill in the blank: q′(0) = ___ (as a fraction).

(a) With f(x) = sin x (f′ = cos x) and g(x) = x + 3 (g′ = 1), the Quotient Rule gives q′(x) = [f′g − fg′]/g² = [cos(x)(x+3) − sin(x)]/(x+3)². (b) At x = 0: q′(0) = [cos(0)(3) − sin(0)]/3² = [3 − 0]/9 = 1/3.
