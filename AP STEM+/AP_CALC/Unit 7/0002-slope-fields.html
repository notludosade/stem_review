Slope Fields

A differential equation gives a slope at every point in the plane, before any solving happens at all. Plotting all those slopes at once is a slope field — a picture of every solution simultaneously.

← Lesson 1 Lesson 3 → Contents Glossary →

1. What a slope field shows

Definition — Slope Field For a differential equation dy/dx = f(x, y), a slope field (or direction field) draws a short line segment at each point (x, y) on a grid, with slope f(x, y). Any solution curve, wherever it passes through the grid, must run tangent to the segment at that point — the field shows the "flow" every solution has to follow, without solving anything.
Worked Example For dy/dx = x − y: at (2, 0), the slope is 2 − 0 = 2, so the segment there tilts steeply upward. At (0, 2), the slope is 0 − 2 = −2, tilting steeply downward. At any point where y = x, the slope is 0 — flat segments trace out the line y = x.

2. Reasoning from the field

Method — Sketching a Solution from a Slope Field To sketch the solution through a given point, start there and follow the tilt of the nearby segments, moving in the direction they point — the resulting curve stays tangent to the field the whole way.

1. In a slope field for dy/dx = x − y, the segment at the point (3, 3) is:

x − y = 3 − 3 = 0 at that point — any point on the line y = x gives a flat segment for this particular differential equation.

2. A solution curve sketched from a slope field must stay ___ to every segment it passes through.

Each segment shows the exact slope the solution must have at that point, so a correctly sketched curve runs tangent to the field the entire way through.

3. A slope field is built directly from:

Every segment's slope comes straight from evaluating f(x, y) at that point — no solving is required to draw the field, which is exactly what makes it useful before a solution technique is available.
