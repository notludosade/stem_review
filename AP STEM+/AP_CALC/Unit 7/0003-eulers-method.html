Euler's Method

Following a slope field by eye gives a rough sketch. Euler's Method turns "follow the arrows" into an exact numerical procedure — small, computable steps that approximate a solution the equation might not even have a clean formula for.

← Lesson 2 Lesson 4 → Contents Glossary →

1. The method

Method — Euler's Method Given dy/dx = f(x, y) with y(x₀) = y₀ and a step size h, repeatedly apply: xn+1 = xn + h and yn+1 = yn + h·f(xn, yn). Each step uses the slope field's value at the current point to predict the next one — exactly the "follow the arrow" idea from Lesson 2, but stepped forward by a fixed, precise amount instead of sketched by eye.
Worked Example For dy/dx = x + y, y(0) = 1, with step size h = 0.5: Step 1 — slope at (0, 1) is 0 + 1 = 1, so y₁ = 1 + 0.5(1) = 1.5 at x₁ = 0.5. Step 2 — slope at (0.5, 1.5) is 0.5 + 1.5 = 2, so y₂ = 1.5 + 0.5(2) = 2.5 at x₂ = 1.0. Euler's Method estimates y(1) ≈ 2.5 using only two steps.

3. Sources of error

Fact — Euler's Method Is an Approximation Each step uses the slope at the start of the interval and assumes it holds for the whole step — but the true slope is changing continuously. That mismatch is truncation error, and it accumulates over steps. Smaller h means more steps but less error per step; in the limit as h → 0, the estimate approaches the exact solution.

Check your recall

1. Euler's Method update rule for y is:

Each new y-value is the old one plus the step size times the slope at the current point — a direct numerical version of "follow the arrow for a distance h."

2. For dy/dx = x + y, y(0) = 1, h = 0.5, two Euler steps give y(1) ≈ ___

Step 1 gives (0.5, 1.5); step 2 uses slope 0.5 + 1.5 = 2 to reach y₂ = 1.5 + 0.5(2) = 2.5 at x = 1.

3. Making the step size h smaller generally:

A smaller h means the slope is re-evaluated more often, so each step's assumption that the slope stays constant holds more nearly true — at the cost of needing more steps to cover the same distance.

Ask for practice with a non-constant step size, or a case where f depends on both x and y in a trickier way, if the mechanics still feel unfamiliar.
